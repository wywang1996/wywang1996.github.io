滞回曲线

构件或结构在循环荷载下的力–位移关系， 含骨架曲线、等效粘滞阻尼比与 损伤指标。滞回曲线的形状、面积与退化特征 直接反映构件的耗能能力与抗震性能， 是拟静力试验与弹塑性时程分析的核心输出。

数据来源

  • 拟静力试验——在试验机上对构件施加循环位移， 作动器记录位移与反力，是滞回曲线最直接的来源。
  • 弹塑性时程分析——ETABS、SAP2000、Perform-3D、 OpenSees、ABAQUS，输出控制点的位移与力时程。
  • 纤维截面模型——OpenSees 的 forceBeamColumn 单元，可以逐点输出截面弯矩–曲率 或构件力–位移关系。
  • 恢复力模型——如 Clough、Takeda、Bouc-Wen 等， 在数值模拟中直接生成滞回关系。
本页示例是一个典型的钢筋混凝土柱滞回曲线： 初始弹性刚度 Ke ≈ 24 kN/mm，屈服力 Vy ≈ 260 kN， 峰值力 Vmax ≈ 320 kN，滞回环随位移增大逐渐饱满， 呈现明显的捏拢效应。替换为你自己的试验或分析结果只需修改 hysteresis.csv。

计算步骤：从力-位移数据提取滞回特征

滞回曲线的原始数据是力与位移的时程， 从中提取四类特征量：骨架曲线、等效粘滞阻尼比、损伤指标与耗能。 这些量是评价构件抗震性能的核心指标。

(t, d, F) 时程 → 找各循环峰值 → 连接峰值 → 骨架曲线 → 计算每个循环的滞回面积 Ah → 等效粘滞阻尼比 ζeq = Ah / (2π · Fm · dm) → 累积耗能 Σ Ah → 损伤指标

四个关键量的定义

量 定义 物理意义
骨架曲线 连接各循环位移峰值的包络线 反映构件的整体力-位移关系
等效粘滞阻尼比 ζeq ζeq = Ah / (2π · Fm · dm) 衡量滞回环的饱满程度，反映耗能能力
累积耗能 Eh 所有循环滞回面积之和 反映构件的总耗能能力
损伤指标 DI DI = Eh / (Fy · dy) 综合反映累计损伤程度
常用损伤指标（DI）的几种形式： Park-Ang 指标（考虑位移与耗能）、 累积塑性位移比、累积耗能比。 本页采用最简单的累积耗能比形式，可根据需要替换。

Python 代码：滞回特征提取

hysteresis_features.pyPython
# =============================================================
# 滞回曲线特征提取
# -------------------------------------------------------------
# 输入：hysteresis.csv
#   time_s,disp_mm,force_kN
# -------------------------------------------------------------
# 输出：
#   - 骨架曲线数据
#   - 每个循环的等效粘滞阻尼比 ζeq
#   - 累积耗能 Eh
#   - 损伤指标 DI
# =============================================================

import numpy as np

# ---- 1. 读取数据 ----
data = np.loadtxt('hysteresis.csv', delimiter=',', skiprows=1)
t = data[:, 0]
d = data[:, 1]
F = data[:, 2]

# ---- 2. 找位移峰值点（局部极值） ----
# 相邻三点，中间点比两边大或小 → 极值
peaks_idx = []
for i in range(1, len(d) - 1):
    if (d[i] > d[i-1] and d[i] > d[i+1]) or \
       (d[i] < d[i-1] and d[i] < d[i+1]):
        peaks_idx.append(i)

peaks_idx = np.array(peaks_idx)
print(f'检测到 {len(peaks_idx)} 个位移峰值点')

# ---- 3. 骨架曲线 ----
d_skel = d[peaks_idx]
F_skel = F[peaks_idx]

# 分正负方向，取包络
# 正方向：d > 0
pos_mask = d_skel > 0
neg_mask = d_skel < 0

# 对每个幅值，取力最大的点
def skeleton_curve(d_arr, F_arr, sign):
    if sign > 0:
        mask = d_arr > 0
    else:
        mask = d_arr < 0
    d_s = d_arr[mask]
    F_s = F_arr[mask]
    order = np.argsort(np.abs(d_s))
    d_s = d_s[order]
    F_s = F_s[order]

    # 逐点保留更大峰值
    d_out, F_out = [], []
    F_cur = 0
    for di, Fi in zip(d_s, F_s):
        if abs(Fi) >= abs(F_cur):
            d_out.append(di)
            F_out.append(Fi)
            F_cur = Fi
    return np.array(d_out), np.array(F_out)

d_pos, F_pos = skeleton_curve(d, F, +1)
d_neg, F_neg = skeleton_curve(d, F, -1)

# ---- 4. 等效粘滞阻尼比 ζeq ----
# 对每个完整循环（正峰值 → 负峰值 → 正峰值）计算滞回面积
zeta_eq = []
cumulative_energy = 0.0

for k in range(1, len(peaks_idx)):
    i1 = peaks_idx[k-1]
    i2 = peaks_idx[k]
    seg_d = d[i1:i2+1]
    seg_F = F[i1:i2+1]

    # 滞回面积（多边形面积，梯形法）
    Ah = 0.5 * np.sum((seg_d[1:] + seg_d[:-1]) *
                      (seg_F[1:] - seg_F[:-1]))

    # 峰值点
    d_m = np.max(np.abs(seg_d))
    F_m = np.max(np.abs(seg_F))

    if d_m > 0 and F_m > 0:
        zeta = Ah / (2 * np.pi * F_m * d_m)
        zeta_eq.append(zeta)
        cumulative_energy += Ah

zeta_eq = np.array(zeta_eq)
print(f'\n等效粘滞阻尼比范围：{zeta_eq.min():.4f} – {zeta_eq.max():.4f}')
print(f'累积耗能：{cumulative_energy:.2f} kN·mm')

# ---- 5. 损伤指标（累积耗能比） ----
# 取骨架曲线上的屈服点
if len(d_pos) > 0:
    # 用初始刚度定义屈服
    Ke = np.polyfit(d_pos[:3], F_pos[:3], 1)[0]
    Vy = 0.75 * np.max(F_pos)              # 简化：取峰值 75%
    dy = Vy / Ke
    DI = cumulative_energy / (Vy * dy)
    print(f'\n初始刚度 Ke = {Ke:.2f} kN/mm')
    print(f'屈服承载力 Vy = {Vy:.2f} kN')
    print(f'屈服位移 dy = {dy:.2f} mm')
    print(f'损伤指标 DI = {DI:.3f}')

# ---- 6. 绘图 ----
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

fig, ax = plt.subplots(figsize=(7.2, 5.6))

# 滞回曲线
ax.plot(d, F, lw=0.9, color='#b45309', alpha=0.85,
        label='Hysteresis loop')

# 骨架曲线
ax.plot(d_pos, F_pos, '-o', lw=1.8, color='#2563eb',
        ms=5, label='Skeleton curve (+)', zorder=5)
ax.plot(d_neg, F_neg, '-s', lw=1.8, color='#9333ea',
        ms=5, label='Skeleton curve (−)', zorder=5)

ax.axhline(0, color='#888888', lw=0.5, ls='--')
ax.axvline(0, color='#888888', lw=0.5, ls='--')

ax.set_xlabel('Displacement  d (mm)')
ax.set_ylabel('Force  F (kN)')
ax.set_title('Hysteresis curve and skeleton', fontsize=11)
ax.grid(True, ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='lower right', fontsize=9, frameon=False)
ax.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('hysteresis.png', dpi=300, bbox_inches='tight')
plt.show()
关键点：
  • 峰值检测：用局部极值法（三点比较）， 找出所有位移极值点，即每个循环的加载峰值。
  • 骨架曲线：连接各正负位移峰值对应的最大力， 正负分别处理。
  • 滞回面积：用多边形面积公式（梯形法）， 可以直接对每个循环的 (d, F) 序列计算。
  • 等效粘滞阻尼比：ζeq = Ah / (2π·Fm·dm)， 是衡量滞回环饱满程度的无量纲指标。
  • 损伤指标：本页用最简单的累积耗能比， 工程上常用的 Park-Ang 指标还需要叠加最大位移项。
Meaning

这张图说明了什么

滞回曲线描述构件或结构在往复荷载下的 力–位移关系。一个完整的滞回环由加载段与 卸载段围成，环的面积即为该循环消耗的能量。

滞回曲线的三种典型形状

  • 梭形——形状饱满，耗能能力最强， 对应弯曲破坏的钢筋混凝土构件或钢结构。
  • 弓形——中部有捏拢（pinching）现象， 耗能能力中等，对应剪切-弯曲耦合破坏或钢筋滑移。
  • 反 S 形——捏拢明显，形状滑移， 耗能能力最弱，对应剪切破坏或锚固滑移严重。

从滞回曲线上能读出什么

  • 初始刚度 Ke——原点附近滞回环的斜率， 反映构件初始弹性刚度。
  • 屈服点——滞回环从线性转向非线性的位置， 由骨架曲线与等能量法确定。
  • 峰值承载力——骨架曲线上的最大值， 反映构件的极限强度。
  • 滞回环面积——单次循环消耗的能量， 面积越大耗能能力越强。
  • 刚度退化——随着循环次数与位移幅值增加， 滞回环斜率逐渐减小，反映构件损伤累积。
  • 强度退化——相同位移幅值下， 后续循环的峰值力低于前一次，反映强度衰减。
  • 捏拢现象——加载段中部收缩， 通常由裂缝闭合或钢筋滑移引起，降低耗能能力。
  • 等效粘滞阻尼比 ζeq—— 综合反映滞回环的饱满程度。
与 Pushover 曲线的关系： Pushover 是单调加载下的力–位移曲线，而滞回是循环加载下的。 把循环加载的每个半循环的峰值点连起来，就得到骨架曲线， 与 Pushover 曲线形状接近。 滞回曲线比 Pushover 多了卸载-反向加载-再加载的完整信息， 反映了构件的耗能与退化特性。
注意：滞回曲线的形状与试验加载制度密切相关。 不同的加载幅值序列（递增、等幅、变幅）会得到不同的曲线。 工程上常用的加载制度有： 位移控制递增（每级 3 次循环，幅值递增）、 力控制（适用于弹性阶段）、 混合控制。报告中必须说明加载制度。

Python

Python 代码

依赖 numpy 与 matplotlib。 核心步骤：读取 CSV → 检测位移峰值 → 提取骨架曲线 → 计算等效粘滞阻尼比与损伤指标 → 绘图。 CSV 文件不存在时自动生成合成数据。

hysteresis.pyPython
# =============================================================
# 滞回曲线 | 力 - 位移关系
# -------------------------------------------------------------
# 输入数据：hysteresis.csv
#   time_s,disp_mm,force_kN
#   0.00,0.00,0.00
#   ...
#   单位：时间 s，位移 mm，力 kN
# -------------------------------------------------------------
# 功能：
#   1. 读取 CSV（或使用内置合成数据）
#   2. 检测位移峰值 → 骨架曲线
#   3. 计算等效粘滞阻尼比 ζeq 与累积耗能 Eh
#   4. 绘制滞回环 + 骨架曲线
# =============================================================

import os
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

CSV_FILE = 'hysteresis.csv'


def generate_synthetic():
    """CSV 缺失时生成合成滞回曲线。

    模拟一个钢筋混凝土柱：初始刚度 24 kN/mm，屈服力 260 kN，
    峰值力 320 kN，带捏拢效应。
    """
    t_all, d_all, F_all = [], [], []
    t_cur = 0.0

    # 加载幅值序列（递增）
    amplitudes = [5, 10, 20, 30, 40, 50]
    n_per_amp = 60                # 每个半循环的点数
    dt = 0.02

    Ke = 24.0                     # 初始刚度 kN/mm
    Fy = 260.0                    # 屈服力 kN
    dy = Fy / Ke                  # 屈服位移 mm
    F_max = 320.0                 # 峰值力
    alpha = 0.05                  # 强化比

    for amp in amplitudes:
        # 正向加载：0 → +amp → 0
        for direction in [+1, -1]:
            d_seg = np.linspace(0, direction * amp, n_per_amp)
            F_seg = []
            for di in d_seg:
                ad = abs(di)
                sign = np.sign(di) if di != 0 else 1
                if ad <= dy:
                    Fi = Ke * ad
                else:
                    # 强化段
                    Fi = Fy + alpha * Ke * (ad - dy)
                    # 捏拢：加一个收缩因子
                    pinch = 1.0 - 0.15 * (ad / max(amplitudes)) ** 2
                    Fi *= pinch
                F_seg.append(sign * Fi)
            d_all.extend(d_seg.tolist())
            F_all.extend(F_seg)
            t_all.extend((t_cur + dt * np.arange(n_per_amp)).tolist())
            t_cur += dt * n_per_amp

    return np.array(t_all), np.array(d_all), np.array(F_all)


# ---- 1. 读取数据 ----
if os.path.exists(CSV_FILE):
    data = np.loadtxt(CSV_FILE, delimiter=',', skiprows=1)
    t = data[:, 0]
    d = data[:, 1]
    F = data[:, 2]
    print(f'从 {CSV_FILE} 读取 {len(d)} 个点')
else:
    print(f'{CSV_FILE} 不存在，使用合成数据演示')
    t, d, F = generate_synthetic()


# ---- 2. 检测位移峰值 ----
peaks_idx = []
for i in range(1, len(d) - 1):
    if (d[i] > d[i-1] and d[i] > d[i+1]) or \
       (d[i] < d[i-1] and d[i] < d[i+1]):
        peaks_idx.append(i)
peaks_idx = np.array(peaks_idx)
print(f'检测到 {len(peaks_idx)} 个位移峰值点')


# ---- 3. 骨架曲线 ----
def skeleton_curve(d_arr, F_arr, sign):
    if sign > 0:
        mask = d_arr > 0
    else:
        mask = d_arr < 0
    d_s = d_arr[mask]
    F_s = F_arr[mask]
    order = np.argsort(np.abs(d_s))
    d_s = d_s[order]
    F_s = F_s[order]

    d_out, F_out = [], []
    F_cur = 0
    for di, Fi in zip(d_s, F_s):
        if abs(Fi) >= abs(F_cur):
            d_out.append(di)
            F_out.append(Fi)
            F_cur = Fi
    return np.array(d_out), np.array(F_out)

d_pos, F_pos = skeleton_curve(d, F, +1)
d_neg, F_neg = skeleton_curve(d, F, -1)


# ---- 4. 等效粘滞阻尼比 ----
zeta_eq = []
cumulative_energy = 0.0
for k in range(1, len(peaks_idx)):
    i1 = peaks_idx[k-1]
    i2 = peaks_idx[k]
    seg_d = d[i1:i2+1]
    seg_F = F[i1:i2+1]

    Ah = 0.5 * np.sum((seg_d[1:] + seg_d[:-1]) *
                      (seg_F[1:] - seg_F[:-1]))
    d_m = np.max(np.abs(seg_d))
    F_m = np.max(np.abs(seg_F))

    if d_m > 0 and F_m > 0:
        zeta_eq.append(Ah / (2 * np.pi * F_m * d_m))
        cumulative_energy += Ah

zeta_eq = np.array(zeta_eq)
print(f'等效粘滞阻尼比：{zeta_eq.min():.4f} – {zeta_eq.max():.4f}')
print(f'累积耗能：{cumulative_energy:.2f} kN·mm')


# ---- 5. 绘图（A4 尺寸 7.2 × 5.6 in） ----
fig, ax = plt.subplots(figsize=(7.2, 5.6))

ax.plot(d, F, lw=0.9, color='#b45309', alpha=0.85,
        label='Hysteresis loop')
ax.plot(d_pos, F_pos, '-o', lw=1.8, color='#2563eb',
        ms=5, label='Skeleton curve (+)', zorder=5)
ax.plot(d_neg, F_neg, '-s', lw=1.8, color='#9333ea',
        ms=5, label='Skeleton curve (−)', zorder=5)

ax.axhline(0, color='#888888', lw=0.5, ls='--')
ax.axvline(0, color='#888888', lw=0.5, ls='--')

# 峰值标注
if len(F_pos) > 0:
    i_pk = int(np.argmax(F_pos))
    ax.annotate(f'Vmax = {F_pos[i_pk]:.0f} kN',
                xy=(d_pos[i_pk], F_pos[i_pk]),
                xytext=(d_pos[i_pk] + 5, F_pos[i_pk] * 0.9),
                fontsize=9, color='#2563eb',
                arrowprops=dict(arrowstyle='-', color='#2563eb', lw=0.6))

ax.set_xlabel('Displacement  d (mm)')
ax.set_ylabel('Force  F (kN)')
ax.set_title('Hysteresis curve and skeleton', fontsize=11)
ax.grid(True, ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='lower right', fontsize=9, frameon=False)
ax.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('hysteresis.png', dpi=300, bbox_inches='tight')
plt.show()
关键点：
  • 位移峰值检测：三点比较法，找出所有局部极值点。
  • 骨架曲线：分正负方向，对每个幅值保留最大力， 避免重复点。
  • 滞回面积：用多边形面积公式 Ah = 0.5·Σ(dᵢ₊₁+dᵢ)·(Fᵢ₊₁−Fᵢ)， 对所有循环累加得累积耗能。
  • 等效阻尼比：ζeq = Ah / (2π·Fm·dm)， 峰值越大、环越饱满，ζeq 越大。
  • 常见现象：初始弹性阶段 ζeq 很小（≈ 0.02）， 屈服后逐渐增大到 0.15–0.30。
  • 替换为真实试验数据只需修改 hysteresis.csv。

% ===== 合成数据（当 CSV 缺失时使用） =====
function [t, d, F] = generate_synthetic()
    amplitudes = [5 10 20 30 40 50];
    n_per = 60;
    dt = 0.02;
    Ke = 24.0; Fy = 260.0; dy = Fy / Ke;
    F_max = 320.0; alpha = 0.05;

    t = []; d = []; F = [];
    t_cur = 0;

    for amp = amplitudes
        for dir = [1 -1]
            d_seg = linspace(0, dir * amp, n_per);
            F_seg = zeros(size(d_seg));
            for i = 1:numel(d_seg)
                ad = abs(d_seg(i));
                sgn = sign(d_seg(i)); if sgn == 0, sgn = 1; end
                if ad <= dy
                    Fi = Ke * ad;
                else
                    Fi = Fy + alpha * Ke * (ad - dy);
                    pinch = 1 - 0.15 * (ad / max(amplitudes))^2;
                    Fi = Fi * pinch;
                end
                F_seg(i) = sgn * Fi;
            end
            d = [d, d_seg]; %#ok
            F = [F, F_seg]; %#ok
            t = [t, t_cur + dt * (0:n_per-1)]; %#ok
            t_cur = t_cur + dt * n_per;
        end
    end
end


% ===== 骨架曲线提取 =====
function [d_out, F_out] = local_skeleton(d_arr, F_arr, sign)
    if sign > 0
        mask = d_arr > 0;
    else
        mask = d_arr < 0;
    end
    d_s = d_arr(mask);
    F_s = F_arr(mask);
    [~, order] = sort(abs(d_s));
    d_s = d_s(order);
    F_s = F_s(order);

    d_out = []; F_out = [];
    F_cur = 0;
    for i = 1:numel(d_s)
        if abs(F_s(i)) >= abs(F_cur)
            d_out(end+1) = d_s(i); %#ok
            F_out(end+1) = F_s(i); %#ok
            F_cur = F_s(i);
        end
    end
end


% ===== 等效粘滞阻尼比 =====
function [zeta_eq, Eh_total] = local_zeta_eq(d, F, peaks_idx)
    zeta_eq = [];
    Eh_total = 0;
    for k = 2:numel(peaks_idx)
        i1 = peaks_idx(k-1);
        i2 = peaks_idx(k);
        seg_d = d(i1:i2);
        seg_F = F(i1:i2);

        Ah = 0.5 * sum((seg_d(2:end) + seg_d(1:end-1)) .* ...
                       (seg_F(2:end) - seg_F(1:end-1)));
        d_m = max(abs(seg_d));
        F_m = max(abs(seg_F));

        if d_m > 0 && F_m > 0
            zeta_eq(end+1) = Ah / (2 * pi * F_m * d_m); %#ok
            Eh_total = Eh_total + Ah;
        end
    end
end

方法与说明

项符号单位

输出 · 累积耗能EhkN·mm
输出 · 损伤指标DI无量纲
  • 峰值检测：三点比较法，适用于大多数规则循环加载。
  • 骨架曲线：分正负方向，对每个幅值保留最大力， 避免重复点。
  • 滞回面积：Ah = 0.5·Σ(dᵢ₊₁+dᵢ)·(Fᵢ₊₁−Fᵢ)， 对所有循环累加得累积耗能。
  • 等效阻尼比：ζeq = Ah / (2π·Fm·dm)， 工程上屈服前 ζeq ≈ 0.02–0.05，屈服后可达 0.10–0.30。
  • 损伤指标：本页用最简单的累积耗能比。工程上更常用 Park-Ang 指标：DI = dm/du + β·Eh/(Fy·dy)。
  • 加载制度：常见的有递增位移控制（每级 3 次循环）、 等幅循环、变幅循环。报告中必须说明。
  • 常见问题：
    • 滞回环面积明显偏大 → 检查位移与力的单位是否正确， 或数据是否混入不同幅值的循环。
    • 骨架曲线不单调 → 检查是否用了同一幅值的多次循环， 或峰值检测漏掉了某些点。
    • ζeq 异常大（> 0.5）→ 数据可能包含大量噪声， 或位移幅值过小导致计算不稳定。
    • 曲线出现明显的捏拢 → 这是构件滑移或裂缝闭合， 属正常现象，会降低耗能能力。
    • CSV 编码乱码 → 保存为 UTF-8，列名严格按示例。
