H/V 谱比曲线

Nakamura 提出的水平/竖向谱比（HVSR）方法：用单台三分量记录 同时计算水平分量与竖向分量的 Fourier 幅值谱之比， 识别场地的卓越频率 f0 与放大因子 A0。 这是《场地地震安全性评价》《土动力学》中应用最广的经验方法之一。

Input Format

输入数据格式

本模板读取三个分量文件（EW / NS / UP），每个文件均为两列文本 （空格、制表符或逗号分隔），与 El Centro、SAC ASCII 等地震记录格式一致。 三个文件的采样率与量纲必须一致——HVSR 是频谱比， 只要三个分量一致，量纲会自动消去。

输入文件要求（每个文件格式相同）

列号物理量 推荐单位说明
第 1 列时间 ts（秒）等间隔。三个文件需完全同步。
第 2 列地面加速度 ag 或 m/s²三个文件使用同一单位。

三个文件命名约定

分量 文件名 说明

NS（水平 2）elcentro_NS.txt南北向加速度
UP（竖向）elcentro_UP.txt竖向加速度

Meaning

这张图说明了什么

H/V 谱比（HVSR）是 Nakamura（1989）提出的经验方法： 用同一台站的三分量记录，计算水平分量 Fourier 幅值谱 与竖向分量 Fourier 幅值谱的比值：

HVSR(f) = √[ EW(f)² + NS(f)² ] / UP(f)

物理直觉是：竖向分量几乎不受场地松软土层放大（土层对竖向振动 影响很小），而水平分量会被土层显著放大。因此二者的比值 近似反映了场地传递函数的形状。

H/V 曲线上的两个关键点

  • 卓越频率 f0——H/V 曲线峰值对应的频率。 经验关系式：f0 ≈ Vs / (4H)， Vs 为土层平均剪切波速，H 为覆盖层厚度。 这是场地分类与土层厚度估计的直接依据。
  • 放大因子 A0——H/V 峰值的高度。 反映场地对水平地震动的放大能力。经验上：
    • A0 < 2：无明显放大，岩石场地；
    • A0 = 2–4：中等放大，覆盖层较薄或 Vs 较高；
    • A0 > 4：强放大，厚软土场地。

H/V 曲线的三种典型形态

  • 单峰型——一个明显的卓越频率，对应单一土层界面。 最常见，可以直接估计覆盖层厚度。
  • 双峰型——两个峰值，对应两层或多层主要阻抗界面。 需要结合钻孔数据解释。
  • 平坦型——无明显峰值，场地无明显放大， 或记录的频率成分不足以揭示场地响应。
与场地分类的关系： 中国规范 GB 50011-2010 中，场地类别由覆盖层厚度与等效剪切波速共同确定。 H/V 谱比作为一种快速无损方法，可以在钻孔数据不足时 先给出卓越频率估计，与 Vs30 存在经验相关：
Vs30 ≈ 100 · f0 （粗略经验式，仅作参考）
注意：HVSR 是一种经验方法， 不是严格的场地传递函数。它的假设（竖向分量不受场地放大） 在某些情况下（深厚软土、强非线性、特殊震源）会失效。 规范要求最终场地评价仍应由钻孔与波速测试确定， HVSR 作为辅助手段。

Python

Python 代码

依赖 numpy 与 matplotlib。 核心步骤：读取三个分量 → 分窗加 Hann 窗 → FFT → 计算每个窗口的 H/V → 所有窗口平均 → 绘制三张子图。 不做去均值、不去线性趋势。

hvsr.pyPython
# =============================================================
# 输入数据格式（三个分量文件，每个文件两列文本）
#   第 1 列：时间 t   —— 单位 s（秒），等间隔
#   第 2 列：加速度 a —— 单位 g（或 m/s²，三个文件必须一致）
# -------------------------------------------------------------
# 文件名约定：
#   elcentro_EW.txt   东西向
#   elcentro_NS.txt   南北向
#   elcentro_UP.txt   竖向
# -------------------------------------------------------------
# 说明：本脚本不做去均值、不去线性趋势。
#       三个文件必须时间同步（采样率与起始时刻一致）。
# =============================================================

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.ticker import LogLocator

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 9,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

# ---- 处理参数 ----
WINDOW_SEC = 20.0    # 分窗长度（秒）
OVERLAP    = 0.5     # 窗口重叠比例
FMIN, FMAX = 0.2, 15.0   # H/V 曲线有效频率范围（Hz）
KO_B       = 40.0    # Konno-Ohmachi 平滑带宽参数


# ---------- 1. 读取三个分量 ----------
def read_two_cols(fname):
    t, a = np.loadtxt(fname, unpack=True)
    return t, a

t, ew = read_two_cols('elcentro_EW.txt')
_, ns = read_two_cols('elcentro_NS.txt')
_, up = read_two_cols('elcentro_UP.txt')

fs = 1.0 / (t[1] - t[0])
n  = len(ew)
print(f'采样率 fs = {fs:.1f} Hz，长度 n = {n} 点，时长 {t[-1]:.1f} s')


# ---------- 2. Konno-Ohmachi 平滑（对数间隔移动加权） ----------
def konno_ohmachi(freqs, spec, b=KO_B):
    """对谱做 Konno-Ohmachi 平滑（对数频率域）。"""
    n = len(freqs)
    out = np.zeros(n)
    for i in range(n):
        fi = freqs[i]
        if fi <= 0:
            out[i] = spec[i]
            continue
        x = b * np.log10(freqs / fi)
        w = np.where(np.abs(x) < 1e-10, 1.0, np.sin(x) / x)
        w = np.where(np.isfinite(w), w, 0.0)
        num = np.sum(w * spec)
        den = np.sum(w)
        out[i] = num / den if den > 0 else spec[i]
    return out


# ---------- 3. 分窗计算 H/V ----------
def compute_hvsr(ew, ns, up, fs, window_sec, overlap):
    """返回 (freqs, hvsr_all, hvsr_mean, hvsr_std)。"""
    n_win = int(window_sec * fs)
    step  = int(n_win * (1 - overlap))
    win   = np.hanning(n_win)
    n_total = len(ew)
    n_windows = (n_total - n_win) // step + 1
    freqs = np.fft.rfftfreq(n_win, 1 / fs)

    hvsr_all = []
    for k in range(n_windows):
        i0 = k * step
        i1 = i0 + n_win
        if i1 > n_total:
            break

        EW_f = np.fft.rfft(ew[i0:i1] * win)
        NS_f = np.fft.rfft(ns[i0:i1] * win)
        UP_f = np.fft.rfft(up[i0:i1] * win)

        # 水平分量：两个水平分量的平方和开根号
        H_f = np.sqrt(np.abs(EW_f) ** 2 + np.abs(NS_f) ** 2)
        V_f = np.abs(UP_f)

        # Konno-Ohmachi 平滑
        H_f = konno_ohmachi(freqs, H_f)
        V_f = konno_ohmachi(freqs, V_f)

        # 避免除零
        V_f = np.where(V_f < 1e-20, 1e-20, V_f)
        hvsr_all.append(H_f / V_f)

    hvsr_all = np.array(hvsr_all)
    hvsr_mean = hvsr_all.mean(axis=0)
    hvsr_std  = hvsr_all.std(axis=0)
    return freqs, hvsr_all, hvsr_mean, hvsr_std


freqs, hvsr_all, hvsr_mean, hvsr_std = compute_hvsr(
    ew, ns, up, fs, WINDOW_SEC, OVERLAP)

# 限制到有效频率范围
mask = (freqs >= FMIN) & (freqs <= FMAX)
f_plot = freqs[mask]
H_plot = hvsr_mean[mask]

# ---- 找峰值 (f0, A0) ----
i0 = np.argmax(H_plot)
f0 = f_plot[i0]
A0 = H_plot[i0]
print(f'卓越频率 f0 ≈ {f0:.3f} Hz，放大因子 A0 ≈ {A0:.2f}')


# ---------- 4. 绘制三张子图 ----------
fig, axes = plt.subplots(3, 1, figsize=(7.2, 8.0))

# ===== (a) 三分量时程 =====
ax = axes[0]
ax.plot(t, ew, lw=0.5, color='#b45309', label='EW', alpha=0.85)
ax.plot(t, ns, lw=0.5, color='#2563eb', label='NS', alpha=0.85)
ax.plot(t, up, lw=0.5, color='#15803d', label='UP', alpha=0.85)
ax.set_xlabel('Time (s)')
ax.set_ylabel('Acc. (g)')
ax.set_title('(a) Three-component acceleration', fontsize=10)
ax.legend(loc='upper right', fontsize=8, frameon=False, ncol=3)
ax.grid(True, ls=':', lw=0.4, alpha=0.6)

# ===== (b) 三分量 Fourier 幅值谱 =====
ax = axes[1]
n_win = int(WINDOW_SEC * fs)
win = np.hanning(n_win)
EW_f = np.abs(np.fft.rfft(ew[:n_win] * win))
NS_f = np.abs(np.fft.rfft(ns[:n_win] * win))
UP_f = np.abs(np.fft.rfft(up[:n_win] * win))
f_full = np.fft.rfftfreq(n_win, 1 / fs)
m2 = (f_full >= FMIN) & (f_full <= FMAX)
ax.loglog(f_full[m2], EW_f[m2], lw=0.9, color='#b45309', label='EW')
ax.loglog(f_full[m2], NS_f[m2], lw=0.9, color='#2563eb', label='NS')
ax.loglog(f_full[m2], UP_f[m2], lw=0.9, color='#15803d', label='UP')
ax.set_xlabel('Frequency f (Hz)')
ax.set_ylabel('Fourier amplitude')
ax.set_title('(b) Fourier amplitude spectra', fontsize=10)
ax.legend(loc='upper right', fontsize=8, frameon=False)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)

# ===== (c) H/V 谱比曲线 =====
ax = axes[2]
# 各窗口淡色曲线
for k in range(hvsr_all.shape[0]):
    ax.plot(freqs[mask], hvsr_all[k][mask],
            color='#cbd5e1', lw=0.5, alpha=0.5, zorder=1)
# ±1σ 带
ax.fill_between(f_plot,
                (hvsr_mean - hvsr_std)[mask],
                (hvsr_mean + hvsr_std)[mask],
                color='#c4b5fd', alpha=0.4, zorder=2)
# 均值曲线
ax.plot(f_plot, H_plot, color='#9333ea', lw=1.8, label='Mean H/V', zorder=3)
# 参考线
ax.axhline(1.0, color='#888888', lw=0.6, ls='--', zorder=1)
# 峰值标记
ax.plot(f0, A0, 'o', color='#9333ea', ms=6, zorder=4)
ax.axvline(f0, color='#9333ea', lw=0.7, ls=':', zorder=1)
ax.annotate(f'f$_0$ = {f0:.2f} Hz\nA$_0$ = {A0:.2f}',
            xy=(f0, A0), xytext=(f0 * 2.2, A0 * 0.9),
            fontsize=9, color='#222222',
            arrowprops=dict(arrowstyle='-', color='#888888', lw=0.6))

ax.set_xscale('log')
ax.set_xlabel('Frequency f (Hz)')
ax.set_ylabel('H/V spectral ratio')
ax.set_title('(c) H/V spectral ratio', fontsize=10)
ax.set_xlim(FMIN, FMAX)
ax.set_ylim(0, max(A0 * 1.35, 4))
ax.legend(loc='upper right', fontsize=8, frameon=False)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)

# ---------- 5. 统一格式 ----------
for ax in axes:
    ax.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('hvsr.png', dpi=300, bbox_inches='tight')
plt.show()
关键点：
  • 分窗：默认 20 s 窗口、50% 重叠。窗口数 = 5（54 s 记录）。
  • Hann 窗：抑制频谱泄漏。
  • Konno-Ohmachi 平滑：对数频率域平滑，避免高频段样本过密、低频段样本过稀。
  • 水平分量：H = √(EW² + NS²)，而不是简单平均。
  • 峰值识别：在 0.2–15 Hz 范围内找 H/V 最大值。
  • 不做去均值、不去线性趋势。

MATLAB 代码

用 readmatrix 读取三个分量，hann 加窗， fft 变换。Konno-Ohmachi 平滑用局部函数实现。 不去均值、不去趋势。

hvsr.mMATLAB
% =============================================================
% 输入数据格式（三个分量文件，每个文件两列文本）
%   第 1 列：时间 t   —— 单位 s（秒），等间隔
%   第 2 列：加速度 a —— 单位 g（或 m/s²，三个文件必须一致）
% -------------------------------------------------------------
% 文件名约定：
%   elcentro_EW.txt   东西向
%   elcentro_NS.txt   南北向
%   elcentro_UP.txt   竖向
% -------------------------------------------------------------
% 说明：本脚本不做去均值、不去线性趋势。
% =============================================================

WINDOW_SEC = 20.0;
OVERLAP    = 0.5;
FMIN = 0.2; FMAX = 15.0;
KO_B = 40.0;

% ---------- 1. 读取三个分量 ----------
EW = readmatrix('elcentro_EW.txt');
NS = readmatrix('elcentro_NS.txt');
UP = readmatrix('elcentro_UP.txt');

t  = EW(:, 1);
ew = EW(:, 2);
ns = NS(:, 2);
up = UP(:, 2);

fs = 1 / (t(2) - t(1));
n  = numel(ew);
fprintf('采样率 fs = %.1f Hz，长度 n = %d 点，时长 %.1f s\n', ...
        fs, n, t(end));

% ---------- 2. 分窗计算 H/V ----------
n_win = round(WINDOW_SEC * fs);
step  = round(n_win * (1 - OVERLAP));
win   = hann(n_win);
n_windows = floor((n - n_win) / step) + 1;

freqs = (0:n_win/2)' * fs / n_win;
n_freq = numel(freqs);

hvsr_all = zeros(n_windows, n_freq);

for k = 1:n_windows
    i0 = (k - 1) * step + 1;
    i1 = i0 + n_win - 1;
    if i1 > n
        break;
    end

    EW_f = fft(ew(i0:i1) .* win);
    NS_f = fft(ns(i0:i1) .* win);
    UP_f = fft(up(i0:i1) .* win);

    half = 1:n_freq;
    EW_a = abs(EW_f(half));
    NS_a = abs(NS_f(half));
    UP_a = abs(UP_f(half));

    H_a = sqrt(EW_a .^ 2 + NS_a .^ 2);
    V_a = UP_a;

    % Konno-Ohmachi 平滑
    H_s = konno_ohmachi(freqs, H_a, KO_B);
    V_s = konno_ohmachi(freqs, V_a, KO_B);

    V_s = max(V_s, 1e-20);
    hvsr_all(k, :) = (H_s ./ V_s)';
end

hvsr_mean = mean(hvsr_all, 1);
hvsr_std  = std(hvsr_all, 0, 1);

% ---------- 3. 找峰值 (f0, A0) ----------
mask = freqs >= FMIN & freqs <= FMAX;
f_plot = freqs(mask);
H_plot = hvsr_mean(mask);

[A0, i0] = max(H_plot);
f0 = f_plot(i0);

fprintf('卓越频率 f0 ≈ %.3f Hz，放大因子 A0 ≈ %.2f\n', f0, A0);

% ---------- 4. 绘制三张子图 ----------
figure('Color', 'w', 'Position', [100 100 720 800]);

% ===== (a) 三分量时程 =====
subplot(3, 1, 1);
plot(t, ew, 'Color', [0.71 0.33 0.04], 'LineWidth', 0.5); hold on;
plot(t, ns, 'Color', [0.15 0.39 0.92], 'LineWidth', 0.5);
plot(t, up, 'Color', [0.08 0.50 0.24], 'LineWidth', 0.5);
xlabel('Time (s)'); ylabel('Acc. (g)');
title('(a) Three-component acceleration', 'FontSize', 10);
legend({'EW', 'NS', 'UP'}, 'Location', 'northeast', 'Box', 'off', 'FontSize', 8);
grid on; box on;

% ===== (b) 三分量 Fourier 幅值谱 =====
subplot(3, 1, 2);
EW_f = abs(fft(ew(1:n_win) .* win));
NS_f = abs(fft(ns(1:n_win) .* win));
UP_f = abs(fft(up(1:n_win) .* win));
loglog(freqs(mask), EW_f(mask), 'Color', [0.71 0.33 0.04], 'LineWidth', 0.9); hold on;
loglog(freqs(mask), NS_f(mask), 'Color', [0.15 0.39 0.92], 'LineWidth', 0.9);
loglog(freqs(mask), UP_f(mask), 'Color', [0.08 0.50 0.24], 'LineWidth', 0.9);
xlabel('Frequency f (Hz)'); ylabel('Fourier amplitude');
title('(b) Fourier amplitude spectra', 'FontSize', 10);
legend({'EW', 'NS', 'UP'}, 'Location', 'northeast', 'Box', 'off', 'FontSize', 8);
grid on; box on;

% ===== (c) H/V 谱比曲线 =====
subplot(3, 1, 3);
% 各窗口
for k = 1:n_windows
    semilogx(freqs(mask), hvsr_all(k, mask), 'Color', [0.8 0.84 0.88], ...
             'LineWidth', 0.5); hold on;
end
% ±1σ 带
fill([f_plot; flipud(f_plot)], ...
     [hvsr_mean(mask) - hvsr_std(mask); flipud(hvsr_mean(mask) + hvsr_std(mask))]', ...
     [0.77 0.71 0.99], 'FaceAlpha', 0.4, 'EdgeColor', 'none');
% 均值曲线
semilogx(f_plot, H_plot, 'Color', [0.58 0.20 0.92], 'LineWidth', 1.8);
% 参考线
yline(1.0, '--', 'Color', [0.53 0.53 0.53], 'LineWidth', 0.6);

title('(c) H/V spectral ratio', 'FontSize', 10);
xlim([FMIN FMAX]);
ylim([0 max(A0 * 1.35, 4)]);
grid on; box on;

% 统一格式
for k = 1:3
    subplot(3, 1, k);

end

% ===== 局部函数：Konno-Ohmachi 平滑 =====
function out = konno_ohmachi(freqs, spec, b)
    n = numel(freqs);
    out = zeros(size(spec));
    for i = 1:n
        fi = freqs(i);
        if fi <= 0
            out(i) = spec(i);
            continue;
        end
        x = b * log10(freqs / fi);
        w = ones(size(x));
        idx = abs(x) > 1e-10;
        w(idx) = sin(x(idx)) ./ x(idx);
        w = w(:);
        num = sum(w .* spec(:));
        den = sum(w);
        out(i) = num / den;
    end
end

输入 / 输出量纲一览

项符号单位
输入 · 时间ts（秒）
输入 · 加速度ag / m/s²（三分量一致）
中间 · 频率fHz
输出 · 水平幅值谱H(f)与输入加速度同单位
输出 · 竖向幅值谱V(f)与输入加速度同单位
输出 · H/V 谱比HVSR(f)无量纲
输出 · 卓越频率f0Hz
输出 · 放大因子A0无量纲
  • 方法：Nakamura (1989) 单台三分量 HVSR 方法。
  • 分窗：默认 20 s 窗口、50% 重叠。窗口数 = floor((n − n_win) / step) + 1。
  • Hann 窗：抑制频谱泄漏，代价是频率分辨率略微降低。
  • Konno-Ohmachi 平滑：对数频率域加权平滑，参数 b = 40 是常用值。 b 越大平滑越强。等价于带宽 ≈ f / b。
  • 水平分量：H = √(EW² + NS²)，两个水平分量独立参与。
  • 峰值识别：在 0.2–15 Hz 有效频率范围内找 H/V 最大值。
  • 无去趋势：不做去均值、不去线性趋势，直接使用原始记录。
  • 常见问题：
    • HVSR 曲线高频段异常抬升 → 竖向记录含较多噪声，需检查 UP 分量的信噪比。
    • 峰值不明显 → 记录的频率成分不足，或场地本身无明显放大。
    • 三个窗口的 H/V 差异过大 → 记录的 S 波段到达时间过晚，可用窗口数不足。
    • 峰值频率随时间漂移 → 可能记录了非线性场地响应（强震下土层软化）。
    • f0 与实际钻孔不符 → 检查三分量是否时间同步，或检查峰值是否误识别为噪声峰。
