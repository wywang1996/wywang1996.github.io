Pushover 曲线

静力弹塑性分析（Pushover）的核心输出：基底剪力–顶点位移曲线。 图上叠加等能量法双线性理想化、屈服点与 峰值点，给出初始刚度 Ke、屈服承载力 Vy、 屈服位移 dy、极限位移 du 与延性比 μ。 这是能力谱法、性能化设计与结构抗倒塌评估的起点。

数据来源

  • 通用有限元程序——ETABS、SAP2000、Perform-3D、ABAQUS、 OpenSees、MIDAS Gen，都提供 Pushover 分析功能。
  • 加载模式——常用倒三角分布、均匀分布、 一阶振型分布，不同加载模式的结果略有差别。
  • 目标位移——由能力谱法（ATC-40、FEMA 440） 或位移系数法（FEMA 356）确定。
本页示例是一条典型的 Pushover 曲线： 初始弹性段刚度 Ke ≈ 24 kN/mm，屈服后进入轻微强化段， 在顶点位移约 100 mm 处达到峰值 Vmax ≈ 800 kN， 随后进入下降段。替换为你自己的分析结果只需修改 pushover.csv。

计算步骤：用 OpenSees 计算 Pushover 曲线

实际工程几乎不会手算 Pushover 曲线，都用有限元程序完成。 下面以 OpenSeesPy 为例，给出一个单层框架的完整计算流程。 SAP2000、ETABS、Perform-3D、ABAQUS、MIDAS 的核心步骤与之一致。

七步计算流程

  1. 建模——定义节点坐标、单元、支座约束。
  2. 本构——定义材料本构（钢材双线性、混凝土 Kent-Scott-Park 等）。
  3. 截面——用纤维截面（Fiber Section）描述构件的非线性行为。
  4. 单元——用 forceBeamColumn 非线性梁柱单元连接节点， 每个单元沿长度布多个积分点。
  5. 重力荷载——先施加恒载、活载，让结构进入初始受力状态， 然后用 loadConst('-time', 0) 把时间归零。
  6. Pushover 工况——按倒三角分布施加侧向力， 用位移控制（DisplacementControl）逐步加载。
  7. 记录数据——每步收敛后记录顶点位移 d 与基底剪力 V，导出为 CSV。
核心思想：每个位移增量都需要做 Newton-Raphson 迭代求解非线性平衡方程 Kt·Δu = ΔF。构件屈服后切线刚度矩阵 Kt 不断更新， 曲线上每一个 (d, V) 点都是一次收敛迭代的结果。

OpenSeesPy 完整代码（单层单跨框架）

opensees_pushover.pyPython
# =============================================================
# Pushover 分析 | OpenSeesPy 完整示例
# -------------------------------------------------------------
# 结构：单层单跨平面框架
#   柱高 3000 mm，跨度 5000 mm
#   柱底固定，梁柱刚接
#   钢材：Fy = 235 MPa, E = 210 GPa, 强化比 0.02
#   截面：400 × 400 mm 矩形（简化为纤维截面）
# -------------------------------------------------------------
# 输出：pushover.csv
#   disp_mm,shear_kN
#   顶点位移（mm），基底剪力（kN）
# =============================================================

import openseespy.opensees as ops
import numpy as np

# ---------- 1. 初始化模型 ----------
ops.wipe()
ops.model('basic', '-ndm', 2, '-ndf', 3)

# 节点（单位：mm）
H = 3000.0        # 柱高
L = 5000.0        # 跨度

ops.node(1, 0.0, 0.0)     # 左柱底
ops.node(2, 0.0, H)       # 左柱顶
ops.node(3, L,  0.0)      # 右柱底
ops.node(4, L,  H)        # 右柱顶

# 约束：柱底固定
ops.fix(1, 1, 1, 1)
ops.fix(3, 1, 1, 1)

# ---------- 2. 材料本构 ----------
# Steel01：双线性随动强化钢材
Fy = 235.0        # 屈服强度 MPa
E0 = 210000.0     # 弹性模量 MPa
b  = 0.02         # 强化比

ops.uniaxialMaterial('Steel01', 1, Fy, E0, b)

# ---------- 3. 纤维截面 ----------
secTag = 1
ops.section('Fiber', secTag)

# 矩形截面 400×400，用 10×10 纤维离散
# patch('rect', matTag, numSubdivY, numSubdivZ, yI, zI, yJ, zJ)
B = 400.0
ops.patch('rect', 1, 10, 10, -B/2, -B/2, B/2, B/2)

# ---------- 4. 单元 ----------
# 几何转换：线性
ops.geomTransf('Linear', 1)

# 非线性梁柱单元：forceBeamColumn
# 沿长度方向用 Lobatto 积分，5 个积分点
integTag = 1
ops.beamIntegration('Lobatto', integTag, secTag, 5)

ops.element('forceBeamColumn', 1, 1, 2, 1, integTag)  # 左柱
ops.element('forceBeamColumn', 2, 3, 4, 1, integTag)  # 右柱

# 刚性梁（弹性，刚度放大 100 倍）
ops.element('elasticBeamColumn', 3, 2, 4,
            B*B, E0*100, 1e10, 1)

# ---------- 5. 重力荷载 ----------
ops.timeSeries('Linear', 1)
ops.pattern('Plain', 1, 1)

# 每个柱顶施加 100 kN 竖向荷载
ops.load(2, 0.0, -100000.0, 0.0)
ops.load(4, 0.0, -100000.0, 0.0)

ops.system('BandGeneral')
ops.numberer('RCM')
ops.constraints('Plain')
ops.algorithm('Newton')
ops.integrator('LoadControl', 0.1)
ops.analysis('Static')

ok = ops.analyze(10)
if ok != 0:
    raise RuntimeError('重力荷载分析不收敛')

# 时间归零，重力荷载保持
ops.loadConst('-time', 0.0)

# ---------- 6. Pushover 工况 ----------
# 倒三角分布：单层结构 → 侧向力全部加在柱顶
V_ref = 10000.0   # 参考侧向力 N

ops.pattern('Plain', 2, 1)
ops.load(2, V_ref, 0.0, 0.0)
ops.load(4, V_ref, 0.0, 0.0)

# 位移控制：控制节点 4，自由度 1（X 方向），步长 0.1 mm
d_incr = 0.1
ops.integrator('DisplacementControl', 4, 1, d_incr)

ops.system('BandGeneral')
ops.numberer('RCM')
ops.constraints('Plain')
ops.algorithm('Newton')
ops.test('NormDispIncr', 1e-6, 20, 0)
ops.analysis('Static')

# ---------- 7. 逐步加载并记录 ----------
N_steps = 3000
d_list = []
V_list = []

for i in range(N_steps):
    ok = ops.analyze(1)
    if ok != 0:
        print(f'不收敛，第 {i} 步，位移 = {ops.nodeDisp(4,1):.2f} mm')
        break

    d = ops.nodeDisp(4, 1)           # 顶点位移 mm
    lam = ops.getTime()              # 加载系数
    V = lam * 2 * V_ref / 1000.0     # 基底剪力 kN（两根柱侧向力之和）

    d_list.append(d)
    V_list.append(V)

    if i % 200 == 0:
        print(f'  step {i:5d}  d = {d:8.2f} mm  V = {V:8.2f} kN')

# ---------- 8. 导出 CSV ----------
d_arr = np.array(d_list)
V_arr = np.array(V_list)
out = np.column_stack([d_arr, V_arr])

np.savetxt('pushover.csv', out,
           delimiter=',',
           header='disp_mm,shear_kN',
           comments='',
           fmt='%.4f')

print(f'\n共 {len(d_arr)} 个点')
print(f'顶点位移范围：{d_arr.min():.2f} – {d_arr.max():.2f} mm')
print(f'基底剪力范围：{V_arr.min():.2f} – {V_arr.max():.2f} kN')
print('已保存 pushover.csv')
关键点：
  • 单元类型：forceBeamColumn（力插值梁柱单元）， 配合纤维截面自动考虑轴力–弯矩耦合。
  • 积分点：Lobatto 5 点，两端积分点正好落在节点处， 能准确捕捉端部塑性铰。
  • 加载模式：倒三角分布要求 Fi ∝ mi·hi， 单层结构退化为全部加在柱顶。
  • 位移控制：控制节点取屋顶质心，步长 0.1 mm， 总步数 3000 对应 300 mm 的顶点位移。
  • 基底剪力换算：V = 加载系数 × 侧向力合力， 单位从 N 换算为 kN。
  • 重力荷载：先加载，再用 loadConst('-time', 0) 把时间归零，保证 Pushover 从结构自重平衡态开始。
  • 收敛判据：NormDispIncr 容差 1e-6， 最大 20 次迭代，超过则判定不收敛（通常已到下降段）。
常见不收敛原因：
  • 步长太大——位移增量超过塑性铰的发展速度，减小到 0.05 mm 或更小。
  • 算法不稳健——把 Newton 换成 ModifiedNewton 或 KrylovNewton。
  • 下降段——承载力下降超过 20% 后求解困难， 改用 ArcLength 弧长法。
  • 本构参数不合理——检查 Fy、E0、b， 以及纤维截面的尺寸与配筋。
  • 单元划分过粗——增加积分点数量，或改为 dispBeamColumn + 更细的网格。
用其他程序时的对应设置：
  • SAP2000：定义默认塑性铰（FEMA 356）→ 新建 Pushover 工况 → 加载模式选“倒三角” → 控制位移 150 mm → 运行 → 导出 Base Reactions。
  • ETABS：类似，用 Nonlinear Static 工况， 结果表格里取 Joint Displacements 与 Base Reactions。
  • Perform-3D：用 Fiber Section + Inelastic Bar 单元，Pushover 工况与 OpenSees 思路一致。
  • ABAQUS：用 Static, Riks 分析步， 位移控制加载，提取顶部参考点的反力与位移。
Meaning

这张图说明了什么

Pushover 曲线描述结构在单调递增侧向力作用下的 整体非线性行为。横轴为控制节点的顶点位移 d，纵轴为基底剪力 V。 曲线一般分为三个阶段：

  • 弹性段——所有构件保持弹性，V 与 d 近似线性， 斜率即初始刚度 Ke；
  • 强化段——部分构件屈服，刚度下降， 曲线以较小的斜率继续上升；
  • 下降段——构件进入破坏或失稳，承载力开始衰减， 峰值点标志着结构的极限承载力。

双线性理想化的意义

真实的 Pushover 曲线是连续光滑的，直接用于计算不方便。 工程上通常把它理想化为双线性：

V(d) = Ke · d   (d ≤ dy)   ,   V(d) = Vy   (dy < d ≤ du)

最常用的双线性化方法是等能量法（equal energy）： 让双线性曲线与原曲线包围的面积相等。这样得到的等效体系 与原结构在耗能上一致，是能力谱法与 FEMA 356 系数法的基础。

从双线性化得到的五个关键量

  • 初始刚度 Ke——弹性段斜率， 反映结构的初始整体刚度。
  • 屈服承载力 Vy——理想化弹性段的终点剪力， 是结构"屈服"的等效标志。
  • 屈服位移 dy——dy = Vy / Ke。
  • 极限位移 du——分析结束时的位移， 通常取峰值承载力下降 15–20% 处，或层间位移角达到规范限值处。
  • 延性比 μ = du / dy——衡量结构 弹塑性变形能力的关键指标。μ 越大，结构抗震性能越好。
与能力谱法的关系： 把 Pushover 曲线的 V–d 关系转换为 能力谱（Sa–Sd）后， 与需求谱放在同一张 ADRS 图上，二者的交点即为性能点， 对应结构在给定地震作用下的位移需求。 本页的双线性化结果就是能力谱的输入。
注意：Pushover 分析本身是一种静力近似， 不考虑高阶振型、扭矩与循环加载退化。用于高层结构或 扭转不规则结构时，需要与动力时程分析结果对照。

Python

Python 代码

依赖 numpy 与 matplotlib。 核心函数 bilinear_idealization 用等能量法把 原始 Pushover 曲线转换为理想弹塑性双线性。 CSV 文件不存在时自动生成合成数据。

pushover.pyPython
# =============================================================
# Pushover 曲线 | 基底剪力 - 顶点位移
# -------------------------------------------------------------
# 输入数据：pushover.csv
#   disp_mm,shear_kN
#   0.0,0.0
#   2.5,60.0
#   ...
#   单位：位移 mm，剪力 kN
# -------------------------------------------------------------
# 功能：
#   1. 读取 CSV（或使用内置合成数据）
#   2. 等能量法双线性化，得到 Ke、Vy、dy、du、mu
#   3. 绘制原始曲线 + 双线性化 + 屈服点 + 峰值点
# =============================================================

import os
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

CSV_FILE = 'pushover.csv'


def generate_synthetic():
    """CSV 缺失时生成合成 Pushover 曲线（三段折线）。"""
    d = np.arange(0, 151, 2.5)
    V = np.zeros_like(d)
    for i, di in enumerate(d):
        if di <= 25:
            V[i] = 24.0 * di
        elif di <= 100:
            V[i] = 600.0 + (800.0 - 600.0) / (100.0 - 25.0) * (di - 25.0)
        else:
            V[i] = 800.0 - 2.0 * (di - 100.0)
    return d, V


def bilinear_idealization(d, V):
    """等能量法双线性化（理想弹塑性）。

    参数
    ----
    d : 顶点位移数组
    V : 基底剪力数组

    返回
    ----
    Ke : 初始刚度
    Vy : 屈服承载力
    dy : 屈服位移
    du : 极限位移（取最后一个点）
    """
    d = np.asarray(d, dtype=float)
    V = np.asarray(V, dtype=float)

    # ---- 初始刚度：用 d <= 10% d_max 的数据点线性拟合 ----
    mask = d <= 0.1 * d.max()
    if mask.sum() >= 3:
        Ke = np.polyfit(d[mask], V[mask], 1)[0]
    else:
        Ke = V[1] / d[1]

    # ---- 极限位移取最后一个点 ----
    du = d[-1]

    # ---- 原始曲线下的面积 ----
    A_actual = np.trapz(V, d)

    # ---- 解方程 Vy*du - 0.5*Vy^2/Ke = A_actual ----
    #      等价于 Vy^2 - 2*Ke*du*Vy + 2*Ke*A_actual = 0
    disc = du ** 2 - 2.0 * A_actual / Ke
    if disc < 0:
        Vy = 0.6 * V.max()   # 异常情况：退化为 0.6 Vmax
    else:
        Vy = Ke * (du - np.sqrt(disc))

    dy = Vy / Ke
    return Ke, Vy, dy, du


# ---- 1. 读取 CSV ----
if os.path.exists(CSV_FILE):
    data = np.genfromtxt(CSV_FILE, delimiter=',', names=True,
                         dtype=None, encoding='utf-8')
    d = np.asarray(data['disp_mm'], dtype=float)
    V = np.asarray(data['shear_kN'], dtype=float)
    print(f'从 {CSV_FILE} 读取 {len(d)} 个点')
else:
    print(f'{CSV_FILE} 不存在，使用合成数据演示')
    d, V = generate_synthetic()


# ---- 2. 双线性化 ----
Ke, Vy, dy, du = bilinear_idealization(d, V)
mu = du / dy

print(f'初始刚度   Ke = {Ke:.2f} kN/mm')
print(f'屈服承载力 Vy = {Vy:.2f} kN')
print(f'屈服位移   dy = {dy:.2f} mm')
print(f'极限位移   du = {du:.2f} mm')
print(f'延性比     mu = {mu:.2f}')


# ---- 3. 绘图（A4 尺寸 7.2 × 4.4 in） ----
fig, ax = plt.subplots(figsize=(7.2, 4.4))

# 原始曲线
ax.plot(d, V, lw=1.8, color='#b45309', label='Pushover curve')

# 双线性理想化
ax.plot([0, dy, du], [0, Vy, Vy], lw=1.6, color='#2563eb',
        ls='--', label='Bilinear idealization')

# 屈服点
ax.plot(dy, Vy, 'o', color='#2563eb', ms=7, zorder=5)
ax.annotate(
    f'Yield  (dy = {dy:.1f} mm, Vy = {Vy:.0f} kN)',
    xy=(dy, Vy), xytext=(dy + 15, Vy * 0.72),
    fontsize=9, color='#2563eb',
    arrowprops=dict(arrowstyle='-', color='#2563eb', lw=0.7))

# 峰值点
i_peak = int(np.argmax(V))
ax.plot(d[i_peak], V[i_peak], 'o', color='#b45309', ms=7, zorder=5)
ax.annotate(
    f'Peak  ({d[i_peak]:.0f} mm, {V[i_peak]:.0f} kN)',
    xy=(d[i_peak], V[i_peak]),
    xytext=(d[i_peak] + 8, V[i_peak] * 0.98),
    fontsize=9, color='#b45309',
    arrowprops=dict(arrowstyle='-', color='#b45309', lw=0.7))

# 极限位移竖线
ax.axvline(du, color='#888888', lw=0.7, ls=':')
ax.text(du - 3, V.max() * 0.05, f'du = {du:.0f} mm',
        fontsize=9, color='#555555', ha='right')

ax.set_xlabel('Roof displacement  d (mm)')
ax.set_ylabel('Base shear  V (kN)')
ax.set_title('Pushover curve and bilinear idealization', fontsize=11)
ax.set_xlim(0, d.max() * 1.05)
ax.set_ylim(0, V.max() * 1.18)
ax.grid(True, ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='lower right', fontsize=9, frameon=False)
ax.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('pushover.png', dpi=300, bbox_inches='tight')
plt.show()
关键点：
  • 初始刚度：用前 10% 位移范围内的数据点做线性拟合， 比直接用第一个点的斜率更稳健。
  • 等能量法：令双线性曲线与原曲线包围的面积相等， 解一元二次方程得到 Vy。
  • 极限位移：本页取最后一个数据点。实际工程中通常取 峰值承载力下降 15–20% 处，或层间位移角达到规范限值处。
  • 延性比：μ = du/dy， 是结构抗震性能的核心指标。
  • 替换为真实 Pushover 数据只需修改 pushover.csv。

% =============================================================
% Pushover 曲线 | 基底剪力 - 顶点位移
% -------------------------------------------------------------
% 输入数据：pushover.csv
%   disp_mm,shear_kN
%   0.0,0.0
%   2.5,60.0
%   ...
%   单位：位移 mm，剪力 kN
% =============================================================

CSV_FILE = 'pushover.csv';

% ---- 1. 读取 CSV ----
if isfile(CSV_FILE)
    T = readtable(CSV_FILE, 'CommentStyle', '#', ...
                  'VariableNamingRule', 'preserve');
    d = T.disp_mm;
    V = T.shear_kN;
    fprintf('从 %s 读取 %d 个点\n', CSV_FILE, numel(d));
else
    fprintf('%s 不存在，使用合成数据演示\n', CSV_FILE);
    d = (0:2.5:150)';
    V = zeros(size(d));
    for i = 1:numel(d)
        di = d(i);
        if di <= 25
            V(i) = 24.0 * di;
        elseif di <= 100
            V(i) = 600.0 + (800.0 - 600.0) / (100.0 - 25.0) * (di - 25.0);
        else
            V(i) = 800.0 - 2.0 * (di - 100.0);
        end
    end
end

% ---- 2. 双线性化 ----
[Ke, Vy, dy, du] = bilinear_idealization(d, V);
mu = du / dy;

fprintf('初始刚度   Ke = %.2f kN/mm\n', Ke);
fprintf('屈服承载力 Vy = %.2f kN\n', Vy);
fprintf('屈服位移   dy = %.2f mm\n', dy);
fprintf('极限位移   du = %.2f mm\n', du);
fprintf('延性比     mu = %.2f\n', mu);

% ---- 3. 绘图（A4 尺寸 720 × 440 px） ----
figure('Color', 'w', 'Position', [100 100 720 440]);
hold on;

% 原始曲线
plot(d, V, 'Color', [0.71 0.33 0.04], 'LineWidth', 1.8, ...
     'DisplayName', 'Pushover curve');

% 双线性
plot([0, dy, du], [0, Vy, Vy], '--', 'Color', [0.15 0.39 0.92], ...
     'LineWidth', 1.6, 'DisplayName', 'Bilinear idealization');

% 屈服点
plot(dy, Vy, 'o', 'MarkerFaceColor', [0.15 0.39 0.92], ...
     'MarkerEdgeColor', 'none', 'MarkerSize', 8, ...
     'HandleVisibility', 'off');

% 峰值点
[V_peak, i_peak] = max(V);
plot(d(i_peak), V_peak, 'o', 'MarkerFaceColor', [0.71 0.33 0.04], ...
     'MarkerEdgeColor', 'none', 'MarkerSize', 8, ...
     'HandleVisibility', 'off');

% 标注
text(dy + 8, Vy * 0.75, ...
     sprintf('Yield  (dy = %.1f mm, Vy = %.0f kN)', dy, Vy), ...
     'FontSize', 9, 'Color', [0.15 0.39 0.92]);
text(d(i_peak) + 5, V_peak * 0.98, ...

% 极限位移竖线

% ===== 局部函数：等能量法双线性化 =====
function [Ke, Vy, dy, du] = bilinear_idealization(d, V)
    d = d(:); V = V(:);

    % 初始刚度：d <= 10% * d_max 线性拟合
    mask = d <= 0.1 * max(d);
    if sum(mask) >= 2
        p = polyfit(d(mask), V(mask), 1);
        Ke = p(1);
    else
        Ke = V(2) / d(2);
    end

    du = d(end);
    A_actual = trapz(d, V);

    disc = du ^ 2 - 2.0 * A_actual / Ke;
    if disc < 0
        Vy = 0.6 * max(V);
    else
        Vy = Ke * (du - sqrt(disc));
    end

    dy = Vy / Ke;
end

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 顶点位移dmm
输入 · 基底剪力VkN
输出 · 初始刚度KekN/mm
输出 · 屈服承载力VykN
输出 · 屈服位移dymm
输出 · 极限位移dumm
输出 · 延性比μ = du/dy无量纲
  • 初始刚度：用前 10% 位移范围内的数据点线性拟合。 这样比用第一个点更稳健，减少初始不平滑的影响。
  • 等能量法：令双线性曲线与原曲线包围面积相等。 面积公式 A = Vy·du − 0.5·Vy²/Ke。
  • 方程求解：对 Vy 解一元二次方程 Vy² − 2KeduVy + 2KeA = 0， 取较小的根（理想弹塑性双线性的屈服点在下降段之前）。
  • 极限位移选取：本页取最后一个数据点。工程上通常取 峰值承载力下降 15–20% 处，或层间位移角达到规范限值处。
  • 延性比：μ = du/dy，是结构 抗震性能的核心指标。混凝土框架 μ ≈ 3–5，钢结构 μ ≈ 5–8。
  • 与能力谱的关系：双线性化后，把 V–d 转成 Sa–Sd 即得能力谱，与需求谱求交得到性能点。
  • 常见问题：
    • 双线性曲线与原曲线偏差很大 → 检查初始刚度拟合范围， 可改用 0.6·Vmax 经验法。
    • Vy 明显偏大或偏小 → 检查极限位移 du 的选取是否合理。
    • μ 值异常大（> 10）→ 可能包含了非结构位移或数值发散段， 需检查原始 Pushover 分析。
    • CSV 编码乱码 → 保存为 UTF-8，列名严格按示例。
