偏微分方程

从方程分类到波动、热传导、拉普拉斯三大方程，覆盖特征线法、 分离变量、格林函数与数值解法。它是连续介质力学、地震波传播、 场地地震反应分析、热-力耦合问题的共同数学基础。

波动方程 热传导 分离变量 连续介质

§引言

偏微分方程（PDE）是含有未知函数多个自变量偏导数的方程。 与常微分方程（ODE）相比，PDE 描述的是空间分布 + 时间演化的物理过程， 是连续介质力学的通用语言。

对结构工程师与地震工程师来说，PDE 出现在三个层次：

  • 连续体描述：一维杆的纵波、梁的弯曲波、三维弹性动力学方程，都是 PDE。
  • 波的传播：地震波在土层中的传播、场地放大效应，本质是波动方程的边值问题。
  • 数值离散：有限元与有限差分把 PDE 离散化为代数方程组，这是所有工程仿真软件的内核。

这份笔记按"分类 $\to$ 一阶方程 $\to$ 三大方程 $\to$ 分离变量 $\to$ 格林函数 $\to$ 数值方法 $\to$ 工程应用" 的顺序梳理，每一节都尽量落到工程语境上。

01方程分类

阶数与线性性

按最高阶偏导数的阶数，PDE 分为一阶、二阶、高阶。 按未知函数及其导数的出现方式，分为：

  • 线性：所有项都是未知函数及其导数的一次式，系数只依赖自变量。
  • 半线性：最高阶项线性，低阶项可以非线性。
  • 拟线性：最高阶项的系数含未知函数或其低阶导数。
  • 完全非线性：最高阶项关于最高阶导数非线性。

二阶方程的分类

考虑一般的二阶线性 PDE：

$$ A u_{xx} + 2B u_{xy} + C u_{yy} + \cdots = 0 $$

根据判别式 $\Delta = B^2 - AC$ 的符号分为三类：

类型判别式标准形式典型方程物理意义
椭圆型 $\Delta < 0$ $u_{xx} + u_{yy} = f$ 拉普拉斯 / 泊松方程 平衡、稳态
抛物型 $\Delta = 0$ $u_t = u_{xx}$ 热传导方程 扩散、耗散
双曲型 $\Delta > 0$ $u_{tt} = u_{xx}$ 波动方程 传播、振动

三类方程在数学性质上有本质差异：

  • 椭圆型：解在区域内无穷光滑（若系数光滑）；边界数据决定内部解。
  • 抛物型：解随时间演化；初始条件 + 边界条件决定；具有无限传播速度（数学上）。
  • 双曲型：解沿特征线传播；波速有限；可能出现间断（激波）。

定解条件

PDE 本身有无穷多解，需要附加条件才能确定唯一解：

  • 初始条件：给定位移、速度、温度等在 $t = 0$ 的值（抛物型、双曲型需要）。
  • 边界条件：给定边界上的函数值（Dirichlet）、法向导数（Neumann）、或两者组合（Robin）。
💡

工程意义：结构动力学中的运动方程 $\mathbf{M}\ddot{\mathbf{u}} + \mathbf{C}\dot{\mathbf{u}} + \mathbf{K}\mathbf{u} = \mathbf{P}(t)$ 是空间离散化的双曲型方程（或抛物型，当阻尼很大时）。 不同的数值积分方法（显式 vs 隐式）正好对应不同的方程类型特征。

02一阶方程与特征线法

一阶线性方程

考虑一阶拟线性方程：

$$ a(x, y, u) u_x + b(x, y, u) u_y = c(x, y, u) $$

特征线法的思想：把 PDE 转化为沿某些曲线（特征线）的 ODE。 特征线由下述 ODE 系统定义：

$$ \frac{dx}{dt} = a, \qquad \frac{dy}{dt} = b, \qquad \frac{du}{dt} = c $$

沿特征线，PDE 退化为 ODE，可以积分求解。

守恒律与激波

一阶方程的重要特例是守恒律：

$$ u_t + f(u)_x = 0 $$

即使初始条件光滑，解也可能在有限时间内出现间断（激波）。 一维气体动力学、交通流、浅水波方程都是这类。

例子：输运方程

最简单的输运方程：

$$ u_t + c u_x = 0, \qquad u(x, 0) = \phi(x) $$

解为 $u(x, t) = \phi(x - ct)$，即初始波形以速度 $c$ 向右平移。 这就是行波的原型。

地震学中的一维波动传播，在不考虑反射折射时， 可以近似用输运方程描述。地下介质的分层性、波阻抗差异， 则对应特征线法中的"边界反射"处理。

Python 示例：一阶方程的数值解

transport.py Python 
import numpy as np
import matplotlib.pyplot as plt


def upwind_transport(c, L, T, nx, nt):
    """
    一阶输运方程 u_t + c·u_x = 0 的一阶迎风格式。
    稳定条件：|c|·dt/dx ≤ 1（CFL 条件）
    """
    dx = L / nx
    dt = T / nt
    x = np.linspace(0, L, nx + 1)

    # 初始条件：高斯脉冲
    u = np.exp(-((x - L / 4) ** 2) / (2 * (L / 20) ** 2))

    # CFL 数
    nu = abs(c) * dt / dx
    print(f"CFL 数 = {nu:.3f}（应 ≤ 1 保证稳定）")

    # 时间推进
    for n in range(nt):
        u_new = u.copy()
        for i in range(1, nx + 1):
            if c > 0:
                # 迎风格式：c > 0 时用左侧信息
                u_new[i] = u[i] - nu * (u[i] - u[i - 1])
            else:
                u_new[i] = u[i] - nu * (u[i + 1] - u[i])
        u = u_new

    return x, u


if __name__ == "__main__":
    L, T = 1.0, 0.5
    c = 1.0

    plt.figure(figsize=(10, 4))

    for nx, nt in [(100, 200), (200, 400), (400, 800)]:
        x, u = upwind_transport(c, L, T, nx, nt)
        plt.plot(x, u, label=f"nx={nx}")

    plt.xlabel("x")
    plt.ylabel("u(x, T)")
    plt.title("输运方程：初始高斯脉冲在 t=0.5 时的波形")
    plt.legend()
    plt.grid(True, alpha=0.3)
    plt.tight_layout()
    plt.show()

运行后可以看到：脉冲在传播过程中被数值格式抹平（数值耗散）， 网格越密，抹平越少。这是所有一阶格式的共性， 也是 CFD 与波传播数值模拟中"高阶格式"研究动力的来源。

03波动方程

方程形式

一维波动方程：

$$ \frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2} $$

其中 $c$ 是波速。三维形式：

$$ \frac{\partial^2 u}{\partial t^2} = c^2 \nabla^2 u $$

达朗贝尔解

对一维波动方程，达朗贝尔给出通解：

$$ u(x, t) = f(x - ct) + g(x + ct) $$

其中 $f$ 是右行波，$g$ 是左行波。 初始条件 $u(x, 0) = \phi(x)$，$u_t(x, 0) = \psi(x)$ 对应：

$$ u(x, t) = \frac{1}{2}[\phi(x - ct) + \phi(x + ct)] + \frac{1}{2c} \int_{x - ct}^{x + ct} \psi(s) \, ds $$

能量守恒

波动方程有守恒的总能量：

$$ E(t) = \frac{1}{2} \int \left( u_t^2 + c^2 u_x^2 \right) dx = \text{const} $$

这正是它适合描述无耗散波传播的数学原因。

结构中的波动方程

结构杆件中的纵波方程：

$$ \frac{\partial^2 u}{\partial t^2} = \frac{E}{\rho} \frac{\partial^2 u}{\partial x^2}, \qquad c = \sqrt{\frac{E}{\rho}} $$

例如钢的 $E \approx 200 \text{ GPa}$，$\rho \approx 7850 \text{ kg/m}^3$， 纵波速约 $c \approx 5100 \text{ m/s}$。

梁的弯曲波（Euler-Bernoulli 梁）：

$$ \rho A \frac{\partial^2 w}{\partial t^2} + EI \frac{\partial^4 w}{\partial x^4} = q(x, t) $$

注意弯曲波是四阶 PDE，具有色散特性： 不同频率的波速不同。这与纵波的非色散形成对比。

地震学中的波动方程

三维弹性动力学方程（无体力）：

$$ \rho \frac{\partial^2 \mathbf{u}}{\partial t^2} = (\lambda + \mu) \nabla (\nabla \cdot \mathbf{u}) + \mu \nabla^2 \mathbf{u} $$

其中 $\lambda$、$\mu$ 是 Lamé 常数。通过 Helmholtz 分解， 可以拆成两个独立的波动方程：

$$ \mathbf{u} = \nabla \phi + \nabla \times \boldsymbol{\psi} $$

分别对应P 波（压缩波）与S 波（剪切波）：

$$ c_P = \sqrt{\frac{\lambda + 2\mu}{\rho}}, \qquad c_S = \sqrt{\frac{\mu}{\rho}} $$

这就是地震学中 P 波先到、S 波后到的数学解释。 两者的速度比 $c_P/c_S = \sqrt{(1-\nu)/(1-2\nu)}$，只依赖泊松比。

💡

场地地震反应分析：一维土层地震反应分析（如 SHAKE 程序） 就是把水平土层简化为一维剪切梁，求解 SH 波在层状介质中的传播方程。 通过频域内逐层传递（传递矩阵法），得到地表的放大因子。 这是场地效应分析的标准方法。

Python 示例：一维波动方程的数值解

wave1d.py Python 
import numpy as np
import matplotlib.pyplot as plt


def wave1d_explicit(c, L, T, nx, nt, x_source=None):
    """
    一维波动方程 u_tt = c² u_xx 的显式中心差分格式。
    稳定条件：Courant 数 C = c·dt/dx ≤ 1。
    边界：两端固定（u = 0）。
    """
    dx = L / nx
    dt = T / nt
    C = c * dt / dx
    print(f"Courant 数 C = {C:.3f}（应 ≤ 1）")

    x = np.linspace(0, L, nx + 1)
    u = np.zeros((nt + 1, nx + 1))

    # 初始条件：高斯脉冲
    x0 = x_source if x_source is not None else L / 4
    u[0, :] = np.exp(-((x - x0) ** 2) / (2 * (L / 30) ** 2))

    # 第一步（用 u_t(x, 0) = 0 的特殊处理）
    for i in range(1, nx):
        u[1, i] = u[0, i] + 0.5 * C**2 * (u[0, i + 1] - 2 * u[0, i] + u[0, i - 1])

    # 时间推进
    for n in range(1, nt):
        for i in range(1, nx):
            u[n + 1, i] = (2 * u[n, i] - u[n - 1, i]
                           + C**2 * (u[n, i + 1] - 2 * u[n, i] + u[n, i - 1]))

    return x, u


if __name__ == "__main__":
    c, L = 1.0, 1.0
    nx = 400
    T = 1.0

    # 展示不同时刻的波形
    snapshots = [0.0, 0.2, 0.4, 0.6]
    nt = int(T * nx / c / L)

    fig, axes = plt.subplots(2, 2, figsize=(12, 7))
    axes = axes.flatten()

    for ax, t_snap in zip(axes, snapshots):
        n_snap = int(t_snap * nx / c / L)
        _, u = wave1d_explicit(c, L, t_snap, nx, max(1, n_snap), x_source=0.3)
        x = np.linspace(0, L, nx + 1)
        ax.plot(x, u[-1, :])
        ax.set_title(f"t = {t_snap:.1f}")
        ax.set_ylim(-1.1, 1.1)
        ax.grid(True, alpha=0.3)

    plt.tight_layout()
    plt.show()

运行后会看到：初始脉冲分裂成左右两个行波， 分别以速度 $c$ 传播；碰到固定端后反射并变号。 这正是地震波在自由地表与基岩界面反射的简化模型。

04热传导方程

方程形式

一维热传导方程：

$$ \frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2} $$

其中 $\alpha$ 是热扩散系数。三维形式：

$$ \frac{\partial u}{\partial t} = \alpha \nabla^2 u $$

基本解

在无限域上，初始点源 $\delta(x)$ 的解是热核：

$$ u(x, t) = \frac{1}{\sqrt{4\pi \alpha t}} \exp\!\left(-\frac{x^2}{4 \alpha t}\right) $$

这是一个宽度随时间增长、峰值随时间衰减的高斯函数。 它体现了扩散过程的两个基本特征：

  • 无穷传播速度：任何位置的温度在瞬间就能感受到点源的影响（虽然极小）。
  • 不可逆性：时间反演不成立，信息在扩散中丢失。

极大值原理

热传导方程满足极大值原理： 解在区域内部的最大值必在边界或初始时刻取得。 物理上就是"热量不会自发集中"。

数学推论：初值的光滑性会被立即提升（$t > 0$ 后解 $C^\infty$）， 这与波动方程保持初始奇异性形成鲜明对比。

工程类比

虽然结构工程中直接的"热传导"不多，但热传导方程的数学结构 （抛物型）出现在许多问题中：

  • 粘弹性阻尼：Kelvin-Voigt 模型的应力松弛过程。
  • 孔隙水压力扩散：饱和土体的固结方程（Terzaghi 一维固结）。
  • 损伤演化：连续损伤力学中的损伤变量演化方程。
  • 混凝土水化热：大体积混凝土的温度场演化。

例如，一维固结方程：

$$ \frac{\partial u}{\partial t} = c_v \frac{\partial^2 u}{\partial z^2} $$

其中 $u$ 是超孔隙水压力，$c_v$ 是固结系数。形式与热传导完全一致， 连解法（分离变量、级数解）都相同。

Python 示例：显式与隐式格式对比

heat1d.py Python 
import numpy as np
import matplotlib.pyplot as plt


def heat_explicit(alpha, L, T, nx, nt):
    """
    显式格式求解 u_t = α u_xx。
    稳定条件：r = α·dt/dx² ≤ 0.5。
    边界：两端固定 u = 0。
    """
    dx = L / nx
    dt = T / nt
    r = alpha * dt / dx**2
    print(f"显式格式：r = {r:.4f}（应 ≤ 0.5）")

    x = np.linspace(0, L, nx + 1)
    u = np.sin(np.pi * x / L)  # 初始条件

    for n in range(nt):
        u_new = u.copy()
        for i in range(1, nx):
            u_new[i] = u[i] + r * (u[i + 1] - 2 * u[i] + u[i - 1])
        u = u_new

    return x, u


def heat_implicit(alpha, L, T, nx, nt):
    """
    隐式格式（Crank-Nicolson 风格）求解，无条件稳定。
    """
    dx = L / nx
    dt = T / nt
    r = alpha * dt / dx**2

    x = np.linspace(0, L, nx + 1)
    u = np.sin(np.pi * x / L)

    # 三对角矩阵
    n_inner = nx - 1
    main = (1 + 2 * r) * np.ones(n_inner)
    off  = -r * np.ones(n_inner - 1)

    # 简单的 Thomas 算法
    def solve_tridiag(a, b, c, d):
        n = len(b)
        cp = np.zeros(n)
        dp = np.zeros(n)
        cp[0] = c[0] / b[0]
        dp[0] = d[0] / b[0]
        for i in range(1, n):
            m = b[i] - a[i - 1] * cp[i - 1]
            cp[i] = c[i] / m if i < n - 1 else 0
            dp[i] = (d[i] - a[i - 1] * dp[i - 1]) / m
        x_sol = np.zeros(n)
        x_sol[-1] = dp[-1]
        for i in range(n - 2, -1, -1):
            x_sol[i] = dp[i] - cp[i] * x_sol[i + 1]
        return x_sol

    a = off.copy()
    c = off.copy()

    for n in range(nt):
        d = u[1:-1].copy()  # 内部节点
        u_inner = solve_tridiag(a, main, c, d)
        u[1:-1] = u_inner

    return x, u


if __name__ == "__main__":
    alpha, L = 0.01, 1.0

    plt.figure(figsize=(10, 4))

    for T in [0.5, 1.0, 2.0]:
        x, u_explicit = heat_explicit(alpha, L, T, 50, 200)
        x, u_implicit = heat_implicit(alpha, L, T, 50, 200)
        plt.plot(x, u_explicit, "--", alpha=0.6, label=f"显式 T={T}")
        plt.plot(x, u_implicit, "-", label=f"隐式 T={T}")

    plt.xlabel("x")
    plt.ylabel("u(x, T)")
    plt.title("热传导方程：正弦初始条件的衰减")
    plt.legend(fontsize=9, ncol=2)
    plt.grid(True, alpha=0.3)
    plt.tight_layout()
    plt.show()

    # 理论解对比
    print("\n理论解：u(x, t) = exp(-α π² t / L²) · sin(πx/L)")
    for T in [0.5, 1.0, 2.0]:
        decay = np.exp(-alpha * np.pi**2 * T / L**2)
        print(f"  t = {T}: 峰值衰减因子 = {decay:.6f}")

运行后可以看到：显式格式受稳定性限制（$r \le 0.5$）， 隐式格式无条件稳定，但每步需要解三对角方程组。 这正是显式 vs 隐式经典权衡的直观体现。

05拉普拉斯方程

方程形式

拉普拉斯方程：

$$ \nabla^2 u = 0 $$

带源项时称为泊松方程：

$$ \nabla^2 u = f $$

调和函数的性质

满足拉普拉斯方程的函数称为调和函数。它们有几条非常强的性质：

  • 均值性质：函数在某点的值等于以该点为球心的球面上的平均值。
  • 极大值原理：非常数调和函数的最大值与最小值都在边界上取得。
  • 解析性：调和函数在内部无穷可微，且是解析的（与复变函数连接）。
  • 唯一性：Dirichlet 问题的解在区域内唯一。

均值性质有一个漂亮的物理含义：平衡状态下，任何点都是周围点的"平均"， 不存在局部极值——这就是"平衡态"的数学表述。

与复变函数的联系

若 $f(z) = u + iv$ 是解析函数，则 $u$ 与 $v$ 都是调和函数。 反过来，在单连通区域内，任何调和函数都是某个解析函数的实部。

这个联系使得二维拉普拉斯方程可以用复变函数方法求解—— 保角映射把复杂几何映射到简单几何，从而快速求解边值问题。 这正是弹性力学中孔口问题（Kirsch 解、Michell 解）的数学基础。

基本解与格林函数

拉普拉斯算子的基本解（即 $\nabla^2 G = -\delta$ 的解）为：

$$ G(\mathbf{x}, \boldsymbol{\xi}) = \begin{cases} -\dfrac{1}{2\pi} \ln |\mathbf{x} - \boldsymbol{\xi}|, & \text{二维} \\[6pt] \dfrac{1}{4\pi |\mathbf{x} - \boldsymbol{\xi}|}, & \text{三维} \end{cases} $$

这是泊松方程和位势理论的核心工具。 结合边界条件构造出满足齐次边界条件的格林函数后， 任意源项的泊松方程解都可以写成积分形式。

工程应用

  • 稳态渗流：土坝中的稳态渗流场满足 Laplace 方程，等势线与流线正交。
  • 稳态温度场：无热源区域的稳态温度场是调和函数。
  • 弹性力学平面问题：无体力的平面弹性问题可用 Airy 应力函数表达，应力函数满足双调和方程 $\nabla^4 \phi = 0$。
  • 扭转问题：Saint-Venant 扭转问题的应力函数满足 Poisson 方程。
💡

Airy 应力函数：二维弹性力学中最巧妙的工具之一。 取 $\sigma_x = \partial^2 \phi/\partial y^2$， $\sigma_y = \partial^2 \phi/\partial x^2$， $\tau_{xy} = -\partial^2 \phi/\partial x \partial y$， 则平衡方程自动满足，而相容方程化为双调和方程 $\nabla^4 \phi = 0$。这是把 PDE 边值问题化为标量问题的经典手法。

06分离变量法

基本思想

分离变量法是求解线性 PDE 边值问题的最基本方法。 假设解可以写成单变量函数的乘积：

$$ u(x, t) = X(x) T(t) $$

代入 PDE 后，把变量分离到等式两侧，两侧必须都等于常数 （称为分离常数），从而得到两个 ODE。

方法步骤

  1. 假设分离形式 $u(x, t) = X(x) T(t)$，代入 PDE。
  2. 整理成左端只含 $x$、右端只含 $t$ 的形式。
  3. 令两侧等于 $-\lambda$（或 $+\lambda$），得到两个 ODE。
  4. 求解 $X$ 的 ODE 并施加边界条件，得到特征值 $\lambda_n$ 与特征函数 $X_n$。
  5. 求解 $T$ 的 ODE，得到 $T_n$。
  6. 叠加所有解 $u(x, t) = \sum_n X_n(x) T_n(t)$，用初始条件确定系数。

例：一维波动方程

考虑两端固定的弦振动：

$$ u_{tt} = c^2 u_{xx}, \qquad u(0, t) = u(L, t) = 0 $$

分离变量后得到特征值问题：

$$ X'' + \lambda X = 0, \qquad X(0) = X(L) = 0 $$

解为特征函数与特征值：

$$ X_n(x) = \sin\!\left(\frac{n\pi x}{L}\right), \qquad \lambda_n = \left(\frac{n\pi}{L}\right)^2, \quad n = 1, 2, \ldots $$

时间部分 $T_n(t) = A_n \cos(\omega_n t) + B_n \sin(\omega_n t)$， 其中：

$$ \omega_n = c \sqrt{\lambda_n} = \frac{n\pi c}{L} $$

最终解为级数：

$$ u(x, t) = \sum_{n=1}^{\infty} \left[A_n \cos(\omega_n t) + B_n \sin(\omega_n t)\right] \sin\!\left(\frac{n\pi x}{L}\right) $$

这正是振型分解的数学原型： 任意初始波形都可以分解成若干正弦波（振型）的叠加， 每个振型以各自的频率 $\omega_n$ 独立振动。

傅里叶级数

系数 $A_n$、$B_n$ 由初始条件与正交性确定：

$$ A_n = \frac{2}{L} \int_0^L \phi(x) \sin\!\left(\frac{n\pi x}{L}\right) dx, \qquad B_n = \frac{2}{n\pi c} \int_0^L \psi(x) \sin\!\left(\frac{n\pi x}{L}\right) dx $$

这正是傅里叶正弦级数的系数公式。 分离变量法把 PDE 求解归结为傅里叶级数展开， 这把偏微分方程与积分变换紧密联系起来。

💡

与结构动力学的对应：分离变量法在结构动力学中就是 振型分解法。连续体（梁、板、壳）的振型函数 就是分离变量得到的特征函数，固有频率 $\omega_n$ 就是特征值。 把连续体离散化为多自由度体系后，振型向量代替振型函数， 但数学结构完全一样：广义特征值问题 $\mathbf{K}\boldsymbol{\phi} = \omega^2 \mathbf{M}\boldsymbol{\phi}$。

07格林函数

基本思想

格林函数法是把线性微分方程的解表示为积分形式：

$$ u(\mathbf{x}) = \int_\Omega G(\mathbf{x}, \boldsymbol{\xi}) f(\boldsymbol{\xi}) \, d\boldsymbol{\xi} $$

其中 $G(\mathbf{x}, \boldsymbol{\xi})$ 是格林函数， 物理意义是在 $\boldsymbol{\xi}$ 处施加单位点源时， 在 $\mathbf{x}$ 处的响应。

对线性算子 $\mathcal{L}$，格林函数满足：

$$ \mathcal{L} G(\mathbf{x}, \boldsymbol{\xi}) = -\delta(\mathbf{x} - \boldsymbol{\xi}) $$

并满足齐次边界条件。

物理直觉

格林函数法是叠加原理的数学表达：

  • 把任意源分解成无数点源的叠加
  • 每个点源的响应就是格林函数
  • 总响应是所有这些响应的叠加（积分）

这与结构动力学中的杜哈梅积分如出一辙： 任意激励的响应 = 单位脉冲响应 × 激励的积分。

求解方法

格林函数的构造方式：

  • 镜像法：利用对称性构造（如半空间问题）。
  • 特征函数展开：用边值问题的特征函数展开格林函数。
  • 变换法：用傅里叶或拉普拉斯变换求解。

地震学中的格林函数

格林函数在地震学中有极其重要的地位：

  • 震源表示定理：地震位移场可以写成震源矩张量与格林函数的卷积。
  • 合成地震图：给定震源与地下结构，用格林函数合成地震波。
  • 波形反演：从观测地震图反推震源参数，需要用格林函数计算理论波形。
  • 经验格林函数法：用小震记录作为经验格林函数，合成大震的强地面运动。

Python 示例：一维格林函数

green1d.py Python 
import numpy as np
import matplotlib.pyplot as plt


def green_1d_dirichlet(x, xi, L=1.0):
    """
    一维拉普拉斯方程在 [0, L] 上、两端 Dirichlet 边界条件（u = 0）的格林函数：
        G(x, ξ) = ξ(L - x)/L,   x > ξ
        G(x, ξ) = x(L - ξ)/L,   x < ξ
    """
    x = np.asarray(x)
    if xi <= 0 or xi >= L:
        raise ValueError("源点必须在 (0, L) 内")
    G = np.where(x < xi, x * (L - xi) / L, xi * (L - x) / L)
    return G


if __name__ == "__main__":
    L = 1.0
    x = np.linspace(0, L, 500)

    plt.figure(figsize=(10, 4))

    for xi in [0.25, 0.5, 0.75]:
        G = green_1d_dirichlet(x, xi, L)
        plt.plot(x, G, label=f"源点 ξ = {xi}")

    plt.axhline(0, color="gray", linewidth=0.5)
    plt.xlabel("x")
    plt.ylabel("G(x, ξ)")
    plt.title("一维 Dirichlet 格林函数")
    plt.legend()
    plt.grid(True, alpha=0.3)
    plt.tight_layout()
    plt.show()

    # ---- 用格林函数求解 -u'' = f，u(0) = u(L) = 0 ----
    def solve_by_green(f, x_grid, L):
        """u(x) = ∫ G(x, ξ) f(ξ) dξ"""
        xi = x_grid
        f_xi = f(xi)
        u = np.zeros_like(x_grid)
        for i, xx in enumerate(x_grid):
            G = green_1d_dirichlet(xx, xi, L)
            u[i] = np.trapz(G * f_xi, xi)
        return u

    # 源项 f(x) = sin(πx)
    f = lambda x: np.sin(np.pi * x / L)
    # 理论解：u(x) = sin(πx) / π²
    u_theory = np.sin(np.pi * x / L) / np.pi**2

    u_numeric = solve_by_green(f, x, L)
    error = np.max(np.abs(u_numeric - u_theory))

    print(f"\n最大绝对误差 = {error:.3e}")
    print("（理论解 u(x) = sin(πx) / π²）")

运行后可以看到：格林函数是一根分段直线（在源点处有斜率突变）， 用格林函数积分得到的解与理论解吻合。 这就是点源叠加思想的数值体现。

08数值方法

有限差分法（FDM）

用差分商代替偏导数：

$$ \frac{\partial u}{\partial x} \approx \frac{u_{i+1} - u_{i-1}}{2\Delta x}, \qquad \frac{\partial^2 u}{\partial x^2} \approx \frac{u_{i+1} - 2u_i + u_{i-1}}{\Delta x^2} $$

优点：实现简单、适用于规则网格。 缺点：复杂几何难以处理、边界处理麻烦。

有限元法（FEM）

FEM 基于变分原理或加权残值法。 以弱形式为例，对 $-\nabla^2 u = f$ 乘以试验函数 $v$ 并积分：

$$ \int_\Omega \nabla u \cdot \nabla v \, d\Omega = \int_\Omega f v \, d\Omega + \text{边界项} $$

在单元上用形函数插值 $u \approx \sum N_i u_i$， 得到线性方程组 $\mathbf{K}\mathbf{u} = \mathbf{F}$。

FEM 的优势：

  • 复杂几何与不规则网格
  • 自然处理各种边界条件
  • 严格数学基础（变分原理）
  • 易扩展到非线性、动力学、多物理场

有限体积法（FVM）

以守恒律的积分形式为基础：

$$ \frac{d}{dt} \int_V u \, dV + \oint_{\partial V} \mathbf{F} \cdot \mathbf{n} \, dS = 0 $$

FVM 天然守恒，适合流体力学、传热学。 地震学中的某些波传播算法也借鉴 FVM 的思想。

谱方法

用全局基函数（傅里叶级数、Chebyshev 多项式）展开解。 对光滑解具有指数收敛，远快于有限差分/有限元的多项式收敛。

缺点：复杂几何与间断解处理困难。 地震学中的伪谱法（pseudospectral method） 在大规模波传播模拟中有重要应用。

方法对比

方法网格收敛速度守恒性适用场景
FDM 规则 多项式 弱 简单几何、波传播
FEM 非结构 多项式 中 复杂几何、结构分析
FVM 非结构 多项式 强 流体、守恒律
谱方法 规则 指数 中 光滑解、波传播

稳定性与收敛性

数值方法必须满足：

  • 一致性：离散方程在网格趋零时逼近原 PDE。
  • 稳定性：舍入误差不会被放大。
  • 收敛性：网格趋零时数值解趋近真解。

三者满足 Lax 等价定理：一致性 + 稳定性 $\Leftrightarrow$ 收敛性。

对显式格式，稳定性通常要求 CFL 条件：

$$ C = \frac{c \Delta t}{\Delta x} \le C_{\max} $$

其中 $C_{\max}$ 依赖于格式（一般取 1）。 这是地震波数值模拟中时间步长选择的基本约束。

⚠️

数值色散与数值耗散：离散格式会引入两类误差： ① 数值色散：不同波数的波速不准确，导致波形变形； ② 数值耗散：波幅随时间衰减，能量损失。 地震波传播模拟中，需要在精度、稳定性、计算量之间权衡， 常采用高阶格式（4 阶或更高）降低色散。

09工程应用

一维土层地震反应分析

把水平土层简化为一维剪切梁，SH 波在层状介质中传播：

$$ \rho \frac{\partial^2 u}{\partial t^2} = \frac{\partial}{\partial z}\left(G \frac{\partial u}{\partial z}\right) + \eta \frac{\partial^3 u}{\partial z^2 \partial t} $$

其中 $\rho$ 是密度，$G$ 是剪切模量，$\eta$ 是粘性系数。 这是频域传递函数法（SHAKE 程序）的数学基础。

通过频域内逐层传递（传递矩阵法），得到地表与基岩的传递函数：

$$ H(\omega) = \frac{u_{\text{surface}}(\omega)}{u_{\text{bedrock}}(\omega)} $$

它的峰值对应场地的卓越频率，与场地覆盖层厚度 $H$ 和剪切波速 $V_s$ 满足：

$$ f_0 = \frac{V_s}{4H} $$

这就是场地卓越周期的物理来源， 也是建筑抗震设计规范中场地分类的基础。

地震波传播的数值模拟

区域尺度地震波传播的 PDE：

$$ \rho \ddot{\mathbf{u}} = \nabla \cdot \boldsymbol{\sigma} + \mathbf{f} $$

其中 $\boldsymbol{\sigma}$ 是应力张量，$\mathbf{f}$ 是震源力。 加上本构关系 $\boldsymbol{\sigma} = \mathbf{C} : \boldsymbol{\varepsilon}$ 与几何关系 $\boldsymbol{\varepsilon} = \frac{1}{2}(\nabla \mathbf{u} + \nabla \mathbf{u}^{\mathsf{T}})$， 得到弹性动力学方程。

数值方法包括：

  • 有限差分法：规则网格，适合大规模模拟（如 SW4）
  • 谱元法：结合 FEM 的灵活性与谱方法的高精度（如 SPECFEM3D）
  • 有限元法：复杂几何，商业软件广泛使用

热-力耦合问题

大体积混凝土水化热、核废料处置、地热开采都涉及热-力耦合：

$$ \rho c_p \frac{\partial T}{\partial t} = \nabla \cdot (k \nabla T) + Q $$

温度场通过热膨胀影响应力场：

$$ \boldsymbol{\sigma} = \mathbf{C} : (\boldsymbol{\varepsilon} - \alpha \Delta T \, \mathbf{I}) $$

这是两个 PDE 的耦合系统，通常用有限元耦合求解。

饱和土体固结

Terzaghi 一维固结方程：

$$ \frac{\partial u}{\partial t} = c_v \frac{\partial^2 u}{\partial z^2} $$

其中 $u$ 是超孔隙水压力，$c_v$ 是固结系数。 这个抛物型方程与热传导完全同构， 解析解可用分离变量法或傅里叶级数得到。

Biot 固结理论把固结推广到三维，得到耦合的孔压扩散与固体骨架变形方程， 是土动力学与地震工程中重要的 PDE 系统。

💡

PDE 在结构工程中的三个层次： ① 建模层：从守恒律出发推导连续体方程（波动、热传导、弹性动力学）。 ② 求解层：用分离变量、积分变换、格林函数求解析解（简单几何）。 ③ 数值层：用有限差分、有限元、谱方法求数值解（复杂几何）。 结构工程师日常使用的大多是第三层，但理解前两层是判断数值结果合理性的基础。

10小结

📌 核心要点

  • 方程分类：椭圆型（平衡）、抛物型（扩散）、双曲型（传播），三类性质差异巨大。
  • 一阶方程：特征线法把 PDE 化为 ODE；守恒律可能出现激波。
  • 波动方程：达朗贝尔解为行波叠加；P 波与 S 波是弹性动力学的两个基本波型。
  • 热传导方程：扩散型；极大值原理；与固结方程数学同构。
  • 拉普拉斯方程：调和函数的均值性质、极大值原理、与复变函数的联系。
  • 分离变量法：PDE 化为特征值问题，是振型分解的数学原型。
  • 格林函数：点源叠加的思想，地震学中震源表示定理的核心。
  • 数值方法：FDM / FEM / FVM / 谱方法各有取舍；CFL 条件与数值色散是波传播模拟的关键。

  • 线性代数：离散化后的 PDE 变成 $\mathbf{K}\mathbf{u} = \mathbf{F}$ 或广义特征值问题。
