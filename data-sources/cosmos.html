Data Source

COSMOS 强震记录

COSMOS（Consortium of Organizations for Strong-Motion Observation Systems） 运营的虚拟数据中心（VDC），提供美国及全球 14 个贡献国家的强震动记录。 数据以 ASCII 文本格式免费下载，覆盖加速度、速度、位移、傅里叶谱与反应谱， 是场地效应研究与规范校核的重要数据源。

强震动记录 美国 · 全球 场地效应 免费开放 ASCII 格式
Overview

概述

COSMOS VDC（Virtual Data Center）是 COSMOS 组织运营的 免费、开放的强震动数据门户，网址为 http://db.cosmos-eq.org。 COSMOS 本身是一个由政府机构、私营组织、大学及个人组成的联盟， 成员包括 USGS、加州地质调查局（CGS）、南加州地震中心（SCEC）、 美国陆军工程兵团、垦务局等，共同致力于促进地震安全与教育[reference:0]。

VDC 的核心定位是面向地震工程与地震学研究的强震动数据分发平台。 与分散在各地台网的原始记录不同，VDC 提供统一的检索、预览与下载界面， 用户可通过地震事件、台站、地图或参数搜索等多种方式定位数据， 并在下载前预览加速度时程与反应谱[reference:1]。 截至 2006 年 1 月，VDC 收录了 514 个地震事件、3,052 个台站、 26,708 条加速度记录的元数据[reference:2]。

VDC 的数据来源分为两类：一部分由 VDC 直接存储（通过 FTP 服务器分发）， 但绝大多数数据文件仍保存在原始数据提供方的服务器上， VDC 仅提供重定向链接。VDC 通过每周运行的可用性检测脚本来管理数据提供方服务器的变更问题[reference:3]。

数据收录范围

  • 震级门槛：高地震活动区 M ≥ 5.0，低地震活动区 M ≥ 4.5。
  • 震源深度：通常排除深度大于 100 km 的事件，因为 VDC 主要面向结构效应研究[reference:4]。
  • 数据状态：非实时数据。大部分记录经台站所有者审核，均值归零并进行带通滤波后发布[reference:5]。
  • 覆盖国家：美国及 14 个贡献国家，包括日本（K-NET / KiK-net）、土耳其、台湾、新西兰、萨尔瓦多等[reference:6]。

数据产品类型

  • 原始加速度：数字化后的原始记录，未处理。
  • 处理后加速度、速度、位移：经基线校正与滤波的时程。
  • 傅里叶谱与反应谱：频域与反应谱数据。
  • 元数据表：包含 PGA、Vs30、台站坐标等参数的汇总表。

注意：并非所有地震事件都提供全部类型的数据，尤其较早的历史记录[reference:7]。

提示：COSMOS VDC 与 PEER NGA 数据库在定位上有明显差异。 VDC 是数据分发平台，侧重记录的检索与下载，不提供统一的 GMPE 模型； 而 NGA 是数据库 + GMPE 研究计划，记录经过更严格的统一处理与筛选。 两者在场地效应研究中常互为补充。
COSMOS Format

COSMOS 数据格式

COSMOS 定义了从原始数据到工程产品的四级格式标准（V0–V3）， 这是 COSMOS 联盟最重要的技术贡献之一。VDC 下载的数据可能采用多种格式， 点击下方标签查看每种格式的详情。

COSMOS V0

原始数据 · 未处理

V0 格式用于原始（raw）数据，数据以未处理的整数 counts 形式存储， 完全未经过任何处理——不应用仪器增益，不移除均值，不滤波[reference:8]。 V0 是 USGS PRISM 处理软件的标准输入格式， 所有需要进入 PRISM 处理的加速度时程都必须先转换为 V0[reference:9]。

COSMOS V1

增益校正 · 均值归零

V1 格式对原始数据进行了仪器增益校正， 输出单位为 cm/sec²（加速度计）或 cm/sec（速度计）， 并移除时间序列的均值（均值记录在文件头中）[reference:10]。 这是最常用的未校正加速度时程格式， 适合需要自行进行基线校正与滤波的用户。

COSMOS V2

基线校正 · 滤波 · 完整时程

V2 格式是处理后的加速度、速度与位移时程， 经过基线校正与带通滤波。这是工程应用中最常用的格式， 可直接用于结构时程分析[reference:11]。

COSMOS V3

反应谱 · 傅里叶谱 · 强度指标

V3 格式包含反应谱、傅里叶振幅谱与常用地震工程强度指标。 这是面向工程分析的派生数据产品，通常与 V2 配套使用[reference:12]。

Flowchart

下载流程

COSMOS VDC 采用“下载篮”（download bin）机制： 用户先检索并预览记录，将感兴趣的文件加入下载篮， 最后统一批量下载。VDC 支持一次最多压缩下载 21 个文件[reference:13]。

1
访问 VDC 网站
进入 http://db.cosmos-eq.org。 VDC 为免费开放访问，无需注册账号即可检索和下载数据[reference:14]。
2
选择检索方式
VDC 提供四种检索入口：
① 按地震事件 — 从事件列表选择地震； ② 按台站 — 从台站列表选择； ③ 地图检索 — 在交互地图上点击震中或台站； ④ 参数检索 — 按 PGA、Vs30、震级、距离等元数据筛选（支持 Basic / Advanced 两级）。
3
预览记录
在下载前可预览加速度时程和反应谱， 并将反应谱与设计谱进行对比，帮助判断记录是否适用[reference:15]。
4
加入下载篮
在事件页面或台站页面中，将所需的数据文件加入 “download bin”。 可同时加入多个文件，最多 21 个。
5
下载数据
进入下载篮页面，可选择： ① 逐个下载单个文件； ② 批量下载 — 将所有文件打包为 tar + zip 压缩包。 也可单独下载元数据表（RTF 格式）。
6
处理数据格式
下载的文件可能采用多种格式：CSMIP 格式（加州数据为主）、 USGS SMC 格式、COSMOS 格式（土耳其、台湾数据）、 K-NET / KiK-net 格式（日本数据）等[reference:16]。 部分文件为 .exe 自解压格式，需先解压。 如需要统一格式，可使用 COSMOS 提供的 Converter 工具（Java 应用程序）进行格式转换。
数据提供方重定向：COSMOS VDC 本身仅存储少量数据。 大多数情况下，VDC 提供的是指向原始数据提供方服务器的链接， 点击下载后实际从提供方服务器获取文件。如果提供方服务器不可用， VDC 的每周检测脚本会在一周内发现问题，但短期内可能无法下载[reference:17]。

下载数据文件说明

1. 时程文件（Time Series）

数据产品 对应格式 说明
原始加速度 V0 / 各台网原始格式 数字化后的原始记录，未处理。可作为 PRISM 等处理工具的输入。
未校正加速度 V1 已应用仪器增益校正，已移除均值。单位为 cm/s²。
处理后加速度 V2 基线校正 + 带通滤波后的加速度时程。
处理后速度 V2 由处理后加速度积分得到，单位为 cm/s。
处理后位移 V2 由处理后速度积分得到，单位为 cm。
文件格式多样性：COSMOS VDC 的数据来自多个数据提供方， 文件格式不统一。常见格式包括 CSMIP、USGS SMC、COSMOS V1.2、 K-NET / KiK-net、PNSN 等[reference:18]。部分 .exe 文件为自解压压缩包， 需先解压才能使用。建议统一转换为 COSMOS V1 或 V2 格式后再进行分析。

2. 谱文件（Spectra）

数据产品 对应格式 说明
反应谱 V3 5% 阻尼比伪绝对谱加速度（PSA），覆盖常用周期范围。
傅里叶振幅谱 V3 频域数据，可用于频谱分析与场地响应研究。

3. 元数据文件（Metadata）

COSMOS 定义了强震动记录的推荐最小元数据集（Guideline 2）， 涵盖台站参数、传感器/通道参数与记录参数三大类[reference:19]。

字段类别 主要内容
台站参数 台站编号、台站名称、所属台网、纬度、经度、坐标基准、台站类型
传感器参数 传感器类型（FBA 等）、自然频率、阻尼比、灵敏度、满量程、增益、方位角
记录参数 起始时间（UTC）、时间质量、采样间隔、记录长度
强度指标 PGA、PGV、PGD、Arias 强度、有效持时等
元数据完整性差异：VDC 的数据来自不同台网， 部分记录可能缺少某些元数据字段。COSMOS Guideline 2 列出了 推荐的最小必需字段，缺少这些字段会显著降低记录的可用性[reference:20]。

Notes

下载注意事项

  1. 免费开放，无需注册： COSMOS VDC 提供无限制的免费访问， 用户无需注册账号即可检索、预览和下载数据。 这与 PEER NGA 需要邮箱注册的机制不同[reference:21]。
  2. 数据非实时： VDC 提供的是审核后的数据， 大多数记录经台站所有者处理后才发布，存在一定的延迟。 VDC 不提供实时数据流[reference:22]。
  3. 数据提供方重定向： 绝大多数数据文件实际存储在原始数据提供方的服务器上， VDC 仅提供链接。如果提供方服务器不可用，短期内可能无法下载[reference:23]。
  4. 震级门槛： VDC 收录的数据有明确的震级门槛： 高地震活动区 M ≥ 5.0，低地震活动区 M ≥ 4.5。 低于此门槛的记录通常不在收录范围内[reference:24]。
  5. 深度限制： 震源深度大于 100 km 的事件通常被排除， 因为 VDC 主要面向结构效应研究，深源地震的工程意义有限[reference:25]。
  6. 文件格式不统一： 数据文件可能采用 CSMIP、USGS SMC、COSMOS V1.2、K-NET / KiK-net、 PNSN 等多种格式。部分 .exe 文件为自解压压缩包。 建议下载后统一转换为 COSMOS V1 或 V2 格式[reference:26]。
  7. 下载篮上限： VDC 的下载篮一次最多支持 21 个文件的批量压缩下载。 超出部分需分批处理[reference:27]。
  8. 元数据完整性： 部分记录可能缺少 COSMOS Guideline 2 推荐的最小元数据字段。 使用前应检查关键字段（如 Vs30、震级、距离）是否完整[reference:28]。
  9. 引用要求： 使用 VDC 数据发表研究成果时， 应同时引用数据所有者与 COSMOS VDC。 VDC 明确要求用户在论文中注明数据来源[reference:29]。
