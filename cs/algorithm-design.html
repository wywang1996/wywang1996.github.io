算法设计与分析

从分治到动态规划，覆盖贪心、回溯、分支限界与 NP 完全性。 算法设计是科学计算、优化求解与高性能实现的方法论基础， 决定了同一问题在"可行"与"不可行"之间的分界线。

分治 动态规划 贪心 优化求解

§引言

算法设计研究如何为问题构造高效的求解方法。 与数据结构（研究数据的组织）互补， 两者共同构成程序的核心。

在工程计算与地震学中，算法设计的意义体现在三个方面：

  • 可行性：同一问题，不同算法的复杂度可能相差数个量级——从"秒级"到"不可行"。
  • 规模上限：$O(n^2)$ 算法在 $n=10^6$ 时需要数小时，而 $O(n \log n)$ 只需不到一秒。
  • 工程约束：实时处理（地震预警）、大规模数据（地震目录）、高精度数值（PSHA）都对算法提出苛刻要求。

典型的工程场景：

问题朴素算法优化算法差距
地震目录去重 $O(n^2)$ 哈希 + 排序 $O(n \log n)$ 10⁶ 倍
最近台站查询 $O(n)$ 扫描 kd 树 $O(\log n)$ 10³ 倍
矩阵-向量乘法 稠密 $O(n^2)$ CSR 稀疏 $O(\text{nnz})$ 10~1000 倍
反应谱计算 重复积分 $O(n \cdot m)$ 递推 + 缓存 $O(n)$ 10 倍
地震重定位 全网格搜索 $O(G)$ 共轭梯度 $O(k \cdot \text{nnz})$ 10²~10³ 倍

这份笔记按"范式 $\to$ 分治 $\to$ 贪心 $\to$ 动态规划 $\to$ 回溯 $\to$ 随机化 $\to$ NP $\to$ 应用" 的顺序梳理，每一节都尽量落到工程语境上。

01算法设计范式

五大范式

算法设计有五种基本范式，大多数算法都是这些范式的组合或变体：

范式核心思想典型问题复杂度特征
分治 分解 → 求解 → 合并 归并排序、FFT、快速排序 $T(n) = aT(n/b) + f(n)$
贪心 局部最优 → 全局最优 最小生成树、霍夫曼编码 通常 $O(n \log n)$
动态规划 最优子结构 + 重叠子问题 最短路径、背包问题 状态数 × 状态转移
回溯 逐步构造 + 剪枝 八皇后、数独、SAT 最坏指数，实际远小
随机化 引入随机性 快速排序、素数测试、MCMC 期望或高概率界

问题建模

算法设计的第一步是建模—— 把实际问题抽象成标准形式：

  • 图论建模：台站网络 → 加权图；事件序列 → DAG。
  • 优化建模：台站选址 → 集合覆盖；资源分配 → 线性规划。
  • 序列建模：波形对齐 → 最长公共子序列；走时反演 → 动态规划。
  • 搜索建模：震源参数反演 → 高维搜索；断层分段 → 组合优化。

同一个问题，不同的建模方式导致完全不同的算法选择。 这是算法设计中最考验经验的部分。

正确性证明

算法不仅要"能跑"，还要"跑对"。常用的证明方法：

  • 循环不变式：证明循环每次迭代后某种性质成立。
  • 数学归纳法：对递归算法特别有效。
  • 交换论证：证明贪心选择可交换为最优解。
  • 反证法：假设存在更优解，导出矛盾。

复杂度分析

递归算法的时间复杂度由主定理（Master Theorem）给出：

$$ T(n) = a T(n/b) + f(n) $$

其中 $a \ge 1$、$b > 1$，$f(n)$ 是分解与合并的代价。主定理分三种情形：

情形条件结果示例
1 $f(n) = O(n^{\log_b a - \epsilon})$ $T(n) = \Theta(n^{\log_b a})$ 归并排序（a=2, b=2，$n^{\log_2 2} = n$）
2 $f(n) = \Theta(n^{\log_b a})$ $T(n) = \Theta(n^{\log_b a} \log n)$ 归并排序（$f(n) = n$）
3 $f(n) = \Omega(n^{\log_b a + \epsilon})$ $T(n) = \Theta(f(n))$ 二分查找（a=1, b=2，$f(n) = 1$）
💡

算法设计的"分水岭"： $O(n \log n)$ 与 $O(n^2)$ 的差距，就是"可行"与"不可行"的分水岭。 在 $n = 10^6$ 时，前者不到一秒，后者数小时。 在 $n = 10^9$ 时，前者需数分钟，后者完全不可行。 因此，算法设计的第一目标通常是把复杂度降到 $O(n \log n)$ 或以下。

02分治法

三步法

分治法（Divide and Conquer）把问题分成三个步骤：

  1. 分：把原问题划分为若干子问题。
  2. 治：递归求解子问题。
  3. 合：把子问题的解合并成原问题的解。

经典例子

1. 归并排序

把数组二分，递归排序两半，再线性合并。 时间 $T(n) = 2T(n/2) + O(n) = O(n \log n)$。

2. 快速排序

选 pivot，划分数组，递归排序两边。 平均 $O(n \log n)$，最坏 $O(n^2)$。

3. 二分查找

在有序数组上每次排除一半，$T(n) = T(n/2) + O(1) = O(\log n)$。

4. 快速傅里叶变换（FFT）

FFT 是分治法最成功的应用之一。 DFT 的定义：

$$ X_k = \sum_{n=0}^{N-1} x_n e^{-i 2\pi kn / N} $$

直接计算需要 $O(N^2)$。FFT 利用单位根的对称性，把 $N$ 点 DFT 分解为两个 $N/2$ 点 DFT：

$$ T(N) = 2 T(N/2) + O(N) = O(N \log N) $$

对 $N = 10^6$，FFT 比朴素 DFT 快约 5 万倍。 这是信号处理、地震数据处理、频谱分析的基础。

5. 快速矩阵乘法（Strassen）

朴素矩阵乘法是 $O(n^3)$。 Strassen 算法把 $2 \times 2$ 分块乘法从 8 次降到 7 次：

$$ T(n) = 7 T(n/2) + O(n^2) = O(n^{\log_2 7}) \approx O(n^{2.807}) $$

对 $n = 10^3$，Strassen 比朴素算法快约 5 倍。 实际实现中因常数因子大，通常只用在大规模问题上。

6. 最近点对问题

给定平面上 $n$ 个点，找距离最近的一对。 朴素方法 $O(n^2)$。 分治方法：按 x 坐标分成两半， 递归求两半的最近点对， 再检查跨越中线的点对（只需检查 $O(1)$ 个邻居）， 总复杂度 $O(n \log n)$。

这个问题在地震目录分析中有直接应用： 找相距最近的地震事件、识别重复事件、台站分布均匀性评估。

Python 示例：归并排序与最近点对

divide_conquer.py Python 
import math
import numpy as np


def merge_sort(arr):
    """归并排序：分治典范"""
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return _merge(left, right)


def _merge(a, b):
    result = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            result.append(a[i])
            i += 1
        else:
            result.append(b[j])
            j += 1
    result.extend(a[i:])
    result.extend(b[j:])
    return result


def closest_pair(points):
    """
    最近点对（分治）。
    points: [(x, y), ...]
    返回：(距离, 点1, 点2)
    """
    # 按 x 排序
    px = sorted(points, key=lambda p: p[0])
    py = sorted(points, key=lambda p: p[1])
    return _closest(px, py)


def _dist(p1, p2):
    return math.hypot(p1[0] - p2[0], p1[1] - p2[1])


def _closest(px, py):
    n = len(px)
    if n <= 3:
        best = (float("inf"), None, None)
        for i in range(n):
            for j in range(i + 1, n):
                d = _dist(px[i], px[j])
                if d < best[0]:
                    best = (d, px[i], px[j])
        return best

    mid = n // 2
    mid_x = px[mid][0]

    left_x = px[:mid]
    right_x = px[mid:]
    left_y = [p for p in py if p[0] <= mid_x]
    right_y = [p for p in py if p[0] > mid_x]

    dl = _closest(left_x, left_y)
    dr = _closest(right_x, right_y)
    d_best = dl if dl[0] < dr[0] else dr

    # 检查跨越中线的点
    strip = [p for p in py if abs(p[0] - mid_x) < d_best[0]]
    for i in range(len(strip)):
        for j in range(i + 1, min(i + 8, len(strip))):
            d = _dist(strip[i], strip[j])
            if d < d_best[0]:
                d_best = (d, strip[i], strip[j])
    return d_best


if __name__ == "__main__":
    # ---- 归并排序 ----
    rng = np.random.default_rng(42)
    arr = rng.integers(0, 1000, size=20).tolist()
    print(f"原始数组: {arr}")
    sorted_arr = merge_sort(arr)
    print(f"归并排序: {sorted_arr}")
    assert sorted_arr == sorted(arr)

    # ---- 最近点对 ----
    n = 200
    pts = [(float(x), float(y)) for x, y in rng.uniform(0, 100, (n, 2))]

    d, p1, p2 = closest_pair(pts)
    print(f"\n最近点对距离: {d:.4f}")
    print(f"  点 1: {p1}")
    print(f"  点 2: {p2}")

    # 朴素验证
    d_naive = min(
        _dist(pts[i], pts[j])
        for i in range(n) for j in range(i + 1, n)
    )
    print(f"  朴素验证: {d_naive:.4f}")
    assert abs(d - d_naive) < 1e-9

运行后可以看到：归并排序稳定输出有序结果， 最近点对的分治算法与 $O(n^2)$ 朴素方法结果一致。

03贪心算法

核心思想

贪心算法在每一步都选择当前看起来最优的方案， 并希望通过一系列局部最优达到全局最优。

贪心算法的关键不在于"贪心"， 而在于证明贪心选择性质与最优子结构：

  • 贪心选择性质：每一步的局部最优选择能导致全局最优解。
  • 最优子结构：问题的最优解包含子问题的最优解。

两个性质都满足时，贪心算法就是正确的。 反之，贪心可能得到次优解——此时需要动态规划。

经典问题

1. 活动选择问题

给定若干活动，每个活动有开始与结束时间， 选择最多的互不重叠的活动。 贪心策略：按结束时间排序，依次选择不与已选活动冲突的活动。

时间复杂度 $O(n \log n)$（主要是排序）。

2. 霍夫曼编码

用变长编码压缩数据，高频字符用短码。 贪心策略：反复取频率最小的两个节点合并，构建哈夫曼树。

时间复杂度 $O(n \log n)$（用最小堆）。 霍夫曼编码是无损压缩的经典算法， 在数据传输、文件压缩、地震数据存储中广泛使用。

3. 最小生成树（Prim 与 Kruskal）

加权连通无向图的最小生成树。 两种贪心算法：

  • Prim：从一点开始，每次加入离树最近的节点。
  • Kruskal：按边权从小到大加边，用并查集判环。

4. Dijkstra 最短路径

对非负权图，从源点出发，每次取距离最小的未访问节点， 用优先队列维护。

Dijkstra 本质上是贪心算法： 每次选择当前距离最小的节点， 并保证这个距离是最终最短距离。

5. 分数背包问题

物品可以分割，选择价值密度最高的物品直到装满。 贪心策略：按价值/重量比排序。

注意：0/1 背包不能用贪心， 因为不可分割导致贪心选择可能非最优，必须用动态规划。

贪心 vs 动态规划

维度贪心动态规划
决策方式 自顶向下，每步最优 自底向上，逐步累积
是否回溯 不回溯 可"重做"决策
适用条件 贪心选择性质 + 最优子结构 最优子结构 + 重叠子问题
时间复杂度 通常更低 通常更高
正确性 需要证明 由最优子结构保证

Python 示例：霍夫曼编码

huffman.py Python 
import heapq
from collections import Counter


class HuffmanNode:
    def __init__(self, char=None, freq=0):
        self.char = char
        self.freq = freq
        self.left = None
        self.right = None

    def __lt__(self, other):
        return self.freq < other.freq


def build_huffman_tree(text):
    """构建霍夫曼树"""
    freq = Counter(text)
    heap = [HuffmanNode(ch, f) for ch, f in freq.items()]
    heapq.heapify(heap)

    while len(heap) > 1:
        left = heapq.heappop(heap)
        right = heapq.heappop(heap)
        merged = HuffmanNode(freq=left.freq + right.freq)
        merged.left = left
        merged.right = right
        heapq.heappush(heap, merged)
    return heap[0] if heap else None


def generate_codes(node, prefix="", codes=None):
    """遍历霍夫曼树生成编码表"""
    if codes is None:
        codes = {}
    if node is None:
        return codes
    if node.char is not None:
        codes[node.char] = prefix
    generate_codes(node.left, prefix + "0", codes)
    generate_codes(node.right, prefix + "1", codes)
    return codes


def huffman_encode(text):
    """霍夫曼编码"""
    if not text:
        return "", {}
    root = build_huffman_tree(text)
    codes = generate_codes(root)
    encoded = "".join(codes[ch] for ch in text)
    return encoded, codes


def huffman_decode(encoded, codes):
    """霍夫曼解码"""
    reverse = {v: k for k, v in codes.items()}
    result = []
    buf = ""
    for bit in encoded:
        buf += bit
        if buf in reverse:
            result.append(reverse[buf])
            buf = ""
    return "".join(result)


if __name__ == "__main__":
    # 一个典型文本
    text = "ABRACADABRA" * 100
    print(f"原文长度: {len(text)} 字符")

    encoded, codes = huffman_encode(text)
    print(f"编码后长度: {len(encoded)} 比特")
    print(f"压缩率: {len(encoded) / (len(text) * 8):.3f}")

    print(f"\n编码表:")
    for ch, code in sorted(codes.items()):
        freq = text.count(ch)
        print(f"  {ch!r}: {code}  (频率 {freq})")

    # 验证解码
    decoded = huffman_decode(encoded, codes)
    assert decoded == text
    print(f"\n✓ 解码结果与原文一致")

霍夫曼编码的无损压缩效率取决于字符频率分布： 分布越不均匀，压缩率越高。 在地震数据存储中，如果波形样本分布集中， 霍夫曼编码可以获得 2~3 倍的压缩。

04动态规划

核心思想

动态规划（Dynamic Programming，DP）通过保存子问题的解避免重复计算。 它要求问题具有两个性质：

  • 最优子结构：最优解包含子问题的最优解。
  • 重叠子问题：递归过程中同一个子问题被多次求解。

两种实现方式

方式方向特点例子
记忆化搜索 自顶向下 递归 + 缓存 斐波那契、LCS
递推 自底向上 迭代填表 0/1 背包、编辑距离

DP 的设计步骤

  1. 定义状态：$dp[i]$ 表示什么？
  2. 确定转移方程：$dp[i]$ 如何由子状态推出？
  3. 确定初值：最小的子问题是什么？
  4. 确定计算顺序：子问题先于父问题。
  5. 优化空间：能否只用几个变量或滚动数组？

经典问题

1. 0/1 背包

给定 $n$ 个物品，每个有重量 $w_i$ 与价值 $v_i$， 背包容量 $W$。选择若干物品使总价值最大。

$$ dp[i][j] = \max(dp[i-1][j], \; dp[i-1][j-w_i] + v_i) $$

时间复杂度 $O(nW)$，空间可优化到 $O(W)$（滚动数组）。

2. 最长公共子序列（LCS）

两个序列的最长公共子序列：

$$ dp[i][j] = \begin{cases} dp[i-1][j-1] + 1, & a_i = b_j \\ \max(dp[i-1][j], dp[i][j-1]), & a_i \ne b_j \end{cases} $$

应用：序列比对、DNA 分析、波形匹配。

3. 编辑距离

把字符串 A 变成字符串 B 所需的最少操作数：

$$ dp[i][j] = \min\begin{cases} dp[i-1][j] + 1 & \text{删除} \\ dp[i][j-1] + 1 & \text{插入} \\ dp[i-1][j-1] + \delta(a_i, b_j) & \text{替换} \end{cases} $$

应用：拼写纠错、语音识别、序列相似度。

4. 最短路径的 DP 视角

Floyd-Warshall 算法本质上是 DP：

$$ D^{(k)}[i][j] = \min(D^{(k-1)}[i][j], \; D^{(k-1)}[i][k] + D^{(k-1)}[k][j]) $$

状态 $D^{(k)}[i][j]$ 表示只经过前 $k$ 个中间节点的最短路径。 时间 $O(V^3)$，空间 $O(V^2)$。

5. 维特比算法

隐马尔可夫模型（HMM）中的最优路径解码， 本质是序列上的动态规划：

$$ \delta_t(j) = \max_i [\delta_{t-1}(i) \cdot a_{ij}] \cdot b_j(o_t) $$

其中 $a_{ij}$ 是状态转移概率，$b_j(o_t)$ 是发射概率。 维特比算法在语音识别、P 波自动拾取、 GPS 轨迹平滑中有广泛应用。

DP 与状态空间

DP 的复杂度由状态数与状态转移代价共同决定：

$$ T = O(\text{状态数} \times \text{转移代价}) $$

对多维状态（如 $dp[i][j][k]$），状态数可能爆炸。 此时需要寻找状态压缩、降维或近似方法。

Python 示例：0/1 背包与编辑距离

dp_demo.py Python 
import numpy as np


def knapsack_01(weights, values, capacity):
    """
    0/1 背包问题的动态规划解法。
    返回 (最大价值, 选择的物品索引)。
    """
    n = len(weights)
    # dp[j] 表示容量为 j 时的最大价值
    dp = [0] * (capacity + 1)
    # 记录选择（用于回溯方案）
    choice = [[False] * (capacity + 1) for _ in range(n)]

    for i in range(n):
        w, v = weights[i], values[i]
        # 逆序更新，避免同一物品被多次选择
        for j in range(capacity, w - 1, -1):
            if dp[j - w] + v > dp[j]:
                dp[j] = dp[j - w] + v
                choice[i][j] = True

    # 回溯选择的物品
    selected = []
    j = capacity
    for i in range(n - 1, -1, -1):
        if choice[i][j]:
            selected.append(i)
            j -= weights[i]
    selected.reverse()

    return dp[capacity], selected


def edit_distance(a, b):
    """
    编辑距离（Levenshtein 距离）。
    """
    m, n = len(a), len(b)
    # 二维 DP（也可以用滚动数组优化到 O(n)）
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            cost = 0 if a[i-1] == b[j-1] else 1
            dp[i][j] = min(
                dp[i-1][j] + 1,        # 删除
                dp[i][j-1] + 1,        # 插入
                dp[i-1][j-1] + cost,   # 替换
            )
    return dp[m][n]


def lcs_length(a, b):
    """最长公共子序列长度"""
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i-1] == b[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]

05回溯与分支限界

回溯法

回溯法把问题看成决策树的搜索： 在每一步做出选择， 若选择导致无解则撤销（回溯）到上一步， 尝试其他选择。

回溯法的三个要素：

  • 解空间：所有可能解构成的树。
  • 约束函数：判断部分解是否违反约束。
  • 限界函数：判断部分解是否还能优于当前最优解。

经典问题

问题搜索空间复杂度应用
N 皇后 棋盘放置 $O(N!)$，剪枝后远小 组合优化教学
数独 数字填充 指数级，剪枝后实用 约束满足
图的着色 颜色分配 NP 完全 频率分配、调度
旅行商问题 路径排列 $O(n!)$ 路径规划
子集和 元素选择 $O(2^n)$ 密码学、载荷分配

剪枝策略

剪枝是回溯法的核心—— 没有剪枝的回溯就是穷举：

  • 可行性剪枝：当前部分解已违反约束，不再继续。
  • 最优性剪枝：当前部分解的下界已超过当前最优解，不再继续。
  • 对称性剪枝：利用问题的对称性，避免搜索等价解。
  • 启发式排序：优先搜索可能好的分支（如按价值密度排序）。

分支限界法

分支限界法是回溯法的广度优先版本：

  • 用优先队列管理活节点。
  • 优先扩展"最有希望"的节点（如下界最小）。
  • 当发现某节点的下界超过当前最优解时，剪枝整棵子树。

回溯 vs 分支限界的区别：

维度回溯分支限界
搜索方式 深度优先 广度优先 / 最佳优先
存储 当前路径（栈） 活节点表（队列/堆）
目标 找所有解 / 任一解 找最优解
典型问题 N 皇后、数独 0/1 背包、TSP

工程应用

  • 地震台站选址：从候选点中选 $k$ 个使覆盖最优。
  • 断层分段方案：从多种分段组合中找最优。
  • 震源参数反演：在多维参数空间中搜索最优解。
  • 波形对齐：在多个候选时移中搜索最佳匹配。

def solve_n_queens(n):
    """
    N 皇后问题的回溯解法。
    返回所有解的列表（每个解是每行皇后所在列）。
    """
    solutions = []
    cols = set()
    diag1 = set()   # i - j 相同的主对角线
    diag2 = set()   # i + j 相同的副对角线
    board = []

    def backtrack(row):
        if row == n:
            solutions.append(board[:])
            return
        for col in range(n):
            if col in cols or (row - col) in diag1 or (row + col) in diag2:
                continue
            cols.add(col)
            diag1.add(row - col)
            diag2.add(row + col)
            board.append(col)
            backtrack(row + 1)
            board.pop()
            cols.remove(col)
            diag1.remove(row - col)
            diag2.remove(row + col)

    backtrack(0)
    return solutions


def subset_sum(nums, target):
    """
    子集和问题的回溯解法。
    返回所有和为 target 的子集。
    """
    nums = sorted(nums)
    results = []
    subset = []

    def backtrack(start, current_sum):
        if current_sum == target:
            results.append(subset[:])
            return
        if current_sum > target:
            return
        for i in range(start, len(nums)):
            # 剪枝：若加上当前元素已经超过 target，后面的也一定超过
            if current_sum + nums[i] > target:
                break
            # 剪枝：跳过相邻重复元素
            if i > start and nums[i] == nums[i-1]:
                continue
            subset.append(nums[i])
            backtrack(i + 1, current_sum + nums[i])
            subset.pop()

    backtrack(0, 0)
    return results


def knapsack_branch_bound(weights, values, capacity):
    """
    分支限界法求解 0/1 背包。
    返回最优价值。
    """
    import heapq
    n = len(weights)
    # 按价值密度降序排列
    items = sorted(
        [(values[i] / weights[i], weights[i], values[i], i) for i in range(n)],
        reverse=True
    )
    sorted_w = [it[1] for it in items]
    sorted_v = [it[2] for it in items]

    # 上界函数：线性松弛（允许分数物品）
    def upper_bound(idx, cur_w, cur_v):
        bound = cur_v
        j = idx
        total_w = cur_w
        while j < n and total_w + sorted_w[j] <= capacity:
            total_w += sorted_w[j]
            bound += sorted_v[j]
            j += 1
        if j < n:
            bound += (capacity - total_w) * sorted_v[j] / sorted_w[j]
        return bound

    # 优先队列按上界降序
    pq = [(-upper_bound(0, 0, 0), 0, 0, 0)]   # (-bound, idx, w, v)
    best = 0

    while pq:
        neg_bound, idx, cur_w, cur_v = heapq.heappop(pq)
        if -neg_bound <= best:
            continue
        if idx == n:
            best = max(best, cur_v)
            continue

        # 分支 1：选第 idx 个
        if cur_w + sorted_w[idx] <= capacity:
            new_w = cur_w + sorted_w[idx]
            new_v = cur_v + sorted_v[idx]
            ub = upper_bound(idx + 1, new_w, new_v)
            heapq.heappush(pq, (-ub, idx + 1, new_w, new_v))

        # 分支 2：不选第 idx 个
        ub = upper_bound(idx + 1, cur_w, cur_v)
        if ub > best:
            heapq.heappush(pq, (-ub, idx + 1, cur_w, cur_v))

    return best

06随机化算法

为什么引入随机性

随机化算法在运行过程中使用随机数。 看似"不稳定"，但往往能带来：

  • 更简单的实现：避免复杂的确定性构造。
  • 更好的平均性能：避免最坏情况。
  • 更优的复杂度：如素性测试、最小割。
  • 更强的对抗鲁棒性：防止输入恶意构造。

两类随机化算法

类型特点典型算法
拉斯维加斯 结果总是正确，时间随机 随机化快速排序
蒙特卡洛 时间固定，结果可能错误 Miller-Rabin 素性测试

经典算法

1. 随机化快速排序

随机选 pivot，避免输入导致的最坏情况。 对任意输入，期望复杂度 $O(n \log n)$。

2. Miller-Rabin 素性测试

概率性判断一个数是否为素数。 单次测试的错误概率 < 1/4， 重复 $k$ 次后错误概率 < $(1/4)^k$。

对 64 位整数，用几个固定基底， 可以做到"错误概率小于宇宙射线干扰"的确定性判断。 这在密码学中是基础算法。

3. 随机化最小割（Karger）

随机选择边并收缩，重复多次。 一次成功的概率 $\ge 2/n^2$， 重复 $O(n^2 \log n)$ 次即可高概率找到最小割。

4. 水库抽样

从大小未知的数据流中均匀抽取 $k$ 个样本。 算法：

  1. 取前 $k$ 个元素，存入水库。
  2. 对第 $i$ 个元素（$i > k$），以 $k/i$ 的概率替换水库中的随机一个。
  3. 遍历结束后，水库中即为均匀样本。

水库抽样在地震数据流处理、 大数据统计采样中有广泛应用。

5. 蒙特卡洛方法

用随机抽样估计确定性问题的解。 经典例子：用随机撒点估计 $\pi$。

$$ \pi \approx \frac{4 m}{n} $$

其中 $n$ 是总点数，$m$ 是落在单位圆内的点数。 误差 $O(1/\sqrt{n})$，与维度无关—— 这是蒙特卡洛最大的优势。

在 PSHA、可靠度、随机振动中， 蒙特卡洛是标准方法。

随机化在数值计算中

  • 随机 SVD：用随机投影加速大规模矩阵分解。
  • 随机梯度下降（SGD）：机器学习优化。
  • 随机化数值线性代数：小规模近似代替精确计算。
  • MCMC：贝叶斯反演、参数估计。

import random
import numpy as np


def randomized_quicksort(arr, rng=None):
    """
    随机化快速排序：随机选 pivot。
    期望复杂度 O(n log n)。
    """
    if rng is None:
        rng = random.Random(42)
    if len(arr) <= 1:
        return arr
    pivot = rng.choice(arr)
    left = [x for x in arr if x < pivot]
    mid = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return (randomized_quicksort(left, rng)
            + mid
            + randomized_quicksort(right, rng))


def reservoir_sample(stream, k, seed=42):
    """
    水库抽样：从流中均匀抽取 k 个样本。
    """
    rng = random.Random(seed)
    reservoir = []
    for i, item in enumerate(stream):
        if i < k:
            reservoir.append(item)
        else:
            j = rng.randint(0, i)
            if j < k:
                reservoir[j] = item
    return reservoir


def miller_rabin(n, k=20, seed=42):
    """
    Miller-Rabin 素性测试。
    k 次测试后错误概率 < 4^(-k)。
    """
    if n < 2:
        return False
    if n in (2, 3):
        return True
    if n % 2 == 0:
        return False

    # 把 n-1 写成 2^r * d
    r, d = 0, n - 1
    while d % 2 == 0:
        r += 1
        d //= 2

    rng = random.Random(seed)
    for _ in range(k):
        a = rng.randint(2, n - 2)
        x = pow(a, d, n)
        if x == 1 or x == n - 1:
            continue
        for _ in range(r - 1):
            x = pow(x, 2, n)
            if x == n - 1:
                break
        else:
            return False
    return True


def monte_carlo_pi(n, seed=42):
    """蒙特卡洛估算 π"""
    rng = np.random.default_rng(seed)
    x = rng.uniform(-1, 1, n)
    y = rng.uniform(-1, 1, n)
    inside = (x**2 + y**2) <= 1.0
    return 4.0 * np.sum(inside) / n

07NP 完全性

复杂度类

计算复杂度理论把问题按难度分为若干类：

类别含义典型问题
P 多项式时间可解 排序、最短路、线性规划
NP 多项式时间可验证 SAT、TSP、图着色
NP 完全 NP 中最难的问题 SAT、3-SAT、背包
NP 困难 至少与 NP 完全一样难 TSP 优化、整数规划
EXP 指数时间可解 大多数博弈问题

核心开放问题：P = NP？ 至今未解决，是数学与计算机科学最重要的悬赏问题之一。

NP 完全性证明

证明一个问题是 NP 完全的标准步骤：

  1. 证明问题属于 NP（解可以在多项式时间验证）。
  2. 选一个已知的 NP 完全问题。
  3. 构造多项式时间的归约。
  4. 证明归约正确（原问题的解 ⇔ 新问题的解）。

第一个 NP 完全问题是 Cook-Levin 定理证明的 SAT（布尔可满足性）。 之后通过归约，证明了数千个问题都是 NP 完全的。

经典 NP 完全问题

问题描述工程对应
SAT / 3-SAT 布尔公式可满足性 逻辑验证、约束求解
旅行商（TSP） 访问所有城市的最短回路 台站巡测路线规划
背包 容量限制下的最优选择 资源分配
图着色 相邻节点不同色 频率分配、调度
集合覆盖 最少集合覆盖全集 台站选址、传感器布设
最大团 最大完全子图 社交网络分析
子集和 子集和等于目标 载荷分配
顶点覆盖 最少顶点覆盖所有边 网络监控

应对 NP 完全问题

面对 NP 完全问题，工程上有四种应对策略：

1. 近似算法

牺牲精确性，换取多项式时间。 例如：

  • 顶点覆盖：2-近似（简单贪心）。
  • TSP（满足三角不等式）：1.5-近似（Christofides 算法）。
  • 集合覆盖：$O(\log n)$-近似（贪心）。

2. 参数化算法

当某个参数较小时，复杂度为 $f(k) \cdot n^{O(1)}$。 例如顶点覆盖的复杂度为 $O(2^k \cdot n)$， 其中 $k$ 是覆盖大小。

3. 启发式算法

不做最优性保证，但实际表现好：

  • 模拟退火
  • 遗传算法
  • 蚁群算法
  • 禁忌搜索

4. 精确算法（小规模）

对规模较小的问题，可以用分支限界、 整数规划（ILP）、SAT 求解器求精确解。

工程中的 NP 完全问题

  • 台站选址：集合覆盖或 $k$-中位问题。
  • 传感器布设：最大覆盖或最小成本覆盖。
  • 任务调度：多机调度、时间窗约束。
  • 路径规划：巡检路线、应急路径。
  • 参数反演：组合搜索、模型选择。
  • 断层分段方案选择：组合优化。

import random
import math
import numpy as np


def greedy_set_cover(universe, sets):
    """
    贪心算法求解集合覆盖。
    近似比 O(log n)。
    universe: 全集（集合）
    sets: 可用集合列表（每个是集合）
    """
    uncovered = set(universe)
    chosen = []

    while uncovered:
        # 选覆盖最多未覆盖元素的集合
        best = max(sets, key=lambda s: len(s & uncovered))
        if not (best & uncovered):
            break
        chosen.append(best)
        uncovered -= best

    return chosen


def simulated_annealing_tsp(dist_matrix, n_iter=10000, seed=42):
    """
    模拟退火求解 TSP。
    dist_matrix: 距离矩阵
    """
    rng = random.Random(seed)
    n = len(dist_matrix)

    def total_distance(tour):
        return sum(dist_matrix[tour[i]][tour[(i+1) % n]] for i in range(n))

    # 初始解：随机排列
    current = list(range(n))
    rng.shuffle(current)
    current_cost = total_distance(current)
    best = current[:]
    best_cost = current_cost

    T = 100.0        # 初始温度
    cooling = 0.995

    for _ in range(n_iter):
        # 生成邻居：2-opt 交换
        i, j = sorted(rng.sample(range(n), 2))
        new_tour = current[:i] + current[i:j+1][::-1] + current[j+1:]
        new_cost = total_distance(new_tour)

        delta = new_cost - current_cost
        if delta < 0 or rng.random() < math.exp(-delta / T):
            current = new_tour
            current_cost = new_cost
            if current_cost < best_cost:
                best = current[:]
                best_cost = current_cost
        T *= cooling

    return best, best_cost


def vertex_cover_greedy(edges, vertices):
    """
    贪心 2-近似顶点覆盖。
    """
    edges = set(edges)
    cover = set()

    while edges:
        # 选一条边
        u, v = next(iter(edges))
        cover.add(u)
        cover.add(v)
        # 删除所有与 u 或 v 关联的边
        edges = {e for e in edges if u not in e and v not in e}

    return cover

⚠️

NP 完全性对工程实践的意义： 当面对一个问题时，第一件事是判断它是否 NP 完全： ① 如果是 P 问题——找精确高效算法； ② 如果是 NP 完全——不要试图找精确高效算法（除非 P=NP）； ③ 转而寻找近似算法、启发式算法或利用问题特性。 这个判断能避免大量无效的算法设计努力。

算法设计在数值计算中的体现

数值计算的核心算法本质上都是算法设计的产物：

  • FFT：分治法，从 $O(n^2)$ 降到 $O(n \log n)$。
  • 共轭梯度：Krylov 子空间迭代，适合大规模稀疏系统。
  • 多重网格：分治思想，加速 PDE 求解。
  • 快速多极子（FMM）：层次分解，把 $N$ 体问题从 $O(N^2)$ 降到 $O(N)$。
  • 稀疏矩阵重排序：贪心 + 图算法，减少填充。

算法在机器学习中的角色

现代地震学大量使用机器学习，其核心也是算法：

  • 随机梯度下降（SGD）：大规模优化。
  • 反向传播：动态规划（链式法则的复用）。
  • k-means 聚类：贪心迭代优化。
  • 主成分分析（PCA）：随机 SVD 或幂迭代。
  • 决策树：递归分治 + 贪心分裂。
  • 随机森林：集成随机化算法。
  • MCMC：马尔可夫链蒙特卡洛。

实时算法与地震预警

地震预警对算法有极高要求：

  • 低延迟：秒级完成震相拾取、定位、震级估计。
  • 在线处理：数据流算法（环形缓冲区、滑动窗口）。
  • 鲁棒性：单台站错误不影响整体判断。
  • 可更新：随信息累积不断更新估计。

典型算法：

  • STA/LTA（在线）
  • τc、Pd（P 波特征参数在线估计）
  • 网格搜索 + 梯度下降（快速定位）
  • 贝叶斯更新（震级持续修正）

09小结

📌 核心要点

  • 算法设计范式：分治、贪心、DP、回溯、随机化；主定理分析递归复杂度。
  • 分治法：分解-求解-合并；归并排序、FFT、Strassen、最近点对。
  • 贪心算法：局部最优 → 全局最优；需证明贪心选择性质与最优子结构。
  • 动态规划：最优子结构 + 重叠子问题；状态定义、转移方程、初值、顺序。
  • 回溯与分支限界：决策树搜索 + 剪枝；DFS 回溯 vs 优先队列分支限界。
  • 随机化算法：拉斯维加斯（结果正确）vs 蒙特卡洛（结果可能错）；水库抽样、Miller-Rabin。
  • NP 完全性：P vs NP；近似算法、参数化算法、启发式方法应对难解问题。
  • 工程应用：地震学定位、反演、目录处理、实时预警；机器学习与数值计算。
