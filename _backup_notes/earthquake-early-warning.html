地震预警

从 P 波到 S 波的时间差，覆盖预警原理、台网架构、 震源参数快速估计与预警信息发布。 地震预警是目前唯一能在地震波到达之前向目标区域发出警报的技术， 也是减轻地震灾害的实时防线。

P 波 实时处理 震级估计 防灾减灾

§引言

地震预警（Earthquake Early Warning，EEW）利用地震波的传播时间差， 在地震发生后、破坏性地震动到达目标区域之前， 通过电磁波（光速）向公众、机构和关键设施发出警报。

它的核心物理原理只有一条：

$$ v_P > v_S, \qquad v_{\text{电磁波}} \gg v_S $$

P 波（纵波）速度约 6 km/s，S 波（横波）约 3.5 km/s， 而电磁波以光速传播。因此在震中附近检测到 P 波后， 可以赶在破坏性 S 波到达之前向远处目标发出警报。

预警时间的来源

对距离震中 $D$ 的目标，预警时间可粗略估计为：

$$ t_{\text{warn}} = \frac{D}{v_S} - \frac{D}{v_P} - t_{\text{proc}} - t_{\text{comm}} $$

其中：

  • $\dfrac{D}{v_S}$：S 波到达目标的时间。
  • $\dfrac{D}{v_P}$：P 波从震源到达目标的时间。
  • $t_{\text{proc}}$：系统处理时间（震相拾取、定位、震级估计）。
  • $t_{\text{comm}}$：通信与发布延迟。

对 100 km 外的目标，$D/v_S - D/v_P$ 约为：

$$ \frac{100}{3.5} - \frac{100}{6} \approx 28.6 - 16.7 = 11.9 \text{ s} $$

扣除处理与通信延迟，实际预警时间约 5~10 s。 这个时间虽然短，但足以：

  • 高速列车减速或紧急制动
  • 电梯在最近楼层停靠开门
  • 燃气管线自动关闭
  • 精密设备停机或切换保护模式
  • 手术室暂停手术、人员躲避
  • 核电站切换到安全状态

与地震预测的区别

维度地震预测地震预警
时间 地震发生之前（天、月、年） 地震发生后、地震动到达前（秒）
依据 前兆异常、统计模型 已发生的地震波
确定性 尚无可靠方法 物理原理明确，可工程实现
现状 仍在探索 多国已业务化运行

地震预警不是"预测地震"，而是"地震已经发生，抢在破坏性波到达之前报警"。 这个区别非常重要——它让预警成为一项可实现的工程系统。

01预警原理

P 波与 S 波

地震发生时，震源向外辐射多种波：

波型质点运动典型速度破坏性
P 波（纵波） 沿传播方向压缩-膨胀 5.5~7.0 km/s（地壳） 较弱
S 波（横波） 垂直传播方向剪切 3.0~4.0 km/s（地壳） 强
面波（Love、Rayleigh） 地表椭圆/水平 略小于 S 波 强、衰减慢

工程结构的主要破坏来自 S 波与面波。 P 波虽然先到，但幅值小，通常不造成破坏。 这正是地震预警可利用的"时间窗"。

时间差原理

设震源到目标的距离为 $D$， P 波与 S 波的到时差为：

$$ \Delta t = D \left( \frac{1}{v_S} - \frac{1}{v_P} \right) $$

近似地，取 $v_P = 6$ km/s，$v_S = 3.5$ km/s：

$$ \Delta t \approx D \times 0.119 \text{ s/km} \approx \frac{D}{8.4} \text{ s} $$

即距离每增加 8.4 km，预警时间增加 1 秒。 这就是为什么预警对远场更有效—— 距离越远，预警时间越长，但地震动衰减也越大。

预警盲区

震中附近区域无法获得有效预警，称为预警盲区。 盲区半径约为：

$$ R_{\text{blind}} \approx v_S \cdot (t_{\text{detect}} + t_{\text{proc}}) $$

若系统在 P 波到达后 $t_{\text{detect}} \approx 3$ s 检测到， 处理需要 $t_{\text{proc}} \approx 2$ s， 则盲区半径约为 $3.5 \times 5 = 17.5$ km。 盲区内的破坏性地震动可能已经到达，来不及预警。

减小盲区的方向：

  • 密集台网：缩短 P 波检测时间。
  • 快速算法：缩短处理延迟。
  • 前沿预警：用最先触发台站向其后方向发送预警。
  • 多源联合：结合多种观测（GPS、强震、烈度计）。
💡

预警是"空间换时间"：震中附近盲区内的目标无法获得预警， 但震中以外数十到数百公里的区域可以。这就决定了预警系统必须 沿断层走向和主要城市方向布设密集台网， 才能让最重要的目标区域获得最大预警时间。

02预警类型

三种技术路线

地震预警系统按运行方式分为三类：

类型原理优点缺点
区域预警（Front-detection） 震中附近台站检测 P 波后，向远处目标发布 预警时间较长、技术成熟 盲区内无预警
现场预警（On-site） 目标场地自身布设传感器，检测 P 波后本地报警 适用于关键设施、无通信依赖 预警时间很短（几秒）
混合预警 区域 + 现场结合，多级预警 兼顾覆盖范围与响应速度 系统复杂、成本高

区域预警

区域预警是主流方式，典型系统包括：

  • 日本 JMA EEW：2007 年业务化，全球最成熟的系统。
  • 墨西哥 SASMEX：1991 年投入使用，全球最早。
  • 台湾地区 CWB EEW：覆盖全岛，秒级发布。
  • 美国 ShakeAlert：加州、俄勒冈、华盛顿，2019 年公开。
  • 中国国家地震烈度速报与预警工程：2020 年代逐步建成。

区域预警的关键挑战：盲区与误报。 盲区内无法预警，误报会降低公众信任。

现场预警

现场预警在目标场地（如核电站、高速铁路、医院）布设加速度计或地震计， 检测 P 波后直接触发保护动作。典型预警时间 1~5 s。

典型应用：

  • 高速铁路：P 波检测后触发减速或制动。
  • 核电站：切换控制棒、停堆。
  • 电梯：最近楼层停靠开门。
  • 精密制造：设备停机、阀门关闭。

预警级别

各国预警系统的分级不同。日本 JMA 分为：

  • 緊急地震速報（予報）：预测震度 3 以上。
  • 緊急地震速報（警報）：预测震度 5 弱以上。

中国按预警震级分为：

  • 红色：预测震级 ≥ 7.0，或预估烈度 ≥ 7 度。
  • 橙色：预测震级 6.0~7.0，或预估烈度 5~6 度。
  • 黄色：预测震级 5.0~6.0，或预估烈度 3~4 度。
  • 蓝色：预测震级 < 5.0。
💡

预警不是越早越好：过早发布意味着震源参数估计不准， 可能误报或低估。预警系统必须在及时性与准确性之间权衡。 日本 JMA 采用"先发后修"策略：先用少量台站快速发布第一报， 随后用更多台站不断更新。

03台网与算法

台网架构

典型地震预警系统的架构：

  1. 观测层：密集布设强震仪、地震计、烈度计。
  2. 传输层：实时数据流（低延迟、高可靠）。
  3. 处理层：震相拾取、定位、震级估计、地震动预测。
  4. 决策层：判断是否发布、分级、更新。
  5. 发布层：通过广播、手机、专用终端发布。

台站密度要求

台站间距决定了震源参数估计的速度与精度：

台站间距典型盲区半径应用
~100 km ~50 km 区域预警（初期）
~50 km ~25 km 区域预警（成熟）
~20 km ~10 km 国家预警工程
~10 km ~5 km 城市预警、重点区域

日本 K-NET / KiK-net 台站间距约 20 km， 加州 ShakeAlert 台站间距约 10~20 km， 中国国家预警工程台站间距约 15~20 km。

震相拾取

实时 P 波拾取是预警的第一步。常用算法：

  • STA/LTA：短时平均/长时平均比，超过阈值则触发。
  • AIC（Akaike Information Criterion）：基于信息准则的最优分割点。
  • AR-AIC：自回归 + AIC，精度更高。
  • 机器学习拾取：如 PhaseNet、EQTransformer、GPD，深度学习拾取。

STA/LTA 是最基础的方法，计算量小、适合实时系统。 机器学习方法精度更高，但需要 GPU 或专门硬件。

定位方法

预警系统使用至少 3 个台站的 P 波到时，通过三角定位确定震源位置。 简化的定位方程：

$$ (x_i - x_0)^2 + (y_i - y_0)^2 = v_P^2 (t_i - t_0)^2 $$

其中 $(x_i, y_i, t_i)$ 是第 $i$ 个台站的位置与到时， $(x_0, y_0, t_0)$ 是震源位置与发震时刻。 求解该方程组即可定位。

对预警系统，定位必须在 1~3 s 内完成， 因此通常采用简化的网格搜索或迭代最小二乘， 而不是完整的三维反演。

日本 JMA 的处理流程

JMA 的紧急地震速报流程：

  • P 波到达第 1 个台站后立即触发。
  • 用 1 个台站做初步震级估计（$M_{\text{est}}$ 基于 $\tau_c$ 或 $P_d$）。
  • 用 2~3 个台站做初步定位。
  • 第 1 报发布（通常在地震发生后 3~5 s）。
  • 持续更新：用更多台站、更长时间窗，提高精度。
  • 如果预测震度超过阈值，升级为"警报"。

Python 示例：STA/LTA 实时触发

sta_lta.py Python 
import numpy as np


def sta_lta(data, fs, sta_len=0.5, lta_len=10.0, threshold=4.0):
    """
    短时平均/长时平均（STA/LTA）触发检测。
    data:     输入波形
    fs:       采样率 Hz
    sta_len:  短时窗长 s
    lta_len:  长时窗长 s
    threshold: 触发阈值
    返回：
      trigger_idx: 触发点索引
      ratio:       每个采样点的 STA/LTA 比
    """
    n = len(data)
    n_sta = int(sta_len * fs)
    n_lta = int(lta_len * fs)

    # 用能量（平方）代替幅值，更稳健
    energy = data ** 2

    # 累积和加速计算
    csum = np.cumsum(energy)
    csum = np.concatenate([[0], csum])

    ratio = np.zeros(n)

    # 从 LTA 窗口填满的位置开始
    for i in range(n_lta, n):
        sta = (csum[i] - csum[i - n_sta]) / n_sta
        lta = (csum[i] - csum[i - n_lta]) / n_lta
        if lta > 0:
            ratio[i] = sta / lta

    # 找第一次超过阈值的位置
    trigger_idx = None
    for i in range(n_lta, n):
        if ratio[i] > threshold:
            trigger_idx = i
            break

    return trigger_idx, ratio


def estimate_tau_c(data, fs, p_idx, window=3.0):
    """
    用 τc 方法估计震级（简化）。
    τc 定义为积分：
        τc = 2π · sqrt(∫u² dt / ∫(du/dt)² dt)
    震级经验关系（示意）：
        M ≈ a · log10(τc) + b
    """
    n_win = int(window * fs)
    seg = data[p_idx : p_idx + n_win]
    if len(seg) < 10:
        return None

    dt = 1.0 / fs
    u2 = np.sum(seg**2) * dt
    du = np.diff(seg) / dt
    du2 = np.sum(du**2) * dt

    if du2 <= 0:
        return None

    tau_c = 2 * np.pi * np.sqrt(u2 / du2)
    return tau_c


if __name__ == "__main__":
    # ---- 合成一段含 P 波的地震记录 ----
    rng = np.random.default_rng(42)
    fs = 100.0
    t = np.arange(0, 30, 1.0 / fs)

    # 背景噪声
    data = 0.001 * rng.normal(size=len(t))

    # P 波在 t = 5 s 到达
    p_arrival = 5.0
    p_idx = int(p_arrival * fs)
    p_wave = 0.05 * np.exp(-((t - p_arrival) ** 2) / (2 * 0.3**2)) \
             * np.sin(2 * np.pi * 5.0 * t)
    data += p_wave * (t >= p_arrival)

    # S 波在 t = 8 s 到达（幅值更大）
    s_arrival = 8.0
    s_wave = 0.5 * np.exp(-((t - s_arrival) ** 2) / (2 * 0.8**2)) \
             * np.sin(2 * np.pi * 2.0 * t)
    data += s_wave * (t >= s_arrival)

    # ---- STA/LTA 检测 ----
    trig_idx, ratio = sta_lta(data, fs, sta_len=0.5, lta_len=5.0, threshold=4.0)

    if trig_idx is not None:
        trig_time = trig_idx / fs
        delay = trig_time - p_arrival
        print(f"P 波实际到时: {p_arrival:.3f} s")
        print(f"STA/LTA 触发时刻: {trig_time:.3f} s")
        print(f"触发延迟: {delay:.3f} s")

        # ---- τc 估计 ----
        tau_c = estimate_tau_c(data, fs, trig_idx, window=3.0)
        if tau_c:
            print(f"\nτc = {tau_c:.4f} s")
            # 经验关系（示意）：M ≈ 3.0 * log10(τc) + 5.0
            M_est = 3.0 * np.log10(tau_c) + 5.0
            print(f"估计震级（示意）: M ≈ {M_est:.2f}")
    else:
        print("未触发")

    # ---- 绘图 ----
    import matplotlib.pyplot as plt

    fig, axes = plt.subplots(2, 1, figsize=(12, 6), sharex=True)

    axes[0].plot(t, data, linewidth=0.7)
    if trig_idx is not None:
        axes[0].axvline(trig_idx / fs, color="red", linestyle="--",
                        label=f"STA/LTA 触发 t={trig_idx/fs:.2f}s")
        axes[0].axvline(p_arrival, color="green", linestyle=":",
                        label="P 波到时")
        axes[0].axvline(s_arrival, color="orange", linestyle=":",
                        label="S 波到时")
        axes[0].legend()
    axes[0].set_ylabel("加速度")
    axes[0].set_title("波形与 P/S 波到时")
    axes[0].grid(True, alpha=0.3)

    axes[1].plot(t, ratio, linewidth=0.7)
    axes[1].axhline(4.0, color="red", linestyle="--", label="阈值 = 4")
    axes[1].set_xlabel("t / s")
    axes[1].set_ylabel("STA/LTA")
    axes[1].legend()
    axes[1].grid(True, alpha=0.3)

    plt.tight_layout()

04震级快速估计

为什么震级估计最难

震级估计是地震预警中最难、最关键的环节。 原因：

  • 时间不足：通常只能用 P 波到达后 3~10 s 的数据。
  • 信息有限：大地震需要几十秒甚至几分钟才能完全破裂。
  • 震级饱和：传统震级标度（$M_L$、$m_b$、$M_S$）在大震时饱和。
  • 更新策略：震级估计必须随破裂过程持续更新。

常用方法

1. τc 方法

τc 是 P 波到达后前 3 秒波形的"特征周期"，定义为：

$$ \tau_c = 2\pi \sqrt{\frac{\int_0^{\tau_0} u^2(t) \, dt} {\int_0^{\tau_0} \dot{u}^2(t) \, dt}} $$

其中 $u(t)$ 是位移（由加速度积分），$\dot{u}(t)$ 是速度， $\tau_0$ 是积分窗长（通常 3 s）。

τc 与震级有经验关系：

$$ \log_{10} M_0 = a \log_{10} \tau_c + b $$

其中 $M_0$ 是地震矩，$a$、$b$ 由区域数据回归得到。 τc 方法适合 3~7 级地震，大震时需要更长的窗。

2. Pd 方法

Pd 是 P 波到达后前 3 秒的峰值位移：

$$ P_d = \max_{0 < t < 3\text{s}} |u(t)| $$

与震级的关系：

$$ \log_{10} P_d = A + B \cdot M + C \cdot \log_{10} R $$

其中 $R$ 是震中距。Pd 方法对近场大震敏感， 是 ShakeAlert 系统的核心方法之一。

3. 卓越周期方法

用 P 波前几秒的卓越周期 $\tau_p$ 估计震级：

$$ \tau_p = \frac{\sum_i A_i^2 / f_i}{\sum_i A_i^2} $$

其中 $A_i$ 与 $f_i$ 是第 $i$ 个频率成分的幅值与频率。

4. 幅值-距离联合方法

结合多个台站的 P 波幅值：

$$ M = \log_{10} A + \log_{10} R + C $$

这类方法适合震中距较大、台站较多的情况。

震级饱和问题

短时间窗内的震级估计存在饱和： 当实际震级超过某一水平时，估计值不再增长。 原因：大震的破裂持续时间长， 前几秒的波形只反映了最初破裂段， 不足以反映整个地震的规模。

典型饱和现象：

方法饱和震级说明
τc（3 s 窗） ≈ 7.0 超过 7 级后估计偏低
Pd（3 s 窗） ≈ 7.0 同上
传统 $M_L$ ≈ 6.5 短周期饱和
$m_b$ ≈ 6.0 体波饱和
$M_S$ ≈ 8.0 面波饱和
$M_w$ 无饱和 需长时间记录

减小饱和的方向：

  • 延长时间窗：从 3 s 逐渐延长到 10~20 s。
  • 多台站联合：用多台站数据共同估计。
  • 多点破裂模型：考虑破裂传播方向。
  • 机器学习：用神经网络从波形直接估计 $M_w$。

2011 年东日本地震的教训

2011 年 3 月 11 日东日本 Mw9.0 地震， JMA 紧急地震速报系统面临严峻挑战：

  • 第一报估计震级 4.3（严重低估）。
  • 第二报估计 5.9，第三报 6.8。
  • 最终估计 8.4，仍低于实际 Mw9.0。
  • 大范围地区预测震度偏低，预警效果受限。

这次事件推动了预警算法的重大改进：

  • 引入多台站联合震级估计。
  • 改进 τc、Pd 的区域关系。
  • 加入机器学习方法。
  • 考虑破裂方向性对远场地震动的影响。
⚠️

震级估计的哲学：地震预警必须在有限信息下做快速决策。 这不是"精确测量"问题，而是"及时判断"问题。 预警系统的价值不在于精确预测震级，而在于在破坏性波到达前给出足够好的估计， 让关键设施有时间采取保护动作。宁可保守（高估），也不宜低估（漏报）。

05地震动预测

从震级到地震动

得到震源位置与震级后，预警系统需要预测目标场地的地震动强度。 常用指标：

  • PGA：峰值加速度。
  • 烈度：日本气象厅震度、中国地震烈度。
  • 反应谱：结构工程关心的参数。
  • MMI：改进麦加利烈度，美国常用。

地震动预测方程（GMPE）

标准 GMPE 形式：

$$ \ln Y = f(M, R, V_{S30}, \ldots) + \varepsilon $$

其中 $Y$ 是地震动参数，$M$ 是震级，$R$ 是距离， $V_{S30}$ 是场地参数，$\varepsilon$ 是残差。

预警系统使用简化版 GMPE，通常只依赖 $M$ 与 $R$， 有时加入场地类别修正。例如：

$$ \log_{10} \mathrm{PGA} = a M - b \log_{10}(R + c) - d R + e $$

烈度预测

日本 JMA 用计测震度表示地震动强度， 与实际震度对应：

$$ I_{\text{JMA}} = 2 \log_{10} a_{\max} + 0.94 - 1.5 $$

其中 $a_{\max}$ 是峰值加速度（gal）。 计测震度 5 弱对应约 100 gal， 6 强对应约 400 gal，7 对应约 800 gal。

中国地震烈度与 PGA 对应关系：

烈度PGA 范围（gal）典型现象
Ⅵ 度 63~125 轻微破坏
Ⅶ 度 125~250 中等破坏
Ⅷ 度 250~500 严重破坏
Ⅸ 度 500~1000 局部倒塌
Ⅹ 度 > 1000 大面积倒塌

场地效应修正

预警系统的地震动预测需要考虑场地放大。常用方法：

$$ \mathrm{PGA}_{\text{site}} = \mathrm{PGA}_{\text{rock}} \times \mathrm{AF}(V_{S30}) $$

其中 $\mathrm{AF}$ 是放大因子，$V_{S30}$ 是地表 30 m 平均剪切波速。 软土场地放大因子可达 2~4 倍。

预警系统通常预设每个台站或每个格网的场地类别， 用查表方式快速应用放大因子。

不确定性与误报

预警系统的地震动预测存在较大不确定性：

  • 震级不确定性：特别是大震的饱和问题。
  • 定位不确定性：台站少时误差可达 10~20 km。
  • GMPE 残差：标准差可达 0.3~0.5（对数单位）。
  • 场地效应：缺乏场地资料时误差大。

降低误报的策略：

  • 多参数联合判断：震级、位置、烈度多指标。
  • 动态更新：随信息积累提高估计。
  • 概率表达：给出预测的概率分布而非单值。
  • 设置阈值：仅对超过阈值的预测发布预警。

Python 示例：简易地震动预测

gmpe_eew.py Python 
import numpy as np


def gmpe_simple(M, R, vs30=500.0):
    """
    简化的地震动预测方程（示意）。
    输入：
      M:     震级
      R:     震中距 km
      vs30:  地表 30 m 平均剪切波速 m/s
    返回：
      PGA:   峰值加速度（gal = cm/s²）
    """
    # 基础 PGA（基岩）
    log_pga_rock = 0.5 * M - 1.0 * np.log10(R + 10) - 0.002 * R + 1.5
    pga_rock = 10 ** log_pga_rock

    # 场地放大因子（简化）
    # 软土 vs30 < 200 放大 2 倍，硬土 vs30 > 500 放大 1 倍
    af = np.clip(1000.0 / vs30, 1.0, 3.0)

    return pga_rock * af


def pga_to_intensity(pga_gal):
    """
    用简化关系估计中国地震烈度：
      I = 3.3 * log10(PGA) - 1.0
    其中 PGA 单位 gal。
    """
    if pga_gal <= 0:
        return 0.0
    return 3.3 * np.log10(pga_gal) - 1.0


def pga_to_jma_intensity(pga_gal):
    """
    用简化关系估计日本计测震度：
      I_JMA = 2 * log10(PGA) + 0.94 - 1.5
    """
    if pga_gal <= 0:
        return 0.0
    return 2.0 * np.log10(pga_gal) + 0.94 - 1.5


if __name__ == "__main__":
    print("不同震级与距离的 PGA 预测：")
    print(f"{'M':>4}{'R (km)':>8}{'PGA (gal)':>12}{'烈度':>8}{'JMA':>8}")
    print("-" * 45)

    for M in [5.0, 6.0, 7.0, 8.0]:
        for R in [10, 30, 100, 200]:
            pga = gmpe_simple(M, R, vs30=300)
            I = pga_to_intensity(pga)
            I_jma = pga_to_jma_intensity(pga)
            print(f"{M:>4.1f}{R:>8}{pga:>12.1f}{I:>8.1f}{I_jma:>8.1f}")
        print()

    # ---- 预警时间计算 ----
    print("预警时间估算（假设震中距 D）：")
    print(f"{'D (km)':>10}{'Δt_P-S (s)':>15}{'剩余预警时间 (s)':>20}")
    print("-" * 48)

    vP, vS = 6.0, 3.5    # km/s
    t_proc = 3.0         # 处理延迟 s

    for D in [30, 50, 100, 200]:
        dt_ps = D * (1/vS - 1/vP)
        t_warn = dt_ps - t_proc
        print(f"{D:>10}{dt_ps:>15.2f}{max(0, t_warn):>20.2f}")

运行后可以看到：

  • 震级每增加 1 级，PGA 约增大 3 倍。
  • 距离每增加 10 倍，PGA 约降低 3~5 倍。
  • 100 km 外的目标预警时间约 8~9 s（扣除处理延迟）。

06信息发布

发布渠道

预警信息必须快速、广泛、可靠地送达目标用户：

渠道延迟覆盖典型应用
电视/广播 1~5 s 广泛 公众预警
手机 App 1~3 s 个人 公众预警
手机小区广播 1~5 s 区域 无 App 依赖
专用终端 0.5~2 s 机构 高铁、核电、医院
专线/API 0.1~1 s 关键设施 自动化控制

预警信息内容

标准预警信息包含：

  • 发震时刻：年-月-日 时:分:秒。
  • 震中位置：经纬度、地名。
  • 震级：估计震级（不断更新）。
  • 震源深度：km。
  • 预测烈度：目标区域预测的地震烈度。
  • 预警级别：红/橙/黄/蓝。
  • 预计到达时间：S 波到达目标区域的时间。
  • 更新次数：第几报。

用户响应

不同用户对预警的响应不同：

用户可用时间典型响应
公众 5~30 s 躲避、远离玻璃、打开门
高速铁路 10~30 s 减速、制动、切断供电
电梯 3~10 s 最近楼层停靠、开门
燃气 3~10 s 自动关闭阀门
核电站 10~60 s 切换控制棒、停堆
手术室 5~30 s 暂停手术、固定设备
数据中心 5~20 s 切换备用电源、保护硬盘

误报与漏报

预警系统面临两类错误：

  • 误报（False Alarm）：预测有强震但实际没有。 后果：公众失去信任、自动系统误动作。
  • 漏报（Missed Alarm）：有强震但未发出预警。 后果：失去预警的意义。

系统设计需要在两者之间权衡。通常设置：

  • 误报率 < 10%。
  • 漏报率 < 5%。
  • 预警发布时间 < 5 s。

日本 JMA 的实践

JMA 紧急地震速报运行十余年，积累了丰富经验：

  • 每月发布数次预警（多为小震）。
  • 误报率较低，但每次误报都引起公众讨论。
  • 2011 年东日本地震后升级为"多台站联合处理"。
  • 针对大震的震级饱和问题持续改进。
⚠️

预警的"狼来了"问题：如果预警系统频繁误报， 公众可能逐渐忽视预警，甚至拒绝响应。 这对系统的长期有效性是致命的。 因此预警系统的设计必须宁可漏报小震，不可误报大震， 并且持续优化算法与用户体验。

07挑战与局限

物理局限

  • 预警盲区：震中附近无法获得有效预警。
  • 震级饱和：大震的震级估计需要时间。
  • 不确定的破裂过程：多点破裂、超剪切破裂难以预测。
  • 地震动的空间变化：不同场地、不同方向差异大。

技术挑战

  • 台网密度：密集台网成本高、维护困难。
  • 通信延迟：偏远地区、海底台站的通信瓶颈。
  • 算法速度：复杂算法难以在秒级完成。
  • 误报控制：在速度与准确性之间权衡。
  • 系统可靠性：地震本身可能破坏通信设施。

社会挑战

  • 公众教育：让公众理解预警的局限，不恐慌也不忽视。
  • 责任界定：误报造成的损失谁负责？
  • 成本分摊：谁为预警系统付费？
  • 跨境协作：跨国地震预警的协调。

新兴方向

  • 机器学习：用深度学习从波形直接估计震级、位置。
  • GNSS 预警：用 GPS 位移数据补充传统地震仪。
  • DAS（分布式声传感）：光纤传感提供密集观测。
  • 智能手机众包：利用手机加速度计形成超级密集台网。
  • 低成本 MEMS 台网：降低台网密度瓶颈。
  • 多灾种耦合预警：地震 + 海啸 + 滑坡联合预警。
💡

地震预警的未来：从"单一台网预警"走向 "多源、密集、智能、协同"。 手机众包、低成本 MEMS 台站、GNSS、DAS 都是重要发展方向。 最终目标是把预警盲区缩到最小， 并让预警信息成为像天气预报一样普及的公共服务。

08工程应用

典型应用场景

1. 高速铁路

高铁在高速运行中，脱轨风险大。预警系统可以在 S 波到达前：

  • 自动减速或紧急制动。
  • 切断牵引供电，减少火险。
  • 通知沿线信号系统进入安全模式。
  • 对隧道、桥梁段加强监控。

日本新干线、中国高铁都在推进 EEW 联动。 日本新干线在 2011 年东日本地震中实现了全部列车安全停车。

2. 核电站

核电站一旦受损，后果极其严重。EEW 可触发：

  • 控制棒快速插入（停堆）。
  • 应急柴油发电机启动准备。
  • 冷却系统切换至安全模式。
  • 关键阀门关闭。

3. 医院

医院有手术、生命维持设备、影像设备。EEW 可以：

  • 暂停手术操作。
  • 切换生命维持设备电源。
  • 固定或保护大型医疗设备。
  • 通知病房人员避难。

4. 工业设施

化工厂、石化厂、半导体厂：

  • 停止关键工艺过程。
  • 关闭危险化学品阀门。
  • 保护精密设备、光刻机。
  • 切换备用电源。

5. 城市基础设施

  • 燃气：自动关闭主管道阀门。
  • 电力：切换备用电源、隔离敏感设备。
  • 供水：保护水泵、关闭关键阀门。
  • 通信：切换备用基站，保障应急通信。
  • 电梯：最近楼层停靠。

6. 公共安全

  • 向公众手机推送预警。
  • 地铁、机场暂停运营。
  • 大型活动（体育赛事、演唱会）应急响应。
  • 学校、幼儿园紧急避险。

系统集成

预警系统的工程集成需要考虑：

  • 接口标准化：API、协议、数据格式。
  • 响应时间：从触发到动作的端到端延迟。
  • 可靠性：双通道、冗余设计。
  • 自检机制：定期测试、演练。
  • 可追溯性：每次预警的日志与记录。

效益评估

预警系统的经济与社会效益：

  • 减轻人员伤亡：公众及时避险。
  • 减少财产损失：关键设施自动保护。
  • 保障生命线：减少次生灾害。
  • 社会心理安慰：减轻恐慌、提高应对能力。

日本、墨西哥、美国加州的实践表明， 预警系统的社会效益远超其建设和运行成本。

与其它技术的结合

  • 与结构健康监测结合：结构台阵触发后评估损伤。
  • 与地震危险性分析结合：预警后快速更新危险性估计。
  • 与快速震害评估结合：预警 + 震后快速评估，形成完整链条。
  • 与应急响应结合：预警自动触发应急指挥系统。
💡

预警系统的工程价值：它把地震工程从"事后分析"扩展到"实时响应"。 传统地震工程关注震后评估与设计改进， 而预警系统让工程师可以在地震波到达前的几秒到几十秒内 主动保护结构、设备与人员。 这是地震工程从"被动防御"到"主动防护"的转变。

09小结

📌 核心要点

  • 预警原理：利用 P 波与 S 波的速度差，抢在破坏性波到达前报警。
  • 预警时间：$t_{\text{warn}} = D/v_S - D/v_P - t_{\text{proc}} - t_{\text{comm}}$；距离每增加 8.4 km 增加约 1 s。
  • 预警盲区：震中附近无法有效预警，盲区半径取决于台网密度与算法速度。
  • 三类系统：区域预警、现场预警、混合预警，各有适用场景。
  • 震相拾取：STA/LTA、AIC、机器学习；实时性要求极高。
  • 震级估计：τc、Pd、卓越周期方法；存在饱和问题，大震估计偏低。
  • 地震动预测：简化 GMPE + 场地放大因子；转换为烈度或震度。
  • 信息发布：多渠道、低延迟、标准化；误报与漏报需权衡。
  • 工程应用：高铁、核电、医院、工业、城市基础设施的自动保护。
