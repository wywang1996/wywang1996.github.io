设计反应谱

GB 50011-2010《建筑抗震设计规范》的地震影响系数曲线 α(T)。 曲线由四段组成：上升段、平台段、下降段、直线下降段， 阻尼调整系数 η1、η2、γ 按规范公式计算。 本页支持多设防烈度同图对比与阻尼比敏感性， 是抗震设计最常用的图件。

Parameters

输入参数

设计反应谱是解析式，不需要外部数据文件。 只需三个规范参数：设防烈度（决定 αmax）、 场地类别与设计地震分组（决定特征周期 Tg）、 结构阻尼比 ζ。所有参数直接写在代码里，便于批量修改。

Meaning

这张图说明了什么

GB 50011-2010 的地震影响系数曲线 α(T) 是设计反应谱， 表示结构自振周期为 T 时地震作用引起的等效加速度与重力加速度之比。 它是多遇地震（小震）或罕遇地震（大震） 作用下结构弹性或弹塑性反应的规范化包络。

四段曲线的含义

  • 上升段（T < 0.1 s）：
    α = [0.45 + 10(η2 − 0.45)T] · αmax
    从 0.45·αmax 线性增加到 η2·αmax。 周期很小时结构接近刚体，响应跟随地面运动。
  • 平台段（0.1 s ≤ T ≤ Tg）：
    α = η2 · αmax
    结构自振周期与场地卓越周期接近，动力放大达到最大。 平台高度即为地震影响系数最大值 η2·αmax。
  • 下降段（Tg < T ≤ 5Tg）：
    α = (Tg/T)γ · η2 · αmax
    随周期增大按幂函数衰减，γ 为衰减指数（默认 0.9）。
  • 直线下降段（5Tg < T ≤ 6 s）：
    α = [η2·0.2γ − η1(T − 5Tg)] · αmax
    长周期段按线性衰减，斜率由 η1 控制。

三个阻尼调整系数

当阻尼比不等于 5% 时，需要用三个系数修正曲线：

η2 = 1 + (0.05 − ζ) / (0.08 + 1.6ζ)
γ = 0.9 + (0.05 − ζ) / (0.3 + 6ζ)
η1 = 0.02 + (0.05 − ζ) / (4 + 32ζ)
  • η2——阻尼调整系数，影响平台段高度与下降段幅值。 ζ > 0.05 时 η2 < 1（曲线降低）；ζ < 0.05 时 η2 > 1（曲线抬高）。
  • γ——下降段衰减指数，ζ > 0.05 时 γ < 0.9（衰减更快）。
  • η1——直线下降段斜率调整系数， 只在 5Tg < T ≤ 6 s 段起作用。

从图上能读出什么

  • 平台高度——即 η2·αmax， 是地震影响系数的最大值，直接反映设防烈度。
  • 平台起点——T = 0.1 s，规范统一规定的下限。
  • 平台终点——T = Tg， 特征周期越长，平台越宽，软土场地对长周期结构更不利。
  • 下降段斜率——由 γ 控制，反映结构响应随周期的衰减速度。
  • 曲线截止——T = 6 s 处截止，规范不考虑更长的周期。
与地震影响系数 α 的关系： 地震影响系数 α 与谱加速度 Sa 的关系为 α = Sa / g。所以 α 本质上就是 以 g 为单位的谱加速度。 设计时用水平地震作用 FEk = α · Geq， 其中 Geq 是结构等效总重力荷载。
注意：规范设计谱是标准化 + 保守包络， 不是任何一次真实地震的反应谱。它的平台段对应场地的卓越周期， 下降段则考虑到真实地震动的高频衰减特性。 与一致危险性谱（UHS）相比，规范谱更光滑、更保守。

Python

Python 代码

依赖 numpy 与 matplotlib。 核心函数 gb50011_spectrum 按规范公式实现四段曲线， 并按阻尼比自动计算 η1、η2、γ。

design-spectrum.pyPython
# =============================================================
# GB 50011-2010 地震影响系数曲线（设计反应谱）
# -------------------------------------------------------------
# 四段曲线：
#   T < 0.1 s        α = [0.45 + 10(η₂ - 0.45)T] · α_max
#   0.1 ≤ T ≤ Tg     α = η₂ · α_max
#   Tg < T ≤ 5Tg     α = (Tg/T)^γ · η₂ · α_max
#   5Tg < T ≤ 6 s    α = [η₂·0.2^γ - η₁(T - 5Tg)] · α_max
#
# 阻尼调整系数：
#   η₂ = 1 + (0.05 - ζ) / (0.08 + 1.6ζ)
#   γ  = 0.9 + (0.05 - ζ) / (0.3 + 6ζ)
#   η₁ = 0.02 + (0.05 - ζ) / (4 + 32ζ)
# =============================================================

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})


def gb50011_spectrum(T, alpha_max, Tg=0.40, zeta=0.05):
    """GB 50011-2010 地震影响系数曲线。

    参数
    ----
    T         : 周期数组 (s)
    alpha_max : 地震影响系数最大值
    Tg        : 特征周期 (s)
    zeta      : 阻尼比

    返回
    ----
    alpha : 地震影响系数数组，与 T 同形状
    """
    T = np.asarray(T, dtype=float)
    alpha = np.zeros_like(T)

    # ---- 阻尼调整系数 ----
    eta2 = 1.0 + (0.05 - zeta) / (0.08 + 1.6 * zeta)
    gamma = 0.9 + (0.05 - zeta) / (0.3 + 6.0 * zeta)
    eta1 = 0.02 + (0.05 - zeta) / (4.0 + 32.0 * zeta)

    for i, Ti in enumerate(T):
        if Ti < 0.1:
            alpha[i] = (0.45 + 10.0 * (eta2 - 0.45) * Ti) * alpha_max
        elif Ti <= Tg:
            alpha[i] = eta2 * alpha_max
        elif Ti <= 5.0 * Tg:
            alpha[i] = (Tg / Ti) ** gamma * eta2 * alpha_max
        elif Ti <= 6.0:
            alpha[i] = (eta2 * 0.2 ** gamma - eta1 * (Ti - 5.0 * Tg)) * alpha_max
        else:
            alpha[i] = 0.0

    return alpha


# ---- 1. 参数设置 ----
T = np.logspace(np.log10(0.01), np.log10(6.0), 400)

# 四个设防烈度（多遇地震）
cases = [
    {'name': '6 度 (0.04)',  'alpha_max': 0.04, 'color': '#0891b2'},
    {'name': '7 度 (0.08)',  'alpha_max': 0.08, 'color': '#2563eb'},
    {'name': '8 度 (0.16)',  'alpha_max': 0.16, 'color': '#b45309'},
    {'name': '9 度 (0.32)',  'alpha_max': 0.32, 'color': '#dc2626'},
]

Tg = 0.40    # II 类场地，第二组
zeta = 0.05  # 钢筋混凝土结构

# ---- 2. 绘图（A4 尺寸 7.2 × 5.4 in） ----
fig, ax = plt.subplots(figsize=(7.2, 5.4))

for case in cases:
    alpha = gb50011_spectrum(T, case['alpha_max'], Tg, zeta)
    ax.semilogx(T, alpha, lw=1.8, color=case['color'],
                label=f"{case['name']}")

# 标注特征周期 Tg
ax.axvline(Tg, color='#888888', lw=0.7, ls='--')
ax.text(Tg * 1.05, 0.01, f'Tg = {Tg:.2f} s',
        fontsize=9, color='#555555', rotation=90,
        va='bottom', ha='left')

# 标注平台段

ax.set_xlabel('Period  T (s)')

             fontsize=11)

ax.set_ylim(0, 0.36)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)

ax.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('design-spectrum.png', dpi=300, bbox_inches='tight')

print('阻尼调整系数：')

关键点：
  • 四个设防烈度：6 / 7 / 8 / 9 度（多遇地震）， αmax 分别为 0.04 / 0.08 / 0.16 / 0.32。
  • 特征周期：默认 Tg = 0.40 s（II 类场地、第二组）， 可改为其他场地条件。
  • 阻尼比：默认 ζ = 0.05，若用消能减震结构（ζ = 0.10） 或钢结构（ζ = 0.02），η2 会自动调整。
  • 对数横轴：周期范围 0.01–6 s，与规范一致。
  • 平台段阴影：axvspan(0.1, Tg) 用浅黄色标出平台段，直观看到平台宽度。
  • 曲线截断：T > 6 s 后 α = 0，规范不再考虑。

% ===== 局部函数 =====
function alpha = local_gb50011(T, alpha_max, Tg, zeta)
    eta2 = 1 + (0.05 - zeta) / (0.08 + 1.6 * zeta);
    gamma = 0.9 + (0.05 - zeta) / (0.3 + 6 * zeta);
    eta1 = 0.02 + (0.05 - zeta) / (4 + 32 * zeta);

    if T < 0.1
        alpha = (0.45 + 10 * (eta2 - 0.45) * T) * alpha_max;
    elseif T <= Tg
        alpha = eta2 * alpha_max;
    elseif T <= 5 * Tg
        alpha = (Tg / T) ^ gamma * eta2 * alpha_max;
    elseif T <= 6
        alpha = (eta2 * 0.2 ^ gamma - eta1 * (T - 5 * Tg)) * alpha_max;
    else
        alpha = 0;
    end
end

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 周期Ts
输入 · 特征周期Tgs
输入 · 阻尼比ζ无量纲
输入 · 地震影响系数最大值αmax无量纲
输出 · 地震影响系数α(T)无量纲
输出 · 阻尼调整系数η1, η2, γ无量纲
  • 公式来源：GB 50011-2010《建筑抗震设计规范》第 5.1.5 条。
  • αmax 取值：多遇地震查表 5.1.4-1， 罕遇地震按规范调整。本页默认多遇。
  • 特征周期 Tg：查表 5.1.4-2， 由场地类别与设计地震分组共同确定。
  • 阻尼比调整：ζ = 0.05 时 η2 = 1、γ = 0.9、η1 = 0.02， 曲线无调整。ζ ≠ 0.05 时按公式计算。
  • 周期截断：规范规定 T > 6 s 时不再使用本曲线， 需专门研究。
  • 与 UHS 的关系：规范设计谱是标准化 + 保守包络， UHS 是真实 PSHA 结果，两者物理意义不同但形状相似。
  • 常见问题：
    • 平台段高度与预期不符 → 检查 αmax 取值是否正确。
    • 下降段衰减太快或太慢 → 检查阻尼比 ζ 是否用了非常规值。
    • 曲线在某周期处突变 → 检查是否在 5Tg 处出现了分段衔接问题。
    • 消能减震结构 ζ = 0.20 → η2 ≈ 0.63，曲线整体降低约 37%。
