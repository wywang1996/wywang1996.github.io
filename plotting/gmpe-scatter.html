GMPE 四图

按 GMPE（地震动预测方程）研究中的标准做法，用四张子图分别展示 震级标度、距离衰减、 场地放大、残差诊断。 四张图合起来完整覆盖 GMPE 回归的核心诊断流程， 是《工程地震学》论文中反复出现的标准组合。

Data & Model

数据与模型

Python 与 MATLAB 代码默认读取 CSV 格式的真实数据（四列）。 页面下方的在线预览使用合成数据（不依赖外部文件）， 目的是演示四张子图的效果；CSV 数据可直接替换。

CSV 数据格式（推荐）

四列，带表头，逗号分隔。任意行数，行数越多拟合越稳定。

合成数据模型（页面预览用）

log10(PGA/g) = 0.3·M − 1.0·log10(R + 10) − 0.3·log10(Vs30 / 760) − 0.8
参数 取值
震级 M5.0 / 6.0 / 7.0 三组
距离 R5 – 200 km，对数均匀分布
Vs30150 – 1500 m/s，对数均匀分布

注意：合成模型的系数是教学用，不能用于实际工程。 真实 GMPE（如 Boore-Atkinson 2014、Campbell-Bozorgnia 2014） 包含几十个系数，场地项还区分线性与非线性部分。
Meaning

四张图的意义

GMPE 回归的核心是把对数 PGA 分解为震级项、距离项、场地项之和：

ln(PGA) = fM(M) + fR(M, R) + fS(VS30) + ε

四张图分别检验这三项的标度是否正确，以及残差是否随机。 这是 Boore-Atkinson、Campbell-Bozorgnia、Chiou-Youngs 等 主流 GMPE 论文中反复出现的标准组合。

(a) Magnitude scaling · 震级标度

固定 Vs30 = 760 m/s，画 PGA 随震级 M 的变化，四条曲线对应 R = 10 / 30 / 70 / 150 km。同一距离下，震级越大，PGA 越大， 曲线整体上移。数据散点按距离分档着色，与曲线对照。

诊断什么：震级项 fM(M) 是否捕捉了主要的 震级效应；不同震级之间的间距是否与曲线一致；近场是否出现饱和。

(b) Distance attenuation · 距离衰减

固定 Vs30 = 760 m/s，画 PGA 随距离 R 的变化，三条曲线对应 M = 5 / 6 / 7。对数横轴下，中远场曲线接近直线，近场逐渐变平。

诊断什么：距离项 fR(M, R) 的几何衰减 是否与观测一致；大震级曲线在近场是否出现了接近饱和的平坦段； 远场是否衰减过快或过慢。

(c) Site amplification · 场地放大

固定 R = 30 km，画 PGA 随 Vs30 的变化，三条曲线对应 M = 5 / 6 / 7。 理论关系为 PGA ∝ (Vs30/760)−0.3，双对数坐标下近似直线。

诊断什么：场地项 fS(Vs30) 的放大趋势 是否与数据一致；软土场地（Vs30 < 300 m/s）的放大是否被高估或低估； 是否存在非线性场地效应（软土处散点明显低于线性预测）。

(d) Residual diagnostics · 残差诊断

残差 = log10(PGA / PGAmedian)， 表示 GMPE 中位值未解释的部分。横轴为距离 R，纵轴为残差， 按震级着色。

诊断什么：理想情况下残差应围绕 0 随机分布， 且不随距离或震级出现系统趋势。如果出现 U 型、V 型或斜向趋势， 说明对应的项（距离项或震级项）标定不足。

回归分析的诊断闭环：
  1. 看 (a) 判断震级项是否合理；
  2. 看 (b) 判断距离项是否合理；
  3. 看 (c) 判断场地项是否合理；
  4. 看 (d) 判断三项合起来后残差是否无偏；
  5. 若 (d) 出现趋势，回到对应项重新标定。

Python

Python 代码

依赖 numpy 与 matplotlib。 从 gmpe_data.csv 读取四列数据，绘制 GMPE 标准四图。 CSV 文件不存在时自动生成合成数据。

gmpe-4panel.pyPython
# =============================================================
# 输入数据：CSV 文件（四列，带表头）
#   M,   R,   Vs30,  PGA
#   5.0, 12.3, 210,  0.108
#   5.2, 25.7, 540,  0.028
#   ...
#   单位：M 无量纲，R 单位 km，Vs30 单位 m/s，PGA 单位 g
# -------------------------------------------------------------
# 如果你的 PGA 单位是 m/s²，在读取后除以 9.80665 转 g；
# 如果是 gal（cm/s²），除以 980.665。
# =============================================================

import os
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.ticker import LogLocator

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 9,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

CSV_FILE = 'gmpe_data.csv'
VS30_REF = 760.0


# ---------- GMPE 中位值模型（含场地项） ----------
def gmpe_median(M, R, Vs30, Vs30_ref=VS30_REF):
    """简化 GMPE：
    log10(PGA_g) = 0.3·M − 1.0·log10(R+10)
                   − 0.3·log10(Vs30/Vs30_ref) − 0.8
    """
    f_mag  = 0.3 * M
    f_dist = -1.0 * np.log10(R + 10.0)
    f_site = -0.3 * np.log10(Vs30 / Vs30_ref)
    return 10 ** (f_mag + f_dist + f_site - 0.8)


# ---------- 生成合成数据（CSV 不存在时使用） ----------
def generate_synthetic(seed=42):
    rng = np.random.default_rng(seed)
    Ms = [5.0, 6.0, 7.0]
    M_all, R_all, Vs30_all, PGA_all = [], [], [], []
    for M in Ms:
        R    = 10 ** rng.uniform(np.log10(5),    np.log10(200),   60)
        Vs30 = 10 ** rng.uniform(np.log10(150),  np.log10(1500),  60)
        pga_med = gmpe_median(M, R, Vs30)
        pga = pga_med * 10 ** (0.25 * rng.standard_normal(60))
        M_all.append(np.full(60, M))
        R_all.append(R)
        Vs30_all.append(Vs30)
        PGA_all.append(pga)
    return (np.concatenate(M_all), np.concatenate(R_all),
            np.concatenate(Vs30_all), np.concatenate(PGA_all))


# ---------- 1. 读取数据 ----------
if os.path.exists(CSV_FILE):
    data = np.genfromtxt(CSV_FILE, delimiter=',', names=True,
                         dtype=None, encoding='utf-8')
    M    = np.asarray(data['M'],    dtype=float)
    R    = np.asarray(data['R'],    dtype=float)
    Vs30 = np.asarray(data['Vs30'], dtype=float)
    PGA  = np.asarray(data['PGA'],  dtype=float)
    # 若 PGA 单位不是 g，取消对应注释
    # PGA = PGA / 9.80665   # m/s² → g
    # PGA = PGA / 980.665   # gal  → g
    print(f'从 {CSV_FILE} 读取 {len(M)} 条记录')
else:
    print(f'{CSV_FILE} 不存在，使用合成数据演示')
    M, R, Vs30, PGA = generate_synthetic()


# ---------- 2. 计算残差 ----------
pga_med  = gmpe_median(M, R, Vs30)
residual = np.log10(PGA) - np.log10(pga_med)


# ---------- 3. 四张子图 ----------
fig, axes = plt.subplots(2, 2, figsize=(8.0, 8.0))

colors_M = {5.0: '#2563eb', 6.0: '#b45309', 7.0: '#15803d'}
R_bins   = [(0, 20, '<20',    '#0891b2'),
            (20, 50, '20–50', '#ca8a04'),
            (50, 100, '50–100', '#9333ea'),
            (100, 1e9, '>100', '#dc2626')]

# ===== (a) Magnitude scaling =====
ax = axes[0, 0]
M_range = np.linspace(4.5, 7.5, 100)
for R_val, color in zip([10, 30, 70, 150], ['#0891b2', '#ca8a04', '#9333ea', '#dc2626']):
    ax.plot(M_range, gmpe_median(M_range, R_val, VS30_REF),
            color=color, lw=1.5, label=f'R = {R_val} km')
for lo, hi, name, c in R_bins:
    mask = (R >= lo) & (R < hi)
    if mask.any():
        ax.scatter(M[mask], PGA[mask], s=14, color=c, alpha=0.6, edgecolors='none')
ax.set_yscale('log')
ax.set_xlabel('Magnitude M')
ax.set_ylabel('PGA (g)')
ax.set_title('(a) Magnitude scaling  ·  Vs30 = 760 m/s', fontsize=10)
ax.set_xlim(4.5, 7.5); ax.set_ylim(0.003, 3)
ax.legend(loc='lower right', fontsize=8, frameon=False)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)

# ===== (b) Distance attenuation =====
ax = axes[0, 1]
R_curve = np.logspace(np.log10(5), np.log10(200), 200)
for M_val in [5.0, 6.0, 7.0]:
    ax.plot(R_curve, gmpe_median(M_val, R_curve, VS30_REF),
            color=colors_M[M_val], lw=1.5, label=f'M = {M_val}')
for M_val in [5.0, 6.0, 7.0]:
    mask = np.round(M, 1) == M_val
    ax.scatter(R[mask], PGA[mask], s=14, color=colors_M[M_val],
               alpha=0.6, edgecolors='none')
ax.set_xscale('log'); ax.set_yscale('log')
ax.set_xlabel('Joyner-Boore distance R (km)')
ax.set_ylabel('PGA (g)')
ax.set_title('(b) Distance attenuation  ·  Vs30 = 760 m/s', fontsize=10)
ax.set_xlim(3, 250); ax.set_ylim(0.003, 3)
ax.legend(loc='lower left', fontsize=8, frameon=False)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)

# ===== (c) Site amplification =====
ax = axes[1, 0]
Vs30_curve = np.logspace(np.log10(150), np.log10(1500), 100)
for M_val in [5.0, 6.0, 7.0]:
    ax.plot(Vs30_curve, gmpe_median(M_val, 30.0, Vs30_curve),
            color=colors_M[M_val], lw=1.5, label=f'M = {M_val}')
# 散点：只显示 R 在 20–50 km 之间的样本
mask_near = (R > 20) & (R < 50)
for M_val in [5.0, 6.0, 7.0]:
    sub = mask_near & (np.round(M, 1) == M_val)
    ax.scatter(Vs30[sub], PGA[sub], s=14, color=colors_M[M_val],
               alpha=0.75, edgecolors='none')
ax.set_xscale('log'); ax.set_yscale('log')
ax.set_xlabel('Vs30 (m/s)')
ax.set_ylabel('PGA (g)')
ax.set_title('(c) Site amplification  ·  R = 30 km', fontsize=10)
ax.set_xlim(100, 2000); ax.set_ylim(0.01, 2)
ax.legend(loc='lower left', fontsize=8, frameon=False)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)

# ===== (d) Residual diagnostics =====
ax = axes[1, 1]
for M_val in [5.0, 6.0, 7.0]:
    mask = np.round(M, 1) == M_val
    ax.scatter(R[mask], residual[mask], s=14, color=colors_M[M_val],
               alpha=0.6, edgecolors='none', label=f'M = {M_val}')
ax.axhline(0, color='#888888', lw=0.7, ls='--')
ax.set_xscale('log')
ax.set_xlabel('Joyner-Boore distance R (km)')
ax.set_ylabel(r'Residual $\log_{10}(PGA/PGA_{median})$')
ax.set_title('(d) Residual diagnostics', fontsize=10)
ax.set_xlim(3, 250); ax.set_ylim(-0.8, 0.8)
ax.legend(loc='upper right', fontsize=8, frameon=False)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)

# ---------- 4. 统一格式 ----------
for a in axes.flat:
    a.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('gmpe-4panel.png', dpi=300, bbox_inches='tight')
plt.show()

print(f'共 {len(M)} 条记录')
print(f'残差均值 = {residual.mean():.4f}，标准差 = {residual.std():.4f}')

  • CSV 格式：四列（M, R, Vs30, PGA），带表头，逗号分隔。
  • 四张图的作用：
    • (a) 震级项诊断——PGA vs M，多距离曲线；
    • (b) 距离项诊断——PGA vs R，多震级曲线；
    • (c) 场地项诊断——PGA vs Vs30，多震级曲线；
    • (d) 残差诊断——残差 vs R，检查是否随机。
  • 为什么四张图都用同一套配色：M = 5 用蓝、M = 6 用橙、M = 7 用绿， 在 (a)(b)(c)(d) 之间形成视觉一致性，方便对照。
  • 子图 (a) 的距离配色：近场用青、中远场用黄/紫/红， 与子图 (b)(c)(d) 的震级配色区分开。
  • 常见问题：
    • 子图 (c) 散点太少 → 数据中 R 在 20–50 km 的样本不足，可放宽到 15–70 km。
    • 子图 (d) 出现 U 型或斜向趋势 → 距离项标定不足，需要重新拟合。
    • 子图 (d) 出现某一震级系统性偏差 → 震级项标定不足。
    • 中文表头乱码 → CSV 保存为 UTF-8 编码，或用英文列名。
