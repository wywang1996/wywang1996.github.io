Husid 曲线

对 assets/elcentro_EW.txt 的加速度记录，计算归一化累积平方 加速度曲线 H(t)，并标注 5% / 95% 能量点与有效持时 D5-95。 这是描述地震动"能量随时间累积"的核心图件，也是《强震动观测》笔记中 Arias 强度与有效持时计算的直接依据。

工程地震 能量累积 有效持时 Python / MATLAB A4 尺寸
Input Format

输入数据格式

本模板读取两列文本文件（空格、制表符或逗号分隔）， 与 El Centro、SAC ASCII 等地震记录格式一致。量纲必须明确， 否则 Arias 强度的绝对值会差若干量级（Husid 曲线本身因归一化而无量纲）。

输入文件要求

列号物理量 推荐单位说明
第 1 列时间 ts（秒）等间隔。程序用相邻两点之差推算采样步长 dt。
第 2 列地面加速度 agg（重力加速度）也可为 m/s² 或 gal（cm/s²）。

常用量纲的换算

你的数据单位 换算到 m/s² 代码里怎么写
g× 9.80665a = a * 9.80665
m/s²× 1a = a
gal（cm/s²）× 0.01a = a * 0.01
mm/s²× 0.001a = a * 0.001
本页示例 assets/elcentro_EW.txt 的第 2 列单位是 g。 代码不做去均值、不去线性趋势，直接对原始记录计算 Husid 曲线。

Meaning

这张图说明了什么

Husid 曲线（又称累积平方加速度曲线）描述地震动能量随时间累积的过程。 定义很简单：

H(t) = ∫0t a²(τ) dτ  /  ∫0T a²(τ) dτ

分母是整个记录的平方加速度积分，与 Arias 强度 IA = π/(2g) · ∫ a² dt 只差一个常数因子。因此 Husid 曲线 实际上就是"归一化的 Arias 强度累积曲线"，从 0 出发单调递增到 1。

曲线上的两个关键点定义了有效持时 D5-95：

  • t5%：H(t) 首次达到 5% 的时刻，代表地震动的实质性开始。
  • t95%：H(t) 首次达到 95% 的时刻，代表地震动的实质性结束。
  • D5-95 = t95% − t5%：5% 到 95% 能量累积区间的长度，是工程上最常用的有效持时定义。

从 Husid 曲线的形状还可以直接看出地震动的能量分布特征：

  • 陡升型曲线——能量在很短时段内释放，对应脉冲型地震动（近断层记录）。
  • 缓升型曲线——能量逐渐累积，对应长持时地震动（远场或盆地效应）。
  • 两段式曲线——中间有一段平缓区，说明 P 波段和 S 波段之间有明显的能量间隙。
与其他持时定义的关系： 工程上常用的持时定义有三类：
  • 括号持时——|a| 首次与末次超过某阈值（如 0.05 g）之间的时长；
  • 有效持时——基于 Husid 曲线的 5%–95% 区间（本页重点）；
  • 重要持时——例如 70% 能量区间，或 5%–75% 区间。
三者数值差别较大，使用时必须说明定义。
注意：本页不做去均值处理。原始记录的直流偏置会贡献额外的 a²， 使 Husid 曲线整体形状略受影响，尤其是 D5-95 的数值可能偏小。 工程应用中通常需要先做基线校正。

Python

Python 代码

依赖 numpy 与 matplotlib。核心步骤： 读取两列文本 → 单位换算 → 累积平方积分 → 归一化 → 找 5% / 95% 点 → 绘制 Husid 曲线并标注有效持时。 不做去均值、不去线性趋势。

husid-curve.pyPython
# =============================================================
# 输入数据格式（两列文本，空格 / 制表符 / 逗号分隔）
#   第 1 列：时间 t   —— 单位 s（秒），等间隔
#   第 2 列：加速度 a —— 单位 g（重力加速度）
# -------------------------------------------------------------
# 如果你的加速度列不是 g，请在下方 DATA_UNIT 处选择：
#   'g'     → 第 2 列单位 g   （× 9.80665 → m/s²）
#   'm/s2'  → 第 2 列单位 m/s²（× 1）
#   'gal'   → 第 2 列单位 cm/s²（× 0.01）
#   'mm/s2' → 第 2 列单位 mm/s²（× 0.001）
# -------------------------------------------------------------
# 说明：本脚本不做去均值、不去线性趋势。
# =============================================================
DATA_UNIT = 'g'

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

g = 9.80665

# ---- 1. 读取两列文本 ----
t, a_raw = np.loadtxt('elcentro_EW.txt', unpack=True)
dt = t[1] - t[0]
n = len(a_raw)

# ---- 2. 单位换算到 m/s²（不做去均值） ----
unit_factor = {'g': g, 'm/s2': 1.0, 'gal': 0.01, 'mm/s2': 0.001}
factor = unit_factor.get(DATA_UNIT, g)
a = a_raw * factor

# ---- 3. 累积平方加速度积分（梯形法） ----
#   I(t) = ∫₀ᵗ a²(τ) dτ，用累积梯形法，首点补 0
a2 = a ** 2
I = np.concatenate([[0], np.cumsum((a2[1:] + a2[:-1]) / 2) * dt])

# ---- 4. 归一化 → Husid 曲线 ----
H = I / I[-1]

# ---- 5. 找 5% 与 95% 能量点 ----
i5  = np.argmax(H >= 0.05)
i95 = np.argmax(H >= 0.95)
t5, t95 = t[i5], t[i95]
D595 = t95 - t5

# ---- 6. Arias 强度（与 Husid 曲线共用积分） ----
Ia = np.pi / (2 * g) * I[-1]   # m/s

# ---- 7. 绘图（A4 尺寸 7.2 × 3.8 in） ----
fig, ax = plt.subplots(figsize=(7.2, 3.8))

# 有效持时阴影区
ax.axvspan(t5, t95, color='#fde68a', alpha=0.45,
           label=f'D$_{{5-95}}$ = {D595:.2f} s')

# 5% / 95% 水平虚线
ax.axhline(0.05, color='#888888', lw=0.7, ls='--')
ax.axhline(0.95, color='#888888', lw=0.7, ls='--')

# t5 / t95 竖线
ax.axvline(t5,  color='#b45309', lw=0.9, ls=':')
ax.axvline(t95, color='#b45309', lw=0.9, ls=':')

# Husid 曲线
ax.plot(t, H, lw=1.4, color='#b45309', label='Husid curve')

# 5% / 95% 标注
ax.plot(t5,  0.05, 'o', color='#b45309', ms=5, zorder=5)
ax.plot(t95, 0.95, 'o', color='#b45309', ms=5, zorder=5)
ax.annotate(f't$_{{5\\%}}$ = {t5:.2f} s',  xy=(t5, 0.05),
            xytext=(t5 + 1.5, 0.18), fontsize=9, color='#222222',
            arrowprops=dict(arrowstyle='-', color='#888888', lw=0.6))
ax.annotate(f't$_{{95\\%}}$ = {t95:.2f} s', xy=(t95, 0.95),
            xytext=(t95 - 12, 0.78), fontsize=9, color='#222222',
            arrowprops=dict(arrowstyle='-', color='#888888', lw=0.6))

# 坐标轴
ax.set_xlabel('Time t (s)')
ax.set_ylabel('Normalized cumulative energy  H(t)')
ax.set_xlim(t[0], t[-1])
ax.set_ylim(-0.03, 1.03)
ax.grid(True, ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='lower right', fontsize=9, frameon=False)
ax.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('husid-curve.png', dpi=300, bbox_inches='tight')
plt.show()

# ---- 8. 打印参数 ----
print(f't_5%   = {t5:.3f} s')
print(f't_95%  = {t95:.3f} s')
print(f'D_5-95 = {D595:.3f} s')
print(f'Arias 强度 Ia = {Ia:.4f} m/s')
关键点：
  • 输入量纲：时间 s，加速度 g（默认）。改 DATA_UNIT 一个变量即可切换单位。
  • 累积积分：用 np.cumsum((a2[1:] + a2[:-1]) / 2) * dt 得到 I(t)，与梯形积分等价。
  • 归一化：H(t) = I(t) / I(T)，两端分别为 0 和 1。
  • 5% / 95% 点：np.argmax(H >= level) 找首次达到该水平的索引。
  • 不做去均值、不去线性趋势，直接使用原始记录计算。
MATLAB

MATLAB 代码

用 readmatrix 读取数据，cumsum 做累积平方积分。 不做去均值、去趋势。

husid-curve.mMATLAB
% =============================================================
% 输入数据格式（两列文本，空格 / 制表符 / 逗号分隔）
%   第 1 列：时间 t   —— 单位 s（秒），等间隔
%   第 2 列：加速度 a —— 单位 g（重力加速度）
% -------------------------------------------------------------
% 如果你的加速度列不是 g，请在下方 DATA_UNIT 处选择：
%   'g'     → 第 2 列单位 g      （× 9.80665 → m/s²）
%   'm/s2'  → 第 2 列单位 m/s²   （× 1）
%   'gal'   → 第 2 列单位 cm/s²  （× 0.01）
%   'mm/s2' → 第 2 列单位 mm/s²  （× 0.001）
% -------------------------------------------------------------
% 说明：本脚本不做去均值、不去线性趋势。
% =============================================================
DATA_UNIT = 'g';

g = 9.80665;

% ---- 1. 读取两列文本 ----
data = readmatrix('elcentro_EW.txt');
t    = data(:, 1);
a_raw = data(:, 2);
dt   = t(2) - t(1);

% ---- 2. 单位换算到 m/s² ----
switch DATA_UNIT
    case 'g',     factor = g;
    case 'm/s2',  factor = 1.0;
    case 'gal',   factor = 0.01;
    case 'mm/s2', factor = 0.001;
    otherwise,    factor = g;
end
a = a_raw * factor;

% ---- 3. 累积平方加速度积分（梯形法） ----
a2 = a .^ 2;
I  = [0; cumsum((a2(2:end) + a2(1:end-1)) / 2) * dt];

% ---- 4. 归一化 → Husid 曲线 ----
H = I / I(end);

% ---- 5. 找 5% 与 95% 能量点 ----
i5  = find(H >= 0.05, 1, 'first');
i95 = find(H >= 0.95, 1, 'first');
t5  = t(i5);
t95 = t(i95);
D595 = t95 - t5;

% ---- 6. Arias 强度 ----
Ia = pi / (2 * g) * I(end);

% ---- 7. 绘图（A4 尺寸 720 × 380 px） ----
figure('Color', 'w', 'Position', [100 100 720 380]);
hold on;

% 有效持时阴影区
patch([t5 t95 t95 t5], [-0.03 -0.03 1.03 1.03], ...
      [0.99 0.90 0.55], 'FaceAlpha', 0.45, 'EdgeColor', 'none');

% 5% / 95% 水平虚线
yline(0.05, '--', 'Color', [0.53 0.53 0.53], 'LineWidth', 0.7);
yline(0.95, '--', 'Color', [0.53 0.53 0.53], 'LineWidth', 0.7);

% t5 / t95 竖线
xline(t5,  ':', 'Color', [0.71 0.33 0.04], 'LineWidth', 0.9);
xline(t95, ':', 'Color', [0.71 0.33 0.04], 'LineWidth', 0.9);

% Husid 曲线
plot(t, H, 'Color', [0.71 0.33 0.04], 'LineWidth', 1.4);

% 5% / 95% 标记点
plot(t5,  0.05, 'o', 'MarkerFaceColor', [0.71 0.33 0.04], ...
     'MarkerEdgeColor', 'none', 'MarkerSize', 6);
plot(t95, 0.95, 'o', 'MarkerFaceColor', [0.71 0.33 0.04], ...
     'MarkerEdgeColor', 'none', 'MarkerSize', 6);

% 标注
text(t5 + 1.5, 0.18, sprintf('t_{5%%} = %.2f s', t5), 'FontSize', 9);
text(t95 - 13, 0.78, sprintf('t_{95%%} = %.2f s', t95), 'FontSize', 9);

xlabel('Time t (s)');
ylabel('Normalized cumulative energy  H(t)');
xlim([t(1) t(end)]);
ylim([-0.03 1.03]);
grid on; box on;
set(gca, 'FontName', 'Times New Roman', 'FontSize', 10, 'TickDir', 'in');

legend({'', '', '', '', '', '', ...
        sprintf('D_{5-95} = %.2f s', D595), 'Husid curve'}, ...
       'Location', 'southeast', 'Box', 'off', 'FontSize', 9);

exportgraphics(gcf, 'husid-curve.png', 'Resolution', 300);

% ---- 8. 打印参数 ----
fprintf('t_5%%   = %.3f s\n', t5);
fprintf('t_95%%  = %.3f s\n', t95);
fprintf('D_5-95 = %.3f s\n', D595);
fprintf('Arias 强度 Ia = %.4f m/s\n', Ia);
Notes

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 时间ts（秒）
输入 · 加速度agg / m/s² / gal / mm/s²
中间 · 加速度（SI）am/s²
输出 · Husid 曲线H(t)无量纲（0–1）
输出 · 5% 能量时刻t5%s
输出 · 95% 能量时刻t95%s
输出 · 有效持时D5-95s
输出 · Arias 强度IAm/s
  • 定义：H(t) = ∫₀ᵗ a²dτ / ∫₀ᵀ a²dτ，从 0 单调递增到 1。
  • 与 Arias 强度的关系：IA = π/(2g) · ∫₀ᵀ a²dτ，Husid 曲线是 Arias 强度归一化后的累积形式。
  • 有效持时：D5-95 = t95% − t5%，是工程中最常用的持时定义。
  • 积分方法：梯形法，对等间隔序列有 O(dt²) 精度。
  • 与括号持时的区别：括号持时基于 |a| 超过阈值的时间范围；有效持时基于能量，二者数值可能相差较大。
  • 无去均值：本模板不去均值，原始记录的直流偏置会贡献额外 a²， 使 Husid 曲线整体形状略受影响。工程应用中通常先做基线校正。
  • 常见问题：
    • D5-95 明显小于经验值 → 记录含高频噪声或直流偏置，需预处理。
    • 曲线末段斜率不为 0 → 记录被截断，应补充尾段数据。
    • Arias 强度偏小 10³ 量级 → 输入加速度单位选错了。
