加速度 / 速度 / 位移时程

把一条加速度记录通过两次梯形积分得到速度与位移，三个物理量按同一时间轴 纵向排列在一张图上。这是地震动处理中最基础的图件，也是反应谱、傅里叶谱、 Arias 强度等参数的起点。

工程地震 时程 梯形积分 Python / MATLAB A4 尺寸
Input Format

输入数据格式

本模板读取两列文本文件（空格、制表符或逗号分隔）， 与 El Centro、SAC ASCII 等地震记录格式一致。量纲必须明确。

输入文件要求

列号物理量 推荐单位说明
第 1 列时间 ts（秒）等间隔。程序用相邻两点之差推算采样步长 dt。
第 2 列地面加速度 agg（重力加速度）也可为 m/s² 或 gal（cm/s²）。

常用量纲的换算

你的数据单位 换算到 m/s² 代码里怎么写
g× 9.80665a = a * 9.80665
m/s²× 1a = a
gal（cm/s²）× 0.01a = a * 0.01
mm/s²× 0.001a = a * 0.001
本页示例 assets/elcentro_EW.txt 的第 2 列单位是 g。 代码不做去均值、不去线性趋势，直接对原始记录进行积分。

输入文件示例（前 5 行）

elcentro_EW.txtTXT

第 1 列：时间，单位 s；第 2 列：加速度，单位 g。采样率 50 Hz，记录长度约 54 s。

Meaning

这张图说明了什么

一条完整的地震动记录包含三个物理量：加速度 a(t)、 速度 v(t)、位移 d(t)。 它们通过一次和二次积分相互联系：

v(t) = ∫ a(τ) dτ   ,   d(t) = ∫ v(τ) dτ

三个物理量对结构的作用并不相同：

  • 加速度——高频成分，决定结构的惯性力，对应 PGA 与反应谱 Sa。
  • 速度——中频成分，与地震能量直接相关，PGV 是地震动能量水平的重要指标。
  • 位移——低频成分，决定大跨结构与长周期结构的位移需求。
重要提示：本页不做任何去趋势处理， 保留原始积分结果，因此速度与位移中可能出现明显的漂移。 工程实践中通常还需做基线校正，见《强震动观测》笔记。

Python

Python 代码

依赖 numpy 与 matplotlib。输入量纲见代码头部注释。

acc_vel_disp.pyPython
# =============================================================
# 输入数据格式（两列文本，空格 / 制表符 / 逗号分隔）
#   第 1 列：时间 t   —— 单位 s（秒），等间隔
#   第 2 列：加速度 a —— 单位 g（重力加速度）
# -------------------------------------------------------------
# 如果你的加速度列不是 g，请在下方 DATA_UNIT 处选择：
#   'g'     → 第 2 列单位 g   （× 9.80665 → m/s²）
#   'm/s2'  → 第 2 列单位 m/s²（× 1）
#   'gal'   → 第 2 列单位 cm/s²（× 0.01）
#   'mm/s2' → 第 2 列单位 mm/s²（× 0.001）
# -------------------------------------------------------------
# 说明：本脚本不做去均值、不去线性趋势，直接对原始记录积分。
#       速度、位移中可能保留原始记录的基线偏置。
# =============================================================
DATA_UNIT = 'g'

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
    'xtick.top': True,
    'ytick.right': True,
})

g = 9.80665

# ---- 1. 读取两列文本 ----
t, a_raw = np.loadtxt('elcentro_EW.txt', unpack=True)
dt = t[1] - t[0]

# ---- 2. 单位换算到 m/s² ----
unit_factor = {'g': g, 'm/s2': 1.0, 'gal': 0.01, 'mm/s2': 0.001}
factor = unit_factor.get(DATA_UNIT, g)
a = a_raw * factor

# ---- 3. 梯形积分 → 速度 (m/s)，不做去趋势 ----
v = np.concatenate([[0], np.cumsum((a[1:] + a[:-1]) / 2) * dt])

# ---- 4. 梯形积分 → 位移 (m)，不做去趋势 ----
d = np.concatenate([[0], np.cumsum((v[1:] + v[:-1]) / 2) * dt])

# ---- 5. 绘制三个子图（适合 A4 排版） ----
fig, axes = plt.subplots(3, 1, figsize=(7.2, 6.0), sharex=True)

axes[0].plot(t, a_raw, lw=0.9, color='#b45309')
axes[0].set_ylabel('Acc. (g)')

axes[1].plot(t, v * 100, lw=0.9, color='#2563eb')
axes[1].set_ylabel('Vel. (cm/s)')

axes[2].plot(t, d * 100, lw=0.9, color='#15803d')
axes[2].set_ylabel('Disp. (cm)')
axes[2].set_xlabel('Time (s)')

for ax in axes:
    ax.axhline(0, color='0.5', lw=0.5, ls='--')
    ax.grid(True, ls=':', lw=0.4, alpha=0.6)
    ax.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('acc-vel-disp.png', dpi=300, bbox_inches='tight')
plt.show()
关键点：
  • 输入量纲：时间 s，加速度 g（默认）。
  • 梯形积分用 np.cumsum((a[1:] + a[:-1]) / 2) * dt 实现，速度首点补 0。
  • 不做去均值、不去线性趋势，直接用原始记录积分。
  • 线宽 lw=0.9，配合 7.2 in 宽、6.0 in 高的画布，适合 A4 排版。
MATLAB

MATLAB 代码

用 readmatrix 读取数据，cumsum 做梯形积分。 不做去均值、去趋势。

acc_vel_disp.mMATLAB
% =============================================================
% 输入数据格式（两列文本，空格 / 制表符 / 逗号分隔）
%   第 1 列：时间 t   —— 单位 s（秒），等间隔
%   第 2 列：加速度 a —— 单位 g（重力加速度）
% -------------------------------------------------------------
% 如果你的加速度列不是 g，请在下方 DATA_UNIT 处选择：
%   'g'     → 第 2 列单位 g      （× 9.80665 → m/s²）
%   'm/s2'  → 第 2 列单位 m/s²   （× 1）
%   'gal'   → 第 2 列单位 cm/s²  （× 0.01）
%   'mm/s2' → 第 2 列单位 mm/s²  （× 0.001）
% -------------------------------------------------------------
% 说明：本脚本不做去均值、不去线性趋势，直接对原始记录积分。
% =============================================================
DATA_UNIT = 'g';

g = 9.80665;

% ---- 1. 读取两列文本 ----
data = readmatrix('elcentro_EW.txt');
t    = data(:, 1);
a_raw = data(:, 2);
dt   = t(2) - t(1);

% ---- 2. 单位换算到 m/s² ----
switch DATA_UNIT
    case 'g',     factor = g;
    case 'm/s2',  factor = 1.0;
    case 'gal',   factor = 0.01;
    case 'mm/s2', factor = 0.001;
    otherwise,    factor = g;
end
a = a_raw * factor;

% ---- 3. 梯形积分 → 速度 (m/s) ----
v = [0; cumsum((a(2:end) + a(1:end-1)) / 2) * dt];

% ---- 4. 梯形积分 → 位移 (m) ----
d = [0; cumsum((v(2:end) + v(1:end-1)) / 2) * dt];

% ---- 5. 绘制三个子图（适合 A4 排版） ----
figure('Color', 'w', 'Position', [100 100 720 600]);

subplot(3, 1, 1);
plot(t, a_raw, 'Color', [0.71 0.33 0.04], 'LineWidth', 0.9);
hold on;
yline(0, '--', 'Color', [0.5 0.5 0.5], 'LineWidth', 0.5);
ylabel('Acc. (g)');
grid on; box on;
set(gca, 'XTickLabel', [], 'FontName', 'Times New Roman', 'FontSize', 10, ...
    'TickDir', 'in');

subplot(3, 1, 2);
plot(t, v * 100, 'Color', [0.15 0.39 0.92], 'LineWidth', 0.9);
hold on;
yline(0, '--', 'Color', [0.5 0.5 0.5], 'LineWidth', 0.5);
ylabel('Vel. (cm/s)');
grid on; box on;
set(gca, 'XTickLabel', [], 'FontName', 'Times New Roman', 'FontSize', 10, ...
    'TickDir', 'in');

subplot(3, 1, 3);
plot(t, d * 100, 'Color', [0.08 0.50 0.24], 'LineWidth', 0.9);
hold on;
yline(0, '--', 'Color', [0.5 0.5 0.5], 'LineWidth', 0.5);
ylabel('Disp. (cm)');
xlabel('Time (s)');
grid on; box on;
set(gca, 'FontName', 'Times New Roman', 'FontSize', 10, 'TickDir', 'in');

exportgraphics(gcf, 'acc-vel-disp.png', 'Resolution', 300);
Notes

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 时间ts（秒）
输入 · 加速度agg / m/s² / gal / mm/s²
中间 · 加速度（SI）am/s²
输出 · 速度vm/s（绘图转 cm/s）
输出 · 位移dm（绘图转 cm）
  • 输入数据：两列文本，第一列时间（秒），第二列加速度（g）。
  • 无去趋势：本模板不做去均值、去线性趋势，直接使用原始记录积分。
  • 梯形积分：v[i] = v[i-1] + (a[i-1] + a[i]) / 2 · dt。
  • 常见问题：
    • 速度或位移整体偏小或偏大 10³ 量级 → 输入加速度单位选错了。
    • 位移明显偏离零线并持续增长 → 这是原始积分的正常现象。
