科学计算与 MATLAB

从矩阵运算到 Simulink 建模，覆盖 MATLAB 语言特性、数值计算、 信号处理与工程可视化。MATLAB 在结构动力学、信号处理、 控制系统与地震数据处理中有着广泛的应用， 与 Python 科学计算栈构成互补的工具链。

矩阵运算 Simulink 信号处理 工程仿真

§引言

MATLAB（MATrix LABoratory）起源于 1980 年代的数值线性代数教学工具， 如今已发展为工程与科研领域的标准计算环境。 它以矩阵为基本数据类型，配套了丰富的工具箱与可视化能力。

MATLAB 在工程中的定位：

场景MATLAB 的角色典型工具箱
数值算法原型 快速实现与验证 基础 MATLAB
信号处理 主力工具 Signal Processing Toolbox
控制系统 标准环境 Control System Toolbox
系统建模与仿真 图形化平台 Simulink
优化 求解器丰富 Optimization Toolbox
统计与机器学习 功能齐全 Statistics and Machine Learning Toolbox
图像处理 成熟工具箱 Image Processing Toolbox
并行计算 内置支持 Parallel Computing Toolbox

对地震工程师来说，MATLAB 的三大价值：

  • 矩阵计算零摩擦：语法天然支持矩阵运算，代码简洁。
  • 工具链完整：从数据处理、算法开发到 GUI 部署的完整支持。
  • Simulink：图形化建模环境，适合动态系统仿真与控制设计。

这份笔记按"语言 $\to$ 矩阵 $\to$ 函数 $\to$ 数值 $\to$ 可视化 $\to$ 工具箱 $\to$ Simulink $\to$ 对比 $\to$ 应用" 的顺序梳理，每一节都尽量落到工程语境上。

01语言特性

基本语法

MATLAB 的语法以矩阵为核心，几乎所有操作都是矩阵操作： 

% 注释
% 变量无需声明，动态类型
a = 3.14;
name = 'wayione';
flag = true;

% 分号抑制输出，逗号或无符号则输出
x = 10;   % 不输出
y = 20    % 输出到命令行

% 续行用三个点
total = 1 + 2 + 3 + 4 + ...
        5 + 6 + 7;

向量化优先

MATLAB 与 Python 一样，向量化优先于循环： 

% 慢：循环
n = 1e7;
a = rand(n, 1);
b = rand(n, 1);
c = zeros(n, 1);
tic;
for i = 1:n
    c(i) = a(i) + b(i);
end
toc

% 快：向量化
tic;
c = a + b;
toc

% 通常快 50~100 倍

常见陷阱

陷阱说明对策
循环中数组扩容 每次循环重新分配内存 预分配 zeros(n,1)
未预分配 性能急剧下降 循环前预估大小
全局变量 难以调试 用函数参数传递
字符串与 char 混用 比较行为不同 统一用 string 或 char
1-based 索引 与 Python 0-based 不同 注意换算
列优先存储 与 C 行优先不同 沿列遍历更快
💡

MATLAB 的哲学：一切皆为矩阵。 这种设计让 MATLAB 的语法极简—— 一个 A * B 可能是标量乘、矩阵乘或逐元素乘（需 .*）， 取决于操作数。 理解这一点，就理解了 MATLAB 的精髓。 同时它也是 MATLAB 与 Python/NumPy 最大的语义差异所在： NumPy 用 @ 显式区分矩阵乘与逐元素乘， MATLAB 用 * 与 .* 区分。

函数定义

function [pga, pgv] = compute_peaks(acc, dt)
% COMPUTE_PEAKS 计算峰值加速度与速度
%
% 输入：
%   acc - 加速度时程 (m/s^2)
%   dt  - 采样间隔 (s)
%
% 输出：
%   pga - 峰值加速度 (m/s^2)
%   pgv - 峰值速度 (m/s)

    pga = max(abs(acc));
    vel = cumsum(acc) * dt;
    pgv = max(abs(vel));
end

04数值计算

线性代数

% 线性方程组
A = rand(100);
b = rand(100, 1);
x = A \ b;           % 推荐
x2 = inv(A) * b;     % 不推荐（慢且不稳）

% LU 分解
[L, U, P] = lu(A);

% Cholesky 分解（对称正定）
S = A * A';
R = chol(S);         % R' * R = S

% QR 分解
[Q, R] = qr(A);

% 特征值分解
[V, D] = eig(A);

% 对称矩阵专用
S = A + A';
[V, D] = eig(S);     % 自动用对称算法

% 奇异值分解
[U, S, V] = svd(A);

% 广义特征值
B = rand(100);
[V, D] = eig(A, B);

稀疏矩阵

% 创建稀疏矩阵
n = 10000;
main = 2 * ones(n, 1);
off = -ones(n-1, 1);
K = spdiags([off, main, off], -1:1, n, n);

% 稀疏求解

u = K \ F;           % 自动用稀疏求解器

% 稀疏特征值（前 6 阶）

% dy/dt = [v; (-c*v - k*x)/m]

ylabel('位移 / m');

07Simulink 与建模

Simulink 概述

Simulink 是 MATLAB 的图形化建模与仿真环境， 用模块 + 连线描述动态系统，无需手写方程。

典型应用场景：

  • 结构动力学系统的时程仿真。
  • 隔震与消能装置的响应仿真。
  • 控制系统设计与验证。
  • 多物理场耦合系统。
  • 地震动输入与结构响应的仿真。
  • 硬件在环（HIL）测试。

基本模块

类别典型模块用途
信号源 Sine Wave、Step、From File 激励输入
数学运算 Gain、Sum、Product 构建方程
积分 Integrator、Derivative 求解 ODE
状态空间 State-Space 线性系统

单自由度体系的 Simulink 模型

对运动方程：

$$ m \ddot{u} + c \dot{u} + k u = -m \ddot{u}_g(t) $$

Simulink 模型结构：

  1. 地面加速度 $\ddot{u}_g(t)$ 作为输入信号。
  2. 求和器计算 $(-m \ddot{u}_g - c \dot{u} - k u) / m$ 得到 $\ddot{u}$。
  3. 积分器 1 得到 $\dot{u}$。
  4. 积分器 2 得到 $u$。
  5. 反馈回路用 Gain 模块乘以 $-c$、$-k$。
  6. Scope 观察响应时程。

MATLAB 与 Simulink 的交互

% 从 MATLAB 脚本运行 Simulink 模型

地震数据处理

process_wave.m MATLAB 
function [pga, pgv, pgd, ia, t_d] = process_wave(acc, dt)
% PROCESS_WAVE 处理单条强震记录
%
% 输入：
%   acc - 加速度时程 (m/s^2)
%   dt  - 采样间隔 (s)
%
% 输出：
%   pga - 峰值加速度
%   pgv - 峰值速度
%   pgd - 峰值位移
%   ia  - Arias 强度
%   t_d - 有效持时

    % 1. 去趋势
    acc = detrend(acc, 'linear');

    % 2. 带通滤波（0.1~25 Hz）
    fs = 1 / dt;
    [b, a] = butter(4, [0.1, 25]/(fs/2), 'bandpass');
    acc = filtfilt(b, a, acc);

    % 3. 积分
    vel = cumsum(acc) * dt;
    disp_ = cumsum(vel) * dt;

    % 4. 峰值
    pga = max(abs(acc));
    pgv = max(abs(vel));
    pgd = max(abs(disp_));

    % 5. Arias 强度
    g = 9.81;
    ia = pi / (2 * g) * sum(acc.^2) * dt;

    % 6. 有效持时（5%~95%）
    cum_ia = cumsum(acc.^2);
    total = cum_ia(end);
    t5 = find(cum_ia >= 0.05 * total, 1) * dt;
    t95 = find(cum_ia >= 0.95 * total, 1) * dt;
    t_d = t95 - t5;

    % 7. 绘图
    figure;
    t = (0:length(acc)-1)' * dt;
    tiledlayout(3, 1);

    nexttile; plot(t, acc); ylabel('a (m/s^2)'); grid on;
    nexttile; plot(t, vel); ylabel('v (m/s)'); grid on;
    nexttile; plot(t, disp_); ylabel('d (m)'); grid on;
    xlabel('t / s');
end

反应谱计算

response_spectrum.m MATLAB 
function [T, Sa] = response_spectrum(acc, dt, periods, zeta)
% RESPONSE_SPECTRUM 计算加速度反应谱
%
% 用 Newmark-β 平均加速度法

    if nargin < 4
        zeta = 0.05;
    end

    n_periods = length(periods);
    Sa = zeros(n_periods, 1);

    for i = 1:n_periods
        T = periods(i);
        if T <= 0.01
            Sa(i) = max(abs(acc));
            continue;
        end
        omega = 2 * pi / T;
        Sa(i) = sdof_max_acc(acc, dt, omega, zeta);
    end
end

function a_max = sdof_max_acc(acc, dt, omega, zeta)
% 单自由度体系的绝对加速度峰值（Newmark-β 法）

    n = length(acc);
    m = 1.0;
    c = 2 * m * omega * zeta;
    k = m * omega^2;

    gamma = 0.5;
    beta = 0.25;

    u = 0; v = 0;
    a = -acc(1) - 2*zeta*omega*v - omega^2*u;

    K_eff = k + gamma/(beta*dt)*c + 1/(beta*dt^2)*m;

    a_max = 0;
    for i = 1:n-1
        P_eff = -m*acc(i+1) + ...
                m * (1/(beta*dt^2)*u + 1/(beta*dt)*v + ...
                     (1/(2*beta)-1)*a) + ...
                c * (gamma/(beta*dt)*u + (gamma/beta-1)*v + ...
                     dt*(gamma/(2*beta)-1)*a);

        u_new = P_eff / K_eff;
        v = gamma/(beta*dt)*(u_new - u) - (gamma/beta-1)*v - ...
            dt*(gamma/(2*beta)-1)*a;
        a = 1/(beta*dt^2)*(u_new - u) - 1/(beta*dt)*v - ...
            (1/(2*beta)-1)*a;
        u = u_new;

        a_abs = abs(a + acc(i+1));
        if a_abs > a_max
            a_max = a_abs;
        end
    end
end

GMPE 拟合

fit_gmpe.m MATLAB 
% 拟合地震动预测方程：
% ln(PGA) = c0 + c1*M + c2*ln(R + 10) + c3*R + eps

rng(42);
n = 500;

% 生成"观测"数据
M = 4 + 3.5 * rand(n, 1);
R = 10 + 200 * rand(n, 1);
lnPGA = 1.5 + 0.8*M - 1.2*log(R + 10) - 0.002*R + 0.4*randn(n, 1);

% 构建设计矩阵
X = [ones(n, 1), M, log(R + 10), R];

% 最小二乘
coef = X \ lnPGA;

fprintf('拟合系数：\n');
fprintf('  c0 = %8.4f\n', coef(1));
fprintf('  c1 = %8.4f  (真值 0.8000)\n', coef(2));
fprintf('  c2 = %8.4f  (真值 -1.2000)\n', coef(3));
fprintf('  c3 = %8.4f  (真值 -0.0020)\n', coef(4));

% 残差标准差
residuals = lnPGA - X * coef;
sigma = std(residuals);
fprintf('\n残差标准差 sigma = %.4f\n', sigma);

% 决定系数
SS_res = sum(residuals.^2);
SS_tot = sum((lnPGA - mean(lnPGA)).^2);
R2 = 1 - SS_res / SS_tot;
fprintf('R² = %.4f\n', R2);

% 残差诊断图
figure('Position', [100, 100, 1000, 400]);
tiledlayout(1, 2);

nexttile;
scatter(X*coef, residuals, 15, 'filled');
xlabel('拟合值'); ylabel('残差');
title('残差 vs 拟合值'); grid on;

nexttile;
histogram(residuals, 30);
xlabel('残差'); ylabel('频次');
title('残差分布'); grid on;
