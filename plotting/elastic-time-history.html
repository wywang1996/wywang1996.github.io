弹性时程响应

用 Newmark-β 平均加速度法计算单自由度体系在 assets/elcentro_EW.txt 作用下的 相对位移 u(t)、相对速度 v(t) 与 绝对加速度 aabs(t) 时程， 并按三个不同自振周期（0.5 / 1.0 / 2.0 s）对比。 这是反应谱计算的时域基础，也是《结构动力学》与《振动力学》的核心内容。

地震工程 时程响应 Newmark-β Python / MATLAB A4 尺寸
Input Format

输入数据格式

本模板读取两列文本文件（空格、制表符或逗号分隔）， 与 El Centro、SAC ASCII 等地震记录格式一致。 结构参数不放在文件里，直接写在代码中，便于批量修改。

输入文件要求

列号物理量 推荐单位说明
第 1 列时间 ts（秒）等间隔。程序用相邻两点之差推算采样步长 dt。
第 2 列地面加速度 agg（重力加速度）也可为 m/s² 或 gal（cm/s²）。

常用量纲的换算

你的数据单位 换算到 m/s² 代码里怎么写
g× 9.80665ag = a * 9.80665
m/s²× 1ag = a
gal（cm/s²）× 0.01ag = a * 0.01
mm/s²× 0.001ag = a * 0.001

Meaning

这张图说明了什么

单自由度体系在地面运动作用下的运动方程为：

m·ü(t) + c·u̇(t) + k·u(t) = −m·üg(t)

其中 u 为质量块相对地面的位移，üg 为地面加速度。 方程两边除以 m，得到用 ωn 与 ζ 表达的等价形式：

ü(t) + 2ζωn·u̇(t) + ωn²·u(t) = −üg(t)

用 Newmark-β 平均加速度法（γ = 1/2，β = 1/4）逐步积分， 得到每一个时刻的 u、u̇、ü，进而得到三个物理量：

  • 相对位移 u(t)——质量块相对地面的位移， 反映结构的变形需求，是层间位移角的来源。
  • 相对速度 u̇(t)——与结构的阻尼耗能直接相关， 阻尼力 fD = c·u̇。
  • 绝对加速度 aabs(t) = üg + ü—— 反映结构的惯性力，fI = m·aabs， 是抗震设计中地震作用的直接依据。

不同自振周期的响应差异

同一地震动下，周期不同的结构响应差别很大：

  • 短周期结构（T = 0.5 s）——响应跟随地面运动， 位移幅值小，加速度幅值大，接近"刚体"行为；
  • 中周期结构（T = 1.0 s）——与地震动的主要频率成分接近， 可能出现放大；
  • 长周期结构（T = 2.0 s）——响应以低频为主， 位移幅值明显增大，加速度幅值反而减小，呈现"柔性"特征。
与时程曲线的关系： 把上面三个周期各自的 |u|max、|u̇|max、|aabs|max 对周期作图，就得到反应谱 Sa(T)、Sv(T)、Sd(T)。 本页是反应谱的时域基础，两者是同一件事的两种表达。
注意：本页不做去均值处理， 原始记录的直流偏置会通过两次积分在位移中造成明显漂移。 工程应用中通常先做基线校正。

Python

Python 代码

依赖 numpy 与 matplotlib。 核心函数 sdof_response 用 Newmark-β 平均加速度法返回完整时程。

elastic-time-history.pyPython
# =============================================================
# 单自由度体系弹性时程响应 | Newmark-β 平均加速度法
# -------------------------------------------------------------
# 输入数据格式（两列文本，空格 / 制表符 / 逗号分隔）
#   第 1 列：时间 t   —— 单位 s（秒），等间隔
#   第 2 列：加速度 a —— 单位 g（重力加速度）
# -------------------------------------------------------------
# 如果你的加速度列不是 g，请在下方 DATA_UNIT 处选择：
#   'g'     → 第 2 列单位 g   （× 9.80665 → m/s²）
#   'm/s2'  → 第 2 列单位 m/s²（× 1）
#   'gal'   → 第 2 列单位 cm/s²（× 0.01）
#   'mm/s2' → 第 2 列单位 mm/s²（× 0.001）
# -------------------------------------------------------------
# 说明：本脚本不做去均值、不去线性趋势，直接对原始记录积分。
#       位移与速度中可能保留原始记录的基线偏置。
# =============================================================
DATA_UNIT = 'g'

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

g = 9.80665

# ---- 1. 读取两列文本 ----
t, a_raw = np.loadtxt('elcentro_EW.txt', unpack=True)
dt = t[1] - t[0]
n = len(a_raw)

# ---- 2. 单位换算到 m/s² ----
unit_factor = {'g': g, 'm/s2': 1.0, 'gal': 0.01, 'mm/s2': 0.001}
factor = unit_factor.get(DATA_UNIT, g)
ag = a_raw * factor


def sdof_response(ag, dt, T, zeta=0.05):
    """Newmark-β 平均加速度法计算 SDOF 的完整时程。

    运动方程（单位质量）：
        u'' + 2ζω u' + ω²u = -ag(t)

    返回
    ----
    u     : 相对位移时程 (m)
    v     : 相对速度时程 (m/s)
    a_abs : 绝对加速度时程 (m/s²) = ag + u''
    """
    n = len(ag)
    if T <= 0:
        return np.zeros(n), np.zeros(n), ag.copy()

    omega = 2.0 * np.pi / T
    c = 2.0 * omega * zeta
    k = omega * omega
    gamma, beta = 0.5, 0.25

    keff = k + gamma / (beta * dt) * c + 1.0 / (beta * dt * dt)

    u = np.zeros(n)
    v = np.zeros(n)
    acc = np.zeros(n)
    acc[0] = -ag[0]          # 初始相对加速度（u(0)=0, v(0)=0）

    for j in range(1, n):
        p = (-ag[j]
             + (1.0 / (beta * dt * dt) * u[j - 1]
                + 1.0 / (beta * dt) * v[j - 1]
                + (1.0 / (2 * beta) - 1.0) * acc[j - 1])
             + c * (gamma / (beta * dt) * u[j - 1]
                    + (gamma / beta - 1.0) * v[j - 1]
                    + dt * (gamma / (2 * beta) - 1.0) * acc[j - 1]))

        u[j] = p / keff
        v[j] = (gamma / (beta * dt) * (u[j] - u[j - 1])
                - (gamma / beta - 1.0) * v[j - 1]
                - dt * (gamma / (2 * beta) - 1.0) * acc[j - 1])
        acc[j] = (1.0 / (beta * dt * dt) * (u[j] - u[j - 1])
                  - 1.0 / (beta * dt) * v[j - 1]
                  - (1.0 / (2 * beta) - 1.0) * acc[j - 1])

    return u, v, ag + acc


# ---- 3. 三个周期对比 ----
periods = [0.5, 1.0, 2.0]
zeta = 0.05
colors = ['#b45309', '#2563eb', '#15803d']

fig, axes = plt.subplots(3, 1, figsize=(7.2, 6.0), sharex=True)

for T, color in zip(periods, colors):
    u, v, a_abs = sdof_response(ag, dt, T, zeta)
    axes[0].plot(t, u * 100, lw=0.9, color=color, label=f'T = {T:.2f} s')
    axes[1].plot(t, v * 100, lw=0.9, color=color)
    axes[2].plot(t, a_abs / g, lw=0.9, color=color)

axes[0].set_ylabel('Disp. (cm)')
axes[1].set_ylabel('Vel. (cm/s)')
axes[2].set_ylabel('Abs. acc. (g)')
axes[2].set_xlabel('Time (s)')

axes[0].legend(loc='upper right', fontsize=8, frameon=False, ncol=3)

for ax in axes:
    ax.axhline(0, color='0.5', lw=0.5, ls='--')
    ax.grid(True, ls=':', lw=0.4, alpha=0.6)
    ax.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('elastic-time-history.png', dpi=300, bbox_inches='tight')
plt.show()

# ---- 4. 打印峰值 ----
print('峰值响应：')
for T in periods:
    u, v, a_abs = sdof_response(ag, dt, T, zeta)
    print(f'  T = {T:.2f} s : |u|max = {np.max(np.abs(u)) * 100:.3f} cm, '
          f'|v|max = {np.max(np.abs(v)) * 100:.2f} cm/s, '
          f'|a|max = {np.max(np.abs(a_abs)) / g:.4f} g')
关键点：
  • 输入量纲：时间 s，加速度 g（默认）。改 DATA_UNIT 一个变量即可切换单位。
  • Newmark-β 参数：γ = 1/2，β = 1/4，即平均加速度法，无条件稳定。
  • 初始条件：u(0) = 0，v(0) = 0，相对加速度 ü(0) = −ag(0)。
  • 绝对加速度：aabs = ag + ü，不能直接用相对加速度。
  • 不做去均值、不去线性趋势，直接使用原始记录积分。

% 单自由度体系弹性时程响应 | Newmark-β 平均加速度法
% -------------------------------------------------------------
% 输入数据格式（两列文本，空格 / 制表符 / 逗号分隔）
%   第 1 列：时间 t   —— 单位 s（秒），等间隔
%   第 2 列：加速度 a —— 单位 g（重力加速度）
% -------------------------------------------------------------
%   'g'     → × 9.80665
%   'm/s2'  → × 1
%   'gal'   → × 0.01
%   'mm/s2' → × 0.001
% -------------------------------------------------------------
% 说明：本脚本不做去均值、不去线性趋势，直接对原始记录积分。
% =============================================================

% ---- 1. 读取两列文本 ----

t     = data(:, 1);

dt    = t(2) - t(1);
n     = numel(a_raw);

% ---- 2. 单位换算到 m/s² ----
switch DATA_UNIT
    case 'g',     factor = g;
    case 'm/s2',  factor = 1.0;
    case 'gal',   factor = 0.01;
    case 'mm/s2', factor = 0.001;

% ---- 3. 三个周期对比 ----

% ===== 局部函数：Newmark-β 平均加速度法 =====
function [u, v, a_abs] = sdof_response(ag, dt, T, zeta)
    n = numel(ag);
    if T <= 0
        u = zeros(n, 1); v = zeros(n, 1); a_abs = ag;
        return;
    end

    omega = 2 * pi / T;
    c     = 2 * omega * zeta;
    k     = omega ^ 2;
    gam   = 0.5;    % γ
    bet   = 0.25;   % β

    keff = k + gam / (bet * dt) * c + 1 / (bet * dt ^ 2);

    u   = zeros(n, 1);
    v   = zeros(n, 1);
    acc = zeros(n, 1);
    acc(1) = -ag(1);

    for j = 2:n
        p = -ag(j) + ...
            (1/(bet*dt^2)*u(j-1) + 1/(bet*dt)*v(j-1) + (1/(2*bet)-1)*acc(j-1)) + ...
            c * (gam/(bet*dt)*u(j-1) + (gam/bet-1)*v(j-1) + ...
                 dt*(gam/(2*bet)-1)*acc(j-1));

        u(j) = p / keff;
        v(j) = gam/(bet*dt)*(u(j) - u(j-1)) - (gam/bet-1)*v(j-1) - ...
               dt*(gam/(2*bet)-1)*acc(j-1);
        acc(j) = 1/(bet*dt^2)*(u(j) - u(j-1)) - 1/(bet*dt)*v(j-1) - ...
                 (1/(2*bet)-1)*acc(j-1);
    end

    a_abs = ag + acc;
end
Notes

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 时间ts（秒）
输入 · 地面加速度agg / m/s² / gal / mm/s²
输入 · 自振周期Ts
输入 · 阻尼比ζ无量纲
输出 · 相对位移u(t)m（绘图转 cm）
输出 · 相对速度u̇(t)m/s（绘图转 cm/s）
输出 · 绝对加速度aabs(t)m/s²（绘图转 g）
  • 积分方法：Newmark-β 平均加速度法，γ = 1/2，β = 1/4，无条件稳定。
  • 运动方程：ü + 2ζωnu̇ + ωn²u = −ag（单位质量形式）。
  • 等效刚度：keff = k + γ/(β·dt)·c + 1/(β·dt²)。
  • 绝对加速度：aabs = ag + ü，惯性力 fI = m·aabs。
  • 初始条件：u(0) = 0，u̇(0) = 0，ü(0) = −ag(0)。
  • 与反应谱的关系：对多个周期分别做本页计算，取各时程的绝对值最大值， 即得反应谱 Sa(T)、Sv(T)、Sd(T)。
  • 多自由度扩展：对 MDOF 体系，先用特征值分析得到振型与周期， 再对每个振型做本页的单自由度计算，最后按 SRSS 或 CQC 组合。
  • 无去趋势：直接使用原始记录，位移中可能出现基线漂移。
  • 常见问题：
    • 位移异常大且单调漂移 → 原始记录含基线偏置，需先做基线校正。
    • 加速度时程在末尾不归零 → 记录的尾段被截断，或未做去趋势。
    • 周期很小时响应跟随地面运动 → 这是正常现象（准静态区）。
    • 周期很大时位移幅值明显放大 → 长周期结构的位移需求，属正常现象。
