数据结构

从数组链表到图与排序，覆盖栈、队列、树、哈希、堆与图算法。 数据结构是科学计算、有限元组装、地震数据处理与信号分析的基础工具， 决定了算法的效率与代码的可维护性。

算法分析 树与图 排序查找 科学计算

§引言

数据结构研究数据的组织、存储与操作方式。 它与算法一起构成计算机科学的核心—— 程序 = 数据结构 + 算法。

对工程计算来说，数据结构并非"纯计算机科学"话题， 而是决定计算效率的关键因素：

  • 有限元：稀疏矩阵的存储格式（CSR、CSC）决定内存占用与运算速度。
  • 地震数据处理：波形记录的存储、索引、检索需要合适的数据结构。
  • 信号处理：FFT、滤波、卷积的实现依赖数组与队列。
  • PSHA：大量震源与距离组合的空间索引依赖树与哈希。
  • 地震预警：实时数据流的处理依赖环形缓冲区与优先队列。
  • 地震目录：数十万条事件的检索、排序、空间查询需要高效的数据结构。

一个直观的例子：同样的矩阵-向量乘法， 用稠密数组存储是 $O(n^2)$，用 CSR 稀疏格式可以达到 $O(\text{nnz})$， 当 nnz（非零元素数）远小于 $n^2$ 时，效率提升数千倍。 这就是数据结构的价值。

这份笔记按"复杂度 $\to$ 线性 $\to$ 树 $\to$ 哈希 $\to$ 堆 $\to$ 图 $\to$ 排序 $\to$ 应用" 的顺序梳理，每一节都尽量落到工程语境上。

01算法分析

渐进复杂度

算法分析关心的是运算量随问题规模 $n$ 的增长趋势， 用大 $O$ 记号表示上界：

$$ O(f(n)) = \{ g(n) : \exists c > 0, n_0, \; \forall n > n_0, \; 0 \le g(n) \le c \cdot f(n) \} $$

常见复杂度从优到劣：

记号名称典型算法n=10⁶ 时的量级
$O(1)$ 常数 数组索引、哈希查找 1
$O(\log n)$ 对数 二分查找、平衡树 20
$O(n)$ 线性 遍历、线性查找 10⁶
$O(n \log n)$ 线性对数 归并排序、快速排序 2×10⁷
$O(n^2)$ 平方 冒泡排序、朴素矩阵乘 10¹²
$O(n^3)$ 立方 高斯消元 10¹⁸
$O(2^n)$ 指数 穷举、朴素 TSP 不可行

关键观察：当 $n = 10^6$ 时，$O(n^2)$ 需要约 $10^{12}$ 次运算， 在现代计算机上需数小时；而 $O(n \log n)$ 只需 $2 \times 10^7$ 次， 不到一秒。这就是算法设计的意义。

空间复杂度

空间复杂度衡量算法所需的额外内存。常见考虑：

  • 原地算法：额外空间 $O(1)$，如冒泡排序、快速排序（递归栈除外）。
  • 非原地算法：额外空间 $O(n)$，如归并排序、哈希表。
  • 稀疏存储：只存非零元素，把 $O(n^2)$ 降到 $O(\text{nnz})$。

均摊分析

有些操作的单次代价可能很高，但均摊到每次操作很低。 经典例子：动态数组的扩容。

每次数组满时，容量翻倍（2 倍策略）。 虽然扩容需要 $O(n)$ 复制， 但均摊到 $n$ 次插入上，每次只需 $O(1)$。

均摊分析也可以用势能法严格证明， 是分析哈希表、动态数组、并查集等结构的基础工具。

工程中的复杂度选择

复杂度不是唯一标准。实际选择时还要考虑：

  • 常数因子：$O(n)$ 的算法可能因常数因子大而慢于 $O(n \log n)$（在 $n$ 小时）。
  • 缓存友好性：数组比链表有更好的空间局部性，实际性能更优。
  • 并行性：有些算法天然易于并行。
  • 实现复杂度：简单的算法更易维护、更少 bug。
💡

工程计算的复杂度门槛： 在结构有限元、地震波模拟等领域， 问题规模常达到 $10^6$~$10^9$ 自由度。 此时： ① $O(n^2)$ 算法完全不可行； ② $O(n^{1.5})$ 算法勉强可行； ③ 稀疏矩阵 + 迭代法（$O(\text{nnz})$）是唯一选择。 这就是为什么有限元软件大量投资于稀疏存储与迭代求解器。

02线性结构

数组

数组是最基础的数据结构：连续内存 + 随机访问。

操作复杂度说明
随机访问 $O(1)$ 下标计算直接定位
尾部插入/删除 $O(1)$（均摊） 动态数组
中间插入/删除 $O(n)$ 需要移动元素
查找 $O(n)$ 线性扫描

数组的优势是缓存友好。 现代 CPU 一次访存读取 64 字节缓存行， 数组的连续访问几乎达到内存带宽上限。 科学计算中，优先用数组而非链表，就是为了利用这一点。

链表

链表由节点组成，每个节点存放数据与下一个节点的指针。

类型特点典型应用
单链表 每节点一个 next 指针 栈、队列
双链表 每节点 prev + next LRU 缓存
循环链表 尾节点指向头 轮询调度、约瑟夫环

链表在头部插入/删除是 $O(1)$， 但随机访问是 $O(n)$， 且缓存不友好。 实际工程中，链表通常只在需要频繁中间插入/删除时使用。

栈

栈是后进先出（LIFO）的结构。基本操作：

  • push(x)：压入栈顶。
  • pop()：弹出栈顶。
  • peek()：查看栈顶。

栈的典型应用：

  • 函数调用：调用栈记录返回地址与局部变量。
  • 表达式求值：中缀转后缀、后缀求值。
  • 括号匹配：编译器、解析器。
  • 深度优先搜索：DFS 用栈实现。
  • 撤销操作：编辑器的 undo/redo。

队列

队列是先进先出（FIFO）的结构。变体：

变体特点应用
普通队列 FIFO BFS、任务调度
双端队列（deque） 两端可入可出 滑动窗口、单调队列
优先队列 按优先级出队 Dijkstra、任务调度
环形缓冲区 固定容量，循环使用 实时数据流、DSP

环形缓冲区在地震预警、实时信号处理中特别重要： 它允许在固定内存下持续接收数据， 新数据覆盖旧数据，无需动态分配。

Python 示例：环形缓冲区

ring_buffer.py Python 
import numpy as np


class RingBuffer:
    """
    固定容量的环形缓冲区。
    适合实时数据流：写入速度快，永不动态分配。
    """
    def __init__(self, capacity):
        self.capacity = capacity
        self.buffer = np.zeros(capacity, dtype=float)
        self.head = 0      # 写指针
        self.size = 0      # 当前元素数

    def push(self, value):
        """写入一个值，覆盖最旧的值（若已满）"""
        self.buffer[self.head] = value
        self.head = (self.head + 1) % self.capacity
        if self.size < self.capacity:
            self.size += 1

    def get_all(self):
        """按时间顺序返回所有有效数据"""
        if self.size < self.capacity:
            return self.buffer[:self.size].copy()
        # 已满：从 head 开始环形读取
        idx = (np.arange(self.size) + self.head) % self.capacity
        return self.buffer[idx].copy()

    def get_latest(self, n=1):
        """返回最近 n 个值"""
        if n > self.size:
            n = self.size
        end = self.head
        start = (end - n) % self.capacity
        if start < end:
            return self.buffer[start:end].copy()
        else:
            return np.concatenate([
                self.buffer[start:],
                self.buffer[:end]
            ])


if __name__ == "__main__":
    rb = RingBuffer(capacity=10)

    # 模拟实时数据流
    for i in range(15):
        rb.push(float(i))
        if i < 3 or i >= 12:
            print(f"push({i}) → 缓冲区: {rb.get_all()}")

    print(f"\n最近 3 个值: {rb.get_latest(3)}")
    print(f"当前大小: {rb.size} / 容量 {rb.capacity}")

环形缓冲区在地震预警、DSP 实时处理、 网络数据包接收等场景中不可或缺。

03树结构

二叉树与遍历

二叉树每个节点最多有两个子节点。 三种深度优先遍历：

  • 前序（Preorder）：根 → 左 → 右。
  • 中序（Inorder）：左 → 根 → 右。
  • 后序（Postorder）：左 → 右 → 根。

还有广度优先遍历（层序遍历），用队列实现。

二叉搜索树（BST）

BST 满足：左子树所有节点 < 根 < 右子树所有节点。 平均情况下查找、插入、删除都是 $O(\log n)$。 但若按有序序列插入，会退化为链表，复杂度变成 $O(n)$。

平衡树

为解决 BST 退化问题，出现多种平衡树：

类型平衡条件查找/插入/删除典型应用
AVL 树 左右高度差 ≤ 1 $O(\log n)$ 查找密集场景
红黑树 颜色 + 路径约束 $O(\log n)$ STL map / set
B 树 多路平衡 $O(\log n)$ 数据库索引
B+ 树 叶子节点链式连接 $O(\log n)$ 文件系统、数据库
Trie 前缀树 按字符分支 $O(L)$（L 为串长） 字符串检索、IP 路由

B 树与数据库索引

B 树是专为磁盘存储设计的平衡树。 每个节点可以存多个键（通常几百个）， 高度只有 3~4 层就能存储上亿条记录。

为什么 B 树适合磁盘？ 磁盘的读写以块（通常 4 KB）为单位， 一次 I/O 读取整个节点远比多次小 I/O 高效。 B 树的节点大小与磁盘块对齐，因此每次访问只需一次 I/O。

空间索引：四叉树与 R 树

对地震目录、GIS 数据的空间查询 （如"查询某个矩形范围内的所有地震"）， 需要空间索引：

  • 四叉树：递归把平面分成四个象限。
  • R 树：用最小外接矩形组织空间对象，PostGIS、SQLite R*Tree 使用。
  • kd 树：k 维空间二分，适合最近邻查询。
  • H3 / S2：球面网格索引，适合全球尺度的空间分析。

USGS、IRIS 等地震数据中心用 R 树或类似结构索引数百万条地震事件， 让"矩形范围内的地震"查询在毫秒级完成。

Python 示例：BST 与 kd 树

tree_demo.py Python 
import numpy as np


class BSTNode:
    def __init__(self, key, value=None):
        self.key = key
        self.value = value
        self.left = None
        self.right = None


class BST:
    """二叉搜索树的插入、查找与中序遍历"""
    def __init__(self):
        self.root = None

    def insert(self, key, value=None):
        if self.root is None:
            self.root = BSTNode(key, value)
            return
        node = self.root
        while True:
            if key < node.key:
                if node.left is None:
                    node.left = BSTNode(key, value)
                    return
                node = node.left
            elif key > node.key:
                if node.right is None:
                    node.right = BSTNode(key, value)
                    return
                node = node.right
            else:
                node.value = value
                return

    def search(self, key):
        node = self.root
        while node is not None:
            if key == node.key:
                return node.value
            node = node.left if key < node.key else node.right
        return None

    def inorder(self):
        """中序遍历：输出有序序列"""
        result = []
        def _walk(n):
            if n is None:
                return
            _walk(n.left)
            result.append((n.key, n.value))
            _walk(n.right)
        _walk(self.root)
        return result


class KDTreeSimple:
    """
    简化的 2D kd 树：用于地震目录的空间索引。
    每个节点存储一个点 (x, y) 并按轴交替划分。
    """
    def __init__(self, points, depth=0):
        if not points:
            self.point = None
            self.left = None
            self.right = None
            return
        k = 2   # 2D
        axis = depth % k
        points = sorted(points, key=lambda p: p[axis])
        mid = len(points) // 2
        self.point = points[mid]
        self.axis = axis
        self.left = KDTreeSimple(points[:mid], depth + 1)
        self.right = KDTreeSimple(points[mid + 1:], depth + 1)

    def query_rect(self, xmin, xmax, ymin, ymax):
        """矩形范围查询"""
        result = []
        if self.point is None:
            return result
        x, y = self.point
        if xmin <= x <= xmax and ymin <= y <= ymax:
            result.append(self.point)
        # 简化：两棵子树都递归（实际应有剪枝）
        if self.left is not None:
            result.extend(self.left.query_rect(xmin, xmax, ymin, ymax))
        if self.right is not None:
            result.extend(self.right.query_rect(xmin, xmax, ymin, ymax))
        return result


if __name__ == "__main__":
    # ---- BST ----
    bst = BST()
    for k in [50, 30, 70, 20, 40, 60, 80]:
        bst.insert(k, f"event_{k}")

    print("BST 中序遍历（有序）:")
    print(bst.inorder())
    print(f"\n查找 key=40: {bst.search(40)}")
    print(f"查找 key=45: {bst.search(45)}")

    # ---- kd 树 ----
    rng = np.random.default_rng(42)
    n = 1000
    points = [(float(rng.uniform(0, 100)), float(rng.uniform(0, 100)))
              for _ in range(n)]
    kd = KDTreeSimple(points)

    # 查询矩形范围内的点
    result = kd.query_rect(20, 40, 30, 50)
    print(f"\nkd 树矩形查询 (20~40, 30~50)：找到 {len(result)} 个点")

运行后可以看到 BST 的中序遍历按 key 有序， kd 树能快速筛选出矩形范围内的点。 实际地震目录的 kd 树用 scipy.spatial.cKDTree， 性能远高于简化版。

04哈希表

基本原理

哈希表用哈希函数把键映射到数组下标， 实现平均 $O(1)$ 的插入、查找、删除。

$$ h: \text{Key} \to [0, m-1] $$

其中 $m$ 是哈希表大小。 理想情况下，每个键均匀分布到不同槽位，无冲突。

冲突处理

不同的键可能映射到同一槽位，称为哈希冲突。 两种主要处理方式：

方式原理优点缺点
链地址法 同一槽位挂链表 实现简单、删除方便 指针开销、缓存不友好
开放寻址 线性/二次探测下一个空槽 缓存友好、无指针 删除复杂、易聚集

Python 的 dict、Java 的 HashMap、 C++ 的 unordered_map 都用哈希表实现。

负载因子与再哈希

负载因子定义为：

$$ \alpha = \frac{n}{m} $$

其中 $n$ 是元素数，$m$ 是槽位数。 当 $\alpha$ 超过阈值（通常 0.7~0.75）， 需要再哈希：扩容并重新插入所有元素。

均摊分析证明：再哈希的总代价均摊到每次插入为 $O(1)$。

哈希函数的性质

好的哈希函数应满足：

  • 确定性：同一个键总是产生同一个哈希值。
  • 均匀性：键在槽位上均匀分布，减少冲突。
  • 快速计算：避免复杂的操作。
  • 雪崩效应：输入的微小变化产生输出的巨大变化。

常见哈希函数：

  • 乘法哈希：$h(k) = \lfloor m (kA \bmod 1) \rfloor$，$A \approx 0.618$（黄金比例）。
  • 除法哈希：$h(k) = k \bmod m$，$m$ 取质数。
  • MurmurHash：工程中广泛使用，雪崩效应好。
  • SHA-256：密码学哈希，用于安全场景。
  • xxHash：极快的非密码学哈希，适合大数据处理。

一致性哈希

分布式系统中，把键映射到多台服务器。 普通哈希在节点增减时需要重新分配所有键，代价巨大。

一致性哈希把哈希空间组织成环， 键与节点都映射到环上， 每个键由顺时针最近的节点处理。 节点增减只影响相邻区域的键， 最小化重分配。

地震数据中心、云存储、CDN 都使用一致性哈希。

Python 示例：简单哈希表

hash_table.py Python 
class HashTable:
    """
    用链地址法实现的哈希表。
    支持 put / get / delete。
    """
    def __init__(self, capacity=16):
        self.capacity = capacity
        self.size = 0
        self.buckets = [[] for _ in range(capacity)]

    def _hash(self, key):
        """简单乘法哈希"""
        return hash(key) % self.capacity

    def put(self, key, value):
        idx = self._hash(key)
        bucket = self.buckets[idx]
        for i, (k, v) in enumerate(bucket):
            if k == key:
                bucket[i] = (key, value)
                return
        bucket.append((key, value))
        self.size += 1

        # 负载因子超过 0.75 就扩容
        if self.size / self.capacity > 0.75:
            self._resize(self.capacity * 2)

    def get(self, key, default=None):
        idx = self._hash(key)
        for k, v in self.buckets[idx]:
            if k == key:
                return v
        return default

    def delete(self, key):
        idx = self._hash(key)
        bucket = self.buckets[idx]
        for i, (k, v) in enumerate(bucket):
            if k == key:
                bucket.pop(i)
                self.size -= 1
                return True
        return False

    def _resize(self, new_capacity):
        """再哈希"""
        old_buckets = self.buckets
        self.capacity = new_capacity
        self.buckets = [[] for _ in range(new_capacity)]
        self.size = 0
        for bucket in old_buckets:
            for k, v in bucket:
                self.put(k, v)

    def stats(self):
        """统计冲突分布"""
        lengths = [len(b) for b in self.buckets]
        return {
            "capacity": self.capacity,
            "size": self.size,
            "load_factor": self.size / self.capacity,
            "max_bucket": max(lengths) if lengths else 0,
            "avg_bucket": sum(lengths) / len(lengths) if lengths else 0,
        }


if __name__ == "__main__":
    ht = HashTable()

    # 插入一批台站记录
    stations = [f"ST{i:03d}" for i in range(200)]
    for i, st in enumerate(stations):
        ht.put(st, {"lat": 30 + i * 0.01, "lon": 100 + i * 0.01})

    print(f"插入 {len(stations)} 个台站")
    print(f"统计: {ht.stats()}")

    # 查找
    print(f"\n查找 ST042: {ht.get('ST042')}")
    print(f"查找 ST999: {ht.get('ST999')}")

    # 删除
    ht.delete("ST042")
    print(f"\n删除 ST042 后查找: {ht.get('ST042')}")

运行后可以看到：200 个台站分布在 512 个槽位中， 最大桶长度通常 1~2， 证明简单哈希在均匀分布下表现良好。

05堆与优先队列

堆的定义

二叉堆是完全二叉树，满足堆性质：

  • 最小堆：每个节点 ≤ 其子节点。
  • 最大堆：每个节点 ≥ 其子节点。

堆通常用数组表示： 下标 $i$ 的节点，左子节点 $2i+1$，右子节点 $2i+2$， 父节点 $\lfloor (i-1)/2 \rfloor$。

核心操作

操作复杂度说明
取最小值 $O(1)$ 根节点
插入 $O(\log n)$ 上浮
删除最小值 $O(\log n)$ 下沉
建堆 $O(n)$ 自底向上调整
堆排序 $O(n \log n)$ 反复取最小值

优先队列

优先队列是抽象数据类型，堆是其最常见实现。 应用：

  • Dijkstra 最短路径：每次取距离最小的节点。
  • A* 搜索：按 $f = g + h$ 优先级扩展节点。
  • 任务调度：按优先级执行任务。
  • 事件驱动模拟：按时间排序事件。
  • 霍夫曼编码：反复取频率最小的两个节点合并。
  • Top-K 问题：用大小为 K 的最小堆，$O(n \log K)$。

Top-K 与流式数据

一个常见问题：从 $n$ 个数据中找最大的 $K$ 个。 如果 $n$ 很大且数据是流式的， 用一个大小为 $K$ 的最小堆即可：

  1. 初始化最小堆，插入前 $K$ 个元素。
  2. 对每个新元素 $x$，若 $x >$ 堆顶，则弹出堆顶并插入 $x$。
  3. 遍历结束后，堆中即为最大的 $K$ 个元素。

时间复杂度 $O(n \log K)$， 空间复杂度 $O(K)$。 当地震目录有数十万条记录， 要找震级最大的前 100 条，这个算法几乎是瞬时的。

Python 示例：Top-K 与优先队列

heap_demo.py Python 
import heapq
import numpy as np


def top_k_largest(stream, k):
    """
    用大小为 k 的最小堆求流式数据的 Top-K 最大值。
    复杂度 O(n log k)，空间 O(k)。
    """
    heap = []
    for x in stream:
        if len(heap) < k:
            heapq.heappush(heap, x)
        elif x > heap[0]:
            heapq.heapreplace(heap, x)
    # 堆中是最大的 k 个，按从大到小返回
    return sorted(heap, reverse=True)


def dijkstra(graph, start):
    """
    Dijkstra 最短路径：用优先队列（最小堆）。
    graph: {node: [(neighbor, weight), ...]}
    """
    dist = {start: 0}
    pq = [(0, start)]         # (距离, 节点)
    visited = set()

    while pq:
        d, u = heapq.heappop(pq)
        if u in visited:
            continue
        visited.add(u)
        for v, w in graph.get(u, []):
            nd = d + w
            if v not in dist or nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist


if __name__ == "__main__":
    # ---- Top-K 示例：从地震目录中找最大震级 ----
    rng = np.random.default_rng(42)
    n_events = 100000
    magnitudes = rng.gumbel(loc=4.5, scale=0.5, size=n_events)

    top_10 = top_k_largest(magnitudes, k=10)
    print("震级最大的 10 次事件：")
    for i, m in enumerate(top_10, 1):
        print(f"  {i:>2}. M = {m:.3f}")

    print(f"\n直接排序验证: {sorted(magnitudes, reverse=True)[:10]}")

    # ---- Dijkstra 示例：台站网络最短路径 ----
    graph = {
        "A": [("B", 4), ("C", 2)],
        "B": [("C", 5), ("D", 10)],
        "C": [("E", 3)],
        "D": [("F", 11)],
        "E": [("D", 4)],
        "F": [],
    }
    dist = dijkstra(graph, "A")
    print(f"\n从 A 出发的最短距离: {dist}")

运行后可以看到：从 10 万条事件中提取 Top-10， 用堆只需 $O(n \log 10)$ 的运算量， 且内存只占 10 个元素，适合流式处理。

06图与图算法

图的表示

图 $G = (V, E)$ 由顶点集与边集组成。 两种主要表示：

表示空间查边遍历邻居适用
邻接矩阵 $O(V^2)$ $O(1)$ $O(V)$ 稠密图
邻接表 $O(V+E)$ $O(\deg)$ $O(\deg)$ 稀疏图
CSR $O(V+E)$ — $O(\deg)$ 科学计算、大规模图
边列表 $O(E)$ — — Kruskal 算法

CSR 格式：稀疏矩阵的核心

CSR（Compressed Sparse Row）用三个数组表示稀疏矩阵：

  • values：所有非零元素的值。
  • col_indices：每个非零元素所在的列。
  • row_ptr：每行第一个非零元素在 values 中的下标。

例如矩阵：

$$ \mathbf{A} = \begin{bmatrix} 1 & 0 & 2 & 0 \\ 0 & 3 & 0 & 4 \\ 5 & 0 & 6 & 0 \end{bmatrix} $$

CSR 表示为： 

values      = [1, 2, 3, 4, 5, 6]
col_indices = [0, 2, 1, 3, 0, 2]
row_ptr     = [0, 2, 4, 6]

对 $n \times n$ 的有限元刚度矩阵， 稠密存储需要 $n^2$ 个元素， CSR 只需 $O(\text{nnz})$。 当 $n = 10^6$、$\text{nnz} \approx 10^7$ 时， 内存占用从 8 TB 降到 80 MB。 这就是稀疏数据结构在科学计算中的价值。

图遍历

广度优先搜索（BFS）

从起点出发，先访问所有距离为 1 的节点， 再访问距离为 2 的，依此类推。 用队列实现，复杂度 $O(V + E)$。

应用：

  • 无权图的最短路径。
  • 连通分量识别。
  • 社交网络分析。
  • 地震台网的连通性分析。

深度优先搜索（DFS）

沿一条路径一直走到底，再回溯。 用栈或递归实现，复杂度 $O(V + E)$。

应用：

  • 拓扑排序。
  • 强连通分量（Tarjan 算法）。
  • 桥与割点识别。
  • 迷宫生成与求解。

最短路径

算法适用复杂度特点
BFS 无权图 $O(V+E)$ 最短边数
Dijkstra 非负权 $O((V+E)\log V)$ 贪心 + 优先队列
Bellman-Ford 可有负权 $O(VE)$ 可检测负环
Floyd-Warshall 全源最短路径 $O(V^3)$ 动态规划
A* 启发式 依赖启发函数 地图导航、路径规划

最小生成树

连通加权无向图的最小生成树（MST）是边权和最小的生成树。 两种经典算法：

  • Prim：从一个点开始，每次加入离树最近的节点。$O(E \log V)$。
  • Kruskal：按边权从小到大加边，用并查集判环。$O(E \log E)$。

MST 在台站网络规划、供水管网设计、电路布线中有应用。

地震学中的图

  • 台站网络：台站作为节点，通信链路作为边。
  • 断层网络：断层段作为节点，相互作用作为边。
  • 地震序列：事件作为节点，触发关系作为边，用于余震序列分析。
  • 地震目录聚类：用图聚类算法识别地震丛集。

Python 示例：BFS 与 Dijkstra

graph_demo.py Python 
from collections import deque
import heapq


def bfs_shortest_path(graph, start, goal=None):
    """
    BFS 求无权图最短路径。
    返回从 start 到所有节点的最短距离（边数）。
    """
    dist = {start: 0}
    parent = {start: None}
    queue = deque([start])

    while queue:
        u = queue.popleft()
        for v in graph.get(u, []):
            if v not in dist:
                dist[v] = dist[u] + 1
                parent[v] = u
                queue.append(v)

    if goal is not None and goal in parent:
        # 重建路径
        path = []
        cur = goal
        while cur is not None:
            path.append(cur)
            cur = parent[cur]
        return dist, path[::-1]
    return dist, parent


def dijkstra_full(graph, start):
    """
    Dijkstra 算法：非负权图的最短路径。
    返回 (距离字典, 父节点字典)。
    """
    dist = {start: 0}
    parent = {start: None}
    pq = [(0, start)]
    visited = set()

    while pq:
        d, u = heapq.heappop(pq)
        if u in visited:
            continue
        visited.add(u)
        for v, w in graph.get(u, []):
            nd = d + w
            if v not in dist or nd < dist[v]:
                dist[v] = nd
                parent[v] = u
                heapq.heappush(pq, (nd, v))
    return dist, parent


def reconstruct_path(parent, goal):
    """从父节点字典重建路径"""
    path = []
    cur = goal
    while cur is not None:
        path.append(cur)
        cur = parent[cur]
    return path[::-1]


if __name__ == "__main__":
    # ---- 无权图：BFS ----
    # 假想的地震台站通信网络
    g_unweighted = {
        "A": ["B", "C"],
        "B": ["A", "D", "E"],
        "C": ["A", "F"],
        "D": ["B"],
        "E": ["B", "F"],
        "F": ["C", "E", "G"],
        "G": ["F"],
    }

    dist, path = bfs_shortest_path(g_unweighted, "A", "G")
    print("BFS 台站网络：")
    print(f"  从 A 到 G 的最短路径: {path}")
    print(f"  距离（边数）: {dist['G']}")
    print(f"  各节点距离: {dist}")

    # ---- 带权图：Dijkstra ----
    # 边权代表通信延迟（ms）
    g_weighted = {
        "A": [("B", 4), ("C", 2)],
        "B": [("C", 5), ("D", 10)],
        "C": [("E", 3)],
        "D": [("F", 11)],
        "E": [("D", 4)],
        "F": [],
    }

    dist_w, parent_w = dijkstra_full(g_weighted, "A")
    path_w = reconstruct_path(parent_w, "F")
    print(f"\nDijkstra 台站网络（带延迟）：")
    print(f"  从 A 到 F 的最短路径: {path_w}")
    print(f"  总延迟: {dist_w['F']} ms")
    print(f"  各节点最短距离: {dist_w}")

运行后可以看到 BFS 给出边数最短路径， Dijkstra 给出加权最短路径。 台站网络规划、通信路径选择都用到这类算法。

07排序与查找

排序算法对比

算法平均最坏空间稳定特点
冒泡 $O(n^2)$ $O(n^2)$ $O(1)$ 是 教学用，实际不用
插入 $O(n^2)$ $O(n^2)$ $O(1)$ 是 小数组或近似有序时快
归并 $O(n \log n)$ $O(n \log n)$ $O(n)$ 是 稳定，适合外排序
快速 $O(n \log n)$ $O(n^2)$ $O(\log n)$ 否 实际最快
堆排序 $O(n \log n)$ $O(n \log n)$ $O(1)$ 否 原地、最坏也保证
计数排序 $O(n + k)$ $O(n + k)$ $O(k)$ 是 整数、范围小
基数排序 $O(d(n + k))$ $O(d(n + k))$ $O(n + k)$ 是 整数/字符串

"稳定"指相等元素的相对顺序在排序后保持不变。 对多关键字排序，稳定性很重要。

快速排序

快速排序是实践中最快的通用排序：

  1. 选一个基准元素（pivot）。
  2. 把数组分成小于基准和大于基准两部分。
  3. 递归排序两部分。

平均 $O(n \log n)$，常数因子小、缓存友好。 最坏情况（如已排序数组 + 首元素作 pivot）会退化到 $O(n^2)$， 用随机 pivot 或三数取中可避免。

二分查找

在有序数组上查找，每次排除一半，$O(\log n)$。

$$ \text{mid} = \text{lo} + \lfloor (\text{hi} - \text{lo}) / 2 \rfloor $$

注意用 lo + (hi - lo) / 2 而非 (lo + hi) / 2， 避免整数溢出。

外部排序

当数据大于内存时，需要外部排序：

  • 把数据分成若干块，每块在内存中排序后写回磁盘。
  • 用 k 路归并把所有块合并。
  • 或用败者树加速合并。

地震数据中心处理 TB 级连续波形记录时， 外部排序是必须的技术。

Python 示例：排序与二分查找

sort_search.py Python 
import numpy as np


def quicksort(arr):
    """原地快速排序（简化的递归实现）"""
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    mid = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + mid + quicksort(right)


def binary_search(arr, target):
    """
    在有序数组中二分查找。
    返回 target 的下标，未找到返回 -1。
    """
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1


def binary_search_lower_bound(arr, target):
    """
    二分查找：返回第一个 >= target 的元素下标。
    这是 bisect_left 的行为。
    """
    lo, hi = 0, len(arr)
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo


if __name__ == "__main__":
    # ---- 排序演示 ----
    rng = np.random.default_rng(42)
    data = rng.integers(0, 1000, size=20).tolist()
    print(f"原始数组: {data}")

    sorted_data = quicksort(data)
    print(f"快速排序后: {sorted_data}")

    # 用 NumPy 验证
    assert sorted_data == sorted(data), "排序错误！"
    print("✓ 排序结果与 Python 内置 sorted() 一致")

    # ---- 二分查找 ----
    target = sorted_data[7]
    idx = binary_search(sorted_data, target)
    print(f"\n二分查找 target={target}: 下标 {idx}")
    assert sorted_data[idx] == target

    # ---- 范围查询：用 lower_bound ----
    # 场景：查询震级在 [5.0, 5.5] 之间的事件
    mags = np.sort(rng.uniform(3.0, 8.0, 10000))
    lo = binary_search_lower_bound(mags, 5.0)
    hi = binary_search_lower_bound(mags, 5.5)
    print(f"\n震级在 [5.0, 5.5] 的事件数: {hi - lo}")
    print(f"  最小震级: {mags[lo]:.3f}")
    print(f"  最大震级: {mags[hi-1]:.3f}")

运行后可以看到：

  • 快速排序与 Python 内置排序结果一致。
  • 二分查找精确找到目标位置。
  • 用两次 lower_bound 可以在 $O(\log n)$ 内完成范围查询。

PSHA 中的空间索引

PSHA 需要把场地周围的震源都考虑进来。 当震源数量很大（数千个断层段 + 网格源）， 每次计算都要遍历所有震源，代价极高。

优化方案：

  • R 树：先筛选出距离场地一定范围内的震源。
  • kd 树：快速查询最近邻震源。
  • 网格哈希：把区域划分为网格，每个网格存储其内的震源。
  • 距离截断：忽略距离超过阈值（如 200 km）的震源，因为它们贡献可忽略。

这些优化能让 PSHA 的计算速度提升数十倍。
