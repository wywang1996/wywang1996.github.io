材料力学

从杆件的基本变形到复杂应力状态下的强度校核，梳理材料力学的完整体系。 材料力学是结构设计的基础——无论是钢筋混凝土梁、钢结构柱， 还是有限元分析中的本构关系，其内力、应力、变形的计算方法都在这里建立。

应力分析 强度理论 压杆稳定 结构设计

§引言

材料力学研究构件在外力作用下的强度、刚度与稳定性， 为结构设计提供定量依据。它的基本思路可以归纳为三步：

  • 外力分析：通过静力平衡求出支座反力和外力。
  • 内力分析：用截面法求构件内部各截面上的内力（轴力、剪力、弯矩、扭矩）。
  • 应力与变形分析：由内力分布求应力与应变，再按强度理论校核。

本笔记按照基本变形的类型展开：轴向拉压、剪切、扭转、弯曲， 再讨论复杂应力状态下的强度理论与压杆稳定。 这些内容也是结构力学与有限元方法的共同基础。

💡

四个基本假设：连续性、均匀性、各向同性、小变形。 材料力学的全部公式都建立在这四条之上，超出适用范围时会失效。

01轴向拉伸与压缩

轴力与应力

轴向受力构件横截面上的内力只有轴力 $N$， 正应力在横截面上均匀分布：

$$ \sigma = \frac{N}{A} $$

拉伸时 $\sigma > 0$，压缩时 $\sigma < 0$。 正负号约定对后续强度校核极为重要。

胡克定律与变形

线弹性范围内，正应力与正应变成正比：

$$ \sigma = E \varepsilon, \qquad \varepsilon = \frac{\Delta l}{l}, \qquad \Delta l = \frac{N l}{E A} $$

其中 $E$ 为弹性模量，$EA$ 称为抗拉（压）刚度。

泊松比

轴向拉伸时长度的增加伴随着横向收缩。横向应变与轴向应变之比的负值定义为 泊松比：

$$ \nu = -\frac{\varepsilon'}{\varepsilon} $$

典型材料的弹性常数：

材料弹性模量 E (GPa)泊松比 ν
低碳钢200 – 2100.24 – 0.30
合金钢200 – 2200.25 – 0.30
铝合金70 – 790.33
混凝土20 – 400.16 – 0.18
木材（顺纹）8 – 120.3 – 0.5

强度条件

为保证构件安全，最大工作应力不得超过材料的许用应力：

$$ \sigma_{\max} = \frac{N_{\max}}{A} \le [\sigma] $$

其中许用应力 $[\sigma] = \sigma_u / n$，$\sigma_u$ 为极限应力（屈服或抗拉强度）， $n$ 为安全系数。

02剪切与挤压

剪切应力

连接件（螺栓、铆钉、销轴）受剪切作用时，剪切面上的平均切应力为：

$$ \tau = \frac{Q}{A_s} $$

其中 $Q$ 为剪力，$A_s$ 为剪切面面积。剪切强度条件：

$$ \tau = \frac{Q}{A_s} \le [\tau] $$

挤压应力

连接件与被连接件接触面之间会传递挤压作用，挤压应力为：

$$ \sigma_{bs} = \frac{F}{A_{bs}} \le [\sigma_{bs}] $$

其中 $A_{bs}$ 为挤压计算面积（通常取投影面积 $d \cdot t$）。

剪切胡克定律

纯剪切状态下，切应力与切应变成正比：

$$ \tau = G \gamma $$

其中 $G$ 为切变模量。对各向同性材料， 三个弹性常数之间存在一个恒等式：

$$ G = \frac{E}{2(1 + \nu)} $$
⚠️

工程意义：剪切破坏是连接件的主要失效形式。 抗震设计中，支撑、节点板、螺栓群都要做抗剪承载力验算。 剪切破坏往往呈脆性，破坏前变形小，应给予足够的安全储备。

03圆轴扭转

切应力分布

圆轴扭转时，横截面上的切应力沿半径线性分布，圆心为零，边缘最大：

$$ \tau_\rho = \frac{T \rho}{I_p}, \qquad \tau_{\max} = \frac{T R}{I_p} = \frac{T}{W_p} $$

其中 $T$ 为扭矩，$I_p$ 为极惯性矩，$W_p = I_p / R$ 为抗扭截面系数。

截面几何量

截面极惯性矩 $I_p$抗扭截面系数 $W_p$
实心圆（直径 d） $\dfrac{\pi d^4}{32}$ $\dfrac{\pi d^3}{16}$
空心圆（外径 D，内径 d） $\dfrac{\pi (D^4 - d^4)}{32}$ $\dfrac{\pi (D^4 - d^4)}{16 D}$

扭转角

等截面圆轴在扭矩作用下的相对扭转角为：

$$ \varphi = \frac{T l}{G I_p} $$

$G I_p$ 称为抗扭刚度。

强度与刚度条件

$$ \tau_{\max} = \frac{T_{\max}}{W_p} \le [\tau], \qquad \theta = \frac{T}{G I_p} \cdot \frac{180}{\pi} \le [\theta] \; \text{(°/m)} $$

刚度条件在精密机械、传动轴设计中尤为重要。

04弯曲内力与应力

剪力与弯矩

梁在横向荷载作用下，横截面上产生剪力 $Q$ 与弯矩 $M$。 取隔离体并应用静力平衡：

$$ Q(x) = \sum F_y, \qquad M(x) = \sum M_{\text{截面}} $$

微分关系

荷载、剪力、弯矩三者之间存在微分关系：

$$ \frac{dQ}{dx} = q(x), \qquad \frac{dM}{dx} = Q(x), \qquad \frac{d^2 M}{dx^2} = q(x) $$

这三个关系是画剪力弯矩图的核心依据。

荷载形式剪力图形状弯矩图形状
无荷载（$q=0$）水平线斜直线
均布荷载（$q$ 常数）斜直线抛物线
集中力突变折角
集中力偶不变突变

正应力公式

纯弯曲时，横截面上的正应力沿高度线性分布，中性轴处为零：

$$ \sigma = \frac{M y}{I_z}, \qquad \sigma_{\max} = \frac{M_{\max}}{W_z} $$

其中 $I_z$ 为关于中性轴的惯性矩，$W_z = I_z / y_{\max}$ 为抗弯截面系数。

常用截面的几何量

截面惯性矩 $I_z$抗弯截面系数 $W_z$
矩形（宽 b，高 h） $\dfrac{b h^3}{12}$ $\dfrac{b h^2}{6}$
实心圆（直径 d） $\dfrac{\pi d^4}{64}$ $\dfrac{\pi d^3}{32}$
工字形（近似） $\sum I_i$ $I_z / (h / 2)$

切应力公式

横力弯曲时，横截面上还存在切应力，可用下式计算：

$$ \tau = \frac{Q S_z^*}{I_z b} $$

其中 $S_z^*$ 为所求点以外部分面积对中性轴的静矩，$b$ 为截面在该处的宽度。 矩形截面最大切应力出现在中性轴处，为平均切应力的 1.5 倍。

05弯曲变形

挠曲线近似微分方程

梁弯曲时，横截面形心的竖向位移称为挠度 $w(x)$。 在小变形条件下，挠曲线满足：

$$ \frac{d^2 w}{dx^2} = \frac{M(x)}{E I_z} $$

$EI_z$ 称为抗弯刚度。

积分法

对上式连续积分两次，可得到转角与挠度：

$$ \theta = \frac{dw}{dx} = \int \frac{M(x)}{E I_z} dx + C_1 $$ $$ w = \iint \frac{M(x)}{E I_z} dx \, dx + C_1 x + C_2 $$

积分常数由边界条件确定：固定端 $\theta = w = 0$，铰支端 $w = 0$。

叠加法

在线弹性、小变形条件下，多个荷载产生的挠度可以叠加。 常见梁在典型荷载下的挠度公式有表可查，是设计中最常用的工具。

刚度条件

$$ w_{\max} \le [w], \qquad \theta_{\max} \le [\theta] $$

例如楼板梁常用 $[w] = l / 250$ 或更严， 机械轴类则对转角有更严格的限制。

Python 数值求解

beam_deflection.py Python 
"""
简支梁均布荷载下的挠曲线
用差分法求解 EI * w'''' = q(x)
"""
import numpy as np
import matplotlib.pyplot as plt


def simply_supported_beam(L=6.0, q=10e3, EI=1.0e8, n=200):
    """
    简支梁，均布荷载 q（N/m）
    L  : 梁长 (m)
    EI : 抗弯刚度 (N·m²)
    n  : 网格数
    """
    x = np.linspace(0.0, L, n)
    dx = x[1] - x[0]

    # 组装刚度矩阵（欧拉-伯努利梁的差分格式）
    # w'''' = q / EI  →  (w_{i-2} - 4w_{i-1} + 6w_i - 4w_{i+1} + w_{i+2}) / dx^4 = q/EI
    A = np.zeros((n, n))
    b = np.full(n, q / EI) * dx**4

    for i in range(2, n - 2):
        A[i, i - 2] = 1.0
        A[i, i - 1] = -4.0
        A[i, i]     = 6.0
        A[i, i + 1] = -4.0
        A[i, i + 2] = 1.0

    # 简支边界：w(0) = w(L) = 0
    A[0, 0] = 1.0;  b[0] = 0.0
    A[n - 1, n - 1] = 1.0;  b[n - 1] = 0.0
    # 近似处理近端弯矩为零：用对称性 w_{-1} = w_{1}, w_{n} = w_{n-2}
    A[1, 1] = 5.0; A[1, 2] = -4.0; A[1, 3] = 1.0
    A[n - 2, n - 4] = 1.0; A[n - 2, n - 3] = -4.0; A[n - 2, n - 2] = 5.0

    w = np.linalg.solve(A, b)
    return x, w


if __name__ == "__main__":
    x, w = simply_supported_beam()

    # 理论解：w_max = 5 q L^4 / (384 EI)，出现在跨中
    L, q, EI = 6.0, 10e3, 1.0e8
    w_theory = 5 * q * L**4 / (384 * EI)
    print(f"数值最大挠度: {np.min(w):.6e} m")
    print(f"理论最大挠度: {-w_theory:.6e} m")

    plt.figure(figsize=(9, 3.5))
    plt.plot(x, w * 1000, color="#db2777")
    plt.xlabel("x / m")
    plt.ylabel("挠度 w / mm")
    plt.title("简支梁均布荷载挠曲线")
    plt.grid(True, alpha=0.3)
    plt.tight_layout()
    plt.show()
💡

从梁到板壳：欧拉-伯努利梁的挠曲线方程 $EI w'''' = q$ 是有限元梁单元的理论基础。 扩展到二维就是板理论，扩展到三维就是壳理论。 数值求解时，梁单元的刚度矩阵正是从这个方程离散化得到的。

06应力状态与强度理论

平面应力状态

一点的应力状态可以用三个分量表示：$\sigma_x$、$\sigma_y$、$\tau_{xy}$。 任意斜截面上的应力由应力圆（莫尔圆）给出：

$$ \sigma_\alpha = \frac{\sigma_x + \sigma_y}{2} + \frac{\sigma_x - \sigma_y}{2} \cos 2\alpha - \tau_{xy} \sin 2\alpha $$ $$ \tau_\alpha = \frac{\sigma_x - \sigma_y}{2} \sin 2\alpha + \tau_{xy} \cos 2\alpha $$

主应力

主平面上的切应力为零，主应力为：

$$ \sigma_{1,2} = \frac{\sigma_x + \sigma_y}{2} \pm \sqrt{ \left( \frac{\sigma_x - \sigma_y}{2} \right)^2 + \tau_{xy}^2 } $$

主平面方位角：

$$ \tan 2\alpha_0 = -\frac{2 \tau_{xy}}{\sigma_x - \sigma_y} $$

四种强度理论

理论失效判据等效应力适用材料
第一（最大拉应力） $\sigma_1 = \sigma_u$ $\sigma_1$ 脆性材料拉伸
第二（最大伸长线应变） $\varepsilon_1 = \varepsilon_u$ $\sigma_1 - \nu(\sigma_2 + \sigma_3)$ 脆性材料（少用）
第三（最大切应力） $\tau_{\max} = \tau_u$ $\sigma_1 - \sigma_3$ 塑性材料
第四（畸变能） $v_d = v_{du}$ $\sqrt{\dfrac{1}{2} \left[ (\sigma_1 - \sigma_2)^2 + (\sigma_2 - \sigma_3)^2 + (\sigma_3 - \sigma_1)^2 \right]}$ 塑性材料（更准）

组合变形

实际构件常同时承受多种基本变形。线弹性小变形条件下可以叠加：

  • 拉弯组合：$\sigma = \dfrac{N}{A} + \dfrac{M}{W}$
  • 弯扭组合：按第三或第四强度理论合成，例如 $\sigma_{eq3} = \sqrt{\sigma^2 + 4\tau^2}$
  • 偏心压缩：$\sigma = \dfrac{N}{A} \pm \dfrac{M_z}{W_z} \pm \dfrac{M_y}{W_y}$
⚠️

选择强度理论的原则：塑性材料（钢、铝合金）用第三或第四； 脆性材料（铸铁、混凝土）用第一或第二。 第三与第四的选择：第三偏保守，第四与试验更接近。 复杂应力状态下优先用第四。

07压杆稳定

欧拉临界力

细长压杆在压力达到某个临界值时，会从直线平衡突然变为弯曲平衡—— 这一现象称为失稳或屈曲。临界力由欧拉公式给出：

$$ P_{cr} = \frac{\pi^2 E I}{(\mu l)^2} $$

其中 $\mu l$ 为相当长度，$\mu$ 为长度系数，取决于杆端约束：

杆端约束长度系数 μ相当长度 μl
两端铰支1.0$l$
一端固定、一端自由2.0$2l$
一端固定、一端铰支0.7$0.7l$
两端固定0.5$0.5l$

临界应力与柔度

定义柔度（长细比）$\lambda = \mu l / i$，其中 $i = \sqrt{I / A}$ 为截面回转半径。欧拉公式可以写成临界应力的形式：

$$ \sigma_{cr} = \frac{\pi^2 E}{\lambda^2} $$

欧拉公式只在大柔度（细长杆）时成立。根据柔度分为三类：

  • 大柔度杆（$\lambda \ge \lambda_p$）：用欧拉公式。
  • 中柔度杆（$\lambda_s \le \lambda < \lambda_p$）：用经验公式（如直线公式 $\sigma_{cr} = a - b\lambda$）。
  • 小柔度杆（$\lambda < \lambda_s$）：不会失稳，按强度问题处理。

稳定条件

$$ \frac{P_{cr}}{P} \ge n_{st} $$

其中 $n_{st}$ 为稳定安全系数，通常取 1.8–3.0，具体取值依规范与工况而定。

💡

工程意义：压杆失稳是突然的、脆性的破坏形式， 在破坏前没有明显征兆。钢结构柱、网架杆件、桥梁压杆都必须进行稳定验算。 历史上多次重大结构事故都与失稳有关。

08小结

📌 核心要点

  • 轴向拉压：$\sigma = N / A$，变形 $\Delta l = Nl / EA$，核心是胡克定律。
  • 剪切：连接件的主要失效形式，$\tau = Q / A_s$，各向同性材料满足 $G = E / [2(1+\nu)]$。
  • 扭转：圆轴切应力沿半径线性分布，$\tau_{\max} = T / W_p$，扭转角 $\varphi = Tl / GI_p$。
  • 弯曲：正应力 $\sigma = My / I_z$，微分关系 $dM/dx = Q$、$dQ/dx = q$ 是画内力图的钥匙。
  • 弯曲变形：$EI w'''' = q$，积分法与叠加法是主要工具。
  • 强度理论：塑性材料用第三或第四，脆性材料用第一或第二。
  • 压杆稳定：欧拉公式 $P_{cr} = \pi^2 EI / (\mu l)^2$，只在大柔度时成立。
