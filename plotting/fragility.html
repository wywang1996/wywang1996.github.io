易损性曲线

结构易损性曲线（Seismic Fragility Curve）： 在不同地震动强度下，结构超越某一损伤状态 的条件概率曲线 P(DS ≥ ds | IM)。 通常有四条曲线分别对应轻微、中等、严重、完全 四个损伤状态。它是区域抗震风险评估、防灾决策、 保险定价与韧性城市分析的核心工具。

数据来源

  • IDA 分析——用 IDA 曲线与各损伤状态阈值比较， 统计每个 IM 水平下超越阈值的波数占比，即得超越概率。
  • 云图法——不调幅，用大量地震波随机 IM 做时程分析， 用回归或极大似然估计拟合易损性函数。
  • 专家判断——基于经验或历史震害数据， 直接给出损伤状态阈值的中位值与对数标准差（HAZUS 方法）。
  • 经验易损性——基于历史地震震害调查统计， 如日本、美国、意大利的震害数据库。
本页示例是一栋中层钢筋混凝土框架的易损性曲线： 四个损伤状态的中位值（50% 超越概率对应的 Sa）分别约为 0.26 / 0.46 / 0.74 / 1.30 g， 对数标准差分别约为 0.40 / 0.42 / 0.44 / 0.46。 替换为你自己的分析结果只需修改 fragility.csv。

计算步骤：从 IDA 曲线到易损性曲线

易损性曲线可以由 IDA 结果统计得到，也可以用对数正态分布拟合。 主流做法是先统计超越概率，再用极大似然估计拟合对数正态参数。

IDA 曲线 → 定义损伤状态阈值 LSi → 对每个 IM 水平统计 P(DS ≥ LSi | IM) = nexceed/ntotal → 用极大似然估计拟合对数正态分布 P(DS ≥ LSi | IM) = Φ[ ln(IM/θi) / βi ] → 得到中位值 θi 与对数标准差 βi → 绘制四条易损性曲线

四个损伤状态的阈值（GB / HAZUS 参考）

损伤状态 层间位移角阈值 典型描述
轻微（Slight）0.005非结构构件轻微损伤，结构完好
中等（Moderate）0.010部分构件轻微开裂，可修复
严重（Extensive）0.020构件明显破坏，修复困难
完全（Complete）0.040结构濒临倒塌，不可修复
阈值不是固定的——不同结构类型、不同规范、 不同性能目标对应不同阈值。这里给出的是钢筋混凝土框架的常用值。 钢结构、砌体结构、桥梁等需查阅相应规范或文献。

Python 代码：从 IDA 曲线统计易损性曲线

fragility.pyPython
# =============================================================
# 易损性曲线 | 从 IDA 结果统计
# -------------------------------------------------------------
# 输入：
#   ida_curves.csv     Sa_g, wave1, ..., waveN
# -------------------------------------------------------------
# 输出：
#   fragility.csv      Sa_g, DS1, DS2, DS3, DS4
#   fragility.png      易损性曲线
# =============================================================

import os
import numpy as np
from scipy.stats import norm
from scipy.optimize import minimize
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

IDA_FILE = 'ida_curves.csv'

# 损伤状态阈值（最大层间位移角）
THRESHOLDS = {
    'DS1 Slight':    0.005,
    'DS2 Moderate':  0.010,
    'DS3 Extensive': 0.020,
    'DS4 Complete':  0.040,
}

COLORS = {
    'DS1 Slight':    '#0891b2',
    'DS2 Moderate':  '#2563eb',
    'DS3 Extensive': '#b45309',
    'DS4 Complete':  '#dc2626',
}


# ---------- 1. 读取 IDA 曲线 ----------
if os.path.exists(IDA_FILE):
    data = np.genfromtxt(IDA_FILE, delimiter=',', names=True,
                         dtype=None, encoding='utf-8')
    Sa = np.asarray(data['Sa_g'], dtype=float)
    wave_cols = [n for n in data.dtype.names if n != 'Sa_g']
    DM = np.column_stack([np.asarray(data[n], dtype=float)
                          for n in wave_cols])
    print(f'从 {IDA_FILE} 读取 {len(Sa)} 个 IM、{DM.shape[1]} 条波')
else:
    raise FileNotFoundError(f'缺少文件：{IDA_FILE}')


# ---------- 2. 统计各损伤状态的超越概率 ----------
n_waves = DM.shape[1]
probs = {}

for name, threshold in THRESHOLDS.items():
    p = np.zeros(len(Sa))
    for i in range(len(Sa)):
        n_exceed = np.sum(DM[i, :] >= threshold)
        p[i] = n_exceed / n_waves
    probs[name] = p
    print(f'{name}（阈值 {threshold:.4f}）:')
    for i in range(len(Sa)):
        print(f'  Sa = {Sa[i]:.2f} g → P = {p[i]:.3f}')


# ---------- 3. 极大似然估计拟合对数正态分布 ----------
def neg_log_likelihood(params, Sa, p):
    """对数正态易损性的负对数似然。

    模型: P(IM) = Φ[ ln(IM/θ) / β ]
    用二项分布似然: L = Π p^k (1-p)^(n-k)
    """
    ln_theta, ln_beta = params
    theta = np.exp(ln_theta)
    beta = np.exp(ln_beta)
    if beta <= 0:
        return 1e10

    p_model = norm.cdf(np.log(Sa / theta) / beta)
    p_model = np.clip(p_model, 1e-10, 1 - 1e-10)

    # 假设每条波为一个样本（二项似然）
    n = 20  # 每个 IM 水平的波数估计
    log_L = np.sum(p * n * np.log(p_model) +
                   (1 - p) * n * np.log(1 - p_model))
    return -log_L


fits = {}
for name, p in probs.items():
    # 去掉 p = 0 或 1 的点（无法拟合）
    mask = (p > 0.02) & (p < 0.98)
    if mask.sum() < 3:
        mask = p > 0

    Sa_fit = Sa[mask]
    p_fit = p[mask]

    # 初值：用第一个超越点做中位值估计
    i50 = np.argmin(np.abs(p_fit - 0.5)) if len(p_fit) > 0 else 0
    theta0 = Sa_fit[i50] if len(Sa_fit) > 0 else 0.5

    res = minimize(neg_log_likelihood,
                   [np.log(theta0), np.log(0.4)],
                   args=(Sa_fit, p_fit),
                   method='Nelder-Mead')

    theta = np.exp(res.x[0])
    beta = np.exp(res.x[1])
    fits[name] = (theta, beta)
    print(f'{name}: θ = {theta:.4f} g, β = {beta:.4f}')


# ---------- 4. 输出 CSV ----------
header = 'Sa_g,' + ','.join([n.split()[0] for n in THRESHOLDS.keys()])
out = np.column_stack([Sa] + [probs[n] for n in THRESHOLDS.keys()])
np.savetxt('fragility.csv', out, delimiter=',',
           header=header, comments='', fmt='%.4f')
print('\n已保存 fragility.csv')


# ---------- 5. 绘图 ----------
fig, ax = plt.subplots(figsize=(7.2, 5.6))

# 光滑曲线
Sa_plot = np.logspace(np.log10(Sa.min() * 0.8),
                      np.log10(Sa.max() * 1.2), 200)

for name in THRESHOLDS.keys():
    theta, beta = fits[name]
    p_curve = norm.cdf(np.log(Sa_plot / theta) / beta)
    ax.plot(Sa_plot, p_curve, lw=1.8, color=COLORS[name],
            label=f'{name}  (θ={theta:.2f} g, β={beta:.2f})')

    # 数据点
    ax.plot(Sa, probs[name], 'o', color=COLORS[name],
            ms=5, mfc=COLORS[name], mec='none',
            alpha=0.7, zorder=5)

    # 中位值竖线
    ax.axvline(theta, color=COLORS[name], lw=0.6, ls=':', alpha=0.6)

# 0.5 水平线
ax.axhline(0.5, color='#888888', lw=0.6, ls='--')

# 坐标轴
ax.set_xscale('log')
ax.set_xlabel('Intensity measure  Sa(T$_1$)  (g)')
ax.set_ylabel('Exceedance probability  P(DS ≥ ds | IM)')
ax.set_title('Seismic fragility curves', fontsize=11)
ax.set_xlim(Sa.min() * 0.8, Sa.max() * 1.2)
ax.set_ylim(-0.02, 1.02)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='upper left', fontsize=9, frameon=False)
ax.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('fragility.png', dpi=300, bbox_inches='tight')
plt.show()
关键点：
  • 超越概率统计：对每个 IM 水平， 统计 DM ≥ 阈值的波数除以总波数。
  • 对数正态模型：P(IM) = Φ[ln(IM/θ)/β]， 其中 θ 是中位值，β 是对数标准差。
  • 极大似然估计：用二项分布似然拟合， 比最小二乘更稳健，特别是概率接近 0 或 1 时。
  • 光滑曲线：用拟合得到的 θ 与 β， 在对数 IM 网格上绘制光滑曲线。
  • 中位值竖线：θ 即曲线与 P = 0.5 的交点， 是易损性曲线的关键特征。
Meaning

这张图说明了什么

易损性曲线描述结构在不同地震动强度下发生损坏的概率。 它是结构抗震性能的统计描述，与 IDA 曲线的关系是： IDA 是确定性的（一条波一条曲线）， 易损性是统计性的（所有波的综合）。

对数正态模型

易损性曲线通常用对数正态累积分布函数描述：

P(DS ≥ ds | IM) = Φ [ ln(IM/θ) / β ]

其中：

  • Φ——标准正态累积分布函数；
  • θ——中位值（IM 的 50% 超越水平）， 反映结构的平均抵抗能力；
  • β——对数标准差， 反映能力的不确定性。β 越大，曲线越"平缓"。

四个损伤状态的解读

  • DS1 轻微——最早超越的曲线， 在较低 IM 下就开始上升。对应非结构构件损伤。
  • DS2 中等——结构构件开始出现明显损伤， 可修复但成本较高。
  • DS3 严重——结构损伤严重， 修复困难，可能需加固。
  • DS4 完全——结构濒临或达到倒塌， 不可修复。

四条曲线的中位值 θ1 < θ2 < θ3 < θ4，间距反映不同损伤状态 之间的安全裕度。

从易损性曲线能读出什么

  • 中位值——曲线与 P = 0.5 的交点， 是该损伤状态的特征强度。
  • 曲线斜率——β 越小，曲线越陡， 说明能力不确定性越小。
  • 曲线位置——曲线越靠右， 结构抵抗该损伤状态的能力越强。
  • 曲线间距——反映不同损伤状态 之间的渐进性，间距均匀说明损伤渐进， 间距突变说明存在薄弱环节。
  • 设计地震动水平下的超越概率—— 在设防地震动 Sa 处垂直向上读，即得该损伤状态的超越概率。
区域风险评估中的应用： 易损性曲线是区域地震风险评估的核心工具。 把区域内每栋建筑的易损性曲线与该场地的地震危险性曲线 卷积，得到每栋建筑的损伤概率，再乘以损失比与建筑价值， 得到期望经济损失。 这是灾害保险定价、韧性城市分析的基础。
注意：易损性曲线是统计描述， 不代表单栋具体建筑在给定地震下的结果。 它给出的是"在相同条件下的建筑物"中预期有多少比例 会达到某损伤状态。不能用来预测单栋建筑的损伤， 只能用于群体评估。

Python

Python 代码

依赖 numpy、scipy 与 matplotlib。 核心步骤：读取 CSV → 拟合对数正态参数（极大似然）→ 绘制四条曲线。 CSV 文件不存在时自动生成合成数据。

fragility.pyPython
# =============================================================
# 易损性曲线 | 对数正态拟合
# -------------------------------------------------------------
# 输入数据：fragility.csv
#   Sa_g,DS1,DS2,DS3,DS4
#   0.05,0.02,0.00,0.00,0.00
#   ...
#   单位：Sa_g (g)，概率 0–1
# -------------------------------------------------------------
# 功能：
#   1. 读取 CSV（自动识别损伤状态列数）
#   2. 用极大似然估计拟合对数正态参数 (θ, β)
#   3. 绘制四条光滑易损性曲线
# =============================================================

import os
import numpy as np
from scipy.stats import norm
from scipy.optimize import minimize
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

CSV_FILE = 'fragility.csv'

COLORS = ['#0891b2', '#2563eb', '#b45309', '#dc2626']
LABELS = ['DS1 Slight', 'DS2 Moderate', 'DS3 Extensive', 'DS4 Complete']


def generate_synthetic():
    """CSV 缺失时生成合成易损性数据。"""
    Sa = np.array([0.05, 0.10, 0.15, 0.20, 0.30, 0.40,
                   0.50, 0.70, 0.90, 1.20, 1.50])
    # 四个损伤状态的超越概率（平滑单调）
    probs = {
        'DS1': np.array([0.02, 0.08, 0.18, 0.32, 0.55,
                         0.73, 0.85, 0.95, 0.98, 1.00, 1.00]),
        'DS2': np.array([0.00, 0.01, 0.04, 0.09, 0.22,
                         0.38, 0.54, 0.76, 0.87, 0.95, 0.99]),
        'DS3': np.array([0.00, 0.00, 0.00, 0.01, 0.05,
                         0.12, 0.22, 0.42, 0.58, 0.75, 0.86]),
        'DS4': np.array([0.00, 0.00, 0.00, 0.00, 0.01,
                         0.02, 0.05, 0.13, 0.24, 0.40, 0.55]),
    }
    return Sa, probs


# ---- 1. 读取数据 ----
if os.path.exists(CSV_FILE):
    data = np.genfromtxt(CSV_FILE, delimiter=',', names=True,
                         dtype=None, encoding='utf-8')
    Sa = np.asarray(data['Sa_g'], dtype=float)
    ds_names = [n for n in data.dtype.names if n != 'Sa_g']
    probs = {n: np.asarray(data[n], dtype=float) for n in ds_names}
    print(f'从 {CSV_FILE} 读取 {len(Sa)} 个 IM、{len(ds_names)} 个损伤状态')
else:
    print(f'{CSV_FILE} 不存在，使用合成数据演示')
    Sa, probs = generate_synthetic()
    ds_names = list(probs.keys())


# ---- 2. 极大似然估计拟合对数正态 ----
def neg_log_likelihood(params, Sa, p, n=20):
    """对数正态易损性的负对数似然。"""
    ln_theta, ln_beta = params
    theta = np.exp(ln_theta)
    beta = np.exp(ln_beta)
    if beta <= 0:
        return 1e10
    p_model = norm.cdf(np.log(Sa / theta) / beta)
    p_model = np.clip(p_model, 1e-10, 1 - 1e-10)
    log_L = np.sum(p * n * np.log(p_model) +
                   (1 - p) * n * np.log(1 - p_model))
    return -log_L


fits = {}
for name in ds_names:
    p = probs[name]
    # 去掉 p = 0 或 1 的极端点
    mask = (p > 0.01) & (p < 0.99)
    if mask.sum() < 3:
        mask = p > 0

    Sa_fit = Sa[mask]
    p_fit = p[mask]

    # 初值
    i50 = np.argmin(np.abs(p_fit - 0.5)) if len(p_fit) > 0 else 0
    theta0 = Sa_fit[i50] if len(Sa_fit) > 0 else 0.5

    res = minimize(neg_log_likelihood,
                   [np.log(theta0), np.log(0.4)],
                   args=(Sa_fit, p_fit),
                   method='Nelder-Mead')

    theta = np.exp(res.x[0])
    beta = np.exp(res.x[1])
    fits[name] = (theta, beta)
    print(f'{name}: θ = {theta:.4f} g, β = {beta:.4f}')


# ---- 3. 绘图（A4 尺寸 7.2 × 5.6 in） ----
fig, ax = plt.subplots(figsize=(7.2, 5.6))

# 光滑曲线
Sa_plot = np.logspace(np.log10(Sa.min() * 0.8),
                      np.log10(Sa.max() * 1.2), 200)

for i, name in enumerate(ds_names):
    theta, beta = fits[name]
    p_curve = norm.cdf(np.log(Sa_plot / theta) / beta)
    label = LABELS[i] if i < len(LABELS) else name
    ax.plot(Sa_plot, p_curve, lw=1.8, color=COLORS[i % len(COLORS)],
            label=f'{label}  (θ={theta:.2f} g, β={beta:.2f})')

    # 数据点
    ax.plot(Sa, probs[name], 'o', color=COLORS[i % len(COLORS)],
            ms=5, mfc=COLORS[i % len(COLORS)], mec='none',
            alpha=0.7, zorder=5)

    # 中位值竖线
    ax.axvline(theta, color=COLORS[i % len(COLORS)],
               lw=0.6, ls=':', alpha=0.6)

# 0.5 水平线
ax.axhline(0.5, color='#888888', lw=0.6, ls='--')

# 坐标轴
ax.set_xscale('log')
ax.set_xlabel('Intensity measure  Sa(T$_1$)  (g)')

关键点：
  • 自动识别列数：data.dtype.names 读取所有损伤状态列。
  • 对数正态 CDF：norm.cdf(np.log(Sa/theta)/beta)。
  • 极大似然估计：用 scipy.optimize.minimize， 参数用对数值 ln θ、ln β 保证正值。
  • 极端点处理：概率接近 0 或 1 的点会被剔除， 避免似然函数出现 log(0)。
  • 中位值竖线：axvline(theta) 标出曲线与 P = 0.5 的交点。
  • 数据点叠加：光滑曲线之外叠加原始数据点， 直观对照拟合质量。

% ===== 局部函数：负对数似然 =====
function nll = local_nll(x, Sa, p)
    theta = exp(x(1));
    beta  = exp(x(2));
    if beta <= 0
        nll = 1e10;
        return;
    end
    p_model = normcdf(log(Sa / theta) / beta);
    p_model = min(max(p_model, 1e-10), 1 - 1e-10);
    n = 20;   % 每个 IM 水平的波数
    log_L = sum(p * n .* log(p_model) + ...
                (1 - p) * n .* log(1 - p_model));
    nll = -log_L;
end
Notes

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 强度指标Sa(T1)g
输入 · 超越概率P(DS ≥ ds | IM)0–1
输出 · 中位值θg
输出 · 对数标准差β无量纲
输出 · 光滑曲线P(IM)0–1
  • 对数正态模型：P(IM) = Φ[ln(IM/θ)/β]， 是易损性曲线的标准形式。
  • 中位值 θ：曲线与 P = 0.5 的交点， 反映该损伤状态的平均抵抗能力。
  • 对数标准差 β：反映能力的不确定性。 β 通常在 0.3–0.6 之间，包含地震动、结构、损伤状态定义等多重不确定性。
  • 数据统计：对每个 IM 水平统计 DM ≥ 阈值的波数占比。
  • 极大似然估计：用二项分布似然拟合， 比最小二乘更稳健。
  • 四种损伤状态：轻微、中等、严重、完全， 对应的层间位移角阈值通常为 0.005 / 0.010 / 0.020 / 0.040。
  • 常见问题：
    • 拟合曲线不单调 → 检查 CSV 数据是否单调， 或剔除极端点后重新拟合。
    • 曲线间距过小 → 损伤状态阈值设置过密， 需按规范或经验重新取值。
    • β > 1.0 → 数据离散度过大，可能混用了不同结构类型， 或地震波数量太少。
    • θ 与预期差别大 → 检查 IM 单位是否一致（g 还是 m/s²）， 或阈值是否有误。
    • 数据点数太少 → 至少 5 个 IM 水平才能稳定拟合， 建议 8 个以上。
