傅里叶幅值谱

对 assets/elcentro_EW.txt 的加速度记录做 FFT， 加 Hann 窗抑制频谱泄漏，双对数坐标显示频域能量分布与卓越频率。 这是《数字信号处理》与《地震动谱分析入门》的交叉应用。

工程地震 FFT Hann 窗 Python / MATLAB A4 尺寸
Input Format

输入数据格式

本模板读取两列文本文件（空格、制表符或逗号分隔）， 与 El Centro、SAC ASCII 等地震记录格式一致。量纲必须明确， 否则得到的傅里叶幅值会差若干量级。

输入文件要求

列号物理量 推荐单位说明
第 1 列时间 ts（秒）等间隔。程序用相邻两点之差推算采样步长 dt。
第 2 列地面加速度 agg（重力加速度）也可为 m/s² 或 gal（cm/s²）。

常用量纲的换算

你的数据单位 换算到 m/s² 代码里怎么写
g× 9.80665a = a * 9.80665
m/s²× 1a = a
gal（cm/s²）× 0.01a = a * 0.01
mm/s²× 0.001a = a * 0.001
本页示例 assets/elcentro_EW.txt 的第 2 列单位是 g， 绘图时幅值单位为 g·s。代码不做去均值、不去线性趋势， 直接对原始记录做 FFT。

Meaning

这张图说明了什么

傅里叶幅值谱把时域加速度记录变换到频域， 回答"地震动能量主要分布在哪些频率上"。横轴为频率 f（Hz）， 纵轴为对应频率成分的幅值。

从物理上看，一条地震记录可以分解为无数个不同频率的正弦波叠加：

a(t) = Σ Ak · cos(2π fk t + φk)

傅里叶谱的几个关键特征：

  • 卓越频率：幅值谱最高峰对应的频率，反映场地或震源的主要振动频率。El Centro 记录的卓越频率一般在 1–2 Hz 左右。
  • 高频衰减：超过某个频率后幅值迅速下降，反映地震波在传播路径上的高频衰减、场地的滤波作用以及震源的高频截止。
  • 低频平台：0.1–1 Hz 之间通常有一段相对平坦的区域。
  • 频率分辨率：Δf = 1/T。54 s 的记录分辨率约 0.019 Hz。
  • Nyquist 频率：fN = 1/(2·dt)，50 Hz 采样对应 25 Hz。
为什么用双对数坐标？ 地震动的频率成分跨越 2–3 个数量级，幅值也跨越几个数量级。 双对数坐标能同时展示低频和高频特征，也让幂律衰减在高频段表现为直线。
重要提示：不加窗直接做 FFT 会因为"截断效应"产生频谱泄漏， 使谱值失真。工程上通常加 Hann 窗、Hamming 窗或 Kaiser 窗抑制泄漏。
本页不做去均值处理，DC 分量（f = 0）中会保留原始记录的基线偏置， 因此绘图时跳过 DC 点。

Python

Python 代码

依赖 numpy 与 matplotlib。核心步骤： 读取两列文本 → 单位换算 → 加 Hann 窗 → FFT → 单边谱归一化 → 双对数绘制。 不做去均值、不去线性趋势。

fourier-spectrum.pyPython
# =============================================================
# 输入数据格式（两列文本，空格 / 制表符 / 逗号分隔）
#   第 1 列：时间 t   —— 单位 s（秒），等间隔
#   第 2 列：加速度 a —— 单位 g（重力加速度）
# -------------------------------------------------------------
# 如果你的加速度列不是 g，请在下方 DATA_UNIT 处选择：
#   'g'     → 第 2 列单位 g   （× 9.80665 → m/s²）
#   'm/s2'  → 第 2 列单位 m/s²（× 1）
#   'gal'   → 第 2 列单位 cm/s²（× 0.01）
#   'mm/s2' → 第 2 列单位 mm/s²（× 0.001）
# -------------------------------------------------------------
# 说明：本脚本不做去均值、不去线性趋势，直接对原始记录做 FFT。
# =============================================================
DATA_UNIT = 'g'

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.ticker import LogLocator

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

# ---- 1. 读取两列文本 ----
t, a_raw = np.loadtxt('elcentro_EW.txt', unpack=True)
dt = t[1] - t[0]
n = len(a_raw)

# ---- 2. 单位换算（不去均值） ----
unit_factor = {'g': 9.80665, 'm/s2': 1.0, 'gal': 0.01, 'mm/s2': 0.001}
factor = unit_factor.get(DATA_UNIT, 9.80665)
a = a_raw * factor

# ---- 3. 加 Hann 窗 ----
win = np.hanning(n)
a_win = a * win

# ---- 4. FFT ----
af = np.fft.rfft(a_win)
freq = np.fft.rfftfreq(n, dt)

# ---- 5. 幅值归一化 ----
#   系数 2 是单边谱系数，1/mean(win) 补偿窗函数引起的幅值损失。
amp = np.abs(af) * 2.0 / (n * win.mean())
amp[0] /= 2.0   # DC 分量不乘 2

# ---- 6. 绘图（A4 尺寸 7.2 × 3.8 in，双对数） ----
fig, ax = plt.subplots(figsize=(7.2, 3.8))
ax.loglog(freq[1:], amp[1:], lw=1.0, color='#b45309')
ax.set_xlabel('Frequency f (Hz)')
ax.set_ylabel('Fourier amplitude (g·s)')
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)
ax.set_title('Fourier amplitude spectrum — El Centro 1940, EW', fontsize=11)
ax.set_xlim(freq[1], freq[-1])
ax.tick_params(direction='in', which='both', top=True, right=True)

# 纵轴只保留 1、2、5 × 10ⁿ 主刻度
ax.yaxis.set_major_locator(LogLocator(base=10.0, subs=(1.0, 2.0, 5.0), numticks=15))
ax.yaxis.set_minor_locator(LogLocator(base=10.0, subs=tuple(np.arange(2, 10) * 0.1), numticks=100))
ax.tick_params(axis='y', which='minor', length=2)

fig.tight_layout()
fig.savefig('fourier-spectrum.png', dpi=300, bbox_inches='tight')
plt.show()

# ---- 7. 打印卓越频率 ----
idx = np.argmax(amp[1:]) + 1
print(f'卓越频率 Tp ≈ {freq[idx]:.4f} Hz (周期 {1/freq[idx]:.3f} s)')
print(f'频率分辨率 Δf = {freq[1]:.4f} Hz')
print(f'Nyquist 频率  = {freq[-1]:.2f} Hz')
关键点：
  • 输入量纲：时间 s，加速度 g（默认）。改 DATA_UNIT 一个变量即可切换单位。
  • np.fft.rfft 返回单边复数谱，只包含 0 到 Nyquist 频率。
  • 归一化系数 2/(n·mean(win))：2 是单边谱系数，1/mean(win) 补偿窗函数引起的幅值损失。
  • DC 分量（freq=0）不乘 2，因为它在单边谱里本来就只算一次。
  • 绘图时跳过第一个点（DC），避免对数坐标下 log(0) 报错。
  • 纵轴刻度：LogLocator(subs=(1, 2, 5)) 只保留 1、2、5 × 10ⁿ 主刻度，避免标签拥挤。
MATLAB

MATLAB 代码

用 fft 做变换，hann 生成 Hann 窗， loglog 绘制双对数曲线。 不做去均值、不去趋势。

fourier-spectrum.mMATLAB
% =============================================================
% 输入数据格式（两列文本，空格 / 制表符 / 逗号分隔）
%   第 1 列：时间 t   —— 单位 s（秒），等间隔
%   第 2 列：加速度 a —— 单位 g（重力加速度）
% -------------------------------------------------------------
% 如果你的加速度列不是 g，请在下方 DATA_UNIT 处选择：
%   'g'     → 第 2 列单位 g      （× 9.80665 → m/s²）
%   'm/s2'  → 第 2 列单位 m/s²   （× 1）
%   'gal'   → 第 2 列单位 cm/s²  （× 0.01）
%   'mm/s2' → 第 2 列单位 mm/s²  （× 0.001）
% -------------------------------------------------------------
% 说明：本脚本不做去均值、不去线性趋势，直接对原始记录做 FFT。
% =============================================================
DATA_UNIT = 'g';

% ---- 1. 读取两列文本 ----
data = readmatrix('elcentro_EW.txt');
t    = data(:, 1);
a_raw = data(:, 2);
dt   = t(2) - t(1);
n    = numel(a_raw);

% ---- 2. 单位换算（不去均值） ----
switch DATA_UNIT
    case 'g',     factor = 9.80665;
    case 'm/s2',  factor = 1.0;
    case 'gal',   factor = 0.01;
    case 'mm/s2', factor = 0.001;
    otherwise,    factor = 9.80665;
end
a = a_raw * factor;

% ---- 3. 加 Hann 窗 ----
win   = hann(n);
a_win = a .* win;

% ---- 4. FFT 与单边幅值谱 ----
af   = fft(a_win);
half = 1:floor(n/2) + 1;

freq = (0:n-1)' / (n * dt);
freq = freq(half);

amp = abs(af(half)) * 2 / (n * mean(win));
amp(1) = amp(1) / 2;   % DC 不乘 2

% ---- 5. 绘图（A4 尺寸 720 × 380 px，双对数） ----
figure('Color', 'w', 'Position', [100 100 720 380]);
loglog(freq(2:end), amp(2:end), 'Color', [0.71 0.33 0.04], 'LineWidth', 1.0);
xlabel('Frequency f (Hz)');
ylabel('Fourier amplitude (g\cdot s)');
grid on; box on;
title('Fourier amplitude spectrum — El Centro 1940, EW');
set(gca, 'FontName', 'Times New Roman', 'FontSize', 10, 'TickDir', 'in', ...
    'XScale', 'log', 'YScale', 'log');
xlim([freq(2), freq(end)]);

% 纵轴只保留 1、2、5 × 10^n 主刻度
ax = gca;
yt = get_log_ticks(ax.YLim);
set(ax, 'YTick', yt);

exportgraphics(gcf, 'fourier-spectrum.png', 'Resolution', 300);

% ---- 6. 打印卓越频率 ----
[~, idx] = max(amp(2:end));
idx = idx + 1;
fprintf('卓越频率 Tp ≈ %.4f Hz (周期 %.3f s)\n', freq(idx), 1/freq(idx));
fprintf('频率分辨率 Δf = %.4f Hz\n', freq(2));
fprintf('Nyquist 频率  = %.2f Hz\n', freq(end));


% ===== 辅助函数：1、2、5 × 10^n 刻度，标签太多时退化为 10^n =====
function ticks = get_log_ticks(ylim)
    lo = log10(ylim(1));
    hi = log10(ylim(2));
    ticks = [];
    for e = floor(lo):ceil(hi)
        for m = [1 2 5]
            v = m * 10^e;
            if v >= ylim(1) && v <= ylim(2)
                ticks(end+1) = v; %#ok
            end
        end
    end
    if numel(ticks) > 8
        ticks = [];
        for e = floor(lo):ceil(hi)
            v = 10^e;
            if v >= ylim(1) && v <= ylim(2)
                ticks(end+1) = v; %#ok
            end
        end
    end
end
Notes

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 时间ts（秒）
输入 · 加速度agg（默认）/ m/s² / gal / mm/s²
输出 · 频率fHz
输出 · 傅里叶幅值|A(f)|输入单位 · s（示例为 g·s）
输出 · 卓越频率fpHz
  • FFT 与单边谱：原始 FFT 输出对称的双边谱，物理上只有非负频率有意义。单边谱取前 n/2+1 个点，把负频能量折算到正频（系数 2）。
  • 窗函数归一化：加窗后信号总能量降低，需除以窗函数的均值 mean(win) 补偿。这样单一正弦分量的幅值才能被正确还原。
  • 频率分辨率：Δf = 1/(n·dt) = 1/T。50 Hz、2700 点的记录 Δf ≈ 0.0185 Hz。
  • Nyquist 频率：fN = 1/(2·dt)。50 Hz 采样对应 25 Hz，这是能识别的最高频率。
  • 窗函数选择：Hann 窗主瓣宽、旁瓣低，通用性最好。若关心窄带峰值，可用矩形窗或 Hamming 窗；若关心宽频响应，可用 Kaiser 窗。
  • 纵轴刻度：只保留 1、2、5 × 10ⁿ 主刻度，避免标签拥挤。
  • 无去均值：本模板不去均值，所以 DC 分量（f = 0）会保留原始记录的基线偏置。 为避免对数坐标下 log(0) 问题，绘图时跳过 DC 点。
  • 常见问题：
    • 谱值整体偏小或偏大 10³ 量级 → 输入加速度单位选错了，检查 DATA_UNIT。
    • 低频段出现异常高值 → 原始记录含有长周期基线漂移（不做去均值的直接结果）。
    • 高频段出现等间距尖峰 → 记录中可能有周期性的电力干扰或仪器噪声。
    • 谱值随频率单调上升 → 单位换算错误。
