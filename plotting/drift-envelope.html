层间位移角包络

多层框架在多条地震波作用下的层间位移角包络曲线。 每条曲线对应一条地震波的时程分析结果，粗黑线为所有地震波 的逐层最大值（即包络），红色虚线为规范限值（如 1/550 或 1/50）。 这是性能化设计、抗震验算与规范审查的关键图件。

CSV Input

输入数据格式

本页读取 assets/drift_envelope.csv 作为输入。 文件是多波时程分析结果的整理输出：第一列为楼层号， 后续每列对应一条地震波，单元格为该楼层在该波作用下的 最大层间位移角（无量纲小数）。

数据来源

  • 弹性时程分析——ETABS、SAP2000、Perform-3D、OpenSees、 MIDAS Gen、ABAQUS，输入一组地震波，输出每层的位移时程， 取绝对值最大值除以层高即得层间位移角。
  • 弹塑性时程分析——用于罕遇地震验算， 层间位移角反映结构的塑性变形需求。
  • 规范选波要求——GB 50011-2010 规定： 至少选 2 组实际强震记录 + 1 组人工模拟波； 实际强震记录数量不少于总数的 2/3。
  • 结果包络——把每条波的结果逐层取最大值， 即得包络曲线，用于抗震验算。
本页示例是一个 10 层框架在三条地震波下的弹性层间位移角。 最大值出现在第 10 层，约 2.59 × 10⁻³（wave2）。 按 GB 50011-2010 对钢筋混凝土框架多遇地震的限值 1/550 ≈ 1.82 × 10⁻³， wave2 在 7–10 层超过限值。替换为你自己的时程分析结果只需修改 drift_envelope.csv。

计算步骤：用 Newmark-β 做 MDOF 时程分析

drift_envelope.csv 里的层间位移角不是直接测出来的， 而是通过多自由度（MDOF）结构时程分析计算得到。 对每一条地震波，建立结构的质量、刚度、阻尼矩阵，用 Newmark-β 平均加速度法逐步积分得到各层位移时程 ui(t)， 再取相邻两层位移差的最大值除以层高，即得该层的层间位移角。

建立 MDOF 模型 (M, K, C) → 读取地震波 ag(t) → Newmark-β 逐步积分 → 各层位移时程 ui(t) → 层间位移差 Δui(t) = ui(t) − ui−1(t) → maxt|Δui| / hi → 每条波一组 θi → 合并为 drift_envelope.csv

结构模型（剪切型 MDOF）

采用最常用的剪切型模型：每层一个集中质量 mi， 相邻层之间用层间刚度 ki 连接。这是框架结构、砌体结构 时程分析的基本简化模型。

参数 符号 单位 说明
层数N整数默认 10 层
层质量mikg每层集中质量，取 1.0×10⁵ kg
层间刚度kiN/m每层抗侧刚度，取 5.0×10⁷ N/m
层高himm默认 3000 mm
阻尼比ζ无量纲5%，用瑞利阻尼

输入文件（地震波）

列号 物理量 单位 说明
第 1 列时间 ts等间隔
第 2 列地面加速度 agg可换算为 m/s²
单位一致性：位移时程与层高必须使用同一单位。 本页代码中质量 kg、刚度 N/m、地震动 m/s²，输出的位移为 m， 最后换算为 mm 再除以层高 mm，位移角无量纲。

Python 代码：MDOF 时程分析 → 层间位移角

mdof_drift.pyPython
# =============================================================
# MDOF 时程分析 | 剪切型模型 + Newmark-β 法
# -------------------------------------------------------------
# 输入：
#   elcentro_EW.txt（或你自己的地震波文件）
#     第 1 列：时间 t (s)
#     第 2 列：地面加速度 ag (g)
# -------------------------------------------------------------
# 输出：
#   wave1_disp.csv  各层位移时程（mm）
#   drift_envelope.csv  各波下每层的最大层间位移角
# =============================================================

import numpy as np

# ---------- 1. 结构参数 ----------
N = 10                                # 层数
m = 1.0e5 * np.ones(N)                # 每层质量 (kg)
k = 5.0e7 * np.ones(N)                # 层间刚度 (N/m)
h = 3000.0 * np.ones(N)               # 层高 (mm)
zeta = 0.05                           # 阻尼比

# ---------- 2. 组装质量矩阵 ----------
M = np.diag(m)

# ---------- 3. 组装刚度矩阵（剪切型） ----------
K = np.zeros((N, N))
for i in range(N):
    if i == 0:
        K[i, i] = k[0] + (k[1] if N > 1 else 0)
        if N > 1:
            K[i, i + 1] = -k[1]
    elif i == N - 1:
        K[i, i] = k[i]
        K[i, i - 1] = -k[i]
    else:
        K[i, i] = k[i] + k[i + 1]
        K[i, i - 1] = -k[i]
        K[i, i + 1] = -k[i + 1]

# ---------- 4. 瑞利阻尼 ----------
eigvals = np.linalg.eigvalsh(np.linalg.solve(M, K))
omega = np.sqrt(np.sort(eigvals))
omega1, omega2 = omega[0], omega[1]
a0 = 2 * zeta * omega1 * omega2 / (omega1 + omega2)
a1 = 2 * zeta / (omega1 + omega2)
C = a0 * M + a1 * K

print(f'第 1 阶频率 f1 = {omega1 / (2 * np.pi):.3f} Hz')
print(f'第 2 阶频率 f2 = {omega2 / (2 * np.pi):.3f} Hz')
print(f'瑞利阻尼系数 a0 = {a0:.4f}, a1 = {a1:.6f}')

# ---------- 5. 读取地震波 ----------
g = 9.80665
t, ag_g = np.loadtxt('elcentro_EW.txt', unpack=True)
ag = ag_g * g                         # g → m/s²
dt = t[1] - t[0]
n = len(ag)

# ---------- 6. Newmark-β 平均加速度法 ----------
gamma, beta = 0.5, 0.25
Keff = K + gamma / (beta * dt) * C + 1.0 / (beta * dt ** 2) * M
Keff_inv = np.linalg.inv(Keff)

# 初始条件
u   = np.zeros(N)                     # 位移
v   = np.zeros(N)                     # 速度
acc = -ag[0] * np.ones(N)             # 相对加速度

# 存储位移时程
U = np.zeros((n, N))
U[0] = u

for j in range(1, n):
    # 等效荷载
    p = (-M @ (ag[j] * np.ones(N))
         + M @ (1.0 / (beta * dt ** 2) * u
                + 1.0 / (beta * dt) * v
                + (1.0 / (2 * beta) - 1) * acc)
         + C @ (gamma / (beta * dt) * u
                + (gamma / beta - 1) * v
                + dt * (gamma / (2 * beta) - 1) * acc))

    u_new = Keff_inv @ p
    v_new = (gamma / (beta * dt) * (u_new - u)
             - (gamma / beta - 1) * v
             - dt * (gamma / (2 * beta) - 1) * acc)
    acc_new = (1.0 / (beta * dt ** 2) * (u_new - u)
               - 1.0 / (beta * dt) * v
               - (1.0 / (2 * beta) - 1) * acc)

    u, v, acc = u_new, v_new, acc_new
    U[j] = u

# ---------- 7. 输出各层位移时程（mm） ----------
disp_mm = U * 1000.0
header_disp = 'time,' + ','.join([f'u{i+1}' for i in range(N)])
np.savetxt('wave1_disp.csv',
           np.column_stack([t, disp_mm]),
           delimiter=',', header=header_disp,
           comments='', fmt='%.6f')
print('\n已保存 wave1_disp.csv')

# ---------- 8. 计算层间位移角 ----------
drifts = np.zeros(N)
drifts[0] = np.max(np.abs(disp_mm[:, 0])) / h[0]
for i in range(1, N):
    du = disp_mm[:, i] - disp_mm[:, i - 1]
    drifts[i] = np.max(np.abs(du)) / h[i]

print('\n各层最大层间位移角：')
for i in range(N):
    print(f'  第 {i+1:2d} 层：{drifts[i]:.5f}  '
          f'(= 1/{1/drifts[i]:.0f})')

i_peak = int(np.argmax(drifts))
print(f'\n峰值在第 {i_peak+1} 层，θmax = {drifts[i_peak]:.5f}')

# ---------- 9. 多条波循环 + 合并 ----------
# 实际使用时把下面的 wave_files 换成你的三个文件
wave_files = ['elcentro_EW.txt', 'elcentro_NS.txt', 'elcentro_UP.txt']
wave_names = ['wave1', 'wave2', 'wave3']

all_drifts = np.zeros((N, len(wave_files)))

for w, fname in enumerate(wave_files):
    # 对每条波重复上面第 5–8 步
    t_w, ag_g_w = np.loadtxt(fname, unpack=True)
    ag_w = ag_g_w * g
    n_w = len(ag_w)

    u_w   = np.zeros(N)
    v_w   = np.zeros(N)
    acc_w = -ag_w[0] * np.ones(N)
    U_w = np.zeros((n_w, N))
    U_w[0] = u_w

    for j in range(1, n_w):
        p = (-M @ (ag_w[j] * np.ones(N))
             + M @ (1.0 / (beta * dt ** 2) * u_w
                    + 1.0 / (beta * dt) * v_w
                    + (1.0 / (2 * beta) - 1) * acc_w)
             + C @ (gamma / (beta * dt) * u_w
                    + (gamma / beta - 1) * v_w
                    + dt * (gamma / (2 * beta) - 1) * acc_w))
        u_new = Keff_inv @ p
        v_new = (gamma / (beta * dt) * (u_new - u_w)
                 - (gamma / beta - 1) * v_w
                 - dt * (gamma / (2 * beta) - 1) * acc_w)
        acc_new = (1.0 / (beta * dt ** 2) * (u_new - u_w)
                   - 1.0 / (beta * dt) * v_w
                   - (1.0 / (2 * beta) - 1) * acc_w)
        u_w, v_w, acc_w = u_new, v_new, acc_new
        U_w[j] = u_w

    disp_w = U_w * 1000.0
    drifts_w = np.zeros(N)
    drifts_w[0] = np.max(np.abs(disp_w[:, 0])) / h[0]
    for i in range(1, N):
        du = disp_w[:, i] - disp_w[:, i - 1]
        drifts_w[i] = np.max(np.abs(du)) / h[i]
    all_drifts[:, w] = drifts_w

# 合并为 drift_envelope.csv
story = np.arange(1, N + 1)
out = np.column_stack([story, all_drifts])
header = 'story,' + ','.join(wave_names)
np.savetxt('drift_envelope.csv', out,
           delimiter=',', header=header,
           comments='', fmt='%.6f')
print('\n已保存 drift_envelope.csv')
关键点：
  • 运动方程：M·ü + C·u̇ + K·u = −M·1·ag(t)。 右边把地面加速度等效为惯性力，作用在所有楼层上。
  • 刚度矩阵：剪切型模型下 K 是三对角矩阵， 对角线为相邻层刚度之和，非对角线为负的层间刚度。
  • 瑞利阻尼：C = a0·M + a1·K， 系数由前两阶频率与阻尼比确定。
  • Newmark-β：γ = 1/2，β = 1/4， 平均加速度法，无条件稳定。
  • 等效刚度：Keff = K + γ/(β·dt)·C + 1/(β·dt²)·M， 只需在最开始求一次逆。
  • 层间位移角：第 1 层 = max|u₁|/h₁； 第 i 层 = max|ui − ui−1|/hi。
  • 三条波循环：对每条波重复一遍 Newmark-β 积分， 最后按列合并得到 CSV。

MATLAB 代码：MDOF 时程分析 → 层间位移角

mdof_drift.mMATLAB
% =============================================================
% MDOF 时程分析 | 剪切型模型 + Newmark-β 法
% -------------------------------------------------------------
% 输入：
%   elcentro_EW.txt
%     第 1 列：时间 t (s)
%     第 2 列：地面加速度 ag (g)
% -------------------------------------------------------------
% 输出：
%   drift_envelope.csv  各波下每层的最大层间位移角
% =============================================================

% ---------- 1. 结构参数 ----------
N = 10;                                 % 层数
m = 1.0e5 * ones(N, 1);                 % 每层质量 (kg)
k = 5.0e7 * ones(N, 1);                 % 层间刚度 (N/m)
h = 3000.0 * ones(N, 1);                % 层高 (mm)
zeta = 0.05;                            % 阻尼比

% ---------- 2. 质量矩阵 ----------
M = diag(m);

% ---------- 3. 刚度矩阵（剪切型） ----------
K = zeros(N, N);
for i = 1:N
    if i == 1
        K(i, i) = k(1) + (k(2) * (N > 1));
        if N > 1
            K(i, i + 1) = -k(2);
        end
    elseif i == N
        K(i, i) = k(i);
        K(i, i - 1) = -k(i);
    else
        K(i, i) = k(i) + k(i + 1);
        K(i, i - 1) = -k(i);
        K(i, i + 1) = -k(i + 1);
    end
end

% ---------- 4. 瑞利阻尼 ----------
eigvals = sort(eig(M \ K));
omega = sqrt(eigvals);
w1 = omega(1); w2 = omega(2);
a0 = 2 * zeta * w1 * w2 / (w1 + w2);
a1 = 2 * zeta / (w1 + w2);
C = a0 * M + a1 * K;

fprintf('第 1 阶频率 f1 = %.3f Hz\n', w1 / (2 * pi));
fprintf('第 2 阶频率 f2 = %.3f Hz\n', w2 / (2 * pi));

% ---------- 5. 读取地震波 ----------
g = 9.80665;
data = readmatrix('elcentro_EW.txt');
t = data(:, 1);
ag = data(:, 2) * g;                    % g → m/s²
dt = t(2) - t(1);
n = numel(ag);

% ---------- 6. Newmark-β 参数 ----------
gamma = 0.5; beta = 0.25;
Keff = K + gamma / (beta * dt) * C + 1 / (beta * dt^2) * M;

% ---------- 7. 逐步积分 ----------
u   = zeros(N, 1);
v   = zeros(N, 1);
acc = -ag(1) * ones(N, 1);
U = zeros(n, N);
U(1, :) = u';

for j = 2:n
    p = -M * (ag(j) * ones(N, 1)) ...
        + M * (1/(beta*dt^2)*u + 1/(beta*dt)*v + (1/(2*beta)-1)*acc) ...
        + C * (gamma/(beta*dt)*u + (gamma/beta-1)*v ...
               + dt*(gamma/(2*beta)-1)*acc);

    u_new = Keff \ p;
    v_new = gamma/(beta*dt)*(u_new - u) ...
            - (gamma/beta-1)*v - dt*(gamma/(2*beta)-1)*acc;
    acc_new = 1/(beta*dt^2)*(u_new - u) ...
              - 1/(beta*dt)*v - (1/(2*beta)-1)*acc;

    u = u_new; v = v_new; acc = acc_new;
    U(j, :) = u';
end

% ---------- 8. 位移时程（mm） ----------
disp_mm = U * 1000.0;

% ---------- 9. 层间位移角 ----------
drifts = zeros(N, 1);
drifts(1) = max(abs(disp_mm(:, 1))) / h(1);
for i = 2:N
    du = disp_mm(:, i) - disp_mm(:, i - 1);
    drifts(i) = max(abs(du)) / h(i);
end

fprintf('\n各层最大层间位移角：\n');
for i = 1:N
    fprintf('  第 %2d 层：%.5f  (= 1/%.0f)\n', ...
            i, drifts(i), 1/drifts(i));
end
[peak, ipeak] = max(drifts);
fprintf('\n峰值在第 %d 层，θmax = %.5f\n', ipeak, peak);

% ---------- 10. 三条波循环 + 合并 ----------
wave_files = {'elcentro_EW.txt', 'elcentro_NS.txt', 'elcentro_UP.txt'};
wave_names = {'wave1', 'wave2', 'wave3'};

all_drifts = zeros(N, numel(wave_files));

for w = 1:numel(wave_files)
    d_w = readmatrix(wave_files{w});
    t_w = d_w(:, 1);
    ag_w = d_w(:, 2) * g;
    n_w = numel(ag_w);

    u_w = zeros(N, 1); v_w = zeros(N, 1);
    acc_w = -ag_w(1) * ones(N, 1);
    U_w = zeros(n_w, N);
    U_w(1, :) = u_w';

    for j = 2:n_w
        p = -M * (ag_w(j) * ones(N, 1)) ...
            + M * (1/(beta*dt^2)*u_w + 1/(beta*dt)*v_w ...
                   + (1/(2*beta)-1)*acc_w) ...
            + C * (gamma/(beta*dt)*u_w + (gamma/beta-1)*v_w ...
                   + dt*(gamma/(2*beta)-1)*acc_w);
        u_new = Keff \ p;
        v_new = gamma/(beta*dt)*(u_new - u_w) ...
                - (gamma/beta-1)*v_w - dt*(gamma/(2*beta)-1)*acc_w;
        acc_new = 1/(beta*dt^2)*(u_new - u_w) ...
                  - 1/(beta*dt)*v_w - (1/(2*beta)-1)*acc_w;
        u_w = u_new; v_w = v_new; acc_w = acc_new;
        U_w(j, :) = u_w';
    end

    disp_w = U_w * 1000.0;
    drifts_w = zeros(N, 1);
    drifts_w(1) = max(abs(disp_w(:, 1))) / h(1);
    for i = 2:N
        du = disp_w(:, i) - disp_w(:, i - 1);
        drifts_w(i) = max(abs(du)) / h(i);
    end
    all_drifts(:, w) = drifts_w;
end

% ---------- 11. 导出 CSV ----------
story = (1:N)';
T_out = array2table([story, all_drifts], ...
    'VariableNames', [{'story'}, wave_names]);
writetable(T_out, 'drift_envelope.csv');
fprintf('\n已保存 drift_envelope.csv\n');
常见问题：
  • 频率不合理——检查质量与刚度单位。k 用 N/m， m 用 kg，得到 rad/s；若用 kN 与 t，结果会差 1000 倍。
  • 位移发散——时间步长过大（dt > 0.1·Tmin）， 减小 dt 或改无条件稳定的 Newmark-β（本页已用平均加速度法）。
  • 瑞利阻尼系数异常——检查前两阶频率是否取对， 高层结构第 2 阶可能是扭转或高阶振型。
  • 层间位移角在某层突变——该层刚度突变， 需检查结构布置或 k 数组。
  • 多条波结果差异大——频谱不同，属正常现象， 这也是规范要求多波包络的原因。
  • 未调幅——多遇地震验算时， 各波峰值加速度需调到设防烈度对应值，否则位移角偏小。
Meaning

这张图说明了什么

层间位移角（inter-story drift ratio）定义为：

θi = maxt | ui(t) − ui−1(t) | / hi

其中 ui、ui−1 分别是第 i 层与第 i−1 层的位移时程， hi 是第 i 层的层高。它是衡量结构非结构构件损伤 与整体变形能力的关键指标。

规范限值（GB 50011-2010）

不同结构类型、不同设防水平的限值不同：

结构类型 多遇地震 罕遇地震
钢筋混凝土框架1/5501/50
钢筋混凝土框架-剪力墙1/8001/100
钢筋混凝土剪力墙1/10001/120
钢结构（多高层）1/2501/50
钢框架-支撑1/3001/50

从包络曲线上能读出什么

  • 最大值位置——通常在结构的中上部或顶部。 若最大值出现在底部，可能表示薄弱层在底层。
  • 曲线形状——沿高度单调递增表示结构刚度沿高度递减； 中部出现突变表示该层存在薄弱环节或刚度突变。
  • 地震波间差异——不同波的曲线形状与峰值不同， 说明结构对不同频谱成分的响应有差异。 如果某条波的结果明显偏大，可能是该波的频谱与结构自振周期接近。
  • 与限值的关系——包络曲线与限值线的相对位置决定 结构是否满足规范要求。任何一层超过限值，都需要调整结构设计。
  • 层间位移角与位移的关系——层间位移角是位移的差分， 它反映的是"局部变形"，而层位移反映的是"整体侧移"。
性能化设计中的用法： 在基于性能的地震工程中，层间位移角是最常用的 工程需求参数（EDP）。它与结构损伤状态直接对应： 约 0.5% 对应"立即入住"（IO），约 1.5% 对应"生命安全"（LS）， 约 2.5% 对应"防止倒塌"（CP）。性能化设计的目标就是让层间位移角 在各个性能水平下不超过相应限值。
注意：本页只对已有时程分析结果做后处理， 不重新计算层间位移角。真实的层间位移角必须由时程分析中 每层节点的位移时程计算得到。若数据未经调幅或只用了单条地震波， 结果不能直接用于抗震验算。

Python

Python 代码

依赖 numpy 与 matplotlib。 代码读取 CSV 后自动识别地震波列数，绘制各波曲线与包络线， 并标出规范限值。

drift-envelope.pyPython
# =============================================================
# 层间位移角包络 | 多条地震波对比
# -------------------------------------------------------------
# 输入数据：drift_envelope.csv
#   story,wave1,wave2,wave3
#   1,0.00028,0.00032,0.00030
#   2,0.00058,0.00066,0.00062
#   ...
#   单位：位移角（无量纲小数）
# -------------------------------------------------------------
# 功能：
#   1. 读取 CSV（自动识别地震波列数）
#   2. 计算逐层包络（所有波的最大值）
#   3. 绘制各波曲线 + 包络 + 规范限值
# =============================================================

import os
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

CSV_FILE = 'drift_envelope.csv'

# ---- 规范限值（无量纲小数），按需要修改 ----
DRIFT_LIMIT = 1.0 / 550.0       # 钢筋混凝土框架，多遇地震
LIMIT_LABEL = '1/550 limit'


def generate_synthetic():
    """CSV 缺失时生成合成数据（10 层，3 条波）。"""
    story = np.arange(1, 11)
    wave1 = np.array([0.00028, 0.00058, 0.00086, 0.00112, 0.00136,
                      0.00158, 0.00178, 0.00196, 0.00212, 0.00226])
    wave2 = np.array([0.00032, 0.00066, 0.00098, 0.00128, 0.00156,
                      0.00181, 0.00204, 0.00225, 0.00243, 0.00259])
    wave3 = np.array([0.00030, 0.00062, 0.00092, 0.00120, 0.00146,
                      0.00170, 0.00192, 0.00211, 0.00228, 0.00243])
    return story, {'wave1': wave1, 'wave2': wave2, 'wave3': wave3}


# ---- 1. 读取 CSV ----
if os.path.exists(CSV_FILE):
    data = np.genfromtxt(CSV_FILE, delimiter=',', names=True,
                         dtype=None, encoding='utf-8')
    story = np.asarray(data['story'], dtype=float)
    wave_names = [n for n in data.dtype.names if n != 'story']
    waves = {name: np.asarray(data[name], dtype=float)
             for name in wave_names}
    print(f'从 {CSV_FILE} 读取 {len(story)} 层、{len(wave_names)} 条波')
else:
    print(f'{CSV_FILE} 不存在，使用合成数据演示')
    story, waves = generate_synthetic()
    wave_names = list(waves.keys())


# ---- 2. 计算逐层包络 ----
envelope = np.zeros_like(story)
for name in wave_names:
    envelope = np.maximum(envelope, waves[name])

i_peak = int(np.argmax(envelope))
print(f'包络最大值：{envelope[i_peak]:.5f} 在第 {int(story[i_peak])} 层')
print(f'规范限值：{DRIFT_LIMIT:.5f}')


# ---- 3. 绘图（A4 尺寸 6.0 × 7.2 in） ----
fig, ax = plt.subplots(figsize=(6.0, 7.2))

# 各条地震波曲线（细线）
colors = ['#2563eb', '#b45309', '#15803d', '#9333ea', '#dc2626',
          '#0891b2', '#ca8a04']
for i, name in enumerate(wave_names):
    ax.plot(waves[name] * 1000, story, '-o', lw=1.2, ms=4,
            color=colors[i % len(colors)],
            alpha=0.65, label=name)

# 包络（粗黑线）
ax.plot(envelope * 1000, story, '-', lw=2.4, color='#111111',
        label='Envelope', zorder=5)

# 规范限值（红色虚线）
ax.axvline(DRIFT_LIMIT * 1000, color='#dc2626', lw=1.2,
           ls='--', label=LIMIT_LABEL, zorder=4)

# 峰值标注
ax.plot(envelope[i_peak] * 1000, story[i_peak], 'o',
        color='#111111', ms=8, zorder=6)
ax.annotate(
    f'Peak = {envelope[i_peak]*1000:.2f}×10⁻³\n(story {int(story[i_peak])})',
    xy=(envelope[i_peak] * 1000, story[i_peak]),
    xytext=(envelope[i_peak] * 1000 + 0.3, story[i_peak] - 1.5),
    fontsize=9,
    arrowprops=dict(arrowstyle='-', color='#555555', lw=0.6))

# 坐标轴
ax.set_xlabel('Inter-story drift ratio  (× 10$^{-3}$)')
ax.set_ylabel('Story')
ax.set_yticks(story)
ax.set_ylim(0.3, story.max() + 0.7)
ax.grid(True, ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='lower right', fontsize=9, frameon=False)
ax.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('drift-envelope.png', dpi=300, bbox_inches='tight')
plt.show()
关键点：
  • 自动识别列数：data.dtype.names 会自动读取所有列， 增加地震波只需在 CSV 里增加一列，代码不用改。
  • 逐层包络：对每层用 np.maximum 取所有波的最大值， 即得包络曲线。
  • 单位显示：绘图时乘 1000，以 10⁻³ 为单位显示， 避免坐标轴上出现 0.0005 这类小数。
  • 规范限值：DRIFT_LIMIT 是变量， 改一个值即可切换多遇 / 罕遇、不同结构类型。
  • 配色：地震波用蓝、橙、绿、紫、红等， 包络用黑色粗线，限值用红色虚线，视觉层次清晰。

Notes

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 楼层号i整数（1 为底层）
输入 · 层间位移角θi无量纲小数
输出 · 层间位移角包络maxwave θi无量纲小数
输出 · 包络峰值θmax无量纲小数
输出 · 峰值所在楼层ipeak整数
  • 定义：θi = maxt|ui(t) − ui−1(t)| / hi， 对每条地震波单独计算。
  • 包络：对每一层，取所有地震波的最大值。 包络曲线用于抗震验算，而不是取平均。
  • 规范选波：GB 50011-2010 要求至少 2 组实际强震记录 + 1 组人工波； 实际记录不少于总数的 2/3。
  • 调幅：多遇地震验算时，各波峰值加速度需调到设防烈度对应值； 罕遇地震验算时调到罕遇设防值。
  • 层高：底层层高通常较大，若底层位移角偏小， 表示底部相对刚，属于正常现象。
  • 与位移的关系：层间位移角是位移的差分， 反映"局部变形"，比顶层位移更能反映结构的损伤程度。
  • 常见问题：
    • 包络曲线在某层突变 → 该层存在刚度突变或薄弱层， 需检查结构布置。
    • 某条波结果明显偏大 → 该波的频谱与结构自振周期接近， 属于正常现象。
    • 底层位移角小于上部 → 底层层高大或底部刚度大， 需对照结构布置判断。
    • 所有波都超限 → 结构整体偏柔，需加大截面或增加支撑。
    • CSV 编码乱码 → 保存为 UTF-8，列名严格按示例。
