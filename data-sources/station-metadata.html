台站元数据与方位角

台站元数据（Station Metadata）是描述地震台站、通道、仪器响应等信息的结构化数据， 是波形数据正确使用的前提。FDSN StationXML 是当前国际通用的元数据标准， 方位角与仪器响应是其中最关键的两个参数——方位角决定分量旋转的正确性， 仪器响应决定物理量的准确还原。

台站元数据 StationXML 方位角 仪器响应 FDSN 标准
Overview

概述

台站元数据是描述地震观测系统配置的结构化信息，涵盖台站位置、 通道方向、仪器类型、响应函数等关键参数。在强震动数据处理中，元数据与波形数据 同等重要：仅有波形而没有正确的元数据，无法完成仪器响应校正、 分量旋转、震相识别等基本操作。

FDSN StationXML 是由国际数字地震台网联盟（FDSN） 制定的地震学元数据标准，旨在替代已有 30 年历史的 SEED 格式（dataless SEED）， 提供更灵活、更完整的元数据描述能力。 StationXML 采用 XML 格式，支持描述台网、台站、通道、传感器、 数据采集器及响应函数等多个层级的详细信息。 当前主流数据中心（IRIS DMC、ORFEUS EIDA、GEOFON 等） 均已采用 StationXML 作为标准元数据格式。

台站元数据的核心组成

  • 台网信息：台网代码、管理机构、联系人、台站总数。
  • 台站信息：台站代码、经纬度、高程、场地名称、安装日期、终止日期。
  • 通道信息：通道代码（频带码 + 仪器码 + 方向码）、 采样率、方位角（Azimuth）、 倾角（Dip）、深度。
  • 仪器响应：传感器、前置放大器、数据采集器的传递函数， 以 Poles and Zeros（PAZ）、系数（Coefficients）或 有限脉冲响应（FIR）形式描述。
元数据为何重要： 现代地震学研究通常对三分量观测数据进行旋转，以分离不同类型的地震波。 因此两个水平分量的方位角信息是保证数据旋转正确的关键。 同时，仪器响应校正需要完整的传递函数信息， 否则无法从原始记录中准确还原地面运动物理量。
Format

数据格式

FDSN StationXML 采用层级结构组织元数据， 从台网到台站，再到通道，逐级细化；同时包含方位角与仪器响应等关键参数。 点击下方标签查看各部分的详细说明。

台网（Network）

层级结构的顶层 · 2 字符代码

台网是 StationXML 层级结构的顶层，代表一个逻辑上的台站集合。 台网代码由 2 个字符组成，遵循 FDSN 的命名规范。

字段 类型 说明
Network.Codestring台网代码（2 字符），如 IU、II、GE
Network.Descriptionstring台网名称描述
Network.StartDatedateTime台网起始日期
Network.EndDatedateTime台网终止日期（留空表示仍活跃）
Network.TotalNumberStationsint台网中的台站总数
Network.SelectedNumberStationsint当前查询返回的台站数
Operatorstring运营机构名称
Contactstring联系人信息（姓名、邮箱、电话）

台站（Station）

台网下的单个观测点 · 2–5 字符代码

台站代表一个具体的观测点，包含地理位置和场地信息。 台站代码由 2–5 个字符组成。

字段 类型 说明
Station.Codestring台站代码（2–5 字符）
Station.Latitudefloat台站纬度（度），建议精度 6 位小数（约 10 cm）
Station.Longitudefloat台站经度（度）
Station.Elevationfloat台站高程（米）
Station.Siteobject场地信息，包括场地名称、国家、城市等
Station.StartDatedateTime台站安装日期（UTC）
Station.EndDatedateTime台站终止日期（留空表示仍活跃）
Station.Vaultstring观测室类型（如 WWSSN、CMG-3T 等）
Station.Channelarray该台站下的所有通道信息

通道（Channel）

台站下的具体传感器通道 · 3 字符代码

通道是 StationXML 中最细粒度的层级，描述一个具体的传感器方向。 通道代码由 3 个字符组成，分别代表频带码、仪器码和方向码。 方位角（Azimuth）和倾角（Dip）在此层级定义。

字段 类型 说明
Channel.Codestring通道代码（3 字符），如 BHN、BHE、BHZ
Channel.LocationCodestring位置代码（2 字符），区分同一台站的不同安装位置
Channel.Latitudefloat通道纬度（可与台站纬度不同）
Channel.Longitudefloat通道经度
Channel.Elevationfloat通道高程（米）
Channel.Depthfloat传感器安装深度（米），井下台站尤为重要
Channel.Azimuthfloat方位角（度），从正北顺时针旋转的角度
Channel.Dipfloat倾角（度），从水平面向下旋转的角度
Channel.SampleRatefloat采样率（Hz）
Channel.StartDatedateTime通道起始日期
Channel.EndDatedateTime通道终止日期
通道命名规则：3 字符通道代码 = 频带码 + 仪器码 + 方向码。 频带码表示采样率（如 B=宽带、H=高宽带、E=极短周期）， 仪器码表示传感器类型（如 H=加速度计、N=加速度计、L=加速度计）， 方向码表示方位（N=北、E=东、Z=垂直）。 强震动加速度计常用 HN 或 BN 前缀。

响应（Response）

仪器传递函数 · 物理量还原的关键

响应描述通道的仪器传递函数，是从原始 counts 还原地面运动物理量 的核心信息。StationXML 支持多种响应描述方式， 包括 Poles and Zeros（PAZ）、系数（Coefficients）和 FIR 滤波器。

字段 说明
InstrumentSensitivity总灵敏度：将 counts 转换为物理量的比例因子
InputUnits输入单位（如 m/s²、m/s、m）
OutputUnits输出单位（通常为 counts）
Stage响应阶段：每个阶段描述一个处理单元（传感器、前置放大器、采集器）
PolesAndZeros模拟响应：以极点和零点形式描述
Coefficients数字响应：以系数形式描述 FIR 或 IIR 滤波器
NormalizationFactor归一化因子，用于单位转换
NormalizationFrequency归一化频率（Hz）
Sensor传感器信息：厂商、型号、序列号
Datalogger数据采集器信息：厂商、型号、序列号

方位角（Azimuth）

传感器指向 · 分量旋转的前提

方位角（Azimuth）是台站元数据中最关键的参数之一。 它定义为从正北方向开始，顺时针旋转到传感器水平分量指向的角度， 取值范围为 0°–360°。

为什么方位角至关重要

  • 分量旋转：现代地震学研究通常将三分量记录旋转至 径向（Radial）和切向（Transverse）分量，以分离不同类型的体波。 两个水平分量的方位角信息是保证旋转正确的关键。
  • 震相识别：方位角错误会导致 P 波在切向分量上出现虚假能量， 影响震相识别和震源机制反演。
  • 场地效应分析：在水平-竖向谱比（HVSR）等场地效应方法中， 方位角偏差会影响水平分量的正确合成。

方位角的获取与校正

  • 安装记录：台站安装时使用罗盘测量传感器指向，记录在元数据中。
  • P 波质点运动法：基于远场 P 波质点运动， 通过最小能量法或主成分分析法测定实际方位角。
  • 背景噪声法：利用背景噪声的互相关或极化分析估计方位角偏差。
  • 中国测震站网方位角数据集： 国家地震科学数据中心发布了基于 P 波质点运动测定的 952 个宽频带台站最佳方位角数值解。
方位角与后方位角的区别： 方位角（Azimuth）描述的是传感器指向， 是台站本身的属性；后方位角（Back-Azimuth）描述的是 从台站看向震中的方向，是事件与台站的相对几何关系。 两者含义不同，使用时应明确区分。

仪器响应校正

从 counts 到物理量 · 响应去卷积

仪器响应是描述从地面运动物理量到数字记录 counts 之间传递关系 的数学函数。不进行响应校正，波形数据无法用于物理量分析。

响应描述方式

方式 说明
Poles and Zeros（PAZ）以极点和零点形式描述模拟响应，适用于传感器和模拟滤波器。
Coefficients以系数形式描述数字 FIR 或 IIR 滤波器。
FIR 滤波器有限脉冲响应滤波器，常用于数据采集器的抽取滤波。
Polynomial多项式响应，用于某些特殊传感器。

响应校正流程

1
获取 StationXML 元数据
通过 FDSN station Web 服务下载目标台站的 StationXML 文件。
2
读取波形数据
以 MiniSEED 或 SAC 格式读取原始波形。
3
去除仪器响应
使用 ObsPy 的 remove_response() 方法， 或 SAC 的 transfer 命令进行去卷积。
4
验证结果
检查校正后的波形是否合理（如 PGA 量级、频谱形状）， 并与已知结果对比。
Data Centers

数据中心

台站元数据通过各数据中心提供的 FDSN station Web 服务获取。 全球有 50 多个 FDSN 注册数据中心提供 StationXML 格式的台站元数据， 以下按类别列出其中主要的数据中心，每项均包含格式支持、网站与说明。 完整列表可查阅 FDSN 数据中心注册表。

全球性数据中心

数据覆盖全球 · FDSN station 服务标准

全球性数据中心的台站元数据覆盖世界各地台网，以 FDSN station Web 服务提供统一接口，返回 StationXML 格式。 适合研究区域不固定、或需要跨区域比较的场景。

数据中心 格式支持 网站 说明
IRIS DMC / EarthScope StationXML · 文本 · RESP · SAC PZ service.iris.edu 全球覆盖最广的元数据源。fdsnws-station 服务返回 StationXML v1.1 或文本格式， 支持 level=network/station/channel/response 多层级查询。
GEOFON (GFZ) StationXML · 文本 geofon.gfz.de 德国地球科学研究中心运营，全球宽带地震台网的台站元数据。 FDSN 标准接口，无需注册。
GEOSCOPE StationXML · 文本 geoscope.ipgp.fr 法国全球地震台网，提供全球范围内高质量台站的完整元数据。
EMSC StationXML（转发） emsc-csem.org 欧洲-地中海地震中心，主要提供事件目录和元数据转发服务。
引用注意：使用全球性数据中心的台站元数据时， 应标注原始台网代码（如 IU、II、GE 等）， 而非数据中心本身。

ETH / SED StationXML · 文本 sed.ethz.ch 瑞士地震服务中心。提供瑞士及周边地区高质量台站元数据，FDSN 标准接口。
INGV StationXML · 文本 ingv.it 意大利国家地球物理与火山学研究所。提供意大利及地中海区域密集台站元数据。

亚太区域地震活动性强，数据中心众多。 这些中心的元数据格式和获取方式差异较大，需根据实际需求选择。

其他区域也有各自的数据中心，提供本地台网的元数据。 这些中心多为 FDSN 注册节点，可通过标准 Web 服务访问。

数据获取建议：对于非主要区域的研究， 优先使用 IRIS DMC 或 GEOFON 的全球覆盖； 如需要本地化元数据，可通过 FDSN 注册表查询该区域是否有专属数据中心。
选择数据中心的三个原则： ① 区域优先 — 目标区域覆盖是首要因素，本地中心元数据通常最完整； ② 格式匹配 — 确认中心是否直接提供 StationXML， 或需要额外转换； ③ 引用规范 — 各中心的引用要求不同，使用前应阅读其数据政策。
Flowchart

获取流程

不同数据中心获取台站元数据的流程差异显著。以下以三种典型模式为例， 点击标签查看详细流程。

开放 Web 服务型

IRIS DMC · ORFEUS EIDA · GEOFON

适用于开放数据，通过 FDSN station Web 服务直接调用，无需注册。

1
确定目标数据中心与台站
按研究区域选择数据中心，确定台网、台站、通道和时间范围。
2
调用 FDSN station 服务
构造请求 URL，指定 level=response 获取完整响应信息。 可指定 format=xml 或 format=text。
3
下载元数据
使用浏览器、wget、curl 或 ObsPy 的 obspy.clients.fdsn 下载 StationXML 文件。
4
读取与使用
使用 ObsPy 读取 StationXML，配合波形数据 完成响应校正与分量旋转。

订单审批型

国家地震科学数据中心

适用于需要实名注册与人工审批的国家级数据中心。 以国家地震科学数据中心为例。

1
实名注册
进入数据中心网站，完成实名注册，填写个人信息和单位信息。
2
确定用户等级
普通用户（一级数据）/ 高级用户（二、三级数据，需签字盖章申请）/ 团队用户（需签署协议）。
3
提交数据订单
填写数据订单、使用用途、上传证明材料， 等待人工审核（一般 1 个工作日处理，3–5 天完成）。
4
选择服务方式并获取
在线下载 / 邮件发送 / 硬盘邮寄（大数据量）。 下载台站元数据与方位角数据集。

格式转换型

StationXML → dataless SEED / RESP / SAC PZ

StationXML 是主流格式，但部分旧版软件（如 SAC、rdseed） 需要 dataless SEED、RESP 或 SAC PZ 格式。 此时需进行格式转换。

1
下载 StationXML
通过 FDSN station 服务下载完整的 StationXML 文件。
2
使用转换工具
使用 IRIS 的 StationXML Converter （stationxml-converter）工具进行转换。
3
选择输出格式
可输出为 dataless SEED、 RESP 或 SAC PZ 格式。
4
验证转换结果
检查转换后的响应函数与原始 StationXML 是否一致。

Notes

使用注意事项

  1. 元数据与波形必须匹配： 下载波形时，必须同时获取该台站对应时间段的元数据。 台站配置可能随时间变化（传感器更换、方位角调整等）， 使用过期元数据会导致响应校正错误。
  2. 方位角是分量旋转的前提： 三分量旋转至径向和切向分量时， 两个水平分量的方位角信息是保证旋转正确的关键。 方位角错误会导致 P 波在切向分量上出现虚假能量。
  3. 方位角与后方位角不同： 方位角（Azimuth）是传感器指向的台站属性； 后方位角（Back-Azimuth）是从台站看向震中的方向。 两者含义不同，使用时应明确区分。
  4. 仪器响应必须去除： 原始记录以 counts 为单位存储， 必须使用 StationXML 中的响应函数进行去卷积， 才能得到物理量（加速度、速度、位移）。
  5. StationXML 正在取代 dataless SEED： FDSN 已将 StationXML 作为推荐标准， 主流数据中心均以 StationXML 为主要元数据格式。 如需要 dataless SEED，可使用 StationXML Converter 转换。
  6. 响应层级可选择： FDSN station 服务支持 level 参数， 可选择返回 network、station、 channel 或 response 粒度的结果。 需要完整响应时选择 level=response。
  7. 中国台站方位角有独立数据集： 国家地震科学数据中心发布了基于 P 波质点运动测定的 952 个宽频带台站最佳方位角数值解， 使用中国台站数据时应优先采用该数据集。
  8. 推荐使用 ObsPy： ObsPy 的 obspy.clients.fdsn.Client 可直接从各数据中心获取台站元数据， 并提供 remove_response() 等方法进行响应校正。

引用格式

使用台站元数据时，建议引用 FDSN StationXML 标准文档和具体的数据中心。

FDSN StationXML 标准引用

BibTeX
@misc{FDSNStationXML,
  title        = {FDSN StationXML Schema},
  author       = {{International Federation of Digital Seismograph Networks}},
  howpublished = {\url{https://www.fdsn.org/xml/station/}},
  note         = {A metadata standard for seismological and related data}
}

dataless SEED 标准引用

BibTeX
@techreport{IRIS2012,
  title       = {SEED Reference Manual, Version 2.4},
  author      = {{Incorporated Research Institutions for Seismology}},
  year        = {2012},
  institution = {IRIS Consortium},
  address     = {Seattle, WA}
}

各数据中心的引用要求

数据中心 引用要求
IRIS DMC 引用原始台网代码（如 IU、II、GE 等），而非 IRIS 本身。
ORFEUS EIDA 引用具体的 EIDA 节点及其数据集 DOI（如有）。
国家地震科学数据中心 必须标注“中国地震局工程力学研究所‘国家强震动台网中心’为本研究提供数据支持”。
通用原则：无论使用哪个数据中心，都应在论文中 明确标注元数据来源，并在致谢中感谢数据提供单位。
致谢格式：在论文致谢中，如使用多个数据中心的元数据， 应逐一列出。例如： “台站元数据来自 IRIS DMC 的 IU 台网 StationXML 文件， 以及国家地震科学数据中心的台站方位角数据集。”
