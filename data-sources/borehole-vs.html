钻孔剪切波速剖面

钻孔剪切波速剖面（Borehole Vs Profile）是通过钻孔波速测试获得的 剪切波速度随深度变化的曲线，是场地效应评估、土层反应分析和 Vs30 计算的直接实测依据。相比地形坡度等间接代理方法， 钻孔实测 Vs 剖面精度更高，是场地条件研究中最可靠的基础数据。

场地参数 钻孔实测 Vs 剖面 单孔检层法 CNSDB
Overview

概述

钻孔剪切波速剖面是通过在钻孔中开展波速测试（如单孔检层法、 跨孔法、井下地震法等）获得的剪切波速度（Vs）随深度变化的 实测数据。它直接反映了场地土层的刚度特征， 是场地效应评估、一维土层反应分析、 Vs30 计算和场地分类最可靠的实测依据。

与基于地形坡度等间接代理的 Vs30 外推方法不同， 钻孔实测 Vs 剖面具有更高的精度和可靠性。 然而，钻孔波速测试成本较高、覆盖范围有限， 全球范围内实测 Vs 剖面数据分布不均。 因此，整理和汇编已有的钻孔实测数据 成为场地条件研究的重要基础工作。

主要数据来源

  • 中国场地数据库（CNSDB）：中国地震局工程力学研究所 为 1,450 个国家强震动台站建立的场地参数数据库， 包含推荐 Vs30 值和场地类别，优先采用钻孔实测波速剖面。
  • 中国大陆工程场地钻孔汇编：中国地震局地球物理研究所 收集整理了全国范围内 7,939 个工程场地钻孔数据， 构建了中国大陆场地资料基础数据库。
  • USGS Vs30 汇编：美国地质调查局汇编的美国境内 Vs30 实测数据，包含井下和地表方法估计， 2,997 个场地，其中西部 2,141 个。
  • USGS Vs Profile 数据库：美国社区 Vs 剖面数据库（PDB）， 以 JSON 格式存储场地坐标、Vs 剖面、岩土数据和 HVSR 曲线。
  • PEER NGA 钻孔数据：PEER NGA-West2 数据库中 包含台站场地的 Vs 剖面测试数据。
钻孔实测 vs 坡度外推： 钻孔实测 Vs 剖面精度最高，但覆盖有限； 地形坡度外推可覆盖全球，但在平坦沉积盆地精度较低。 中国 SCK 模型以 7,939 个实测钻孔为主要约束， 在钻孔位置收敛于实测值，兼顾了精度和覆盖。
Format

数据格式

钻孔剪切波速剖面的数据格式因测试方法和数据来源而异。 点击下方标签查看各格式的详细说明。

剖面数据格式

深度-Vs 对应关系 · 最常用的交换格式

钻孔 Vs 剖面最常见的表示方式是深度-速度对应表， 每行包含一个深度点及其对应的剪切波速度。 可存储为 CSV、Excel 或纯文本格式。

字段 单位 说明
钻孔编号—钻孔的唯一标识
深度m测点深度（从孔口起算）
剪切波速 Vsm/s该深度处的剪切波速度
压缩波速 Vpm/s该深度处的压缩波速度（若可得）
层厚m该速度值对应的土层厚度（分层表示时使用）
土类名称—土层类型描述（如填土、粉质黏土、砂岩等）
备注—补充说明
数据组织方式：两种常见形式——分层表示 （每层给出层厚和该层平均 Vs）和逐点表示 （每个测点给出深度和 Vs）。使用前应确认数据采用哪种形式。

LAS 测井格式

Log ASCII Standard · 地球物理测井标准

LAS（Log ASCII Standard）是地球物理和石油工业中 广泛使用的测井数据标准格式。该格式将测井数据分为五个主要部分： 版本信息、井信息、参数信息、曲线数据和 ASCII 测井值。

段落 内容
~VersionLAS 版本信息
~Well井信息：井名、位置、起始深度、终止深度、测量间隔
~Parameter参数信息：测井参数定义
~Curve曲线信息：曲线名称、单位、描述
~ASCII数据区：以空格分隔的数值列
索引通道：LAS 文件中第一个通道为索引通道， 有效名称仅为 DEPT、DEPTH 或 TIME。 读取时需注意该约定。

JSON 数据库格式

USGS PDB 数据模型 · 层级化结构

USGS 提出的地震速度剖面数据库（PDB）数据模型 采用 JSON 格式，以层级化嵌套结构存储元数据和数据。

层级 内容
位置信息经纬度、高程、地表地质、地貌类型、坡度
速度剖面地球物理方法、记录数据类型、建模的 Vp 和 Vs 随深度变化
频散曲线面波方法获取的相速度 vs 波长或频率
岩土数据钻孔柱状图、CPT 触探数据、室内试验结果
HVSR 曲线水平-竖向谱比随频率的变化
最小数据要求：站点纳入数据库的最低元数据要求是 大地坐标和高程，最低数据要求是一条剪切波速度剖面。

数据文件说明

1. 剖面数据字段说明

字段 单位 说明
钻孔编号—钻孔唯一标识
深度m测点深度（从孔口起算）
剪切波速 Vsm/s该深度处的剪切波速度
压缩波速 Vpm/s该深度处的压缩波速度（若可得）

备注—补充说明
中国规范要求：根据相关标准， 剪切波速测试成果数据的数据内容应包括钻孔编号、深度、剪切波速、备注。

2. Vs30 计算方法

Vs30 是从钻孔 Vs 剖面计算得到的核心场地参数， 表示地表以下 30 m 深度内的平均剪切波速。

场景 计算方法
剖面深度 ≥ 30 m 直接取 0–30 m 范围内的加权平均：Vs30 = 30 / Σ(di / Vsi)
剖面深度 < 30 m 使用区域外推模型估计。中国采用基于 6,179 个工程钻孔建立的外推模型
无实测剖面 使用 HVSR 机器学习或地质/地形代理估计
计算公式： Vs30 = 30 / Σ(di / Vsi)，其中 di 为第 i 层厚度，Vsi 为该层剪切波速， 所有层位之和为 30 m。

3. 数据种类总览

数据内容
钻孔编号 深度-Vs 剖面 Vp 剖面 层厚与土类 Vs30 值 场地类别 HVSR 曲线 岩土参数
格式与工具
CSV Excel LAS JSON DBF Python QGIS pandas Excel

4. 数据质量检查要点

  1. 确认剖面深度： 检查剖面是否覆盖至 30 m 深度。若不足 30 m， 需使用外推模型估计 Vs30，并注明所用模型。
  2. 检查数据分级： 部分数据集按数据可靠性和可用性进行了分级。 使用前应确认数据所属等级，优先使用高可靠性等级的数据。
  3. 区分分层与逐点表示： 分层表示给出每层厚度和平均 Vs； 逐点表示给出每个测点的深度和 Vs。 计算 Vs30 时需根据表示方式选择正确方法。
  4. 核实钻孔位置： 确认钻孔坐标与台站坐标一致。 部分数据集包含迁址或更名台站，需注意历史记录的对应关系。
  5. 检查异常值： 检查 Vs 随深度是否单调递增（一般情况下）， 识别可能的测试错误或数据录入错误。
  6. 版本管理与可复现性： 论文中应注明所用数据集版本、钻孔编号和下载日期。
Notes

使用注意事项

  1. 钻孔实测精度最高： 钻孔波速测试直接测量土层刚度， 精度远高于地形坡度等间接代理方法。 场地效应研究和土层反应分析应优先使用实测剖面。
  2. 剖面深度不足时的处理： 若剖面深度不足 30 m，需使用外推模型估计 Vs30。 中国采用基于 6,179 个工程钻孔建立的专属外推模型。
  3. 数据可靠性分级： 部分数据集对钻孔资料按可靠性和可用性进行了分级。 使用前应确认数据等级，避免使用低质量数据。
  4. LAS 格式的索引通道： LAS 文件中第一个通道为索引通道， 有效名称仅为 DEPT、DEPTH 或 TIME。 读取时需注意该约定。
  5. JSON 数据库的最小要求： USGS PDB 要求站点至少提供大地坐标、高程和一条 Vs 剖面。 使用前应检查数据完整性。
  6. 中国数据优先本土来源： 中国大陆区域的钻孔数据应优先使用 CNSDB、 SCK 模型钻孔数据或中国西部台站数据， 其覆盖范围和精度优于国际数据集。
  7. 许可协议不同： USGS 数据为美国联邦政府公共领域； 中国 SCK 模型 2024 版为 CC BY 许可； CNSDB 为开源数据集。 使用时须遵守各自条款。
  8. 版本管理： 各数据集持续更新，论文中应注明版本号、钻孔编号和下载日期， 确保分析结果可复现。
