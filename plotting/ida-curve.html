IDA 曲线

增量动力分析（Incremental Dynamic Analysis，IDA）曲线： 多条地震波在逐渐增大的强度下，结构损伤指标 DM（通常为最大层间位移角）随强度指标 IM（通常为 Sa(T1)）的变化曲线。 页面上叠加 16% / 50% / 84% 分位曲线， 并给出倒塌裕度比 CMR，是结构抗倒塌能力评估的标准方法。

CSV Input

输入数据格式

本页读取 assets/ida_curves.csv 作为输入。 文件是 IDA 分析结果的整理输出：宽格式表格， 第一列为强度指标 IM，后续每列对应一条地震波的损伤指标 DM。 若文件不存在，页面会使用内置的合成数据演示。

CSV 格式说明

列名 物理量 单位 说明

列数可以任意扩展——增加一条地震波就增加一列。程序会自动识别列数。

数据来源

  • 弹塑性时程分析——OpenSees、Perform-3D、ABAQUS、 MIDAS、ETABS（非线性版本），对每条地震波做多个强度水平的时程分析。
  • 调幅方案——常用的有两种： 等步长（0.1 g, 0.2 g, 0.3 g …）和 变步长（hunt & fill）（先粗后细，效率更高）。
  • 选波要求——通常 10–20 条实际地震记录， 与场地条件匹配，符合规范选波要求。
  • 倒塌判定——DM 超过倒塌阈值（通常 4%–5% 层间位移角）， 或动力失稳、求解不收敛。
本页示例是一个 7 条地震波的 IDA 结果： IM 从 0.05 g 到 1.0 g，DM 从 0.001 增大到约 0.05。 50% 分位曲线在 0.4 g 附近屈服， 在 1.0 g 处达到 0.048；16% / 84% 分位 反映曲线间的离散程度。替换为你自己的 IDA 结果只需修改 ida_curves.csv。
Meaning

这张图说明了什么

增量动力分析（IDA）由 Vamvatsikos 与 Cornell（2002）提出， 通过对每条地震波逐步增大强度，反复做弹塑性时程分析， 得到结构从弹性到倒塌的完整行为。每一条波产生一条 IDA 曲线， 多条曲线叠加后给出结构抗倒塌能力的统计特征。

两个关键指标

指标 符号 说明
强度指标（IM） Sa(T1) 第一振型谱加速度，单位 g。反映地震动强度。
损伤指标（DM） θmax 最大层间位移角，无量纲。反映结构损伤程度。

IDA 曲线的三段特征

  • 弹性段——所有构件保持弹性，IM 与 DM 近似线性， 曲线在双对数坐标下斜率约为 1。
  • 屈服段——部分构件屈服，刚度退化， 曲线开始弯曲，斜率逐渐减小。
  • 倒塌段——结构接近或达到倒塌， DM 急剧增大，曲线几乎水平或略微下降。

16% / 50% / 84% 分位曲线

对每一个 IM 水平，把各条地震波的 DM 值排序，取三个分位：

  • 50% 分位——中位曲线，代表典型结构行为；
  • 16% 分位——下界曲线，代表有利情况；
  • 84% 分位——上界曲线，代表不利情况。

16% 与 84% 分位之间大致对应±1 倍对数标准差的范围。 如果三条曲线间距越大，说明结构对不同地震波的敏感度越高， 地震动不确定性越大。

倒塌裕度比 CMR

倒塌裕度比（Collapse Margin Ratio）定义为：

CMR = Sa中位倒塌容量 / SaMCE

即50% 分位倒塌容量与最大考虑地震（MCE） 对应强度的比值。CMR 越大，结构抗倒塌储备越高。 FEMA P695 要求 CMR 不低于 1.5–2.5（取决于结构类型）。

倒塌容量的定义： 通常取 50% 分位曲线首次达到 DM = 0.04（或 0.05）时的 IM 值。 也可以用曲线斜率的退化（切线刚度降到初始的 20%）来定义。 不同定义下的 CMR 略有差异，报告中必须说明。
注意：IDA 需要大量弹塑性时程分析， 计算成本很高。对于中等规模结构， 通常 10 条波 × 15 个强度水平 = 150 次时程分析。 实际工程中可用简化 IDA（如 MPA-based） 或云图法（不调幅，用多波随机 IM）替代。

Python

Python 代码

依赖 numpy 与 matplotlib。 核心步骤：读取 CSV → 逐 IM 水平计算 16/50/84 分位 → 绘制各波曲线与分位曲线 → 计算中位倒塌容量与 CMR。 CSV 文件不存在时自动生成合成数据。

ida-curve.pyPython
# =============================================================
# IDA 曲线 | 增量动力分析
# -------------------------------------------------------------
# 输入数据：ida_curves.csv
#   Sa_g,wave1,wave2,...,waveN
#   0.05,0.00095,0.00110,...
#   ...
#   单位：Sa_g (g)，DM 无量纲（最大层间位移角）
# -------------------------------------------------------------
# 功能：
#   1. 读取 CSV（自动识别地震波列数）
#   2. 逐 IM 计算 16% / 50% / 84% 分位
#   3. 绘制各波 + 分位 + 倒塌阈值
#   4. 计算中位倒塌容量与 CMR
# =============================================================

import os
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

CSV_FILE = 'ida_curves.csv'
COLLAPSE_DRIFT = 0.04           # 倒塌阈值（4% 层间位移角）
MCE_SA = 0.60                   # 最大考虑地震 Sa(T1)，用于 CMR 计算


def generate_synthetic():
    """CSV 缺失时生成合成 IDA 数据。"""
    Sa = np.array([0.05, 0.10, 0.15, 0.20, 0.30,
                   0.40, 0.50, 0.70, 1.00])

    # 7 条波，带随机变化
    rng = np.random.default_rng(42)
    waves = []
    for _ in range(7):
        # 基础形状
        base = np.array([0.00095, 0.00190, 0.00290, 0.00480, 0.00870,
                         0.01360, 0.01920, 0.03080, 0.04800])
        # ±15% 随机变化
        factor = 1.0 + 0.15 * (rng.random(len(Sa)) - 0.5) * 2
        waves.append(base * factor)
    return Sa, waves


# ---- 1. 读取 CSV ----
if os.path.exists(CSV_FILE):
    data = np.genfromtxt(CSV_FILE, delimiter=',', names=True,
                         dtype=None, encoding='utf-8')
    Sa = np.asarray(data['Sa_g'], dtype=float)
    wave_names = [n for n in data.dtype.names if n != 'Sa_g']
    DM = np.column_stack([np.asarray(data[n], dtype=float)
                          for n in wave_names])
    print(f'从 {CSV_FILE} 读取 {len(Sa)} 个 IM、{len(wave_names)} 条波')
else:
    print(f'{CSV_FILE} 不存在，使用合成数据演示')
    Sa, wave_list = generate_synthetic()
    DM = np.column_stack(wave_list)
    wave_names = [f'wave{i+1}' for i in range(DM.shape[1])]


# ---- 2. 逐 IM 计算分位数 ----
p16 = np.percentile(DM, 16, axis=1)
p50 = np.percentile(DM, 50, axis=1)
p84 = np.percentile(DM, 84, axis=1)

print(f'\n每个 IM 水平的分位数：')
for i, sa in enumerate(Sa):
    print(f'  Sa = {sa:.2f} g：16% = {p16[i]:.4f}, '
          f'50% = {p50[i]:.4f}, 84% = {p84[i]:.4f}')


# ---- 3. 中位倒塌容量与 CMR ----
def interp_collapse(Sa, DM_curve, threshold):
    """插值求 DM 首次达到 threshold 对应的 Sa。"""
    for i in range(1, len(DM_curve)):
        if DM_curve[i] >= threshold:
            # 在 (Sa[i-1], Sa[i]) 之间线性插值
            x1, x2 = Sa[i-1], Sa[i]
            y1, y2 = DM_curve[i-1], DM_curve[i]
            return x1 + (threshold - y1) / (y2 - y1) * (x2 - x1)
    return None


Sa_collapse = interp_collapse(Sa, p50, COLLAPSE_DRIFT)
print(f'\n50% 分位倒塌容量：Sa_c = {Sa_collapse:.3f} g')
print(f'MCE 强度：Sa_MCE = {MCE_SA:.3f} g')

if Sa_collapse is not None:
    CMR = Sa_collapse / MCE_SA
    print(f'倒塌裕度比：CMR = {CMR:.3f}')
else:
    CMR = None
    print('未达到倒塌阈值，无法计算 CMR')


# ---- 4. 绘图（A4 尺寸 7.2 × 5.6 in） ----
fig, ax = plt.subplots(figsize=(7.2, 5.6))

# 各条波（灰色细线）
for i in range(DM.shape[1]):
    ax.plot(Sa, DM[:, i], '-', color='#cccccc', lw=0.9,
            alpha=0.75, zorder=1)

# 分位曲线
ax.plot(Sa, p16, '--', color='#2563eb', lw=1.8,
        label='16th percentile', zorder=3)
ax.plot(Sa, p50, '-',  color='#b45309', lw=2.6,
        label='50th percentile (median)', zorder=4)
ax.plot(Sa, p84, '--', color='#9333ea', lw=1.8,
        label='84th percentile', zorder=3)

# 倒塌阈值线
ax.axhline(COLLAPSE_DRIFT, color='#dc2626', lw=1.0, ls=':',
           label=f'Collapse threshold = {COLLAPSE_DRIFT:.2f}')

# 标注中位倒塌容量
if Sa_collapse is not None:
    ax.plot(Sa_collapse, COLLAPSE_DRIFT, '*',
            color='#dc2626', ms=16, mec='#222222', mew=0.8,
            zorder=10)
    ax.annotate(
        f'Median collapse capacity\nSa_c = {Sa_collapse:.3f} g\n'
        f'CMR = {CMR:.2f}',
        xy=(Sa_collapse, COLLAPSE_DRIFT),
        xytext=(Sa_collapse * 0.32, COLLAPSE_DRIFT * 0.42),
        fontsize=9, color='#dc2626',
        arrowprops=dict(arrowstyle='->', color='#dc2626', lw=0.8))

# 坐标轴
ax.set_xscale('log')
ax.set_xlabel('Intensity measure  Sa(T$_1$)  (g)')
ax.set_ylabel('Damage measure  —  maximum inter-story drift')
ax.set_title('IDA curves and percentiles', fontsize=11)
ax.set_xlim(Sa.min() * 0.85, Sa.max() * 1.15)
ax.set_ylim(0, max(DM.max() * 1.12, COLLAPSE_DRIFT * 1.3))
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='upper left', fontsize=9, frameon=False)
ax.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('ida-curve.png', dpi=300, bbox_inches='tight')
plt.show()
关键点：
  • 自动识别列数：data.dtype.names 会自动读取所有波， 增加波只需在 CSV 里增加一列。
  • 分位数计算：np.percentile(DM, 16, axis=1) 沿波方向计算每个 IM 水平的 16% 分位数。
  • 横轴对数：IM 跨越一个量级以上时用对数坐标更清晰。
  • 倒塌容量：用线性插值精确求 DM = 0.04 时的 Sa。
  • CMR：需要给定 MCE 强度（本页取 0.60 g）， 实际工程按场地危险性确定。

MATLAB 代码

ida-curve.mMATLAB
% =============================================================
% IDA 曲线 | 增量动力分析
% -------------------------------------------------------------
% 输入数据：ida_curves.csv
%   Sa_g,wave1,wave2,...,waveN
%   单位：Sa_g (g)，DM 无量纲
% =============================================================

CSV_FILE = 'ida_curves.csv';
COLLAPSE_DRIFT = 0.04;
MCE_SA = 0.60;

% ---- 1. 读取 CSV ----
if isfile(CSV_FILE)
    T = readtable(CSV_FILE, 'CommentStyle', '#', ...
                  'VariableNamingRule', 'preserve');
    Sa = T.Sa_g;
    wave_names = T.Properties.VariableNames(2:end);
    DM = table2array(T(:, 2:end));
    fprintf('从 %s 读取 %d 个 IM、%d 条波\n', ...
            CSV_FILE, numel(Sa), numel(wave_names));
else
    fprintf('%s 不存在，使用合成数据演示\n', CSV_FILE);
    Sa = [0.05 0.10 0.15 0.20 0.30 0.40 0.50 0.70 1.00]';
    base = [0.00095 0.00190 0.00290 0.00480 0.00870 ...
            0.01360 0.01920 0.03080 0.04800]';
    rng(42);
    DM = zeros(numel(Sa), 7);
    for i = 1:7
        DM(:, i) = base .* (1 + 0.15 * (rand(numel(Sa), 1) - 0.5) * 2);
    end
    wave_names = {'wave1', 'wave2', 'wave3', 'wave4', ...
                  'wave5', 'wave6', 'wave7'};
end

% ---- 2. 逐 IM 计算分位数 ----
p16 = prctile(DM, 16, 2);
p50 = prctile(DM, 50, 2);
p84 = prctile(DM, 84, 2);

fprintf('\n每个 IM 水平的分位数：\n');
for i = 1:numel(Sa)
    fprintf('  Sa = %.2f g: 16%% = %.4f, 50%% = %.4f, 84%% = %.4f\n', ...
            Sa(i), p16(i), p50(i), p84(i));
end

% ---- 3. 中位倒塌容量与 CMR ----
idx = find(p50 >= COLLAPSE_DRIFT, 1, 'first');
if ~isempty(idx) && idx > 1
    x1 = Sa(idx-1); x2 = Sa(idx);
    y1 = p50(idx-1); y2 = p50(idx);
    Sa_collapse = x1 + (COLLAPSE_DRIFT - y1) / (y2 - y1) * (x2 - x1);
    CMR = Sa_collapse / MCE_SA;
    fprintf('\n50%% 分位倒塌容量：Sa_c = %.3f g\n', Sa_collapse);
    fprintf('倒塌裕度比：CMR = %.3f\n', CMR);
else
    Sa_collapse = NaN; CMR = NaN;
    fprintf('未达到倒塌阈值\n');
end

% ---- 4. 绘图（A4 尺寸 720 × 560 px） ----
figure('Color', 'w', 'Position', [100 100 720 560]);
hold on;

% 各条波（灰色细线）
for i = 1:size(DM, 2)
    semilogx(Sa, DM(:, i), '-', 'Color', [0.8 0.8 0.8], ...
             'LineWidth', 0.9, 'HandleVisibility', 'off');
end

% 分位曲线
semilogx(Sa, p16, '--', 'Color', [0.15 0.39 0.92], ...
         'LineWidth', 1.8, 'DisplayName', '16th percentile');
semilogx(Sa, p50, '-', 'Color', [0.71 0.33 0.04], ...
         'LineWidth', 2.6, 'DisplayName', '50th percentile (median)');
semilogx(Sa, p84, '--', 'Color', [0.58 0.20 0.92], ...
         'LineWidth', 1.8, 'DisplayName', '84th percentile');

% 倒塌阈值线
yline(COLLAPSE_DRIFT, ':', 'Color', [0.86 0.15 0.15], ...
      'LineWidth', 1.0, 'DisplayName', ...
      sprintf('Collapse threshold = %.2f', COLLAPSE_DRIFT));

% 标注中位倒塌容量
if ~isnan(Sa_collapse)
    plot(Sa_collapse, COLLAPSE_DRIFT, 'p', ...
         'MarkerSize', 16, 'MarkerFaceColor', [0.86 0.15 0.15], ...
         'MarkerEdgeColor', [0.13 0.13 0.13], 'LineWidth', 0.8, ...
         'HandleVisibility', 'off');
    text(Sa_collapse * 0.32, COLLAPSE_DRIFT * 0.42, ...
         sprintf('Median collapse\nSa_c = %.3f g\nCMR = %.2f', ...
                 Sa_collapse, CMR), ...
         'FontSize', 9, 'Color', [0.86 0.15 0.15]);
end

xlabel('Intensity measure  Sa(T_1)  (g)');
ylabel('Damage measure  —  maximum inter-story drift');
title('IDA curves and percentiles', 'FontSize', 11);
xlim([min(Sa) * 0.85, max(Sa) * 1.15]);
ylim([0, max(max(DM(:)) * 1.12, COLLAPSE_DRIFT * 1.3)]);
grid on; box on;
set(gca, 'XScale', 'log', 'FontName', 'Times New Roman', ...
    'FontSize', 10, 'TickDir', 'in');
legend('Location', 'northwest', 'Box', 'off', 'FontSize', 9);

exportgraphics(gcf, 'ida-curve.png', 'Resolution', 300);
Notes

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 强度指标Sa(T1)g
输入 · 损伤指标θmax无量纲（层间位移角）
输出 · 16% 分位θ16(IM)无量纲
输出 · 50% 分位θ50(IM)无量纲
输出 · 84% 分位θ84(IM)无量纲
输出 · 中位倒塌容量Sa,cg
输出 · 倒塌裕度比CMR无量纲
  • IDA 定义：对每条地震波逐步增大强度， 反复做弹塑性时程分析，得到完整的 IM–DM 曲线。
  • IM 选择：常用 Sa(T1)、 Sa,avg(T1–T2)、 PGV 等。Sa(T1) 最常用，因为与结构响应相关性最好。
  • DM 选择：常用最大层间位移角、屋顶位移、 残余位移等。θmax 最常用，因为与倒塌直接相关。
  • 调幅方案：等步长（简单但浪费计算）， 变步长（hunt & fill，效率高）。
  • 分位数：16% / 50% / 84% 对应 对数正态分布的±1 倍对数标准差。
  • 倒塌容量：通常取 DM = 0.04 或 0.05 对应的 IM，或用斜率退化（切线刚度 < 20% 初始刚度）定义。
  • CMR：中位倒塌容量与 MCE 强度的比值。 FEMA P695 要求不同结构类型的 CMR 不低于 1.5–2.5。
  • 常见问题：
    • 曲线不单调 → 检查时程分析是否收敛，或调幅方案是否有重复点。
    • 分位数曲线不光滑 → 地震波数量太少， 建议 10 条以上；或 IM 水平太少。
    • 某条波明显偏离 → 该波的频谱与结构自振周期接近， 属正常现象，需保留。
    • 中位倒塌容量 < MCE → 结构抗倒塌能力不足，需重新设计。
