地震动参数对比

读取同一台站三个分量（EW / NS / UP）的加速度记录，分别计算 PGA、PGV、PGD、Arias 强度、有效持时 D5-95 五项常用参数，以五个独立子图并列展示横向对比。 这是《强震动观测》与《工程地震学》中参数统计分析的标准图件。

工程地震 参数统计 分组柱状 Python / MATLAB A4 尺寸
Input Format

输入数据格式

本模板读取三个分量文件（EW / NS / UP），每个文件均为两列文本 （空格、制表符或逗号分隔），与 El Centro、SAC ASCII 等地震记录格式一致。 三个文件的量纲必须一致。

输入文件要求（每个文件格式相同）

列号物理量 推荐单位说明
第 1 列时间 ts（秒）等间隔。程序用相邻两点之差推算采样步长 dt。
第 2 列地面加速度 agg（重力加速度）也可为 m/s² 或 gal（cm/s²）。

三个文件命名约定

分量 文件名 说明
EW（东西向）elcentro_EW.txt水平主方向
NS（南北向）elcentro_NS.txt水平次方向
UP（竖向）elcentro_UP.txt竖直方向

常用量纲的换算（三个文件使用同一单位）

你的数据单位 换算到 m/s² 代码里怎么写
g× 9.80665a = a * 9.80665
m/s²× 1a = a
gal（cm/s²）× 0.01a = a * 0.01
mm/s²× 0.001a = a * 0.001
本页示例 三个文件均位于 assets/ 目录下，第 2 列单位是 g。 代码不做去均值、不去线性趋势，直接对原始记录计算参数。

Meaning

这张图说明了什么

地震动参数是描述地震动强度、能量与频率特征的定量指标。同一台站的三个分量 因方向不同，其参数值差别显著——尤其竖向分量（UP）通常只有水平分量的 1/2 到 2/3。把这些参数横向并列，可以：

  • 比较不同分量的强度差异（PGA、PGV、PGD）；
  • 比较不同分量的能量水平（Arias 强度 IA）；
  • 比较不同分量的持时特征（有效持时 D5-95）；
  • 为结构抗震分析选择合适的输入分量提供依据。

五个参数的物理意义

  • PGA（Peak Ground Acceleration）——峰值地面加速度，单位 g 或 m/s²。 最常用的地震动强度指标，直接对应结构的惯性力。
  • PGV（Peak Ground Velocity）——峰值地面速度，单位 cm/s。 与地震动能量密切相关，在中长周期段比 PGA 更能反映地震动破坏能力。
  • PGD（Peak Ground Displacement）——峰值地面位移，单位 cm。 反映长周期地震动的位移需求，是长周期结构与隔震设计的关键量。
  • Arias 强度 IA——IA = π/(2g) · ∫ a² dt，单位 m/s。 综合反映地震动的总能量，是连接地震动与结构损伤的重要指标。
  • 有效持时 D5-95——基于 Husid 曲线 5%–95% 能量区间，单位 s。 反映地震动主要能量释放的时间长度，与结构的累积损伤直接相关。
为什么分五个子图？ 五个参数的单位不同（g / cm/s / cm / m/s / s），数值量级也相差很多 （如 PGA 约 0.3，Arias 强度约 1.5）。放在同一坐标轴上无法对比， 所以每个参数用独立的子图，各自有对应的纵轴刻度。
注意：本页不做去均值处理。原始记录的直流偏置会同时影响 PGV、PGD 与 Arias 强度的绝对值，尤其 PGD 可能因积分漂移明显偏大。 工程应用中通常需要先做基线校正。

Python

Python 代码

依赖 numpy 与 matplotlib。核心步骤： 分别读取三个分量 → 单位换算 → 计算五项参数 → 五个子图分组柱状对比。 不做去均值、不去线性趋势。

gm-params.pyPython
# =============================================================
# 输入数据格式（三个分量文件，每个文件两列文本）
#   第 1 列：时间 t   —— 单位 s（秒），等间隔
#   第 2 列：加速度 a —— 单位 g（重力加速度）
# -------------------------------------------------------------
# 文件名约定：
#   elcentro_EW.txt   东西向
#   elcentro_NS.txt   南北向
#   elcentro_UP.txt   竖向
# -------------------------------------------------------------
# 如果你的加速度列不是 g，请在下方 DATA_UNIT 处选择：
#   'g'     → 第 2 列单位 g   （× 9.80665 → m/s²）
#   'm/s2'  → 第 2 列单位 m/s²（× 1）
#   'gal'   → 第 2 列单位 cm/s²（× 0.01）
#   'mm/s2' → 第 2 列单位 mm/s²（× 0.001）
# -------------------------------------------------------------
# 说明：本脚本不做去均值、不去线性趋势。
# =============================================================
DATA_UNIT = 'g'

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

g = 9.80665
unit_factor = {'g': g, 'm/s2': 1.0, 'gal': 0.01, 'mm/s2': 0.001}
factor = unit_factor.get(DATA_UNIT, g)


def compute_params(filename, factor, g):
    """读取两列文本并计算五项地震动参数。

    返回 dict：PGA(g), PGV(cm/s), PGD(cm), Ia(m/s), D595(s)
    """
    t, a_raw = np.loadtxt(filename, unpack=True)
    dt = t[1] - t[0]

    # 单位换算到 m/s²（不做去均值）
    a = a_raw * factor

    # ---- 峰值加速度 ----
    pga = np.max(np.abs(a))

    # ---- 梯形积分 → 速度、位移 ----
    v = np.concatenate([[0], np.cumsum((a[1:] + a[:-1]) / 2) * dt])
    d = np.concatenate([[0], np.cumsum((v[1:] + v[:-1]) / 2) * dt])

    pgv = np.max(np.abs(v))
    pgd = np.max(np.abs(d))

    # ---- Arias 强度 ----
    Ia = np.pi / (2 * g) * np.sum(a ** 2) * dt

    # ---- 有效持时 D5-95（基于 Husid 曲线） ----
    a2 = a ** 2
    I = np.concatenate([[0], np.cumsum((a2[1:] + a2[:-1]) / 2) * dt])
    H = I / I[-1]
    i5  = np.argmax(H >= 0.05)
    i95 = np.argmax(H >= 0.95)
    D595 = t[i95] - t[i5]

    return {
        'PGA':   pga / g,       # g
        'PGV':   pgv * 100,     # cm/s
        'PGD':   pgd * 100,     # cm
        'Ia':    Ia,            # m/s
        'D595':  D595,          # s
    }


# ---- 1. 分别计算三个分量的参数 ----
files = {
    'EW': 'elcentro_EW.txt',
    'NS': 'elcentro_NS.txt',
    'UP': 'elcentro_UP.txt',
}
params = {name: compute_params(fname, factor, g)
          for name, fname in files.items()}

# ---- 2. 准备绘图 ----
keys   = ['PGA', 'PGV', 'PGD', 'Ia', 'D595']
labels = ['PGA', 'PGV', 'PGD', 'Ia', 'D5-95']
units  = ['g',   'cm/s', 'cm', 'm/s', 's']
comps  = list(files.keys())
colors = ['#b45309', '#2563eb', '#15803d']

# ---- 3. 5 个子图（2 行 × 3 列，最后一格留空） ----
fig, axes = plt.subplots(2, 3, figsize=(8.0, 5.4))
axes = axes.flatten()

for i, (key, label, unit) in enumerate(zip(keys, labels, units)):
    ax = axes[i]
    vals = [params[name][key] for name in comps]
    bars = ax.bar(comps, vals, color=colors, width=0.6,
                  edgecolor='#222222', linewidth=0.6)

    # 柱条上方标注数值
    for j, v in enumerate(vals):
        ax.text(j, v, f'{v:.3g}', ha='center', va='bottom', fontsize=8.5)

    ax.set_title(f'{label} ({unit})', fontsize=10)
    ax.set_ylim(0, max(vals) * 1.25)
    ax.grid(True, axis='y', ls=':', lw=0.4, alpha=0.6)
    ax.tick_params(direction='in', which='both', top=True, right=True)

# 隐藏最后一个空格
axes[-1].axis('off')

fig.tight_layout()
fig.savefig('gm-params.png', dpi=300, bbox_inches='tight')
plt.show()

# ---- 4. 打印参数一览 ----
for name in comps:
    p = params[name]
    print(f'{name}: PGA={p["PGA"]:.3f} g, PGV={p["PGV"]:.2f} cm/s, '
          f'PGD={p["PGD"]:.2f} cm, Ia={p["Ia"]:.3f} m/s, '
          f'D5-95={p["D595"]:.2f} s')
关键点：
  • 输入量纲：三个文件均为 时间 s + 加速度 g（默认）。
  • 参数计算：
    • PGA = max|a|，转 g
    • PGV = max|v|，v 由 a 梯形积分，转 cm/s
    • PGD = max|d|，d 由 v 梯形积分，转 cm
    • Ia = π/(2g) · Σa²·dt
    • D5-95 基于 Husid 曲线的 5%–95% 区间
  • 柱条颜色：EW 用 #b45309，NS 用 #2563eb，UP 用 #15803d。
  • 不做去均值、不去线性趋势。
MATLAB

MATLAB 代码

用 readmatrix 读取三个分量文件，bar 绘制分组柱状图。 不去均值、不去趋势。

gm-params.mMATLAB
% =============================================================
% 输入数据格式（三个分量文件，每个文件两列文本）
%   第 1 列：时间 t   —— 单位 s（秒），等间隔
%   第 2 列：加速度 a —— 单位 g（重力加速度）
% -------------------------------------------------------------
% 文件名约定：
%   elcentro_EW.txt   东西向
%   elcentro_NS.txt   南北向
%   elcentro_UP.txt   竖向
% -------------------------------------------------------------
% 如果你的加速度列不是 g，请在下方 DATA_UNIT 处选择：
%   'g'     → × 9.80665
%   'm/s2'  → × 1
%   'gal'   → × 0.01
%   'mm/s2' → × 0.001
% -------------------------------------------------------------
% 说明：本脚本不做去均值、不去线性趋势。
% =============================================================
DATA_UNIT = 'g';

g = 9.80665;
switch DATA_UNIT
    case 'g',     factor = g;
    case 'm/s2',  factor = 1.0;
    case 'gal',   factor = 0.01;
    case 'mm/s2', factor = 0.001;
    otherwise,    factor = g;
end

% ---- 1. 读取三个分量并计算参数 ----
files = {'elcentro_EW.txt', 'elcentro_NS.txt', 'elcentro_UP.txt'};
comps = {'EW', 'NS', 'UP'};
nComp = numel(files);

params = struct('PGA', cell(1, nComp), 'PGV', cell(1, nComp), ...
                'PGD', cell(1, nComp), 'Ia',  cell(1, nComp), ...
                'D595', cell(1, nComp));

for k = 1:nComp
    data = readmatrix(files{k});
    t  = data(:, 1);
    a_raw = data(:, 2);
    dt = t(2) - t(1);

    a = a_raw * factor;        % m/s²

    % 峰值加速度
    pga = max(abs(a));

    % 梯形积分 → 速度、位移
    v = [0; cumsum((a(2:end) + a(1:end-1)) / 2) * dt];
    d = [0; cumsum((v(2:end) + v(1:end-1)) / 2) * dt];

    pgv = max(abs(v));
    pgd = max(abs(d));

    % Arias 强度
    Ia = pi / (2 * g) * sum(a .^ 2) * dt;

    % 有效持时 D5-95
    a2 = a .^ 2;
    I  = [0; cumsum((a2(2:end) + a2(1:end-1)) / 2) * dt];
    H  = I / I(end);
    i5  = find(H >= 0.05, 1, 'first');
    i95 = find(H >= 0.95, 1, 'first');
    D595 = t(i95) - t(i5);

    params(k).PGA  = pga / g;
    params(k).PGV  = pgv * 100;
    params(k).PGD  = pgd * 100;
    params(k).Ia   = Ia;
    params(k).D595 = D595;
end

% ---- 2. 准备绘图数据 ----
keys   = {'PGA', 'PGV', 'PGD', 'Ia', 'D595'};
labels = {'PGA', 'PGV', 'PGD', 'Ia', 'D_5_9_5'};
units  = {'g', 'cm/s', 'cm', 'm/s', 's'};
colors = [0.71 0.33 0.04; 0.15 0.39 0.92; 0.08 0.50 0.24];

% ---- 3. 五个子图（2 行 × 3 列，最后一格留空） ----
figure('Color', 'w', 'Position', [100 100 800 540]);

for i = 1:5
    subplot(2, 3, i);
    key = keys{i};

    vals = zeros(1, nComp);
    for k = 1:nComp
        vals(k) = params(k).(key);
    end

    b = bar(vals, 'FaceColor', 'flat', 'EdgeColor', [0.13 0.13 0.13], ...
            'LineWidth', 0.6);
    for k = 1:nComp
        b.CData(k, :) = colors(k, :);
    end

    % 柱条上方标注数值
    for k = 1:nComp
        text(k, vals(k), sprintf('%.3g', vals(k)), ...
             'HorizontalAlignment', 'center', ...
             'VerticalAlignment', 'bottom', 'FontSize', 8.5);
    end

    title(sprintf('%s (%s)', labels{i}, units{i}), 'FontSize', 10);
    set(gca, 'XTickLabel', comps, 'FontName', 'Times New Roman', ...
        'FontSize', 10, 'TickDir', 'in');
    ylim([0, max(vals) * 1.25]);
    grid on; box on;
end

exportgraphics(gcf, 'gm-params.png', 'Resolution', 300);

% ---- 4. 打印参数一览 ----
for k = 1:nComp
    p = params(k);
    fprintf('%s: PGA=%.3f g, PGV=%.2f cm/s, PGD=%.2f cm, Ia=%.3f m/s, D5-95=%.2f s\n', ...
            comps{k}, p.PGA, p.PGV, p.PGD, p.Ia, p.D595);
end
Notes

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 时间ts（秒）
输入 · 加速度agg / m/s² / gal / mm/s²
输出 · 峰值加速度PGAg
输出 · 峰值速度PGVcm/s
输出 · 峰值位移PGDcm
输出 · Arias 强度IAm/s
输出 · 有效持时D5-95s
  • 峰值参数：PGA、PGV、PGD 分别取绝对值最大。PGV、PGD 由梯形积分从加速度得到。
  • Arias 强度：IA = π/(2g) · Σa²·dt，直接反映地震动总能量。
  • 有效持时：D5-95 基于 Husid 曲线，从 5% 能量累积点到 95% 能量累积点。
  • 为什么用五个子图：五个参数单位不同（g / cm/s / cm / m/s / s），数值量级也相差很多，放在同一坐标轴上无法对比。
  • 无去均值、无去趋势：直接使用原始记录。PGD 与 Arias 强度可能因积分漂移而偏大。
  • 常见问题：
    • 所有参数整体偏小或偏大 10³ 量级 → 输入加速度单位选错了。
    • UP 分量 PGA 明显偏小 → 这是正常现象，竖向加速度通常约为水平的 1/3–2/3。
    • PGD 异常大 → 原始记录含明显低频漂移，工程应用中需先做基线校正。
    • 某个分量文件缺失 → 在线预览会跳过该分量，只显示成功加载的部分。
