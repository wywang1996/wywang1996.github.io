台站与事件元数据

事件元数据（Event Metadata）描述地震事件的震源参数，包括发震时刻、震中位置、 震源深度、震级及其标度等。它与台站元数据共同构成地震目录（Earthquake Catalog）， 是地震活动性分析、危险性计算与强震动记录选取的基础。

事件元数据 地震目录 震源参数 QuakeML CSV / XML
Overview

概述

事件元数据是描述地震事件震源信息的结构化数据。 每条记录对应一次地震事件，包含发震时刻、震中经纬度、震源深度、 震级及标度类型、定位精度、断层机制等参数。 事件元数据与台站元数据共同构成地震目录（Earthquake Catalog）， 是地震活动性分析、地震危险性计算、强震动记录选取等一系列工作的基础输入。

全球有多个机构编制和发布地震目录，其中 ISC（国际地震中心）、 USGS ANSS（美国地质调查局）、EMSC （欧洲-地中海地震中心）、中国地震台网中心（CENC） 等是最主要的目录来源。各机构在定位方法、震级标度、完整震级阈值、 更新策略上差异显著，跨目录使用时需注意一致性问题。

事件元数据的核心组成

  • 发震时刻：事件起始时间（UTC），精度从秒到毫秒不等。
  • 震中位置：震中经纬度、定位误差椭圆、定位方法。
  • 震源深度：从地表到震源的距离（km）， 通常采用固定深度或自由深度解算。
  • 震级与标度：包括矩震级 Mw、面波震级 Ms、 体波震级 mb、地方震级 ML、持续时间震级 Md 等。
  • 断层机制：走向、倾角、滑动角，或矩张量解。
  • 定位精度：水平定位误差、深度误差、台站数量、方位角间隙。
事件元数据与台站元数据的区别： 台站元数据描述观测系统（台站、通道、仪器响应）， 事件元数据描述震源参数（时刻、位置、震级）。 两者共同决定记录的空间-时间关联， 是地震目录与波形数据能够正确配套使用的前提。
Format

数据格式

事件元数据有多种格式，从简明的 CSV 到结构化的 QuakeML。 点击下方标签查看各格式的详细说明。

QuakeML

XML 格式 · 地震学标准

QuakeML 是地震学领域描述事件相关信息的国际标准 XML 格式， 由瑞士地震服务中心（SED）主导开发。它支持完整描述震源、 震相、振幅、矩张量等层级信息，是事件元数据领域的主流结构化格式。

层级 主要内容
Event事件标识、类型、发震时刻
Origin震源位置（经纬度、深度）、定位方法、时刻精度
Magnitude震级值、震级标度（Mw、Ms、mb 等）、计算方法
FocalMechanism节面解、矩张量解
Amplitude各台站振幅观测值
Pick震相到时与极性
核心优势：QuakeML 可同时描述一个事件的多个 Origin 和 Magnitude， 并指明优选值（preferred），便于在不同机构结果之间对比。 主流数据中心与 FDSN Web 服务均支持 QuakeML 输出。

CSV / 文本格式

简单表格 · 易读易处理

CSV（逗号分隔值）是最通用的事件元数据格式，每行对应一次事件， 每列对应一个参数。适合批量处理与 Excel 快速查看， 但不支持层级结构（如多个 Origin 或 Magnitude）。

常见字段 说明
time发震时刻（ISO 8601 或 Unix 时间戳）
latitude震中纬度（度）
longitude震中经度（度）
depth震源深度（km）
mag震级值
magType震级标度（Mw、Ms、mb、ML 等）
place震中位置描述（如 "Hokkaido, Japan"）
eventID事件唯一标识符

ISC 格式

定长文本 · 历史传承

ISC（国际地震中心）采用定长文本格式发布地震目录， 分为 Bulletin（综合目录）和 ISF（ISC Summary Format）两种形式。 该格式历史悠久，字段位置固定，适合批量程序化处理。

文件类型 说明
ISC Bulletin 包含完整的事件、震相、振幅和矩张量信息，是历史地震重新定位的权威来源。
ISC-GEM 目录 ISC 与 GEM 基金会联合发布的统一震级目录，覆盖 1900 年至今的全球 M≥5.5 地震。
ISC-EHB 目录 对 EHB（Engdahl, van der Hilst, Buland）目录的改进版本，用于深源地震与远震定位。
定长格式注意事项：ISC 格式的字段宽度固定， 读取时需按字节位置切分，不建议直接按分隔符解析。 官方提供格式说明文档供参考。

CMT / 矩张量

震源机制解 · 矩张量描述

CMT（Centroid Moment Tensor）是描述震源机制的矩张量解， 由全球矩张量项目（GCMT，原哈佛 CMT 项目）等机构发布。 包含震源时间函数、矩张量、最佳双力偶解等信息。

字段 说明
Centroid Time矩心时刻
Centroid Location矩心位置
Moment Magnitude Mw矩震级
Scalar Moment M0标量地震矩（dyne·cm）
Moment Tensor六个独立分量（Mrr、Mtt、Mpp、Mrt、Mrp、Mtp）
Nodal Planes两个节面的走向、倾角、滑动角
Principal AxesP、T、N 轴的方位与倾伏角
Data Centers

数据中心

全球有多个机构编制和发布地震目录，各中心的定位方法、 震级标度与更新策略不同。以下按类别列出主要的数据中心， 每项均包含格式支持、网站与说明。

全球性数据中心

覆盖全球 · 权威目录来源

全球性数据中心发布覆盖全球的地震目录，是长期地震活动性研究的权威数据源。

数据中心 格式支持 网站 说明
ISC Bulletin · ISF · QuakeML · CSV isc.ac.uk 国际地震中心。汇总全球各台网观测数据进行统一重新定位， 是历史地震重新定位的权威来源，也是 ISC-GEM 目录的发布方。
USGS ANSS QuakeML · CSV · GeoJSON · KML earthquake.usgs.gov 美国地质调查局先进国家地震系统。全球实时目录， 更新最快（分钟级），适合近期事件研究。
EMSC QuakeML · CSV · JSON emsc-csem.org 欧洲-地中海地震中心。欧洲区域目录权威， 同时转发全球事件信息，实时性高。
GCMT CMT 文本 · QuakeML globalcmt.org 全球矩张量项目。提供 Mw ≥ 5.0 全球事件的矩张量解， 是震源机制研究的核心数据源。
GEM CSV · SQLite globalquakemodel.org 全球地震模型基金会。发布历史地震目录与 ISC-GEM 统一目录， 用于全球地震危险性分析。
目录一致性：ISC、USGS、EMSC 对同一事件的定位结果可能不同 （震中偏移 10–50 km、震级差 0.1–0.5）。 跨目录使用时应先评估差异来源，避免混用。

区域数据中心

区域覆盖 · 小震级目录更完整

区域数据中心对本地地震的检测能力更强，能提供更低震级阈值的目录。 这些目录在研究区域地震活动性时往往比全球目录更完整。

数据中心 格式支持 网站 说明
NCEDC QuakeML · CSV ncedc.org 北加州地震数据中心。提供加州北部及周边的完整地震目录， 小震级事件检测能力强。
SCEDC QuakeML · CSV · SCEC DC scedc.caltech.edu 南加州地震数据中心。南加州密集台网，目录完整度高， 是地震活动性研究的重要数据源。
GeoNet QuakeML · CSV geonet.org.nz 新西兰 GeoNet。覆盖新西兰及周边海域， 对俯冲带与浅地壳地震均有良好目录。
JMA CSV · 文本 jma.go.jp 日本气象厅。日本区域的地震目录权威来源， 对板间地震与板内地震均有良好监测。
KOERI CSV · QuakeML koeri.boun.edu.tr 土耳其海峡大学坎迪利天文台。土耳其及中东区域地震目录。

中国区域数据中心

中国大陆 · 官方目录

中国大陆的地震目录由中国地震台网中心（CENC）统一编制， 通过国家地震科学数据中心对外发布。

数据中心 格式支持 网站 说明
中国地震台网中心 CSV · 文本 cenc.ac.cn 中国大陆地震目录的官方来源。包含全国及周边地区地震事件， 震级标度以 Ms、ML 为主。
国家地震科学数据中心 CSV · 文本 · 数据集 data.earthquake.cn 发布中国及周边地震目录数据集。需实名注册，部分数据集需订单审批。 提供 2020 年以来的强震动参数数据集。
中国地震局地球物理研究所 CSV · 文本 cea-igp.ac.cn 发布中国区域震源机制解（CAP）与华北地区中小地震重定位目录。
震级标度注意：中国地震目录中的震级通常为 面波震级 Ms 或 近震震级 ML， 与 ISC/USGS 常用的 矩震级 Mw 不同。 跨目录使用时需进行震级标度转换，否则会引入系统偏差。
选择数据中心的三个原则： ① 区域优先 — 目标区域目录的完整性是首要因素； ② 时效性匹配 — 近期事件用 USGS/EMSC，历史事件用 ISC/ISC-GEM； ③ 震级标度统一 — 跨目录使用时必须进行震级标度转换。
Flowchart

获取流程

不同数据中心的目录获取流程不同。以下以三种典型模式为例， 点击标签查看详细流程。

API 实时获取型

USGS · EMSC · FDSN event 服务

适用于实时性要求高的场景。通过 REST API 或 FDSN Web 服务直接获取， 无需注册，返回 QuakeML、GeoJSON、CSV 等格式。

1
选择查询参数
确定时间范围、空间范围（矩形或圆形）、最小震级等条件。
2
调用 API
USGS：earthquake.usgs.gov/fdsnws/event/1/query
EMSC：www.seismicportal.eu/fdsnws/event/1/query
FDSN：各数据中心提供的 fdsnws-event 服务
3
解析返回结果
根据 format 参数选择输出格式 （QuakeML、GeoJSON、CSV、Text）。 使用 ObsPy、pandas 或自研脚本解析。
4
过滤与整合
按需过滤事件，与其他数据源（如波形、台站元数据）关联。

目录检索型

ISC Bulletin · ISC-GEM · GCMT

适用于历史事件与长期活动性研究。通过网页检索或批量下载获取完整目录。

1
确定目标目录版本
ISC Bulletin 按年份发布；ISC-GEM 为统一震级目录； GCMT 为矩张量解。根据研究需求选择。
2
构造检索条件
指定时间范围、区域（经纬度或矩形）、震级范围、 输出字段等。
3
下载目录文件
ISC 通常返回定长文本；GCMT 返回 CMT 格式文本； GEM 提供 CSV 或 SQLite 数据库。
4
解析与校验
按格式说明解析，检查缺失值、重复事件、 震级标度一致性。

订单审批型

国家地震科学数据中心

适用于中国区域目录。需实名注册并提交订单，部分数据集需人工审核。

1
实名注册
进入 data.earthquake.cn，完成实名注册。
2
选择数据集
按需选择中国地震目录、震源机制解或强震动参数数据集。
3
提交订单
填写用途、上传证明材料，等待人工审核（3–5 天）。
4
获取与标注来源
下载目录文件，在成果中标注数据来源单位。

2. 常用震级标度对照

标度 中文名 说明
Mw矩震级基于地震矩，物理意义最明确，不饱和，国际推荐使用
Ms面波震级基于 20 s 面波振幅，适用于浅源中强震
mb体波震级基于短周期 P 波振幅，适用于深源地震
ML近震震级基于 Wood-Anderson 地震仪振幅，适用于地方震
Md持续时间震级基于振动持续时间，适用于小震
MwpP 波矩震级基于 P 波高频能量，适用于快速响应
标度转换：不同震级标度之间无严格解析关系， 经验关系（如 Mw ≈ ML + 0.3 或 Mw ≈ 0.67Ms + 2.07）仅适用于特定区域与震级范围， 跨区域使用需谨慎。

Notes

使用注意事项

  1. 震级标度必须明确： 不同目录使用不同震级标度。使用前应确认 magType 字段，跨目录混合前应进行标度转换， 否则会引入系统偏差。
  2. 目录一致性差异： 同一事件在 ISC、USGS、EMSC 中的震中位置可能相差 10–50 km， 震级可能相差 0.1–0.5。跨目录使用时需评估差异来源。
  3. 时效性与权威性的权衡： USGS、EMSC 更新快（分钟级）但为自动初解； ISC 目录经过统一重新定位，权威性高但滞后数月。 近期事件用实时目录，历史研究用 ISC。
  4. 完整震级阈值不同： 全球目录的完整震级通常在 M5.0 左右； 区域目录（如 SCEDC、JMA）的完整震级更低。 地震活动性分析需考虑目录的完整震级。
  5. 事件去重： 跨目录合并时，需按发震时刻、位置、震级进行事件去重， 避免同一事件被多次计入。
  6. 定位深度约束： 浅源地震的深度解算误差较大， 近场记录稀少的事件深度可能固定为 10 km。 使用前应检查深度误差字段。
  7. 深度符号约定： 国际目录中深度为正值向下。 个别历史目录或自定义文件中可能使用相反约定，需确认。
  8. 时区为 UTC： 所有事件元数据的发震时刻均为 UTC 时间。
  9. 推荐使用 ObsPy： ObsPy 的 obspy.clients.fdsn.Client 可直接获取事件目录， obspy.core.event 支持读写 QuakeML。
