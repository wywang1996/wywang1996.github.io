强震动数据处理

面向强震动记录的全流程预处理工具链：从原始加速度时程出发， 依次完成格式解析、去尖峰、基线校正、滤波、重采样与积分， 输出可直接用于结构时程分析与反应谱计算的加速度、速度与位移时程。

开发中 Python 3.10+ NumPy · SciPy 兼容 ObsPy 2026
Overview

概述

强震动记录在采集与传输过程中不可避免地引入多种误差：传感器零点漂移、 积分带来的基线偏移、通信干扰造成的尖峰、触发与采样系统带来的直流分量与趋势项。 这些误差如果不加处理，会直接污染反应谱与结构响应计算，甚至导致位移时程发散。

本项目的目标是把这一套预处理流程标准化、可复现：把每一步处理都记录为可追溯的操作， 支持参数化配置与批处理，使得同一批记录可以在相同参数下得到一致的结果， 同时保留原始记录以便对比与回溯。

处理顺序很重要：一般应先去除尖峰（尖峰会严重干扰滤波与基线拟合）， 再做基线校正，然后滤波，最后积分。顺序颠倒会引入虚假的低频成分， 或者让尖峰在滤波后被“抹开”成更宽的异常段。
Features

主要功能

01

数据读取与格式解析

统一读取国内外主流强震动记录格式，自动解析采样率、单位、时标、 通道方位与仪器响应信息，把异构文件归一为内部统一的数据结构。

  • 支持 PEER NGA、COSMOS V1/V2、SAC、MiniSEED、ASCII 等格式
  • 自动识别单位（g / gal / m/s²）并统一换算为 cm/s²
  • 解析通道方位角，为后续旋转与分量合成做准备
  • 支持多分量文件（三分量）一次性读取
  • 保留原始元数据，处理链全程可追溯
02

基线校正

消除由传感器漂移与积分误差引起的速度、位移基线偏移， 使处理后的位移时程在强震段结束后回到零值附近，避免位移不合理发散。

  • 多项式基线校正（线性、二次、三次），可分段拟合
  • Iwan 双段校正与 Boore 方法
  • 基于 P 波触发前后的均值去直流
  • 支持人工指定强震段起止时间，分段处理
  • 自动检验校正后位移的残余偏移量
03

数字滤波

按记录的信噪比与可用频带，选择合适的高通、低通或带通滤波器， 去除长周期漂移与高频噪声，同时避免滤波引入的相位失真。

  • Butterworth、Chebyshev、椭圆滤波器设计
  • 零相位滤波（filtfilt）与单相位滤波可选
  • 支持长周期滤波拐点自动估计（基于信噪比）
  • 滤波前后频谱对比与频带检查
  • 可配置因果/非因果模式以匹配不同分析需求
04

去尖峰与异常值剔除

检测并修复由通信中断、传感器瞬时故障造成的尖峰与毛刺， 避免尖峰在滤波与积分后被放大成宽频异常。

  • 基于滑动中位数与 MAD 的稳健检测
  • 基于加速度、速度、位移一致性的检测
  • 支持插值修复、置零或整段剔除
  • 可查看被剔除样本的数量与位置
  • 检测阈值可自适应记录噪声水平
05

重采样

把不同采样率的记录统一到目标采样率，便于批量对比与结构分析输入， 并进行抗混叠处理。

  • 多相滤波重采样，支持任意有理比
  • 降采样前置抗混叠低通滤波
  • 支持升采样与任意目标采样率
  • 重采样误差与频谱一致性检查
06

积分与微分

由加速度时程积分得到速度与位移时程，支持多种数值积分格式与 积分后校正，是反应谱与结构时程分析的必要输入。

  • 梯形法、Simpson 法与频域积分
  • 积分常数与初始条件可配置
  • 积分后自动检测并报告残余速度与位移
  • 支持逐段积分以配合分段基线校正
07

分量旋转与合成

处理三分量记录，按方位角旋转到指定坐标系，或合成水平向与竖向， 便于与设计谱和场地主轴向对比。

  • EW/NS 旋转到断层法向与走向方向
  • 任意角度旋转与主轴向搜索
  • 水平双向合成（SRSS、最大方向）
  • 旋转前后反应谱对比
08

质量控制与处理报告

对每条记录给出质量指标与处理报告，识别低质量记录， 让批量处理的每一步都可检查、可追溯。

  • 信噪比、可用频带、PGA 与仪表量程检查
  • 触发信息完整性、截断与削波检测
  • 处理前后能量平衡与残余位移报告
  • 质量标记（优、良、合格、剔除）自动分级
  • 生成每步操作日志与参数记录
09

批处理与流水线

面向成百上千条记录的批量处理需求，提供配置文件与命令行接口， 支持并行执行与失败重试。

  • YAML / JSON 配置文件驱动的处理流水线
  • 多进程并行，支持进度显示与日志输出
  • 处理规则可复用、可继承、可按事件分组覆盖
  • 失败记录单独归档，便于人工复核
10

可视化与导出

内置交互式绘图与批量导出，方便结果复核、参数敏感性检查与报告生成。

  • 加速度 / 速度 / 位移时程与傅里叶谱、反应谱绘图
  • 处理前后叠加对比、批处理质量概览
  • 导出 SAC、MiniSEED、CSV、HDF5
  • 一键生成含参数与图表的 HTML / PDF 处理报告
Workflow

工作流程

  1. 读取与解析：读取原始记录，解析格式、单位、方位角与元数据，归一为统一数据结构。
  2. 去尖峰：用稳健统计方法检测尖峰与异常值，插值修复或标记剔除。
  3. 去直流与趋势：去除触发前的均值与明显的线性趋势项。
  4. 基线校正：按 Iwan 双段或多项式方法校正，重点控制位移残余。
  5. 数字滤波：根据信噪比选择频带，做零相位高通/低通或带通滤波。
  6. 重采样：统一到目标采样率，降采样时做抗混叠处理。
  7. 积分与微分：由加速度积分得到速度与位移，检查残余量并二次校正。
  8. 旋转与合成：按需旋转到目标方向或合成水平向，输出分析用分量。
  9. 质检与导出：生成质量报告，导出标准格式与处理日志。
Method

方法与公式

基线校正

常用多项式基线校正：对速度时程拟合低阶多项式并扣除，其等价于在加速度时程上 扣除该多项式的导数项。Iwan 双段校正假设强震段内存在两段不同的基线偏移， 分别拟合后拼接，能较好兼顾近场大位移记录。

v_corr(t) = v(t) − p(t) , p(t) = c₀ + c₁t + c₂t² + … a_corr(t) = a(t) − p′(t) # 校正后的加速度 ∫ a_corr dt → v_corr , ∫ v_corr dt → d_corr 要求：d_corr(t_end) ≈ 0 , v_corr(t_end) ≈ 0 # 校正目标

滤波器设计

采用 Butterworth 等 IIR 滤波器时，通常使用零相位滤波（前向 + 反向各一次）， 使相位失真相互抵消，但等效阶数翻倍，实际截止特性会变陡。

H(s) = 1 / √(1 + (s/ω_c)^(2n)) # Butterworth 幅频响应 filtfilt 等效于 |H(ω)|² , 相位为 0 # 零相位滤波 推荐：高通拐点 f_hp ≈ 1/(1.5·T_total) , 低通 ≤ 0.8·f_Nyq

去尖峰

以滑动窗口的中位数与 MAD 为基准，超过阈值的样本视为异常。 相比均值和标准差，中位数与 MAD 不受尖峰本身影响，检测更稳健。

MAD = median( |x_i − median(x)| ) flag_i = |x_i − median(x)| > k · 1.4826 · MAD # k 常取 5 ~ 10 修复：x_i ← median(x) 或 线性插值 / 三次样条插值

重采样

有理比重采样先升采样到两采样率的最小公倍数，再降采样到目标采样率， 降采样前必须低通到新的奈奎斯特频率以下，否则会产生混叠。

L / M 重采样：x ↑L → 低通 → ↓M f_cut ≤ min(f_Nyq_in, f_Nyq_out) = 0.5 · min(f_s_in, f_s_out) f_s_out = (L/M) · f_s_in

积分与微分

时域积分常用梯形法；也可在频域做积分，即除以 jω， 但需注意零频与极低频的分量处理，通常与高通滤波配合使用。

v_n = v_{n-1} + (a_{n-1} + a_n)/2 · Δt # 梯形积分 d_n = d_{n-1} + (v_{n-1} + v_n)/2 · Δt 频域：V(ω) = A(ω) / (jω) , D(ω) = −A(ω) / ω² # ω → 0 处需置零或高通截断，避免发散
Code

代码示例

下面是一个最小可运行的预处理流程：去尖峰 → 去均值 → 高通滤波 → 积分， 演示关键步骤的实现方式。实际工程中需在此基础上补齐基线校正、低通滤波、 重采样与质量控制。

strong_motion_preprocess.py Python 
"""
强震动记录预处理最小示例
去尖峰 → 去均值 → 高通滤波 → 梯形积分
"""
import numpy as np
from scipy.signal import butter, filtfilt


def remove_spikes(a, k=8.0, win=5):
    """基于滑动中位数与 MAD 的尖峰检测与插值修复"""
    a = a.copy()
    n = len(a)
    half = win // 2
    flagged = np.zeros(n, dtype=bool)

    for i in range(n):
        lo, hi = max(0, i - half), min(n, i + half + 1)
        seg = a[lo:hi]
        med = np.median(seg)
        mad = np.median(np.abs(seg - med))
        if mad > 0 and abs(a[i] - med) > k * 1.4826 * mad:
            flagged[i] = True

    if flagged.any():
        idx = np.arange(n)
        a[flagged] = np.interp(idx[flagged], idx[~flagged], a[~flagged])
    return a, flagged


def highpass(a, fs, f_corner, order=4):
    """零相位 Butterworth 高通滤波"""
    b, ax = butter(order, f_corner / (fs / 2.0), btype="high")
    return filtfilt(b, ax, a)


def integrate(a, dt):
    """梯形法积分，返回速度与位移"""
    v = np.cumsum((a[1:] + a[:-1]) / 2.0) * dt
    v = np.insert(v, 0, 0.0)
    d = np.cumsum((v[1:] + v[:-1]) / 2.0) * dt
    d = np.insert(d, 0, 0.0)
    return v, d


if __name__ == "__main__":
    fs = 200.0                     # 采样率 Hz
    dt = 1.0 / fs
    t = np.arange(0, 30.0, dt)
    # 合成一段带趋势与尖峰的示意加速度（cm/s²）
    a = 50 * np.sin(2 * np.pi * 3 * t) * np.exp(-((t - 5) ** 2) / 8)
    a += 0.8 * t                    # 线性趋势，模拟基线漂移
    a[1200] += 800.0                # 人为尖峰

    a, flags = remove_spikes(a)
    a -= np.mean(a[:200])           # 触发前均值作为直流基准
    a = highpass(a, fs, 0.1)
    v, d = integrate(a, dt)

    print(f"修复尖峰数: {flags.sum()}")
    print(f"PGA = {np.max(np.abs(a)):.2f} cm/s²")
    print(f"PGV = {np.max(np.abs(v)):.2f} cm/s")
    print(f"PGD = {np.max(np.abs(d)):.2f} cm")
    print(f"残余位移 = {d[-1]:.3f} cm")
这段代码只做演示：没有包含基线校正、低通滤波、重采样与质量控制， 也没有处理三分量旋转。用于实际记录时，必须先按建议顺序执行完整处理链， 并检查处理前后反应谱的差异是否在可接受范围内。
