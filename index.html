Tools

小工具

在线工具 4

地震动参数计算器

→

上传加速度时程（CSV / TXT），自动计算 PGA、PGV、PGD、 Arias 强度、有效持时、卓越周期与 5% 阻尼反应谱， 支持导出参数汇总 CSV。

地震动 反应谱 浏览器端

抗震规范谱生成器

→

支持 7 部中国抗震规范的设计谱生成：建筑抗震、公路桥梁、城市桥梁、 城轨结构、水运工程、建筑隔震与核电厂。内置规范查表与精确参数两种模式， 可导出科研级 SVG 矢量图与 CSV 数据。

设计谱 多规范 SVG 矢量图

震级能量换算器

→

在不同震级标度（ML、mb、MS、Mw）之间进行经验换算， 估算地震释放能量与地震矩，含震级饱和预警。

震级 能量 换算

波形格式转换器

→

上传 SAC、MiniSEED、ASCII 等波形文件，在浏览器本地解析、 预览波形，并导出为 SAC、MiniSEED、CSV 等格式。

波形 ObsPy 转换

数据来源

→

三个项目的输入数据汇总：强震动记录、波形与台站、地震目录、 震源与构造、场地条件与项目内部数据，覆盖国际主流数据库、 国内台网与规范依据，附数据一览表与引用规范。

数据源 强震动 地震目录

地震学绘图

→

面向地震学的绘图模板：波形时程、反应谱、震级-频度关系、 震中分布与震源机制沙滩球，支持对数坐标、缩放交互与高分辨率导出。

地震学 Plotly.js 导出

地震动参数分析

→

从地震动时程中提取常用参数，包括 PGA、PGV、PGD、Arias 强度、 有效持时、反应谱等，并支持多记录批量对比与可视化。

地震动 反应谱 参数分析

强震动数据处理

→

强震动记录预处理工具，支持基线校正、滤波、去尖峰、重采样， 以及加速度时程的积分与校正，输出可供结构时程分析使用的数据。

强震动 Python 信号处理

地震危险性分析

→

基于概率地震危险性分析（PSHA）框架，结合地震活动性模型、 地震动预测方程与场地效应，计算不同周期下的地震危险性曲线与 一致危险性反应谱。

PSHA 危险性曲线 UHS
