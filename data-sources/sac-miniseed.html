SAC / MiniSEED 波形

SAC（Seismic Analysis Code）和 MiniSEED 是地震学领域两种通用的波形数据格式。 SAC 用于单台波形分析，MiniSEED 用于连续波形存档与交换， 两者均可在 ObsPy 中读写，是强震动数据处理与结构时程分析的基础输入格式。

波形格式 通用标准 ObsPy 读写 Steim 压缩 50+ 数据中心
Overview

概述

SAC（Seismic Analysis Code）最初由美国劳伦斯利弗莫尔国家实验室 开发，后由 IRIS 维护，是地震学领域最广泛使用的波形分析工具之一。 SAC 格式也随之成为地震波形数据的通用交换格式。 一个 SAC 文件通常包含单个连续时间段的时间序列数据， 由头段区（header）和数据区（data）两部分组成： 头段区为固定长度（632 字节），存储波形元数据；数据区为浮点型数值序列，长度可变。

MiniSEED 是 SEED（Standard for the Exchange of Earthquake Data） 标准的子集，仅包含时间序列数据及其最基本的标识信息， 不包含完整的仪器响应等元数据。 SEED 标准是国际通用的数字地震数据交换格式， 自 1991 年 Version 2.2 起将格式拆分为 dataless SEED（元数据） 和 miniSEED（波形数据）两部分。 一个 MiniSEED 记录由固定头段、块ette 链表和波形样本三部分组成， 常见记录长度为 512 字节、1 KB 或 4 KB。

两种格式的对比

  • SAC：单台波形分析格式，头段包含台站、事件、震相到时等元数据， 适合交互式分析与处理，文件通常为二进制或 ASCII 格式。
  • MiniSEED：连续波形存档与交换格式，仅包含波形数据和最基本的标识信息， 适合长期存储和批量传输，采用 Steim 压缩编码以减小文件体积。
  • 互补关系：SAC 侧重分析，MiniSEED 侧重存储。 实际工作中常将 MiniSEED 连续波形截取为事件波形后转换为 SAC 格式进行分析。

在强震动数据处理中的角色

  • 数据获取：各国测震台网以 MiniSEED 格式提供连续波形数据， 用户可从中截取地震事件波形并写入 SAC 文件。
  • 数据处理：SAC 文件可直接用于去除趋势、去均值、仪器响应校正等预处理操作。
  • 格式转换：ObsPy 等工具可在 SAC、MiniSEED、GSE2、SEISAN 等格式之间相互转换。
本页说明的是波形格式，而非单一数据库： 能提供 SAC 和 MiniSEED 格式波形数据的数据中心有50 多个， 它们是不同机构运营的独立服务。这些中心在数据覆盖范围、 格式支持、仪器响应提供方式、引用要求上差异显著。 下一节「数据中心」将按类别介绍主要的数据中心。
Format

数据格式

SAC 和 MiniSEED 在文件结构上有本质区别。点击下方标签查看两种格式的详细说明。

SAC 格式

单台波形分析格式 · 头段 632 字节

SAC 文件由头段区和数据区两部分组成。 头段区固定为 632 字节，包含 133 个头段变量， 类型混合了整数（int）、浮点数（float）和字符串（char）。 数据区为浮点型数值序列，长度取决于数据点数和文件类型。

头段变量分类

类别 数量 主要内容
浮点型（F） 70 个 delta（采样间隔）、depmin、depmax、scale、b、e、o、a、t0–t9、stla、stlo 等
整型（I） 40 个 npts（数据点数）、nwfid（波形 ID）、iftype（文件类型）、nzhour、nzmin、nzsec 等
字符串（K） 23 个 kstnm（台站名）、knetwk（台网名）、kcmpnm（分量名）、kevnm（事件名）等
时间基准：SAC 中的绝对时刻由 nzyear、nzjday、nzhour、nzmin、 nzsec、nzmsec 六个变量共同定义，其他时刻均以相对于该基准的秒数表示。

文件类型（iftype）

值 类型 说明
1时间序列常规等间隔时间序列数据
2谱数据频谱分析结果
3非等间隔序列非均匀采样的时间序列
4一般 XY 数据通用 X-Y 数据对

文件命名规则

使用 rdseed 从 SEED 格式解压得到的 SAC 文件通常采用固定命名格式：

yyyy.ddd.hh.mm.ss.ffff.NN.SSSSS.LL.CCC.Q.SAC
字段 说明
yyyy.ddd.hh.mm.ss.ffff第一个数据点对应的 UTC 时间
NN台网代码（2 字符）
SSSSS台站代码（5 字符）
LL位置代码（2 字符）
CCC通道代码（3 字符）
Q质量标识

MiniSEED 格式

连续波形存档格式 · Steim 压缩

MiniSEED 是 SEED 标准的精简子集，仅用于存储时间序列数据， 不包含完整的仪器响应等元数据。 一个 MiniSEED 记录由固定头段、 块ette 链表（blockettes）和波形样本三部分组成。

记录结构

组成部分 说明
固定头段 48 字节，包含台网代码、台站代码、位置代码、通道代码、起始时间、采样率等基本信息
块ette 链表 可变长度，包含数据质量标识、时间校正、采样率精确值等扩展信息
波形样本 实际的时间序列数据，采用 Steim 压缩编码存储

数据编码类型

MiniSEED 支持多种数据编码，常见类型如下：

编码值 类型 说明
0ASCII文本格式
1INT1616 位整数
3INT3232 位整数
4FLOAT3232 位浮点数
5FLOAT6464 位浮点数
10Steim-1Steim-1 压缩整数，最常用
11Steim-2Steim-2 压缩整数，压缩率更高
Steim 压缩原理：Steim-1 和 Steim-2 将 32 位整数按差值编码压缩。 Steim-1 在一个 32 位块内可存储最多 4 个 1 字节差值或最少 1 个 4 字节差值， Steim-2 的压缩率更高，适合高采样率数据。 解压后的数据为 32 位整数，需乘以灵敏度因子转换为物理单位。

记录长度

MiniSEED 的常见记录长度为 512 字节、1 KB 或 4 KB。 512 字节是最小记录长度，适合实时数据传输； 4 KB 记录适合存档。

格式选择建议： 交互式波形分析选择 SAC； 连续波形存档与批量交换选择 MiniSEED； 需要与其他地震学工具兼容时，使用 ObsPy 进行格式转换。
Data Centers

数据中心

全球有 50 多个 FDSN 正式注册的数据中心， 以及大量国家级和区域性数据中心提供 SAC 和 MiniSEED 格式波形。 以下按类别列出其中主要的数据中心，每项均包含格式支持、网站与说明。 完整列表可查阅 FDSN 数据中心注册表。

全球性数据中心

数据覆盖全球 · FDSN Web 服务标准

全球性数据中心的数据来自世界各地台网，以 FDSN Web 服务提供统一接口。 适合研究区域不固定、或需要跨区域比较的场景。

数据中心 格式支持 网站 说明
IRIS DMC / EarthScope MiniSEED · SAC · GeoCSV · ASCII ds.iris.edu 全球覆盖最广。dataselect 返回 MiniSEED，timeseries 支持 SAC.zip 等。无需注册。
GEOFON (GFZ) MiniSEED · StationXML geofon.gfz.de 德国地球科学研究中心运营，全球宽带地震台网。FDSN 服务标准，无需注册。
GEOSCOPE MiniSEED · StationXML geoscope.ipgp.fr 法国全球地震台网，提供全球范围内高质量宽带记录。
EMSC MiniSEED（转发） emsc-csem.org 欧洲-地中海地震中心，主要提供事件目录和波形转发服务。
引用注意：使用全球性数据中心的数据时， 应标注原始台网代码（如 IU、II、GE 等）， 而非数据中心本身。

欧洲区域数据中心

ORFEUS EIDA 分布式网络 · 多个节点

ORFEUS EIDA（European Integrated Data Archive）是欧洲的分布式数据中心网络， 由多个国家节点组成，通过统一 FDSN 接口提供服务。核心格式为 MiniSEED， 元数据统一采用 StationXML。部分节点（如 Résif-DC）还支持 SAC 格式。

节点 格式支持 网站 说明
Résif-DC MiniSEED · SAC zip · StationXML seismology.epos-france.fr 法国国家观测服务。EIDA 节点中少数支持 SAC 格式直接下载的中心，dataselect 可返回 SAC zip。
ETH / SED MiniSEED · StationXML sed.ethz.ch 瑞士地震服务中心。提供瑞士及周边地区高质量台网数据，FDSN 标准接口。
INGV MiniSEED · StationXML ingv.it 意大利国家地球物理与火山学研究所。提供意大利及地中海区域密集台网数据。
GFZ (GEOFON) MiniSEED · StationXML geofon.gfz.de 德国地球科学研究中心。同时作为全球性数据中心和 EIDA 节点提供服务。
KNMI MiniSEED · StationXML knmi.nl 荷兰皇家气象研究所。提供荷兰及周边区域地震与形变数据。
NIEP MiniSEED · StationXML niep.ro 罗马尼亚国家地球物理研究所。提供东欧 Vrancea 地震带数据。
KOERI MiniSEED · StationXML koeri.boun.edu.tr 土耳其海峡大学坎迪利天文台与地震研究所。提供土耳其及中东区域数据。
NOA MiniSEED · StationXML noa.gr 希腊国家天文台。提供希腊及爱琴海区域地震台网数据。
格式差异：大部分 EIDA 节点主要提供 MiniSEED 波形， 但 Résif-DC 的 dataselect 服务可返回 SAC zip 格式。 使用前应确认目标节点的格式支持情况，必要时先下载 MiniSEED 再自行转换为 SAC。

北美区域数据中心

加州、阿拉斯加、加拿大 · 强震动记录集中

北美的区域数据中心以加州地区最为成熟，是强震动研究的重要数据源。 这些中心均提供 MiniSEED 格式波形，部分配套 SAC PZ 格式的仪器响应。

SCEDC MiniSEED · StationXML scedc.caltech.edu 南加州地震数据中心。提供南加州密集台网的 MiniSEED 格式波形数据。

亚太区域数据中心

中国、日本、台湾、新西兰 · 强震动数据丰富

亚太区域地震活动性强，数据中心众多。 这些中心的数据格式和获取方式差异较大，需根据实际需求选择。

数据中心 格式支持 网站 说明

NIED (日本) ASCII · Binary · CSV kyoshin.bosai.go.jp K-NET / KiK-net 台网。主要提供特有的 ASCII/Binary/CSV 格式，国际数据中心常镜像为 MiniSEED。
IESDMC (台湾) MiniSEED · StationXML batsws.earth.sinica.edu.tw 台湾中央研究院地球科学研究所数据管理中心，FDSN 注册中心。
GeoNet (新西兰) MiniSEED · StationXML geonet.org.nz 新西兰国家地震台网，FDSN 注册中心，数据开放获取。
GEOFON（亚太镜像） MiniSEED · StationXML geofon.gfz.de GEOFON 在亚太地区有部分台站数据，可作为区域补充。

其他区域数据中心

中美洲 · 南美 · 中东 · 非洲

其他区域也有各自的数据中心，覆盖本地台网记录。 这些中心多为 FDSN 注册节点，可通过标准 Web 服务访问。

数据中心 格式支持 网站 说明

数据获取建议：对于非主要区域的研究， 优先使用 IRIS DMC 或 GEOFON 的全球覆盖； 如需要本地化数据，可通过 FDSN 注册表查询该区域是否有专属数据中心。
选择数据中心的三个原则： ① 区域优先 — 目标区域覆盖是首要因素，本地中心数据通常最完整； ② 格式匹配 — 确认中心是否直接提供 SAC / MiniSEED，或需要额外转换； ③ 引用规范 — 各中心的引用要求不同，使用前应阅读其数据政策。
Flowchart

获取流程

不同数据中心的获取流程差异显著。以下以三种典型模式为例， 点击标签查看详细流程。

开放 Web 服务型

IRIS DMC · GEOFON · ORFEUS EIDA

适用于开放数据，通过 FDSN Web 服务直接调用，无需注册。

1
确定目标数据中心与数据范围
按研究区域选择数据中心，确定台网、台站、通道和时间范围。
2
调用 FDSN Web 服务
构造请求 URL：
dataselect → MiniSEED
timeseries → MiniSEED / SAC / ASCII
station → StationXML / dataless SEED
3
下载波形与元数据
使用浏览器、wget、curl 或 ObsPy 的 obspy.clients.fdsn 下载。
4
读取与预处理
使用 ObsPy 读取波形和元数据，进行去趋势、 去均值、仪器响应校正与格式转换。

订单审批型

国家地震科学数据中心 · 部分国家级中心

适用于需要实名注册与人工审批的国家级数据中心。 以国家地震科学数据中心为例。

1
实名注册
进入数据中心网站，完成实名注册，填写个人信息和单位信息。
2
确定用户等级
普通用户（一级数据）/ 高级用户（二、三级数据，需签字盖章申请）/ 团队用户（需签署协议）。
3
提交数据订单
填写数据订单、使用用途、上传证明材料， 等待人工审核（一般 1 个工作日处理，3–5 天完成）。
4
选择服务方式
在线下载（小数据量）/ 邮件发送 / 硬盘邮寄（大数据量）/ 定向推送（单位用户）。
5
获取数据并标注来源
下载 MiniSEED 或 SAC 格式波形， 在成果中标注数据来源单位（必填）。

专用格式型

NIED K-NET / KiK-net · 特定台网

部分国家级台网（如日本 NIED）主要发布特有格式， 需自行转换为 SAC 或 MiniSEED。

1
注册账号
进入 NIED 强震观测网官网，完成用户注册。
2
下载原始格式文件
下载 ASCII、Binary 或 CSV 格式的波形文件。 注意：这些格式不是 SAC 或 MiniSEED。
3
编写转换脚本
根据文件头段（如第 14 行的 Scale Factor） 将 digit 值转换为物理加速度， 再按 SAC 或 MiniSEED 结构写入。
4
验证与使用
使用 ObsPy 读取转换后的文件， 检查波形与元数据是否正确。

Notes

使用注意事项

  1. 数据中心远不止三家： 全球有 50 多个 FDSN 正式注册的数据中心。 选择时应考虑目标区域覆盖、格式支持、引用要求三个因素。 完整列表参见 FDSN 数据中心注册表。
  2. 各中心的格式支持范围不同： IRIS DMC 的 dataselect 返回 MiniSEED， timeseries 额外支持 SAC.zip 和 GeoCSV； ORFEUS EIDA 节点主要返回 MiniSEED， Résif-DC 也支持 SAC； 国家地震科学数据中心同时提供 MiniSEED 和 SAC。
  3. 仪器响应的获取方式不同： IRIS DMC 通过独立的 resp（RESP）和 sacpz（SAC PZ）服务； ORFEUS EIDA 统一提供 StationXML； 国家地震科学数据中心的部分数据在文件头段中直接包含仪器参数。
  4. SAC 文件不含仪器响应： SAC 格式本身仅包含波形数据， 不包含仪器响应信息。 需要仪器响应校正时，必须另行获取配套的 SACPZ 文件。
  5. MiniSEED 不包含完整元数据： MiniSEED 仅包含时间序列数据及其最基本的标识信息， 不包含仪器类型、响应函数、台站坐标等完整元数据。 这些信息需从 dataless SEED 或 StationXML 文件中获取。
  6. Steim 压缩为整数编码： Steim-1 和 Steim-2 压缩的 MiniSEED 数据解压后为 32 位整数，需乘以灵敏度因子才能得到物理单位。
  7. 字节序需注意： MiniSEED 通常使用大端序（Big-Endian）存储， 而 SAC 二进制文件通常使用小端序（Little-Endian）。 跨平台读取时需注意字节序转换。
  8. 通道命名可能不同： SAC 和 MiniSEED 中的通道代码由频带码、仪器码和方向码组成。 不同台网可能使用不同的命名约定。 强震动加速度计常用 HN 或 BN 前缀。
  9. 数据质量标识： MiniSEED 的固定头段中包含数据质量标识。 D 表示不确定，R 表示原始， Q 表示质量受控，M 表示已校正。 使用前应检查质量标识。
  10. 时区为 UTC： SAC 和 MiniSEED 中的时间均为 UTC 时间。
  11. 推荐使用 ObsPy： ObsPy 是 Python 地震学工具包， 支持 SAC、MiniSEED、GSE2、SEISAN 等多种格式的读写， 同时提供 FDSN Web 服务的客户端接口。

各数据中心的引用要求

数据中心 引用要求
IRIS DMC 引用原始台网代码（如 IU、II、GE 等），而非 IRIS 本身。
GEOFON 引用 GEOFON 或原始台网，视数据集而定。
ORFEUS EIDA 引用具体的 EIDA 节点及其数据集 DOI（如有）。
国家地震科学数据中心 必须标注“中国地震局工程力学研究所‘国家强震动台网中心’为本研究提供数据支持”。
NIED 引用 DOI 10.17598/NIED.0004。
GeoNet 引用 GeoNet 数据集 DOI 或台网代码。
通用原则：无论使用哪个数据中心，都应在论文中 明确标注数据来源，并在致谢中感谢数据提供单位。
致谢格式：在论文致谢中，如使用多个数据中心的数据， 应逐一列出。例如： “波形数据来自 IRIS DMC 的 IU 台网、ORFEUS EIDA 的 IV 台网， 以及国家地震科学数据中心。”
