绘图模板

面向工程地震与地震工程两个研究方向的常用图件代码模板。 每个模板提供 Python（matplotlib） 与 MATLAB 两套可直接运行的代码，按研究方向 → 图件两级组织。

21 个模板 工程地震 · 12 地震工程 · 9 Python / MATLAB 排版
Overview

概述

工程地震与地震工程虽然都以"地震"为对象，但关注点不同： 工程地震关心地震动的产生、传播、场地效应与危险性，为结构设计提供输入； 地震工程关心结构在地震作用下的弹性与弹塑性响应、抗震设计与损伤评估，是输出。 两个方向各自都有若干核心图件，本页把它们按研究方向抽出，做成代码模板。

模板统一使用 matplotlib 的 rcParams 与 MATLAB 的 exportgraphics， 默认 300 dpi、Times New Roman 字体、出版级排版。 代码里写清了输入数据格式、公式来源与参数含义，稍作修改即可用于论文插图。

使用原则：模板给出可运行的最小实现， 目的是让图先画出来。再把真实的计算数据、自己的参数填进去， 按目标期刊微调排版即可。

Usage

使用方式

  1. 确定研究方向：从工程地震或地震工程出发，找到对应研究方向下的模板。
  2. 复制代码：点击卡片进入详情页，切换 Python / MATLAB 标签，复制代码到本地保存。
  3. 准备数据：按模板注释准备输入文件，多数地震动模板使用两列文本（时间、加速度）。
  4. 本地运行：Python 直接运行 python plot.py；MATLAB 保存为 .m 后运行。
  5. 调整参数：阻尼比、周期范围、设防烈度、特征周期、土层参数等按规范或数据特性修改。
  6. 微调排版：字号、线宽、图例位置按目标期刊要求微调。
  7. 导出图件：默认输出 300 dpi PNG，可改 savefig / exportgraphics 为 PDF 或 SVG。
