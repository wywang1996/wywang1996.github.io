USGS ANSS 目录

ANSS 综合地震目录（ComCat）由美国地质调查局（USGS）地震灾害计划维护， 是美国及全球地震事件的权威目录。它整合了 ANSS 各贡献台网及其他来源的 地震记录，包含震源参数、震级、震相拾取、矩张量解、宏观地震信息、构造摘要 等多种产品，通过网页检索和 FDSN 标准 Web 服务对外发布。

Overview

概述

ANSS 综合地震目录（ComCat）是美国地质调查局（USGS） 地震灾害计划维护的美国及全球地震事件权威目录。 它整合了 ANSS 各贡献台网及其他来源（如百年目录、全球矩心矩张量目录等） 的地震记录，动态接收各来源发布或更新的产品。

ComCat 自 2013 年 1 月 1 日起成为 ANSS 的正式记录目录， 取代了旧的 ANSS 目录。其数据覆盖范围广泛， 从 1856 年的历史地震到当前实时事件， 包含阿拉斯加、加州、夏威夷、波多黎各等多个区域台网的记录。 USGS 国家地震信息中心（NEIC）负责监测全球 Mw 4.5 级以上地震。

数据产品类型

  • 震源参数：发震时刻、震中位置、震源深度、震级（多种标度）、震相拾取、振幅。
  • 矩张量解：全球及区域矩张量解，包括矩心位置、矩张量分量、最佳双力偶解。
  • 宏观地震信息：震感报告（DYFI）、ShakeMap 震动图、PAGER 警报等级。
  • 构造摘要：区域构造背景、断层信息。
  • 有限断层模型：大地震的滑动分布模型。
与其他目录的差异： ComCat 是美国区域的官方目录，同时对全球 Mw 4.5+ 事件提供快速定位。 与 ISC 目录相比，ComCat 更新更快（分钟级实时更新）， 但 ISC 在历史地震重新定位方面更权威。 两者在长期地震活动性研究中常互为补充。
Format

数据格式

ComCat 通过 FDSN Event Web Service 提供多种输出格式， 默认格式为 QuakeML。点击下方标签查看各格式的详细说明。

QuakeML

XML 格式 · 默认输出 · 结构化程度最高

QuakeML 是 FDSN Event Web Service 的默认输出格式， 采用 XML 结构描述事件、震源、震级、震相、振幅、矩张量等完整信息。 支持同时描述一个事件的多个 Origin 和 Magnitude，并指明优选值。

层级 主要内容
Event事件标识、类型、发震时刻
Origin震源位置（经纬度、深度）、定位方法、时刻精度
Magnitude震级值、震级标度、计算方法、台站数
FocalMechanism节面解、矩张量解
Amplitude各台站振幅观测值
Pick震相到时与极性
使用方式：在 FDSN Event Web Service 请求中指定 format=quakeml（或不指定 format 参数，默认即为 QuakeML）。 返回的 XML 文件可用 ObsPy 的 read_events() 直接读取。

GeoJSON

JSON 格式 · 地图友好 · 轻量

GeoJSON 是 ComCat 推荐的地图展示格式， 以 JSON 结构描述事件的几何位置和属性信息。 USGS 官方建议自动化应用优先使用 Real-time GeoJSON Feeds 来显示地震信息，因为其性能和可用性最佳。

字段 说明
geometry.coordinates经度、纬度、深度
properties.mag震级值
properties.place震中位置描述
properties.time发震时刻（Unix 时间戳，毫秒）
properties.tsunami海啸标志（0 或 1）
properties.felt震感报告数量
properties.alertPAGER 警报等级
properties.detail事件详情页 URL
实时 Feeds：USGS 提供过去 1 小时、1 天、7 天、30 天的 GeoJSON 摘要文件，分为 significant、4.5+、2.5+、1.0+ 等等级。 地址见下方「数据中心」章节。

CSV / 文本

表格格式 · 易读易处理

CSV 是 ComCat 的简单表格输出格式， 每行一个事件，每列一个参数。适合批量处理与 Excel 快速查看， 但不支持层级结构（如多个 Origin 或 Magnitude）。

常见字段 说明
time发震时刻（ISO 8601 或 Unix 时间戳）
latitude震中纬度（度）
longitude震中经度（度）
depth震源深度（km）
mag震级值
magType震级标度（Mw、Ms、mb、ML 等）
place震中位置描述
id事件唯一标识符
获取方式：在 FDSN Event Web Service 请求中指定 format=csv。也可使用 libcomcat 的 getcsv() 方法生成 CSV 或 Excel 文件。

KML

Google Earth 格式 · 三维可视化

KML 是 ComCat 提供的 Google Earth 格式， 用于在 Google Earth 中三维可视化地震事件的位置和震级。 每个事件以地标（Placemark）形式展示，包含震级、深度、位置等属性。

特点 说明
三维展示在 Google Earth 中查看地震的深度分布
颜色编码按震级或深度着色
点击信息点击地标查看事件详情
获取方式：在 FDSN Event Web Service 请求中指定 format=kml。同时可指定额外的 KML 控制参数。

请求参数速查

参数 类型 说明
formatString输出格式：quakeml（默认）/ geojson / csv / kml / text
starttimeISO8601起始时间，默认 NOW-30 天
endtimeISO8601结束时间，默认当前时间
minmagnitudeFloat最小震级
maxmagnitudeFloat最大震级
minlatitudeFloat最小纬度（矩形区域）
maxlatitudeFloat最大纬度
minlongitudeFloat最小经度
maxlongitudeFloat最大经度
latitudeFloat中心纬度（圆形区域，需配合 maxradiuskm）
longitudeFloat中心经度
maxradiuskmFloat圆形区域半径（km）
catalogString目录来源过滤（如 ak、ci、us）
eventidString按事件 ID 查询
服务地址：earthquake.usgs.gov/fdsnws/event/1/。 支持 query、count、catalogs、contributors 等方法。
Data Centers

数据中心

ComCat 由 USGS 地震灾害计划统一维护，同时整合了多个 ANSS 贡献台网的数据。 以下列出主要的数据入口与贡献台网。

USGS 主入口

官方发布 · 网页检索 · FDSN Web 服务

USGS 地震灾害计划是 ComCat 的官方维护机构， 提供网页检索界面和 FDSN 标准 Web 服务两种访问方式。

入口 地址

实时 Feed

GeoJSON · 分钟级更新 · 无需认证

USGS 提供实时 GeoJSON Feeds，以固定 URL 返回 最近 1 小时、1 天、7 天、30 天的地震事件摘要， 适合地图展示和监控应用。

Feed 类型 说明
过去 1 小时最近一小时所有事件
过去 1 天最近一天所有事件
过去 7 天最近一周 M1.0+ 事件
过去 30 天最近一月 M2.5+ / M4.5+ / significant 事件
Feed 地址：earthquake.usgs.gov/earthquakes/feed/v1.0/。 无需 API 密钥，直接 GET 即可返回 GeoJSON。
平台选择建议： 需要批量历史目录 → FDSN Event Web 服务或网页检索界面； 需要实时监控 → 实时 GeoJSON Feeds； 需要特定区域数据 → 在请求中指定 catalog 参数过滤贡献台网。
Flowchart

获取流程

ComCat 的获取方式分为网页检索和程序化 API 两种，均无需注册。 点击下方标签查看详细流程。

网页检索下载

无需注册 · 交互式筛选 · 多格式输出

适用于交互式检索与少量下载。通过 USGS 地震搜索页面 按条件筛选事件，直接下载结果文件。

1
访问 USGS 地震搜索页面
进入 earthquake.usgs.gov/earthquakes/search/。
2
设置检索条件
按时间范围、震级范围、地理区域（矩形或圆形）、 深度等条件筛选。可选择特定贡献台网（catalog）。
3
查看结果
结果以地图和列表形式展示，可查看事件详情页。
4
选择输出格式并下载
选择 CSV、GeoJSON、QuakeML、KML 等格式， 点击下载按钮获取文件。
5
标注数据来源
在研究成果中标注 USGS ANSS ComCat。

FDSN Web 服务

程序化访问 · 无需认证 · 多格式支持

适用于批量、程序化的数据获取。 通过构造 URL 调用 FDSN Event Web Service，返回结构化数据。

1
确定请求参数
确定时间范围（starttime、endtime）、 空间范围（矩形或圆形）、震级范围、输出格式等。
2
构造请求 URL
基础 URL：earthquake.usgs.gov/fdsnws/event/1/query
示例参数：?format=csv&starttime=2024-01-01&minmagnitude=5.0
3
调用服务
使用浏览器、curl、wget 或 Python（requests、ObsPy）发送 GET 请求。
4
解析返回结果
根据 format 参数选择解析方式。 QuakeML 用 ObsPy，CSV 用 pandas，GeoJSON 用 json。
5
标注数据来源
在研究成果中标注 USGS ANSS ComCat。
Python 示例： 可使用 libcomcat 库封装常用查询， 或直接使用 requests 构造 URL。 ObsPy 的 obspy.clients.fdsn.Client 也支持 USGS 事件服务。

实时 Feed 订阅

固定 URL · 分钟级更新 · GeoJSON

适用于需要实时或近实时地震信息的应用。 USGS 提供固定的 GeoJSON Feed URL，无需参数即可获取最新事件摘要。

1
选择 Feed 类型
根据需求选择时间范围（1 小时 / 1 天 / 7 天 / 30 天） 和震级等级（significant / 4.5+ / 2.5+ / 1.0+ / all）。
2
获取 Feed URL
如 earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson 返回过去一天所有事件的 GeoJSON。
3
定时拉取
在应用中定时（如每 5 分钟）GET 该 URL， 解析返回的 GeoJSON 更新地图或列表。
4
标注数据来源
在地图或应用中标注 USGS ANSS ComCat。
Data Files

数据文件说明

1. 事件元数据字段说明

ComCat 的字段数量众多，按用途可分为基本参数、 定位质量参数、影响与评估参数和 事件标识与状态四类。点击下方标签查看各类字段的详细说明。

基本参数

所有事件均包含 · 描述震源基本属性
字段 单位/类型 说明
timeUTC / ISO8601发震时刻，格式为 YYYY-MM-DDTHH:MM:SS.sssZ
latitude度震中纬度（-90 至 90）
longitude度震中经度（-180 至 180）
depthkm震源深度，正值向下。浅源事件深度误差较大
mag—震级值（无量纲）
magTypestring震级标度：mw / mww / mb / ml / md / mwr 等
placestring震中位置的文字描述（如 “10 km NE of Ridgecrest, CA”）
typestring事件类型：earthquake / quarry blast / explosion / ice quake 等
震级标度差异：ComCat 中同一事件可能包含多个震级解， 每条解有各自的标度。首选解（preferred）通常采用 矩震级（Mw），适用于中强震； 小震级事件可能仅提供 ml 或 md。

定位质量参数

评估震源定位可靠性 · 筛选优质事件

定位质量参数用于评估震源定位的可靠性。 在批量下载和统计分析前，应检查这些参数以剔除质量较差的事件。

字段 单位 说明
nst个参与定位的台站数。台站越多定位越可靠，通常 ≥ 10 为佳
dmin度最近台站到震中的距离（度）
rms秒走时残差的均方根。越小表示定位拟合越好
gap度方位角间隙。台站分布的最大方位角空隙，越小越好（< 180° 较可靠）
horizontalErrorkm震中水平定位误差
depthErrorkm震源深度误差。浅源地震深度误差通常较大
magError—震级的标准误差
magNst个参与震级测定的台站数
locationSourcestring定位来源台网代码（如 ak、ci、us）
magSourcestring震级来源台网代码
质量筛选建议： 通常水平误差 < 10 km、台站数 ≥ 8、方位角间隙 < 180°、 RMS < 1.0 s 的定位较为可靠。 对于台站数很少或方位角间隙接近 360° 的事件，震中位置可能偏差较大。

影响与评估参数

宏观影响 · 灾害评估 · 自动生成

USGS 在事件发生后会自动生成一系列影响与评估产品， 这些参数在事件详情页和 GeoJSON/QuakeML 中均有体现。

字段 单位 说明
tsunami0/1海啸标志。1 表示该事件可能引发海啸
feltint公众震感报告数量（DYFI）
cdi—最大社区十进制烈度（Community Decimal Intensity）
mmi—最大修正麦卡利烈度（Modified Mercalli Intensity）
alertstringPAGER 警报等级：green / yellow / orange / red
sig0–1000事件重要性评分，综合震级、震感、海啸等计算
netstring发布该事件的主要贡献台网代码
sourcesstring提供该事件信息的台网代码列表（逗号分隔）
PAGER 等级：green 表示影响很小，red 表示可能造成严重人员伤亡与经济损失。 PAGER 等级仅对全球 M5.5+ 事件发布。

事件标识与状态

唯一标识 · 版本管理 · 更新追踪

ComCat 的事件标识与状态字段用于追踪事件的版本和更新历史。 由于 ComCat 数据是动态更新的，这些字段对于数据管理尤为重要。

字段 说明
id事件唯一标识符，格式为 台网代码 + 序号（如 us6000abcd、ci12345678）
codes该事件的所有已知标识符列表（不同台网使用不同 ID）
ids逗号分隔的所有标识符
status审核状态：automatic（自动） / reviewed（已审核） / deleted（已删除）
updated最后更新时间（UTC），每次信息更新均会刷新
detail事件详情页的 URL
url事件主页 URL（通常与 detail 相同）
状态说明： 自动（automatic）解由系统在事件发生后数分钟内生成， 可能随时间被审核（reviewed）解替换。 在研究中应优先使用 reviewed 状态的事件。

2. 数据产品类型

ComCat 的核心特色之一是同一事件可关联多种产品。 这些产品由 USGS 及合作机构自动或半自动生成， 涵盖从震源参数到灾害评估的完整链条。

产品类型 生成机构 说明
OriginUSGS / 区域台网震源位置解。一个事件可能有多个 Origin（不同台网或不同时间）
MagnitudeUSGS / 区域台网震级解。同一事件可能有多种标度
Moment TensorGCMT / USGS矩张量解，包含矩心位置、分量、最佳双力偶解
Focal MechanismUSGS / 区域台网断层面解（走向、倾角、滑动角）
Finite FaultUSGS有限断层滑动分布模型（M6.0+ 事件）
ShakeMapUSGS震动图，估计地面运动分布
DYFIUSGS“Did You Feel It?” 公众震感报告汇总
PAGERUSGS警报等级与影响评估（人员伤亡、经济损失）
Phase DataUSGS / 区域台网震相拾取（到时、振幅、周期、极性）
Ground FailureUSGS地面破坏评估（液化、滑坡概率）
WaveformIRIS DMC波形数据引用链接（通过 IRIS 获取）
产品获取：通过 FDSN Event Web Service 的 format=quakeml 请求可获取 Origin、Magnitude、Moment Tensor、 Focal Mechanism、Phase Data 等结构化数据。 ShakeMap、DYFI、PAGER 等产品需通过 ComCat API 或事件详情页单独获取。

4. 数据质量检查要点

  1. 检查事件状态： 优先使用 status=reviewed 的事件。 自动解（automatic）可能在数小时或数天内被审核解替换。
  2. 选择首选解： 一个事件可能包含多个 Origin 和 Magnitude。 QuakeML 中通过 preferredOriginID 和 preferredMagnitudeID 字段标识首选解， 使用时应遵循这些字段。
  3. 评估定位质量： 检查 nst、gap、dmin、 horizontalError 等字段。 台站数少、间隙大或误差大的事件，震中位置可能不可靠。
  4. 确认贡献台网： net 和 sources 字段标明数据来源。 美国区域事件优先使用对应区域台网（如 ci、ak）； 全球事件使用 us（NEIC）。
  5. 核对更新时刻： ComCat 数据动态更新，同一事件的信息可能随时间变化。 使用 updated 字段确认数据版本， 并在论文中注明数据获取日期。
  6. 版本一致性： 批量下载后如再次拉取，可能得到更新后的解。 建议锁定数据版本（记录下载日期和 event ID）， 避免分析结果因数据更新而不可重现。
  7. 产品完整性： 并非所有事件都有全部产品。 ShakeMap、PAGER 等通常仅对 M4.5+ 事件生成； 有限断层仅对 M6.0+ 事件生成。 使用前应确认所需产品是否可用。
Notes

使用注意事项

  1. 无需注册，免费开放： ComCat 提供无限制的免费访问， 无需注册账号或 API 密钥即可使用网页检索和 FDSN Web 服务。
  2. 数据许可为公共领域： USGS 数据属于美国联邦政府公共领域， 可自由使用和分发，但需注明数据来源。
  3. 实时更新，动态变化： ComCat 的动态特性意味着同一事件的信息可能随时间更新。 使用前应检查 updated 字段，并在论文中注明数据获取日期。
  4. 一个事件可能有多个 Origin： QuakeML 格式中一个事件可包含多个 Origin 和 Magnitude。 使用时应优先选择标记为 preferred 的解。
  5. 区域目录 vs 全球目录： 美国区域事件优先使用区域台网目录（如 ci、ak）， 全球事件使用 us 目录。可通过 catalog 参数指定。
  6. 全球监测阈值： USGS NEIC 监测全球 Mw 4.5+ 事件。 更低震级的事件可能仅在美国区域台网目录中提供。
  7. 时区为 UTC： ComCat 中所有时间均为 UTC 时间， ISO8601 格式。
  8. 推荐使用 ObsPy： ObsPy 的 obspy.clients.fdsn.Client 支持 USGS 事件服务，可直接获取 QuakeML 格式的事件数据。

引用格式

USGS 对数据引用有明确规范。使用 ComCat 数据时， 建议引用以下标准格式，并在致谢中注明 USGS 地震灾害计划。

官方推荐引用格式

Text
U.S. Geological Survey. (2017). Advanced National Seismic System (ANSS)
Comprehensive Catalog. U.S. Geological Survey.
https://doi.org/10.5066/F7MS3QZH

BibTeX 格式

BibTeX
@misc{ANSSComCat2017,
  title        = {Advanced National Seismic System (ANSS) Comprehensive Catalog},
  author       = {{U.S. Geological Survey}},
  year         = {2017},
  howpublished = {U.S. Geological Survey},
  doi          = {10.5066/F7MS3QZH},
  url          = {https://earthquake.usgs.gov/data/comcat/}
}

致谢格式

Text
Earthquake information was retrieved from the ANSS Comprehensive Catalog
(https://earthquake.usgs.gov/data/comcat/), operated by the U.S. Geological Survey.
引用要点：引用 ComCat 数据时， 应同时注明 USGS 地震灾害计划和所使用的具体贡献台网 （如 Alaska Earthquake Center、California Integrated Seismic Network 等）。 如使用了特定产品（如 ShakeMap、PAGER），也应一并引用。
