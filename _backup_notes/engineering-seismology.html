工程地震学

从地震危险性分析到地震动预测方程，覆盖 PSHA、GMPE、 一致危险性谱与设计地震动选取。 它是连接地震学与结构抗震设计的桥梁—— 把"地球如何振动"翻译成"结构需要抵抗多大的作用"。

PSHA GMPE UHS 设计地震动

§引言

工程地震学研究为工程目的如何表征地震作用。 它处于地震学与结构工程的交界处：

学科关注问题输出
地震学 震源如何破裂？波如何传播？ 震源参数、地球结构
工程地震学 场地未来可能遭遇多大的地震动？ 设计地震动参数、反应谱、时程
结构工程 结构如何抵抗地震作用？ 构件尺寸、配筋、构造

工程地震学的核心任务是回答三个问题：

  • 多大？——场地未来可能遭遇的地震动强度（PGA、谱加速度）。
  • 多频繁？——不同强度地震动的发生概率（年超越概率）。
  • 什么形状？——地震动的频谱与持时特性（反应谱、时程）。

在工程实践中，这三个问题由以下工具回答：

  • 地震危险性分析（PSHA / DSHA）：给出场地地震动参数的概率分布。
  • 地震动预测方程（GMPE）：从震级、距离、场地预测地震动。
  • 地震动模拟：合成与设计谱匹配的地震动时程。

这份笔记按"危险性 $\to$ 震源 $\to$ GMPE $\to$ PSHA $\to$ UHS $\to$ 选波 $\to$ 模拟 $\to$ 应用" 的顺序梳理，每一节都尽量落到工程语境上。

01地震危险性分析

两种方法

地震危险性分析分为两大类：

方法全称核心思想输出
DSHA 确定性地震危险性分析 假定特定震源发生特定地震，计算场地地震动 单一地震动值（"最坏情况"）
PSHA 概率地震危险性分析 考虑所有可能震源、震级、距离的概率分布 年超越概率曲线、一致危险性谱

DSHA 的基本流程

  1. 确定场地附近的活动断层与地震构造区。
  2. 对每个震源，确定"最大可信地震"（MCE）或"特征地震"。
  3. 假定震源发生该地震，计算场地到震源的距离。
  4. 用 GMPE 或衰减关系计算场地地震动。
  5. 取所有震源计算结果的最大值作为设计地震动。

DSHA 的优点是简单直观，缺点是：

  • 没有概率概念，无法区分"经常发生的小震"与"极少发生的大震"。
  • 不考虑不同震源的相对贡献。
  • 结果对"最大可信地震"的选取高度敏感。

PSHA 的基本思想

PSHA 由 Cornell（1968）提出，McGuire（1976）实现为计算机程序。 它的基本公式是：

$$ \lambda(Y > y) = \sum_{i} \nu_i \iiint P[Y > y \mid m, r] \, f_M(m) \, f_R(r) \, dm \, dr $$

其中：

  • $\lambda(Y > y)$：场地地震动 $Y$ 超过阈值 $y$ 的年发生率。
  • $\nu_i$：第 $i$ 个震源的年发生率。
  • $f_M(m)$：震级概率密度。
  • $f_R(r)$：距离概率密度。
  • $P[Y > y \mid m, r]$：给定震级与距离时，地震动超过 $y$ 的条件概率（由 GMPE 给出）。

年超越概率与重现期

年超越概率 $\lambda$ 与重现期 $T_R$ 的关系：

$$ T_R = \frac{1}{\lambda} $$

例如年超越概率 $0.0021$（即 1/475）对应重现期 475 年， 这正是"50 年超越概率 10%"的由来：

$$ 1 - (1 - 0.0021)^{50} \approx 0.10 $$
50 年超越概率年超越概率重现期典型用途
63% 0.02 50 年 多遇地震（小震）
10% 0.0021 475 年 设防地震（中震）
2% 0.0004 2475 年 罕遇地震（大震）
💡

DSHA 与 PSHA 的选择： 核电站、大坝等高安全要求设施通常两者并用—— PSHA 给出概率水平的设计地震动，DSHA 给出 MCE 作为上限校核。 普通建筑的设计地震动则直接由 PSHA 给出（规范中的"地震影响系数"）。 中国、美国、欧洲规范的设防地震动都基于 PSHA。

02震源模型

震源类型

PSHA 中需要把所有可能产生地震的源都建模。常见震源类型：

类型几何特点典型应用
断层源 三维面 已知活动断层，破裂位置受限 圣安德烈斯断层、龙门山断裂
区域源（面源） 二维多边形 地震分散在区域内，不集中在断层 地震活动性弱的区域
点源 单点 简化的震源 初步分析
网格源 密集点集 近似面源 计算优化

震级-频度关系

古登堡-里希特（Gutenberg-Richter）关系描述地震发生频率与震级的关系：

$$ \log_{10} N(M) = a - b M $$

其中：

  • $N(M)$：震级 $\ge M$ 的地震年发生次数。
  • $a$：地震活动性水平（截距）。
  • $b$：震级分布斜率，通常 $b \approx 1.0$，反映大小地震的相对比例。

$b$ 值的物理意义：$b = 1$ 时，震级每降低 1 级，地震次数增加 10 倍。 这意味着小震比大震频繁得多。

震级分布

在 PSHA 中，震级需要设上限 $M_{\max}$。常用的截断 GR 分布：

$$ f_M(m) = \frac{\beta e^{-\beta(m - M_{\min})}} {1 - e^{-\beta(M_{\max} - M_{\min})}}, \quad M_{\min} \le m \le M_{\max} $$

其中 $\beta = b \ln 10$，$M_{\min}$ 与 $M_{\max}$ 分别是震级下限与上限。

特征地震模型：某些断层上，大地震的发生频率比 GR 关系预测的更高， 形成"特征地震"现象。这是对一些断层（如圣安德烈斯断层南部）的观测结论。

距离分布

对点源或面源，距离分布由几何关系决定：

$$ f_R(r) = \frac{2r}{R_{\max}^2 - R_{\min}^2}, \quad R_{\min} \le r \le R_{\max} $$

对断层源，距离分布要考虑破裂面的几何—— 采用等效随机破裂（ERS）模型： 假定破裂等概率地发生在断层面的任意位置， 由此得到距离的概率密度。

逻辑树

PSHA 中的输入参数（$b$ 值、$M_{\max}$、GMPE 选择、场地参数） 都存在不确定性。工程上用逻辑树来表达：

  • 每个参数有若干"分支"，各分支有对应权重。
  • 所有分支的组合给出多条 PSHA 结果。
  • 用加权平均得到"中值"危险性与"分位数"危险性（如 15%、85%）。

现代 PSHA 平台（OpenQuake、CRISIS）都支持逻辑树。 一个典型的 PSHA 逻辑树有数百到数千个分支。

💡

震源模型的哲学：地震是罕见的随机事件， 人类无法精确预测下一次地震。 因此 PSHA 采用概率建模—— 把"未来是否发生"转化为"每年发生的概率"， 把"在哪里发生"转化为"距离的概率分布"。 这是工程地震学的基本方法论。

03地震动预测方程

GMPE 的作用

地震动预测方程（Ground Motion Prediction Equation，GMPE）， 也称衰减关系，是从震级、距离、场地条件预测地震动参数的经验公式：

$$ \ln Y = f(M, R, V_{S30}, \ldots) + \varepsilon $$

其中 $Y$ 是地震动参数（PGA、PGV、谱加速度 $S_a(T)$）， $\varepsilon$ 是残差，通常假设正态分布。

典型形式

一个简化的 GMPE 形式：

$$ \ln Y = c_1 + c_2 M + c_3 \ln(R + c_4) + c_5 R + c_6 \ln(V_{S30}/760) + \varepsilon $$

各项含义：

  • $c_1$：常数项，标定整体水平。
  • $c_2 M$：震级项，地震动随震级增加。
  • $c_3 \ln(R + c_4)$：几何衰减，近场平缓远场快速衰减。
  • $c_5 R$：非弹性衰减，远场加速衰减。
  • $c_6 \ln(V_{S30}/760)$：场地项，以 760 m/s 为参考。
  • $\varepsilon$：残差，标准差 $\sigma$ 反映预测不确定性。

距离的定义

不同 GMPE 使用不同的距离定义，必须与数据匹配：

符号含义适用
$R_{\text{epi}}$ 震中距（地表投影） 点源
$R_{\text{hyp}}$ 震源距（三维直线距离） 点源
$R_{\text{jb}}$ Joyner-Boore 距离（到破裂面地表投影） 有限断层
$R_{\text{rup}}$ 到破裂面的最近距离 有限断层，近场
$R_x$ 到断层走向的垂直距离 方向性研究

距离定义不一致是 GMPE 使用中最常见的错误来源。 必须仔细阅读原始文献，使用与拟合数据一致的距离定义。

残差结构

GMPE 的残差不是纯随机噪声，具有明显的结构：

$$ \varepsilon = \varepsilon_{\text{event}} + \varepsilon_{\text{path}} + \varepsilon_{\text{site}} + \varepsilon_{\text{measurement}} $$

常用分解：

  • 事件间残差 $\eta$：同一次地震不同台站的共同偏差。
  • 事件内残差 $\varepsilon$：不同台站之间的差异。
  • 场地残差：相同 $V_{S30}$ 场地的系统差异。

标准总残差：

$$ \sigma_{\text{total}} = \sqrt{\tau^2 + \phi^2} $$

其中 $\tau$ 是事件间标准差，$\phi$ 是事件内标准差。 典型值：$\tau \approx 0.3 \sim 0.5$，$\phi \approx 0.4 \sim 0.6$（对数单位）。

考虑残差相关性的 PSHA 需要事件间与事件内残差分别处理。 这就是为什么一致危险性谱（UHS）需要"解聚"分析—— 找到对危险性贡献最大的震级-距离组合。

Python 示例：简单 GMPE 与残差模拟

gmpe_residual.py Python 
import numpy as np
import matplotlib.pyplot as plt


def gmpe_simple(M, R, Vs30=760.0,
                c1=-1.0, c2=1.0, c3=-1.2, c4=10.0,
                c5=-0.002, c6=-0.3):
    """
    简化的 GMPE（示意，不用于实际工程）：
        ln(PGA) = c1 + c2·M + c3·ln(R + c4) + c5·R + c6·ln(Vs30/760)
    返回 ln(PGA)，单位 m/s²
    """
    return c1 + c2 * M + c3 * np.log(R + c4) + c5 * R + c6 * np.log(Vs30 / 760.0)


def simulate_gmpe_residual(M, R, Vs30=760.0, tau=0.4, phi=0.5, n_samples=10000):
    """
    模拟 GMPE 残差：
      ε = η + ε_内
      η ~ N(0, τ²)  事件间
      ε_内 ~ N(0, φ²) 事件内
    """
    rng = np.random.default_rng(42)

    # 中值预测
    ln_median = gmpe_simple(M, R, Vs30)

    # 事件间残差（同一次地震的所有台站共享）
    eta = rng.normal(0, tau, n_samples)

    # 事件内残差（各台站独立）
    eps_inner = rng.normal(0, phi, n_samples)

    # 总残差
    ln_total = ln_median + eta + eps_inner

    return np.exp(ln_total), ln_median


if __name__ == "__main__":
    # ---- GMPE 曲线：不同震级 ----
    R_arr = np.logspace(0, 2.5, 100)

    plt.figure(figsize=(12, 5))

    plt.subplot(1, 2, 1)
    for M in [5.0, 6.0, 7.0, 8.0]:
        ln_pga = gmpe_simple(M, R_arr, Vs30=760)
        plt.plot(R_arr, np.exp(ln_pga), label=f"M = {M}")
    plt.xlabel("距离 R / km")
    plt.ylabel("PGA / (m/s²)")
    plt.xscale("log")
    plt.yscale("log")
    plt.title("GMPE 中值预测（基岩）")
    plt.legend()
    plt.grid(True, which="both", alpha=0.3)

    # ---- 场地效应 ----
    plt.subplot(1, 2, 2)
    M, R = 6.5, 30.0
    Vs30_arr = np.logspace(np.log10(150), np.log10(1200), 100)
    ln_pga = gmpe_simple(M, R, Vs30_arr)
    plt.plot(Vs30_arr, np.exp(ln_pga))
    plt.xlabel("Vs30 / (m/s)")
    plt.ylabel("PGA / (m/s²)")
    plt.xscale("log")
    plt.title(f"场地效应（M={M}, R={R} km）")
    plt.grid(True, which="both", alpha=0.3)

    plt.tight_layout()
    plt.show()

    # ---- 残差分布 ----
    pga_samples, ln_median = simulate_gmpe_residual(M=6.5, R=30.0)

    print(f"M = 6.5, R = 30 km, Vs30 = 760 m/s")
    print(f"中值 PGA = {np.exp(ln_median):.4f} m/s²")
    print(f"16% 分位 = {np.percentile(pga_samples, 16):.4f} m/s²")
    print(f"50% 分位 = {np.percentile(pga_samples, 50):.4f} m/s²")
    print(f"84% 分位 = {np.percentile(pga_samples, 84):.4f} m/s²")

    ln_samples = np.log(pga_samples)
    print(f"\n对数残差标准差 σ = {np.std(ln_samples):.4f}")
    print(f"（理论 σ = sqrt(τ² + φ²) = sqrt(0.4² + 0.5²) = {np.sqrt(0.4**2 + 0.5**2):.4f}）")

  • PGA 随震级增大、随距离减小。
  • 软土（$V_{S30}$ 小）的 PGA 显著高于基岩。
  • 残差呈对数正态分布，标准差与 $\sqrt{\tau^2 + \phi^2}$ 一致。

04PSHA 方法

完整公式

对第 $i$ 个震源，地震动 $Y$ 超过阈值 $y$ 的年发生率：

$$ \lambda_i(Y > y) = \nu_i \int_{M_{\min}}^{M_{\max}} \int_{R_{\min}}^{R_{\max}} P[Y > y \mid m, r] \, f_M(m) \, f_R(r) \, dr \, dm $$

对多个震源求和：

$$ \lambda(Y > y) = \sum_i \lambda_i(Y > y) $$

条件概率 $P[Y > y \mid m, r]$ 由 GMPE 的对数正态假设给出：

$$ P[Y > y \mid m, r] = 1 - \Phi\!\left( \frac{\ln y - \ln \bar{Y}(m, r)}{\sigma} \right) $$

其中 $\bar{Y}(m, r)$ 是 GMPE 的中值预测， $\sigma$ 是总对数标准差，$\Phi$ 是标准正态累积分布函数。

数值实现

上述积分通常没有解析解，需要数值离散：

  • 把震级范围分成若干区间（如 $M_{\min}$ 到 $M_{\max}$，步长 0.1）。
  • 把距离范围分成若干区间。
  • 在每个 $(m_j, r_k)$ 网格点计算贡献。
  • 加权求和得到年发生率。

现代实现（OpenQuake、CRISIS）用更精细的算法：

  • 等效随机破裂：处理有限断层源。
  • 自适应网格：在贡献大的区域加密。
  • 截断正态：处理残差的有界性。

危险性曲线

对一系列阈值 $y$（如 PGA = 0.01g, 0.02g, ..., 1.0g）， 计算对应的 $\lambda(Y > y)$， 得到危险性曲线：$\lambda$ 随 $y$ 的变化。

双对数坐标下，危险性曲线通常近似为直线：

$$ \log \lambda = a - b \log y $$

这是 PSHA 结果的基本形式，也是场地地震危险性最直接的表达。

地震动参数的完整危险性

对多个周期分别做 PSHA，得到：

  • PGA 的危险性曲线
  • $S_a(0.2\text{ s})$ 的危险性曲线
  • $S_a(1.0\text{ s})$ 的危险性曲线
  • ……

对每个周期，取相同超越概率（如 10%/50 年）对应的值， 组合成一致危险性谱（UHS）。

Python 示例：简化的 PSHA 计算

psha_simple.py Python 
import numpy as np
from scipy.stats import norm
import matplotlib.pyplot as plt


def gmpe_ln_pga(M, R, Vs30=760.0,
                c1=-1.0, c2=1.0, c3=-1.2, c4=10.0,
                c5=-0.002, c6=-0.3):
    """简化 GMPE，返回中值 ln(PGA)"""
    return c1 + c2 * M + c3 * np.log(R + c4) + c5 * R + c6 * np.log(Vs30 / 760.0)


def psha_point_source(y_arr, nu=0.01, M_range=(4.5, 7.5),
                       R_range=(5.0, 200.0), sigma=0.6, Vs30=760.0,
                       n_M=30, n_R=40):
    """
    简化 PSHA：单个点源。
    y_arr:  PGA 阈值数组（m/s²）
    nu:     震源年发生率
    M_range, R_range: 震级与距离范围
    sigma:  GMPE 总对数标准差
    """
    # 网格离散
    M_edges = np.linspace(M_range[0], M_range[1], n_M + 1)
    R_edges = np.linspace(R_range[0], R_range[1], n_R + 1)
    M_mid = 0.5 * (M_edges[:-1] + M_edges[1:])
    R_mid = 0.5 * (R_edges[:-1] + R_edges[1:])

    # 震级分布（截断 GR，b=1）
    b = 1.0
    beta = b * np.ln10 if hasattr(np, 'ln10') else b * np.log(10)
    fM = beta * np.exp(-beta * (M_mid - M_range[0])) / \
         (1 - np.exp(-beta * (M_range[1] - M_range[0])))
    dM = M_edges[1] - M_edges[0]
    fM = fM * dM

    # 距离分布（点源，面积均匀，f_R(r) ∝ 2r）
    fR = 2 * R_mid / (R_range[1]**2 - R_range[0]**2)
    dR = R_edges[1] - R_edges[0]
    fR = fR * dR

    # 危险性曲线
    lambda_arr = np.zeros(len(y_arr))
    for i, y in enumerate(y_arr):
        ln_y = np.log(y)
        total = 0.0
        for j, m in enumerate(M_mid):
            for k, r in enumerate(R_mid):
                ln_median = gmpe_ln_pga(m, r, Vs30)
                # P[Y > y | m, r] = 1 - Φ((ln y - ln median) / σ)
                prob = 1.0 - norm.cdf((ln_y - ln_median) / sigma)
                total += prob * fM[j] * fR[k]
        lambda_arr[i] = nu * total

    return lambda_arr


if __name__ == "__main__":
    # ---- 参数 ----
    nu = 0.01         # 年发生率
    T_return = 475.0  # 重现期
    lambda_target = 1.0 / T_return

    # ---- 计算危险性曲线 ----
    y_arr = np.logspace(np.log10(0.001), np.log10(2.0), 50)
    lambda_arr = psha_point_source(y_arr, nu=nu, sigma=0.6)

    idx = np.argmin(np.abs(lambda_arr - lambda_target))
    PGA_design = y_arr[idx]
    print(f"震源年发生率 ν = {nu}")
    print(f"重现期 T_R = {T_return} 年 → λ = {lambda_target:.6f}")
    print(f"设计 PGA（475 年重现期）= {PGA_design:.4f} m/s² "
          f"= {PGA_design/9.81:.4f} g")

    plt.figure(figsize=(10, 5))
    plt.loglog(y_arr, lambda_arr, "b-", label="危险性曲线")

                label=f"PGA = {PGA_design:.3f} m/s²")

    plt.ylabel("年超越概率 λ")
    plt.title("PSHA 危险性曲线（简化点源）")
    plt.legend()
    plt.grid(True, which="both", alpha=0.3)
    plt.tight_layout()
    plt.show()

    print("\nσ 对设计 PGA 的影响：")
    print(f"{'σ':>6}{'设计 PGA (m/s²)':>20}")
    for sigma in [0.4, 0.5, 0.6, 0.7, 0.8]:
        lam = psha_point_source(y_arr, nu=nu, sigma=sigma)
        idx = np.argmin(np.abs(lam - lambda_target))
        print(f"{sigma:>6.1f}{y_arr[idx]:>20.4f}")

运行后可以看到危险性曲线随 $\sigma$ 增大而"抬高"—— 残差标准差越大，相同 PGA 水平的超越概率越高， 对应的设计 PGA 也越大。

💡

PSHA 的核心思想：把所有"不确定性" 都转化为"概率"，然后积分。 震源位置不确定 → 距离的概率分布； 震级不确定 → 震级的概率分布； 地震动预测不确定 → GMPE 的残差分布。 最终的输出是年超越概率曲线—— 这是工程地震学最核心的产物。

05一致危险性谱

定义

一致危险性谱（Uniform Hazard Spectrum，UHS） 是在每个周期上取相同超越概率对应的谱加速度， 组合成的反应谱。

具体步骤：

  1. 对每个周期 $T_i$，用 PSHA 计算 $S_a(T_i)$ 的危险性曲线。
  2. 对每个周期，取目标超越概率（如 10%/50 年）对应的 $S_a$ 值。
  3. 把所有这些 $(T_i, S_a(T_i))$ 连成曲线，就是 UHS。

UHS 的特点

UHS 的关键特征：

  • 每个周期的年超越概率相同（"一致"）。
  • 通常对应"50 年超越概率 2%"或"10%"等目标。
  • 是抗震设计谱的基础（规范设计谱由 UHS 简化得到）。

UHS 的"解聚"问题

UHS 有一个重要的局限： 不同周期上，贡献最大的震级-距离组合可能不同。

周期主导震级主导距离物理意义
短周期（0.1~0.3 s） 小震（M 5~6） 近场（10~30 km） 高频，由小震近场贡献
中周期（0.5~1.0 s） 中震（M 6~7） 中距（30~80 km） 过渡区
长周期（> 2 s） 大震（M 7~8） 远场（> 80 km） 低频，由大震远场贡献

这意味着 UHS 并不对应"某一个真实地震"的谱， 而是多个不同地震的组合。 对需要一致地震动输入的工程问题（如非线性时程分析）， 必须做解聚分析找出主导的震级-距离组合， 再选取或合成对应的地震动。

条件均值谱（CMS）

为解决 UHS 的"非一致性"问题，Baker（2011）提出条件均值谱（CMS）： 给定某周期 $T^*$ 的谱加速度 $S_a(T^*)$， 其他周期的条件均值谱为：

$$ \mu_{\ln S_a(T_i) \mid S_a(T^*)} = \mu_{\ln S_a(T_i)} + \rho(T_i, T^*) \sigma_{\ln S_a(T_i)} \cdot \frac{\ln S_a(T^*) - \mu_{\ln S_a(T^*)}}{\sigma_{\ln S_a(T^*)}} $$

其中 $\rho(T_i, T^*)$ 是两个周期之间的相关系数。 CMS 给出的是"结构主要周期确定时的条件谱"， 更符合结构响应的物理意义。

CMS 在现代性能化抗震设计中得到广泛应用， 特别是作为非线性时程分析的输入谱。

Python 示例：简化的 UHS 计算

uhs.py Python 
import numpy as np
from scipy.stats import norm
import matplotlib.pyplot as plt


def gmpe_ln_sa(M, R, T, Vs30=760.0):
    """
    简化的谱加速度 GMPE（示意）。
    ln(Sa) = c0(T) + c1(T)·M + c2(T)·ln(R + c3(T)) + c4(T)·R + c5(T)·ln(Vs30/760)
    其中系数随周期变化（此处简化形式）。
    """
    # 周期相关的系数（简化）
    c0 = -2.0 - 0.5 * np.log(T) if T > 0.1 else -2.0
    c1 = 1.0
    c2 = -1.0
    c3 = 10.0
    c4 = -0.002
    c5 = -0.4
    return c0 + c1 * M + c2 * np.log(R + c3) + c4 * R + c5 * np.log(Vs30 / 760.0)


def psha_sa(y_arr, T, nu=0.01, M_range=(4.5, 7.5),
            R_range=(5.0, 200.0), sigma=0.6, Vs30=760.0,
            n_M=25, n_R=30):
    """对给定周期 T 计算 Sa 的危险性曲线"""
    M_edges = np.linspace(M_range[0], M_range[1], n_M + 1)
    R_edges = np.linspace(R_range[0], R_range[1], n_R + 1)
    M_mid = 0.5 * (M_edges[:-1] + M_edges[1:])
    R_mid = 0.5 * (R_edges[:-1] + R_edges[1:])

    b = 1.0
    beta = b * np.log(10)
    fM = beta * np.exp(-beta * (M_mid - M_range[0])) / \
         (1 - np.exp(-beta * (M_range[1] - M_range[0])))
    fM *= (M_edges[1] - M_edges[0])

    fR = 2 * R_mid / (R_range[1]**2 - R_range[0]**2)
    fR *= (R_edges[1] - R_edges[0])

    lambda_arr = np.zeros(len(y_arr))
    for i, y in enumerate(y_arr):
        ln_y = np.log(y)
        total = 0.0
        for j, m in enumerate(M_mid):
            for k, r in enumerate(R_mid):
                ln_med = gmpe_ln_sa(m, r, T, Vs30)
                prob = 1.0 - norm.cdf((ln_y - ln_med) / sigma)
                total += prob * fM[j] * fR[k]
        lambda_arr[i] = nu * total
    return lambda_arr


def compute_uhs(periods, T_return=475.0, nu=0.01):
    """对多个周期计算 UHS"""
    lambda_target = 1.0 / T_return
    Sa_uhs = np.zeros(len(periods))

    for i, T in enumerate(periods):
        # 阈值网格（周期相关，长周期 Sa 更大）
        y_arr = np.logspace(np.log10(0.001), np.log10(5.0), 60)
        lam = psha_sa(y_arr, T, nu=nu)
        idx = np.argmin(np.abs(lam - lambda_target))
        Sa_uhs[i] = y_arr[idx]

    return Sa_uhs


if __name__ == "__main__":

    print("一致危险性谱（T_R = 475 年）：")

06设计地震动选取

三种设计地震动

工程设计中常见三种设计地震动：

类型来源用途
规范设计谱 规范给定的标准化谱 常规结构设计
场地设计谱 PSHA + 场地反应分析 重要结构、特殊场地
设计地震动时程 实际记录 + 人工合成 时程分析

选波的三条准则

选取实际强震记录作为设计地震动时，需满足：

准则要求常用判据
幅值匹配 PGA / PGV 与设计水平一致 PGA 差 < 20%
频谱匹配 在结构主要周期段，谱形状与设计谱匹配 SSE < 10%
持时匹配 有效持时覆盖结构主要响应时段 $t_{5-95}$ 与目标一致

频谱匹配常用指标是SSE（Sum of Squared Errors）：

$$ \mathrm{SSE} = \sum_i \left[ \ln S_a^{\text{记录}}(T_i) - \ln S_a^{\text{目标}}(T_i) \right]^2 $$

通常在结构主要周期段（如 $0.2T_1$ 到 $2T_1$）计算， 越小越好。

选波数量

各国规范对选波数量的要求：

  • 中国 GB 50011：至少 2 组实际 + 1 组人工，共 3 组。取包络。
  • 美国 ASCE 7：至少 3 组，取最大值；至少 7 组，取平均值。
  • 欧洲 EC8：至少 3 组，取最大值；至少 7 组，取平均值。

为什么 7 组？统计上，7 组样本的平均值标准误差约为样本标准差的 38%， 已经接近工程可接受水平。这是统计推断与工程实践的折中。

幅值调整

选出记录后，需要调整幅值以匹配设计水平。常用方法：

  • 单一缩放系数：把整条记录乘以 $k$，使 PGA 或某个周期 $S_a$ 匹配目标。简单、常用。
  • 频谱匹配：在频域内调整，使整个反应谱匹配目标。更精细，但可能引入非物理成分。
  • 小波调整：用时频分析调整，保持时域特性。

常用的单一缩放系数：

$$ k = \frac{S_a^{\text{目标}}(T_1)} {S_a^{\text{记录}}(T_1)} $$

其中 $T_1$ 是结构第一阶自振周期。 这种调整使记录在结构主要周期处与设计谱匹配。

人工合成地震动

当实际记录不足或需要特定谱形时，人工合成。常用方法：

  • 三角级数法：用正弦波叠加，迭代调整幅值谱与相位。
  • 随机振动法：用目标功率谱生成平稳随机过程，乘以包络函数。
  • 经验格林函数法：用小震记录作为经验格林函数，通过叠加合成大震。
  • 物理模拟法：用震源模型 + 波传播模拟合成（如有限断层模型）。

三角级数法的基本形式：

$$ a(t) = f(t) \sum_{k=1}^{n} A_k \cos(\omega_k t + \varphi_k) $$

其中 $f(t)$ 是包络函数（如指数上升-下降型）， $A_k$ 由目标谱确定，$\varphi_k$ 是随机相位。

import numpy as np
import matplotlib.pyplot as plt


def target_spectrum(T, PGA=0.3, Tg=0.4):
    """
    简化设计谱（三段式）。
    T:    周期数组 s
    PGA:  峰值加速度 g
    Tg:   特征周期 s
    """
    Sa = np.zeros_like(T)
    for i, Ti in enumerate(T):
        if Ti < 0.1:
            Sa[i] = PGA * (0.45 + 5.5 * Ti)
        elif Ti <= Tg:
            Sa[i] = PGA * 2.25
        elif Ti <= 5 * Tg:
            Sa[i] = PGA * 2.25 * (Tg / Ti)
        else:
            Sa[i] = PGA * 2.25 * (Tg / (5 * Tg)) * (5 * Tg / Ti)
    return Sa


def sdof_sa(ag, dt, T, zeta=0.05):
    """计算一条记录的 Sa(T)"""
    from scipy.integrate import solve_ivp

    omega = 2 * np.pi / T
    c = 2 * zeta * omega

    def rhs(t, y):
        u, v = y
        # 线性插值 ag(t)
        idx = int(t / dt)
        idx = min(idx, len(ag) - 1)
        return [v, -c * v - omega**2 * u - ag[idx]]

    sol = solve_ivp(rhs, [0, len(ag) * dt], [0, 0],
                    max_step=dt, dense_output=True)
    n = len(ag)
    t_arr = np.arange(n) * dt
    u_arr = sol.sol(t_arr)[0]
    a_rel = np.gradient(np.gradient(u_arr, dt), dt)
    a_abs = a_rel + ag
    return np.max(np.abs(a_abs))


def compute_spectrum(ag, dt, periods, zeta=0.05):
    """计算记录的反应谱"""
    Sa = np.zeros_like(periods)
    for i, T in enumerate(periods):
        Sa[i] = sdof_sa(ag, dt, T, zeta)
    return Sa


def select_and_scale(records, dt, periods, target_Sa, T1=1.0):
    """
    从若干记录中选出与目标谱最匹配的一条，并缩放。
    records: 记录列表 [(name, ag), ...]
    T1:      结构主要周期 s
    """
    # 找目标周期 T1 对应的目标 Sa
    idx_T1 = np.argmin(np.abs(periods - T1))
    Sa_target_T1 = target_Sa[idx_T1]

    results = []
    for name, ag in records:
        Sa = compute_spectrum(ag, dt, periods)
        # 缩放系数
        k = Sa_target_T1 / Sa[idx_T1]
        ag_scaled = ag * k
        Sa_scaled = Sa * k

        # SSE（在 0.2T1 ~ 2T1 范围）
        mask = (periods >= 0.2 * T1) & (periods <= 2 * T1)
        sse = np.sum((np.log(Sa_scaled[mask]) -
                      np.log(target_Sa[mask]))**2)
        results.append({
            "name": name,
            "scale": k,
            "sse": sse,
            "Sa": Sa_scaled,
            "ag": ag_scaled,
        })

    results.sort(key=lambda x: x["sse"])
    return results

    for r in results:
        print(f"{r['name']:>6}{r['scale']:>12.4f}{r['sse']:>12.4f}")

07地震动模拟

为什么需要模拟

在以下情形，实际记录不足或不适用，需要模拟地震动：

  • 缺少近场大震记录（如 Mw > 7 的断层距 < 20 km 记录）。
  • 需要特定震级-距离-场地组合的记录。
  • 需要大量样本进行概率分析。
  • 需要与目标谱精确匹配的时程。
  • 研究震源或路径效应对地震动的影响。

模拟方法分类

方法原理优点缺点
经验格林函数法 小震记录叠加合成大震 保留真实路径与场地效应 需要合适的小震记录
随机振动法 白噪声过滤 + 包络 简单、快速 缺少物理相位信息
确定性方法 震源 + 波传播数值模拟 物理机制清晰 需要三维速度结构，计算量大
混合方法 低频确定性 + 高频随机 覆盖全频段 方法复杂，参数多

随机振动法（Boore 方法）

随机振动法是最广泛使用的地震动模拟方法之一。 基本流程：

  1. 生成白噪声时程。
  2. 用震源谱 $S(f)$、路径效应 $P(f)$、场地效应 $G(f)$ 过滤。
  3. 乘以时间包络函数。
  4. 调整幅值使与目标 PGA 一致。

震源谱通常用 $\omega^2$ 模型：

$$ S(f) = \frac{M_0}{1 + (f / f_c)^2} $$

其中 $M_0$ 是地震矩，$f_c$ 是拐角频率：

$$ f_c = 4.9 \times 10^6 \cdot V_s \cdot \left(\frac{\Delta\sigma}{M_0}\right)^{1/3} $$

$\Delta\sigma$ 是应力降（bar），$M_0$ 单位 dyn·cm。

路径效应：

$$ P(f) = \frac{1}{R} \exp\!\left(-\frac{\pi f R}{Q(f) V_s}\right) $$

其中 $Q(f)$ 是品质因子，反映介质的非弹性衰减。

经验格林函数法

用小震记录作为经验格林函数，通过叠加合成大震：

$$ A_{\text{main}}(t) = \sum_{i} \sum_{j} \frac{r_{\text{small}}}{r_{\text{main}}} \cdot A_{\text{small}}(t - \Delta t_{ij}) $$

其中 $\Delta t_{ij}$ 是子源相对于破裂起始的时间延迟。 该方法能保留真实的路径与场地效应， 广泛用于近场大震模拟。

确定性方法

从震源模型出发，用数值方法求解波传播方程， 合成地表地震动。常用：

  • 有限差分法：规则网格，适合大规模模拟。
  • 谱元法：高精度，适合复杂几何。
  • 边界元法：适合分层介质。
  • 有限断层模型：把断层离散为子断层，叠加各子源的贡献。

Python 示例：随机振动法模拟

simulation.py Python 
import numpy as np
import matplotlib.pyplot as plt


def envelope(t, t_rise=2.0, t_flat=8.0, t_decay=5.0):
    """
    时间包络函数（Jennings 型）：
      - 0 到 t_rise：指数上升
      - t_rise 到 t_flat：常数 1
      - 之后：指数衰减
    """
    env = np.zeros_like(t)
    env[t < t_rise] = (t[t < t_rise] / t_rise) ** 2
    env[(t >= t_rise) & (t < t_flat)] = 1.0
    env[t >= t_flat] = np.exp(-(t[t >= t_flat] - t_flat) / t_decay)
    return env


def source_spectrum(f, M0, fc):
    """ω² 震源谱"""
    return M0 / (1 + (f / fc)**2)


def path_effect(f, R, Q0=300.0, Vs=3500.0):
    """路径效应：几何衰减 + 非弹性衰减"""
    return np.exp(-np.pi * f * R / (Q0 * Vs)) / R


def simulate_stochastic(Mw, R, Vs30=500.0, dt=0.01, t_end=30.0,
                        stress_drop=100.0, Q0=300.0, Vs=3500.0,
                        seed=42):
    """
    随机振动法模拟地震动（简化版）。
    Mw:  矩震级
    R:   距离 km
    stress_drop: 应力降 bar
    """
    rng = np.random.default_rng(seed)
    n = int(t_end / dt)
    t = np.arange(n) * dt

    # 地震矩（dyn·cm）
    M0 = 10 ** (1.5 * (Mw + 10.7))

    # 拐角频率（简化）
    fc = 4.9e6 * Vs * (stress_drop / M0) ** (1/3)

    # 频率轴
    freqs = np.fft.rfftfreq(n, d=dt)
    omega = 2 * np.pi * freqs

    # 震源谱
    S = source_spectrum(freqs, M0, fc)

    # 路径效应
    P = path_effect(freqs, R, Q0, Vs)

    # 场地效应（简化：高频放大）
    site_amp = 1.0 + 0.5 * np.exp(-freqs / 5.0) * (Vs30 / 500.0)**(-0.3)

    # 总谱
    total_spec = S * P * site_amp

    # 生成白噪声，在频域滤波
    white = rng.normal(0, 1, len(freqs))
    filtered = white * np.sqrt(total_spec)

    # IFFT
    ag = np.fft.irfft(filtered, n=n)

    # 归一化
    ag = ag / np.std(ag)

    # 应用时间包络
    env = envelope(t, t_rise=2.0, t_flat=8.0, t_decay=5.0)
    ag = ag * env

    # 归一化到目标 PGA（由 GMPE 给出，这里简化）
    target_pga = 10 ** (0.5 * Mw - 1.0 * np.log10(R + 10) - 0.002 * R + 1.5) / 100.0
    ag = ag / np.max(np.abs(ag)) * target_pga

    return t, ag


if __name__ == "__main__":
    # ---- 模拟不同震级与距离 ----
    fig, axes = plt.subplots(2, 2, figsize=(13, 7))
    axes = axes.flatten()

    cases = [(6.0, 20.0), (6.5, 30.0), (7.0, 50.0), (7.5, 100.0)]

    for ax, (Mw, R) in zip(axes, cases):
        t, ag = simulate_stochastic(Mw, R, seed=int(Mw * 10 + R))
        pga = np.max(np.abs(ag))
        ax.plot(t, ag, linewidth=0.7)
        ax.set_title(f"Mw = {Mw}, R = {R} km\nPGA = {pga:.3f} m/s²")
        ax.set_xlabel("t / s")
        ax.set_ylabel("加速度 / (m/s²)")
        ax.grid(True, alpha=0.3)

    plt.tight_layout()
    plt.show()

    # ---- 参数研究：应力降对 PGA 的影响 ----
    print("应力降对 PGA 的影响（Mw=6.5, R=30 km）：")
    print(f"{'应力降 (bar)':>15}{'PGA (m/s²)':>15}")
    for ds in [30, 50, 100, 200]:
        t, ag = simulate_stochastic(6.5, 30, stress_drop=ds, seed=1)
        print(f"{ds:>15}{np.max(np.abs(ag)):>15.4f}")

运行后可以看到：

  • 震级越大、距离越近，PGA 越高。
  • 应力降越大，高频成分越丰富，PGA 越高。
  • 包络形状决定了地震动的"三段式"特征。
💡

模拟与记录的互补关系： 实际记录是最真实的地震动样本， 但数量有限、覆盖面有限； 模拟地震动可以按需生成任意震级-距离-场地组合， 但物理真实性依赖模型假设。 工程实践中通常两者结合： 记录用于标定与验证，模拟用于补充与扩展。

重大工程场地地震安全性评价

核电站、大坝、超高层、跨海大桥等重大工程必须做场地地震安全性评价。 工作流程：

  1. 区域地震构造与地震活动性研究。
  2. 近场地震构造与断层活动性鉴定。
  3. 地震危险性分析（PSHA + DSHA）。
  4. 场地地震动参数确定（含场地效应）。
  5. 设计地震动时程合成。
  6. 地震地质灾害评估（液化、滑坡、地表破裂）。

09小结

📌 核心要点

  • 地震危险性分析：DSHA 给出最坏情况，PSHA 给出概率曲线；工程中两者常并用。
  • 震源模型：断层源、面源、点源；GR 关系 + 截断分布 + 距离分布 + 逻辑树。
  • GMPE：从 $M$、$R$、$V_{S30}$ 预测地震动；残差分解为事件间与事件内。
  • PSHA 公式：年发生率 = 年发生率 × 震级分布 × 距离分布 × 条件超越概率。
  • 重现期：$\lambda = 1/T_R$；50 年 10% 对应 475 年重现期。
  • 一致危险性谱：每个周期相同超越概率；不同周期的主导震级-距离不同。
  • 设计地震动选取：幅值、频谱、持时三准则；7 条记录取平均。
  • 地震动模拟：随机振动法、经验格林函数法、确定性方法、混合方法。
  • 工程应用：规范设计谱、地震区划图、场地地震安全性评价、重大工程。

关键公式速查

公式含义用途
$\log_{10} N(M) = a - bM$ 古登堡-里希特关系 震级频度分布
$\lambda(Y > y) = \sum_i \nu_i \iint P \cdot f_M \cdot f_R$ PSHA 主公式 危险性曲线
$T_R = 1/\lambda$ 重现期与年超越概率 设防水平转换
$\ln Y = f(M, R, V_{S30}) + \varepsilon$ GMPE 形式 地震动预测
$\sigma_{\text{total}} = \sqrt{\tau^2 + \phi^2}$ 总残差标准差 GMPE 不确定性
$\mu_{\ln S_a(T_i) \mid S_a(T^*)}$ 条件均值谱 CMS 计算
$\mathrm{SSE} = \sum (\ln S_a^{\text{rec}} - \ln S_a^{\text{target}})^2$ 频谱匹配误差 选波评价
$f_c = 4.9\times10^6 V_s (\Delta\sigma/M_0)^{1/3}$ 拐角频率 随机振动法模拟
