定量地震学

从震源矩张量出发，定量描述地震波的辐射、传播与场地效应， 最终落到波形反演——用观测波形反推震源参数。 这是连接地震学观测与震源物理的完整链条。

震源 矩张量 波形反演 定量地震学

§引言

定量地震学的目标，是用物理量描述“地震发生了什么”，并预测“观测到的波形会是什么样”。 这需要一个从震源到传播路径再到台站场地 的完整模型链：

$$ u(t) = s(t) * g(t) * h(t) $$

其中 $s$ 为震源项，$g$ 为路径项，$h$ 为场地项，$*$ 表示卷积

本笔记按这条链条展开：矩张量描述震源，辐射图型刻画空间分布， 震级建立经验标度，衰减与场地描述传播与放大， 波形反演则将观测反推回震源参数。

01震源矩张量

定义

地震矩张量 $M_{ij}$ 是描述点源震源的最通用表示， 它由 9 个分量组成的对称二阶张量，物理意义是等效体积力系。

$$ M_{ij} = M_0 \, (\hat{u}_i \hat{n}_j + \hat{u}_j \hat{n}_i) $$

其中 $M_0 = \mu A \bar{D}$，$\mu$ 为剪切模量，$A$ 为断层面积，$\bar{D}$ 为平均滑动量

分量含义

分量物理意义典型特征
$M_{xx}$、$M_{yy}$、$M_{zz}$ 正应力偶极子 爆炸源、塌陷源、体积变化
$M_{xy}$、$M_{xz}$、$M_{yz}$ 剪应力偶极子 构造地震的主要成分
迹 $\mathrm{tr}(M)$ 各向同性部分 非双力偶分量的度量

双力偶与最佳双力偶

大多数构造地震可以近似为双力偶（Double-Couple, DC）模型， 其特征是两个正交的力偶，对应断层的两个节面。 矩张量分解为 DC、CLVD（补偿线性矢量偶极）与 ISO（各向同性）三部分：

$$ M = M_{\mathrm{DC}} + M_{\mathrm{CLVD}} + M_{\mathrm{ISO}} $$

通过特征值分解实现，反映震源的非双力偶成分

💡

为什么重要：矩张量不仅能给出震源机制解（走向、倾角、滑动角）， 还能给出标量地震矩 $M_0$，从而与矩震级 $M_w$ 直接对应。 它是现代震源研究的基础语言。

02辐射图型

基本原理

震源向各个方向辐射的波能量并不均匀，辐射强度随方位和离源角变化的图样称为 辐射图型（radiation pattern）。对双力偶源，P 波和 S 波的辐射系数分别为：

$$ R^{P}(\theta, \varphi) = \sin^2\theta \cdot \sin(2\varphi), \qquad R^{SV}(\theta, \varphi) = \sin(2\theta) \cdot \sin(2\varphi) $$

$\theta$ 为离源角（相对垂直轴），$\varphi$ 为方位角（相对断层走向）

典型特征

  • P 波四象限分布：两条正交节线把辐射分成压缩区与膨胀区。
  • S 波辐射更强：在断层滑动方向能量最集中。
  • 节面（nodal plane）：P 波辐射为零的方向，对应断层或辅助面。

与震源机制解的关系

通过观测 P 波初动极性（压缩/膨胀）的方位分布，可以反推节面方位， 得到震源机制解——通常用“沙滩球”图表示。 这是震源机制解的最经典确定方法，称为初动法。

⚠️

注意：初动法只能确定节面方位，无法区分主断层面与辅助面。 要区分两者，需要依赖余震分布、区域构造应力场或波形反演。

03震级标度关系

主要震级类型

震级基于适用饱和
$M_L$（近震）Wood-Anderson 记录最大振幅地方性小震≈ 6.5
$m_b$（体波）P 波 1 s 周期振幅深震、远震≈ 6.0
$M_S$（面波）20 s 周期面波振幅浅源远震≈ 8.0
$M_w$（矩）标量地震矩 $M_0$全范围不饱和

矩震级公式

矩震级由 Kanamori (1977) 提出，直接从地震矩换算：

$$ M_w = \frac{2}{3} \log_{10} M_0 - 6.07 $$

$M_0$ 单位 N·m，6.07 为经验常数（也有用 6.03 或 10.7 的版本）

能量与震级

Gutenberg-Richter 能量-震级关系：

$$ \log_{10} E = 1.5 \, M_S + 4.8 $$

$E$ 单位 J，震级每增加 1，能量增加约 31.6 倍

经验换算

不同震级之间并无严格的物理等价关系，只能通过经验回归近似。 例如 Wells & Coppersmith (1994) 给出的 $m_b$–$M_w$ 关系：

$$ M_w = 0.85 \, m_b + 1.03 $$

适用于 $m_b \in [4, 7]$ 范围的全球地震

04地震波衰减

几何扩散

地震波从震源向外传播，能量分布在越来越大的波前上，振幅随距离衰减。 对体波（球面扩散）：

$$ A \propto 1 / R $$

$R$ 为震源距，面波为柱面扩散 $A \propto 1/\sqrt{R}$

非弹性衰减

介质的非弹性吸收使振幅随距离指数衰减：

$$ A(R) = A_0 \, R^{-n} \, e^{-\pi f R / (Q V)} $$

$n$ 为几何扩散指数，$Q$ 为品质因子，$V$ 为波速

品质因子 Q

介质P 波 $Q_P$S 波 $Q_S$
地壳（稳定区）800 – 2000400 – 1000
地壳（活动区）300 – 600150 – 300
地幔（上部）200 – 500100 – 300
沉积层20 – 10010 – 50
💡

Q 的物理意义：$Q$ 越大，介质越“弹性”，衰减越弱。 $Q$ 定义为每个周期内耗散能量与储存能量之比的倒数： $Q = 2\pi \cdot E_{\mathrm{stored}} / \Delta E_{\mathrm{dissipated}}$。

05场地响应

场地放大机制

软土场地对地震动具有放大作用，尤其是接近场地卓越频率的成分。 最简单的模型是单层土覆盖基岩：

$$ f_0 = \frac{V_S}{4H} $$

$f_0$ 为卓越频率，$V_S$ 为剪切波速，$H$ 为土层厚度

传递函数

定义场地传递函数 $H(\omega)$ 为地表运动与基岩运动之比。在单层情况下：

$$ H(\omega) = \frac{1}{\cos(\omega H / V_S) + i \, \xi \, \sin(\omega H / V_S)} $$

$\xi$ 为土层的等效阻尼比

常用估计方法

  • H/V 谱比法：用单台三分量记录的水平/垂直谱比估计卓越频率，不需要参考基岩台。
  • 标准谱比法（SSR）：同时有基岩和地表台站，直接相除。
  • 广义反演法（GIT）：把震源、路径、场地三项分离，同时求解。
⚠️

H/V 的局限：H/V 谱比只对卓越频率比较可靠， 不能直接作为放大倍数使用。若需要定量放大，应结合 SSR 或数值模拟。

06波形反演

基本思路

波形反演的目标是：给定观测波形 $d_{\mathrm{obs}}(t)$，求解一组震源参数 $m$， 使得合成波形 $d_{\mathrm{syn}}(t; m)$ 与观测波形尽可能接近。

$$ \hat{m} = \arg\min_{m} \left\| d_{\mathrm{obs}}(t) - d_{\mathrm{syn}}(t; m) \right\|^2 $$

$m$ 通常包含矩张量、深度、时间函数、位置等

常用方法

方法特点适用
最小二乘线性反演 假设震源为点源，格林函数预先计算 中小地震矩张量反演
模拟退火 / 遗传算法 全局搜索，不依赖初始模型 非线性强、参数空间大
邻域算法（NA） 在模型空间中“随机游走”，效率高 多参数联合反演
全波形反演（FWI） 利用完整波形，分辨率高 地震勘探、区域结构

Python 示例

一个简化的矩张量反演流程（示意，不含完整格林函数计算）：

moment_tensor_inversion.py Python 
import numpy as np
from scipy.optimize import least_squares

def synthesize(mt, green):
    """根据矩张量 mt 和格林函数 green 合成波形"""
    # mt: 6 维向量 [Mxx, Myy, Mzz, Mxy, Mxz, Myz]
    # green: 对应的 6 分量格林函数字典
    syn = np.zeros_like(green['xx'])
    syn += mt[0] * green['xx']
    syn += mt[1] * green['yy']
    syn += mt[2] * green['zz']
    syn += mt[3] * green['xy']
    syn += mt[4] * green['xz']
    syn += mt[5] * green['yz']
    return syn

def invert_moment_tensor(obs, green, mt0=None):
    """最小二乘反演矩张量"""
    if mt0 is None:
        mt0 = np.zeros(6)
    def residual(mt):
        return synthesize(mt, green) - obs
    # 求解
    result = least_squares(residual, mt0)
    mt_est = result.x
    # 计算残差范数
    rms = np.sqrt(np.mean(result.fun ** 2))
    return mt_est, rms

def decompose_mt(mt):
    """将矩张量分解为 DC + CLVD + ISO 三部分"""
    # 构造 3×3 对称矩阵
    M = np.array([[mt[0], mt[3], mt[4]],
                  [mt[3], mt[1], mt[5]],
                  [mt[4], mt[5], mt[2]]])
    # 特征值分解
    eigvals, eigvecs = np.linalg.eigh(M)
    eigvals = np.sort(eigvals)[::-1]   # 降序
    tr = np.sum(eigvals)
    iso = tr / 3.0
    dev = eigvals - iso
    # DC 与 CLVD 分配（Silver & Jordan 简化）
    dc_mag = 0.5 * (dev[0] - dev[2] - np.abs(dev[0] + dev[2] - 2*dev[1]))
    clvd_mag = dev[0] - dc_mag
    return {
        'iso': iso,
        'dc': dc_mag,
        'clvd': clvd_mag,
        'total_deviatoric': dev.sum()
    }

震源机制解的图件

反演得到的矩张量通常用沙滩球（beach ball）表示：

  • 黑色区域：P 波初动为压缩的方位（正象限）
  • 白色区域：P 波初动为膨胀的方位（负象限）
  • 两条曲线：节面，分别对应主断层面和辅助面
  • 颜色/纹理：反映非双力偶分量比例
💡

常用工具：GMT 的 psmeca、ObsPy 的 obspy.imaging.beachball、PyGMT 的 meca 模块， 都可以根据矩张量分量绘制沙滩球。

07小结

📌 核心要点

  • 矩张量是描述震源的统一语言，双力偶是构造地震的主要成分。
  • 辐射图型决定了 P/S 波在不同方位的强度分布，是震源机制解的基础。
  • 矩震级 $M_w$直接从 $M_0$ 换算，不饱和，是跨尺度比较的标准。
  • 衰减与场地共同塑造观测波形，$Q$ 与 $f_0$ 是核心参数。
  • 波形反演将观测反推回震源参数，是定量地震学的最终闭环。
