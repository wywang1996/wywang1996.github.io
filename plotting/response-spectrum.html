加速度 / 速度 / 位移反应谱

用 Newmark-β 平均加速度法计算单自由度体系在 assets/elcentro_EW.txt 下的绝对加速度谱 Sa、相对速度谱 Sv、相对位移谱 Sd，以及它们对应的 伪谱 PSa、PSv、PSd，共六张图。

工程地震 反应谱 Newmark-β Python / MATLAB A4 尺寸
Input Format

输入数据格式

本模板读取两列文本文件（空格、制表符或逗号分隔）， 与 El Centro、SAC ASCII 等地震记录格式一致。量纲必须明确。

输入文件要求

列号物理量 推荐单位说明
第 1 列时间 ts（秒）等间隔。
第 2 列地面加速度 agg（重力加速度）也可为 m/s² 或 gal（cm/s²）。

常用量纲的换算

你的数据单位 换算到 m/s² 代码里怎么写
g× 9.80665ag = a * 9.80665
m/s²× 1ag = a
gal（cm/s²）× 0.01ag = a * 0.01
mm/s²× 0.001ag = a * 0.001
本页示例 assets/elcentro_EW.txt 的第 2 列单位是 g。 代码不做去均值、去趋势处理，直接使用原始记录计算反应谱。

Meaning

六张图的意义

1. Sa(T) · 绝对加速度反应谱

Sa(T) = max |üg + ü|。直接对应惯性力，是抗震设计中地震作用的直接依据。

2. Sv(T) · 相对速度反应谱

Sv(T) = max |u̇|。与输入结构的地震能量密切相关。

3. Sd(T) · 相对位移反应谱

Sd(T) = max |u|。反映位移需求，是长周期结构与隔震设计的关键量。

4. PSa(T) · 伪加速度反应谱

PSa = ω²·Sd。ζ = 5% 时与 Sa 一般相差 5–10%。

5. PSv(T) · 伪速度反应谱

PSv = ω·Sd。与 PSa 的关系是 PSa = ω·PSv。

6. PSd(T) · 伪位移反应谱

PSd = Sd。与 PSa、PSv 构成三联谱的三个坐标。

Python

Python 代码

依赖 numpy 与 matplotlib。 输入量纲见代码头部注释，代码不去均值、不去趋势。

response-spectrum.pyPython
# =============================================================
# 输入数据格式（两列文本，空格 / 制表符 / 逗号分隔）
#   第 1 列：时间 t   —— 单位 s（秒），等间隔
#   第 2 列：加速度 a —— 单位 g（重力加速度）
# -------------------------------------------------------------
# 如果你的加速度列不是 g，请在下方 DATA_UNIT 处选择：
#   'g'     → 第 2 列单位 g   （× 9.80665 → m/s²）
#   'm/s2'  → 第 2 列单位 m/s²（× 1）
#   'gal'   → 第 2 列单位 cm/s²（× 0.01）
#   'mm/s2' → 第 2 列单位 mm/s²（× 0.001）
# -------------------------------------------------------------
# 说明：本脚本不做去均值、不去线性趋势。
# =============================================================
DATA_UNIT = 'g'

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.ticker import LogLocator

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 9,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

g = 9.80665

# ---- 1. 读取两列文本 ----
t, a_raw = np.loadtxt('elcentro_EW.txt', unpack=True)
dt = t[1] - t[0]

# ---- 2. 单位换算到 m/s² ----
unit_factor = {'g': g, 'm/s2': 1.0, 'gal': 0.01, 'mm/s2': 0.001}
factor = unit_factor.get(DATA_UNIT, g)
ag = a_raw * factor


def sdof_response(ag, dt, T, zeta=0.05):
    """Newmark-β 平均加速度法计算 SDOF 峰值响应。"""
    if T <= 0:
        return 0.0, 0.0, 0.0

    omega = 2.0 * np.pi / T
    c = 2.0 * omega * zeta
    k = omega * omega
    gamma, beta = 0.5, 0.25

    keff = k + gamma / (beta * dt) * c + 1.0 / (beta * dt * dt)

    u, v = 0.0, 0.0
    acc = -ag[0]

    a_abs_max, v_max, u_max = 0.0, 0.0, 0.0

    for j in range(1, len(ag)):
        p = (-ag[j]
             + (1.0 / (beta * dt * dt) * u
                + 1.0 / (beta * dt) * v
                + (1.0 / (2 * beta) - 1.0) * acc)
             + c * (gamma / (beta * dt) * u
                    + (gamma / beta - 1.0) * v
                    + dt * (gamma / (2 * beta) - 1.0) * acc))

        u_new = p / keff
        v_new = (gamma / (beta * dt) * (u_new - u)
                 - (gamma / beta - 1.0) * v
                 - dt * (gamma / (2 * beta) - 1.0) * acc)
        acc_new = (1.0 / (beta * dt * dt) * (u_new - u)
                   - 1.0 / (beta * dt) * v
                   - (1.0 / (2 * beta) - 1.0) * acc)

        u, v, acc = u_new, v_new, acc_new

        a_abs = acc + ag[j]
        a_abs_max = max(a_abs_max, abs(a_abs))
        v_max = max(v_max, abs(v))
        u_max = max(u_max, abs(u))

    return a_abs_max, v_max, u_max


# ---- 3. 反应谱计算 ----
periods = np.logspace(np.log10(0.02), np.log10(10.0), 100)
zeta = 0.05

Sa = np.zeros_like(periods)
Sv = np.zeros_like(periods)
Sd = np.zeros_like(periods)

for i, T in enumerate(periods):
    Sa[i], Sv[i], Sd[i] = sdof_response(ag, dt, T, zeta)

# ---- 4. 伪谱 ----
omega = 2.0 * np.pi / periods
PSa = omega ** 2 * Sd
PSv = omega * Sd
PSd = Sd.copy()

# ---- 5. 绘制六张子图（A4 尺寸 8 × 7.5 in） ----
fig, axes = plt.subplots(3, 2, figsize=(8.0, 7.5))

panels = [
    (axes[0, 0], Sa,  'Sa (m/s²)',  '#b45309', 'Sa — 绝对加速度谱'),
    (axes[0, 1], PSa, 'PSa (m/s²)', '#b45309', 'PSa — 伪加速度谱'),
    (axes[1, 0], Sv,  'Sv (m/s)',   '#2563eb', 'Sv — 相对速度谱'),
    (axes[1, 1], PSv, 'PSv (m/s)',  '#2563eb', 'PSv — 伪速度谱'),
    (axes[2, 0], Sd,  'Sd (m)',     '#15803d', 'Sd — 相对位移谱'),
    (axes[2, 1], PSd, 'PSd (m)',    '#15803d', 'PSd — 伪位移谱'),
]

# 纵轴只显示 1、2、5 × 10ⁿ 主刻度，减少标签拥挤
for ax, y, ylabel, color, title in panels:
    ax.loglog(periods, y, lw=1.4, color=color)
    ax.set_xlabel('Period T (s)')
    ax.set_ylabel(ylabel)
    ax.set_title(title, fontsize=9)
    ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)
    ax.tick_params(direction='in', which='both', top=True, right=True)
    ax.yaxis.set_major_locator(LogLocator(base=10.0, subs=(1.0, 2.0, 5.0), numticks=15))
    ax.yaxis.set_minor_locator(LogLocator(base=10.0, subs=tuple(np.arange(2, 10) * 0.1), numticks=100))
    ax.tick_params(axis='y', which='minor', length=2)

fig.tight_layout()
fig.savefig('response-spectra.png', dpi=300, bbox_inches='tight')
plt.show()
MATLAB

MATLAB 代码

脚本末尾定义局部函数 sdof_response（R2016b+）。 不去均值、不去趋势。

response-spectrum.mMATLAB
% =============================================================
% 输入数据格式（两列文本，空格 / 制表符 / 逗号分隔）
%   第 1 列：时间 t   —— 单位 s（秒），等间隔
%   第 2 列：加速度 a —— 单位 g（重力加速度）
% -------------------------------------------------------------
%   'g'     → × 9.80665
%   'm/s2'  → × 1
%   'gal'   → × 0.01
%   'mm/s2' → × 0.001
% -------------------------------------------------------------
% 说明：本脚本不做去均值、不去线性趋势。
% =============================================================
DATA_UNIT = 'g';

g = 9.80665;

% ---- 1. 读取两列文本 ----
data = readmatrix('elcentro_EW.txt');
t    = data(:, 1);
a_raw = data(:, 2);
dt   = t(2) - t(1);

% ---- 2. 单位换算 ----
switch DATA_UNIT
    case 'g',     factor = g;
    case 'm/s2',  factor = 1.0;
    case 'gal',   factor = 0.01;
    case 'mm/s2', factor = 0.001;
    otherwise,    factor = g;
end
ag = a_raw * factor;

% ---- 3. 反应谱计算 ----
periods = logspace(log10(0.02), log10(10.0), 100);
n = numel(periods);
zeta = 0.05;

Sa = zeros(size(periods));
Sv = zeros(size(periods));
Sd = zeros(size(periods));

for i = 1:n
    [Sa(i), Sv(i), Sd(i)] = sdof_response(ag, dt, periods(i), zeta);
end

% ---- 4. 伪谱 ----
omega = 2 * pi ./ periods;
PSa = omega.^2 .* Sd;
PSv = omega .* Sd;
PSd = Sd;

% ---- 5. 绘制六张子图（A4 尺寸） ----
figure('Color', 'w', 'Position', [100 100 800 750]);

titles = {'Sa — 绝对加速度谱', 'PSa — 伪加速度谱', ...
          'Sv — 相对速度谱',   'PSv — 伪速度谱', ...
          'Sd — 相对位移谱',   'PSd — 伪位移谱'};
ylabels = {'Sa (m/s^2)', 'PSa (m/s^2)', ...
           'Sv (m/s)',   'PSv (m/s)', ...
           'Sd (m)',     'PSd (m)'};
colors = {[0.71 0.33 0.04], [0.71 0.33 0.04], ...
          [0.15 0.39 0.92], [0.15 0.39 0.92], ...
          [0.08 0.50 0.24], [0.08 0.50 0.24]};
dataAll = {Sa, PSa, Sv, PSv, Sd, PSd};

for k = 1:6
    subplot(3, 2, k);
    loglog(periods, dataAll{k}, 'Color', colors{k}, 'LineWidth', 1.4);
    xlabel('Period T (s)');
    ylabel(ylabels{k});
    title(titles{k}, 'FontSize', 9);
    grid on; box on;
    set(gca, 'FontName', 'Times New Roman', 'FontSize', 9, 'TickDir', 'in');
    % 纵轴只保留 1、2、5 × 10^n 主刻度
    ax = gca;
    ax.YAxis.MajorTickMode = 'manual';
    set(ax, 'YTick', get_log_ticks(ax.YLim));
end

exportgraphics(gcf, 'response-spectra.png', 'Resolution', 300);


% ===== 辅助函数：返回 1、2、5 × 10^n 范围内刻度 =====
function ticks = get_log_ticks(ylim)
    lo = log10(ylim(1));
    hi = log10(ylim(2));
    ticks = [];
    for e = floor(lo):ceil(hi)
        for m = [1 2 5]
            v = m * 10^e;
            if v >= ylim(1) && v <= ylim(2)
                ticks(end+1) = v; %#ok
            end
        end
    end
    if numel(ticks) > 8
        % 太多就只保留 1×10^n
        ticks = [];
        for e = floor(lo):ceil(hi)
            v = 10^e;
            if v >= ylim(1) && v <= ylim(2)
                ticks(end+1) = v; %#ok
            end
        end
    end
end


% ===== 局部函数 =====
function [Sa, Sv, Sd] = sdof_response(ag, dt, T, zeta)
    if nargin < 4, zeta = 0.05; end
    if T <= 0
        Sa = 0; Sv = 0; Sd = 0; return;
    end

    omega = 2 * pi / T;
    c = 2 * omega * zeta;
    k = omega^2;
    gamma = 0.5; beta = 0.25;

    keff = k + gamma / (beta * dt) * c + 1 / (beta * dt^2);

    u = 0; v = 0;
    acc = -ag(1);

    a_abs_max = 0; v_max = 0; u_max = 0;

    for j = 2:numel(ag)
        p = -ag(j) + ...
            (1/(beta*dt^2)*u + 1/(beta*dt)*v + (1/(2*beta)-1)*acc) + ...
            c * (gamma/(beta*dt)*u + (gamma/beta-1)*v + ...
                 dt*(gamma/(2*beta)-1)*acc);

        u_new = p / keff;
        v_new = gamma/(beta*dt)*(u_new - u) - (gamma/beta-1)*v - ...
                dt*(gamma/(2*beta)-1)*acc;
        acc_new = 1/(beta*dt^2)*(u_new - u) - 1/(beta*dt)*v - ...
                  (1/(2*beta)-1)*acc;

        u = u_new; v = v_new; acc = acc_new;

        a_abs = acc + ag(j);
        a_abs_max = max(a_abs_max, abs(a_abs));
        v_max = max(v_max, abs(v));
        u_max = max(u_max, abs(u));
    end

    Sa = a_abs_max; Sv = v_max; Sd = u_max;
end
Notes

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 时间ts（秒）
输入 · 加速度agg / m/s² / gal / mm/s²
输出 · 绝对加速度谱Sam/s²
输出 · 相对速度谱Svm/s
输出 · 相对位移谱Sdm
输出 · 伪加速度谱PSam/s²
输出 · 伪速度谱PSvm/s
输出 · 伪位移谱PSdm
  • 积分方法：Newmark-β 平均加速度法，γ = 1/2，β = 1/4。
  • 周期范围：0.02–10 s，对数分布 100 个点。
  • 阻尼比：默认 ζ = 0.05。
  • 无去趋势：直接使用原始记录，不做任何预处理。
  • 纵轴刻度：只保留 1、2、5 × 10ⁿ 主刻度，避免标签拥挤。
  • 常见问题：
    • 谱值整体偏小或偏大 10⁴ 量级 → 输入加速度单位选错了。
    • 长周期段谱值异常抬高 → 原始记录含基线漂移。
