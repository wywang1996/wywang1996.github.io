地震动谱分析入门

从傅里叶谱到反应谱，理解地震动在频域和结构响应两个视角下的表达方式， 是读懂强震记录、设计反应谱与地震危险性分析的基础。

反应谱 傅里叶谱 谱分析 地震工程

§引言

地震动是随机的非平稳信号。直接从时程曲线上读取信息有限， 因此在工程和地震学中，我们通常从两个角度来分析它：

  • 频域视角：用傅里叶谱描述地震动中不同频率成分的能量分布。
  • 结构响应视角：用反应谱描述一个弹性单自由度体系在不同自振周期下所受到的最大响应。

傅里叶谱回答“地震动里有哪些频率成分”，反应谱回答“这些频率成分对结构有多大影响”。 两者互补，是地震动分析的基石。

01傅里叶谱

基本原理

傅里叶变换将一个时域信号 $a(t)$ 分解为不同频率的正弦波叠加。 对离散采样的地震动记录（采样间隔 $\Delta t$，总点数 $N$），使用离散傅里叶变换（DFT）：

$$ A_k = \sum_{n=0}^{N-1} a_n \, e^{-i 2\pi k n / N} $$

其中 $k = 0, 1, \ldots, N-1$，对应频率 $f_k = k / (N \Delta t)$

得到的傅里叶幅值谱 $|A_k|$ 反映各频率成分的强度， 相位谱则描述各频率分量的时间对齐关系。

关键参数

参数含义与地震动的关系
频率分辨率 $\Delta f = 1 / (N \Delta t)$ 记录越长，分辨率越细
Nyquist 频率 $f_N = 1 / (2 \Delta t)$ 能识别的最高频率，采样率一半
卓越频率 幅值谱最大值对应频率 反映场地或震源的固有特征
频带宽度 幅值显著区间的频率范围 反映地震动能量集中程度
💡

实用提示：地震动记录的傅里叶谱通常呈“宽频带”特征， 能量集中在 0.1–10 Hz。硬土场地卓越频率偏高，软土场地偏低。

Python 示例

fourier_spectrum.py Python 
import numpy as np

def fourier_amplitude(acc, dt):
    """计算单边傅里叶幅值谱"""
    N = len(acc)
    # 去均值，减少直流分量
    acc = acc - np.mean(acc)
    # FFT
    A = np.fft.rfft(acc)
    # 单边幅值（归一化）
    amp = 2.0 * np.abs(A) / N
    # 对应频率
    freq = np.fft.rfftfreq(N, d=dt)
    return freq, amp

02反应谱

物理意义

反应谱的核心思想：把地震动作用在一组不同自振周期的 弹性单自由度体系上，记录每个体系的最大响应，得到响应随周期变化的曲线。

$$ S_a(T, \zeta) = \max_t \left| \ddot{x}(t) + \ddot{x}_g(t) \right| $$

$T$ 为体系自振周期，$\zeta$ 为阻尼比，$\ddot{x}_g$ 为地面加速度

三类反应谱

名称符号物理量典型用途
谱加速度 $S_a(T)$ 绝对加速度峰值 地震力、抗震设计
谱速度 $S_v(T)$ 相对速度峰值 能量输入、阻尼器设计
谱位移 $S_d(T)$ 相对位移峰值 层间位移、隔震设计

Newmark–Hall 四段谱

标准设计反应谱通常被简化为四段：上升段、平台段、速度控制段、位移控制段。 分别对应结构的不同自振周期区间。

  • 短周期段（$T < T_0$）：$S_a$ 随 $T$ 增大而上升，斜率由场地决定。
  • 平台段（$T_0 < T < T_g$）：$S_a$ 基本恒定，等于峰值加速度放大系数乘以 PGA。
  • 速度段（$T_g < T < T_d$）：$S_a \propto 1/T$，对应等速度区。
  • 位移段（$T > T_d$）：$S_a \propto 1/T^2$，对应等位移区。

计算方法（时域）

对每个周期 $T$，用 Newmark-$\beta$ 法或 Duhamel 积分逐步积分求解，记录最大响应。 工程中通常取阻尼比 $\zeta = 5\%$。

response_spectrum.py Python 
import numpy as np

def response_spectrum(acc, dt, periods, zeta=0.05):
    """计算谱加速度 Sa、谱速度 Sv、谱位移 Sd"""
    acc = acc - np.mean(acc)
    Sa, Sv, Sd = [], [], []

    for T in periods:
        wn = 2 * np.pi / T           # 自振圆频率
        c  = 2 * zeta * wn           # 阻尼系数
        # Newmark-β 参数（平均加速度法）
        gamma, beta = 0.5, 0.25

        u = ud = udd = 0.0
        umax = udmax = uddmax = 0.0

        for i in range(len(acc)):
            # 有效刚度
            k_eff = wn**2 + gamma/(beta*dt)*c + 1/(beta*dt**2)
            # 有效荷载
            p_eff = (-acc[i]
                     + (1/(beta*dt**2))*u + (1/(beta*dt))*ud + (1/(2*beta)-1)*udd
                     + c*((gamma/(beta*dt))*u + (gamma/beta-1)*ud
                          + (gamma/(2*beta)-1)*dt*udd))
            u_new = p_eff / k_eff
            ud_new = (gamma/(beta*dt))*(u_new-u) + (1-gamma/beta)*ud \
                     + dt*(1-gamma/(2*beta))*udd
            udd_new = (1/(beta*dt**2))*(u_new-u) - (1/(beta*dt))*ud \
                      - (1/(2*beta)-1)*udd

            u, ud, udd = u_new, ud_new, udd_new
            umax   = max(umax,  abs(u))
            udmax  = max(udmax, abs(ud))
            uddmax = max(uddmax, abs(udd + acc[i]))

        Sd.append(umax)
        Sv.append(udmax)
        Sa.append(uddmax)

    return np.array(Sa), np.array(Sv), np.array(Sd)

03谱加速度与谱速度

近似关系

在小阻尼情况下，三种谱之间存在简单的近似关系：

$$ S_a \approx \omega \, S_v \approx \omega^2 \, S_d $$

其中 $\omega = 2\pi/T$ 为自振圆频率，该关系在 $\zeta \le 0.2$ 时精度较高

三联谱（Tripartite Spectrum）

将 $S_a$、$S_v$、$S_d$ 画在同一张对数坐标图上， 得到经典的三联反应谱。它把周期范围划分为三个区域：

  • 等加速度区（短周期）：$S_a$ 为常数，$S_v$ 随 $T$ 线性增长
  • 等速度区（中周期）：$S_v$ 为常数，$S_a \propto 1/T$，$S_d \propto T$
  • 等位移区（长周期）：$S_d$ 为常数，$S_a \propto 1/T^2$
💡

为什么重要：三联谱是结构抗震设计的核心工具。 当你看到一条设计谱曲线，通过它落在哪个区域，就能快速判断 结构的响应由惯性力（短周期）、速度（中周期） 还是位移（长周期）主导。

04阻尼比影响

基本规律

阻尼比 $\zeta$ 决定体系耗散能量的能力。$\zeta$ 越大，共振放大越弱，谱值越低。

结构类型典型阻尼比 ζ说明
钢结构（焊接）2% – 3%阻尼小，共振响应大
钢筋混凝土结构5%设计反应谱常用取值
预应力混凝土3% – 5%介于钢与普通混凝土之间
砌体结构5% – 8%开裂后耗能增加
隔震结构10% – 20%橡胶支座或摩擦摆耗能
土体5% – 15%随应变水平变化

阻尼调整系数

如果设计谱基准阻尼比是 $\zeta_0$（通常 5%），实际阻尼 $\zeta$ 不同时， 可用下式近似调整谱值：

$$ R = \sqrt{\frac{10}{5 + \zeta}} $$

$\zeta$ 以百分数计，该系数用于缩放基准谱

阻尼对谱形的影响

  • 短周期段：阻尼影响小，$S_a$ 变化不明显。
  • 平台段：阻尼影响适中，阻尼增大使平台降低。
  • 长周期段：阻尼影响最显著，尤其共振峰附近（$T \approx$ 场地卓越周期）。
⚠️

常见误区：把阻尼比从 5% 提高到 10%，谱值并不会简单减半。 真实缩放关系依赖周期，短周期处变化很小，长周期附近可能接近 $1/\sqrt{2}$ 甚至更大。 因此不能用简单线性比例去调整设计谱。

05小结

📌 核心要点

  • 傅里叶谱描述地震动的频域能量分布，与结构无关，仅反映地震动本身。
  • 反应谱描述结构响应，通过弹性 SDOF 体系建立地震动与结构之间的桥梁。
  • 三种谱之间存在 $S_a \approx \omega S_v \approx \omega^2 S_d$ 的近似关系，构成三联谱。
  • 阻尼比主要影响长周期段谱值，对短周期影响小，不能用简单线性比例处理。
  • 实际计算中，Newmark-$\beta$ 法是最常用的反应谱时域求解方法，阻尼比一般取 5%。
