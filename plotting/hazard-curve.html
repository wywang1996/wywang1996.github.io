地震危险性曲线

概率地震危险性分析（PSHA）的核心输出：年超越概率 λ 随地面运动 强度（PGA、Sa(T) 等）的变化曲线。图上标注 50 年超越概率 10% 与 2% 两个常用设防水准， 是《工程地震学》《场地地震安全性评价》最标准的图件。

数据来源

  • PSHA 计算程序——OpenQuake、CRISIS、EZ-FRISK、 USGS NSHMP、中国地震局概率危险性分析系统。
  • 规范附录——GB 18306《中国地震动参数区划图》给出全国各 城镇的 50 年 10% 与 2% 设防水准 PGA 值。
  • 专项地震安全性评价报告——重大工程场地的危险性曲线， 含不同概率水平的多年超越概率。
本页示例是一份典型的场地危险性曲线，覆盖 PGA = 0.005 g 到 1.5 g，年超越概率从 ~0.13 到 ~6×10⁻⁷， 大约跨越 5 个数量级。实际工程的 PSHA 输出通常有 30–50 个点。
Meaning

这张图说明了什么

地震危险性曲线描述的是"场地的地震动强度超越某个水平的年频率"。 横轴是地震动强度（PGA、Sa(T) 或其他），纵轴是年超越概率 λ。 横轴用对数（PGA 跨 2–3 个量级），纵轴用对数（λ 跨 4–6 个量级）。

两个常用的设防水准

工程上最常用的两个设防水准，都是在 50 年设计基准期内定义的：

  • 50 年超越概率 10%（俗称"小震"或"多遇地震"）
    年超越概率 λ = 1 − (1 − 0.10)1/50 ≈ 1/475
    对应中国规范"多遇地震"或"第一水准"设防。
  • 50 年超越概率 2%（俗称"大震"或"罕遇地震"）
    年超越概率 λ = 1 − (1 − 0.02)1/50 ≈ 1/2475
    对应中国规范"罕遇地震"或"第三水准"设防。

两条水平虚线标在 λ = 1/475 与 1/2475 处，与曲线交点即为对应设防水准的 PGA 值，直接读出作为抗震设计的输入。

从曲线上能读出什么

  • 低强度段（PGA < 0.05 g）：曲线斜率平缓， 小震频繁发生，年超越概率接近 0.1。
  • 中强度段（0.05 g – 0.3 g）：双对数坐标下接近直线， 斜率 k 反映场地所在区域的地震活动性（k 越大，危险性衰减越快）。
  • 高强度段（PGA > 0.5 g）：曲线出现"尾巴"， 斜率变缓，反映大地震（M > 7）对极端强度的贡献。
与规范设计谱的关系： 从危险性曲线读出的 PGA 就是设计谱的峰值部分（T ≈ 0 处）。 对不同周期 T 分别做 PSHA，可以得到一致危险性谱（UHS）， 是规范设计谱的重要参考。
重要提示：危险性曲线是"基岩"或"参考场地" 的结果，通常指 Vs30 = 760 m/s 或 800 m/s。 用于具体工程时还需叠加场地放大因子（见 transfer-function.html 与 hvsr.html），得到地表危险性曲线。

Python

Python 代码

依赖 numpy 与 matplotlib。 读取 CSV 后绘制危险性曲线，标出设防水准并插值对应 PGA。

hazard-curve.pyPython
# =============================================================
# 地震危险性曲线 | 年超越概率 vs PGA
# -------------------------------------------------------------
# 输入数据：hazard_curve.csv
#   PGA_g,lambda
#   0.005,1.28e-01
#   0.010,7.85e-02
#   ...
# -------------------------------------------------------------
# 说明：本脚本读取 CSV，绘制双对数危险性曲线，
#       标注 50 年 10% (λ=1/475) 与 2% (λ=1/2475) 两个设防水准。
# =============================================================

import os
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

CSV_FILE = 'hazard_curve.csv'

# 两个常用设防水准对应的年超越概率
LAMBDA_10_50 = 1.0 / 475.0     # 50 年 10%
LAMBDA_2_50  = 1.0 / 2475.0    # 50 年 2%


def generate_synthetic(seed=42):
    """CSV 不存在时生成合成数据 —— 用简化的双对数幂律模型。"""
    # lambda(PGA) = k0 * PGA^(-k)
    k0, k = 3.5e-4, 2.85
    pga = np.array([0.005, 0.010, 0.020, 0.030, 0.050, 0.070,
                    0.100, 0.150, 0.200, 0.300, 0.400, 0.500,
                    0.700, 1.000, 1.500])
    lam = k0 * pga ** (-k)
    return pga, lam


# ---------- 1. 读取 CSV ----------
if os.path.exists(CSV_FILE):
    data = np.genfromtxt(CSV_FILE, delimiter=',', names=True,
                         dtype=None, encoding='utf-8')
    pga = np.asarray(data['PGA_g'], dtype=float)
    lam = np.asarray(data['lambda'], dtype=float)
    # 去掉非正数（对数坐标下无法显示）
    mask = (pga > 0) & (lam > 0)
    pga, lam = pga[mask], lam[mask]
    print(f'从 {CSV_FILE} 读取 {len(pga)} 个数据点')
else:
    print(f'{CSV_FILE} 不存在，使用合成数据演示')
    pga, lam = generate_synthetic()


# ---------- 2. 拟合双对数斜率 ----------
# 用中间段拟合（去掉极端低、高概率段）
log_pga = np.log10(pga)
log_lam = np.log10(lam)

mask_fit = (pga > 0.03) & (pga < 0.7)
if mask_fit.sum() >= 3:
    coeffs = np.polyfit(log_pga[mask_fit], log_lam[mask_fit], 1)
    k_slope = -coeffs[0]
    print(f'双对数斜率 k = {k_slope:.3f}')
else:
    coeffs = np.polyfit(log_pga, log_lam, 1)
    k_slope = -coeffs[0]
    print(f'双对数斜率 k = {k_slope:.3f}（样本太少，用全体）')


# ---------- 3. 插值设防水准 ----------
def interp_pga(pga, lam, lam_target):
    """在对数坐标下插值 lam_target 对应的 PGA。"""
    log_lam = np.log10(lam)
    log_pga = np.log10(pga)
    # lam 随 pga 递减，所以需要翻转
    idx = np.argsort(log_lam)
    return 10 ** np.interp(np.log10(lam_target),
                           log_lam[idx], log_pga[idx])


pga_475  = interp_pga(pga, lam, LAMBDA_10_50)
pga_2475 = interp_pga(pga, lam, LAMBDA_2_50)
print(f'50 年 10% 设防水准：PGA = {pga_475:.4f} g')
print(f'50 年  2% 设防水准：PGA = {pga_2475:.4f} g')


# ---------- 4. 绘图 ----------
fig, ax = plt.subplots(figsize=(7.2, 5.4))

# 拟合直线（延伸）
x_fit = np.array([pga.min() * 0.7, pga.max() * 1.3])
y_fit = 10 ** (coeffs[0] * np.log10(x_fit) + coeffs[1])
ax.loglog(x_fit, y_fit, lw=0.9, color='#888888', ls='--',
          label=f'Power-law fit  k = {k_slope:.2f}')

# 数据曲线
ax.loglog(pga, lam, lw=1.8, color='#b45309',
          marker='o', ms=4, mfc='#b45309', mec='none',
          label='Hazard curve')

# 设防水准：水平线
ax.axhline(LAMBDA_10_50, color='#2563eb', lw=0.9, ls='--')
ax.axhline(LAMBDA_2_50,  color='#9333ea', lw=0.9, ls='--')

# 设防水准：竖线 + 标注
ax.axvline(pga_475,  color='#2563eb', lw=0.8, ls=':')
ax.axvline(pga_2475, color='#9333ea', lw=0.8, ls=':')

ax.annotate(f'10% in 50 yr\nPGA = {pga_475:.3f} g',
            xy=(pga_475, LAMBDA_10_50),
            xytext=(pga_475 * 1.6, LAMBDA_10_50 * 4),
            fontsize=9, color='#2563eb',
            arrowprops=dict(arrowstyle='-', color='#2563eb', lw=0.7))

ax.annotate(f'2% in 50 yr\nPGA = {pga_2475:.3f} g',
            xy=(pga_2475, LAMBDA_2_50),
            xytext=(pga_2475 * 0.35, LAMBDA_2_50 * 6),
            fontsize=9, color='#9333ea',
            arrowprops=dict(arrowstyle='-', color='#9333ea', lw=0.7))

# 坐标轴
ax.set_xlabel('PGA (g)')
ax.set_ylabel('Annual exceedance rate  λ (1/yr)')
ax.set_title('Seismic hazard curve  ·  bedrock site', fontsize=11)
ax.set_xlim(pga.min() * 0.7, pga.max() * 1.3)
ax.set_ylim(lam.min() * 0.5, lam.max() * 2)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)
ax.tick_params(direction='in', which='both', top=True, right=True)
ax.legend(loc='lower left', fontsize=9, frameon=False)

fig.tight_layout()
fig.savefig('hazard-curve.png', dpi=300, bbox_inches='tight')
plt.show()
关键点：
  • 双对数拟合：只在 0.03 g – 0.7 g 的中段拟合， 避开低概率尾巴段。幂律模型 λ = k0·PGA−k， 其中 k 是活动性相关指数。
  • 插值设防水准：对数坐标下线性插值， 因为 λ 与 PGA 都是对数分布。
  • 年超越概率换算：50 年超越概率 P 对应的年超越概率 λ = 1 − (1−P)1/50。P = 10% → λ ≈ 1/475；P = 2% → λ ≈ 1/2475。

MATLAB 代码

% 地震危险性曲线 | 年超越概率 vs PGA

%   PGA_g,lambda
%   0.005,1.28e-01
%   ...
% =============================================================

CSV_FILE = 'hazard_curve.csv';
LAMBDA_10_50 = 1.0 / 475.0;
LAMBDA_2_50  = 1.0 / 2475.0;

% ---------- 1. 读取 CSV ----------
if isfile(CSV_FILE)
    T = readtable(CSV_FILE, 'CommentStyle', '#', ...
                  'VariableNamingRule', 'preserve');
    pga = T.PGA_g;
    lam = T.lambda;
    fprintf('从 %s 读取 %d 个数据点\n', CSV_FILE, numel(pga));
else
    fprintf('%s 不存在，使用合成数据演示\n', CSV_FILE);
    k0 = 3.5e-4; k = 2.85;
    pga = [0.005 0.010 0.020 0.030 0.050 0.070 ...
           0.100 0.150 0.200 0.300 0.400 0.500 ...
           0.700 1.000 1.500]';
    lam = k0 * pga .^ (-k);
end

% 去掉非正数
mask = pga > 0 & lam > 0;
pga = pga(mask);
lam = lam(mask);

% ---------- 2. 拟合双对数斜率 ----------
log_pga = log10(pga);
log_lam = log10(lam);
mask_fit = pga > 0.03 & pga < 0.7;

if sum(mask_fit) >= 3
    p = polyfit(log_pga(mask_fit), log_lam(mask_fit), 1);
else
    p = polyfit(log_pga, log_lam, 1);
end
k_slope = -p(1);
fprintf('双对数斜率 k = %.3f\n', k_slope);

% ---------- 3. 插值设防水准 ----------
% lam 随 pga 递减，用 sort 后 interp1
[log_lam_s, idx] = sort(log_lam);
log_pga_s = log_pga(idx);

pga_475  = 10 ^ interp1(log_lam_s, log_pga_s, log10(LAMBDA_10_50));
pga_2475 = 10 ^ interp1(log_lam_s, log_pga_s, log10(LAMBDA_2_50));

fprintf('50 年 10%% 设防水准：PGA = %.4f g\n', pga_475);
fprintf('50 年  2%% 设防水准：PGA = %.4f g\n', pga_2475);

% ---------- 4. 绘图 ----------
figure('Color', 'w', 'Position', [100 100 720 540]);
hold on;

% 拟合直线
x_fit = [min(pga) * 0.7, max(pga) * 1.3];
y_fit = 10 .^ (p(1) * log10(x_fit) + p(2));
loglog(x_fit, y_fit, '--', 'Color', [0.53 0.53 0.53], 'LineWidth', 0.9, ...
       'DisplayName', sprintf('Power-law fit  k = %.2f', k_slope));

% 数据曲线
loglog(pga, lam, '-o', 'Color', [0.71 0.33 0.04], ...
       'MarkerFaceColor', [0.71 0.33 0.04], 'MarkerEdgeColor', 'none', ...
       'MarkerSize', 4, 'LineWidth', 1.8, 'DisplayName', 'Hazard curve');

% 设防水准：水平线
yline(LAMBDA_10_50, '--', 'Color', [0.15 0.39 0.92], 'LineWidth', 0.9, ...
      'HandleVisibility', 'off');
yline(LAMBDA_2_50,  '--', 'Color', [0.58 0.20 0.92], 'LineWidth', 0.9, ...
      'HandleVisibility', 'off');

% 设防水准：竖线
xline(pga_475,  ':', 'Color', [0.15 0.39 0.92], 'LineWidth', 0.8, ...
      'HandleVisibility', 'off');
xline(pga_2475, ':', 'Color', [0.58 0.20 0.92], 'LineWidth', 0.8, ...
      'HandleVisibility', 'off');

% 标注
text(pga_475 * 1.6, LAMBDA_10_50 * 4, ...
     sprintf('10%% in 50 yr\nPGA = %.3f g', pga_475), ...
     'FontSize', 9, 'Color', [0.15 0.39 0.92]);
text(pga_2475 * 0.35, LAMBDA_2_50 * 6, ...
     sprintf('2%% in 50 yr\nPGA = %.3f g', pga_2475), ...

% 坐标轴

ylabel('Annual exceedance rate \lambda (1/yr)');

Notes

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 地面运动强度PGA 或 Sa(T)g
输入 · 年超越概率λ1/年
输出 · 双对数斜率k无量纲
输出 · 50 年 10% 设防 PGAPGA475g
输出 · 50 年 2% 设防 PGAPGA2475g
  • 曲线含义：λ(PGA) 是场地年超越概率，从 PSHA 计算得到。
  • 年超越概率与重现期：λ = 1/TR。 λ = 1/475 对应重现期 475 年，即 50 年超越概率 10%。
  • 幂律模型：中段近似 λ = k0·PGA−k， 双对数坐标下为直线。k 反映地区地震活动性，通常在 2–4 之间。
  • 拟合范围：取 0.03 g – 0.7 g 的中段， 避开低概率尾巴（受大地震主导）与低强度平台（受小震主导）。
  • 设防水准插值：在对数-对数坐标下线性插值， 因为 λ 与 PGA 都近似对数分布。
  • 基岩 vs 地表：危险性曲线通常是基岩（Vs30 = 760 m/s） 的结果。用于具体工程时需叠加场地放大因子。
  • 常见问题：
    • 曲线不单调 → CSV 数据有误，λ 应随 PGA 单调递减。
    • 插值出的 PGA 不在数据范围内 → 设防水准对应的 λ 超出数据覆盖范围，需扩展 PSHA 计算的下限。
    • k 值明显偏离 2–4 → 数据可能包含非地震因素（如爆破、塌陷），或拟合范围选择不当。
    • CSV 编码乱码 → 保存为 UTF-8，列名严格按示例。
