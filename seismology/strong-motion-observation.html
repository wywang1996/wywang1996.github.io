强震动观测

从台网布设到数据质量控制，覆盖强震仪原理、记录格式、 基线校正、滤波与去噪。它是地震工程的数据来源， 也是所有抗震分析、地震动参数提取的第一步。

强震仪 数据格式 信号处理 工程应用

§引言

强震动观测是在地震发生时直接记录地面运动的一门技术。 与地震学中观测微弱地震波（远场、小振幅）不同， 强震动观测关注的是工程场地附近、可能造成结构破坏的强烈地面运动。

两种观测的差异：

维度地震学观测强震动观测
目标 研究震源与地球结构 评估地震动对工程的影响
距离 远场（100~10000 km） 近场（0~200 km）
振幅 $10^{-9} \sim 10^{-3}$ m/s² $10^{-3} \sim 10^1$ m/s²
频段 0.01~10 Hz 0.1~30 Hz
仪器 宽频带地震计 加速度计（强震仪）
记录方式 连续记录 触发记录

强震动观测是地震工程的数据源头。没有强震记录：

  • 无法建立地震动衰减关系（GMPE）
  • 无法计算反应谱与设计谱
  • 无法做场地效应分析
  • 无法做结构时程分析

从 1933 年美国长滩地震首次记录到强震记录以来， 全球已积累数十万条记录， 其中著名的如 1940 年 EL Centro 记录、1971 年 San Fernando、 1995 年神户、1999 年集集、2008 年汶川、2011 年东日本， 都深刻影响了抗震设计理论的发展。

这份笔记按"台网 $\to$ 格式 $\to$ 质控 $\to$ 基线 $\to$ 滤波 $\to$ 积分 $\to$ 应用" 的顺序梳理，每一节都尽量落到工程实践上。

01台网与仪器

强震仪的三种类型

按测量原理，强震仪分为三代：

类型原理特点代表
模拟光记录式 摆 + 光学记录 早期设备，已淘汰 SMA-1
数字式（力平衡） 伺服加速度计 动态范围大、精度高 Kinemetrics、Reftek
MEMS 式 微机电传感器 体积小、成本低、可密集布设 手机、低成本台站

强震仪的关键参数

  • 量程：通常 ±2g 或 ±4g（$g$ 为重力加速度）。
  • 频带：DC~100 Hz 或 DC~200 Hz。
  • 动态范围：$>100$ dB，即能分辨极小与极大的加速度。
  • 采样率：100 Hz、200 Hz、500 Hz 不等。
  • 分辨率：通常 24 bit（约 $10^{-7}g$）。
  • 触发方式：阈值触发（STA/LTA）、外部触发。

台站布设原则

强震台网的布设方式决定了它能记录到什么：

  • 自由场台站：布设在无建筑物的基岩或土层场地，记录地震动输入，用于 GMPE、场地效应研究。
  • 结构台阵：布设在建筑、桥梁、大坝等结构上，记录结构响应，用于系统辨识与抗震性能评估。
  • 密集台阵：间距 10~100 m，用于研究地震动的空间变化与相干性。
  • 井下台阵：沿钻孔不同深度布设，直接测量土层放大。

全球与区域台网

  • USGS NSMP：美国国家强震台网，覆盖全美及海外领土。
  • CESMD：美国工程强震数据中心，整合加州与全国记录。
  • PEER NGA：太平洋地震工程研究中心的强震记录库。
  • K-NET / KiK-net：日本全国台网，约 1700 + 700 个台站。
  • ESM：欧洲强震数据库。
  • CSMNC：中国国家强震动台网中心，覆盖全国。
💡

自由场记录的重要性：只有自由场记录才代表场地输入， 而结构上的记录包含了结构自身的动力特性。 做 GMPE、反应谱、场地效应研究时，必须使用自由场记录。 这是选取训练数据时的关键筛选条件。

02数据格式

主流强震数据格式

格式来源特点
SAC Seismic Analysis Code 地震学标准格式，二进制头段 + 数据
MiniSEED IRIS / FDSN 国际标准，支持多通道、连续记录
ASCII / PEER PEER NGA 文本格式，便于人工查看与交换
COSMOS V1/V2/V3 COSMOS 强震专用格式，含事件与台站元数据
K-NET ASCII 日本 K-NET 固定列文本，日文元数据
ESM ASCII 欧洲 ESM 统一文本格式，含全部元数据

SAC 格式简介

SAC（Seismic Analysis Code）是地震学最常用的格式。 一个 SAC 文件包含两部分：

  • 头段：delta（采样间隔）、b、e（起止时间）、 stla、stlo（经纬度）、kcmpnm（分量名）、 knetwk（台网）、kstnm（台站名）、evla、evlo（事件经纬度）等。
  • 数据段：等间隔采样的浮点数组。

每个分量（NS、EW、UD）通常是独立的文件。

MiniSEED 格式简介

MiniSEED 是 SEED 格式的简化版，数据按记录块组织， 每块 512 字节。记录头包含：

  • 台网代码（network）、台站代码（station）
  • 位置代码（location）、通道代码（channel），如 HN1、HN2、HNZ
  • 起始时间、采样率、样本数

MiniSEED 支持多通道合并、连续记录，适合长期台网数据。

通道命名规范

通道代码通常 3 个字母，第一位表示频带，第二位表示仪器，第三位表示方向：

位置含义常见取值
第 1 位（频带） 带宽 H（80 Hz~250 Hz）、B（宽带）、E（极宽带）
第 2 位（仪器） 仪器类型 N（加速度计）、L（低增益地震计）、H（高增益）
第 3 位（方向） 分量方向 Z（垂直）、N（北南）、E（东西）、1、2（水平）

例如 HN1、HN2、HNZ 分别代表高频加速度计的 1 分量、2 分量和垂直分量。

03质量控制

质控的目标

强震记录的质控目标是：

  • 判断记录是否可用（触发是否正确、有无截幅、有无丢失）。
  • 识别并标记异常（仪器故障、环境干扰、电磁干扰）。
  • 提取事件元数据（震级、震中距、震源深度）。
  • 为后续处理（基线校正、滤波、反应谱）提供基础。

常见的质量问题

问题表现处理
截幅（clipping） 波形顶部/底部被削平 放弃或截取未截幅段
尖峰（spike） 单点或数点突跳 去尖峰滤波
基线漂移 波形整体向上或向下漂移 基线校正
背景噪声大 触发前记录幅值偏高 检查台站环境或仪器
数据丢失 时间轴不连续 标记 gap，分段处理
触发错误 误触发或漏触发 人工复核

质控流程

  1. 检查时间戳与采样率是否与元数据一致。
  2. 检查三分量是否齐全，是否有分量缺失。
  3. 检查波形是否有截幅、尖峰、突跳。
  4. 检查触发前噪声水平（PGA/PGV 阈值）。
  5. 检查波形与地震事件在时间与距离上是否一致。
  6. 计算 PGA、PGV、PGD、Arias 强度等参数，作为质控指标。
  7. 保存质控标记（quality flag）到数据库。

信噪比（SNR）

信噪比是判断记录可用性的重要指标，定义为：

$$ \mathrm{SNR} = \frac{\text{P 波到时前 5~10 s 的信号 RMS}} {\text{P 波到时前 20~30 s 的噪声 RMS}} $$

通常要求 SNR > 3（或 5），才能用于后续分析。 对强震记录，还要注意 PGA 是否超过触发电平， 未触发或触发前的记录也可以用于环境噪声研究。

Python 示例：自动质控检查

quality_check.py Python 
import numpy as np
from scipy import signal


def check_quality(acc, fs, clip_threshold=0.99):
    """
    对单分量强震记录做基本质控检查。
    acc: 加速度时程（numpy 数组）
    fs:  采样率 Hz
    clip_threshold: 截幅判断的相对阈值
    """
    report = {}

    # 1. 极值与均值
    report["npts"] = len(acc)
    report["pga"] = np.max(np.abs(acc))
    report["mean"] = np.mean(acc)
    report["std"] = np.std(acc)
    report["range"] = acc.max() - acc.min()

    # 2. 截幅检查
    # 若多个连续点接近极值，可能为截幅
    max_abs = report["pga"]
    close_to_max = np.abs(np.abs(acc) - max_abs) < 0.01 * max_abs
    max_run = _max_consecutive(close_to_max)
    report["clipped"] = max_run >= 3
    report["clip_run_length"] = max_run

    # 3. 尖峰检查
    # 用中位数绝对偏差（MAD）识别异常点
    med = np.median(acc)
    mad = np.median(np.abs(acc - med))
    if mad > 0:
        spikes = np.abs(acc - med) > 8.0 * mad
        report["n_spikes"] = int(np.sum(spikes))
        report["spike_ratio"] = float(np.sum(spikes) / len(acc))
    else:
        report["n_spikes"] = 0
        report["spike_ratio"] = 0.0

    # 4. 基线漂移检查
    # 用前后两段的均值差衡量
    n_half = len(acc) // 2
    drift = np.mean(acc[n_half:]) - np.mean(acc[:n_half])
    report["drift"] = drift
    report["drift_ratio"] = abs(drift) / (max_abs + 1e-12)

    # 5. 频谱检查：是否有明显 50 Hz 工频干扰
    f, Pxx = signal.welch(acc, fs=fs, nperseg=min(4096, len(acc)))
    # 找 50 Hz 附近的峰
    idx_50 = np.argmin(np.abs(f - 50.0))
    idx_noise = np.argmin(np.abs(f - 10.0))
    if Pxx[idx_noise] > 0:
        report["p50_ratio"] = Pxx[idx_50] / Pxx[idx_noise]
    else:
        report["p50_ratio"] = 0.0

    # 综合评估
    passed = (
        not report["clipped"]
        and report["spike_ratio"] < 1e-4
        and report["drift_ratio"] < 0.1
        and report["pga"] > 1e-4
    )
    report["passed"] = passed

    return report


def _max_consecutive(mask):
    """计算 mask 中最长的连续 True 段长度"""
    if not mask.any():
        return 0
    runs = []
    count = 0
    for v in mask:
        if v:
            count += 1
        else:
            if count > 0:
                runs.append(count)
            count = 0
    if count > 0:
        runs.append(count)
    return max(runs) if runs else 0


if __name__ == "__main__":
    # 合成一条测试记录
    rng = np.random.default_rng(42)
    fs = 100.0
    t = np.arange(0, 60, 1.0 / fs)

    # 噪声 + 地震信号
    acc = 0.001 * rng.normal(size=len(t))
    envelope = np.exp(-((t - 20) ** 2) / (2 * 3.0**2))
    acc += 0.5 * envelope * np.sin(2 * np.pi * 2.0 * t)

    # 加入一段尖峰
    acc[1000:1003] += 5.0

    # 加入基线漂移
    acc += 0.02 * t / t[-1]

    report = check_quality(acc, fs)
    print("质控报告：")
    for k, v in report.items():
        print(f"  {k:20s}: {v}")

运行后会输出一份质控报告，包括：

  • PGA、均值、标准差等基本统计量
  • 是否截幅、尖峰数量、漂移比率
  • 50 Hz 工频干扰强度
  • 综合通过/不通过结论

这类自动质控脚本是强震台网数据处理的常见工具。 在数据量大的情况下，还可以进一步用机器学习方法（异常检测）自动分类。

04基线校正

为什么需要基线校正

强震记录的加速度时程积分一次得到速度， 积分两次得到位移。如果加速度存在微小基线偏差 （如仪器零点漂移、传感器倾斜），积分后位移会无界增长， 表现为位移时程整体向上或向下漂移，这是物理上不可能的。

基线校正的目标：消除加速度的基线偏移， 使积分得到的速度与位移在物理上合理。

经典方法：Iwan 校正

Iwan 等人（1985）提出用分段线性函数拟合加速度基线：

$$ a_{\text{corr}}(t) = a_{\text{raw}}(t) - b(t) $$

其中 $b(t)$ 是分段线性基线函数。基线在各时间点之间线性变化， 控制点在用户指定的时间点，取值使校正后的速度、位移末端归零。

控制点通常选在：

  • P 波到时前（记录起始）
  • S 波到时附近
  • 强震段结束
  • 记录末尾

多项式校正

更简单的方法：用低阶多项式拟合记录的前段或整体趋势， 再从原始记录中减去：

$$ b(t) = c_0 + c_1 t + c_2 t^2 + \cdots $$

一阶多项式去掉常值偏移，二阶去掉线性漂移。 缺点是可能误伤真实的低频信息。

高通滤波（等效基线校正）

工程上常用高通滤波代替基线校正。 选择合适的高通截止频率（通常 0.05~0.2 Hz）， 滤掉极低频成分，从而消除基线漂移。

优点：简单、一致、可复现。 缺点：会损失部分真实的低频信息， 对长周期结构（如超高层、大跨桥梁）可能影响较大。

速度、位移的积分策略

从加速度积分得到速度与位移，常用两种方式：

  • 时域梯形法：直接累加， 需要配合基线校正或高通滤波。
  • 频域积分：在频域内除以 $i\omega$， 低频段置零，等价于高通滤波。 对噪声抑制更好，但对基线校正要求更严格。

Python 示例：基线校正与积分

baseline.py Python 
import numpy as np
import matplotlib.pyplot as plt


def baseline_polynomial(acc, dt, order=2):
    """用多项式拟合基线并校正"""
    n = len(acc)
    t = np.arange(n) * dt
    # 拟合
    coeffs = np.polyfit(t, acc, order)
    baseline = np.polyval(coeffs, t)
    return acc - baseline, baseline


def integrate_trapezoid(acc, dt):
    """时域梯形法积分"""
    n = len(acc)
    vel = np.zeros(n)
    disp = np.zeros(n)
    for i in range(1, n):
        vel[i] = vel[i - 1] + 0.5 * (acc[i] + acc[i - 1]) * dt
        disp[i] = disp[i - 1] + 0.5 * (vel[i] + vel[i - 1]) * dt
    return vel, disp


def integrate_frequency(acc, dt, hp_freq=0.05):
    """
    频域积分：除以 iω，并把低频置零。
    hp_freq: 高通截止频率 Hz
    """
    n = len(acc)
    # FFT
    A = np.fft.fft(acc)
    freqs = np.fft.fftfreq(n, d=dt)
    omega = 2 * np.pi * freqs

    # 频域积分（避开零频）
    V = np.zeros_like(A, dtype=complex)
    D = np.zeros_like(A, dtype=complex)
    for i in range(n):
        if abs(omega[i]) < 1e-9:
            V[i] = 0
            D[i] = 0
        else:
            V[i] = A[i] / (1j * omega[i])
            D[i] = -A[i] / omega[i]**2

    # 高通滤波（低频置零）
    mask = np.abs(freqs) >= hp_freq
    V *= mask
    D *= mask

    vel = np.fft.ifft(V).real
    disp = np.fft.ifft(D).real

    return vel, disp


def highpass_butter(acc, dt, fc=0.1, order=4):
    """Butterworth 高通滤波"""
    from scipy.signal import butter, filtfilt
    fs = 1.0 / dt
    wn = fc / (fs / 2)
    b, a = butter(order, wn, btype="high")
    return filtfilt(b, a, acc)

    vel_raw, disp_raw = integrate_trapezoid(acc, dt)

    # ---- 多项式校正 ----
    acc_corr, baseline = baseline_polynomial(acc, dt, order=1)
    vel_corr, disp_corr = integrate_trapezoid(acc_corr, dt)

    # ---- 频域积分 ----
    vel_freq, disp_freq = integrate_frequency(acc, dt, hp_freq=0.1)

    # ---- 绘图 ----
    fig, axes = plt.subplots(3, 1, figsize=(11, 8), sharex=True)

    axes[0].plot(t, acc, label="原始（含漂移）", alpha=0.6)
    axes[0].plot(t, acc_corr, label="多项式校正", linewidth=1.0)
    axes[0].set_ylabel("加速度 / (m/s²)")
    axes[0].legend()
    axes[0].grid(True, alpha=0.3)

    axes[1].plot(t, vel_raw, label="直接积分")
    axes[1].plot(t, vel_corr, label="校正后积分")
    axes[1].plot(t, vel_freq, "--", label="频域积分")
    axes[1].set_ylabel("速度 / (m/s)")
    axes[1].legend()
    axes[1].grid(True, alpha=0.3)

    axes[2].plot(t, disp_raw, label="直接积分")
    axes[2].plot(t, disp_corr, label="校正后积分")
    axes[2].plot(t, disp_freq, "--", label="频域积分")
    axes[2].set_xlabel("t / s")
    axes[2].set_ylabel("位移 / m")
    axes[2].legend()
    axes[2].grid(True, alpha=0.3)

    plt.tight_layout()
    plt.show()

05滤波与去噪

为什么要滤波

强震记录中包含三类需要去除的成分：

  • 高频噪声：来自传感器、采集器、环境的随机噪声，通常 >30 Hz。
  • 低频噪声：来自仪器温漂、地脉动、基线漂移，通常 <0.1 Hz。
  • 窄带干扰：如 50 Hz 工频、台站附近机械振动。

滤波器类型

类型通带典型用途
低通 $f < f_c$ 去除高频噪声
高通 $f > f_c$ 去除低频漂移
带通 $f_1 < f < f_2$ 同时去除高低频
带阻（陷波） 去除窄带 去除 50 Hz 工频

Butterworth 滤波器

最常用的滤波器是 Butterworth，其幅频响应为：

$$ |H(\omega)|^2 = \frac{1}{1 + (\omega / \omega_c)^{2n}} $$

其中 $n$ 是阶数，$\omega_c$ 是截止频率。 特点：通带平坦、过渡带平缓。阶数越高过渡越陡， 但会引入更大的相位失真。

零相位滤波

单向滤波会引入相位延迟，导致波形时间偏移。 工程上常用零相位滤波： 正向滤波一次，再反向滤波一次。 通过 filtfilt 实现，幅频响应平方，相位为零。

去尖峰

强震记录中常见单点或数点的突跳。去尖峰方法：

  • 中值滤波：用邻域中值替换当前点，可去掉窄脉冲。
  • 阈值法：若某点与中位数之差超过若干倍 MAD，则用中位数替换。
  • Hampel 滤波：滑动窗口内的稳健异常检测。

选择截止频率的原则

低通截止频率通常取 Nyquist 频率的 1/2~1/3， 或根据结构关注频段确定。 对建筑结构，关注频段通常 0.1~10 Hz， 因此常用 0.1 Hz 高通 + 25 Hz 低通。 对长周期结构（如超高层、大跨桥梁）， 高通可降到 0.02~0.05 Hz。

⚠️

滤波的副作用：滤波会损失真实信号成分。 如果高通截止频率选得太高（如 0.5 Hz）， 会把长周期信息也一起滤掉，导致反应谱长周期段被低估。 对地震动记录的滤波参数必须在数据说明中明确记录， 这也是 NGA-West2 等数据库对滤波参数有严格要求的原因。

Python 示例：滤波与去尖峰

filter_denoise.py Python 
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import butter, filtfilt, medfilt, iirnotch


def bandpass_filter(acc, dt, fc_low=0.1, fc_high=25.0, order=4):
    """零相位 Butterworth 带通滤波"""
    fs = 1.0 / dt
    nyq = fs / 2
    wn = [fc_low / nyq, fc_high / nyq]
    b, a = butter(order, wn, btype="band")
    return filtfilt(b, a, acc)


def notch_filter(acc, dt, f0=50.0, Q=30.0):
    """陷波滤波去除工频干扰"""
    fs = 1.0 / dt
    b, a = iirnotch(f0, Q, fs=fs)
    return filtfilt(b, a, acc)


def despike_median(acc, kernel_size=5):
    """中值滤波去尖峰"""
    return medfilt(acc, kernel_size=kernel_size)


def despike_threshold(acc, n_sigma=6.0):
    """基于 MAD 的阈值去尖峰"""
    med = np.median(acc)
    mad = np.median(np.abs(acc - med))
    if mad == 0:
        return acc.copy()
    threshold = n_sigma * 1.4826 * mad
    mask = np.abs(acc - med) > threshold
    out = acc.copy()
    # 用邻域均值替换异常点
    for i in np.where(mask)[0]:
        lo = max(0, i - 3)
        hi = min(len(acc), i + 4)
        out[i] = np.mean(acc[lo:hi][~mask[lo:hi]]) if (~mask[lo:hi]).any() else med
    return out


if __name__ == "__main__":
    # ---- 合成一条含噪声与尖峰的记录 ----
    rng = np.random.default_rng(2024)
    dt = 0.01
    t = np.arange(0, 40, dt)

    # 真实信号
    acc_true = (1.0 * np.sin(2 * np.pi * 2.0 * t)
                * np.exp(-((t - 15) ** 2) / (2 * 5.0**2)))

    # 加入噪声、50 Hz 工频、尖峰
    acc = acc_true.copy()

    acc += 0.1 * np.sin(2 * np.pi * 50.0 * t)       # 50 Hz 工频

    acc[3500:3503] += 3.0                           # 短时尖峰

    # ---- 处理链 ----

    acc_clean = despike_threshold(acc_notch)

    # ---- 绘图 ----
    fig, axes = plt.subplots(2, 1, figsize=(12, 6), sharex=True)

    axes[0].plot(t, acc, alpha=0.6, label="原始")
    axes[0].plot(t, acc_clean, linewidth=1.2, label="处理后")
    axes[0].set_ylabel("加速度 / (m/s²)")
    axes[0].legend()
    axes[0].grid(True, alpha=0.3)

    axes[1].plot(t, acc - acc_clean, color="gray", label="去除的成分")
    axes[1].set_xlabel("t / s")

06积分与导出

加速度、速度、位移

强震仪通常直接记录加速度。工程分析中需要速度与位移时，通过积分获得：

$$ v(t) = \int_0^t a(\tau) \, d\tau, \qquad d(t) = \int_0^t v(\tau) \, d\tau $$

积分必须在基线校正与滤波之后进行， 否则误差会累积。

PGV 与 PGD

常用的地震动峰值参数：

  • PGA：峰值地面加速度，最常用。
  • PGV：峰值地面速度，与结构能量输入关系更密切。
  • PGD：峰值地面位移，对长周期结构重要。

三者的组合，如 PGV/PGA 或 PGD/PGV，可以反映地震动的频率特征。

导出格式

处理后的记录通常导出为：

  • CSV / TXT：便于查看与交换，适合小型数据。
  • SAC / MiniSEED：保持元数据，适合台网归档。
  • PEER NGA：用于 GMPE 拟合与反应谱计算。
  • Excel / HDF5：适合批量处理与机器学习训练数据。

元数据记录

导出记录时，必须同时记录以下元数据：

  • 台网、台站、通道、位置代码
  • 台站经纬度、高程、场地类别
  • 事件时间、震中位置、震源深度、震级
  • 震中距、震源距、RJB、Rrup
  • 采样率、单位、量程
  • 基线校正参数、滤波参数
  • 质控结论、可用性评分

没有元数据的记录几乎无法用于后续研究。 NGA-West2、ESM 等数据库对元数据的完整性有严格要求。

Python 示例：完整处理链与导出

process_export.py Python 
import numpy as np
import csv
from datetime import datetime


def process_record(acc, dt, hp=0.1, lp=25.0):
    """
    完整处理链：
      1. 去尖峰
      2. 带通滤波
      3. 基线校正
      4. 积分得到速度与位移
    """
    from scipy.signal import butter, filtfilt, medfilt

    # 1. 去尖峰
    acc = medfilt(acc, kernel_size=3)

    # 2. 零相位带通滤波
    fs = 1.0 / dt
    nyq = fs / 2
    b, a = butter(4, [hp / nyq, lp / nyq], btype="band")
    acc = filtfilt(b, a, acc)

    # 3. 去均值（作为简单基线校正）
    acc = acc - np.mean(acc)

    # 4. 积分
    n = len(acc)
    vel = np.zeros(n)
    disp = np.zeros(n)
    for i in range(1, n):
        vel[i] = vel[i - 1] + 0.5 * (acc[i] + acc[i - 1]) * dt
        disp[i] = disp[i - 1] + 0.5 * (vel[i] + vel[i - 1]) * dt

    # 再次去除末端的线性趋势（保证位移末端归零）
    t = np.arange(n) * dt
    coeffs = np.polyfit(t, disp, 1)
    disp = disp - np.polyval(coeffs, t)

    return acc, vel, disp


def export_csv(fname, t, acc, vel, disp, metadata=None):
    """导出为 CSV 格式"""
    with open(fname, "w", newline="", encoding="utf-8") as f:
        writer = csv.writer(f)

        # 元数据头
        if metadata:
            writer.writerow(["# Metadata"])
            for k, v in metadata.items():
                writer.writerow([f"# {k}", str(v)])
            writer.writerow([])

        # 数据表头
        writer.writerow(["time_s", "acc_m_s2", "vel_m_s", "disp_m"])
        for i in range(len(t)):
            writer.writerow([f"{t[i]:.4f}",
                             f"{acc[i]:.6e}",
                             f"{vel[i]:.6e}",
                             f"{disp[i]:.6e}"])

    print(f"已导出：{fname}")


if __name__ == "__main__":
    # 合成测试记录

强震记录在工程中的用途

用途所需数据输出

机器学习 大量标注记录 震级/距离估计、异常检测

数据质量对结果的影响

强震记录的质量直接影响下游分析：

  • PGA 错误 → GMPE 残差偏大 → PSHA 结果偏差。
  • 基线漂移 → 位移谱不可信 → 长周期结构分析失效。
  • 滤波参数不一致 → 反应谱不可比 → 数据库无法统一使用。
  • 元数据缺失 → 无法分类、无法统计 → 记录使用价值下降。

因此，国际强震数据库（PEER NGA、ESM、COSMOS） 都对记录处理有统一流程与元数据标准。

与地震工程的衔接

强震动观测是地震工程数据链的起点：

  1. 台网记录 → 原始强震记录。
  2. 质控与处理 → 可用记录 + 元数据。
  3. 参数提取 → PGA、PGV、PGD、反应谱、Arias 强度、持时。
  4. 数据库积累 → GMPE 拟合、场地效应研究。
  5. 工程应用 → 抗震设计、地震危险性分析、结构时程分析。

没有高质量的强震记录，整个链条都会失真。 这也是全球各国持续投入台网建设的原因。

现代趋势

  • 密集台阵与分布式声传感（DAS）：光纤传感提供米级空间分辨率的应变记录。
  • 低成本 MEMS 台站：大量布设、网格化，提高近场记录密度。
  • 实时流数据与云处理：从触发记录走向实时连续流，支持快速响应。
  • 机器学习应用：自动质控、P 波拾取、震级估计、异常检测。
  • 数据共享与标准化：FDSN、ORFEUS、EMSC 等国际标准。

08小结

📌 核心要点

  • 台网与仪器：自由场台站与结构台阵各有用途；强震仪量程大、频带宽、动态范围高。
  • 数据格式：SAC、MiniSEED、PEER ASCII、COSMOS 各有所长；ObsPy 是统一读写工具。
  • 质量控制：检查截幅、尖峰、漂移、信噪比；PGA/PGV 是基本质控指标。
  • 基线校正：多项式、Iwan、高通滤波；保证积分后位移物理合理。
  • 滤波与去噪：零相位 Butterworth 带通 + 陷波 + 中值滤波，去除噪声保留真实信号。
  • 积分与导出：加速度 → 速度 → 位移；导出时必须包含完整元数据。
  • 工程应用：GMPE、反应谱、场地效应、时程分析、系统辨识、地震预警。
  • 数据质量决定一切：错误的记录会导致所有下游分析失效。
