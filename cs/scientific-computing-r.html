科学计算与 R

从向量化到统计建模，覆盖 R 语言特性、数据操作、可视化与时间序列分析。 R 是统计学家的母语，在地震目录统计、极值分析、 ETAS 余震建模与地震危险性统计中有着不可替代的地位。

向量化 统计建模 tidyverse 地震统计

§引言

R 是专为统计计算与数据可视化设计的语言， 起源于 1990 年代的 S 语言。 它在学术界、生物统计、金融、地震统计中广泛使用。

R 在工程中的定位：

场景R 的角色典型包
统计建模 主力环境 stats、lme4、brms
数据探索与清洗 主力环境 dplyr、tidyr
可视化 最强 ggplot2、plotly
时间序列 成熟 forecast、tseries
极值统计 权威 extRemes、ismev
空间统计 成熟 sp、sf、gstat
贝叶斯推断 主流 rstan、brms、rjags
机器学习 不如 Python caret、tidymodels、mlr3
生产部署 不是强项 plumber（REST API）

对地震工程师与地震学家来说，R 的三大价值：

  • 统计建模：极值分析、ETAS 模型、贝叶斯推断。
  • 数据探索：tidyverse 让数据清洗与探索变得优雅。
  • 可视化：ggplot2 是出版级统计图的黄金标准。

R 在地震学中的典型应用：

  • G-R 关系拟合：震级-频度关系的最大似然估计。
  • ETAS 建模：余震序列的统计模型。
  • 极值分析：地震动参数的极值分布。
  • PSHA 统计：危险性曲线的统计分析。
  • 地震目录分析：b 值时空变化、完整性分析。
  • 时间序列分析：地震活动性的时间演化。

这份笔记按"语言 $\to$ 数据结构 $\to$ 函数式 $\to$ tidyverse $\to$ 统计 $\to$ 时序 $\to$ 可视化 $\to$ 对比 $\to$ 应用" 的顺序梳理，每一节都尽量落到工程语境上。

常见陷阱

陷阱说明对策
索引从 1 开始 与 C / Python 不同 注意换算
循环慢 解释执行、无 JIT 向量化、apply、data.table

NA 传染 含 NA 的运算返回 NA na.rm = TRUE

浮点比较 0.1 + 0.2 == 0.3 为 FALSE all.equal()
💡

R 的哲学： ① 向量化优先——循环是最后手段； ② 一切皆对象——函数也是对象； ③ 向量是一等公民——标量是长度为 1 的向量； ④ 统计优先——内置函数面向统计分析。 理解这几点，就理解了 R 与其它语言的根本差异。 它不追求通用编程的优雅， 而是为数据分析和统计建模提供最直接的工具。

03函数式与 apply 家族

apply 家族

R 的 apply 家族是向量化的推广， 用于对数组、列表、数据框的批量操作：

函数输入输出用途
apply 矩阵/数组 向量/矩阵 按行或列操作
lapply 列表/向量 列表 每个元素应用函数
sapply 列表/向量 向量/矩阵 lapply 的简化版
vapply 列表/向量 指定类型向量 类型安全的 sapply
mapply 多个列表 向量/列表 多参数并行映射
tapply 向量 + 分组 数组 分组聚合

示例：批量计算反应谱

apply_spectrum.R R 
# 用 apply 家族批量计算反应谱

# 单自由度体系最大加速度（简化 Newmark-β）
sdof_sa <- function(acc, dt, T, zeta = 0.05) {
  omega <- 2 * pi / T
  beta <- 0.25
  gamma <- 0.5
  c <- 2 * zeta * omega
  k <- omega^2
  K_eff <- k + gamma / (beta * dt) * c + 1 / (beta * dt^2)

  n <- length(acc)
  u <- 0; v <- 0
  a <- -acc[1] - 2 * zeta * omega * v - omega^2 * u
  a_max <- 0

  for (i in 1:(n - 1)) {
    P_eff <- -acc[i + 1] +
      (1 / (beta * dt^2)) * u +
      (1 / (beta * dt)) * v +
      (1 / (2 * beta) - 1) * a +
      c * (gamma / (beta * dt) * u +
           (gamma / beta - 1) * v +
           dt * (gamma / (2 * beta) - 1) * a)
    u_new <- P_eff / K_eff
    v <- gamma / (beta * dt) * (u_new - u) -
      (gamma / beta - 1) * v -
      dt * (gamma / (2 * beta) - 1) * a
    a <- (1 / (beta * dt^2)) * (u_new - u) -
      (1 / (beta * dt)) * v -
      (1 / (2 * beta) - 1) * a
    u <- u_new

    a_abs <- abs(a + acc[i + 1])
    if (a_abs > a_max) a_max <- a_abs
  }
  a_max
}

# 生成地震动
set.seed(42)
dt <- 0.01
t <- seq(0, 60, by = dt)
acc <- rep(0, length(t))
for (freq in c(0.5, 1.5, 3.0, 5.0)) {
  acc <- acc + sin(2 * pi * freq * t + runif(1, 0, 2 * pi))
}
acc <- acc * exp(-((t - 15)^2) / (2 * 8^2))

# 用 sapply 批量计算反应谱
periods <- 10^seq(log10(0.05), log10(5.0), length.out = 100)
Sa <- sapply(periods, function(T) sdof_sa(acc, dt, T, 0.05))

# 用 purrr 并行化（需 future 包）
# library(furrr)
# plan(multisession, workers = 4)
# Sa <- future_map_dbl(periods, ~ sdof_sa(acc, dt, .x, 0.05))

# 输出
cat("PGA =", Sa[1], "\n")
cat("T = 1.0 s 处 Sa =", Sa[which.min(abs(periods - 1.0))], "\n")

# 绘图
plot(periods, Sa, type = "l", log = "xy",
     xlab = "Period (s)", ylab = "Sa (m/s²)",
     main = "加速度反应谱", col = "darkred", lwd = 2)

library(dplyr)
library(tidyr)
library(lubridate)

# 生成模拟地震目录
set.seed(42)
n <- 5000

catalog <- tibble(
  event_id = sprintf("ev%05d", 1:n),
  origin_time = as.POSIXct("2000-01-01") + runif(n, 0, 365 * 25) * 24 * 3600,
  magnitude = 2.5 + rexp(n, rate = 0.6),
  depth_km = rexp(n, rate = 0.1),
  latitude = runif(n, 30, 32),
  longitude = runif(n, 100, 102),
  station = sample(c("ST01", "ST02", "ST03"), n, replace = TRUE)
)

# ---- 1. 基本筛选 ----
large_events <- catalog |>
  filter(magnitude > 5.0, depth_km < 30) |>
  arrange(desc(magnitude))

cat("大地震事件数:", nrow(large_events), "\n")

# ---- 2. 派生字段 ----
catalog <- catalog |>
  mutate(
    year = year(origin_time),
    month = month(origin_time),
    log_energy = 1.5 * magnitude + 4.8,
    depth_class = case_when(
      depth_km < 10 ~ "浅源",
      depth_km < 30 ~ "中源",
      TRUE ~ "深源"
    )
  )

# ---- 3. 分组统计 ----
yearly_stats <- catalog |>
  group_by(year) |>
  summarize(
    n_events = n(),
    n_m5 = sum(magnitude >= 5),
    mean_mag = mean(magnitude),
    max_mag = max(magnitude),
    mean_depth = mean(depth_km),
    .groups = "drop"
  )

print(head(yearly_stats, 10))

# ---- 4. 交叉分析 ----
station_depth <- catalog |>
  group_by(station, depth_class) |>
  summarize(n = n(), .groups = "drop") |>
  pivot_wider(
    names_from = depth_class,
    values_from = n,
    values_fill = 0
  )

print(station_depth)

# ---- 5. 时间窗口统计 ----
# 每月的最大震级
monthly <- catalog |>
  mutate(ym = floor_date(origin_time, "month")) |>
  group_by(ym) |>
  summarize(max_mag = max(magnitude), n = n(), .groups = "drop")

cat("\n月度统计行数:", nrow(monthly), "\n")

极大似然估计：G-R 关系

gr_fit.R R 
# Gutenberg-Richter 关系的极大似然估计
# log10(N) = a - b*M
# 或：频率密度 f(M) = β exp(-β(M - Mc))，β = b*ln(10)

# 模拟地震目录（截断指数分布）
set.seed(42)
Mc <- 3.0       # 完整性震级
b_true <- 1.0   # b 值

n <- 1000
M <- Mc + rexp(n, rate = b_true * log(10))
# 截断到 [Mc, 8]
M <- M[M <= 8]

cat("样本数:", length(M), "\n")
cat("震级范围:", range(M), "\n")

# ---- 1. b 值的 MLE ----
# 对截断指数分布：b_hat = log10(e) / (mean(M) - Mc)
b_hat <- log10(exp(1)) / (mean(M) - Mc)
cat("\nMLE b 值:", b_hat, "\n")
cat("真实 b 值:", b_true, "\n")

# 标准误（Aki 1965）：σ_b ≈ b / sqrt(N)
se_b <- b_hat / sqrt(length(M))
cat("标准误:", se_b, "\n")
cat("95% 置信区间:", b_hat - 1.96 * se_b, "~", b_hat + 1.96 * se_b, "\n")

# ---- 2. a 值的 MLE ----
# a = log10(N) + b * M_min（对区间 [Mc, M_max] 的累积数）
a_hat <- log10(length(M)) + b_hat * Mc
cat("\na 值:", a_hat, "\n")

# ---- 3. 可视化 ----
# 累积频次
M_bins <- seq(Mc, 8, by = 0.1)
cum_counts <- sapply(M_bins, function(m) sum(M >= m))

# 拟合线
fit_line <- 10^(a_hat - b_hat * M_bins)

# 绘图
plot(M_bins, cum_counts, log = "y",
     xlab = "震级 M", ylab = "N(M ≥ m)",
     main = "Gutenberg-Richter 关系",
     pch = 16, cex = 0.7, col = "steelblue")
lines(M_bins, fit_line, col = "darkred", lwd = 2)
legend("topright",
       legend = c("观测", sprintf("拟合 (b = %.3f)", b_hat)),
       col = c("steelblue", "darkred"),
       pch = c(16, NA), lty = c(NA, 1))

# ---- 4. 用 fitdistrplus 拟合 ----
if (requireNamespace("fitdistrplus", quietly = TRUE)) {
  library(fitdistrplus)
  fit <- fitdist(M, "exp", start = list(rate = 1))
  print(summary(fit))
}

  data {
    int N;
    vector[N] M;
    vector[N] lnR;
    vector[N] ln_pga;

  parameters {
    real c0;
    real c1;
    real c2;

  model {
    // 先验
    c0 ~ normal(1.5, 1);
    c1 ~ normal(0.8, 0.5);
    c2 ~ normal(-1.2, 0.5);
    sigma ~ cauchy(0, 0.5);

    // 似然
    for (i in 1:N) {
      ln_pga[i] ~ normal(c0 + c1 * M[i] + c2 * lnR[i], sigma);
    }
  }
  "

  )

  # 编译与采样
  fit <- stan(model_code = stan_code, data = data_list,
              chains = 4, iter = 2000, warmup = 1000)

  print(fit, pars = c("c0", "c1", "c2", "sigma"))
  plot(fit)

ETAS 模型简介

ETAS（Epidemic Type Aftershock Sequence）是余震序列的标准模型：

$$ \lambda(t) = \mu + \sum_{t_i < t} \frac{K e^{\alpha (M_i - M_c)}}{(t - t_i + c)^p} $$

其中：

  • $\mu$：背景地震发生率。
  • $K$、$\alpha$：余震触发强度。
  • $c$、$p$：Omori 衰减参数。

R 中有专门的 ETAS 包（ETAS、etasFLP）， 可以对地震目录做极大似然估计与模拟。

# 危险性曲线插值
hazard_curve <- function(pga_grid, lambda, pga_target) {
  # 对数插值
  approx(log10(pga_grid), log10(lambda),
         xout = log10(pga_target))$y |>
    (function(x) 10^x)()
}

# 一致危险性谱
uhs <- function(T_grid, hazard_level, curves) {
  sapply(T_grid, function(T) {
    sapply(hazard_level, function(h) {
      # curves[[T]] 是危险性曲线
      hazard_curve(curves[[T]]$pga,
                   curves[[T]]$lambda,
                   h)
    })
  })
}

# 分位数
quantile_hazard <- function(curves, probs = c(0.16, 0.5, 0.84)) {
  apply(curves, 1, quantile, probs = probs)
}
