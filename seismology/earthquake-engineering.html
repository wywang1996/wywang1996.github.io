地震工程

从地震动输入到结构响应，从反应谱到性能化设计， 梳理结构抗震分析的核心方法论。 它把地震学与结构动力学连接起来，是土木工程中最"系统化"的分支之一。

反应谱 抗震设计 隔震消能 性能化设计

§引言

地震工程研究地震动对结构的作用以及结构如何抗震。 它横跨三个学科：地震学提供地震动输入， 结构动力学提供响应分析方法， 土木工程提供设计与构造措施。

这门学科的核心问题只有一个： 如何用有限的代价，让结构在未来可能遭遇的地震中 安全、可用、可修复？

按研究链条，地震工程可以分为四个层次：

  • 危险性层：场地未来可能遭遇多大的地震动？——PSHA 与地震区划。
  • 输入层：如何选取或合成合适的地震动时程？——选波、人工合成、比例调整。
  • 响应层：结构在该地震动下的响应如何？——反应谱法、时程分析、Pushover。
  • 设计层：如何保证结构的抗震性能？——承载力设计、延性构造、隔震消能。

这份笔记按"输入 $\to$ 单自由度 $\to$ 多自由度 $\to$ 设计 $\to$ 隔震 $\to$ 场地 $\to$ 性能化 $\to$ 非线性" 的顺序梳理，每一节都尽量落到工程语境上。

01地震动输入

三种输入形式

结构抗震分析中，地震动可以有三种形式的输入：

形式适用方法优点缺点
加速度时程 $a(t)$ 时程分析 信息完整、可考虑非线性 计算量大、选波困难
反应谱 $S_a(T, \zeta)$ 反应谱法 计算简便、规范成熟 丢失相位、仅适用线性
功率谱 $S(\omega)$ 随机振动 概率意义明确 简化假设多

时程选波的三条准则

选择实际强震记录时，通常要求：

  • 幅值匹配：PGA 与设计地震动水平一致。
  • 频谱匹配：在结构主要周期段，反应谱与设计谱匹配。
  • 持时匹配：有效持时覆盖结构主要响应时段。

工程上通常选取 3~7 条实际记录，或 7~11 条人工合成记录， 取响应的平均值（或包络）作为设计依据。

地震动的三要素

描述一条地震动的强度特性，有三个基本要素：

要素物理含义典型指标
幅值 地震动的强弱 PGA、PGV、PGD、Arias 强度
频谱 能量在不同频率的分布 傅里叶谱、反应谱、卓越周期
持时 地震动持续的时间 括号持时、有效持时（Arias 5%~95%）

Arias 强度

Arias 强度是地震动总能量的度量：

$$ I_A = \frac{\pi}{2g} \int_0^{t_d} a^2(t) \, dt $$

单位是 m/s，与地震总能量成正比。 有效持时定义为 Arias 强度从 5% 到 95% 所需的时间，记为 $t_{5-95}$。

人工合成地震动

当实际记录不足时，可以人工合成。常用方法：

  • 三角级数法：用一系列正弦波叠加，通过迭代调整使反应谱匹配目标谱。
  • 经验格林函数法：用小震记录作为经验格林函数，通过叠加合成大震记录。
  • 随机振动法：从功率谱密度出发，生成具有特定统计特性的样本。
💡

工程实践：中国规范（GB 50011）要求至少选取 2 组实际记录 + 1 组人工记录。 美国 ASCE 7 要求至少 7 条记录。日本规范则允许用"设计用地震波"（如 EL Centro、Taft、Kobe） 进行标准时程分析。选波的目标是让结构响应在设计谱与选波谱的差异范围内可控。

02单自由度与反应谱

单自由度运动方程

单自由度体系在基底地震动 $\ddot{u}_g(t)$ 作用下的运动方程：

$$ m \ddot{u} + c \dot{u} + k u = -m \ddot{u}_g(t) $$

除以质量，得到标准形式：

$$ \ddot{u} + 2\zeta\omega_n \dot{u} + \omega_n^2 u = -\ddot{u}_g(t) $$

其中 $\omega_n = \sqrt{k/m}$ 是固有圆频率，$\zeta = c/(2m\omega_n)$ 是阻尼比。

相对位移反应谱

对给定地震动 $\ddot{u}_g(t)$ 和给定阻尼比 $\zeta$， 对一系列周期 $T_i = 2\pi/\omega_{n,i}$ 求解上面的方程， 取最大相对位移：

$$ S_d(T, \zeta) = \max_t |u(t)| $$

由此可以定义：

$$ S_v(T, \zeta) = \omega_n S_d, \qquad S_a(T, \zeta) = \omega_n^2 S_d $$

三者分别称为谱位移、谱速度、谱加速度。

伪速度与四分之一关系

在实际地震动的频率范围内，$S_v$、$S_a$、$S_d$ 近似满足：

$$ S_a \approx \omega_n S_v \approx \omega_n^2 S_d $$

这称为"伪速度近似"。在双对数坐标下， $S_v$ 与 $T$ 的关系呈现三个区段：

  • 短周期段（$T < T_g$）：$S_a$ 近似为常数，等于 PGA 的放大。
  • 中等周期段（$T_g < T < T_d$）：$S_v$ 近似为常数。
  • 长周期段（$T > T_d$）：$S_d$ 近似为常数，$S_a \propto 1/T^2$。

这就是设计谱的三段式来源，也是各国规范设计谱的基本形式。

规范设计谱

中国规范（GB 50011）的水平地震影响系数曲线：

$$ \alpha(T) = \begin{cases} (0.45 + 10(\eta_2 - 0.45)T) \alpha_{\max}, & T < 0.1\text{ s} \\ \eta_2 \alpha_{\max}, & 0.1 \le T \le T_g \\ \left(\dfrac{T_g}{T}\right)^{\gamma} \eta_2 \alpha_{\max}, & T_g \le T \le 5T_g \\ \left[0.2^{\gamma} - \dfrac{\eta_2 (T - 5T_g)}{5T_g}\right] \alpha_{\max}, & T > 5T_g \end{cases} $$

其中 $\alpha_{\max}$ 是地震影响系数最大值，$T_g$ 是场地特征周期， $\gamma$ 是衰减指数，$\eta_2$ 是阻尼调整系数。

Python 示例：计算加速度反应谱

response_spectrum.py Python 
import numpy as np
import matplotlib.pyplot as plt


def sdof_response(ag, dt, T, zeta):
    """
    用 Newmark-β 平均加速度法求解单自由度体系响应。
    ag: 地面加速度时程
    dt: 时间步长
    T:  自振周期
    zeta: 阻尼比
    """
    m = 1.0
    omega = 2 * np.pi / T
    k = m * omega**2
    c = 2 * m * omega * zeta

    n = len(ag)
    u = np.zeros(n)
    v = np.zeros(n)
    a = np.zeros(n)

    # 初始加速度
    a[0] = -ag[0] - 2 * zeta * omega * v[0] - omega**2 * u[0]

    # Newmark-β 参数
    gamma = 0.5
    beta = 0.25

    K_eff = k + gamma / (beta * dt) * c + 1.0 / (beta * dt**2) * m

    for i in range(n - 1):
        P_eff = (
            -m * ag[i + 1]
            + m * (1.0 / (beta * dt**2) * u[i]
                   + 1.0 / (beta * dt) * v[i]
                   + (1.0 / (2 * beta) - 1.0) * a[i])
            + c * (gamma / (beta * dt) * u[i]
                   + (gamma / beta - 1.0) * v[i]
                   + dt * (gamma / (2 * beta) - 1.0) * a[i])
        )
        u[i + 1] = P_eff / K_eff
        v[i + 1] = (gamma / (beta * dt) * (u[i + 1] - u[i])
                    - (gamma / beta - 1.0) * v[i]
                    - dt * (gamma / (2 * beta) - 1.0) * a[i])
        a[i + 1] = (1.0 / (beta * dt**2) * (u[i + 1] - u[i])
                    - 1.0 / (beta * dt) * v[i]
                    - (1.0 / (2 * beta) - 1.0) * a[i])
    return u, v, a


def response_spectrum(ag, dt, periods, zeta=0.05):
    """计算加速度反应谱 Sa"""
    Sa = np.zeros_like(periods)
    for i, T in enumerate(periods):
        if T <= 0.01:
            Sa[i] = np.max(np.abs(ag))   # 极短周期近似 PGA
            continue
        _, _, a_rel = sdof_response(ag, dt, T, zeta)
        Sa[i] = np.max(np.abs(a_rel + ag))   # 绝对加速度
    return Sa


if __name__ == "__main__":
    # 用一段模拟地震动（频率成分丰富）
    dt = 0.01
    t = np.arange(0, 30, dt)
    rng = np.random.default_rng(42)

    # 简单合成：多个正弦 + 包络 + 噪声
    ag = np.zeros_like(t)
    for f in [0.5, 1.0, 2.0, 5.0]:
        ag += np.sin(2 * np.pi * f * t + rng.uniform(0, 2 * np.pi))
    ag *= np.exp(-((t - 8) ** 2) / (2 * 4.0**2))    # 包络
    ag *= 3.0   # 放大到 PGA ≈ 3 m/s²

    print(f"PGA = {np.max(np.abs(ag)):.3f} m/s²")

    # 计算反应谱
    periods = np.logspace(np.log10(0.05), np.log10(5.0), 100)
    for zeta in [0.02, 0.05, 0.10]:
        Sa = response_spectrum(ag, dt, periods, zeta)
        plt.plot(periods, Sa, label=f"ζ = {zeta}")

    plt.xlabel("周期 T / s")
    plt.ylabel("$S_a$ / (m/s²)")
    plt.title("加速度反应谱")
    plt.xscale("log")
    plt.legend()
    plt.grid(True, which="both", alpha=0.3)
    plt.tight_layout()
    plt.show()

运行后可以看到：阻尼比越大，反应谱峰值越低； 在长周期段，反应谱随周期衰减，与设计谱的三段式吻合。

03多自由度与振型分解

多自由度运动方程

$n$ 自由度体系的运动方程：

$$ \mathbf{M}\ddot{\mathbf{u}} + \mathbf{C}\dot{\mathbf{u}} + \mathbf{K}\mathbf{u} = -\mathbf{M}\mathbf{1}\ddot{u}_g(t) $$

其中 $\mathbf{1}$ 是全 1 向量，$\mathbf{M}\mathbf{1}\ddot{u}_g$ 是地面加速度引起的惯性力。

广义特征值问题

无阻尼自由振动：

$$ \mathbf{K}\boldsymbol{\phi} = \omega^2 \mathbf{M}\boldsymbol{\phi} $$

求解得 $n$ 阶固有频率 $\omega_1 < \omega_2 < \cdots < \omega_n$ 和对应的振型 $\boldsymbol{\phi}_1, \ldots, \boldsymbol{\phi}_n$。

振型关于 $\mathbf{M}$ 与 $\mathbf{K}$ 正交：

$$ \boldsymbol{\phi}_i^{\mathsf{T}} \mathbf{M} \boldsymbol{\phi}_j = 0, \quad \boldsymbol{\phi}_i^{\mathsf{T}} \mathbf{K} \boldsymbol{\phi}_j = 0 \qquad (i \ne j) $$

通常对振型做质量归一化：

$$ \boldsymbol{\phi}_i^{\mathsf{T}} \mathbf{M} \boldsymbol{\phi}_i = 1 $$

振型分解法

令 $\mathbf{u}(t) = \sum_{i=1}^{n} \boldsymbol{\phi}_i q_i(t)$， 代入运动方程并左乘 $\boldsymbol{\phi}_j^{\mathsf{T}}$， 利用正交性可得解耦的单自由度方程：

$$ \ddot{q}_i + 2\zeta_i \omega_i \dot{q}_i + \omega_i^2 q_i = -\Gamma_i \ddot{u}_g(t) $$

其中 $\Gamma_i$ 是第 $i$ 阶振型的参与系数：

$$ \Gamma_i = \frac{\boldsymbol{\phi}_i^{\mathsf{T}} \mathbf{M} \mathbf{1}} {\boldsymbol{\phi}_i^{\mathsf{T}} \mathbf{M} \boldsymbol{\phi}_i} $$

振型参与系数反映了该振型对整体响应的贡献。 通常前几阶振型就贡献了大部分响应。

振型组合

每个振型的最大响应求出后，需要组合得到总响应。 常用两种方法：

SRSS（平方和开方）：

$$ R = \sqrt{\sum_i R_i^2} $$

CQC（完全二次组合）：

$$ R = \sqrt{\sum_i \sum_j \rho_{ij} R_i R_j} $$

其中 $\rho_{ij}$ 是振型相关系数。 当振型频率相差较大时，$\rho_{ij} \to 0$，CQC 退化为 SRSS。 对周期接近的密集模态，CQC 更准确。

有效质量与振型截断

定义第 $i$ 阶振型的有效质量：

$$ M_i^* = \frac{(\boldsymbol{\phi}_i^{\mathsf{T}} \mathbf{M} \mathbf{1})^2} {\boldsymbol{\phi}_i^{\mathsf{T}} \mathbf{M} \boldsymbol{\phi}_i} $$

所有振型有效质量之和等于总质量：

$$ \sum_{i=1}^{n} M_i^* = \mathbf{1}^{\mathsf{T}} \mathbf{M} \mathbf{1} $$

工程上通常选取前 $m$ 阶振型，使累计有效质量达到总质量的 90% 以上。 这决定了需要保留多少阶模态。

💡

振型分解的意义：它把一个 $n$ 自由度的耦合问题 变成 $n$ 个独立的单自由度问题。 求解 $n$ 个 SDOF 比直接求解耦合的 MDOF 简单得多， 这就是模态分析的全部价值。 在线性范围内，任何复杂结构的动力响应都可以这样分解。

04抗震设计方法

三水准设防目标

中国规范采用三水准设防：

水准地震水平超越概率设防目标
第一水准（小震） 多遇地震 50 年 63% 不损坏、不需修理
第二水准（中震） 设防地震 50 年 10% 可能损坏、可修复
第三水准（大震） 罕遇地震 50 年 2%~3% 不倒塌、不危及生命

俗称"小震不坏、中震可修、大震不倒"。

底部剪力法

对高度不超过 40 m、以剪切变形为主、质量刚度沿高度分布均匀的结构， 可用底部剪力法：

$$ V_0 = \alpha_1 G_{\text{eq}} $$

其中 $\alpha_1$ 是第一阶振型对应的地震影响系数， $G_{\text{eq}} = 0.85 \sum G_i$ 是等效总重力荷载。

各层水平地震作用：

$$ F_i = \frac{G_i H_i}{\sum_{j=1}^{n} G_j H_j} V_0 (1 - \delta_n), \qquad \Delta F_n = \delta_n V_0 $$

其中 $\delta_n$ 是顶部附加地震作用系数。

振型分解反应谱法

对一般结构，用振型分解反应谱法：

  1. 求结构的固有频率与振型。
  2. 计算每个振型的参与系数 $\Gamma_i$。
  3. 对每个振型，用反应谱求该振型的最大响应。
  4. 用 SRSS 或 CQC 组合得到总响应。
  5. 与荷载效应组合，验算承载力。

时程分析法

对重要结构、超高层、复杂体型，要求做时程分析。 直接对运动方程做数值积分，得到全过程响应。 这是唯一能直接处理非线性的方法。

常用积分方法：

  • Newmark-β 法：隐式、无条件稳定，适合结构动力学。
  • Wilson-θ 法：隐式、有数值阻尼，可抑制高频虚假振荡。
  • 中心差分法：显式、条件稳定，适合波传播问题。

抗震构造措施

计算只是设计的一半，构造措施同样重要：

  • 强柱弱梁：保证梁先于柱屈服，形成延性破坏机制。
  • 强剪弱弯：避免脆性剪切破坏。
  • 强节点弱构件：节点核心区必须足够强。
  • 箍筋加密：提高约束、保证延性。
  • 轴压比限制：避免柱子压溃。
⚠️

常见误区：抗震设计不是"把结构做得越刚越好"。 刚度过大会导致地震作用力增大（$F = ma$，刚度越大、周期越短、加速度响应越大）。 合理的抗震设计追求的是刚柔相济： 通过合理的延性设计，让结构在中震、大震下进入非线性， 用可控的塑性变形耗散地震能量。

05隔震与消能

基础隔震原理

基础隔震的核心思想：在结构与基础之间设置柔性层， 延长结构周期，把结构的主频移出地震动能量集中的频段。

单自由度隔震体系的周期：

$$ T_{\text{iso}} = 2\pi \sqrt{\frac{M}{K_{\text{iso}}}} $$

通常要求 $T_{\text{iso}} \ge 2\sim 3$ s，远大于普通结构的 0.5~1 s。

隔震前后的加速度比（在长周期段）约为：

$$ \frac{S_a(T_{\text{iso}})}{S_a(T_{\text{fix}})} \approx \left(\frac{T_{\text{fix}}}{T_{\text{iso}}}\right)^{\gamma} $$

当 $\gamma \approx 1$ 时，周期延长 3 倍，加速度可降低 2/3。

隔震装置的力学模型

常用隔震支座（如铅芯橡胶支座 LRB）的双线性恢复力模型：

$$ F = \begin{cases} K_1 u, & |u| \le u_y \\ F_y + K_2 (u - u_y \mathrm{sgn}\,u) \cdot \mathrm{sgn}\,u, & |u| > u_y \end{cases} $$

其中 $K_1$ 是初始刚度，$K_2$ 是屈服后刚度，$F_y$ 是屈服力。 等效阻尼比：

$$ \zeta_{\text{eff}} = \frac{2(1 - K_2/K_1) F_y u_{\max}} {\pi K_{\text{eff}} u_{\max}^2} $$

消能减震

在结构中设置阻尼器，增加附加阻尼，直接耗散地震能量。 常用类型：

类型机理特点
粘滞阻尼器 流体通过孔口的粘滞阻力 速度相关、耗能强
粘弹性阻尼器 高分子材料的滞回耗能 位移相关、造价低
金属屈服阻尼器 软钢的塑性滞回 位移相关、稳定可靠
摩擦阻尼器 摩擦面滑动的耗能 库仑型、与速度无关
调谐质量阻尼器（TMD） 附加质量与结构共振反相 控制风振与鞭梢效应

附加阻尼对响应的影响

对单自由度体系，附加阻尼比 $\zeta_a$ 后，共振峰值的降低比例约为：

$$ \frac{|H(\omega_n)|_{\zeta + \zeta_a}}{|H(\omega_n)|_{\zeta}} \approx \frac{\zeta}{\zeta + \zeta_a} $$

例如从 $\zeta = 0.05$ 增加到 $\zeta = 0.20$，峰值降低约 4 倍。 这就是消能减震的直观效果。

Python 示例：隔震前后的响应对比

isolation.py Python 
import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import solve_ivp


def sdof_acceleration(t, y, omega, zeta, ag_func):
    """单自由度体系的加速度响应（相对坐标）"""
    u, v = y
    ag = ag_func(t)
    du = v
    dv = -2 * zeta * omega * v - omega**2 * u - ag
    return [du, dv]


def solve_sdof(T, zeta, ag_func, t_end):
    """给定 T、ζ 和地震动，求解 SDOF 响应"""
    omega = 2 * np.pi / T
    sol = solve_ivp(
        sdof_acceleration, [0, t_end], [0.0, 0.0],
        args=(omega, zeta, ag_func),
        max_step=0.005, dense_output=True
    )
    return sol


if __name__ == "__main__":
    # ---- 简单合成地震动 ----
    def make_ag(freqs, t_end=30.0):
        def ag(t):
            s = 0.0
            for f, amp in freqs:
                s += amp * np.sin(2 * np.pi * f * t)
            envelope = np.exp(-((t - 8) ** 2) / (2 * 5.0**2))
            return s * envelope
        return ag, t_end

    freqs = [(0.5, 1.0), (1.5, 1.5), (3.0, 1.0), (5.0, 0.5)]
    ag_func, t_end = make_ag(freqs)

    t = np.linspace(0, t_end, 3000)
    ag = np.array([ag_func(ti) for ti in t])
    print(f"PGA = {np.max(np.abs(ag)):.3f} m/s²")

    # ---- 固定基础结构：T = 0.5 s, ζ = 0.05 ----
    sol_fix = solve_sdof(T=0.5, zeta=0.05, ag_func=ag_func, t_end=t_end)
    u_fix = sol_fix.sol(t)[0]
    a_fix_abs = np.gradient(np.gradient(u_fix, t), t) + ag

    # ---- 隔震结构：T = 3.0 s, ζ = 0.15 ----
    sol_iso = solve_sdof(T=3.0, zeta=0.15, ag_func=ag_func, t_end=t_end)
    u_iso = sol_iso.sol(t)[0]
    a_iso_abs = np.gradient(np.gradient(u_iso, t), t) + ag

    # ---- 结果对比 ----
    print(f"\n固定基础结构：max|u| = {np.max(np.abs(u_fix)):.4f} m，"
          f"max|a_abs| = {np.max(np.abs(a_fix_abs)):.4f} m/s²")
    print(f"隔震结构：    max|u| = {np.max(np.abs(u_iso)):.4f} m，"
          f"max|a_abs| = {np.max(np.abs(a_iso_abs)):.4f} m/s²")

    ratio = np.max(np.abs(a_iso_abs)) / np.max(np.abs(a_fix_abs))
    print(f"\n隔震后加速度降低到原来的 {ratio*100:.1f}%")

    # ---- 绘图 ----
    fig, axes = plt.subplots(2, 1, figsize=(11, 7), sharex=True)
    axes[0].plot(t, ag, color="gray", label="地面加速度")
    axes[0].set_ylabel("$a_g$ / (m/s²)")
    axes[0].legend()
    axes[0].grid(True, alpha=0.3)

    axes[1].plot(t, a_fix_abs, label=f"固定基础 (T=0.5s)")
    axes[1].plot(t, a_iso_abs, label=f"隔震 (T=3.0s, ζ=0.15)")
    axes[1].set_xlabel("t / s")
    axes[1].set_ylabel("绝对加速度 / (m/s²)")
    axes[1].legend()
    axes[1].grid(True, alpha=0.3)

    plt.tight_layout()
    plt.show()

运行后可以看到：隔震结构的绝对加速度显著低于固定基础结构， 但位移明显增大（这是隔震的代价——需要设置足够的位移空间）。

06场地效应与液化

场地效应

覆盖土层对地震动的放大/缩小作用称为场地效应。 主要由三个因素决定：

  • 剪切波速：$V_s$ 越小，土越软，放大作用越强。
  • 覆盖层厚度：$H$ 越大，卓越周期越长。
  • 阻抗比：基岩与土层的阻抗差异越大，反射越强。

单层覆盖土的卓越频率：

$$ f_0 = \frac{V_s}{4H} $$

对应的卓越周期 $T_0 = 1/f_0 = 4H/V_s$。 当结构自振周期接近卓越周期时，会发生共振放大。

1985 年墨西哥城地震中，中高层建筑破坏严重， 正是因为其周期接近湖积层的卓越周期（约 2 s）。

场地分类

中国规范按等效剪切波速和覆盖层厚度分为四类场地：

场地类别等效剪切波速 $V_{se}$覆盖层厚度特征周期 $T_g$
Ⅰ 类（坚硬土） $V_{se} > 500$ m/s — 0.20~0.25 s
Ⅱ 类（中硬土） 250 < $V_{se} \le 500$ — 0.35~0.40 s
Ⅲ 类（中软土） 150 < $V_{se} \le 250$ < 50 m 0.45~0.55 s
Ⅳ 类（软弱土） $V_{se} \le 150$ > 50 m 0.65~0.90 s

液化

饱和砂土在地震作用下，孔隙水压力迅速上升， 有效应力降低到零，土体失去抗剪强度，表现如液体。

液化判别常用标准贯入试验（SPT）临界值：

$$ N_{\text{cr}} = N_0 [0.9 + 0.1(d_s - d_w)] \sqrt{\frac{3}{\rho_c}} $$

其中 $N_0$ 是基准值，$d_s$ 是深度，$d_w$ 是地下水位深度，$\rho_c$ 是黏粒含量百分比。 当实测 $N < N_{\text{cr}}$ 时，判为液化。

液化防治措施

  • 换土：挖除液化土层，换填非液化土。
  • 加密：振冲法、强夯法，提高砂土密实度。
  • 排水：设置砂井或塑料排水板，加速孔压消散。
  • 固化：水泥搅拌桩、注浆，提高土体强度。
  • 基础处理：桩基穿越液化层，支撑在非液化层上。
💡

场地效应的时域模拟：一维土层地震反应分析用 SHAKE 等程序，在频域内逐层传递 SH 波。 其数学基础正是偏微分方程中的波动方程—— 土层是粘弹性介质，地震波在层状介质中传播、反射、衰减。 这就是地震学与地震工程最直接的交叉点。

07性能化抗震设计

基本思想

传统设计基于"规范合规"，只要满足规范条文即可。 性能化设计基于"性能目标"， 明确结构在不同地震水平下应达到的性能水准。

四个性能水准

水准结构状态人员安全使用功能
Ⅰ 正常使用 无损伤 安全 正常
Ⅱ 立即入住 轻微损伤 安全 基本正常
Ⅲ 生命安全 中等损伤 安全 中断使用
Ⅳ 防止倒塌 严重损伤 基本安全 不可使用

地震水平与性能目标的组合

常见的性能目标矩阵：

地震水平常遇地震偶遇地震罕遇地震
超越概率（50 年） 63% 10% 2%
基本目标 正常使用 立即入住 生命安全
重要建筑 正常使用 正常使用 立即入住
关键设施 正常使用 正常使用 正常使用

能力谱法

能力谱法是性能化设计的核心工具，把结构能力与地震需求在同一坐标系下比较：

  • 能力谱：把 Pushover 曲线转化为 $S_a$-$S_d$ 坐标。
  • 需求谱：把设计反应谱转化为 $S_a$-$S_d$ 坐标。
  • 性能点：两条曲线的交点，代表结构在该地震下的预期响应。

如果性能点的位移小于结构的极限位移，则性能目标满足。 这就是 ATC-40 和 FEMA 356 的方法论。

Pushover 分析

对结构施加单调递增的侧向力，记录基底剪力-顶点位移曲线， 直到结构破坏。这是评估结构非线性行为的常用简化方法。

侧向力分布可以选择：

  • 倒三角分布：$F_i \propto m_i h_i$，适合低层规则结构。
  • 均匀分布：各层力相同，适合刚度分布均匀的结构。
  • 振型分布：按第一阶振型比例分布，适合高层结构。
  • 自适应分布：根据响应实时调整，更接近实际地震作用。
💡

性能化设计的价值：传统规范只提供"最低要求"， 性能化设计允许业主与工程师协商确定"合适的安全水准"。 医院、数据中心、核电站等关键设施可以要求更高的性能目标， 而普通住宅可以在满足生命安全的前提下降低造价。 这让抗震设计从"合规"走向"决策"。

08非线性分析

为什么需要非线性分析

弹性分析假设结构在地震下不损伤，但实际中：

  • 结构在中震、大震下必然进入非线性（混凝土开裂、钢筋屈服）。
  • 非线性耗能是结构抗震的根本机制。
  • 弹性分析会高估地震作用，导致不经济的设计。

非线性分析的必要性：准确评估结构在大震下的真实响应。

非线性来源

  • 材料非线性：混凝土开裂、钢筋屈服、钢材塑性。
  • 几何非线性：大位移、P-Δ 效应、索的几何刚度。
  • 边界非线性：接触、摩擦、间隙。

塑性铰模型

集中塑性模型（如 Clough 模型、Takeda 模型）把非线性集中在构件端部的塑性铰：

$$ M = f(\theta) $$

常见的骨架曲线是三线性或四线性： 弹性段 → 开裂点 → 屈服点 → 强化段 → 极限点。

纤维模型

把截面离散为若干纤维，每根纤维用一维材料本构（如混凝土、钢筋的应力-应变关系）。 截面弯矩由所有纤维的贡献积分得到：

$$ M = \int_A \sigma(\varepsilon) y \, dA \approx \sum_{i=1}^{n} \sigma_i \varepsilon_i y_i A_i $$

纤维模型能自然处理轴力-弯矩耦合、双向弯曲等复杂受力。 这是现代结构分析软件（OpenSees、ABAQUS）的主流方法。

非线性时程分析流程

  1. 建立有限元模型（单元、材料、边界）。
  2. 输入地震动时程。
  3. 每个时间步内，迭代求解非线性方程组。
  4. Newton-Raphson 或 Modified Newton 迭代收敛。
  5. 更新刚度矩阵、内力、变形。
  6. 记录全过程响应，评估性能指标。

性能指标

  • 层间位移角：$\theta = \Delta u / h$，是最常用的损伤指标。
  • 塑性铰转角：$\theta_p$，反映构件延性需求。
  • 残余位移：地震后的永久变形，影响可修复性。
  • 累积滞回耗能：$\int F \, du$，反映损伤累积。

Python 示例：单自由度双线性滞回

bilinear.py Python 
import numpy as np
import matplotlib.pyplot as plt


class BilinearSDOF:
    """
    单自由度双线性滞回体系的非线性时程分析。
    参数：
      m  : 质量
      k  : 初始刚度
      fy : 屈服力
      alpha : 屈服后刚度比
      zeta : 粘性阻尼比
    """
    def __init__(self, m, k, fy, alpha=0.05, zeta=0.02):
        self.m = m
        self.k = k
        self.fy = fy
        self.alpha = alpha
        self.zeta = zeta

        self.uy = fy / k          # 屈服位移
        self.omega = np.sqrt(k / m)
        self.c = 2 * m * self.omega * zeta

        # 状态变量
        self.u = 0.0
        self.v = 0.0
        self.f = 0.0              # 恢复力
        self.u_max = 0.0          # 历史最大位移（用于判断加载/卸载）

    def restoring_force(self, u, u_max):
        """双线性恢复力"""
        uy = self.uy
        alpha = self.alpha
        fy = self.fy
        k = self.k

        # 判断当前状态
        if abs(u) <= uy:
            # 弹性段
            return k * u
        else:
            # 屈服后
            f_yield = fy if u > 0 else -fy
            u_yield = uy if u > 0 else -uy
            # 屈服后刚度
            k_post = alpha * k
            # 判断加载还是卸载
            if abs(u) >= abs(u_max):
                # 继续加载
                return f_yield + k_post * (u - u_yield)
            else:
                # 卸载（弹性卸载，刚度 k）
                u_rev = u_max * (1 if u_max > 0 else -1)
                f_rev = fy if u_max > 0 else -fy
                f_at_rev = f_rev + k_post * (u_rev - u_yield)
                return f_at_rev + k * (u - u_rev)

    def step(self, dt, ag):
        """用中心差分法做一步（简化版本）"""
        # 半隐式（类似 Newmark 平均加速度）
        beta, gamma = 0.25, 0.5

        # 预测位移
        u_pred = self.u + dt * self.v + dt**2 * 0.5 * (1 - 2*beta) * (self.f / self.m + ag)

        # 用固定点迭代求 u 使 运动方程成立
        u_new = u_pred
        for _ in range(20):
            f_new = self.restoring_force(u_new, max(abs(self.u_max), abs(u_new)))
            # 运动方程：m·a + c·v + f = -m·a_g
            # 用 Newmark 关系
            a_new = (u_new - self.u) / (beta * dt**2) \
                    - self.v / (beta * dt) \
                    - (1.0 / (2*beta) - 1) * (self.f / self.m + ag)
            v_new = self.v + dt * ((1 - gamma) * (self.f / self.m + ag) + gamma * a_new)
            f_check = -self.m * ag - self.c * v_new - self.m * a_new

            if abs(f_check - f_new) < 1e-6 * self.fy:
                break
            # 简单修正
            u_new = u_new + (f_check - f_new) / self.k * 0.5

        # 更新状态
        f_new = self.restoring_force(u_new, max(abs(self.u_max), abs(u_new)))
        a_new = (u_new - self.u) / (beta * dt**2) \
                - self.v / (beta * dt) \
                - (1.0 / (2*beta) - 1) * (self.f / self.m + ag)
        v_new = self.v + dt * ((1 - gamma) * (self.f / self.m + ag) + gamma * a_new)

        self.u = u_new
        self.v = v_new
        self.f = f_new
        self.u_max = max(abs(self.u_max), abs(u_new))


if __name__ == "__main__":
    # ---- 系统参数 ----
    m = 1.0
    T = 0.5
    omega = 2 * np.pi / T
    k = m * omega**2
    fy = 0.5 * k * 0.05   # 屈服位移 0.05 m 对应的力
    sys = BilinearSDOF(m, k, fy, alpha=0.05, zeta=0.02)

    print(f"体系参数：T = {T} s, ω = {omega:.3f} rad/s")
    print(f"屈服位移 uy = {sys.uy:.5f} m")
    print(f"屈服力   fy = {fy:.5f} N")

    # ---- 正弦激励（振幅递增，模拟地震动） ----
    dt = 0.002
    t_end = 20.0
    t = np.arange(0, t_end, dt)
    # 频率接近体系自振频率，振幅递增
    envelope = np.minimum(t / 5.0, 1.0) * np.exp(-((t - 10) ** 2) / (2 * 4.0**2))
    ag = -3.0 * envelope * np.sin(2 * np.pi * t / T)

    # ---- 逐步积分 ----
    u_hist = []
    for ag_i in ag:
        sys.step(dt, ag_i)
        u_hist.append(sys.u)
    u_hist = np.array(u_hist)

    print(f"\n最大位移 u_max = {np.max(np.abs(u_hist)):.5f} m")
    print(f"延性比 μ = u_max / uy = {np.max(np.abs(u_hist))/sys.uy:.3f}")

    # ---- 绘图：位移时程 + 滞回曲线 ----
    fig, axes = plt.subplots(1, 2, figsize=(14, 5))

    axes[0].plot(t, u_hist)
    axes[0].axhline(sys.uy, color="gray", linestyle="--", alpha=0.5, label="±uy")
    axes[0].axhline(-sys.uy, color="gray", linestyle="--", alpha=0.5)
    axes[0].set_xlabel("t / s")
    axes[0].set_ylabel("位移 u / m")
    axes[0].set_title("位移时程")
    axes[0].legend()
    axes[0].grid(True, alpha=0.3)

    # 滞回曲线
    u_full = np.concatenate([[0], u_hist[:-1]])
    f_hist = np.array([sys.restoring_force(u, np.max(np.abs(u_hist[:i+1])))
                       for i, u in enumerate(u_hist)])
    axes[1].plot(u_hist, f_hist, linewidth=0.7)
    axes[1].axhline(fy, color="gray", linestyle="--", alpha=0.5)
    axes[1].axhline(-fy, color="gray", linestyle="--", alpha=0.5)
    axes[1].set_xlabel("位移 u / m")
    axes[1].set_ylabel("恢复力 f / N")
    axes[1].set_title("双线性滞回曲线")
    axes[1].grid(True, alpha=0.3)

    plt.tight_layout()
    plt.show()

运行后可以看到：结构在强激励下进入屈服， 滞回环面积代表耗散的能量。 滞回环越饱满，耗能能力越强，抗震性能越好。

09小结

📌 核心要点

  • 地震动输入：三要素（幅值、频谱、持时）；选波需同时满足三者。
  • 反应谱：单自由度体系最大响应的谱；三段式形状对应不同周期段的主导机制。
  • 振型分解：把 MDOF 解耦为 SDOF；有效质量决定振型截断；SRSS/CQC 组合。
  • 抗震设计：三水准设防（小震不坏、中震可修、大震不倒）；底部剪力法、反应谱法、时程法。
  • 隔震与消能：延长周期或增加阻尼，降低地震响应；代价是位移增大。
  • 场地效应：覆盖层放大与卓越周期；液化判别与防治。
  • 性能化设计：基于性能目标而非合规；能力谱法、Pushover 分析。
  • 非线性分析：塑性铰、纤维模型；延性与滞回耗能是抗震的根本机制。
