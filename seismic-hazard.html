地震危险性分析

基于 Cornell–McGuire 概率地震危险性分析（PSHA）框架的场点危险性计算工具： 从震源模型、地震活动性参数与地震动预测方程出发，给出危险性曲线、 一致危险性反应谱与危险性分解结果，为抗震设防与结构时程分析提供地震动输入。

开发中 Python 3.10+ NumPy · SciPy 兼容 OpenQuake 2026
Overview

概述

地震危险性分析要回答的是一个概率问题：在未来一段时间内，某一场点遭受到超过给定强度地震动的可能性有多大？ 与只给出单一“最不利情景”的确定性方法不同，概率方法把震级、距离与地震动残差都视为随机变量， 最终输出的是与超越概率水平相对应的地震动参数。

本项目实现了完整的一套计算链路：把断层与地震带离散化为点源、线源与面源， 用古登堡–里克特关系描述震级分布，用地震动预测方程（GMPE）给出给定震级与距离下 IM 的对数正态分布，再沿震级与距离积分得到年超越概率 λ(IM > im)，最后按泊松模型换算成设计基准期内的超越概率。

PSHA 与 DSHA 的区别：确定性方法（DSHA）选取一个“最大可信地震”加上最不利距离， 得到一条设计地震动；概率方法（PSHA）则给出“50 年超越概率 10% 对应的 PGA 是多少” 这类可比较、可设防的量。两者服务于不同的决策场景，但概率结果更便于纳入规范体系。
Features

主要功能

01

危险性曲线计算

对指定场点与目标 IM，沿震级、距离积分并跨全部震源求和，输出年超越概率 λ(IM > im) 随 IM 变化的完整曲线。这是 PSHA 最核心的产出， 也是后续一致危险性反应谱、分解与区划图的计算基础。

  • 支持 PGA、PGV、PGD、Sa(T)、Arias 强度等多种 IM
  • 震级积分采用截断 G-R 分布，默认 200 采样点，可调
  • 点源、线源、面源三类震源几何统一处理
  • 同时给出年超越概率与设计基准期超越概率
  • 支持多场点批量计算与曲线叠加对比
02

一致危险性反应谱（UHS）

对一组周期逐一执行完整的危险性计算，取同一超越概率水平对应的谱值拼装成谱。 每个周期独立求解，因此 UHS 反映的是各周期各自的危险性水平， 适合直接与规范设计谱对比、校核设防参数。

  • 周期范围 0.01s–10s 任意指定，默认 50 个对数分布点
  • 支持 50 年超越概率 63%、10%、2% 等常用设防水准
  • 同时输出均值谱与逻辑树分位数谱
  • 可导出为 CSV / JSON，供结构时程分析直接调用
03

危险性分解（Deaggregation）

把总危险性按贡献来源拆解，回答“是哪个震级、哪个距离的地震主导了危险性”， 为天然波选取与人工波合成提供定量依据，避免凭经验挑波。

  • 按震级 M、震中距 R、残差 ε 三维分箱统计贡献占比
  • 输出各箱体贡献率，以及均值、众数震级与距离
  • 支持按震源、按周期分别分解
  • 分解结果可直接指导目标谱匹配与选波
04

逻辑树与不确定性

把震源模型、b 值、Mmax、GMPE 选择等认知不确定性用带权重的分支表达， 给出加权平均结果及其分位数，量化危险性估计的不确定区间。

  • 多层逻辑树，支持任意分支结构与权重归一化
  • 输出加权平均危险性曲线与 16 / 50 / 84 分位数
  • 支持分支贡献分析，识别主导不确定源
  • 认知不确定性与偶然不确定性分离报告
05

场地效应

把基岩面危险性转换到工程地表，考虑 Vs30、覆盖层厚度与土层非线性， 使结果能直接用于场地相关的抗震设计。

  • 支持 GMPE 内置 Vs30 场地项直接计算
  • 支持基岩结果乘场地放大因子 AF(Vs30, im)
  • 可对接一维等效线性化土层反应分析结果
  • 中国场地类别 I₀–IV 与 Vs30 双向映射
06

地震活动性参数标定

从地震目录出发，估计各震源区的 a、b 值与年发生率，并处理目录完整性问题， 为危险性积分提供可靠的活动性输入。

  • 最大似然估计 b 值及其标准差
  • 完整性震级 Mc 自动识别（最大曲率法、b 值稳定法）
  • 震级–频度关系拟合与残差诊断
  • 去丛集（Gardner–Knopoff）与泊松检验
07

GMPE 库管理

统一管理多个地震动预测方程，按构造类型与适用范围自动筛选并组合， 避免单一模型带来的系统性偏差。

  • 内置国内外常用 GMPE，支持自定义方程注册
  • 按震级、距离、场地条件检查适用范围并给出警告
  • 支持 GMPE 逻辑树加权与平滑过渡
  • 输出中位数、对数标准差与各周期分量
08

危险性区划图与网格计算

对规则网格批量执行危险性计算，生成指定概率水平下的等值线与分级着色图， 用于区域抗震规划与场地初筛。

  • 支持任意分辨率网格与并行加速
  • 输出等值线图、栅格图与 GeoJSON
  • 可叠加断层、场点与行政区划底图
  • 支持多概率水平分级与色标自定义
09

数据导入与导出

兼容主流地震目录与震源模型格式，计算结果可直接用于后续的结构分析与报告。

  • 目录格式：CSV、ISF、QuakeML、NDK
  • 震源模型：OpenQuake XML、GeoJSON 断层
  • 结果导出：CSV、JSON、HDF5、GeoJSON
  • 波形输入对接 SAC / MiniSEED
10

可视化与报告

内置交互式图表与报告生成，便于结果复核、参数敏感性检查与对外汇报。

  • 双对数危险性曲线、UHS、分解直方图、区划图
  • 交互式悬停读数与曲线对比
  • 一键生成含参数、图表与结论的 HTML / PDF 报告
  • 支持命令行批处理与脚本化调用
Workflow

工作流程

  1. 定义目标：确定场点坐标、目标 IM（PGA / Sa(T) / PGV）与设防概率水平（如 50 年超越概率 10%）。
  2. 构建震源模型：把活动断层、地震带离散为点源、线源与面源，给出几何参数与震源深度分布。
  3. 标定地震活动性：由地震目录统计 a、b 值，确定 Mmin、Mmax 与年发生率 ν，并做完整性震级校正。
  4. 选择 GMPE：按构造类型、震级与距离适用范围、场地条件挑选预测方程，设定逻辑树权重与对数标准差 σ。
  5. 计算条件概率：对每个 (m, r) 组合得到 IM 的对数正态分布，求 P(IM > im | m, r)。
  6. 积分求危险性：沿震级与距离积分并跨震源求和，得到 λ(IM > im)（次/年）。
  7. 换算超越概率：按泊松模型转换为 T 年内的超越概率，或反求目标概率下的 IM。
  8. 输出与后处理：生成危险性曲线、UHS、分解直方图与区划图，导出 CSV / GeoJSON。
Method

方法与公式

地震活动性模型

震级分布通常采用古登堡–里克特关系，并做上、下截断（截断指数分布）， 以保证 Mmax 以上不发生、Mmin 以下不参与积分：

log₁₀ N(m) = a − b·m # 古登堡–里克特关系 f_M(m) = b·ln10 · 10^(−b(m − Mmin)) / [1 − 10^(−b(Mmax − Mmin))] Mmin ≤ m ≤ Mmax # 截断 G-R 的震级概率密度

面源的距离分布 f_R(r) 由源区几何归一化得到；若源区面积远小于场点距离， 可简化为点源，此时 R 为确定值。

地震动预测方程（GMPE）

GMPE 给出给定震级、距离与场地条件下 IM 的中位数与离散度。 多数模型采用震级项、几何衰减项与场地项相加的形式，残差服从对数正态分布：

ln Y = f(M, R, Vs30, …) + ε·σ_lnY , ε ~ N(0, 1) P(IM > im | m, r) = 1 − Φ( [ln im − μ_lnY(m, r)] / σ_lnY ) # Φ 为标准正态累积分布函数；σ_lnY 通常取 0.5 ~ 0.8
选型要点：注意 GMPE 的适用范围（震级区间、距离区间、构造类型、是否含近断层项）， 超出适用范围外推会显著放大不确定性；同类模型之间用逻辑树加权可以缓和模型选择偏倚。

危险性积分

对全部震源求和，并对震级与距离做全概率积分，即得该 IM 水平的年超越概率：

λ(IM > im) = Σᵢ νᵢ · ∬ P(IM > im | m, r) · f_Mᵢ(m) · f_Rᵢ(r) dm dr P(IM > im, T 年内) = 1 − exp( −λ(IM > im) · T ) # 泊松模型 λ_target = −ln(1 − P) / T # 由目标概率反求年发生率

一致危险性反应谱（UHS）

对每个周期 Tₖ 重复一次完整的危险性计算，解出满足 λ(Sa(Tₖ) > sa) = λ_target 的 sa，把这些点连起来就得到 UHS。 注意 UHS 是一条等概率谱，各周期对应的控制性震级与距离并不相同， 不能把它当作某一次地震的反应谱。

场地效应

把基岩结果转换到地表常用两种方式：直接选用含 Vs30 项的 GMPE； 或在基岩结果上乘以场地放大因子 AF(Vs30, im)，后者可进一步与 一维等效线性化土层反应分析的结果校核。

Code

代码示例

下面是一个最小可运行的 PSHA 实现：单个点源 + 截断 G-R + 对数正态 GMPE， 输出危险性曲线与 50 年超越概率。真实项目在此结构上扩展多源、多 GMPE 逻辑树与场地项即可。

simple_psha.py Python 
"""
简化 PSHA：点源 + 截断 G-R + 对数正态 GMPE
输出危险性曲线与 50 年超越概率
"""
import numpy as np
from scipy.stats import norm


def gmpe_median(M, R):
    """返回 PGA 中位数（单位 g）——示意用简化式，实际应替换为选定 GMPE"""
    return np.exp(0.5 * M - 1.2 * np.log(R + 10.0) - 1.0)


def hazard_curve(Mmin, Mmax, b, nu, R, im_levels, sigma=0.55, n_m=200):
    """点源 PSHA：返回各 IM 水平的年超越概率 lambda"""
    m = np.linspace(Mmin, Mmax, n_m)

    # 截断 G-R 的震级概率密度 f_M(m)
    denom = 1.0 - 10 ** (-b * (Mmax - Mmin))
    fm = b * np.log(10) * 10 ** (-b * (m - Mmin)) / denom

    mu = np.log(gmpe_median(m, R))          # 各震级下的对数中位数
    lam = np.empty(len(im_levels))

    for i, im in enumerate(im_levels):
        # 条件超越概率 P(IM > im | m, R)
        p = 1.0 - norm.cdf((np.log(im) - mu) / sigma)
        lam[i] = nu * np.trapz(p * fm, m)   # 沿震级积分

    return lam


if __name__ == "__main__":
    im = np.array([0.05, 0.1, 0.2, 0.3, 0.5, 0.8, 1.0])
    lam = hazard_curve(Mmin=4.5, Mmax=7.5, b=0.9, nu=0.5, R=15.0, im_levels=im)
    p50 = 1.0 - np.exp(-lam * 50.0)         # 50 年超越概率

    for i, l, p in zip(im, lam, p50):
        print(f"PGA={i:4.2f} g   lambda={l:.5f}/yr   P50={p * 100:5.2f}%")
这段代码只做演示：没有包含多震源叠加、距离分布积分、逻辑树加权与场地放大， 也没有处理地震目录的完整性震级。用于实际工程时必须补齐这些环节并做敏感性检验。
