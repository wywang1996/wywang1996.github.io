GEM 全球活动断层库

GEM 全球活动断层库（GEM Global Active Faults Database, GAF-DB）是全球首个公开、 覆盖全球的活动断层数据库。它由全球地震模型基金会（GEM）编制， 汇编了约 19 个区域或专题断层数据集，包含约 13,500 条断层及其几何、 运动学和滑动速率等属性，主要服务于全球概率地震危险性建模。

Overview

概述

GEM 全球活动断层库（GAF-DB）是全球地震模型基金会（GEM） 编制的全球首个公开、覆盖全球的活动断层数据库。 它的核心目标是服务于全球概率地震危险性建模（PSHA）， 为断层源模型提供基础的几何和运动学参数。

GAF-DB 是约 19 个区域或专题断层数据集的汇编成果， 通过 Python 脚本算法化构建，可灵活纳入新数据集或更新。 数据库包含约 13,500 条断层， 其中约 77% 具有滑动速率信息。 数据覆盖全球大部分变形大陆区域，但不包括马来群岛、马达加斯加、加拿大等少数地区。

核心特点

  • 全球覆盖：首个覆盖全球的活动断层数据库，空间完整性高。
  • 统一字段：所有断层使用统一的属性表结构，便于跨区域分析。
  • 滑动速率：约 77% 的断层提供滑动速率，采用三元组形式表示不确定性。
  • 算法化构建：通过 Python 脚本从各区域数据集自动汇编，易于更新和扩展。
  • 开放许可：采用 CC BY-SA 4.0 开放许可，支持学术和商业使用。
与其他数据源的区别： 此前介绍的 PEER NGA、COSMOS、CSMNC 等提供的是地震动记录， CENC、USGS ComCat、ISC-GEM 提供的是地震目录， 而 GAF-DB 提供的是断层几何与运动学参数。 它是断层源模型的基础数据，与地震目录和地震动记录互补， 共同构成地震危险性分析的完整数据体系。
Format

数据格式

GAF-DB 以 GIS 矢量格式提供，支持多种软件平台。 其属性表使用三种数据类型：string（文本）、 integer（整数）和 tuple（三元组）。 点击下方标签查看各部分的详细说明。

几何与运动学字段

描述断层的空间形态和滑动特征
字段 类型 说明
diptuple断层倾角（度），格式 (最可能值, 最小值, 最大值)
dip_dirstring倾向（如 W、NE）
downthrown_side_idstring下降盘方向
average_raketuple平均滑动角（度），遵循 Aki & Richards 约定
slip_typestring运动学类型（如 Sinistral、Dextral、Normal、Reverse）
strike_slip_ratetuple走滑速率（mm/yr），负值表示左旋
dip_slip_ratetuple倾滑速率（mm/yr）
vert_slip_ratetuple垂直滑动速率（mm/yr），均为正值
shortening_ratetuple水平缩短速率（mm/yr）
upper_seis_depthtuple地震发生层上界深度（km）
lower_seis_depthtuple地震发生层下界深度（km）
滑动速率符号约定： 除 shortening_rate 外，所有滑动速率字段描述的是断层上的 滑动分量大小，均为正值。 strike_slip_rate 的负值表示左旋滑动。 vert_slip_rate 表示垂直分离速率（断层落差），均为正值， 需结合 dip_dir、downthrown_side_id 或运动学参数判断是挤压还是拉张。

质量与元数据字段

评估数据可靠性 · 溯源原始文献
字段 类型 说明
accuracyinteger地图比例尺分母（如 40000）
activity_confidenceinteger新构造活动性的置信度：1=高，2=低
exposure_qualityinteger断层出露质量（可见性）：1=好，2=差
epistemic_qualityinteger断层存在的认知置信度：1=高，2=低
last_movementstring最近一次显著地震的日期（如 1865）
namestring断层或断层段名称
fs_namestring断层系统名称
referencestring数据来源文献（如 Rogers and Mann, 2007）
notesstring相关备注信息
ogc_fidintegerGIS 使用的内部 ID
catalog_idstring全局唯一标识符（如 CCARA_8）
质量字段的区域性： activity_confidence、exposure_quality 和 epistemic_quality 的取值（1 或 2）是区域性的， 不能跨数据集直接比较。数值 1 表示在该区域数据集内部为高质量或高置信度。

数据类型说明

理解属性表中的三种数据类型

GAF-DB 的属性表使用三种数据类型，理解它们的含义对于正确使用数据至关重要。

类型 用途 说明
string 文本数据 用于断层名称、倾向、运动学类型、参考文献等文本字段
integer 索引与等级 用于 GIS 索引、地图比例尺分母，以及质量字段的等级（1=高，2=低）
tuple 连续随机变量 格式为 (最可能值, 最小值, 最大值)， 用于表示滑动速率、倾角等具有不确定性的连续变量。 也可仅为 (最可能值)，表示无不确定性信息。
tuple 格式示例： dip = (40, 30, 50) 表示倾角最可能为 40°，范围在 30° 到 50° 之间。 strike_slip_rate = (1.5, 0.5, 2.5) 表示走滑速率最可能为 1.5 mm/yr， 范围在 0.5 到 2.5 mm/yr 之间。三元组格式用于简化 GIS 制图时的数据录入， 并控制数据库的整体大小。

Data Files

数据文件说明

1. 文件格式对比

GAF-DB 提供四种 GIS 矢量格式，每种格式的适用场景和限制不同。

格式 适用软件 文件大小 注意事项
GeoJSON QGIS、Web 地图、API 约 15–17 MB 最推荐的格式，适合 Web 地图和程序化处理
GeoPackage ArcGIS、QGIS 约 9 MB 基于 SQLite 的现代格式，支持完整字段名
KML Google Earth — 适合三维可视化，不适合数据分析
Shapefile 传统 GIS 软件 约 6 MB 不推荐：会截断列名和长文本字段
格式选择建议：优先使用 GeoJSON 或 GeoPackage。Shapefile 会截断 Notes 等长文本字段， 且列名限制为 10 个字符，可能导致属性信息丢失。

2. 文件版本

文件 说明
gem_active_faults 原始版本，直接来自各区域数据集，属性字段可能不一致
gem_active_faults_harmonized 调和版本，经过属性统一和错误检查，推荐使用
调和版本的优势：调和版本对来自不同数据集的属性进行了统一处理， 包括字段名称映射、质量字段标准化等，更适合跨区域分析和 PSHA 建模。

3. 数据种类总览

断层属性
倾角 倾向 滑动角 运动学类型 走滑速率 倾滑速率 垂直滑动速率 缩短速率 地震发生层深度 最近一次地震
质量与元数据
活动性置信度 出露质量 认知置信度 地图比例尺 断层名称 参考文献 全局 ID

4. 数据质量检查要点

  1. 检查质量字段： 关注 activity_confidence、exposure_quality 和 epistemic_quality 的取值。数值 2 表示该断层在该区域数据集内 质量较低或置信度不足。
  2. 滑动速率的不确定性： strike_slip_rate 等字段的 tuple 格式提供了不确定性范围。 在 PSHA 中可将这些范围作为逻辑树的分支依据。
  3. 垂直滑动速率的符号： vert_slip_rate 均为正值，表示垂直分离速率。 需结合 dip_dir 或 downthrown_side_id 判断是正断层还是逆断层。
  4. 深度基准不统一： 不同数据集的 upper_seis_depth 和 lower_seis_depth 可能使用不同的基准（海平面 vs 地表）。定量分析时需查阅原始数据集。
  5. last_movement 标准不一致： 不同数据集维护者判断“最近一次地震”的标准可能不同 （仪器记录、历史记录或古地震记录），跨区域对比时需谨慎。
  6. 区域一致性差异： GAF-DB 是多个区域数据集的汇编，不同来源的数据在质量标准和定义上可能存在差异， 跨区域分析时需注意。
Notes

使用注意事项

  1. CC BY-SA 4.0 许可： GAF-DB 以 CC BY-SA 4.0 开放许可发布。使用时必须署名， 衍生作品须以相同方式共享。商业用途需另行申请许可。
  2. 区域一致性差异： GAF-DB 是约 19 个区域数据集的汇编，不同来源在质量标准和定义上可能存在差异。 跨区域分析时需注意这一特点。
  3. 覆盖范围有限： 数据覆盖全球大部分变形大陆区域，但不包括马来群岛、马达加斯加、加拿大 等少数地区。使用前应确认目标区域是否在覆盖范围内。
  4. 滑动速率的符号约定： strike_slip_rate 的负值表示左旋滑动； vert_slip_rate 均为正值，表示垂直分离速率。
  5. 深度基准不统一： upper_seis_depth 和 lower_seis_depth 的基准在不同数据集间可能不同（海平面 vs 地表）， 定量分析时需查阅原始来源。
  6. last_movement 标准不一致： 不同数据集维护者判断“最近一次地震”的标准可能不同， 跨区域对比时需谨慎。
  7. 版本管理： GAF-DB 持续更新。建议在论文中注明使用的版本号（如 2019.0） 或下载日期，确保结果可复现。
  8. 推荐使用调和版本： gem_active_faults_harmonized 经过属性统一处理， 更适合跨区域分析和 PSHA 建模。
