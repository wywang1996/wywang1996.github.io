需求谱 vs 能力谱

性能化设计（Performance-Based Design）的核心图件： 在 ADRS 格式（Sa–Sd）下， 把结构的能力谱（由 Pushover 曲线转换）与地震的 需求谱（由设计谱转换）放在同一张图上， 两者的交点即性能点，对应结构在给定地震作用下的 位移与加速度需求。这是 ATC-40、FEMA 440 的核心方法。

地震工程 ADRS 性能点 Python / MATLAB A4 尺寸
CSV Input

输入数据格式

本页需要两个 CSV 文件：一个描述结构能力（能力谱）， 一个描述地震需求（需求谱）。 页面默认读取 assets/capacity_spectrum.csv 与 assets/demand_spectrum.csv； 若文件不存在，则使用内置的合成数据演示。

文件 1：能力谱（由 Pushover 转换）

Pushover 曲线（V–d）通过模态转换得到能力谱（Sa–Sd）：

Sa = V / (α1 · W)   ,   Sd = d / (γ1 · φroof,1)
列名 物理量 单位 说明
Sd_m谱位移 Sdm能力谱横坐标
Sa_g谱加速度 Sag能力谱纵坐标

文件 2：需求谱（由设计谱转换）

设计谱 Sa(T) 通过以下关系转为 ADRS 格式：

Sd = Sa · g · T² / (4π²)
列名 物理量 单位 说明
period_s自振周期 Ts对数分布
Sa_g设计谱加速度g来自 GB 50011 或 PSHA

数据来源

  • 能力谱——由 Pushover 分析得到的 V–d 曲线， 按模态参与系数转换。可使用 ETABS、SAP2000 的 Pushover 结果， 或在 Python/MATLAB 里自行转换。
  • 需求谱——来自 GB 50011-2010 设计谱、 一致危险性谱（UHS）或场地专项地震安全性评价报告。
  • 性能点求解——ATC-40 等效线性化方法 （Capacity Spectrum Method），或 FEMA 440 改进方法。
本页示例是一个中等刚度框架的能力谱与 7 度（0.10 g）II 类场地设计谱的转换结果， 性能点约在 Sd ≈ 0.14 m、Sa ≈ 0.33 g 处。 替换为你自己的分析结果只需修改两个 CSV 文件。

计算步骤：从 Pushover 曲线到性能点

性能点的求解分四步：能力谱转换 → 需求谱转换 → 等效线性化 → 迭代求交点。

Pushover (V–d) → 模态转换 → 能力谱 (Sa–Sd) → 设计谱 Sa(T) → 转换为 ADRS → 假设性能点 di → 双线性化 → 等效阻尼比 βeff → 折减需求谱 → 求交点 di+1 → 若 |di+1 − di| < ε → 收敛，输出性能点

四步详解

  1. 能力谱转换——把 Pushover 曲线 (V, d) 转换为 ADRS 格式： Sa = V/(α1·W)，Sd = d/(γ1·φroof,1)。 其中 α1 是第一振型质量参与系数，γ1 是模态参与因子。
  2. 需求谱转换——把设计谱 Sa(T) 转换为 ADRS 格式： Sd = Sa·g·T²/(4π²)。每条 (T, Sa) 对应 ADRS 上的一点。
  3. 等效线性化——假设性能点位移 di， 在能力谱上做双线性化，计算等效粘滞阻尼比： βeff = β0 + κ·Ah/(2π·Sa·Sd)。 根据 βeff 折减需求谱： SR = (3.21 − 0.68·ln βeff) / 2.12（ATC-40 公式）。
  4. 迭代求交点——折减需求谱与能力谱的交点作为新的 di+1， 重复第 3 步，直到 |di+1 − di| < ε 收敛。
ATC-40 折减系数（Short-Period 与 Long-Period 两种）：
SRA = (3.21 − 0.68·ln βeff) / 2.12（短周期）
SRV = (2.31 − 0.41·ln βeff) / 1.65（长周期）
本页简化为短周期形式，作为演示。

Python 代码：性能点求解

demand_capacity.pyPython
# =============================================================
# 需求谱 vs 能力谱 | 性能点求解（ATC-40 等效线性化）
# -------------------------------------------------------------
# 输入：
#   capacity_spectrum.csv   Sd_m, Sa_g
#   demand_spectrum.csv     period_s, Sa_g
# -------------------------------------------------------------
# 输出：
#   demand-capacity.png     性能点求解图
# =============================================================

import os
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

G = 9.80665
CAP_FILE = 'capacity_spectrum.csv'
DEM_FILE = 'demand_spectrum.csv'


def generate_synthetic():
    """生成合成数据。"""
    # 能力谱：三段折线
    Sd_cap = np.array([0.000, 0.010, 0.020, 0.030, 0.040, 0.050,
                       0.060, 0.080, 0.100, 0.120, 0.140, 0.160,
                       0.180, 0.200, 0.220, 0.240])
    Sa_cap = np.array([0.000, 0.048, 0.092, 0.132, 0.168, 0.200,
                       0.226, 0.268, 0.300, 0.320, 0.330, 0.332,
                       0.330, 0.325, 0.318, 0.308])

    # 需求谱：设计谱
    period = np.array([0.05, 0.10, 0.20, 0.30, 0.40, 0.50,
                       0.70, 1.00, 1.50, 2.00, 3.00, 4.00, 5.00])
    Sa_g = np.array([0.320, 0.320, 0.320, 0.320, 0.320, 0.256,
                     0.183, 0.128, 0.085, 0.064, 0.043, 0.032, 0.026])
    return Sd_cap, Sa_cap, period, Sa_g


# ---- 1. 读取数据 ----
if os.path.exists(CAP_FILE) and os.path.exists(DEM_FILE):
    cap = np.loadtxt(CAP_FILE, delimiter=',', skiprows=1)
    Sd_cap = cap[:, 0]
    Sa_cap = cap[:, 1]
    dem = np.loadtxt(DEM_FILE, delimiter=',', skiprows=1)
    period = dem[:, 0]
    Sa_g = dem[:, 1]
    print(f'从 CSV 读取：能力谱 {len(Sd_cap)} 点，需求谱 {len(period)} 点')
else:
    print('CSV 不存在，使用合成数据演示')
    Sd_cap, Sa_cap, period, Sa_g = generate_synthetic()


# ---- 2. 需求谱转换为 ADRS ----
Sd_dem = Sa_g * G * period ** 2 / (4.0 * np.pi ** 2)


# ---- 3. ATC-40 等效线性化迭代 ----
def atc40_reduction(beta_eff):
    """ATC-40 短周期折减系数。"""
    sr = (3.21 - 0.68 * np.log(beta_eff)) / 2.12
    return max(sr, 0.3)   # 不低于 0.3


def find_performance_point(Sd_cap, Sa_cap, Sd_dem, Sa_dem,
                            d_init=0.05, tol=1e-4, max_iter=50):
    """迭代求性能点。"""
    d_i = d_init
    history = []

    for it in range(max_iter):
        # 在能力谱上插值 Sa(d_i)
        Sa_i = np.interp(d_i, Sd_cap, Sa_cap)

        # 用 0 → (d_i, Sa_i) 双线性化，计算等效阻尼比
        Ke = Sa_i / d_i               # 割线刚度
        # 滞回面积（简化：取双线性）
        Ah = 2 * d_i * Sa_i * 0.5     # 简化系数
        # 等效粘滞阻尼比
        beta_eff = 0.05 + Ah / (2 * np.pi * Sa_i * d_i)

        # ATC-40 折减
        SR = atc40_reduction(beta_eff)

        # 折减需求谱
        Sd_dem_red = Sd_dem * SR
        Sa_dem_red = Sa_dem * SR

        # 求折减需求谱与能力谱的交点
        # 用插值把能力谱外推到需求谱的 Sd 网格上
        Sa_cap_interp = np.interp(Sd_dem_red, Sd_cap, Sa_cap,
                                   left=Sa_cap[0], right=Sa_cap[-1])
        diff = Sa_dem_red - Sa_cap_interp

        # 找第一个符号变化
        idx = None
        for j in range(1, len(diff)):
            if diff[j - 1] * diff[j] < 0:
                idx = j
                break

        if idx is None:
            # 无交点，取最接近的点
            d_new = Sd_dem_red[np.argmin(np.abs(diff))]
        else:
            # 线性插值
            x1, x2 = Sd_dem_red[idx - 1], Sd_dem_red[idx]
            y1, y2 = diff[idx - 1], diff[idx]
            d_new = x1 - y1 * (x2 - x1) / (y2 - y1)

        history.append({
            'iter': it, 'd': d_i, 'Sa': Sa_i,
            'beta_eff': beta_eff, 'SR': SR, 'd_new': d_new
        })

        if abs(d_new - d_i) < tol:
            d_i = d_new
            break

        d_i = 0.5 * d_new + 0.5 * d_i   # 松弛迭代，防止振荡

    Sa_i = np.interp(d_i, Sd_cap, Sa_cap)
    return d_i, Sa_i, history


d_perf, Sa_perf, history = find_performance_point(
    Sd_cap, Sa_cap, Sd_dem, Sa_g)

print(f'\n性能点：Sd = {d_perf:.4f} m, Sa = {Sa_perf:.4f} g')
print(f'迭代次数：{len(history)}')
print(f'最终等效阻尼比：{history[-1]["beta_eff"]:.3f}')
print(f'折减系数：{history[-1]["SR"]:.3f}')


# ---- 4. 绘图（A4 尺寸 7.2 × 5.6 in） ----
fig, ax = plt.subplots(figsize=(7.2, 5.6))

# 弹性需求谱
ax.plot(Sd_dem, Sa_g, lw=1.8, color='#2563eb',
        marker='o', ms=4, mfc='#2563eb', mec='none',
        label='Elastic demand spectrum')

# 折减需求谱
SR_final = history[-1]['SR']
Sd_dem_red = Sd_dem * SR_final
Sa_dem_red = Sa_g * SR_final
ax.plot(Sd_dem_red, Sa_dem_red, lw=1.8, color='#9333ea',
        ls='--', marker='s', ms=4, mfc='#9333ea', mec='none',
        label=f'Reduced demand (SR = {SR_final:.2f})')

# 能力谱
ax.plot(Sd_cap, Sa_cap, lw=2.4, color='#b45309',
        marker='^', ms=4, mfc='#b45309', mec='none',
        label='Capacity spectrum', zorder=5)

# 性能点
ax.plot(d_perf, Sa_perf, '*', color='#dc2626', ms=18,
        mec='#222222', mew=0.8, zorder=10,
        label='Performance point')

# 性能点标注
ax.annotate(
    f'PP\nSd = {d_perf:.3f} m\nSa = {Sa_perf:.3f} g',
    xy=(d_perf, Sa_perf),
    xytext=(d_perf * 0.35, Sa_perf * 1.35),
    fontsize=9, color='#dc2626',
    arrowprops=dict(arrowstyle='->', color='#dc2626', lw=0.8))

# 坐标轴
ax.set_xlabel('Spectral displacement  $S_d$ (m)')
ax.set_ylabel('Spectral acceleration  $S_a$ (g)')
ax.set_title('Demand spectrum vs capacity spectrum  ·  ADRS format',
             fontsize=11)
ax.set_xlim(0, max(Sd_cap.max(), Sd_dem.max()) * 1.1)
ax.set_ylim(0, max(Sa_cap.max(), Sa_g.max()) * 1.15)
ax.grid(True, ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='upper right', fontsize=9, frameon=False)
ax.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('demand-capacity.png', dpi=300, bbox_inches='tight')
plt.show()
关键点：
  • 能力谱转换：从 Pushover 的 V–d 得到 ADRS 格式的 Sa–Sd，需要模态参与系数。
  • 需求谱转换：Sd = Sa·g·T²/(4π²)， 把周期域的设计谱转到位移–加速度平面。
  • 等效阻尼比： β_eff = 0.05 + Ah/(2π·Sa·Sd)， 滞回环越饱满，β_eff 越大，需求谱折减越多。
  • ATC-40 折减：SR = (3.21 − 0.68·ln β_eff)/2.12， β_eff 从 0.05 增大到 0.30 时 SR 从 1.0 降到约 0.6。
  • 迭代收敛：用松弛迭代 d_new = 0.5·d + 0.5·d_old 防止振荡，通常 5–10 次收敛。
  • 性能点：折减需求谱与能力谱的交点， 对应结构的位移需求 Sd 与加速度需求 Sa。
Meaning

这张图说明了什么

需求谱 vs 能力谱（也称能力谱法，Capacity Spectrum Method） 是 ATC-40 提出的性能化设计方法。它把结构的能力与 地震的需求放在同一张图上，通过两者的交点确定 结构在给定地震作用下的性能点。

ADRS 格式

ADRS（Acceleration-Displacement Response Spectrum）格式 把传统的 Sa–T 谱转换为 Sa–Sd 平面：

Sd = Sa · g · T² / (4π²)

这种格式的优点是：结构的能力曲线（Pushover）与地震需求曲线 可以直接叠加，交点即性能点。 同一条传统谱曲线在 ADRS 上不再是水平–下降的形状， 而是从低频短周期到高频长周期的对角曲线。

两类曲线

  • 能力谱——由结构的 Pushover 曲线转换。 反映结构自身的承载力与变形能力，与地震动无关。 形状与 Pushover 曲线相似：先线性上升，然后屈服段，最后下降。
  • 需求谱——由设计谱转换。 反映地震对结构的位移与加速度需求。 弹性需求谱按结构弹性响应计算，折减需求谱考虑弹塑性耗能后降低。

等效线性化的意义

结构进入弹塑性后，动力特性不再是常值， 无法直接用弹性反应谱求性能点。ATC-40 用等效线性化 方法解决这个问题：

  • 用割线刚度代替弹性刚度，反映刚度的退化；
  • 用等效粘滞阻尼比 βeff 反映滞回耗能， βeff = β0 + κ·Ah/(2π·Sa·Sd)；
  • 用 βeff 折减弹性需求谱，得到折减需求谱；
  • 折减需求谱与能力谱的交点即性能点。

性能点的意义

  • Sd——结构的位移需求， 与性能水平直接对应。0.5% 高度对应 IO， 1.5% 对应 LS，2.5% 对应 CP（以层间位移角表示）。
  • Sa——结构的加速度需求， 反映惯性力水平，可用于判断构件是否进入屈服。
  • 与抗震验算的关系——性能点的层间位移角 与规范限值比较，判断结构是否满足性能目标。
三种性能水平（ATC-40）：
  • IO（Immediate Occupancy，立即入住）——结构基本完好， 可继续使用；
  • LS（Life Safety，生命安全）——结构有损伤但 不倒塌，人员安全；
  • CP（Collapse Prevention，防止倒塌）——结构 严重损伤但不倒塌。
性能化设计的目标：结构在指定地震作用下的性能点不超过 目标性能水平对应的限值。
注意：ATC-40 方法在近场脉冲型地震动、 强度退化型结构、高阶振型主导结构中可能失效。 FEMA 440 对 ATC-40 的方法做了改进，用 M 因子代替 SR 折减， 更适合这些情况。高精度分析应直接用非线性时程分析验证。

        if idx is None:
            d_new = Sd_dem_red[np.argmin(np.abs(diff))]
        else:
            x1, x2 = Sd_dem_red[idx - 1], Sd_dem_red[idx]
            y1, y2 = diff[idx - 1], diff[idx]
            d_new = x1 - y1 * (x2 - x1) / (y2 - y1)

        history.append({
            'iter': it, 'd': d_i, 'Sa': Sa_i,
            'beta_eff': beta_eff, 'SR': SR, 'd_new': d_new
        })

        if abs(d_new - d_i) < tol:
            d_i = d_new
            break

        d_i = 0.5 * d_new + 0.5 * d_i

    Sa_i = np.interp(d_i, Sd_cap, Sa_cap)
    return d_i, Sa_i, history


d_perf, Sa_perf, history = find_performance_point(
    Sd_cap, Sa_cap, Sd_dem, Sa_g)

print(f'\n性能点：Sd = {d_perf:.4f} m, Sa = {Sa_perf:.4f} g')
print(f'迭代次数：{len(history)}')

% ===== 局部函数 =====
function SR = local_atc40_reduction(beta_eff)
    sr = (3.21 - 0.68 * log(beta_eff)) / 2.12;
    SR = max(sr, 0.3);
end

function [d_perf, Sa_perf, history] = local_find_pp(Sd_cap, Sa_cap, Sd_dem, Sa_dem)
    d_i = 0.05; tol = 1e-4; max_iter = 50;
    hist_iter = []; hist_d = []; hist_Sa = [];
    hist_beta = []; hist_SR = [];

    for it = 1:max_iter
        Sa_i = interp1(Sd_cap, Sa_cap, d_i, 'linear', 'extrap');
        Ke = Sa_i / d_i;
        Ah = 2 * d_i * Sa_i * 0.5;
        beta_eff = 0.05 + Ah / (2 * pi * Sa_i * d_i);
        SR = local_atc40_reduction(beta_eff);

        Sd_dem_red = Sd_dem * SR;
        Sa_dem_red = Sa_dem * SR;

        Sa_cap_interp = interp1(Sd_cap, Sa_cap, Sd_dem_red, ...
                                 'linear', Sa_cap(end));
        diff = Sa_dem_red - Sa_cap_interp;

        idx = [];
        for j = 2:numel(diff)
            if diff(j-1) * diff(j) < 0
                idx = j;
                break;
            end
        end

        if isempty(idx)
            [~, imin] = min(abs(diff));
            d_new = Sd_dem_red(imin);
        else
            x1 = Sd_dem_red(idx-1); x2 = Sd_dem_red(idx);
            y1 = diff(idx-1); y2 = diff(idx);
            d_new = x1 - y1 * (x2 - x1) / (y2 - y1);
        end

        hist_iter(end+1) = it;
        hist_d(end+1) = d_i;
        hist_Sa(end+1) = Sa_i;
        hist_beta(end+1) = beta_eff;
        hist_SR(end+1) = SR;

        if abs(d_new - d_i) < tol
            d_i = d_new;
            break;
        end

        d_i = 0.5 * d_new + 0.5 * d_i;
    end

    d_perf = d_i;
    Sa_perf = interp1(Sd_cap, Sa_cap, d_i, 'linear', 'extrap');
    history.iter = hist_iter;
    history.d = hist_d;
    history.Sa = hist_Sa;
    history.beta_eff = hist_beta;
    history.SR = hist_SR;
end

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 能力谱位移Sdm
输入 · 能力谱加速度Sag
输入 · 需求谱周期Ts
输入 · 需求谱加速度Sag
输出 · 性能点位移Sd,PPm
输出 · 性能点加速度Sa,PPg
输出 · 等效阻尼比βeff无量纲
输出 · 折减系数SR无量纲
  • 能力谱转换：Sa = V/(α1·W)， Sd = d/(γ1·φroof,1)。 本页假设 CSV 中已经是转换后的 ADRS 格式。
  • 需求谱转换：Sd = Sa·g·T²/(4π²)。 本页从周期–谱加速度自动转换。
  • 等效阻尼比：βeff = β0 + κ·Ah/(2π·Sa·Sd)。 β0 = 0.05，κ 是阻尼修正系数，通常在 0.33–1.0 之间。
  • ATC-40 折减：SR = (3.21 − 0.68·ln βeff)/2.12。 短周期形式。长周期用另一个公式。
  • 迭代松弛：dnew = 0.5·d + 0.5·dold， 防止在交点附近振荡。
  • 收敛判据：|dnew − dold| < 1e-4 m， 通常 5–10 次迭代收敛。
  • FEMA 440 改进：用 M 因子代替 SR， M = (Teff/T0)² 或 M = 1 + (1/βeff − 1)/a， 对近场脉冲型地震动更准。
  • 常见问题：
    • 迭代不收敛 → 检查能力谱与需求谱是否有交点， 或改用 FEMA 440 的 M 因子。
    • 性能点落在能力谱的下降段 → 结构已进入极限状态， 需重新设计。
    • 折减系数 SR < 0.3 → 阻尼比过大，可能超出 ATC-40 适用范围， 需用非线性时程验证。
    • 能力谱与需求谱数量级差别大 → 检查单位（Sd 用 m 还是 mm）。
