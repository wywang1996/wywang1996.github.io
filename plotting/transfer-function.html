场地传递函数

一维土层反应分析的核心图件：从基岩到地表的传递函数 |TF(f)|， 展示多层土对地震动的频率选择性放大。 峰值对应的卓越频率 f0 与放大因子 A0 是场地分类与地震动输入的关键参数。

工程地震 CSV 输入 多层土 Python / MATLAB A4 尺寸
CSV Input

CSV 输入数据

本页读取 assets/site_profile.csv 作为输入。 这是一个场地分层模型文件，每行代表一层土， 最后一行标记为 rock，表示基岩半空间。

H_m层厚 Hm基岩行可留空

rho_kg_m3密度 ρkg/m³通常 1700–2400
zeta阻尼比 ζ无量纲通常 0.01–0.10

数据来源

  • 钻孔波速测试——单孔或跨孔法，实测各层 Vs 与层厚 H
  • 室内共振柱 / 扭剪试验——给出各层的小应变 Vs 与阻尼比 ζ
  • 经验关系——Vs 与标准贯入击数 N 或 CPT 锥尖阻力 qc 的经验相关式
  • 场地分类数据库——如 USGS Global Vs30 Map、中国地震局场地资料
本页示例是一个 40 m 厚的三层土剖面， 等效 Vs ≈ 244 m/s，理论 f0 ≈ 1.5 Hz。 替换为你自己的钻孔数据只需修改 site_profile.csv 各行。
Model

物理模型

本页采用多层水平土覆盖基岩半空间模型， 用 Thomson-Haskell 传递矩阵法计算从基岩露头到地表的传递函数。 SH 波从基岩垂直向上传播，在土层界面多次反射与透射。

传递矩阵

每一层的层矩阵为：

Mj = [ cos θj   i·sin θj/Zj ;   i·Zj·sin θj   cos θj ]

其中 θj = ω·hj/Vsj·(1 − i·ζj) 为复波数， Zj = ρj·Vsj 为波阻抗。

总传递函数

总传递矩阵 M = Mn·Mn−1·…·M1（从基岩往地表乘）， 传递函数为：

|TF(f)| = 1 / | M11 + M21 / Zrock |

对于单层情况，这个公式退化为常见的：

|TF(f)| = 1 / √[ cos²(kH) + α²·sin²(kH) ]   ,    α = Zsoil / Zrock

两个关键量的理论关系

  • 卓越频率：f0 ≈ Vseq / (4Htotal)， 其中 Vseq = Htotal / Σ(hj/Vsj) 为传播时间加权平均。
  • 放大因子：A0 ≈ 1/α（无阻尼极限）； 阻尼使实际峰值降低。
本页使用线性粘弹性模型（阻尼比固定）。 强震下土层剪切模量下降、阻尼增加，传递函数的峰值位置会向低频移动、 峰值高度降低。严格分析需要一维等效线性化程序（SHAKE91、DEEPSOIL） 或真非线性分析。

Python

Python 代码

依赖 numpy 与 matplotlib。 核心函数 transfer_function 用 Thomson-Haskell 矩阵法计算多层场地的传递函数。

transfer-function.pyPython
# =============================================================
# 多层土场地的传递函数 |TF(f)|
# -------------------------------------------------------------
# 输入数据：site_profile.csv
#   layer,H_m,Vs_m_s,rho_kg_m3,zeta
#   1,10,150,1750,0.05
#   2,15,250,1850,0.045
#   3,15,400,1950,0.035
#   rock,,800,2400,0.01
# -------------------------------------------------------------
# 方法：Thomson-Haskell 传递矩阵法，SH 波垂直入射
# =============================================================

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 9,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})


def read_profile(csv_file):
    """读取场地分层 CSV，返回 (layers, rock)。

    layers: list of dict，从地表向下的各土层
    rock:   dict，半空间基岩参数
    """
    layers = []
    rock = None
    with open(csv_file, 'r', encoding='utf-8') as f:
        for line in f:
            line = line.strip()
            if not line or line.startswith('#'):
                continue
            if line.startswith('layer'):
                continue  # 表头
            parts = line.split(',')
            tag = parts[0].strip()
            if tag.lower() == 'rock':
                rock = {
                    'Vs':  float(parts[2]),
                    'rho': float(parts[3]),
                    'zeta': float(parts[4]) if parts[4] else 0.01,
                }
            else:
                layers.append({
                    'H':    float(parts[1]),
                    'Vs':   float(parts[2]),
                    'rho':  float(parts[3]),
                    'zeta': float(parts[4]),
                })
    return layers, rock


def layer_matrix(f, L, Vs_scale=1.0, zeta_scale=1.0):
    """单层传递矩阵 M_j（2×2 复数矩阵）。"""
    omega = 2 * np.pi * f
    Vs  = L['Vs'] * Vs_scale
    rho = L['rho']
    zeta = L['zeta'] * zeta_scale
    Z = rho * Vs

    # 复角度 theta = omega*h/Vs * (1 - i*zeta)
    a = omega * L['H'] / Vs
    theta = a * (1 - 1j * zeta)

    cosT = np.cos(theta)
    sinT = np.sin(theta)

    M = np.array([
        [cosT, 1j * sinT / Z],
        [1j * Z * sinT, cosT]
    ], dtype=complex)
    return M


def transfer_function(f, layers, rock, Vs_scale=1.0, zeta_scale=1.0):
    """计算多层场地传递函数 |TF(f)|。f 为标量频率。"""
    M = np.eye(2, dtype=complex)
    for L in layers:
        Mj = layer_matrix(f, L, Vs_scale, zeta_scale)
        M = Mj @ M   # 从左乘 —— 从基岩向上累积

    Z_rock = rock['rho'] * rock['Vs']
    denom = M[0, 0] + M[1, 0] / Z_rock
    return 1.0 / abs(denom)


# ---------- 1. 读取 CSV ----------
layers, rock = read_profile('site_profile.csv')
print(f'共 {len(layers)} 层土 + 基岩')
H_total = sum(L['H'] for L in layers)
Vs_eq = H_total / sum(L['H'] / L['Vs'] for L in layers)
print(f'总厚度 H_total = {H_total:.1f} m')
print(f'等效 Vs_eq = {Vs_eq:.1f} m/s')
print(f'理论 f0 ≈ {Vs_eq / (4 * H_total):.3f} Hz')

# ---------- 2. 频率数组 ----------
f = np.logspace(np.log10(0.2), np.log10(20.0), 500)

# ---------- 3. 三张子图 ----------
fig, axes = plt.subplots(3, 1, figsize=(7.2, 8.0))

# ===== (a) 完整分层模型 =====
ax = axes[0]
TF_full = np.array([transfer_function(fi, layers, rock) for fi in f])
ax.semilogx(f, TF_full, lw=1.8, color='#b45309',
            label=f'{len(layers)}-layer model')
# 找峰值
i0 = np.argmax(TF_full)
f0 = f[i0]; A0 = TF_full[i0]
ax.plot(f0, A0, 'o', color='#b45309', ms=6)
ax.axvline(f0, color='#b45309', lw=0.7, ls=':', alpha=0.7)
ax.annotate(f'f$_0$ = {f0:.2f} Hz\nA$_0$ = {A0:.2f}',
            xy=(f0, A0), xytext=(f0 * 1.5, A0 * 0.75),
            fontsize=9,
            arrowprops=dict(arrowstyle='-', color='#888888', lw=0.6))
ax.set_xlabel('Frequency f (Hz)')
ax.set_ylabel('|TF(f)|')
ax.set_title('(a) Multi-layer model  ·  from CSV', fontsize=10)
ax.set_xlim(0.2, 20.0)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='upper right', fontsize=8, frameon=False)

# ===== (b) 等效单层模型对比 =====
ax = axes[1]
# 等效单层：H_total、Vs_eq、厚度加权平均阻尼比
H_eq = H_total
Vs_eq_val = Vs_eq
zeta_eq = sum(L['H'] * L['zeta'] for L in layers) / H_total
rho_eq = sum(L['H'] * L['rho'] for L in layers) / H_total
layers_eq = [{'H': H_eq, 'Vs': Vs_eq_val, 'rho': rho_eq, 'zeta': zeta_eq}]
TF_eq = np.array([transfer_function(fi, layers_eq, rock) for fi in f])

ax.semilogx(f, TF_full, lw=1.5, color='#b45309', label='Multi-layer (CSV)')
ax.semilogx(f, TF_eq, lw=1.5, color='#2563eb', ls='--',
            label=f'Equivalent single layer\n(Vs_eq={Vs_eq_val:.0f} m/s, H={H_eq:.0f} m)')
ax.set_xlabel('Frequency f (Hz)')
ax.set_ylabel('|TF(f)|')
ax.set_title('(b) Full model vs equivalent single layer', fontsize=10)
ax.set_xlim(0.2, 20.0)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='upper right', fontsize=8, frameon=False)

# ===== (c) 阻尼敏感性 =====
ax = axes[2]
colors3 = ['#2563eb', '#b45309', '#15803d']
for scale, color in zip([0.5, 1.0, 2.0], colors3):

% ===== 局部函数：传递函数 =====
function TF = local_tf(f, layers, rock, Vs_scale, zeta_scale)
    omega = 2 * pi * f;
    M = eye(2);
    for k = 1:numel(layers)
        L = layers(k);
        Vs   = L.Vs_m_s * Vs_scale;
        rho  = L.rho_kg_m3;
        zeta = L.zeta * zeta_scale;
        H    = L.H_m;
        Z    = rho * Vs;
        a    = omega * H / Vs;
        theta = a * (1 - 1j * zeta);
        cosT = cos(theta);
        sinT = sin(theta);
        Mj = [cosT, 1j*sinT/Z; 1j*Z*sinT, cosT];
        M = Mj * M;
    end
    Z_rock = rock.rho * rock.Vs;
    denom = M(1, 1) + M(2, 1) / Z_rock;
    TF = 1 / abs(denom);
end
Notes

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 层厚hjm
输入 · 剪切波速Vsjm/s
输入 · 密度ρjkg/m³
输入 · 阻尼比ζj无量纲
输出 · 传递函数|TF(f)|无量纲
输出 · 卓越频率f0Hz
输出 · 放大因子A0无量纲
  • 方法：Thomson-Haskell 传递矩阵法，垂直入射 SH 波。
  • 复波数：θj = ω·hj/Vsj·(1 − i·ζj)，包含土层阻尼。
  • 波阻抗：Zj = ρj·Vsj。
  • 总矩阵：M = Mn·Mn−1·…·M1（从基岩向上累积）。
  • 传递函数：|TF(f)| = 1 / |M11 + M21/Zrock|。
  • 等效单层：Heq = Σhj， Vseq = Heq / Σ(hj/Vsj)（传播时间加权）。
  • 常见问题：
    • 峰值很低（< 1.5） → 阻抗比 α 接近 1，或 Vsrock 设置过低。
    • 峰值个数 > 3 → 多层模型下会出现更多次级峰，属于正常现象。
    • 与实际钻孔数据对比不符 → 检查 CSV 中 Vs 和 H 的单位是否正确。
    • 强震下峰值位置偏低 → 非线性场地效应，需用等效线性化或真非线性分析。
    • CSV 编码乱码 → 保存为 UTF-8，列名严格按示例。
