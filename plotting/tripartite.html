三联谱（Tripartite Spectrum）

把加速度谱、速度谱、位移谱画在同一张四对数坐标图上，纵轴为伪速度谱 PSv(T)， 叠加等加速度线、等速度线、等位移线三族参考线。这是地震工程中最经典的 谱图表达方式，直观显示结构响应在不同周期段由哪个物理量主导。

工程地震 三联谱 四对数坐标 Python / MATLAB A4 尺寸
Input Format

输入数据格式

本模板读取两列文本文件（空格、制表符或逗号分隔）， 与 El Centro、SAC ASCII 等地震记录格式一致。量纲必须明确， 否则计算出的谱值会差若干量级。

输入文件要求

列号物理量 推荐单位说明
第 1 列时间 ts（秒）等间隔。程序用相邻两点之差推算采样步长 dt。
第 2 列地面加速度 agg（重力加速度）也可为 m/s² 或 gal（cm/s²）。

常用量纲的换算

你的数据单位 换算到 m/s² 代码里怎么写
g× 9.80665ag = a * 9.80665
m/s²× 1ag = a
gal（cm/s²）× 0.01ag = a * 0.01
mm/s²× 0.001ag = a * 0.001
本页示例 assets/elcentro_EW.txt 的第 2 列单位是 g。 代码不做去均值、不去线性趋势，直接对原始记录计算反应谱。

Meaning

这张图说明了什么

三联谱（Tripartite Spectrum）把 Sa、Sv、Sd 三个物理量统一到一张图上： 纵轴为伪速度谱 PSv(T)，横轴为周期 T，双对数坐标。 通过三条基本关系式把三者在同一坐标上表达：

PSa(T) = ω · PSv(T)   ,   PSv(T) = ω · PSd(T)   ,   ω = 2π/T

即 PSa = ω²·PSd，PSv = ω·PSd，PSd = PSd。三者只差一个 ω 的幂次， 所以在双对数坐标上它们是同一条曲线的三种表示。

三族参考线

图上叠加了三族斜率和水平虚线：

  • 等加速度线（斜率 +1）——固定 PSa，随 T 增大 PSv 线性增加。对应结构处于加速度敏感区，短周期结构主要受惯性力控制。
  • 等速度线（水平）——固定 PSv。对应结构处于速度敏感区，中周期结构主要受能量输入控制。
  • 等位移线（斜率 −1）——固定 PSd，随 T 增大 PSv 线性减小。对应结构处于位移敏感区，长周期结构主要受位移需求控制。

把实际 PSv 曲线叠加到这三族参考线上，就能一目了然地看出：

  • 短周期段（T < 0.5 s），曲线与某条等加速度线几乎平行 → Sa 主导；
  • 中周期段（0.5 < T < 5 s），曲线接近水平 → Sv 主导；
  • 长周期段（T > 5 s），曲线与某条等位移线平行 → Sd 主导。
为什么用三联谱？ 单独看 Sa、Sv、Sd 三条谱线，很难快速判断每个周期段是哪个物理量占主导。 三联谱用四条参考线把频谱空间切成三个区域，一眼看出主导量， 是 Newmark-Hall 谱、规范设计谱、隔震设计等工作的共同语言。
注意：本页不做去均值处理。原始记录的直流偏置会放大长周期段谱值， 使 PSv 在长周期端出现异常抬升。工程应用中通常需要先做基线校正。

Python

Python 代码

依赖 numpy 与 matplotlib。核心步骤： 读取两列文本 → 单位换算 → Newmark-β 求 SDOF 峰值响应 → 由 Sd 换算 PSv → 绘制三联谱 + 三族参考线。 不做去均值、不去线性趋势。

tripartite.pyPython
# =============================================================
# 输入数据格式（两列文本，空格 / 制表符 / 逗号分隔）
#   第 1 列：时间 t   —— 单位 s（秒），等间隔
#   第 2 列：加速度 a —— 单位 g（重力加速度）
# -------------------------------------------------------------
# 如果你的加速度列不是 g，请在下方 DATA_UNIT 处选择：
#   'g'     → 第 2 列单位 g   （× 9.80665 → m/s²）
#   'm/s2'  → 第 2 列单位 m/s²（× 1）
#   'gal'   → 第 2 列单位 cm/s²（× 0.01）
#   'mm/s2' → 第 2 列单位 mm/s²（× 0.001）
# -------------------------------------------------------------
# 说明：本脚本不做去均值、不去线性趋势。
# =============================================================
DATA_UNIT = 'g'

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.ticker import LogLocator

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

g = 9.80665

# ---- 1. 读取两列文本 ----
t, a_raw = np.loadtxt('elcentro_EW.txt', unpack=True)
dt = t[1] - t[0]

# ---- 2. 单位换算到 m/s² ----
unit_factor = {'g': g, 'm/s2': 1.0, 'gal': 0.01, 'mm/s2': 0.001}
factor = unit_factor.get(DATA_UNIT, g)
ag = a_raw * factor


def sdof_response(ag, dt, T, zeta=0.05):
    """Newmark-β 平均加速度法计算 SDOF 峰值相对位移 Sd。"""
    if T <= 0:
        return 0.0

    omega = 2.0 * np.pi / T
    c = 2.0 * omega * zeta
    k = omega * omega
    gamma, beta = 0.5, 0.25

    keff = k + gamma / (beta * dt) * c + 1.0 / (beta * dt * dt)

    u, v = 0.0, 0.0
    acc = -ag[0]
    u_max = 0.0

    for j in range(1, len(ag)):
        p = (-ag[j]
             + (1.0 / (beta * dt * dt) * u
                + 1.0 / (beta * dt) * v
                + (1.0 / (2 * beta) - 1.0) * acc)
             + c * (gamma / (beta * dt) * u
                    + (gamma / beta - 1.0) * v
                    + dt * (gamma / (2 * beta) - 1.0) * acc))

        u_new = p / keff
        v_new = (gamma / (beta * dt) * (u_new - u)
                 - (gamma / beta - 1.0) * v
                 - dt * (gamma / (2 * beta) - 1.0) * acc)
        acc_new = (1.0 / (beta * dt * dt) * (u_new - u)
                   - 1.0 / (beta * dt) * v
                   - (1.0 / (2 * beta) - 1.0) * acc)

        u, v, acc = u_new, v_new, acc_new
        if abs(u) > u_max:
            u_max = abs(u)

    return u_max


# ---- 3. 反应谱计算 ----
periods = np.logspace(np.log10(0.02), np.log10(10.0), 100)
zeta = 0.05

Sd = np.zeros_like(periods)
for i, T in enumerate(periods):
    Sd[i] = sdof_response(ag, dt, T, zeta)

# ---- 4. 由 Sd 换算 PSv、PSa ----
omega = 2.0 * np.pi / periods
PSv = omega * Sd        # m/s
PSa = omega ** 2 * Sd   # m/s²

# ---- 5. 绘制三联谱（A4 尺寸 7.2 × 4.0 in） ----
fig, ax = plt.subplots(figsize=(7.2, 4.0))

# 三族参考线
pga_list = [0.01, 0.1, 1.0]         # g，等加速度线
psv_list = [0.01, 0.1, 1.0]         # m/s，等速度线
psd_list = [0.001, 0.01, 0.1]       # m，等位移线

# 等加速度线（斜率 +1）：PSv = PSa · T / (2π)
for pga in pga_list:
    PSa_val = pga * g
    PSv_line = PSa_val * periods / (2 * np.pi)
    ax.loglog(periods, PSv_line, lw=0.7, ls='--', color='#888888', alpha=0.7)
    # 标签放在曲线离开绘图区的位置
    idx = np.argmin(np.abs(PSv_line - 1.0))  # 靠近纵轴上限 1 m/s
    ax.text(periods[idx] * 1.08, PSv_line[idx],
            f'PSa={pga}g', fontsize=8, color='#555555', va='center')

# 等速度线（水平）
for psv in psv_list:
    ax.axhline(psv, lw=0.7, ls='--', color='#888888', alpha=0.7)
    ax.text(periods[-1] * 0.95, psv,
            f'PSv={psv}', fontsize=8, color='#555555',
            va='bottom', ha='right')

# 等位移线（斜率 −1）：PSv = 2π · PSd / T
for psd in psd_list:
    PSv_line = 2 * np.pi * psd / periods
    ax.loglog(periods, PSv_line, lw=0.7, ls='--', color='#888888', alpha=0.7)
    idx = np.argmin(np.abs(PSv_line - 1.0))
    ax.text(periods[idx] * 0.92, PSv_line[idx],
            f'PSd={psd}m', fontsize=8, color='#555555',
            va='center', ha='right')

# PSv 曲线 —— 主线
ax.loglog(periods, PSv, lw=1.8, color='#b45309', label='PSv(T) — 5% damping')

# 坐标轴
ax.set_xlabel('Period T (s)')
ax.set_ylabel('PSv (m/s)')
ax.set_xlim(0.02, 10)
ax.set_ylim(0.001, 10)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)
ax.tick_params(direction='in', which='both', top=True, right=True)

# 仅保留 1、2、5 × 10ⁿ 主刻度，避免标签拥挤
ax.yaxis.set_major_locator(LogLocator(base=10.0, subs=(1.0, 2.0, 5.0), numticks=12))
ax.xaxis.set_major_locator(LogLocator(base=10.0, subs=(1.0, 2.0, 5.0), numticks=12))

ax.legend(loc='upper right', fontsize=9, frameon=False)

fig.tight_layout()
fig.savefig('tripartite.png', dpi=300, bbox_inches='tight')
plt.show()
关键点：
  • 输入量纲：时间 s，加速度 g（默认）。
  • 三族参考线：
    • 等加速度：PSv = PSa · T / (2π)，斜率 +1
    • 等速度：PSv = 常数，水平
    • 等位移：PSv = 2π · PSd / T，斜率 −1
  • PSv 曲线本身由 Sd 换算：PSv = ω · Sd。
  • 纵轴范围固定为 0.001–10 m/s，覆盖常规地震动的谱值。
MATLAB

MATLAB 代码

脚本末尾定义局部函数 sdof_response（R2016b+）。 不去均值、不去趋势。

tripartite.mMATLAB
% =============================================================
% 输入数据格式（两列文本，空格 / 制表符 / 逗号分隔）
%   第 1 列：时间 t   —— 单位 s（秒），等间隔
%   第 2 列：加速度 a —— 单位 g（重力加速度）
% -------------------------------------------------------------
%   'g'     → × 9.80665
%   'm/s2'  → × 1
%   'gal'   → × 0.01
%   'mm/s2' → × 0.001
% -------------------------------------------------------------
% 说明：本脚本不做去均值、不去线性趋势。
% =============================================================
DATA_UNIT = 'g';

g = 9.80665;

% ---- 1. 读取两列文本 ----
data = readmatrix('elcentro_EW.txt');
t    = data(:, 1);
a_raw = data(:, 2);
dt   = t(2) - t(1);

% ---- 2. 单位换算到 m/s² ----
switch DATA_UNIT
    case 'g',     factor = g;
    case 'm/s2',  factor = 1.0;
    case 'gal',   factor = 0.01;
    case 'mm/s2', factor = 0.001;
    otherwise,    factor = g;
end
ag = a_raw * factor;

% ---- 3. 反应谱计算 ----
periods = logspace(log10(0.02), log10(10.0), 100);
n = numel(periods);
zeta = 0.05;

Sd = zeros(size(periods));
for i = 1:n
    Sd(i) = sdof_response(ag, dt, periods(i), zeta);
end

% ---- 4. 由 Sd 换算 PSv、PSa ----
omega = 2 * pi ./ periods;
PSv = omega .* Sd;         % m/s
PSa = omega.^2 .* Sd;      % m/s²

% ---- 5. 绘制三联谱（A4 尺寸 720 × 400 px） ----
figure('Color', 'w', 'Position', [100 100 720 400]);
hold on;

% 等加速度线（斜率 +1）
pga_list = [0.01 0.1 1.0];
for pga = pga_list
    PSa_val = pga * g;
    PSv_line = PSa_val * periods / (2 * pi);
    loglog(periods, PSv_line, '--', 'Color', [0.53 0.53 0.53], ...
           'LineWidth', 0.7);
    [~, idx] = min(abs(PSv_line - 1.0));
    text(periods(idx) * 1.08, PSv_line(idx), ...
         sprintf('PSa=%.2fg', pga), 'FontSize', 8, 'Color', [0.33 0.33 0.33]);
end

% 等速度线（水平）
psv_list = [0.01 0.1 1.0];
for psv = psv_list
    yline(psv, '--', 'Color', [0.53 0.53 0.53], 'LineWidth', 0.7);
    text(periods(end) * 0.95, psv, ...
         sprintf('PSv=%.2f', psv), 'FontSize', 8, 'Color', [0.33 0.33 0.33], ...
         'VerticalAlignment', 'bottom', 'HorizontalAlignment', 'right');
end

% 等位移线（斜率 −1）
psd_list = [0.001 0.01 0.1];
for psd = psd_list
    PSv_line = 2 * pi * psd ./ periods;
    loglog(periods, PSv_line, '--', 'Color', [0.53 0.53 0.53], ...
           'LineWidth', 0.7);
    [~, idx] = min(abs(PSv_line - 1.0));
    text(periods(idx) * 0.92, PSv_line(idx), ...
         sprintf('PSd=%.3fm', psd), 'FontSize', 8, 'Color', [0.33 0.33 0.33], ...
         'VerticalAlignment', 'middle', 'HorizontalAlignment', 'right');
end

% PSv 曲线 —— 主线
loglog(periods, PSv, 'Color', [0.71 0.33 0.04], 'LineWidth', 1.8);

% 坐标轴
xlabel('Period T (s)');
ylabel('PSv (m/s)');
xlim([0.02 10]);
ylim([0.001 10]);
grid on; box on;
set(gca, 'FontName', 'Times New Roman', 'FontSize', 10, 'TickDir', 'in', ...
    'XScale', 'log', 'YScale', 'log');

% 只保留 1、2、5 × 10^n 主刻度
ax = gca;
set(ax, 'YTick', get_log_ticks(ax.YLim));
set(ax, 'XTick', get_log_ticks(ax.XLim));

exportgraphics(gcf, 'tripartite.png', 'Resolution', 300);


% ===== 辅助函数 =====
function ticks = get_log_ticks(lim)
    lo = log10(lim(1));
    hi = log10(lim(2));
    ticks = [];
    for e = floor(lo):ceil(hi)
        for m = [1 2 5]
            v = m * 10^e;
            if v >= lim(1) && v <= lim(2)
                ticks(end+1) = v; %#ok
            end
        end
    end
end


% ===== 局部函数 =====
function Sd = sdof_response(ag, dt, T, zeta)
    if nargin < 4, zeta = 0.05; end
    if T <= 0
        Sd = 0; return;
    end

    omega = 2 * pi / T;
    c = 2 * omega * zeta;
    k = omega^2;
    gamma = 0.5; beta = 0.25;

    keff = k + gamma / (beta * dt) * c + 1 / (beta * dt^2);

    u = 0; v = 0;
    acc = -ag(1);
    u_max = 0;

    for j = 2:numel(ag)
        p = -ag(j) + ...
            (1/(beta*dt^2)*u + 1/(beta*dt)*v + (1/(2*beta)-1)*acc) + ...
            c * (gamma/(beta*dt)*u + (gamma/beta-1)*v + ...
                 dt*(gamma/(2*beta)-1)*acc);

        u_new = p / keff;
        v_new = gamma/(beta*dt)*(u_new - u) - (gamma/beta-1)*v - ...
                dt*(gamma/(2*beta)-1)*acc;
        acc_new = 1/(beta*dt^2)*(u_new - u) - 1/(beta*dt)*v - ...
                  (1/(2*beta)-1)*acc;

        u = u_new; v = v_new; acc = acc_new;
        u_max = max(u_max, abs(u));
    end

    Sd = u_max;
end
Notes

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 时间ts（秒）
输入 · 加速度agg / m/s² / gal / mm/s²
输出 · 纵轴（三联谱）PSvm/s
输出 · 等加速度线PSag（标签）
输出 · 等位移线PSdm（标签）
  • 积分方法：Newmark-β 平均加速度法，γ = 1/2，β = 1/4。
  • 周期范围：0.02–10 s，对数分布 100 个点。
  • 阻尼比：默认 ζ = 0.05。
  • PSv 换算：PSv = ω·Sd，PSa = ω²·Sd。
  • 纵轴范围：0.001–10 m/s，覆盖常规地震动的谱值范围。
  • 三族参考线：
    • 等加速度：PSv = PSa·T/(2π)，斜率 +1；
    • 等速度：PSv = 常数，水平；
    • 等位移：PSv = 2π·PSd/T，斜率 −1。
  • 无去趋势：长周期段谱值可能因原始记录的基线漂移而异常抬高。
  • 常见问题：
    • 谱值整体偏小或偏大 10⁴ 量级 → 输入加速度单位选错了。
    • 长周期段 PSv 曲线明显上翘 → 原始记录含长周期基线漂移。
    • 短周期段 PSv 曲线出现尖峰 → 记录中含高频噪声。
