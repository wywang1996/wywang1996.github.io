科学计算与 Python

从 NumPy 向量化到 SciPy 数值算法，覆盖数组运算、优化、积分、 信号处理与性能调优。Python 科学计算栈是工程计算与地震数据处理的 核心工具链，也是前面所有数学与算法笔记的实践载体。

NumPy SciPy 向量化 工程实践

§引言

Python 已成为科学计算的主流语言之一， 不是因为它的原生性能，而是因为它有一个完整的生态： NumPy 提供高效数组，SciPy 提供数值算法， Matplotlib 提供可视化，Pandas 提供数据处理， ObsPy 提供地震学专用工具。

工程计算中，Python 的定位：

场景Python 的角色典型工具
数据处理与探索 主力语言 NumPy、Pandas、ObsPy
数值算法开发 快速原型 NumPy、SciPy
可视化 主力语言 Matplotlib、Plotly
机器学习 主力语言 scikit-learn、PyTorch、TensorFlow
高性能计算 脚本 + 内核加速 Numba、Cython、CuPy
大型商业软件内核 不适用 FORTRAN / C++ / Julia

对地震工程师来说，Python 的三大价值：

  • 快速原型：把算法思想快速变成可运行的代码。
  • 数据接口：ObsPy 统一了 SAC、MiniSEED、SEED 等格式的读写。
  • 生态完整：从数据下载、处理、建模到可视化，全链路覆盖。

这份笔记按"生态 $\to$ NumPy $\to$ 向量化 $\to$ SciPy $\to$ 可视化 $\to$ Pandas $\to$ 性能 $\to$ 实践 $\to$ 应用" 的顺序梳理，每一节都尽量落到工程语境上。

科学计算栈的分层

理解生态的分层结构有助于技术选型：

  • 底层：BLAS / LAPACK（Fortran / C），提供线性代数内核。
  • 数组层：NumPy，封装 BLAS / LAPACK，提供 Python 接口。
  • 算法层：SciPy、scikit-learn，基于 NumPy 实现算法。
  • 应用层：ObsPy、专业工具包。
  • 加速层：Numba、Cython、CuPy。
  • 可视化层：Matplotlib、Plotly、Seaborn。

包管理建议

  • 环境隔离：一个项目一个环境，避免依赖冲突。
  • 版本锁定：用 pip freeze 或 conda env export 记录版本。
  • 依赖清单：requirements.txt 或 pyproject.toml。
  • 科学包优先用 conda：conda 提供的二进制包含优化过的 BLAS。
💡

为什么科学计算选 Python： ① 数组运算的性能由底层 C / Fortran 保证，Python 只做调度； ② 生态完整——数据处理、数值计算、可视化、机器学习一站式； ③ 胶水语言特性——可以调用 C / Fortran / CUDA 扩展； ④ 开源、跨平台、社区活跃。 这些让它成为工程计算与科研的默认选择。

02NumPy 基础

ndarray：核心数据结构

ndarray 是连续内存上的多维数组， 有三大属性：

  • shape：形状，如 (1000, 3)。
  • dtype：元素类型，如 float64、int32。
  • strides：每个维度上相邻元素的字节步长。
import numpy as np

# 创建数组
a = np.array([1, 2, 3])
b = np.zeros((3, 4))         # 全零
c = np.ones((2, 3))          # 全一
d = np.arange(0, 10, 0.5)    # 等差
e = np.linspace(0, 1, 100)   # 等间隔
f = np.random.default_rng(42).normal(size=(100,))  # 随机

# 属性
print(a.shape, a.dtype, a.strides)
# (3,) int64 (8,)  → 每个元素 8 字节

# 重塑
g = np.arange(12).reshape(3, 4)

索引与切片

NumPy 的切片返回视图而非拷贝， 这是高效的关键： 

a = np.arange(10)

# 基本切片（返回视图）
s = a[2:5]      # [2 3 4]

# 修改视图影响原数组
s[0] = 100      # a[2] 变为 100

# 花式索引（返回拷贝）
idx = [1, 3, 5]
b = a[idx]      # 新数组

# 布尔索引（返回拷贝）
c = a[a > 5]    # 大于 5 的元素

矩阵运算

NumPy 的矩阵乘法与逐元素乘法要区分： 

A = np.random.rand(3, 4)
B = np.random.rand(4, 5)

# 矩阵乘法
C = A @ B             # 或 np.dot(A, B)
# 逐元素乘法
D = A * A             # 形状相同才可行

# 转置
A_T = A.T

# 求逆
M = np.random.rand(4, 4)
M_inv = np.linalg.inv(M)

# 解线性方程组 M x = b
b = np.random.rand(4)
x = np.linalg.solve(M, b)   # 比 inv(M) @ b 更稳定

# 特征值
eigvals, eigvecs = np.linalg.eig(M)

# 对称矩阵专用（更快、更稳定）
S = M + M.T   # 对称化
eigvals_s, eigvecs_s = np.linalg.eigh(S)  # 升序返回

dtype 的选择

dtype 影响内存与速度：

dtype字节精度适用
float64 8 ~15~16 位有效数字 默认，科学计算
float32 4 ~7 位 深度学习、大批量数据
int32 4 ±2×10⁹ 索引、小整数
int64 8 ±9×10¹⁸ 大整数、时间戳
complex128 16 双精度复数 FFT、频域分析
bool 1 真/假 掩码、条件索引

随机数

新版 NumPy 推荐用 default_rng： 

rng = np.random.default_rng(seed=42)

# 均匀
u = rng.uniform(0, 1, size=1000)

# 正态
n = rng.normal(loc=0, scale=1, size=1000)

# 多项分布
m = rng.multinomial(n=10, pvals=[0.2, 0.3, 0.5], size=100)

# 打乱
arr = np.arange(10)
rng.shuffle(arr)

# 抽样
sample = rng.choice(arr, size=5, replace=False)

用固定 seed 保证结果可复现， 这对科学研究至关重要。

03向量化与广播

向量化：性能的关键

向量化是用数组运算代替 Python 循环。 性能差距通常在10~100 倍：

vectorization.py Python 
import numpy as np
import time

n = 10_000_000
a = np.random.rand(n)
b = np.random.rand(n)

# ---- 方式 1：Python 循环 ----
t0 = time.time()
c1 = [a[i] + b[i] for i in range(n)]
t1 = time.time() - t0

# ---- 方式 2：向量化 ----
t0 = time.time()
c2 = a + b
t2 = time.time() - t0

print(f"Python 循环: {t1:.3f} s")
print(f"NumPy 向量化: {t2:.4f} s")
print(f"加速比: {t1 / t2:.0f} 倍")

在 $10^7$ 规模上，向量化通常快 50~200 倍。

广播规则

广播让不同形状的数组可以运算，规则：

  1. 从尾部维度开始比较。
  2. 维度相等或其中一个为 1，则可以广播。
  3. 为 1 的维度会扩展到对方的维度。
# 例子 1：标量与数组
a = np.array([1, 2, 3])
b = 10
c = a + b         # [11 12 13]

# 例子 2：一维 + 二维
a = np.array([1, 2, 3])       # shape (3,)
b = np.array([[1], [2], [3]]) # shape (3, 1)
c = a + b                     # shape (3, 3)

# 例子 3：列向量 + 行向量
x = np.linspace(0, 1, 100).reshape(-1, 1)   # (100, 1)
y = np.linspace(0, 1, 80).reshape(1, -1)    # (1, 80)
z = x + y    # (100, 80)，可以生成 2D 网格

广播可以用少量代码表达复杂运算。 例如地震动衰减关系的批量计算： 

# 1000 个震级 × 500 个距离的 PGA 矩阵
M = np.linspace(4, 8, 1000).reshape(-1, 1)      # (1000, 1)
R = np.linspace(10, 300, 500).reshape(1, -1)    # (1, 500)

# 用广播直接算出 1000×500 的 PGA
ln_pga = 1.5 + 0.8 * M - 1.2 * np.log(R + 10) - 0.002 * R
pga = np.exp(ln_pga)   # 形状 (1000, 500)

ufunc 与聚合

通用函数（ufunc）是 NumPy 的核心： 

a = np.array([1, 4, 9, 16])

# 逐元素
np.sqrt(a)          # [1. 2. 3. 4.]
np.exp(a)
np.log(a)

# 聚合
np.sum(a)           # 30
np.mean(a)          # 7.5
np.std(a)
np.max(a), np.min(a)
np.argmax(a)        # 返回下标

# 沿轴聚合
b = np.random.rand(100, 50)
np.mean(b, axis=0)  # 沿第 0 轴平均 → shape (50,)
np.mean(b, axis=1)  # 沿第 1 轴平均 → shape (100,)

# 累积
np.cumsum(a)        # [1 5 14 30]

避免循环的常见技巧

任务Python 循环向量化
求和 逐元素累加 arr.sum()
条件筛选 for + if arr[arr > 0]
矩阵乘法 三重循环 A @ B
距离计算 双重循环 广播 + np.linalg.norm
累积和 循环累加 np.cumsum
卷积 滑动窗口 scipy.signal.convolve
条件赋值 if-else np.where
💡

向量化的思维： 写 NumPy 代码时，先问自己： "能不能一次处理整个数组，而不是逐元素？" 例如计算两条波形之间的所有时移相关性， 不要写两层循环，而是构造一个二维数组， 用广播或 FFT 一次性完成。 这种"以数组为中心"的思维方式， 是从"会 Python"到"会科学计算"的关键转变。

线性代数与稀疏矩阵

from scipy import linalg
from scipy.sparse import csr_matrix, diags
from scipy.sparse.linalg import spsolve, eigsh

# 稠密
A = np.random.rand(5, 5)
b = np.random.rand(5)

# Cholesky 分解（需要 A 对称正定）
S = A @ A.T
L = linalg.cholesky(S, lower=True)

# QR 分解
Q, R = linalg.qr(A)

# 稀疏矩阵：三对角
n = 1000
main = 2.0 * np.ones(n)
off = -1.0 * np.ones(n - 1)
K = diags([off, main, off], [-1, 0, 1], format="csr")

# 稀疏求解
F = np.ones(n)
u = spsolve(K, F)

# 稀疏特征值（前 6 阶）
eigvals, eigvecs = eigsh(K, k=6, which="SM")

优化

from scipy.optimize import minimize, least_squares, curve_fit

# ---- 无约束最小化 ----
def rosen(x):
    return sum(100 * (x[1:] - x[:-1]**2)**2 + (1 - x[:-1])**2)

x0 = np.array([0.0, 0.0, 0.0])
res = minimize(rosen, x0, method="BFGS")
print(res.x, res.fun, res.success)

# ---- 最小二乘拟合 ----
def model(x, a, b, c):
    return a * np.exp(-b * x) + c

x_data = np.linspace(0, 5, 100)
y_data = model(x_data, 2.5, 0.8, 0.5) + 0.1 * np.random.randn(100)

popt, pcov = curve_fit(model, x_data, y_data, p0=[2, 1, 0.5])
print("拟合参数:", popt)
print("参数协方差:", pcov)

数值积分与常微分方程

from scipy.integrate import quad, solve_ivp

# ---- 定积分 ----
result, error = quad(lambda x: np.exp(-x**2), 0, np.inf)
print(f"∫exp(-x²)dx = {result:.6f} (误差 {error:.2e})")
# 理论值 √π/2 ≈ 0.886227

# ---- ODE 求解：阻尼振子 ----
def damped_oscillator(t, y, m=1.0, c=0.5, k=100.0):
    x, v = y
    dxdt = v
    dvdt = (-c * v - k * x) / m
    return [dxdt, dvdt]

sol = solve_ivp(
    damped_oscillator,
    [0, 5], [1.0, 0.0],
    t_eval=np.linspace(0, 5, 500),
    method="RK45",
)
print(f"求解点数: {len(sol.t)}")
print(f"最大位移: {np.max(np.abs(sol.y[0])):.4f}")

地震波形绘制示例

wave_plot.py Python 
import numpy as np
import matplotlib.pyplot as plt

# 合成三分量地震波形
dt = 0.01
t = np.arange(0, 40, dt)
rng = np.random.default_rng(42)

def synth_wave(t, t_arrival, freq=2.0, width=2.0, amp=1.0):
    envelope = np.exp(-((t - t_arrival) ** 2) / (2 * width ** 2))
    return amp * envelope * np.sin(2 * np.pi * freq * t)

# P 波在 5 s，S 波在 9 s
z = 0.05 * synth_wave(t, 5.0, freq=5.0, width=0.3) \
    + 0.8 * synth_wave(t, 9.0, freq=2.0, width=1.5)
n = 0.5 * synth_wave(t, 9.2, freq=1.5, width=1.8)
e = 0.5 * synth_wave(t, 9.1, freq=1.8, width=1.6)

# 加噪声
z += 0.01 * rng.normal(size=len(t))
n += 0.01 * rng.normal(size=len(t))
e += 0.01 * rng.normal(size=len(t))

# 绘图
fig, axes = plt.subplots(3, 1, figsize=(10, 6), sharex=True)
labels = ["Z (垂直)", "N (南北)", "E (东西)"]
data = [z, n, e]

for ax, label, d in zip(axes, labels, data):
    ax.plot(t, d, linewidth=0.7, color="black")
    ax.axvline(5.0, color="#16a34a", linestyle="--", alpha=0.7, label="P")
    ax.axvline(9.0, color="#dc2626", linestyle="--", alpha=0.7, label="S")
    ax.set_ylabel(label)
    ax.grid(True, alpha=0.3)

axes[0].legend(loc="upper right", ncol=2)
axes[-1].set_xlabel("t / s")
axes[0].set_title("三分量地震波形（合成）")

plt.tight_layout()
plt.show()

import pandas as pd
import numpy as np

import numpy as np
import time
from numba import njit, prange

# 纯 Python 版本
def sum_squares_py(arr):
    s = 0.0
    for x in arr:
        s += x * x
    return s

# Numba 加速版本
@njit
def sum_squares_numba(arr):
    s = 0.0
    for i in range(len(arr)):
        s += arr[i] * arr[i]
    return s

# Numba 并行版本
@njit(parallel=True)
def sum_squares_parallel(arr):
    n = len(arr)
    partial = np.zeros(n, dtype=np.float64)
    for i in prange(n):
        partial[i] = arr[i] * arr[i]
    return partial.sum()

if __name__ == "__main__":

import numpy as np

def compute_heavy(n):

if __name__ == "__main__":

⚠️

过早优化是万恶之源： ① 先让代码正确，再让它快； ② 用 profiler 找出真正的瓶颈，而不是猜测； ③ 优先优化热点（通常 20% 的代码占 80% 的时间）； ④ 优化后要重新测试正确性； ⑤ 记录优化的版本，保留对照。 工程实践中最常见的问题不是"不够快"， 而是"没先测好就在优化"，结果花大量时间优化了非关键路径。

def compute_pga(
    acceleration: np.ndarray,
    dt: float,
    detrend: bool = True,
) -> float:
    """
    计算加速度时程的峰值加速度（PGA）。

    Parameters
    ----------
    acceleration : np.ndarray
        加速度时程，单位 m/s²。
    dt : float
        采样间隔，单位 s。
    detrend : bool, optional
        是否去除线性趋势，默认为 True。

    Returns
    -------
    pga : float
        峰值加速度，单位 m/s²。

    Examples
    --------
    >>> acc = np.random.randn(1000)
    >>> pga = compute_pga(acc, dt=0.01)
    """
    if detrend:
        from scipy.signal import detrend as sp_detrend
        acceleration = sp_detrend(acceleration)
    return float(np.max(np.abs(acceleration)))

import numpy as np
from scipy import signal


def integrate_trapezoid(acc, dt):
    """梯形法积分"""
    vel = np.cumsum(acc) * dt
    disp = np.cumsum(vel) * dt
    return vel, disp


def arias_intensity(acc, dt, g=9.81):
    """
    Arias 强度：
        I_A = (π / 2g) ∫ a² dt
    单位：m/s
    """
    return np.pi / (2 * g) * np.sum(acc ** 2) * dt


def significant_duration(acc, dt, g=9.81, low=0.05, high=0.95):
    """
    有效持时：Arias 强度从 5% 累积到 95% 的时间。
    """
    cum = np.cumsum(acc ** 2)
    total = cum[-1]
    t5 = np.searchsorted(cum, low * total) * dt
    t95 = np.searchsorted(cum, high * total) * dt
    return t95 - t5


def compute_intensity_measures(acc, dt):
    """
    计算常见地震动参数。
    """
    pga = np.max(np.abs(acc))
    vel, disp = integrate_trapezoid(acc, dt)
    pgv = np.max(np.abs(vel))
    pgd = np.max(np.abs(disp))
    ia = arias_intensity(acc, dt)
    t_d = significant_duration(acc, dt)

    return {
        "PGA": pga,
        "PGV": pgv,
        "PGD": pgd,
        "Arias": ia,
        "T5-95": t_d,
        "PGV_PGA": pgv / pga if pga > 0 else 0.0,
    }

反应谱计算

response_spectrum_fast.py Python 
import numpy as np
from numba import njit


@njit
def _newmark_sdof(acc, dt, omega, zeta):
    """
    Newmark-β 法求解单自由度体系响应（Numba 编译）。
    返回最大相对位移、最大绝对加速度。
    """
    n = len(acc)
    beta = 0.25
    gamma = 0.5
    m = 1.0
    k = m * omega ** 2
    c = 2 * m * omega * zeta

    u = 0.0
    v = 0.0
    a = -acc[0] - 2 * zeta * omega * v - omega ** 2 * u

    K_eff = k + gamma / (beta * dt) * c + 1.0 / (beta * dt ** 2) * m

    u_max = 0.0
    a_max = 0.0

    for i in range(n - 1):
        P_eff = (
            -m * acc[i + 1]
            + m * (1.0 / (beta * dt ** 2) * u
                   + 1.0 / (beta * dt) * v
                   + (1.0 / (2 * beta) - 1.0) * a)
            + c * (gamma / (beta * dt) * u
                   + (gamma / beta - 1.0) * v
                   + dt * (gamma / (2 * beta) - 1.0) * a)
        )
        u_new = P_eff / K_eff
        v = (gamma / (beta * dt) * (u_new - u)
             - (gamma / beta - 1.0) * v
             - dt * (gamma / (2 * beta) - 1.0) * a)
        a = (1.0 / (beta * dt ** 2) * (u_new - u)
             - 1.0 / (beta * dt) * v
             - (1.0 / (2 * beta) - 1.0) * a)
        u = u_new

        if abs(u) > u_max:
            u_max = abs(u)
        a_abs = abs(a + acc[i + 1])
        if a_abs > a_max:
            a_max = a_abs

    return u_max, a_max


def response_spectrum(acc, dt, periods, zeta=0.05):
    """
    计算加速度反应谱 Sa。
    用 Numba 加速的单自由度求解器。
    """
    Sa = np.zeros(len(periods))
    for i in range(len(periods)):
        T = periods[i]
        if T <= 0.01:
            Sa[i] = np.max(np.abs(acc))
            continue
        omega = 2 * np.pi / T
        _, a_max = _newmark_sdof(acc, dt, omega, zeta)
        Sa[i] = a_max
    return Sa

    fig, axes = plt.subplots(1, 2, figsize=(13, 5))

    im = axes[0].pcolormesh(R_arr.ravel(), M_arr.ravel(), PGA,
                             shading="auto", cmap="YlOrRd")
    axes[0].set_xscale("log")
    axes[0].set_xlabel("距离 R / km")
    axes[0].set_ylabel("震级 M")
    axes[0].set_title("PGA 分布 (m/s²)")
    plt.colorbar(im, ax=axes[0])

    # 不同震级的衰减曲线
    for M in [5.0, 6.0, 7.0, 8.0]:
        pga_curve = gmpe(M, R_arr.ravel())
        axes[1].loglog(R_arr.ravel(), pga_curve, label=f"M = {M}")
    axes[1].set_xlabel("距离 R / km")
    axes[1].set_ylabel("PGA / (m/s²)")
    axes[1].set_title("不同震级的衰减关系")
    axes[1].legend()
    axes[1].grid(True, which="both", alpha=0.3)

    plt.tight_layout()
    plt.show()

    print(f"PGA 矩阵形状: {PGA.shape}")
    print(f"PGA 范围: {PGA.min():.4f} ~ {PGA.max():.4f} m/s²")
