频率响应函数

单自由度体系的幅频与相频曲线，展示共振峰与阻尼比的关系。 这是《结构动力学》《振动力学》与《数字信号处理》中共用的 核心表达，也是反应谱计算的频域基础。

Parameters

输入参数

频率响应函数是解析式，只需要三个物理量： 质量 m、刚度 k、阻尼比 ζ。不需要外部数据文件。 本页的在线预览与代码示例都基于同一组默认值， 可修改为实际结构的参数。

Meaning

图形说明

频率响应函数（Frequency Response Function, FRF）描述线性系统对 简谐激励的稳态响应。对单自由度体系， 位移传递函数为：

H(ω) = 1 / [ (1 − β²) + i · 2ζβ ]

其中 β = ω / ωn 为频率比。幅频与相频分别为：

|H(ω)| = 1 / √[ (1 − β²)² + (2ζβ)² ]
φ(ω) = −arctan[ 2ζβ / (1 − β²) ]

(a) 幅频曲线 |H(ω)|

纵轴为放大因子，横轴为频率比 β（对数）。三条曲线对应 ζ = 0.02 / 0.05 / 0.10。三个关键区域：

  • 准静态区（β ≪ 1）：|H| ≈ 1，位移响应约等于静力位移；
  • 共振区（β ≈ 1）：|H| ≈ 1/(2ζ)，峰值随阻尼比急剧变化；
  • 惯性区（β ≫ 1）：|H| ≈ 1/β²，位移趋近于零。

(b) 相频曲线 φ(ω)

相位从 0° 逐渐过渡到 −180°。三个关键值：

  • β → 0：φ → 0°（位移与激励同相）；
  • β = 1：φ = −90°（无论阻尼多大）；
  • β → ∞：φ → −180°（位移与激励反相）。
共振峰值与阻尼比的关系： 精确共振频率是 ωr = ωn·√(1 − 2ζ²)， 峰值放大因子为 |H|max = 1 / (2ζ·√(1 − ζ²))。 ζ = 0.05 时，|H|max ≈ 10.0； ζ = 0.02 时，|H|max ≈ 25.0。
注意：本页只展示线性弹性情况下的 FRF。 强震下结构出现非线性（刚度退化、滞回耗能）， FRF 不再是单一曲线，需要用时变系统或等效线性化方法处理。

Python

Python 代码

依赖 numpy 与 matplotlib。 代码直接从解析式绘制幅频与相频曲线，无需外部数据文件。

frf.pyPython
# =============================================================
# 单自由度体系的频率响应函数
# -------------------------------------------------------------
# 位移传递函数：
#   H(ω) = 1 / [ (1 - β²) + i·2ζβ ]     ,  β = ω / ω_n
#
# 幅频：|H(ω)| = 1 / sqrt[ (1 - β²)² + (2ζβ)² ]
# 相频：φ(ω)  = -arctan[ 2ζβ / (1 - β²) ]
#
# 无需外部数据，参数直接写在代码里
# =============================================================

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.ticker import LogLocator

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 10,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

# ---------- 1. 结构参数 ----------
m = 1.0e5          # kg
k = 3.95e7         # N/m

omega_n = np.sqrt(k / m)         # rad/s
f_n     = omega_n / (2 * np.pi)  # Hz

print(f'固有频率 f_n = {f_n:.4f} Hz')
print(f'固有圆频率 ω_n = {omega_n:.4f} rad/s')

# ---------- 2. 频率比 β ----------
beta = np.logspace(np.log10(0.1), np.log10(10.0), 500)

# ---------- 3. 三个阻尼比 ----------
zetas = [0.02, 0.05, 0.10]
colors = ['#2563eb', '#b45309', '#15803d']

# ---------- 4. 绘制幅频与相频 ----------
fig, axes = plt.subplots(2, 1, figsize=(7.2, 7.6))

# ===== 上图：幅频 =====
ax = axes[0]
for zeta, color in zip(zetas, colors):
    H_amp = 1.0 / np.sqrt((1 - beta ** 2) ** 2 + (2 * zeta * beta) ** 2)
    ax.loglog(beta, H_amp, lw=1.6, color=color, label=f'ζ = {zeta:.2f}')

ax.axvline(1.0, color='#888888', lw=0.7, ls='--')
ax.set_xlabel('Frequency ratio  β = f / f$_n$')
ax.set_ylabel('|H(β)|')
ax.set_title('(a) Amplitude response', fontsize=11)
ax.set_xlim(0.1, 10.0)
ax.set_ylim(0.005, 60)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='lower left', fontsize=9, frameon=False)
ax.tick_params(direction='in', which='both', top=True, right=True)

# 标注准静态区、共振区、惯性区
ax.text(0.15, 1.6, 'quasi-static', fontsize=8, color='#888888', style='italic')
ax.text(1.0, 40, 'resonance', fontsize=8, color='#888888',
        style='italic', ha='center')
ax.text(6.0, 0.03, 'inertial', fontsize=8, color='#888888', style='italic')

# ===== 下图：相频 =====
ax = axes[1]
for zeta, color in zip(zetas, colors):
    phi = -np.arctan2(2 * zeta * beta, 1 - beta ** 2) * 180.0 / np.pi
    ax.semilogx(beta, phi, lw=1.6, color=color, label=f'ζ = {zeta:.2f}')

ax.axvline(1.0, color='#888888', lw=0.7, ls='--')
ax.axhline(-90.0, color='#888888', lw=0.5, ls=':')
ax.set_xlabel('Frequency ratio  β = f / f$_n$')
ax.set_ylabel('Phase  φ (deg)')
ax.set_title('(b) Phase response', fontsize=11)
ax.set_xlim(0.1, 10.0)
ax.set_ylim(-185, 5)
ax.set_yticks([0, -45, -90, -135, -180])
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='lower left', fontsize=9, frameon=False)
ax.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('frf.png', dpi=300, bbox_inches='tight')
plt.show()

# ---------- 5. 打印峰值 ----------
print('\n各阻尼比对应的共振峰：')
for zeta in zetas:
    beta_r = np.sqrt(1 - 2 * zeta ** 2) if zeta < 1 / np.sqrt(2) else 0
    if beta_r > 0:
        H_max = 1.0 / (2 * zeta * np.sqrt(1 - zeta ** 2))
        f_r = beta_r * f_n
        print(f'  ζ = {zeta:.2f}：β_r = {beta_r:.4f}，'
              f'f_r = {f_r:.4f} Hz，|H|_max = {H_max:.2f}')
    else:
        print(f'  ζ = {zeta:.2f}：无共振峰（过阻尼）')
关键点：
  • 无需外部数据：FRF 是解析式，参数直接写在代码里。
  • 幅频双对数坐标：β 用对数（跨 2 个量级），|H| 用对数（跨 3–4 个量级）。
  • 相频半对数坐标：β 用对数，φ 用线性。
  • 相位计算用 arctan2：正确处理 β > 1 时 φ < −90° 的情况， 直接 arctan(2ζβ/(1−β²)) 会丢失象限信息。
  • 共振峰位置：ωr = ωn·√(1 − 2ζ²)， ζ < 1/√2 ≈ 0.707 时存在。
MATLAB

MATLAB 代码

与 Python 完全对应。相位用 atan2 计算， 保证相位从 0 平滑过渡到 −180°。

frf.mMATLAB
% =============================================================
% 单自由度体系的频率响应函数
% -------------------------------------------------------------
% 位移传递函数：
%   H(ω) = 1 / [ (1 - β²) + i·2ζβ ]     ,  β = ω / ω_n
% =============================================================

% ---------- 1. 结构参数 ----------
m = 1.0e5;         % kg
k = 3.95e7;        % N/m

omega_n = sqrt(k / m);         % rad/s
f_n     = omega_n / (2*pi);    % Hz

fprintf('固有频率 f_n = %.4f Hz\n', f_n);
fprintf('固有圆频率 ω_n = %.4f rad/s\n', omega_n);

% ---------- 2. 频率比 β ----------
beta = logspace(log10(0.1), log10(10.0), 500);

% ---------- 3. 三个阻尼比 ----------
zetas  = [0.02 0.05 0.10];
colors = [0.15 0.39 0.92;   % 蓝
          0.71 0.33 0.04;   % 橙
          0.08 0.50 0.24];  % 绿

% ---------- 4. 绘制幅频与相频 ----------
figure('Color', 'w', 'Position', [100 100 720 760]);

% ===== 上图：幅频 =====
subplot(2, 1, 1); hold on;
for i = 1:numel(zetas)
    zeta = zetas(i);
    H_amp = 1 ./ sqrt((1 - beta.^2).^2 + (2*zeta*beta).^2);
    loglog(beta, H_amp, 'Color', colors(i, :), 'LineWidth', 1.6, ...
           'DisplayName', sprintf('ζ = %.2f', zeta));
end
xline(1.0, '--', 'Color', [0.53 0.53 0.53], 'LineWidth', 0.7, ...
      'HandleVisibility', 'off');
xlabel('Frequency ratio β = f / f_n');
ylabel('|H(β)|');
title('(a) Amplitude response', 'FontSize', 11);
xlim([0.1 10.0]); ylim([0.005 60]);
grid on; box on;
legend('Location', 'southwest', 'Box', 'off', 'FontSize', 9);

% ===== 下图：相频 =====
subplot(2, 1, 2); hold on;
for i = 1:numel(zetas)
    zeta = zetas(i);
    phi = -atan2(2*zeta*beta, 1 - beta.^2) * 180/pi;
    semilogx(beta, phi, 'Color', colors(i, :), 'LineWidth', 1.6, ...
             'DisplayName', sprintf('ζ = %.2f', zeta));
end
xline(1.0, '--', 'Color', [0.53 0.53 0.53], 'LineWidth', 0.7, ...
      'HandleVisibility', 'off');
yline(-90, ':', 'Color', [0.53 0.53 0.53], 'LineWidth', 0.5, ...
      'HandleVisibility', 'off');
xlabel('Frequency ratio β = f / f_n');
ylabel('Phase φ (deg)');
title('(b) Phase response', 'FontSize', 11);
xlim([0.1 10.0]); ylim([-185 5]);
yticks([0 -45 -90 -135 -180]);
grid on; box on;
legend('Location', 'southwest', 'Box', 'off', 'FontSize', 9);

% 统一格式
for k = 1:2
    subplot(2, 1, k);
    set(gca, 'FontName', 'Times New Roman', 'FontSize', 10, 'TickDir', 'in');
end

exportgraphics(gcf, 'frf.png', 'Resolution', 300);

% ---------- 5. 打印峰值 ----------
fprintf('\n各阻尼比对应的共振峰：\n');
for i = 1:numel(zetas)
    zeta = zetas(i);
    if zeta < 1/sqrt(2)
        beta_r = sqrt(1 - 2*zeta^2);
        H_max = 1 / (2*zeta*sqrt(1 - zeta^2));
        f_r = beta_r * f_n;
        fprintf('  ζ = %.2f：β_r = %.4f，f_r = %.4f Hz，|H|_max = %.2f\n', ...
                zeta, beta_r, f_r, H_max);
    else
        fprintf('  ζ = %.2f：无共振峰（过阻尼）\n', zeta);
    end
end
Notes

方法与说明

输入 / 输出量纲一览

量符号单位
输入 · 质量mkg
输入 · 刚度kN/m
输入 · 阻尼比ζ无量纲
中间 · 固有圆频率ωnrad/s
中间 · 固有频率fnHz
输出 · 幅频\|H(β)\|无量纲（放大因子）
输出 · 相频φ(β)deg
  • 位移传递函数：H(ω) = 1 / [(1−β²) + i·2ζβ]，β = ω/ωn。
  • 幅频公式：\|H\| = 1 / √[(1−β²)² + (2ζβ)²]。
  • 相频公式：φ = −arctan2(2ζβ, 1−β²)。用 atan2 而非 arctan，避免丢失象限。
  • 精确共振频率：ωr = ωn·√(1 − 2ζ²)，仅当 ζ < 1/√2 ≈ 0.707 时存在。
  • 共振峰值：\|H\|max = 1 / [2ζ·√(1−ζ²)]。
  • 与反应谱的关系：反应谱是 FRF 与地震动 Fourier 谱乘积的最大值随周期变化， 即 Sa(T) ≈ max\|H(f)·Ag(f)\|。
  • 无去均值、无去趋势：本页是解析计算，不涉及原始时程处理。
  • 常见问题：
    • β > 1 时相位不对 → 检查是否用了 arctan 而不是 atan2。
    • 幅频曲线在 β = 1 处没有峰 → 阻尼比过大（ζ > 0.707），或坐标范围不对。
    • 纵轴范围太挤 → 阻尼比小时峰值可达几十，需要给足上限。
    • 与实测频响对比偏差大 → 实际结构常为多自由度，单自由度模型只适用于基频段。
