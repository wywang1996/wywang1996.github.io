地震动参数分析

从处理后的地震动时程中系统提取工程常用参数：幅值、持时、能量、 反应谱与傅里叶谱，支持多记录批量对比、参数统计与经验关系拟合， 为地震动特性研究、选波与规范校核提供定量依据。

开发中 Python 3.10+ NumPy · SciPy 兼容 ObsPy 2026
Overview

概述

地震动参数是连接地震学与结构抗震设计的桥梁。一条加速度时程包含了丰富的 幅值、频率与持时信息，只有把其中关键特征量提取出来，才能定量地描述 “这条地震动有多强、哪个频段能量最集中、持续时间有多长”， 也才能与规范设计谱、场地分类和结构响应做对比。

本项目提供一套完整的地震动参数计算与分析工具：从单条记录的参数提取， 到多记录批量统计、参数间经验关系拟合与可视化，覆盖研究分析与工程设计两种 使用场景。所有参数均可溯源至对应的时程与计算公式。

参数与处理链绑定：同一记录经过不同的滤波与基线校正，得到的 PGA、持时与谱值 可能相差很大。本项目默认对处理后的时程计算参数，并保留处理日志， 使参数结果与预处理设置一一对应，避免“参数漂移”问题。
Features

主要功能

01

幅值参数

提取加速度、速度与位移时程的峰值与均方根等幅值参数， 是描述地震动强度最直接、最常用的指标。

  • PGA、PGV、PGD 及出现时刻
  • 加速度、速度、位移 RMS 与有效幅值
  • 峰值比 PGV/PGA，反映频谱与持时特征
  • 三分量分别计算与合成值（SRSS / 最大方向）
  • 支持按方向、按分量、按事件分组统计
02

持时参数

计算地震动的持续时间，反映能量释放的延续程度， 对结构的累积损伤与滞回耗能有直接影响。

  • 括号持时（Bracketed Duration）
  • 显著持时（Significant Duration，5%–75%、5%–95%）
  • 有效持时（基于 Arias 强度的 5%–95%）
  • 能量持时与相对持时
  • 多阈值持时曲线对比
03

反应谱

计算单自由度体系在给定阻尼比下的加速度、速度与位移反应谱， 是结构抗震设计与选波的核心依据。

  • 线弹性反应谱（Newmark-β / Nigam-Jennings 方法）
  • 阻尼比 0.5%–20% 可配置，默认 5%
  • 同时输出 Sa、Sv、Sd 三条谱
  • 伪谱与真实谱、谱速度放大系数 PSV/PGA
  • 多记录谱叠加、均值谱与均值±标准差谱
04

傅里叶谱与功率谱

给出频域描述，用于识别地震动的主频、频带宽度与场地放大特征， 也是人工合成地震动的输入。

  • FFT 幅度谱、相位谱与功率谱密度
  • 窗函数选择（矩形、Hanning、Hamming）
  • 平滑（Konno-Ohmachi 或滑动平均）
  • 反应谱与傅里叶谱对比视图
  • 频带能量占比统计（低/中/高频）
05

Husid 能量与累积曲线

计算累积平方加速度与归一化能量曲线，是持时定义与能量指标的基础， 也能直观看出能量在时间上的分布。

  • Husid 曲线（归一化累积平方加速度）
  • 累积 Arias 强度曲线
  • 5%、95% 能量点自动定位
  • 能量释放速率与瞬时能量
06

强度指标

计算多种反映破坏能力的强度指标，把幅值与持时统一到一个量中， 用于地震动强度分级与结构损伤评估。

  • Arias 强度 Ia 及其单位换算
  • 特征强度 Ic（基于累积损伤）
  • 有效峰值加速度 EPA、有效峰值速度 EPV
  • Housner 谱强度 SI
  • 累积绝对速度 CAV 与 CAV5
07

频带与谱比

通过不同频段的能量与幅值比，判断地震动的频率成分特征， 为场地效应与近断层特性分析提供依据。

  • 低频 / 高频能量比（如 0.5–2 Hz 对 5–10 Hz）
  • 加速度反应谱与速度反应谱之比
  • 水平与竖向谱比（H/V）
  • 不同场地、不同事件间谱比对比
  • 主频与平均周期 Tm、Tp 提取
08

批量对比与统计

面向成百上千条记录，批量计算参数并做分组统计， 快速得到不同震级、距离、场地条件下的参数分布。

  • 按事件、台站、场地类别、距离区间自动分组
  • 输出各组的均值、中位数、标准差与分位数
  • 参数散点图与箱线图
  • 异常记录自动标记与排除
  • 结果导出为 CSV / Excel / JSON
09

参数拟合与回归

在参数之间或参数与震级、距离、场地之间拟合经验关系， 用于预测与校核，也是 GMPE 建模的前置工作。

  • 线性、幂律、对数与多参数回归
  • 最小二乘与稳健回归（RANSAC）
  • 残差分析与决定系数 R²、RMSE 报告
  • 参数间相关系数矩阵
  • 拟合曲线叠加于散点图之上
10

可视化与导出

内置交互式图表与报告生成，便于结果复核、参数敏感性检查与论文制图。

  • 时程、Husid 曲线、反应谱、傅里叶谱四联图
  • 多记录叠加与曲线高亮对比
  • 参数分布直方图、散点图与相关性热图
  • 一键生成参数汇总表（CSV / LaTeX / Markdown）
  • 导出高分辨率 PNG / PDF 与交互式 HTML 报告
Workflow

工作流程

  1. 读取处理后的时程：从预处理结果读取加速度、速度、位移时程及元数据。
  2. 幅值参数计算：提取 PGA、PGV、PGD、RMS 与峰值比。
  3. 能量与持时：计算 Husid 曲线、Arias 强度，据此确定各定义下的持时。
  4. 反应谱计算：对指定阻尼比与周期集合求解单自由度响应，输出 Sa、Sv、Sd。
  5. 频域分析：计算傅里叶幅度谱与功率谱，做平滑与频带能量统计。
  6. 强度指标：计算 Ic、EPA、CAV、Housner 谱强度等复合指标。
  7. 批量统计：对多记录分组统计，输出参数分布与分位数。
  8. 拟合与对比：在参数间做回归，识别主要影响因子。
  9. 出图与导出：生成四联图、汇总表与报告，导出结果文件。
Method

方法与公式

幅值参数

峰值参数取绝对值最大，RMS 反映整条记录的平均能量水平。 峰值时刻对持时与基线校正具有参考意义。

$$ \mathrm{PGA} = \max_t |a(t)|, \qquad t_{\mathrm{PGA}} = \arg\max_t |a(t)| $$ $$ a_{\mathrm{RMS}} = \sqrt{\frac{1}{T} \int_0^T a^2(t) \, dt} $$

PGV/PGA 反映频谱特征：比值大 → 长周期成分相对丰富。

持时定义

括号持时基于幅值阈值（如 0.05g），显著持时与有效持时基于能量累积曲线。 实际分析中必须注明采用了哪种定义，否则不同来源的持时不可直接比较。

Husid 曲线：

$$ H(t) = \frac{\int_0^t a^2(\tau) \, d\tau}{\int_0^T a^2(\tau) \, d\tau} $$

显著持时 / 有效持时（5%–95%）：

$$ D_{5\text{–}95} = t(H = 0.95) - t(H = 0.05) $$

括号持时：

$$ D_{\mathrm{br}} = t_{\mathrm{last}}(|a| > a_0) - t_{\mathrm{first}}(|a| > a_0) $$

反应谱计算

对每个周期 $T$，求解单自由度体系在给定阻尼比 $\zeta$ 下的最大响应。 工程上广泛使用 Newmark-$\beta$ 或 Nigam-Jennings 逐步积分法， 后者无需逐步积分、效率更高。

$$ \ddot{x} + 2\zeta\omega\dot{x} + \omega^2 x = -a_g(t), \qquad \omega = \frac{2\pi}{T} $$ $$ S_d(T,\zeta) = \max_t |x(t)|, \quad S_v(T,\zeta) = \max_t |\dot{x}(t)|, \quad S_a(T,\zeta) = \omega^2 S_d $$

伪谱关系（小阻尼近似）：

$$ \mathrm{PSv} = \omega \, S_d, \qquad \mathrm{PSa} = \omega^2 \, S_d $$

傅里叶谱

对时程做离散傅里叶变换得到频域幅度，通常需要加窗以抑制泄漏， 并可做 Konno-Ohmachi 平滑得到平滑谱。

$$ A(f_k) = \Delta t \left| \sum_{n=0}^{N-1} a_n \, w_n \, e^{-j 2\pi k n / N} \right| $$

单边幅度谱校正因子：

$$ A_{\mathrm{one\text{-}sided}} = \frac{2 \, A(f_k)}{N \, \overline{w}}, \qquad f_k = \frac{k}{N \Delta t} $$

Arias 强度

Arias 强度把加速度平方在时间上积分，是同时包含幅值与持时信息的能量型指标， 在持时定义与结构损伤评估中被广泛使用。

$$ I_A = \frac{\pi}{2g} \int_0^T a^2(t) \, dt $$

离散形式、累积绝对速度与 Housner 谱强度：

$$ I_A = \frac{\pi}{2g} \sum_i a_i^2 \, \Delta t, \quad \mathrm{CAV} = \int_0^T |a(t)| \, dt, \quad \mathrm{SI} = \int_{0.1}^{2.5} \mathrm{PSv}(T, 5\%) \, dT $$
Code

代码示例

下面是一段最小可运行的地震动参数计算示例：幅值、Husid 曲线、显著持时、 Arias 强度与线弹性反应谱。可直接替换为自己的加速度时程数据。

ground_motion_params.py Python 
"""
地震动参数分析最小示例
幅值 / Husid / 显著持时 / Arias 强度 / 反应谱
"""
import numpy as np


def amplitude_params(a, dt):
    """幅值参数"""
    return {
        "PGA": np.max(np.abs(a)),
        "t_PGA": np.argmax(np.abs(a)) * dt,
        "RMS": np.sqrt(np.mean(a ** 2)),
    }


def husid_curve(a, dt):
    """Husid 曲线（归一化累积平方加速度）"""
    ca = np.cumsum(a ** 2) * dt
    total = ca[-1]
    return ca / total if total > 0 else ca


def significant_duration(H, dt, lo=0.05, hi=0.95):
    """基于 Husid 曲线的显著持时"""
    t_lo = np.argmax(H >= lo) * dt
    t_hi = np.argmax(H >= hi) * dt
    return t_hi - t_lo


def arias_intensity(a, dt, g=980.0):
    """Arias 强度（cm/s），输入加速度单位 cm/s²"""
    return (np.pi / (2.0 * g)) * np.sum(a ** 2) * dt


def response_spectrum(a, dt, periods, zeta=0.05):
    """
    线弹性加速度反应谱（简化差分，仅作演示）
    periods : 周期数组（秒）
    """
    Sa = np.zeros(len(periods))
    for i, T in enumerate(periods):
        w = 2.0 * np.pi / T
        u = 0.0
        ud = 0.0
        max_acc = 0.0
        for k in range(1, len(a)):
            u_dd = -a[k] - 2.0 * zeta * w * ud - w ** 2 * u
            ud += u_dd * dt
            u += ud * dt
            abs_acc = abs(u_dd + a[k])
            if abs_acc > max_acc:
                max_acc = abs_acc
        Sa[i] = max_acc
    return Sa


if __name__ == "__main__":
    fs = 100.0
    dt = 1.0 / fs
    t = np.arange(0, 40.0, dt)
    # 合成示意加速度（cm/s²）
    a = 120 * np.sin(2 * np.pi * 2.5 * t) * np.exp(-((t - 6) ** 2) / 12)

    amp = amplitude_params(a, dt)
    H = husid_curve(a, dt)
    D595 = significant_duration(H, dt, 0.05, 0.95)
    IA = arias_intensity(a, dt)

    periods = np.logspace(np.log10(0.01), np.log10(6.0), 60)
    Sa = response_spectrum(a, dt, periods, zeta=0.05)

    print(f"PGA = {amp['PGA']:.2f} cm/s²  (t = {amp['t_PGA']:.2f} s)")
    print(f"RMS = {amp['RMS']:.2f} cm/s²")
    print(f"显著持时 D5-95 = {D595:.2f} s")
    print(f"Arias 强度 Ia = {IA:.3f} cm/s")
    print(f"反应谱峰值 Sa_max = {Sa.max():.2f} cm/s²")
这段代码只做演示：反应谱部分用了简化差分，没有采用完整的 Nigam-Jennings 精确递推，也没有包含基线校正、滤波与三分量处理。 用于实际工程时应使用成熟的反应谱实现（如 OpenSeismoMatlab、pyrotd 或 ObsPy 的响应计算模块），并对结果做数值校核。
