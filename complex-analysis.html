复变函数与积分变换

从复数运算到留数定理，从傅里叶变换到拉普拉斯变换， 覆盖复变函数与积分变换的核心概念。它是振动分析、信号处理、 频域方法、随机振动与地震动谱分析的共同数学基础。

解析函数 留数定理 傅里叶变换 频域方法

§引言

复变函数研究自变量与函数值都取复数的函数。 看似抽象，但它在工程中无处不在：只要涉及到振动、波、信号， 复变函数几乎必然登场。

对结构工程师来说，这套工具的价值体现在三个层面：

  • 振动分析：单自由度体系的复频响应函数 $H(\omega)$ 是传递函数，其极点与系统的固有频率、阻尼直接对应。
  • 积分变换：傅里叶变换把时域卷积变成频域乘积，拉普拉斯变换把微分方程变成代数方程。
  • 频域方法：随机振动、功率谱、传递函数、滤波、地震动谱分析，全部建立在复变函数与积分变换之上。

这份笔记按"复数 $\to$ 解析函数 $\to$ 复积分 $\to$ 级数 $\to$ 留数 $\to$ 傅里叶变换 $\to$ 拉普拉斯变换 $\to$ 工程应用" 的顺序梳理，每一节都尽量落到工程语境上。

01复数与复平面

复数的表示

复数 $z = x + iy$，其中 $i^2 = -1$，$x, y \in \mathbb{R}$。 实部 $\mathrm{Re}(z) = x$，虚部 $\mathrm{Im}(z) = y$。

三种等价表示：

  • 代数形式：$z = x + iy$
  • 三角形式：$z = r(\cos\theta + i\sin\theta)$
  • 指数形式：$z = r e^{i\theta}$

其中 $r = |z| = \sqrt{x^2 + y^2}$ 是模，$\theta = \arg z$ 是辐角。 指数形式由欧拉公式给出：

$$ e^{i\theta} = \cos\theta + i\sin\theta $$

欧拉公式是复变函数中最优美的公式，也是振动分析的核心。 用它把三角函数与指数函数统一：

$$ \cos\theta = \frac{e^{i\theta} + e^{-i\theta}}{2}, \qquad \sin\theta = \frac{e^{i\theta} - e^{-i\theta}}{2i} $$

四则运算与共轭

加减法逐分量运算；乘除法用指数形式最方便：

$$ z_1 z_2 = r_1 r_2 e^{i(\theta_1 + \theta_2)}, \qquad \frac{z_1}{z_2} = \frac{r_1}{r_2} e^{i(\theta_1 - \theta_2)} $$

共轭复数 $\bar{z} = x - iy$，满足：

$$ z \bar{z} = |z|^2, \qquad \overline{z_1 z_2} = \bar{z}_1 \bar{z}_2 $$

棣莫弗公式

由指数形式的乘法性质，立得：

$$ (\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta) $$

这是把三角函数的 $n$ 倍角公式统一成一句话的工具。

复平面上的几何意义

复数与复平面上的点一一对应。 $|z - z_0| = r$ 表示以 $z_0$ 为圆心、$r$ 为半径的圆； $|z - z_1| = |z - z_2|$ 表示到两点等距的垂直平分线。

💡

振动分析中的复数：单自由度体系在简谐激励下的稳态响应为 $u(t) = A e^{i\omega t}$，其中 $A$ 是复振幅， 包含幅值和相位信息。用复数表示可以把三角函数运算变成代数运算， 是频域分析的基本约定。

02解析函数

复变函数的极限与连续

复变函数 $w = f(z)$ 把复平面上的点映射到复平面。 极限 $\lim_{z \to z_0} f(z) = w_0$ 要求 $z$ 沿任意路径趋近 $z_0$ 时，$f(z)$ 都趋近 $w_0$。 这个要求比实函数严格得多。

导数与柯西-黎曼方程

若 $f(z) = u(x, y) + i v(x, y)$ 在 $z_0$ 处可导，则必须满足 柯西-黎曼方程：

$$ \frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \qquad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x} $$

这是复变函数区别于实变函数的核心条件。满足此条件的函数称为解析函数 （或全纯函数）。

解析函数有两条极强的性质：

  • 无穷可微：只要在某点解析，就在该点的邻域内无穷次可微。
  • 调和性：实部 $u$ 与虚部 $v$ 都是调和函数，即 $\nabla^2 u = 0$、$\nabla^2 v = 0$。

初等解析函数

指数函数：

$$ e^z = e^{x + iy} = e^x (\cos y + i \sin y) $$

三角函数（用指数定义）：

$$ \sin z = \frac{e^{iz} - e^{-iz}}{2i}, \qquad \cos z = \frac{e^{iz} + e^{-iz}}{2} $$

对数函数（多值）：

$$ \mathrm{Ln}\, z = \ln |z| + i (\arg z + 2k\pi), \qquad k \in \mathbb{Z} $$

取主值 $\mathrm{ln}\, z = \ln|z| + i \arg z$（$\arg z \in (-\pi, \pi]$）为单值分支。 多值函数的存在是复变函数独有的特性。

工程中的解析函数

  • 传递函数 $H(s)$：在 $s$ 平面（复频域）上有理分式，极点、零点都在复平面上。
  • 保角映射：弹性力学中的复变解法（如孔口问题）利用解析函数保持角度不变的特性。
  • 势流：流体的复势 $w = \phi + i\psi$ 是解析函数，实部与虚部分别是速度势与流函数。
💡

结构动力学中的传递函数：单自由度体系 $m\ddot{u} + c\dot{u} + ku = F(t)$ 在频域内的传递函数为 $H(\omega) = 1/(k - m\omega^2 + i c \omega)$。 它是复变函数的有理函数形式，分母的零点给出固有频率与阻尼， 这正是模态分析与频响函数分析的核心。

03复积分与柯西定理

复积分的定义

复变函数 $f(z)$ 沿曲线 $C$ 的积分定义为：

$$ \int_C f(z) \, dz = \lim_{n \to \infty} \sum_{k=1}^{n} f(\zeta_k) \Delta z_k $$

与实积分类似，但被积函数与积分路径都在复平面上。 复积分具有方向性：换方向则积分变号。

柯西-古萨定理

若 $f(z)$ 在单连通区域 $D$ 内解析，$C$ 是 $D$ 内的任意闭曲线，则：

$$ \oint_C f(z) \, dz = 0 $$

这是复变函数最基本的定理。它表明：解析函数的积分只依赖端点，不依赖路径。 由此可以定义不定积分：

$$ F(z) = \int_{z_0}^{z} f(\zeta) \, d\zeta $$

且 $F'(z) = f(z)$。

柯西积分公式

设 $f(z)$ 在简单闭曲线 $C$ 及其内部解析，$z_0$ 是 $C$ 内一点，则：

$$ f(z_0) = \frac{1}{2\pi i} \oint_C \frac{f(z)}{z - z_0} \, dz $$

这一公式表明：解析函数在区域内部的值完全由边界上的值决定。 这是解析函数"刚性"的本质——知道了边界，就知道了整个区域。

更进一步，解析函数可求高阶导数：

$$ f^{(n)}(z_0) = \frac{n!}{2\pi i} \oint_C \frac{f(z)}{(z - z_0)^{n+1}} \, dz $$

Python 示例：复积分与柯西定理验证

contour_integral.py Python 
import numpy as np

# ---- 数值复积分：沿闭曲线 C 积分 f(z) dz ----

def contour_integral(f, path):
    """
    用梯形法计算复积分。
    path: 复平面上的点序列（首尾闭合）
    """
    z = np.asarray(path, dtype=complex)
    fz = f(z)
    dz = np.diff(z)
    # 梯形法：每段用中点值近似
    return np.sum(0.5 * (fz[:-1] + fz[1:]) * dz)


def circle_path(z0, r, n=2000):
    """以 z0 为中心、r 为半径的圆路径（逆时针）"""
    t = np.linspace(0, 2 * np.pi, n)
    return z0 + r * np.exp(1j * t)


if __name__ == "__main__":
    # ---- 例 1：解析函数 f(z) = z^2 绕单位圆积分 ----
    # 由柯西-古萨定理，结果应为 0
    f1 = lambda z: z**2
    path1 = circle_path(0, 1.0)
    I1 = contour_integral(f1, path1)
    print(f"∮ z^2 dz  (|z| = 1) = {I1:.6e}  （理论值 0）")

    # ---- 例 2：1/z 绕原点积分 ----
    # 理论值 2πi ≈ 6.2832i
    f2 = lambda z: 1 / z
    path2 = circle_path(0, 1.0)
    I2 = contour_integral(f2, path2)
    print(f"∮ 1/z dz  (|z| = 1) = {I2:.6f}  （理论值 2πi）")

    # ---- 例 3：柯西积分公式 ----
    # f(z0) = (1/2πi) ∮ f(z)/(z-z0) dz
    # 取 f(z) = exp(z)，z0 = 0，理论值 f(0) = 1
    f3 = lambda z: np.exp(z) / z
    path3 = circle_path(0, 1.0)
    I3 = contour_integral(f3, path3)
    f_at_0 = I3 / (2j * np.pi)
    print(f"\n柯西积分公式：f(0) = {f_at_0.real:.6f} + "
          f"{f_at_0.imag:.6f}i  （理论值 1）")

运行可以看到：解析函数 $z^2$ 的闭路积分为零（柯西-古萨）， 而有奇点的 $1/z$ 积分给出 $2\pi i$（这是留数定理的直接体现）。

04级数与洛朗展开

泰勒级数

若 $f(z)$ 在圆盘 $|z - z_0| < R$ 内解析，则在该圆盘内可以展开为：

$$ f(z) = \sum_{n=0}^{\infty} a_n (z - z_0)^n, \qquad a_n = \frac{f^{(n)}(z_0)}{n!} $$

这与实函数的泰勒级数形式相同，但复变函数的收敛半径有明确几何意义： $R$ 等于 $z_0$ 到最近奇点的距离。

常用展开（$|z| < 1$）：

$$ \frac{1}{1-z} = \sum_{n=0}^{\infty} z^n, \qquad e^z = \sum_{n=0}^{\infty} \frac{z^n}{n!}, \qquad \ln(1+z) = \sum_{n=1}^{\infty} \frac{(-1)^{n+1}}{n} z^n $$

洛朗级数

如果函数在圆环域 $r < |z - z_0| < R$ 内解析， 则在该圆环内可以展开为双边的幂级数：

$$ f(z) = \sum_{n=-\infty}^{+\infty} a_n (z - z_0)^n $$

其中：

$$ a_n = \frac{1}{2\pi i} \oint_C \frac{f(z)}{(z - z_0)^{n+1}} \, dz $$

洛朗级数包含正幂部分（正则部分）与负幂部分（主要部分）。 负幂部分决定了奇点的性质。

孤立奇点的分类

设 $z_0$ 是 $f(z)$ 的孤立奇点，根据洛朗展开中负幂部分的形态分为三类：

类型负幂部分极限行为示例
可去奇点 全为零 $\lim_{z\to z_0} f(z)$ 有限 $\dfrac{\sin z}{z}$ 在 $z = 0$
$m$ 阶极点 有限项，最高为 $(z-z_0)^{-m}$ $\lim_{z\to z_0} f(z) = \infty$ $\dfrac{1}{z^2}$ 在 $z = 0$（2 阶）
本性奇点 无穷多项 极限不存在（且取值稠密） $e^{1/z}$ 在 $z = 0$

零极点与传递函数

在工程中，传递函数 $H(s)$ 通常是有理分式：

$$ H(s) = \frac{N(s)}{D(s)} = K \frac{(s - z_1)(s - z_2) \cdots}{(s - p_1)(s - p_2) \cdots} $$

$z_i$ 称为零点，$p_i$ 称为极点。 极点的位置决定了系统的稳定性与响应特性：

  • 极点全部在左半平面 $\mathrm{Re}(s) < 0$：系统稳定
  • 极点在虚轴上：系统临界稳定（等幅振荡）
  • 极点在右半平面：系统不稳定（响应发散）

对结构动力学中的单自由度体系，传递函数 $H(\omega) = 1/(k - m\omega^2 + ic\omega)$ 的极点 给出复固有频率：

$$ s_{1,2} = -\zeta \omega_n \pm i \omega_n \sqrt{1 - \zeta^2} $$

实部 $-\zeta \omega_n$ 反映衰减，虚部反映振荡频率。 这就是模态分析中"复模态"的数学来源。

05留数定理

留数的定义

设 $z_0$ 是 $f(z)$ 的孤立奇点，$f(z)$ 在 $0 < |z - z_0| < R$ 内的洛朗展开为：

$$ f(z) = \sum_{n=-\infty}^{+\infty} a_n (z - z_0)^n $$

则 $(z - z_0)^{-1}$ 项的系数 $a_{-1}$ 称为 $f(z)$ 在 $z_0$ 处的留数：

$$ \mathrm{Res}[f, z_0] = a_{-1} $$

留数定理

设 $f(z)$ 在简单闭曲线 $C$ 上及其内部除有限个孤立奇点 $z_1, \ldots, z_n$ 外解析，则：

$$ \oint_C f(z) \, dz = 2\pi i \sum_{k=1}^{n} \mathrm{Res}[f, z_k] $$

这条定理是复变函数最强大的工具之一。它把复杂的围道积分转化为留数的代数求和。

留数的计算

1 阶极点：

$$ \mathrm{Res}[f, z_0] = \lim_{z \to z_0} (z - z_0) f(z) $$

若 $f(z) = P(z)/Q(z)$，$P(z_0) \ne 0$，$Q(z_0) = 0$，$Q'(z_0) \ne 0$：

$$ \mathrm{Res}[f, z_0] = \frac{P(z_0)}{Q'(z_0)} $$

$m$ 阶极点：

$$ \mathrm{Res}[f, z_0] = \frac{1}{(m-1)!} \lim_{z \to z_0} \frac{d^{m-1}}{dz^{m-1}} \left[ (z - z_0)^m f(z) \right] $$

用留数计算实积分

留数定理最重要的应用之一是把某些实积分化为复围道积分。 典型形式：

$$ \int_{-\infty}^{+\infty} f(x) \, dx = 2\pi i \sum_{\mathrm{Im}(z_k) > 0} \mathrm{Res}[f, z_k] $$

条件是 $f(z)$ 在上半平面除有限个极点外解析， 且 $|z| \to \infty$ 时 $|f(z)| \to 0$ 足够快。

例如：

$$ \int_{-\infty}^{+\infty} \frac{dx}{1 + x^2} = \pi, \qquad \int_{-\infty}^{+\infty} \frac{\cos x}{1 + x^2} \, dx = \frac{\pi}{e} $$

Python 示例：留数计算与实积分

residue.py Python 
import numpy as np
import sympy as sp


def residue_example():
    """用 sympy 计算留数"""
    z = sp.Symbol("z")

    # ---- 例 1：f(z) = 1/(1 + z^2)，极点在 z = ±i ----
    f = 1 / (1 + z**2)
    r1 = sp.residue(f, z, sp.I)
    r2 = sp.residue(f, z, -sp.I)

    print("f(z) = 1 / (1 + z^2)")
    print(f"  Res[f, i ] = {r1}")
    print(f"  Res[f, -i] = {r2}")

    # 用留数定理：∫_{-∞}^{+∞} f(x) dx = 2πi · Res[f, i]
    I = 2 * sp.pi * sp.I * r1
    print(f"  ∫ f(x) dx = {sp.simplify(I)}  （理论值 π）")

    print()

    # ---- 例 2：f(z) = e^{iz}/(1 + z^2) ----
    # 用于计算 ∫ cos(x)/(1 + x^2) dx = π/e
    f2 = sp.exp(sp.I * z) / (1 + z**2)
    r = sp.residue(f2, z, sp.I)
    I2 = 2 * sp.pi * sp.I * r
    print("f(z) = e^{iz} / (1 + z^2)")
    print(f"  Res[f, i] = {sp.simplify(r)}")
    print(f"  ∫ cos(x)/(1+x^2) dx = {sp.simplify(I2)}  （理论值 π/e）")


if __name__ == "__main__":
    residue_example()
💡

工程意义：留数定理在振动分析中有两个直接应用： ① 计算脉冲响应函数时，通过对频响函数做拉普拉斯逆变换， 需要求 $H(s) e^{st}$ 的留数； ② 随机振动中的功率谱积分，通过留数定理把复杂的频率积分化为极点处的代数运算。 这使得许多看似困难的频域积分有了封闭解析解。

06傅里叶变换

傅里叶级数

周期为 $T$ 的函数 $f(t)$ 可以展开为三角函数级数：

$$ f(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \left[ a_n \cos(n\omega_0 t) + b_n \sin(n\omega_0 t) \right] $$

其中 $\omega_0 = 2\pi/T$ 是基频。用复指数形式更简洁：

$$ f(t) = \sum_{n=-\infty}^{+\infty} c_n e^{i n \omega_0 t}, \qquad c_n = \frac{1}{T} \int_{-T/2}^{T/2} f(t) e^{-i n \omega_0 t} \, dt $$

傅里叶变换

把周期 $T \to \infty$，傅里叶级数变为傅里叶积分：

$$ F(\omega) = \int_{-\infty}^{+\infty} f(t) e^{-i\omega t} \, dt $$

逆变换：

$$ f(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} F(\omega) e^{i\omega t} \, d\omega $$

$F(\omega)$ 是频谱，$|F(\omega)|$ 是幅值谱，$\arg F(\omega)$ 是相位谱。

傅里叶变换的性质

性质时域频域
线性 $a f + b g$ $a F + b G$
时移 $f(t - t_0)$ $F(\omega) e^{-i\omega t_0}$
频移 $f(t) e^{i\omega_0 t}$ $F(\omega - \omega_0)$
尺度 $f(at)$ $\dfrac{1}{|a|} F\!\left(\dfrac{\omega}{a}\right)$
微分 $f'(t)$ $i\omega F(\omega)$
卷积 $(f * g)(t)$ $F(\omega) G(\omega)$
Parseval $\int |f(t)|^2 dt$ $\dfrac{1}{2\pi} \int |F(\omega)|^2 d\omega$

其中卷积定理是最重要的：时域卷积对应频域乘积。 这是线性时不变系统（LTI）分析的核心——输入信号与系统脉冲响应的卷积， 在频域变成输入频谱与传递函数的乘积。

离散傅里叶变换（DFT）

工程中信号都是离散采样的，用 DFT：

$$ X_k = \sum_{n=0}^{N-1} x_n e^{-i 2\pi kn / N}, \qquad k = 0, 1, \ldots, N-1 $$

快速算法（FFT）把计算量从 $O(N^2)$ 降到 $O(N \log N)$， 是现代信号处理的基石。

Python 示例：矩形脉冲的频谱

fourier.py Python 
import numpy as np
import matplotlib.pyplot as plt


def rect_pulse(t, width=1.0):
    """宽度为 width 的矩形脉冲（中心在 0）"""
    return np.where(np.abs(t) <= width / 2, 1.0, 0.0)


def fft_spectrum(x, dt):
    """对离散信号做 FFT，返回频率轴、幅值谱、相位谱"""
    N = len(x)
    X = np.fft.fft(x)
    freq = np.fft.fftfreq(N, d=dt)

    # 只取正频率部分
    pos = freq >= 0
    freq_pos = freq[pos]
    X_pos = X[pos]

    # 幅值与相位
    amp = np.abs(X_pos) * dt
    phase = np.angle(X_pos)
    return freq_pos, amp, phase


if __name__ == "__main__":
    # 采样参数
    dt = 0.001           # 采样间隔 1 ms
    T = 0.5              # 总时长 0.5 s
    t = np.arange(-T / 2, T / 2, dt)

    # 矩形脉冲
    x = rect_pulse(t, width=0.05)   # 宽 50 ms

    # FFT
    freq, amp, phase = fft_spectrum(x, dt)

    # 理论频谱：矩形脉冲的傅里叶变换 = τ·sinc(ωτ/2)，sinc(u)=sin(u)/u
    tau = 0.05
    omega = 2 * np.pi * freq
    theoretical = np.where(
        np.abs(omega) < 1e-9,
        tau,
        tau * np.sin(omega * tau / 2) / (omega * tau / 2)
    )

    # 打印部分数据对比
    print(f"{'频率 / Hz':>15}{'数值幅值':>18}{'理论幅值':>18}")
    idx = np.linspace(0, 200, 6).astype(int)
    for i in idx:
        print(f"{freq[i]:>15.2f}{amp[i]:>18.6f}{abs(theoretical[i]):>18.6f}")

    plt.figure(figsize=(10, 4))
    plt.plot(freq, amp, label="数值 FFT")
    plt.plot(freq, np.abs(theoretical), "--", label="理论 sinc", alpha=0.7)
    plt.xlabel("f / Hz")
    plt.ylabel("|X(f)|")
    plt.xlim(0, 100)
    plt.legend()
    plt.grid(True, alpha=0.3)
    plt.tight_layout()
    plt.show()

地震工程中的傅里叶变换：地震动加速度时程 $a(t)$ 的傅里叶谱 $|A(f)|$ 反映不同频率成分的能量分布。反应谱是傅里叶谱的"工程化版本"， 更关注结构响应而非信号本身。地震动处理中的基线校正、 滤波、频谱平滑，全部在频域内完成。

07拉普拉斯变换

定义

函数 $f(t)$（$t \ge 0$）的拉普拉斯变换定义为：

$$ F(s) = \mathcal{L}\{f(t)\} = \int_0^{\infty} f(t) e^{-st} \, dt $$

其中 $s = \sigma + i\omega$ 是复变量。 当 $s = i\omega$ 时退化为傅里叶变换（在收敛条件下）。

逆变换：

$$ f(t) = \frac{1}{2\pi i} \int_{c - i\infty}^{c + i\infty} F(s) e^{st} \, ds $$

这是一条复平面上的竖直路径积分，通常用留数定理计算。

常用变换对

$1$（阶跃） $\dfrac{1}{s}$ $\mathrm{Re}(s) > 0$
$t^n$ $\dfrac{n!}{s^{n+1}}$ $\mathrm{Re}(s) > 0$
$e^{-at}$ $\dfrac{1}{s+a}$ $\mathrm{Re}(s) > -a$
$\sin(\omega t)$ $\dfrac{\omega}{s^2 + \omega^2}$ $\mathrm{Re}(s) > 0$
$\cos(\omega t)$ $\dfrac{s}{s^2 + \omega^2}$ $\mathrm{Re}(s) > 0$
$e^{-at}\sin(\omega t)$ $\dfrac{\omega}{(s+a)^2 + \omega^2}$ $\mathrm{Re}(s) > -a$

用拉普拉斯变换解微分方程

拉普拉斯变换最重要的应用是把微分方程变成代数方程。 以单自由度体系的自由振动为例：

$$ m \ddot{u}(t) + c \dot{u}(t) + k u(t) = 0, \qquad u(0) = u_0, \; \dot{u}(0) = v_0 $$

两边做拉普拉斯变换：

$$ (ms^2 + cs + k) U(s) = m s u_0 + m v_0 + c u_0 $$

解得：

$$ U(s) = \frac{m s u_0 + m v_0 + c u_0}{m s^2 + c s + k} $$

再做拉普拉斯逆变换（通常用留数定理或查表）， 得到时域响应 $u(t)$。这就是振动分析中"复频域方法"的基本流程。

Python 示例：用 sympy 求解振动方程

laplace_vibration.py Python 
import sympy as sp


def solve_sdof_vibration():
    """
    用拉普拉斯变换求解单自由度体系自由振动：
        m·ü + c·u̇ + k·u = 0
        u(0) = u0, u̇(0) = v0
    """
    t, s = sp.symbols("t s", real=True)
    m, c, k = sp.symbols("m c k", positive=True)
    u0, v0 = sp.symbols("u0 v0", real=True)

    # 待求函数
    U = sp.Function("U")(s)

    # 拉普拉斯变换后的方程（假设初值 u(0)=u0, u'(0)=v0）
    eq = sp.Eq(
        m * (s**2 * U - s * u0 - v0)
        + c * (s * U - u0)
        + k * U,
        0
    )

    # 解出 U(s)
    U_sol = sp.solve(eq, U)[0]
    U_sol = sp.simplify(U_sol)
    print("U(s) =")
    sp.pprint(U_sol)
    print()

    # 拉普拉斯逆变换
    u_t = sp.inverse_laplace_transform(U_sol, s, t)
    u_t = sp.simplify(u_t)
    print("u(t) =")
    sp.pprint(u_t)


def solve_sdof_forced():
    """
    用拉普拉斯变换求解单自由度体系受迫振动：
        m·ü + c·u̇ + k·u = F0·sin(ω·t)
        u(0) = 0, u̇(0) = 0
    """
    t, s = sp.symbols("t s", real=True)
    m, c, k = sp.symbols("m c k", positive=True)
    F0, omega = sp.symbols("F0 omega", positive=True)

    U = sp.Function("U")(s)

    # sin(ω t) 的拉普拉斯变换
    F_s = F0 * omega / (s**2 + omega**2)

    # 变换后的方程
    eq = sp.Eq(
        m * s**2 * U + c * s * U + k * U,
        F_s
    )

    U_sol = sp.solve(eq, U)[0]
    print("\n受迫振动 U(s) =")
    sp.pprint(sp.simplify(U_sol))

    u_t = sp.inverse_laplace_transform(U_sol, s, t)
    print("\n受迫振动 u(t) =")
    sp.pprint(sp.simplify(u_t))


if __name__ == "__main__":
    solve_sdof_vibration()
    solve_sdof_forced()
💡

为什么结构动力学偏爱拉普拉斯变换： 与傅里叶变换相比，拉普拉斯变换的优势在于 ① 直接包含初始条件，适合求瞬态响应； ② 收敛域更宽，对发散函数也能处理； ③ 极点位置直接对应系统稳定性与模态。 这就是为什么地震工程中的传递函数、频响函数、 反应谱分析都用 $s = -\zeta\omega_n + i\omega_d$ 作为基本变量。

08工程应用

频响函数与传递函数

对线性时不变（LTI）系统，输入 $x(t)$ 与输出 $y(t)$ 的关系在频域中为：

$$ Y(\omega) = H(\omega) X(\omega) $$

其中 $H(\omega)$ 是频响函数。 对单自由度体系：

$$ H(\omega) = \frac{1}{k - m\omega^2 + i c \omega} $$

它的幅值 $|H(\omega)|$ 与相位 $\arg H(\omega)$ 给出系统对每个频率的放大与延迟。

共振与阻尼

当激励频率接近系统固有频率 $\omega_n = \sqrt{k/m}$ 时，$|H(\omega)|$ 达到峰值：

$$ |H(\omega_n)| \approx \frac{1}{2\zeta k} $$

阻尼比 $\zeta$ 越小，峰值越高。这就是共振现象。 半功率带宽法测量阻尼：

$$ \zeta = \frac{\omega_2 - \omega_1}{2\omega_n} $$

其中 $\omega_1, \omega_2$ 是 $|H|$ 降到峰值的 $1/\sqrt{2}$ 处的频率。

随机振动与功率谱

地震动是随机过程，用功率谱密度（PSD）描述其频域特性。 LTI 系统的输出功率谱与输入功率谱的关系：

$$ S_Y(\omega) = |H(\omega)|^2 S_X(\omega) $$

输出的均方（方差）为：

$$ \sigma_Y^2 = \int_{-\infty}^{+\infty} S_Y(\omega) \, d\omega = \int_{-\infty}^{+\infty} |H(\omega)|^2 S_X(\omega) \, d\omega $$

这个积分通常用留数定理计算，是随机振动分析的标准流程。 著名的Kanai-Tajimi 谱、Clough-Penzien 谱 就是为地震动建立的 PSD 模型。

地震反应谱与傅里叶谱的关系

反应谱 $S_a(T, \zeta)$ 与傅里叶幅值谱 $|A(f)|$ 有经验关系：

$$ S_a(T, \zeta) \approx \text{放大因子} \times (2\pi f)^2 |A(f)| $$

但两者有本质区别：

  • 傅里叶谱是信号本身的频域分解，不依赖结构。
  • 反应谱是单自由度体系对信号的最大响应，依赖周期与阻尼比。
  • 傅里叶谱丢失了相位信息（只保留幅值），反应谱保留了峰值信息。

滤波与系统辨识

频域方法是滤波与系统辨识的核心：

  • 理想低通滤波：保留 $|f| < f_c$ 的频率成分，其余置零。
  • Butterworth 滤波：用 $|H(\omega)|^2 = 1/(1 + (\omega/\omega_c)^{2n})$ 逼近理想滤波器。
  • 系统辨识：从输入输出记录估计 $H(\omega) = Y(\omega)/X(\omega)$， 再用最小二乘拟合模态参数。

Python 示例：频响函数与共振峰

frf.py Python 
import numpy as np
import matplotlib.pyplot as plt


def frf_sdof(omega, m, k, c):
    """单自由度体系的频响函数 H(ω) = 1 / (k - mω² + i c ω)"""
    return 1.0 / (k - m * omega**2 + 1j * c * omega)


if __name__ == "__main__":
    # 系统参数
    m = 1.0
    k = 100.0
    omega_n = np.sqrt(k / m)      # 固有频率 = 10 rad/s

    # 频率扫描范围
    omega = np.linspace(0.1, 30, 2000)

    plt.figure(figsize=(10, 5))

    # 三种阻尼比
    for zeta in [0.02, 0.05, 0.10]:
        c = 2 * m * omega_n * zeta
        H = frf_sdof(omega, m, k, c)
        plt.plot(omega, np.abs(H), label=f"ζ = {zeta}")

    plt.axvline(omega_n, color="gray", linestyle="--", alpha=0.5,
                label=f"ω_n = {omega_n:.1f} rad/s")
    plt.xlabel("ω / (rad/s)")
    plt.ylabel("|H(ω)|")
    plt.title("单自由度体系频响函数幅值")
    plt.legend()
    plt.grid(True, alpha=0.3)
    plt.tight_layout()
    plt.show()

    # ---- 用半功率带宽法反推阻尼比 ----
    zeta_true = 0.05
    c = 2 * m * omega_n * zeta_true
    H = frf_sdof(omega, m, k, c)
    H_mag = np.abs(H)

    # 峰值
    idx_peak = np.argmax(H_mag)
    omega_peak = omega[idx_peak]
    H_peak = H_mag[idx_peak]

    # 半功率点
    target = H_peak / np.sqrt(2)
    idx_above = np.where(H_mag >= target)[0]
    omega_1 = omega[idx_above[0]]
    omega_2 = omega[idx_above[-1]]

    zeta_est = (omega_2 - omega_1) / (2 * omega_peak)

    print(f"固有频率 ω_n      = {omega_peak:.4f} rad/s  （真值 {omega_n}）")
    print(f"半功率带宽       = [{omega_1:.4f}, {omega_2:.4f}]")
    print(f"阻尼比估计 ζ     = {zeta_est:.4f}  （真值 {zeta_true}）")

运行后可以看到：阻尼比越小，共振峰越高越窄； 半功率带宽法能从频响曲线中反推出阻尼比，这是实验模态分析的基本方法。

💡

频域方法 vs 时域方法： 时域方法（Newmark-β、RK4）直接积分运动方程， 适合非线性问题、瞬态响应； 频域方法（傅里叶、拉普拉斯）把问题转化为代数运算， 适合线性系统、稳态响应、随机振动。 地震工程中两者互补： 线性分析、反应谱、随机振动用频域； 非线性时程分析、损伤演化用时域。

09小结

📌 核心要点

  • 复数：指数形式 $z = re^{i\theta}$ 与欧拉公式是全部运算的基础。
  • 解析函数：满足柯西-黎曼方程；实部虚部均为调和函数；无穷可微。
  • 柯西定理：解析函数的闭路积分为零；柯西积分公式给出内部值由边界决定。
  • 洛朗级数：含负幂项，是分析奇点性质与计算留数的工具。
  • 留数定理：把围道积分化为极点留数的求和，是计算实积分的利器。
  • 傅里叶变换：时域与频域的桥梁；卷积定理是 LTI 系统分析的核心。
  • 拉普拉斯变换：把微分方程化为代数方程；直接包含初始条件，适合结构动力学。
  • 工程应用：频响函数、共振、随机振动、反应谱、滤波、系统辨识。
