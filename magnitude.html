能量量级对比

横条长度按对数刻度绘制（10⁹ – 10²⁰ J）。震级每增加 1 级， 能量约增大 101.5 ≈ 31.6 倍；增加 2 级约 1000 倍。

方法与说明
标度饱和阈值
Mw 不饱和 基于地震矩，物理量稳定
MS ≈ 8.5 20 s 面波，破裂大于波长后饱和
mb ≈ 6.5 短周期体波，最早发生饱和
ML ≈ 7.0 近震 S 波 / Lg 波

饱和是指传统震级标度在大震时不再随破裂尺度增大而增大。测定震级所用的地震波波长有限， 当断层破裂超过该尺度后振幅趋于"卡住"，从而低估真实地震大小。Mw 不受此限制， 是量度地震大小的首选标度。

震级—能量参考表
Mw 能量 (J) TNT 当量 大致印象

能量按 log₁₀E = 1.5·Mw + 4.8（Gutenberg–Richter）估算，E 单位为焦耳； 地震矩按 log₁₀M₀ = 1.5·Mw + 9.1（M₀ 单位 N·m）估算。 1 吨 TNT = 4.184×10⁹ J，广岛原子弹约 1.5 万吨 TNT 当量。 历史上记录到的最大地震为 1960 年智利地震，Mw ≈ 9.5。

标度换算关系

标度换算采用 Scordilis (2006) 等经验关系：

  • MS → Mw：MS ≤ 6.1 时 Mw = 0.67·MS + 2.07；MS > 6.1 时 Mw = 0.99·MS + 0.08
  • mb → Mw：Mw = 0.85·mb + 1.03（适用 3.5 ≤ mb ≤ 6.2）
  • ML → Mw：Mw = 0.85·ML + 0.85（适用 4.5 ≤ ML ≤ 6.5）

以上关系均为统计拟合结果，超出适用范围时换算仅供量级参考，具体地震应优先采用 Mw。
