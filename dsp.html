数字信号处理

从采样、变换、频域分析到数字滤波器设计，梳理地震波处理中最常用的一套工具链， 也是理解强震记录预处理、谱分析与波形反演的必备基础。

DSP FFT 滤波 采样 信号处理

§引言

地震波是连续的地面运动，被数字地震仪以固定采样率离散化后， 成为一串按时间排列的数值。数字信号处理的目标，是在保持信息的前提下， 对这些数值进行变换、滤波、频谱分析和特征提取。

本笔记覆盖五个核心主题：采样定理决定离散化的上限， Z 变换提供统一的分析框架， DFT/FFT打通时域与频域， 滤波器设计实现频带选择， 窗函数解决截断引起的泄漏。

01采样定理

连续信号的离散化

以采样间隔 $\Delta t$（采样率 $f_s = 1/\Delta t$）对连续信号 $x(t)$ 采样， 得到离散序列 $x[n] = x(n \Delta t)$。要让离散信号无损地恢复原信号，必须满足 Nyquist 采样定理：

$$ f_s > 2 \, f_{\max} $$

其中 $f_{\max}$ 为信号中最高频率成分，$f_s / 2$ 称为 Nyquist 频率

混叠与抗混叠滤波

如果信号中含有高于 $f_s/2$ 的频率成分，采样后会折叠到 低频区域，造成混叠（aliasing）。混叠一旦发生，无法通过后期处理消除。 因此采样前必须使用抗混叠低通滤波器，将高于 $f_s/2$ 的成分滤除。

⚠️

工程意义：地震仪采样率通常为 100 Hz 或 200 Hz， 对应 Nyquist 频率为 50 Hz 或 100 Hz。若原始信号包含更高频率成分， 仪器内部必须先做模拟抗混叠滤波，否则高频噪声会被折叠成假信号。

降采样与升采样

  • 降采样（downsampling）：降低采样率。必须先低通滤波，否则混叠。地震数据常用 decimate 操作把 100 Hz 降到 20 Hz。
  • 升采样（upsampling）：提高采样率，通常通过插值或零填充加低通滤波实现。

02Z 变换

定义

Z 变换是离散信号与系统的核心分析工具，把离散序列 $x[n]$ 映射到复平面上的函数 $X(z)$：

$$ X(z) = \sum_{n=-\infty}^{+\infty} x[n] \, z^{-n} $$

其中 $z = e^{s \Delta t}$ 为复变量，单位圆 $z = e^{j\omega}$ 对应频率响应

与 DFT、拉普拉斯的关系

变换变量适用范围关系
拉普拉斯变换 $s = \sigma + j\omega$ 连续信号 —
Z 变换 $z = e^{s\Delta t}$ 离散信号 $s$ 平面左半 → $z$ 平面单位圆内
DFT $z = e^{j2\pi k/N}$ 有限长序列 Z 变换在单位圆上的等间隔采样

传递函数

离散线性时不变系统的传递函数 $H(z)$ 是输出与输入 Z 变换之比， 通常写成有理函数：

$$ H(z) = \frac{b_0 + b_1 z^{-1} + \cdots + b_M z^{-M}}{1 + a_1 z^{-1} + \cdots + a_N z^{-N}} $$

极点位置决定稳定性：所有极点须在单位圆内

03DFT 与 FFT

离散傅里叶变换

有限长序列 $x[n]$（$n = 0, \ldots, N-1$）的 DFT 定义：

$$ X[k] = \sum_{n=0}^{N-1} x[n] \, e^{-j 2\pi k n / N} $$

$k = 0, 1, \ldots, N-1$，对应频率 $f_k = k / (N \Delta t)$

快速傅里叶变换

DFT 直接计算复杂度为 $O(N^2)$。FFT 通过分治策略将复杂度降到 $O(N \log N)$。 当 $N$ 为 2 的整数次幂时速度最快，因此常用补零（zero-padding）把长度凑到 2 的幂次。

主要性质

性质时域频域
线性$a x + b y$$a X + b Y$
时移$x[n - n_0]$$X[k] \, e^{-j2\pi k n_0 / N}$
频移$x[n] \, e^{j2\pi k_0 n / N}$$X[k - k_0]$
卷积$x[n] * h[n]$$X[k] \cdot H[k]$
帕塞瓦尔$\sum |x[n]|^2$$\frac{1}{N} \sum |X[k]|^2$

Python 实现

fft_spectrum.py Python 
import numpy as np

def fft_spectrum(x, dt, detrend=True, window='hann'):
    """计算单边幅值谱与功率谱"""
    x = np.asarray(x, dtype=float)
    if detrend:
        x = x - np.mean(x)          # 去均值

    N = len(x)
    # 补零到 2 的幂次（可选，加快 FFT）
    Nfft = 1 << (N - 1).bit_length()

    # 窗函数（减少频谱泄漏）
    if window == 'hann':
        w = np.hanning(N)
    elif window == 'hamming':
        w = np.hamming(N)
    else:
        w = np.ones(N)
    xw = x * w

    # FFT
    X = np.fft.rfft(xw, n=Nfft)
    freq = np.fft.rfftfreq(Nfft, d=dt)

    # 单边幅值谱（考虑窗函数能量损失）
    amp = 2.0 * np.abs(X) / (N * np.mean(w))
    amp[0] /= 2.0                     # 直流分量不翻倍

    # 功率谱密度
    psd = (np.abs(X) ** 2) / (Nfft * dt) / np.mean(w ** 2)
    psd[1:] *= 2.0

    return freq, amp, psd
💡

频域分辨率的取舍：$\Delta f = 1/(N \Delta t)$。补零能加密频域采样点， 但不会真正提高分辨率——真实分辨率由记录长度 $N \Delta t$ 决定。

04数字滤波器设计

IIR 与 FIR 对比

类型特点优点缺点
IIR 无限脉冲响应，含反馈 阶数低、计算快、过渡带陡 非线性相位，可能不稳定
FIR 有限脉冲响应，无反馈 严格线性相位、总是稳定 阶数高、计算量大

常用设计方法

  • 巴特沃斯（Butterworth）：通带最平坦，适合地震波处理。
  • 切比雪夫（Chebyshev）：过渡带更陡，但有通带或阻带波纹。
  • 椭圆（Elliptic）：过渡带最陡，通带和阻带都有波纹。
  • 窗函数法（FIR）：用理想滤波器加窗截断，简单直观。
  • 最小二乘 / Parks-McClellan（FIR）：等波纹最优设计。

零相位滤波

地震波处理常要求零相位，避免波形偏移。 方法是前向-反向两次滤波（filtfilt）： 先正着滤一遍，再倒序滤一遍，两次的相位失真相互抵消。

zero_phase_filter.py Python 
from scipy import signal
import numpy as np

def bandpass_zero_phase(x, dt, fmin, fmax, order=4):
    """零相位带通滤波"""
    fs = 1.0 / dt
    nyq = fs / 2.0
    # 归一化频率（0~1，Nyquist 为 1）
    low = fmin / nyq
    high = fmax / nyq
    # 设计 Butterworth 带通
    b, a = signal.butter(order, [low, high], btype='band')
    # 前向-反向滤波，得到零相位
    y = signal.filtfilt(b, a, x)
    return y

def check_stability(b, a):
    """检查 IIR 滤波器稳定性（极点是否在单位圆内）"""
    poles = np.roots(a)
    return np.all(np.abs(poles) < 1.0)
⚠️

常见坑：filtfilt 会引入额外的瞬态效应， 建议在信号两端做镜像延拓或斜坡延拓， 减少边缘失真。此外，滤波器阶数不要盲目调高，否则数值误差可能引发不稳定。

05窗函数与频谱泄漏

泄漏的根源

对无限长信号做 DFT，实际上是对信号加了一个矩形窗。 如果信号频率不是 $\Delta f$ 的整数倍，能量会从主瓣“泄漏”到旁瓣， 造成频谱估计失真。

常用窗函数

窗函数主瓣宽度旁瓣衰减适用场景
矩形最窄−13 dB瞬态信号、脉冲
汉宁（Hann）中等−31 dB通用随机信号
汉明（Hamming）中等−41 dB窄带信号
布莱克曼（Blackman）较宽−57 dB强动态范围
凯泽（Kaiser）可调可调灵活设计

选择原则

  • 主瓣窄：分辨相邻频率成分能力强。
  • 旁瓣低：泄漏少，弱信号不易被强信号掩盖。
  • 两者不能兼顾——主瓣越窄，旁瓣越高。
  • 地震波分析常用 Hann 或 Hamming 窗。
💡

补零并不等于加窗：补零只是在频域插值，不会减少泄漏。 泄漏由截断长度和窗函数共同决定，与补零无关。

06小结

📌 核心要点

  • 采样定理：$f_s > 2 f_{\max}$，采样前必须抗混叠低通。
  • Z 变换：离散系统的统一分析工具，单位圆上对应频响。
  • DFT/FFT：时频桥梁，频域分辨率由记录长度决定。
  • IIR vs FIR：IIR 高效但不保证线性相位；FIR 稳定且线性相位，但阶数高。
  • 零相位滤波：地震波处理的标准做法，用 filtfilt 实现。
  • 窗函数：抑制泄漏，Hann/Hamming 是通用选择。
