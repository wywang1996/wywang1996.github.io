一致危险性谱 UHS

在多个周期上分别做 PSHA，取每个周期上相同年超越概率 对应的谱加速度 Sa(T)，连成一条曲线即一致危险性谱 (Uniform Hazard Spectrum)。它是连接地震危险性分析与结构抗震设计的核心图件。

工程地震 PSHA CSV 输入 Python / MATLAB A4 尺寸

数据来源

  • PSHA 计算程序——OpenQuake、CRISIS、EZ-FRISK 等， 对一组周期分别计算危险性曲线，再取等概率线。
  • 规范区划图——GB 18306《中国地震动参数区划图》给出 全国各城镇的 50 年 10% 和 2% 设防水准 Sa(T)，可直接查表。
  • 专项地震安全性评价报告——重大工程场地会给出 多周期、多设防水准的一致危险性谱。
本页示例是一份典型的场地 UHS： 短周期段 Sa ≈ 0.18 g（475 年）与 0.42 g（2475 年）， 谱峰在 T ≈ 0.4 s 附近，长周期段随 T 逐渐衰减。 两个水准的比值 Sa2475/Sa475 约在 2.2–2.8 之间。
Meaning

三张图说明了什么

一致危险性谱在每一个周期上，都对应同一个年超越概率。 严格地说，它并不是"某一次地震"的反应谱，而是"最不利地震场景组合" 的包络。这与规范设计谱的物理意义不同——后者是一条经过平滑和 保守调整的标准化谱。

(a) UHS at two hazard levels · 两个设防水准

同时展示 50 年 10%（多遇地震）与 50 年 2% （罕遇地震）两条 UHS：

  • 两条曲线形状相似，但罕遇曲线整体高出约 2.5–3 倍；
  • 谱峰位置都在 T ≈ 0.3–0.5 s，反映场地卓越周期；
  • 长周期段两者差别逐渐缩小，因为极端事件对长周期贡献有限。

(b) UHS vs GB 50011 design spectrum · 与规范设计谱对比

把 UHS 与 GB 50011-2010 在 8 度（0.2 g）设防下的设计谱对比：

  • 规范设计谱采用四段分段函数（平台段、下降段、直线下降段）， 是平滑化的保守包络；
  • UHS 是真实计算谱，谱形不够光滑，但更贴近物理；
  • UHS 与规范谱在短周期段可能接近，在中长周期段往往有差异。

(c) Spectral ratio · 谱比 Sa(2475)/Sa(475)

两个设防水准的谱加速度比值随周期的变化：

  • 短周期段（T < 0.3 s）比值约 2.2–2.4；
  • 中周期段（0.3–1 s）比值约 2.5–2.9；
  • 长周期段（T > 2 s）比值逐渐趋向 2.0；
  • 整体比值在 2.2–3.0 之间，可作为不同水准地震动的快速换算系数。
UHS 的物理诠释：UHS 每个周期上的值来自不同的地震场景。 例如短周期 Sa 可能由近场小震（M6）控制，而长周期 Sa 由远场大震（M8）控制。 因此 UHS 是一条人工包络，而不是任何一次真实地震的反应谱。 与 UHS 相对的，是条件均值谱（CMS）——它固定了某个周期的 Sa 值，其他周期用解聚结果的条件分布计算，物理上更一致。
注意：UHS 通常是基岩或参考场地 （Vs30 = 760 m/s）的结果。用于具体场地时需要按场地放大因子调整 （见 transfer-function.html）。

Python

Python 代码

依赖 numpy 与 matplotlib。 读取 CSV 后绘制三张子图，并包含 GB 50011 设计谱的实现。

uhs.pyPython
# =============================================================
# 一致危险性谱 UHS（Uniform Hazard Spectrum）
# -------------------------------------------------------------
# 输入数据：uhs.csv
#   period_s,Sa_475_g,Sa_2475_g
#   0.010,0.182,0.420
#   ...
# -------------------------------------------------------------
# 三张子图：
#   (a) UHS at 50yr 10% and 2%
#   (b) 与 GB 50011 设计谱对比
#   (c) 谱比 Sa(2475)/Sa(475)
# =============================================================

import os
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['Times New Roman', 'Songti SC', 'SimSun'],
    'font.size': 9,
    'axes.linewidth': 0.8,
    'xtick.direction': 'in',
    'ytick.direction': 'in',
})

CSV_FILE = 'uhs.csv'


def gb50011_spectrum(T, alpha_max, Tg=0.4, zeta=0.05):
    """GB 50011-2010 地震影响系数曲线（阻尼比 zeta，特征周期 Tg）。"""
    eta2 = 1 + (0.05 - zeta) / (0.08 + 1.6 * zeta)
    gamma = 0.9 + (0.05 - zeta) / (0.3 + 6 * zeta)
    eta1 = 0.02 + (0.05 - zeta) / (4 + 32 * zeta)

    alpha = np.zeros_like(T)
    for i, Ti in enumerate(T):
        if Ti < 0.1:
            alpha[i] = (0.45 + 10 * (eta2 - 0.45) * Ti) * alpha_max
        elif Ti < Tg:
            alpha[i] = eta2 * alpha_max
        elif Ti < 5 * Tg:
            alpha[i] = (Tg / Ti) ** gamma * eta2 * alpha_max
        else:
            alpha[i] = (eta2 * 0.2 ** gamma - eta1 * (Ti - 5 * Tg)) * alpha_max
    return alpha


def generate_synthetic():
    """CSV 缺失时的合成数据。"""
    T = np.array([0.01, 0.02, 0.05, 0.10, 0.15, 0.20, 0.30, 0.40, 0.50,
                  0.75, 1.00, 1.50, 2.00, 3.00, 4.00, 5.00, 6.00, 8.00, 10.0])
    Sa_475  = np.array([0.182, 0.185, 0.192, 0.221, 0.268, 0.318, 0.385,
                        0.412, 0.402, 0.341, 0.282, 0.192, 0.135, 0.075,
                        0.048, 0.033, 0.024, 0.014, 0.009])
    Sa_2475 = np.array([0.420, 0.428, 0.451, 0.538, 0.685, 0.835, 1.052,
                        1.168, 1.138, 0.942, 0.762, 0.498, 0.342, 0.182,
                        0.112, 0.075, 0.053, 0.030, 0.019])
    return T, Sa_475, Sa_2475


# ---------- 1. 读取 CSV ----------
if os.path.exists(CSV_FILE):
    data = np.genfromtxt(CSV_FILE, delimiter=',', names=True,
                         dtype=None, encoding='utf-8')
    T        = np.asarray(data['period_s'],   dtype=float)
    Sa_475   = np.asarray(data['Sa_475_g'],   dtype=float)
    Sa_2475  = np.asarray(data['Sa_2475_g'],  dtype=float)
    mask = (T > 0) & (Sa_475 > 0) & (Sa_2475 > 0)
    T, Sa_475, Sa_2475 = T[mask], Sa_475[mask], Sa_2475[mask]
    print(f'从 {CSV_FILE} 读取 {len(T)} 个周期点')
else:
    print(f'{CSV_FILE} 不存在，使用合成数据演示')
    T, Sa_475, Sa_2475 = generate_synthetic()


# ---------- 2. 谱比 ----------
ratio = Sa_2475 / Sa_475


# ---------- 3. 三张子图 ----------
fig, axes = plt.subplots(3, 1, figsize=(7.2, 8.0))

# ===== (a) UHS 两个设防水准 =====
ax = axes[0]
ax.loglog(T, Sa_475,  lw=1.8, color='#b45309',
          marker='o', ms=3.5, mfc='#b45309', mec='none',
          label='50 yr 10% (λ = 1/475)')
ax.loglog(T, Sa_2475, lw=1.8, color='#dc2626',
          marker='s', ms=3.5, mfc='#dc2626', mec='none',
          label='50 yr 2% (λ = 1/2475)')
ax.set_xlabel('Period T (s)')
ax.set_ylabel('Sa (g)')
ax.set_title('(a) Uniform Hazard Spectrum  ·  two hazard levels', fontsize=10)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='upper right', fontsize=8, frameon=False)

# ===== (b) 与 GB 50011 设计谱对比 =====
ax = axes[1]
ax.loglog(T, Sa_475,  lw=1.6, color='#b45309', label='UHS · 10% in 50yr')
ax.loglog(T, Sa_2475, lw=1.6, color='#dc2626', label='UHS · 2% in 50yr')

# GB 50011 设计谱（8 度 0.2g，II 类场地，Tg = 0.4 s）
T_curve = np.logspace(np.log10(0.01), np.log10(10), 400)
# 多遇地震：alpha_max ≈ 0.16
gb_minor = gb50011_spectrum(T_curve, alpha_max=0.16, Tg=0.4)
# 罕遇地震：alpha_max ≈ 0.90
gb_major = gb50011_spectrum(T_curve, alpha_max=0.90, Tg=0.4)

ax.loglog(T_curve, gb_minor, lw=1.2, color='#2563eb', ls='--',
          label='GB 50011 · frequent (8°, 0.16g)')
ax.loglog(T_curve, gb_major, lw=1.2, color='#9333ea', ls='--',
          label='GB 50011 · rare (8°, 0.90g)')

ax.set_xlabel('Period T (s)')
ax.set_ylabel('Sa (g)')
ax.set_title('(b) UHS vs GB 50011 design spectrum  ·  Tg = 0.4 s', fontsize=10)
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='upper right', fontsize=8, frameon=False)

# ===== (c) 谱比 =====
ax = axes[2]
ax.semilogx(T, ratio, lw=1.8, color='#15803d',
            marker='o', ms=3.5, mfc='#15803d', mec='none')
ax.axhline(1.0, color='#888888', lw=0.5, ls='--')
ax.axhline(np.mean(ratio), color='#888888', lw=0.7, ls=':',
           label=f'mean = {np.mean(ratio):.2f}')
ax.set_xlabel('Period T (s)')
ax.set_ylabel('Sa(2475) / Sa(475)')
ax.set_title('(c) Spectral ratio between two hazard levels', fontsize=10)
ax.set_ylim(1.5, max(3.5, np.max(ratio) * 1.1))
ax.grid(True, which='major', ls=':', lw=0.4, alpha=0.6)
ax.legend(loc='upper right', fontsize=8, frameon=False)

for ax in axes:
    ax.tick_params(direction='in', which='both', top=True, right=True)

fig.tight_layout()
fig.savefig('uhs.png', dpi=300, bbox_inches='tight')
plt.show()

# ---------- 4. 打印关键量 ----------
print(f'谱比范围：{np.min(ratio):.3f} – {np.max(ratio):.3f}')
print(f'谱比均值：{np.mean(ratio):.3f}')
关键点：
  • UHS 双对数坐标：横轴周期 T、纵轴 Sa，都是对数。
  • GB 50011 设计谱：四段分段函数，αmax 对应 多遇（0.16）与罕遇（0.90）设防水准。
  • 谱比：两个设防水准的 Sa 比值，反映罕遇/多遇的 "放大倍数"，是快速的工程估算手段。
  • η1, η2, γ 是阻尼调整系数， ζ = 0.05 时 η2 = 1、γ = 0.9。

% ===== 局部函数：GB 50011 设计谱 =====
function alpha = local_gb50011(T, alpha_max, Tg, zeta)
    eta2 = 1 + (0.05 - zeta) / (0.08 + 1.6 * zeta);
    gamma = 0.9 + (0.05 - zeta) / (0.3 + 6 * zeta);
    eta1 = 0.02 + (0.05 - zeta) / (4 + 32 * zeta);

    if T < 0.1
        alpha = (0.45 + 10 * (eta2 - 0.45) * T) * alpha_max;
    elseif T < Tg
        alpha = eta2 * alpha_max;
    elseif T < 5 * Tg
        alpha = (Tg / T) ^ gamma * eta2 * alpha_max;
    else
        alpha = (eta2 * 0.2 ^ gamma - eta1 * (T - 5 * Tg)) * alpha_max;
    end
end
Notes

方法与说明

输入 / 输出量纲一览

项符号单位
输入 · 周期Ts
输入 · 谱加速度（多遇）Sa475g
输入 · 谱加速度（罕遇）Sa2475g
输出 · 谱比Sa2475/Sa475无量纲
输出 · 设计谱（对比）α(T)无量纲（相当于 Sa/g）
  • UHS 定义：对每一个周期 T，找到相同年超越概率 对应的 Sa(T)，连成曲线。
  • 与设计谱的区别：设计谱是标准化 + 保守包络； UHS 是真实计算结果的等概率线。
  • 与 CMS 的区别：CMS（条件均值谱）固定一个周期的 Sa， 其他周期用条件分布计算，物理上更一致。
  • 设防水准换算：50 年超越概率 P 对应年超越概率 λ = 1 − (1−P)1/50。P = 10% → λ ≈ 1/475；P = 2% → λ ≈ 1/2475。
  • 与危险性曲线的关系：危险性曲线是单一周期上的 λ–PGA 关系；UHS 是把多周期的危险性曲线放在同一概率截面上。
  • 常见问题：
    • UHS 曲线不光滑 → 每个周期的 Sa 来自不同地震场景，属正常现象。
    • 长周期段 Sa 不收敛 → 数据精度不足或周期覆盖不够，需扩展 PSHA 计算范围。
    • 与规范设计谱差别很大 → 检查设防烈度与场地类别，UHS 与规范谱的 设防标准要对应。
    • 谱比异常大（> 4） → 检查是否混用了不同阻尼比或不同场地条件的数据。
