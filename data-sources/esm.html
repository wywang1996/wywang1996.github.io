ESM 工程强震库

Engineering Strong-Motion Database（ESM）是由意大利国家地球物理与火山学研究所（INGV） 在 ORFEUS 框架下开发的泛欧洲工程强震动数据库，收录欧洲-地中海及中东地区 M≥4.0 地震事件的经质量检查的人工处理三分量强震动波形数据。 数据通过统一 Web 平台与 Web 服务发布，支持在线检索、下载与处理。

Overview

概述

ESM（Engineering Strong-Motion Database）是欧盟 EPOS 项目 （European Plate Observing System）框架下的强震动数据分发基础设施， 由意大利国家地球物理与火山学研究所（Istituto Nazionale di Geofisica e Vulcanologia, INGV）在 ORFEUS（Observatories and Research Facilities for European Seismology）强震动工作组框架下开发和维护。 数据库于 NERA 项目期间建立，自 2016 年起正式对外服务，当前版本为 3.0。

ESM 的核心定位是面向工程地震学的统一处理强震动数据平台。 与分散在各地台网的原始记录不同，ESM 提供经质量检查、统一处理、 元数据完整的强震动波形，处理方案遵循 Paolucci et al. (2011) 方法。 数据库集中分发来自约 50 个欧洲台网的加速度记录， 覆盖欧洲-地中海及中东地区，时间跨度自 1969 年至今。

数据规模

  • 记录总数：超过 23,000 条经人工处理的三分量记录。
  • 事件数：约 2,179 次地震（M≥4.0）。
  • 台站数：约 2,080 个台站，分布于欧洲-地中海及中东地区。
  • 时间范围：自 1969 年至今，持续更新。

数据处理流程

ESM 的波形从地震发生到发布需经过四个标准化步骤：

  • 数据上传：M≥4.0 事件发生后，自动从 ORFEUS 或 IRIS 下载可用记录， 同时检索离线数据仓库中的历史记录。
  • 数据处理：低质量记录（含尖峰或信噪比过低）不予处理， 仅以未处理版本发布；高质量记录按 Paolucci et al. (2011) 方法人工处理， 得到校正加速度、速度、位移时程及 5% 阻尼反应谱。
  • 数据发布：处理完成的记录在数小时至数天内发布， 附初步震源信息。
  • 数据库修订：台站与事件元数据定期修订， 以 ISC 公告为全球事件的权威信息源（通常滞后实时约 24 个月）。

处理类型标识

ESM 记录在文件名中标注处理类型，便于用户识别：

  • CV：未处理加速度，仅转换为物理单位（cm/s²）。
  • MP：人工处理（Manual Processing），按 Paolucci et al. (2011) 方法。
  • AP：自动处理（Automatic Processing），按同一方法自动执行。
与 PEER NGA 的差异： ESM 与 NGA-West2 均提供统一处理的强震动记录，但两者定位不同。 NGA-West2 侧重全球活动构造区浅地壳地震的 GMPE 标定， 记录经过严格的筛选与均一化处理； ESM 侧重欧洲-地中海及中东区域的工程强震动数据分发， 覆盖台网更广（约 50 个），提供在线处理工具与 Web 服务接口。 两者在区域覆盖上互补。
Format

数据格式

ESM 提供多种波形与谱数据格式，用户可根据分析需求选择。 点击下方标签查看每种格式的详情。

ASDF / HDF5 格式

默认格式 · 波形与谱数据统一存储

ASDF（Adaptable Seismic Data Format）基于 HDF5 构建， 是 ESM Event-Data Web-Service 的默认输出格式。 波形与反应谱统一存储在 ASDF 卷的 AuxiliaryData 结构中， 便于批量管理与程序化读取。

ASCII（DYNA 1.2）格式

文本格式 · 64 行文件头

ASCII 格式遵循 DYNA 1.2 标准，文件由 64 行文件头 与数据区组成。文件头包含事件、台站、处理参数等自描述信息， 数据区为加速度、速度、位移或反应谱的数值序列。 可通过 Event-Data Web-Service 下载 ZIP 压缩包，内含各分量 ASCII 文件。

Flatfile 元数据

CSV 参数表 · 元数据与强度指标

ESM Flatfile 是一个参数表，以 CSV 格式提供经人工处理的 波形所关联的元数据与强度指标。每条记录一行，涵盖事件、台站、路径及 强度参数。该表可通过 Flatfile Web-Service 按用户条件定制输出， 也支持 ESRI Shapefile 格式。

Flowchart

下载流程

ESM 提供网页交互界面和Web 服务（编程接口） 两种数据获取方式。网页界面适合交互式检索与少量下载， Web 服务适合批量、程序化的数据获取。整体流程如下：

1
访问 ESM 门户
进入 https://esm-db.eu。 ESM 数据开放访问，无需注册即可检索和下载。 网页界面提供事件、台站、波形和断层的交互式检索工具。
2
检索目标数据
可通过以下入口检索：
① 事件检索 — 按地震事件浏览； ② 台站检索 — 按台站浏览； ③ 地图检索 — 在交互地图上选择； ④ 参数检索 — 按震级、距离、PGA 等约 35 个元数据字段筛选。
3
选择数据格式
根据分析需求选择输出格式： ASDF（默认）、 ASCII（DYNA 1.2）、 或通过 Processing Post 服务获取 MiniSEED / SAC。 也可仅下载 Flatfile 元数据。
4
下载数据
网页下载：在事件或台站页面选择记录，点击下载。 Web 服务下载：通过 Event-Data Web-Service、 Flatfile Web-Service 等接口以编程方式获取数据。 单次请求波形或谱数据上限为 1,000 条。
5
格式转换与使用
ASDF 文件可用 pyasdf、h5py 读取； 如需其他格式，可使用 dyna-convert.py 转换为 MiniSEED、SAC、GSE、SEGY 等格式（需 ObsPy）。 ASCII 文件可直接用文本编辑器或脚本读取，注意 64 行文件头。
Web 服务概览： ESM 提供丰富的 Web 服务接口，包括 Event-Data（波形与谱）、 Flatfile（元数据表）、 Processing（波形处理）、 Processing Post（下载处理结果）、 OGC WFS/WMS（事件、台站、断层几何元数据）等。 详细用法参见 esm-db.eu 的 Web 服务文档。
Data Files

下载数据文件说明

1. 波形文件命名规则

ESM 波形文件命名遵循 FDSN SEED 标准（SEED Format Version 2.4）， 结构如下：

net_code.station_code.location_code.channel_code.D.date.time.processing_type.waveform_type.format
字段 说明
net_code FDSN 台网代码，如 IT（意大利）
station_code 台站代码（3–5 个字符）
location_code 通道位置代码，如自由场或不同深度
channel_code 通道代码，3 位：频带码（H=宽带）+ 仪器码（N/L/G=加速度计）+ 方向码（Z/N/E 或 Z/2/3）
processing_type X = 未处理 / C = 已处理
waveform_type ACC / VEL / DIS / SA / PSV / SD
format .ASC（ASCII）等
示例： IT.SGIUB..HNN.D.20021112.092748.X.ACC.ASC — 意大利台网 SGIUB 台站，2002-11-12 09:27:48 GMT， 未处理加速度 NS 分量，ASCII 格式。

2. ASCII 文件头关键字段

ASCII 文件包含 64 行文件头，主要字段如下：

行号 字段 说明
1EVENT_NAME地震事件名称
2EVENT_ID数据库中的事件 ID
3EVENT_DATE_YYYYMMDDGMT 事件日期
4EVENT_TIME_HHMMSSGMT 发震时刻
5EVENT_LATITUDE_DEGREE事件纬度（十进制）
6EVENT_LONGITUDE_DEGREE事件经度（十进制）
7EVENT_DEPTH_KM事件深度（km）
8HYPOCENTER_REFERENCE震源参考
9MAGNITUDE_W矩震级 Mw
10MAGNITUDE_W_REFERENCEMw 参考
11MAGNITUDE_L地方震级 ML
完整字段列表（共 64 行）参见 ESM 0.1 用户手册的 “ASCII HEADER” 章节。

Notes

下载注意事项

  1. 开放访问，无需注册： ESM 数据免费开放访问，无需注册账号即可检索和下载。 这与 PEER NGA（需邮箱注册）和 CSMNC（需实名认证）不同。
  2. 记录门槛与覆盖范围： ESM 收录 M≥4.0 的事件， 覆盖欧洲-地中海及中东地区，时间跨度自 1969 年。 不包含全球其他区域的记录，跨区域研究需与其他数据库配合使用。
  3. 处理类型需区分： 下载时注意文件命名中的处理类型标识： CV（未处理）、MP（人工处理）、 AP（自动处理）。 人工处理记录质量更高，但数量少于自动处理记录。
  4. 低质量记录仅提供未处理版本： 含尖峰或信噪比过低的记录不予处理， 仅以未处理（CV）版本发布。使用前应自行评估质量。
  5. 单次请求上限： 通过 Event-Data Web-Service 获取波形或谱数据时， 单次请求上限为 1,000 条。批量获取需分批处理。
  6. ASDF 读取需专用工具： ASDF 基于 HDF5，需使用 pyasdf、h5py 或 HDFView 等工具读取。如需其他格式， 可使用 dyna-convert.py 转换（需 ObsPy）。
  7. 元数据修订周期： 台站与事件元数据定期修订，全球事件以 ISC 公告为准， 通常滞后实时约 24 个月。 使用时应关注元数据版本，并在论文中注明数据获取日期。
  8. 引用要求： 使用 ESM 数据需引用官方 DOI： 10.13127/esm.3，并注明数据来源。 具体引用格式见下一节。
